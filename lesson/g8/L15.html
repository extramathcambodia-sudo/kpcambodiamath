មេរៀនទាំងអស់
ប្រវត្តិនៃធរណីមាត្ររង្វង់ និងការស្វែងរកតម្លៃ \(\pi\) របស់អាស៊ីម៉ែត

រង្វង់ គឺជារូបធរណីមាត្រដ៏ល្អឥតខ្ចោះ និងមានអត្ថន័យជ្រាលជ្រៅបំផុតក្នុងវិទ្យាសាស្ត្រ ៖

  • ដើមកំណើតបុរាណ ៖ មនុស្សជាតិបានស្គាល់រង្វង់តាំងពីយុគសម័យបុរេប្រវត្តិ តាមរយៈការសង្កេតព្រះច័ន្ទពេញវង់ និងព្រះអាទិត្យ។ ការបង្កើត «កង់រទេះ» នៅមេសូប៉ូតាមី (ប្រហែល ៣៥០០ មុន គ.ស.) គឺជាបដិវត្តន៍បច្ចេកវិទ្យាដំបូងដែលពឹងផ្អែកលើលក្ខណៈរង្វង់។

  • អាស៊ីម៉ែត នៃស៊ីរ៉ាគូស (Archimedes, c. 287–212 មុន គ.ស.) ៖ គណិតវិទូក្រិកដ៏ឆ្នើម បានបង្កើតវិធីសាស្ត្រគណនាតម្លៃនៃចំនួន \(\pi\) យ៉ាងសុក្រឹតតាមរយៈការពន្លាតពហុកោណចារឹកក្នុង និងចារឹកក្រៅរង្វង់រហូតដល់ ៩៦ ជ្រុង ដោយរកឃើញថា ៖

    \[3\frac{10}{71} < \pi < 3\frac{1}{7} \quad{} (3.1408 < \pi < 3.1428)\]

  • អឺគ្លីដ (Euclid, c. 300 មុន គ.ស.) ៖ ក្នុងគម្ពីរ The Elements (សៀវភៅទី ៣) បានចងក្រងទ្រឹស្ដីបទស្តីពីអង្កត់ធ្នូ បន្ទាត់ប៉ះ មុំចារឹកក្នុង និងមុំផ្ចិត ដែលជាគ្រឹះនៃធរណីមាត្ររង្វង់រហូតមកដល់បច្ចុប្បន្ន។

ធាតុគ្រឹះនៃរង្វង់

និយមន័យ និងធាតុផ្សេងៗ

រង្វង់

រង្វង់ផ្ចិត \(O\) កាំ \(R\) (តាងដោយ \(\mathcal{C}(O, R)\)) គឺជាសំណុំនៃគ្រប់ចំណុច \(M\) ក្នុងប្លង់ ដែលស្ថិតនៅស្មើចម្ងាយ \(R\) ពីចំណុចនឹង \(O\) ៖

\[\mathcal{C}(O, R) = \{ M \mid OM = R \}\]

  • កាំ (Radius) ៖ ជាអង្កត់ភ្ជាប់ពីផ្ចិតទៅកាន់ចំណុចណាមួយនៅលើរង្វង់ (\(OA = R\))។

  • អង្កត់ធ្នូ (Chord) ៖ ជាអង្កត់ភ្ជាប់ពីចំណុចពីរផ្សេងគ្នានៅលើរង្វង់ (\(AB\))។

  • អង្កត់ផ្ចិត (Diameter) ៖ ជាអង្កត់ធ្នូដែលកាត់តាមផ្ចិតរង្វង់។ អង្កត់ផ្ចិតជាអង្កត់ធ្នូវែងជាងគេ ៖ \(D = 2R\)។

  • ធ្នូ (Arc) ៖ ជាផ្នែកនៃរង្វង់ដែលខណ្ឌដោយចំណុចពីរនៅលើរង្វង់ (តាងដោយ \(\overset{\frown}{AB}\))។

រូបភាពនេះកំពុងរៀបចំ

ទំនាក់ទំនងរវាងអង្កត់ផ្ចិត និងអង្កត់ធ្នូ

លក្ខណៈអង្កត់ផ្ចិត និងអង្កត់ធ្នូ

  1. អង្កត់ផ្ចិតដែលកែងនឹងអង្កត់ធ្នូ ត្រូវចែកអង្កត់ធ្នូនោះ និងធ្នូស្កាត់ជាពីរស្មើគ្នា។

  2. អង្កត់ផ្ចិតដែលកាត់តាមចំណុចកណ្តាលនៃអង្កត់ធ្នូ (មិនមែនអង្កត់ផ្ចិត) ត្រូវកែងនឹងអង្កត់ធ្នូនោះ។

  3. បន្ទាត់មេដ្យាទ័រនៃអង្កត់ធ្នូណាមួយ តែងតែកាត់តាមផ្ចិតនៃរង្វង់ជានិច្ច។

អង្កត់ធ្នូ និងចម្ងាយពីផ្ចិត

ក្នុងរង្វង់មួយ ឬក្នុងរង្វង់ពីរប៉ុនគ្នា ៖

  1. អង្កត់ធ្នូពីរប៉ុនគ្នា លុះត្រាតែវាស្ថិតនៅស្មើចម្ងាយពីផ្ចិត ៖

    \[AB = CD \iff OH = OK\]

  2. ក្នុងចំណោមអង្កត់ធ្នូពីរ អង្កត់ធ្នូណាវែងជាង ត្រូវស្ថិតនៅជិតផ្ចិតជាង ៖

    \[AB > CD \iff OH < OK\]

រូបភាពនេះកំពុងរៀបចំ

ឧទាហរណ៍

រង្វង់ផ្ចិត \(O\) មានកាំ \(R = 10\text{ cm}\)។ អង្កត់ធ្នូ \(AB\) មានប្រវែង \(16\text{ cm}\)។ គណនាចម្ងាយ \(OH\) ពីផ្ចិត \(O\) ទៅកាន់អង្កត់ធ្នូ \(AB\)។

ដំណោះស្រាយ

គូស \(OH \bot AB\) ត្រង់ \(H\) នាំឱ្យ \(H\) ជាចំណុចកណ្តាលនៃ \(AB\) ៖

\[AH = \frac{AB}{2} = \frac{16}{2} = 8\text{ cm}\]
ក្នុងត្រីកោណកែង \(\Delta OHA\) (កែងត្រង់ \(H\)) អនុវត្តទ្រឹស្ដីបទពីតាករ ៖
\[OH = \sqrt{OA^2 - AH^2} = \sqrt{10^2 - 8^2} = \sqrt{100 - 64} = \sqrt{36} = 6\text{ cm}\]

បន្ទាត់ប៉ះនឹងរង្វង់ (Tangent to a Circle)

បន្ទាត់ប៉ះ

បន្ទាត់ប៉ះនឹងរង្វង់ គឺជាបន្ទាត់ដែលមានចំណុចរួមតែមួយគត់ជាមួយរង្វង់ (ចំណុចនោះហៅថា ចំណុចប៉ះ)។

លក្ខណៈបន្ទាត់ប៉ះ

  1. បន្ទាត់មួយប៉ះនឹងរង្វង់ត្រង់ចំណុច \(T\) លុះត្រាតែបន្ទាត់នោះកែងនឹងកាំ \(OT\) ត្រង់ចំណុច \(T\) ៖

    \[d \text{ ប៉ះរង្វង់ត្រង់ } T \iff d \bot OT\]

  2. លក្ខណៈបន្ទាត់ប៉ះពីរគូសចេញពីចំណុចក្រៅរង្វង់ ៖ បើតាមចំណុច \(M\) ក្រៅរង្វង់ គេគូសបន្ទាត់ប៉ះពីរ \(MA\) និង \(MB\) (\(A, B\) ជាចំណុចប៉ះ) នោះ ៖

    • \(MA = MB\) (ប្រវែងអង្កត់ប៉ះទាំងពីរប៉ុនគ្នា)

    • \(MO\) ជាកន្លះបន្ទាត់ពុះនៃមុំ \(\angle AMB\) និងកន្លះបន្ទាត់ពុះនៃមុំ \(\angle AOB\)

    • \(MO\) ជាបន្ទាត់មេដ្យាទ័រនៃអង្កត់ \(AB\)

រូបភាពនេះកំពុងរៀបចំ

មុំផ្ចិត និងមុំចារឹកក្នុងរង្វង់

មុំផ្ចិត និងមុំចារឹកក្នុង

  • មុំផ្ចិត (Central Angle) ៖ ជាមុំដែលមានកំពូលនៅចំផ្ចិតនៃរង្វង់ (\(\angle AOB\))។ រង្វាស់មុំផ្ចិតស្មើនឹងរង្វាស់ធ្នូស្កាត់ ៖

    \[\angle AOB = \overset{\frown}{AB}\]

  • មុំចារឹកក្នុងរង្វង់ (Inscribed Angle) ៖ ជាមុំដែលមានកំពូលនៅលើរង្វង់ ហើយជ្រុងទាំងពីរកាត់រង្វង់ (\(\angle AMB\))។

ទំនាក់ទំនងរវាងមុំចារឹកក្នុង និងមុំផ្ចិត

  1. រង្វាស់នៃមុំចារឹកក្នុងរង្វង់ ស្មើនឹងពាក់កណ្តាលនៃរង្វាស់ធ្នូស្កាត់ ឬស្មើពាក់កណ្តាលនៃមុំផ្ចិតដែលស្កាត់ធ្នូជាមួយគ្នា ៖

    \[\angle AMB = \frac{1}{2}\overset{\frown}{AB} = \frac{1}{2}\angle AOB\]

  2. គ្រប់មុំចារឹកក្នុងដែលស្កាត់ធ្នូតែមួយ ឬស្កាត់ធ្នូប៉ុនគ្នា គឺមានរង្វាស់ប៉ុនគ្នា។

  3. គ្រប់មុំចារឹកក្នុងកន្លះរង្វង់ (ស្កាត់អង្កត់ផ្ចិត) គឺជាមុំកែង (\(90^\circ\))។

  2. គណនាបរិមាត្រ និងផ្ទៃក្រឡារបស់វា (យក \(\pi \approx 3.14\))។

មើលដំណោះស្រាយ

  • a. អង្កត់ផ្ចិត ៖ \(D = 2R = 2(12) = 24\text{ cm}\)

  • b. បរិមាត្រ ៖ \(C = 2\pi R = 2(3.14)(12) = 75.36\text{ cm}\)។ ផ្ទៃក្រឡា ៖ \(S = \pi R^2 = 3.14(12^2) = 452.16\text{ cm}^2\)

២លំហាត់ទី ២

រង្វង់មួយមានបរិមាត្រ \(C = 31.4\text{ cm}\)។ គណនាកាំ និងផ្ទៃក្រឡារបស់វា។

មើលដំណោះស្រាយ

\(C = 2\pi R = 31.4 \implies R = \frac{31.4}{2(3.14)} = 5\text{ cm}\)។ ផ្ទៃក្រឡា ៖ \(S = \pi R^2 = 3.14(5^2) = 78.5\text{ cm}^2\)។

៣លំហាត់ទី ៣

រង្វង់មួយមានផ្ទៃក្រឡា \(S = 78.5\text{ cm}^2\)។ គណនាកាំ និងបរិមាត្ររបស់វា។

មើលដំណោះស្រាយ

\(S = \pi R^2 = 78.5 \implies R^2 = \frac{78.5}{3.14} = 25 \implies R = 5\text{ cm}\)។ បរិមាត្រ ៖ \(C = 2\pi R = 31.4\text{ cm}\)។

៤លំហាត់ទី ៤

ក្នុងរង្វង់ផ្ចិត \(O\) កាំ \(R = 15\text{ cm}\) មានអង្កត់ធ្នូ \(AB = 24\text{ cm}\)។ គណនាចម្ងាយ \(OH\) ពីផ្ចិត \(O\) ទៅអង្កត់ធ្នូ \(AB\)។

មើលដំណោះស្រាយ

\(H\) ជាចំណុចកណ្តាល \(AB \implies AH = \frac{24}{2} = 12\text{ cm}\)។ ក្នុង \(\Delta OHA\) កែងត្រង់ \(H\) ៖ \(OH = \sqrt{15^2 - 12^2} = \sqrt{225 - 144} = 9\text{ cm}\)។

៥លំហាត់ទី ៥

ក្នុងរង្វង់ផ្ចិត \(O\) កាំ \(R = 10\text{ cm}\) មានអង្កត់ធ្នូ \(CD\) មួយដែលស្ថិតនៅចម្ងាយ \(6\text{ cm}\) ពីផ្ចិត \(O\)។ គណនាប្រវែងអង្កត់ធ្នូ \(CD\)។

មើលដំណោះស្រាយ

កន្លះអង្កត់ធ្នូ ៖ \(\sqrt{10^2 - 6^2} = 8\text{ cm}\)។ ប្រវែង \(CD = 2(8) = 16\text{ cm}\)។

៦លំហាត់ទី ៦

ក្នុងរង្វង់ផ្ចិត \(O\) អង្កត់ធ្នូ \(AB = 18\text{ cm}\) ស្ថិតនៅចម្ងាយ \(12\text{ cm}\) ពីផ្ចិត។ គណនាកាំ \(R\) នៃរង្វង់។

មើលដំណោះស្រាយ

កន្លះអង្កត់ធ្នូ ៖ \(\frac{18}{2} = 9\text{ cm}\)។ កាំ ៖ \(R = \sqrt{12^2 + 9^2} = \sqrt{144 + 81} = 15\text{ cm}\)។

៧លំហាត់ទី ៧

គេឱ្យរង្វង់ \(\mathcal{C}(O, R)\) និងអង្កត់ធ្នូពីរ \(AB\) និង \(CD\)។ ស្រាយបញ្ជាក់ថា បើ \(AB = CD\) នោះធ្នូ \(\overset{\frown}{AB} = \overset{\frown}{CD}\)។

មើលដំណោះស្រាយ

\(\Delta OAB \cong \Delta OCD\) (ជ.ជ.ជ ៖ \(OA = OC = R, OB = OD = R, AB = CD\))។ \(\implies \angle AOB = \angle COD \implies \overset{\frown}{AB} = \overset{\frown}{CD}\)។

៨លំហាត់ទី ៨

គេឱ្យរង្វង់ផ្ចិត \(O\) និងអង្កត់ធ្នូពីរ \(AB = CD\)។ បង្ហាញថា ចម្ងាយពី \(O\) ទៅកាន់ \(AB\) ស្មើនឹងចម្ងាយពី \(O\) ទៅកាន់ \(CD\) (\(OH = OK\))។

មើលដំណោះស្រាយ

\(\Delta OAH \cong \Delta OCK\) (អ.ជ ៖ \(OA = OC = R, AH = \frac{AB}{2} = \frac{CD}{2} = CK\))។ \(\implies OH = OK\)។

៩លំហាត់ទី ៩

គេឱ្យរង្វង់ផ្ចិត \(O\) និងអង្កត់ធ្នូ \(AB\)។ តាម \(O\) គូសបន្ទាត់កែងនឹង \(AB\) ត្រង់ \(H\) និងកាត់រង្វង់ត្រង់ \(M\)។ បង្ហាញថា \(M\) ជាចំណុចកណ្តាលនៃធ្នូ \(\overset{\frown}{AB}\)។

មើលដំណោះស្រាយ

\(OM \bot AB \implies H\) ជាចំណុចកណ្តាល \(AB\) និង \(\Delta OAH \cong \Delta OBH\) (ជ.ម.ជ) \(\implies \angle AOM = \angle BOM \implies \overset{\frown}{AM} = \overset{\frown}{BM}\)។

១០លំហាត់ទី ១០

ពីចំណុច \(M\) នៅក្រៅរង្វង់ \(\mathcal{C}(O, R = 5\text{ cm})\) គេគូសបន្ទាត់ប៉ះ \(MA\) (\(A\) ជាចំណុចប៉ះ)។ ដឹងថា \(OM = 13\text{ cm}\)។ គណនាប្រវែងអង្កត់ប៉ះ \(MA\)។

មើលដំណោះស្រាយ

\(MA \bot OA\) ត្រង់ \(A\)។ តាមពីតាករ ៖ \(MA = \sqrt{OM^2 - OA^2} = \sqrt{13^2 - 5^2} = 12\text{ cm}\)។

១១លំហាត់ទី ១១

ពីចំណុច \(M\) ក្រៅរង្វង់ផ្ចិត \(O\) គូសបន្ទាត់ប៉ះ \(MA\) និង \(MB\) (\(A, B\) ជាចំណុចប៉ះ)។ ដឹងថា \(\angle AMB = 60^\circ\) និង \(MA = 8\text{ cm}\)។

  1. បង្ហាញថា \(\Delta MAB\) ជាត្រីកោណសម័ង្ស។

  2. គណនាកាំ \(R\) នៃរង្វង់ និងប្រវែង \(OM\)។

មើលដំណោះស្រាយ

  • a. \(MA = MB\) និង \(\angle AMB = 60^\circ \implies \Delta MAB\) សម័ង្ស។

  • b. \(\angle OMA = 30^\circ\)។ ក្នុង \(\Delta OAM\) កែងត្រង់ \(A\) ៖ \(R = OA = MA \tan 30^\circ = \frac{8\sqrt{3}}{3}\text{ cm}\)។ \(OM = 2R = \frac{16\sqrt{3}}{3}\text{ cm}\)។

១២លំហាត់ទី ១២

គេឱ្យរង្វង់ \(\mathcal{C}(O, R)\) អង្កត់ផ្ចិត \(AB\)។ ចំណុច \(C\) ស្ថិតនៅលើរង្វង់ (\(C \ne A, B\))។

  1. បង្ហាញថា \(\Delta ABC\) ជាត្រីកោណកែងត្រង់ \(C\)។

  2. បើ \(AB = 10\text{ cm}\) និង \(AC = 6\text{ cm}\) គណនា \(BC\)។

មើលដំណោះស្រាយ

  • a. \(\angle ACB\) ជាមុំចារឹកក្នុងកន្លះរង្វង់ \(\implies \angle ACB = 90^\circ\) នាំឱ្យ \(\Delta ABC\) កែងត្រង់ \(C\)។

  • b. \(BC = \sqrt{10^2 - 6^2} = 8\text{ cm}\)។

១៣លំហាត់ទី ១៣

ក្នុងរង្វង់ផ្ចិត \(O\) មុំចារឹកក្នុង \(\angle ACB = 45^\circ\)។ គណនារង្វាស់មុំផ្ចិត \(\angle AOB\) និងបង្ហាញថា \(\Delta OAB\) ជាត្រីកោណកែងសមបាត។

មើលដំណោះស្រាយ

\(\angle AOB = 2\angle ACB = 2(45^\circ) = 90^\circ\)។ \(\Delta OAB\) មាន \(OA = OB = R\) និង \(\angle AOB = 90^\circ \implies \Delta OAB\) កែងសមបាតត្រង់ \(O\)។

១៤លំហាត់ទី ១៤

ក្នុងរង្វង់ផ្ចិត \(O\) មានធ្នូ \(\overset{\frown}{AB} = 110^\circ\)។ ចំណុច \(M\) ស្ថិតនៅលើធ្នូធំ \(AB\)។ គណនារង្វាស់មុំ \(\angle AMB\) និងមុំ \(\angle AOB\)។

មើលដំណោះស្រាយ

\(\angle AOB = \overset{\frown}{AB} = 110^\circ\)។ \(\angle AMB = \frac{1}{2}\overset{\frown}{AB} = \frac{110^\circ}{2} = 55^\circ\)។

១៥លំហាត់ទី ១៥

គេឱ្យរង្វង់ \(\mathcal{C}(O, R)\) និងអង្កត់ធ្នូ \(AB = R\)។

  1. បង្ហាញថា \(\Delta OAB\) ជាត្រីកោណសម័ង្ស។

  2. គណនារង្វាស់មុំផ្ចិត \(\angle AOB\) និងមុំចារឹកក្នុងស្កាត់ធ្នូ \(AB\)។

មើលដំណោះស្រាយ

  • a. \(OA = OB = AB = R \implies \Delta OAB\) សម័ង្ស។

  • b. \(\angle AOB = 60^\circ\)។ មុំចារឹកក្នុងស្កាត់ធ្នូ \(AB\) ស្មើ \(\frac{60^\circ}{2} = 30^\circ\)។

១៦លំហាត់ទី ១៦

គេឱ្យរង្វង់ \(\mathcal{C}(O, R)\) និងអង្កត់ធ្នូ \(AB = R\sqrt{2}\)។ គណនារង្វាស់មុំផ្ចិត \(\angle AOB\) និងចម្ងាយពីផ្ចិត \(O\) ទៅកាន់ \(AB\)។

មើលដំណោះស្រាយ

\(OA^2 + OB^2 = R^2 + R^2 = 2R^2 = AB^2 \implies \angle AOB = 90^\circ\)។ ចម្ងាយ ៖ \(d = \sqrt{R^2 - \left(\frac{R\sqrt{2}}{2}\right)^2} = \frac{R\sqrt{2}}{2}\)។

១៧លំហាត់ទី ១៧

គេឱ្យរង្វង់ \(\mathcal{C}(O, R)\) និងអង្កត់ធ្នូ \(AB = R\sqrt{3}\)។ គណនារង្វាស់មុំផ្ចិត \(\angle AOB\) និងចម្ងាយពីផ្ចិត \(O\) ទៅកាន់ \(AB\)។

មើលដំណោះស្រាយ

\(\sin\frac{\angle AOB}{2} = \frac{AB/2}{R} = \frac{\sqrt{3}}{2} \implies \frac{\angle AOB}{2} = 60^\circ \implies \angle AOB = 120^\circ\)។ ចម្ងាយ ៖ \(d = R\cos 60^\circ = \frac{R}{2}\)។

១៨លំហាត់ទី ១៨

រង្វង់ពីរ \(\mathcal{C}(O, 8\text{ cm})\) និង \(\mathcal{C}(O', 6\text{ cm})\) កាត់គ្នាត្រង់ \(A\) និង \(B\)។ ដឹងថា \(OO' = 10\text{ cm}\)។

  1. បង្ហាញថា \(\Delta OAO'\) ជាត្រីកោណកែងត្រង់ \(A\)។

  2. គណនាប្រវែងអង្កត់ធ្នូរួម \(AB\)។

មើលដំណោះស្រាយ

  • a. \(OA^2 + O'A^2 = 8^2 + 6^2 = 100 = 10^2 = OO'^2 \implies \Delta OAO'\) កែងត្រង់ \(A\)។

  • b. \(AB = 2h = 2\frac{OA \times O'A}{OO'} = 2\frac{8 \times 6}{10} = 9.6\text{ cm}\)។

១៩លំហាត់ទី ១៩

គេឱ្យត្រីកោណសម័ង្ស \(ABC\) មានជ្រុងប្រវែង \(a = 6\text{ cm}\)។ \(I, J, K\) ជាចំណុចកណ្តាលនៃ \(AB, BC, CA\) រៀងគ្នា។

  1. បង្ហាញថា ចំណុចទាំងបួន \(B, I, K, C\) ស្ថិតនៅលើរង្វង់តែមួយ។

  2. កំណត់ផ្ចិត និងកាំនៃរង្វង់នោះ។

មើលដំណោះស្រាយ

  • a. \(IK\) ជាបាតមធ្យម \(\implies IK = \frac{BC}{2} = \frac{a}{2}\)។ \(J\) កណ្តាល \(BC \implies JB = JC = \frac{a}{2}\)។ ម៉្យាងទៀត \(JI = JK = \frac{a}{2}\)។

  • b. ចំណុច \(B, I, K, C\) ស្មើចម្ងាយ \(\frac{a}{2} = 3\text{ cm}\) ពីផ្ចិត \(J\)។

២០លំហាត់ទី ២០

ចតុកោណ \(ABCD\) មានអង្កត់ទ្រូងកាត់គ្នាកែងត្រង់ \(O\) (\(AC \bot BD\))។ \(M, N, P, Q\) ជាចំណុចកណ្តាលនៃ \(AB, BC, CD, DA\) រៀងគ្នា។ បង្ហាញថា ចំណុចទាំងបួន \(M, N, P, Q\) ស្ថិតនៅលើរង្វង់តែមួយ។

មើលដំណោះស្រាយ

\(MNPQ\) ជាចតុកោណកែង (ទ្រឹស្ដីបទវ៉ារីញ៉ុង ព្រោះ \(AC \bot BD\))។ ចតុកោណកែងចារឹកក្នុងរង្វង់មួយជានិច្ច ដែលមានផ្ចិតជាចំណុចកណ្តាលនៃអង្កត់ទ្រូងរបស់វា។

២១លំហាត់ទី ២១

គេឱ្យកន្លះរង្វង់អង្កត់ផ្ចិត \(AB\) និងអង្កត់ធ្នូ \(CD\) មួយ។ ពី \(A\) និង \(B\) គូសបន្ទាត់កែងនឹងបន្ទាត់ \(CD\) ត្រង់ \(P\) និង \(S\) រៀងគ្នា។ បង្ហាញថា \(PC = DS\)។

មើលដំណោះស្រាយ

គូស \(OH \bot CD \implies H\) ជាចំណុចកណ្តាល \(CD\) (\(HC = HD\))។ \(AP \parallel OH \parallel BS\) (កែងនឹង \(CD\)) \(\implies OH\) ជាបាតមធ្យមនៃចតុកោណព្នាយ \(ABSP \implies H\) ជាចំណុចកណ្តាល \(PS\) (\(HP = HS\))។ \(\implies HP - HC = HS - HD \iff PC = DS\)។

២២លំហាត់ទី ២២

គេឱ្យរង្វង់ \(\mathcal{C}(O, R)\) និងចំណុច \(P\) នៅខាងក្នុងរង្វង់ (\(P \ne O\))។ បង្ហាញថា ក្នុងចំណោមអង្កត់ធ្នូទាំងអស់ដែលកាត់តាម \(P\) អង្កត់ធ្នូដែលកែងនឹង \(OP\) គឺជាអង្កត់ធ្នូដែលមានប្រវែងខ្លីជាងគេបំផុត។

មើលដំណោះស្រាយ

អង្កត់ធ្នូកាត់តាម \(P\) គូស \(OH \bot\) អង្កត់ធ្នូនោះ។ ក្នុង \(\Delta OHP\) កែងត្រង់ \(H\) ៖ \(OH \le OP\)។ ប្រវែងអង្កត់ធ្នូ \(2\sqrt{R^2 - OH^2}\) តូចបំផុតកាលណា \(OH\) ធំបំផុត ពោលគឺ \(OH = OP \iff\) អង្កត់ធ្នូនោះកែងនឹង \(OP\)។

២៣លំហាត់ទី ២៣

គេឱ្យរង្វង់ផ្ចិត \(O\)។ អង្កត់ធ្នូពីរ \(AB\) និង \(CD\) (\(AB > CD\)) បន្លាយកាត់គ្នាត្រង់ចំណុច \(K\) នៅខាងក្រៅរង្វង់។ \(H, P\) ជាចំណុចកណ្តាលនៃ \(AB, CD\) រៀងគ្នា។

  1. បង្ហាញថា ចំណុចកណ្តាលនៃអង្កត់ \(OK\) ស្មើចម្ងាយពីចំណុច \(O, K, P, H\)។

  2. ប្រៀបធៀបរង្វាស់មុំ \(\angle HKO\) និង \(\angle PKO\)។

  3. ប្រៀបធៀបប្រវែង \(KH\) និង \(KP\)។

មើលដំណោះស្រាយ

  • a. \(\angle OHK = \angle OPK = 90^\circ \implies O, K, P, H\) នៅលើរង្វង់អង្កត់ផ្ចិត \(OK\)។

  • b. \(AB > CD \implies OH < OP\)។ ក្នុងត្រីកោណកែង ៖ \(\angle HKO > \angle PKO\)។

  • c. \(KH = \sqrt{OK^2 - OH^2} > KP = \sqrt{OK^2 - OP^2} \implies KH > KP\)។

២៤លំហាត់ទី ២៤

ចតុកោណ \(ABCD\) ចារឹកក្នុងរង្វង់ផ្ចិត \(O\)។ ដឹងថា \(\angle A = 2x + 10^\circ\) និង \(\angle C = 3x - 30^\circ\)។ គណនាតម្លៃ \(x\) និងរង្វាស់មុំ \(\angle A, \angle C\)។

មើលដំណោះស្រាយ

\(\angle A + \angle C = 180^\circ \iff 5x - 20^\circ = 180^\circ \implies x = 40^\circ\)។ \(\angle A = 2(40^\circ) + 10^\circ = 90^\circ\) និង \(\angle C = 90^\circ\)។

២៥លំហាត់ទី ២៥

ក្នុងរូបរង្វង់ផ្ចិត \(O\) គេឱ្យ \(OQ = OR\) និង \(AB = 6x + 14\), \(CD = -4x + 34\) (\(Q \in AB, R \in CD\) ជាជើងកាត់កែង)។ គណនា \(x\) និងប្រវែងអង្កត់ធ្នូ \(AB, CD\)។

មើលដំណោះស្រាយ

\(OQ = OR \implies AB = CD \iff 6x + 14 = -4x + 34 \implies 10x = 20 \implies x = 2\)។ \(AB = CD = 6(2) + 14 = 26\text{ cm}\)។

២៦លំហាត់ទី ២៦

គេឱ្យរង្វង់ផ្ចិត \(O\) កាំ \(R = 10\text{ cm}\) និងអង្កត់ធ្នូស្របគ្នាពីរ \(AB = 16\text{ cm}\) និង \(CD = 12\text{ cm}\)។ គណនាចម្ងាយរវាងអង្កត់ធ្នូទាំងពីរ ៖

  1. ករណីអង្កត់ធ្នូទាំងពីរនៅសងខាងផ្ចិត \(O\)។

  2. ករណីអង្កត់ធ្នូទាំងពីរនៅម្ខាងនៃផ្ចិត \(O\)។

មើលដំណោះស្រាយ

\(d_1 = \sqrt{10^2 - 8^2} = 6\text{ cm}\) និង \(d_2 = \sqrt{10^2 - 6^2} = 8\text{ cm}\) ៖

  • a. សងខាងផ្ចិត ៖ \(d = d_1 + d_2 = 6 + 8 = 14\text{ cm}\)

  • b. ម្ខាងនៃផ្ចិត ៖ \(d = d_2 - d_1 = 8 - 6 = 2\text{ cm}\)

២៧លំហាត់ទី ២៧

បង្ហាញថា បើចតុកោណព្នាយមួយចារឹកក្នុងរង្វង់ នោះចតុកោណព្នាយនោះត្រូវតែជាចតុកោណព្នាយសមបាត។

មើលដំណោះស្រាយ

\(AB \parallel CD \implies \overset{\frown}{AD} = \overset{\frown}{BC} \implies AD = BC\) (ចតុកោណព្នាយសមបាត)។

២៨លំហាត់ទី ២៨

បង្ហាញថា បើប្រលេឡូក្រាមមួយចារឹកក្នុងរង្វង់ នោះប្រលេឡូក្រាមនោះត្រូវតែជាចតុកោណកែង។

មើលដំណោះស្រាយ

\(ABCD\) ជាប្រលេឡូក្រាម \(\implies \angle A = \angle C\)។ ដោយចារឹកក្នុងរង្វង់ \(\implies \angle A + \angle C = 180^\circ \implies \angle A = 90^\circ\) (ចតុកោណកែង)។

២៩លំហាត់ទី ២៩

បង្ហាញថា បើចតុកោណស្មើមួយចារឹកក្នុងរង្វង់ នោះចតុកោណស្មើនោះត្រូវតែជាការេ។

មើលដំណោះស្រាយ

ចតុកោណស្មើចារឹកក្នុងរង្វង់ \(\implies\) ជាប្រលេឡូក្រាមចារឹកក្នុងរង្វង់ \(\implies\) ជាចតុកោណកែង។ ចតុកោណស្មើផង និងចតុកោណកែងផង គឺជាការេ។

៣០លំហាត់ទី ៣០

គេឱ្យត្រីកោណកែង \(ABC\) កែងត្រង់ \(A\) មាន \(AB = 3\text{ cm}, AC = 4\text{ cm}\)។

  1. គណនាកាំ \(R\) នៃរង្វង់ចារឹកក្រៅត្រីកោណ។

  2. គណនាកាំ \(r\) នៃរង្វង់ចារឹកក្នុងត្រីកោណតាមរូបមន្ត \(r = \frac{a+b-c}{2}\)។

មើលដំណោះស្រាយ

  • a. \(c = \sqrt{3^2 + 4^2} = 5\text{ cm} \implies R = \frac{c}{2} = 2.5\text{ cm}\)

  • b. \(r = \frac{3 + 4 - 5}{2} = 1\text{ cm}\)

៣១លំហាត់ទី ៣១

ចិញ្ចៀនរង្វង់មួយមានកាំក្រៅ \(R = 10\text{ cm}\) និងកាំក្នុង \(r = 6\text{ cm}\)។ គណនាផ្ទៃក្រឡារបស់វាជាអនុគមន៍នៃ \(\pi\)។

មើលដំណោះស្រាយ

\(S = \pi(10^2 - 6^2) = \pi(100 - 36) = 64\pi\text{ cm}^2\)។

៣២លំហាត់ទី ៣២

ក្នុងចិញ្ចៀនរង្វង់មួយ អង្កត់ធ្នូនៃរង្វង់ធំដែលប៉ះនឹងរង្វង់តូចមានប្រវែង \(16\text{ cm}\)។ គណនាផ្ទៃក្រឡានៃចិញ្ចៀនរង្វង់នោះ។

មើលដំណោះស្រាយ

កន្លះអង្កត់ធ្នូស្មើ \(8\text{ cm}\)។ តាមពីតាករ ៖ \(R^2 - r^2 = 8^2 = 64\)។ ផ្ទៃក្រឡាចិញ្ចៀនរង្វង់ ៖ \(S = \pi(R^2 - r^2) = 64\pi\text{ cm}^2\)។

៣៣លំហាត់ទី ៣៣

គណនាផ្ទៃចំរៀករង្វង់ដែលមានកាំ \(R = 6\text{ cm}\) និងមុំផ្ចិត \(\alpha = 60^\circ\)។

មើលដំណោះស្រាយ

\(S = \frac{\alpha}{360^\circ} \pi R^2 = \frac{60^\circ}{360^\circ} \pi (6^2) = 6\pi\text{ cm}^2\)។

៣៤លំហាត់ទី ៣៤

គណនាប្រវែងធ្នូនៃរង្វង់កាំ \(R = 14\text{ cm}\) ដែលត្រូវនឹងមុំផ្ចិត \(\alpha = 45^\circ\) (យក \(\pi \approx \frac{22}{7}\))។

មើលដំណោះស្រាយ

\(L = \frac{\alpha}{180^\circ} \pi R = \frac{45^\circ}{180^\circ} \left(\frac{22}{7}\right)(14) = \frac{1}{4}(44) = 11\text{ cm}\)។

៣៥លំហាត់ទី ៣៥

គេឱ្យកន្លះរង្វង់អង្កត់ផ្ចិត \(AB = 2R\)។ លើ \(AB\) ដៅចំណុច \(C\)។ សង់កន្លះរង្វង់អង្កត់ផ្ចិត \(AC\) និង \(CB\) នៅខាងក្នុងកន្លះរង្វង់ធំ។ បង្ហាញថា បរិមាត្រនៃរូបកំណត់ដោយកន្លះរង្វង់តូចទាំងពីរស្មើនឹងបរិមាត្រនៃកន្លះរង្វង់ធំ។

មើលដំណោះស្រាយ

\(P_1 = \pi \frac{AC}{2} + \pi \frac{CB}{2} = \pi \frac{AC + CB}{2} = \pi \frac{AB}{2} = P_{\text{ធំ}}\)។

៣៦លំហាត់ទី ៣៦

អង្កត់ធ្នូពីរ \(AB\) និង \(CD\) កាត់គ្នាត្រង់ \(P\) ក្នុងរង្វង់។ ដឹងថា \(PA = 4\text{ cm}, PB = 9\text{ cm}, PC = 3\text{ cm}\)។ គណនា \(PD\)។

មើលដំណោះស្រាយ

\(PA \times PB = PC \times PD \implies 4 \times 9 = 3 \times PD \implies PD = 12\text{ cm}\)។

៣៧លំហាត់ទី ៣៧

ពីចំណុច \(P\) ក្រៅរង្វង់ គូសបន្ទាត់ប៉ះ \(PT\) (\(T\) ជាចំណុចប៉ះ) និងបន្ទាត់កាត់ \(PAB\)។ ដឹងថា \(PA = 4\text{ cm}, AB = 5\text{ cm}\)។ គណនាប្រវែងអង្កត់ប៉ះ \(PT\)។

មើលដំណោះស្រាយ

\(PB = PA + AB = 4 + 5 = 9\text{ cm}\)។ \(PT^2 = PA \times PB = 4 \times 9 = 36 \implies PT = 6\text{ cm}\)។

៣៨លំហាត់ទី ៣៨

គេឱ្យរង្វង់ពីររួមផ្ចិត \(O\)។ អង្កត់ធ្នូ \(AB\) នៃរង្វង់ធំកាត់រង្វង់តូចត្រង់ \(C\) និង \(D\) (\(C\) នៅចន្លោះ \(A\) និង \(D\))។ បង្ហាញថា \(AC = BD\)។

មើលដំណោះស្រាយ

គូស \(OH \bot AB \implies H\) ជាចំណុចកណ្តាល \(AB\) (\(HA = HB\)) និងកណ្តាល \(CD\) (\(HC = HD\))។ \(\implies HA - HC = HB - HD \iff AC = BD\)។

៣៩លំហាត់ទី ៣៩

គេឱ្យរង្វង់ \(\mathcal{C}(O, R)\) និងចំណុច \(A\) នៅលើរង្វង់។ តាម \(A\) គូសបន្ទាត់ប៉ះ \(xy\)។ អង្កត់ធ្នូ \(AB\) មួយបង្កើតបានមុំ \(\angle BAy = 60^\circ\)។ គណនារង្វាស់ធ្នូ \(\overset{\frown}{AB}\) និងមុំចារឹកក្នុងស្កាត់ធ្នូ \(AB\)។

មើលដំណោះស្រាយ

\(\overset{\frown}{AB} = 2\angle BAy = 2(60^\circ) = 120^\circ\)។ មុំចារឹកក្នុងស្កាត់ធ្នូ \(AB\) ស្មើ \(\frac{120^\circ}{2} = 60^\circ\)។

៤០លំហាត់ទី ៤០

គេឱ្យ \(\Delta ABC\) សមបាតត្រង់ \(A\) ចារឹកក្នុងរង្វង់ផ្ចិត \(O\)។ ដឹងថា \(\angle A = 50^\circ\)។ គណនារង្វាស់ធ្នូ \(\overset{\frown}{AB}, \overset{\frown}{AC}, \overset{\frown}{BC}\)។

មើលដំណោះស្រាយ

\(\angle B = \angle C = \frac{180^\circ - 50^\circ}{2} = 65^\circ\)។ \(\overset{\frown}{BC} = 2(50^\circ) = 100^\circ\)។ \(\overset{\frown}{AB} = \overset{\frown}{AC} = 2(65^\circ) = 130^\circ\)។

៤១លំហាត់ទី ៤១

គេឱ្យ \(\Delta ABC\) សម័ង្សចារឹកក្នុងរង្វង់ផ្ចិត \(O\)។ \(M\) ជាចំណុចនៅលើធ្នូតូច \(BC\)។ បង្ហាញថា \(MA = MB + MC\) (ទ្រឹស្ដីបទវ៉ានសូប៊ែល - Van Schooten’s Theorem)។

មើលដំណោះស្រាយ

លើ \(MA\) យក \(D\) ឱ្យ \(MD = MB \implies \Delta MBD\) សម័ង្ស \(\implies \Delta BDA \cong \Delta BMC\) (ជ.ម.ជ) \(\implies AD = MC\)។ ដូចនេះ \(MA = MD + DA = MB + MC\)។

៤២លំហាត់ទី ៤២

គេឱ្យរង្វង់ \(\mathcal{C}(O, R)\) អង្កត់ផ្ចិត \(AB\)។ លើបន្លាយ \(AB\) យក \(S\) ឱ្យ \(BS = R\)។ ពី \(S\) គូសបន្ទាត់ប៉ះ \(ST\) ទៅកាន់រង្វង់ (\(T\) ជាចំណុចប៉ះ)។ គណនាប្រវែង \(ST\) ជាអនុគមន៍នៃ \(R\)។

មើលដំណោះស្រាយ

\(OS = OB + BS = 2R\)។ ក្នុង \(\Delta OTS\) កែងត្រង់ \(T\) ៖ \(ST = \sqrt{OS^2 - OT^2} = \sqrt{(2R)^2 - R^2} = R\sqrt{3}\)។

៤៣លំហាត់ទី ៤៣

តាមទិន្នន័យលំហាត់ទី ៤២ គណនារង្វាស់មុំ \(\angle SOT\) និង \(\angle TSO\)។

មើលដំណោះស្រាយ

\(\cos \angle SOT = \frac{OT}{OS} = \frac{R}{2R} = \frac{1}{2} \implies \angle SOT = 60^\circ\)។ \(\angle TSO = 90^\circ - 60^\circ = 30^\circ\)។

៤៤លំហាត់ទី ៤៤

គេឱ្យរង្វង់ពីរ \(\mathcal{C}(O, R)\) និង \(\mathcal{C}(O', R')\) ប៉ះគ្នាក្រៅត្រង់ \(A\)។ បន្ទាត់ប៉ះក្រៅរួម \(TT'\) ប៉ះរង្វង់ទាំងពីរត្រង់ \(T\) និង \(T'\)។ បង្ហាញថា \(\angle TAT' = 90^\circ\)។

មើលដំណោះស្រាយ

តាង \(M\) ជាប្រសព្វបន្ទាត់ប៉ះរួមត្រង់ \(A\) ជាមួយ \(TT'\) ៖ \(MT = MA = MT' \implies \Delta TAT'\) កែងត្រង់ \(A\) (\(\angle TAT' = 90^\circ\))។

៤៥លំហាត់ទី ៤៥

តាមទិន្នន័យលំហាត់ទី ៤៤ បង្ហាញថា \(TT' = 2\sqrt{RR'}\)។

មើលដំណោះស្រាយ

ក្នុងត្រីកោណកែង \(\Delta OMO'\) កម្ពស់ \(MA = \sqrt{R \cdot R'}\)។ \(TT' = 2MA = 2\sqrt{RR'}\)។

៤៦លំហាត់ទី ៤៦

កង់រទេះមួយមានកាំ \(R = 42\text{ cm}\)។ រទេះនោះរត់បានចម្ងាយ \(1.32\text{ km}\)។ តើកង់រទេះវិលបានប៉ុន្មានជុំ? (យក \(\pi \approx \frac{22}{7}\))។

មើលដំណោះស្រាយ

បរិមាត្រកង់ ៖ \(C = 2\left(\frac{22}{7}\right)(42) = 264\text{ cm} = 2.64\text{ m}\)។ ចំនួនជុំ ៖ \(N = \frac{1\,320\text{ m}}{2.64\text{ m}} = 500\) ជុំ។

៤៧លំហាត់ទី ៤៧

គេឱ្យការេ \(ABCD\) មានជ្រុង \(a = 4\text{ cm}\)។ គណនាផ្ទៃក្រឡានៃរង្វង់ចារឹកក្រៅការេ និងរង្វង់ចារឹកក្នុងការេ។

មើលដំណោះស្រាយ

\(R = \frac{4\sqrt{2}}{2} = 2\sqrt{2}\text{ cm} \implies S_{\text{ក្រៅ}} = \pi(2\sqrt{2})^2 = 8\pi\text{ cm}^2\)។ \(r = \frac{4}{2} = 2\text{ cm} \implies S_{\text{ក្នុង}} = \pi(2^2) = 4\pi\text{ cm}^2\)។

៤៨លំហាត់ទី ៤៨

គណនាផលធៀបរវាងផ្ទៃរង្វង់ចារឹកក្រៅការេ និងផ្ទៃរង្វង់ចារឹកក្នុងការេ។

មើលដំណោះស្រាយ

\(\frac{S_{\text{ក្រៅ}}}{S_{\text{ក្នុង}}} = \frac{8\pi}{4\pi} = 2\) (ផ្ទៃក្រៅធំជាងផ្ទៃក្នុង ២ ដងជានិច្ច)។

៤៩លំហាត់ទី ៤៩

គេឱ្យរង្វង់ \(\mathcal{C}(O, R)\)។ ពីចំណុច \(A\) ក្រៅរង្វង់ គូសបន្ទាត់ប៉ះ \(AB, AC\)។ បង្ហាញថា ចតុកោណ \(ABOC\) ចារឹកក្នុងរង្វង់មួយដែលមានអង្កត់ផ្ចិតស្មើនឹង \(OA\)។

មើលដំណោះស្រាយ

\(\angle ABO = \angle ACO = 90^\circ \implies \angle ABO + \angle ACO = 180^\circ\)។ ចតុកោណ \(ABOC\) ចារឹកក្នុងរង្វង់អង្កត់ផ្ចិត \(OA\)។

៥០លំហាត់ទី ៥០

គេឱ្យ \(\Delta ABC\) ស្រួចមានកម្ពស់ \(BD\) និង \(CE\) កាត់គ្នាត្រង់ \(H\)។ បង្ហាញថា ៖

  1. ចតុកោណ \(ADHE\) ចារឹកក្នុងរង្វង់មួយ។

  2. ចតុកោណ \(BCDE\) ចារឹកក្នុងរង្វង់មួយ។

មើលដំណោះស្រាយ

  • a. \(\angle ADH + \angle AEH = 90^\circ + 90^\circ = 180^\circ \implies ADHE\) ចារឹកក្នុងរង្វង់អង្កត់ផ្ចិត \(AH\)។

  • b. \(\angle BDC = \angle BEC = 90^\circ \implies B, C, D, E\) នៅលើរង្វង់អង្កត់ផ្ចិត \(BC\)។

សំណួរពហុជ្រើសរើស

ជ្រើសរើសចម្លើយត្រឹមត្រូវតែមួយ រួចចុច «ពិនិត្យ»។ ចម្លើយរបស់អ្នកត្រូវបានរក្សាទុកក្នុងកុំព្យូទ័រនេះ។
