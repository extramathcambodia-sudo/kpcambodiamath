មេរៀនទាំងអស់
ប្រវត្តិនៃការដោះស្រាយសមីការដឺក្រេទី ១ ក្នុងប្រវត្តិសាស្ត្រមនុស្សជាតិ

ការស្វែងរកតម្លៃនៃ «អញ្ញាត» ឬ «ចំនួនដែលមិនស្គាល់» គឺជាកម្លាំងចលករដ៏ចំណាស់បំផុតមួយក្នុងការកកើតឡើងនៃគណិតវិទ្យា ៖

  • អារ្យធម៌អេហ្ស៊ីបបុរាណ (១៦៥០ មុន គ.ស.) ៖ ក្នុងក្រដាសផាពីរុសរីន (Rhind Papyrus) បញ្ហាស្វែងរកចំនួនត្រូវបានគេហៅថាបញ្ហា «Aha» (មានន័យថា «គំនរ» ឬ «បរិមាណ») ដូចជា ៖ «គំនរមួយ បូកនឹងមួយភាគប្រាំពីរនៃគំនរនោះ ស្មើនឹង ១៩»។ ជនជាតិអេហ្ស៊ីបបានបង្កើតវិធីសាស្ត្រ សន្មតខុស (Method of False Position / Regula Falsi) ដើម្បីស្វែងរកចម្លើយត្រឹមត្រូវ។

  • អារ្យធម៌បាប៊ីឡូន និងចិនបុរាណ ៖ ជនជាតិបាប៊ីឡូនបានកត់ត្រាការដោះស្រាយសមីការលើបន្ទះឥដ្ឋដីឥដ្ឋតាំងពី ២០០០ ឆ្នាំមុន គ.ស.។ ចំណែកគម្ពីរគណិតវិទ្យាចិនបុរាណ សិល្បៈគណិត ៩ ជំពូក (Jiuzhang Suanshu) បានបង្ហាញក្បួនដោះស្រាយសមីការលីនេអ៊ែរយ៉ាងក្បោះក្បាយ។

  • អាល់ខ្វារីស្មី (Al-Khwarizmi) និងប្រភពនៃពាក្យសមីការ ៖ នៅក្នុងសៀវភៅរបស់គាត់នៅឆ្នាំ ៨២០ គណិតវិទូ Al-Khwarizmi បានបង្កើតគោលការណ៍ពីរជាមូលដ្ឋាន ៖

    • Al-Jabr (ការបំពេញ ឬការប្តូរអង្គ) ៖ ការលើកតួអវិជ្ជមានពីអង្គម្ខាងទៅអង្គម្ខាងទៀតឱ្យទៅជាវិជ្ជមាន ដើម្បីរក្សាតុល្យភាពជញ្ជីង។

    • Al-Muqabala (ការសម្រួលតួ) ៖ ការលុបបំបាត់តួដូចគ្នាចេញពីអង្គទាំងសងខាងនៃសមីការ។

    គោលការណ៍ទាំងពីរនេះហើយដែលជាគ្រឹះនៃការដោះស្រាយសមីការរហូតមកដល់បច្ចុប្បន្ន។

សមីការដឺក្រេទី១មានមួយអញ្ញាត

សមីការដឺក្រេទី១មានមួយអញ្ញាត គឺជាសមភាពពីជគណិតដែលមានអថេរ (ឬអញ្ញាត) តែមួយ ហើយអថេរនោះមាននិទស្សន្តស្មើ \(1\)។
ទម្រង់ទូទៅនៃសមីការដឺក្រេទី១មានមួយអញ្ញាតគឺ ៖

\[ax + b = 0 \quad{} (\text{ដែល } a, b \in \mathbb{R} \text{ និង } a \ne 0)\]

  • \(x\) ហៅថា អញ្ញាត (ឬអថេរ)

  • \(a\) ហៅថា មេគុណនៃអញ្ញាត

  • \(b\) ហៅថា តួថេរ

  • កន្សោមនៅខាងឆ្វេងសញ្ញាស្មើ ហៅថា អង្គទីមួយ ហើយកន្សោមនៅខាងស្តាំ ហៅថា អង្គទីពីរ។

ឫសនៃសមីការ

ឫស (ឬដំណោះស្រាយ) នៃសមីការ គឺជាតម្លៃលេខនៃអញ្ញាតដែលនៅពេលយកទៅជំនួសក្នុងសមីការ នាំឱ្យអង្គទាំងពីរស្មើគ្នា (សមភាពពិត)។
ការដោះស្រាយសមីការ គឺការស្វែងរកគ្រប់ឫសទាំងអស់នៃសមីការនោះ។

ឧទាហរណ៍

ផ្ទៀងផ្ទាត់ថាតើ \(x = 3\) ជាឫសនៃសមីការ \(2x + 5 = 11\) ឬទេ?

ដំណោះស្រាយ

ជំនួស \(x = 3\) ចូលក្នុងអង្គទីមួយ ៖

\[2(3) + 5 = 6 + 5 = 11\]
ដោយអង្គទីមួយស្មើអង្គទីពីរ (\(11 = 11\)) ដូច្នេះ \(x = 3\) ជាឫសនៃសមីការ។

លក្ខណៈសមមូល និងវិធាននៃការដោះស្រាយសមីការ

លក្ខណៈនៃសមភាព

លក្ខណៈសមមូលនៃសមីការ

  1. វិធានបូក ឬដក ៖ បើគេបូក ឬដកចំនួនដូចគ្នាទៅលើអង្គទាំងពីរនៃសមីការ គេបានសមីការថ្មីមួយសមមូលនឹងសមីការដើម ៖

    \[A = B \iff A + C = B + C \quad{};\quad{} A - C = B - C\]
    វិធានផ្ទេរតួ (Transposition) ៖ គេអាចលើកតួពីអង្គម្ខាងទៅអង្គម្ខាងទៀតបាន ដោយគ្រាន់តែ ប្តូរសញ្ញានៃតួនោះ (បូកទៅជាដក, ដកទៅជាបូក)។

  2. វិធានគុណ ឬចែក ៖ បើគេគុណ ឬចែកអង្គទាំងពីរនៃសមីការនឹងចំនួនខុសពីសូន្យដូចគ្នា គេបានសមីការថ្មីមួយសមមូលនឹងសមីការដើម ៖

    \[A = B \iff A \times C = B \times C \quad{};\quad{} \frac{A}{C} = \frac{B}{C} \quad{} (C \ne 0)\]

ដំណោះស្រាយសមីការទម្រង់ \(ax + b = 0\)

ឫសនៃសមីការ \(ax = c\)

ចំពោះសមីការ \(ax = c\) ៖

  • បើ \(a \ne 0\) ៖ សមីការមានឫសតែមួយគត់គឺ \(x = \dfrac{c}{a}\)។

  • បើ \(a = 0\) និង \(c = 0\) (\(0x = 0\)) ៖ សមីការមាន ឫសរាប់មិនអស់ (គ្រប់ចំនួនពិតសុទ្ធតែជាឫស)។

  • បើ \(a = 0\) និង \(c \ne 0\) (\(0x = c\)) ៖ សមីការ គ្មានឫស (ឬគ្មានដំណោះស្រាយ)។

ឧទាហរណ៍

ដោះស្រាយសមីការខាងក្រោម ៖

  1. \(3x - 7 = 8\)

  2. \(5x + 4 = 2x - 5\)

ដំណោះស្រាយ

  1. \(3x - 7 = 8 \iff 3x = 8 + 7 \iff 3x = 15 \iff x = \dfrac{15}{3} = 5\)។ ដូចនេះ \(x = 5\)។

  2. \(5x - 2x = -5 - 4 \iff 3x = -9 \iff x = \dfrac{-9}{3} = -3\)។ ដូចនេះ \(x = -3\)។

សមីការដែលមានវង់ក្រចក និងភាគបែងជាចំនួន

ជំហានទូទៅក្នុងការដោះស្រាយ

  1. បំបាត់ភាគបែង ៖ រកភាគបែងរួមតូចបំផុត (LCM) រួចគុណអង្គទាំងពីរនឹង LCM នោះ។

  2. ពន្លាតវង់ក្រចក ៖ ប្រើច្បាប់បំបែក \(a(b+c) = ab + ac\)។

  3. ប្រមូលតួ ៖ លើកតួដែលមានអញ្ញាតទៅអង្គទីមួយ និងតួថេរទៅអង្គទីពីរ។

  4. បង្រួមតួ ៖ បូកដកតួដូចគ្នាឱ្យចេញរាង \(ax = c\)។

  5. ទាញរក \(x\) ៖ ចែកអង្គទាំងពីរនឹង \(a\) គេបាន \(x = \dfrac{c}{a}\)។

ឧទាហរណ៍

ដោះស្រាយសមីការ ៖ \(\dfrac{2x - 1}{3} - \dfrac{x + 2}{4} = 1\)។

ដំណោះស្រាយ

ភាគបែងរួមនៃ \(3\) និង \(4\) គឺ \(12\)។ គុណអង្គទាំងពីរនឹង \(12\) ៖

\[\begin{aligned} 12 \times \frac{2x - 1}{3} - 12 \times \frac{x + 2}{4} &= 12 \times 1 \\ 4(2x - 1) - 3(x + 2) &= 12 \\ 8x - 4 - 3x - 6 &= 12 \\ 5x - 10 &= 12 \\ 5x &= 22 \implies x = \frac{22}{5} = 4.4 \end{aligned}\]

ដោះស្រាយសមីការ

ដោះស្រាយសមីការ ៖ \(3(x - 2) - 2(2x + 1) = 5 - x\)។

ការដោះស្រាយចំណោទដោយប្រើសមីការដឺក្រេទី១

៤ ជំហានដោះស្រាយចំណោទ

  1. ជំហានទី ១ (ជ្រើសរើសអញ្ញាត) ៖ កំណត់បរិមាណមិនស្គាល់ដោយតាងអក្សរ \(x\) (ឬអក្សរផ្សេង) ព្រមទាំងបញ្ជាក់លក្ខខណ្ឌ និងខ្នាត។

  2. ជំហានទី ២ (បង្កើតសមីការ) ៖ បកប្រែប្រយោគភាសាពីបម្រាប់ចំណោទ ឱ្យទៅជាសមភាពពីជគណិត។

  3. ជំហានទី ៣ (ដោះស្រាយសមីការ) ៖ អនុវត្តវិធានពីជគណិតដើម្បីស្វែងរកតម្លៃ \(x\)។

  4. ជំហានទី ៤ (ផ្ទៀងផ្ទាត់ និងសន្និដ្ឋាន) ៖ ពិនិត្យមើលថាតើតម្លៃ \(x\) សមស្របនឹងលក្ខខណ្ឌជាក់ស្តែងឬទេ រួចឆ្លើយសំណួរចំណោទ។

ឧទាហរណ៍

ឪពុកម្នាក់មានអាយុច្រើនជាងកូន ៣០ ឆ្នាំ។ ក្នុងរយៈពេល ៥ ឆ្នាំទៀត អាយុឪពុកនឹងស្មើបីដងនៃអាយុកូន។ រកអាយុបច្ចុប្បន្នរបស់អ្នកទាំងពីរ។

ដំណោះស្រាយ

  • តាង \(x\) ជាអាយុបច្ចុប្បន្នរបស់កូន (\(x > 0\), គិតជាឆ្នាំ)។

  • អាយុបច្ចុប្បន្នរបស់ឪពុកគឺ \(x + 30\) ឆ្នាំ។

  • ក្នុងរយៈពេល ៥ ឆ្នាំទៀត ៖

    • អាយុកូនគឺ \(x + 5\)

    • អាយុឪពុកគឺ \((x + 30) + 5 = x + 35\)

  • តាមបម្រាប់ចំណោទ ៖

    \[x + 35 = 3(x + 5) \iff x + 35 = 3x + 15 \iff 3x - x = 35 - 15 \iff 2x = 20 \iff x = 10\]

  • ផ្ទៀងផ្ទាត់ ៖ បច្ចុប្បន្នកូនអាយុ \(10\) ឆ្នាំ ឪពុកអាយុ \(10 + 30 = 40\) ឆ្នាំ។ ក្នុង ៥ ឆ្នាំទៀត កូនអាយុ \(15\), ឪពុកអាយុ \(45\) (ស្មើ ៣ ដងពិតប្រាកដ)។

សន្និដ្ឋាន ៖ បច្ចុប្បន្នកូនមានអាយុ \(10\) ឆ្នាំ និងឪពុកមានអាយុ \(40\) ឆ្នាំ។

ចំណោទជាក់ស្តែង

ផលបូកនៃបីចំនួនគត់តៗគ្នាស្មើនឹង \(72\)។ ចូរសរសេរសមីការ និងរកចំនួនទាំងបីនោះ។

គុណខ្វែង ៖

សមីការប្រភាគ ៖

១០លំហាត់ទី ១០

សមីការប្រភាគ ៖

  • b. \(8(x-1) - 9(x+1) = 2(x-5) \implies -x - 17 = 2x - 10 \implies 3x = -7 \implies x = -\dfrac{7}{3}\)

សិក្សាភាពមានឫសនៃសមីការខាងក្រោម ៖

  1. \(2(x - 1) + 3(x + 2) = 5x + 4\)

  2. \(3(x - 2) - 2(x - 3) = x + 5\)

  3. \(4(x + 1) - 2(2x - 1) = 6\)

  4. \(\dfrac{x - 1}{2} - \dfrac{x - 2}{3} = \dfrac{x + 1}{6}\)

មើលដំណោះស្រាយ

សិក្សាភាពមានឫស ៖

  • a. \(5x + 4 = 5x + 4 \implies 0x = 0\) (ឫសរាប់មិនអស់)

  • b. \(x = x + 5 \implies 0x = 5\) (គ្មានឫស)

  • c. \(6 = 6 \implies 0x = 0\) (ឫសរាប់មិនអស់)

  • d. \(3(x-1) - 2(x-2) = x+1 \implies x+1 = x+1\) (ឫសរាប់មិនអស់)

១២លំហាត់ទី ១២

ដោះស្រាយសមីការដោយប្រើសមភាពសំខាន់ៗ ៖

  1. \((x + 3)^2 - x^2 = 21\)

  2. \((x - 2)^2 - (x + 1)^2 = 9\)

  3. \((2x - 1)^2 - 4x^2 = 15\)

  4. \((x + 4)(x - 4) - x(x - 2) = 6\)

មើលដំណោះស្រាយ

ប្រើសមភាព ៖

  • a. \(x^2 + 6x + 9 - x^2 = 21 \implies 6x = 12 \implies x = 2\)

  • b. \((x^2-4x+4) - (x^2+2x+1) = 9 \implies -6x + 3 = 9 \implies x = -1\)

  • c. \(4x^2 - 4x + 1 - 4x^2 = 15 \implies -4x = 14 \implies x = -\dfrac{7}{2}\)

  • d. \(x^2 - 16 - x^2 + 2x = 6 \implies 2x = 22 \implies x = 11\)

១៣លំហាត់ទី ១៣

  1. \((x - 5)(2x + 7) = 0\)

  2. \((3x - 2)(4x + 5) = 0\)

  3. \(x^2 - 16 = 0\)

  4. \(4x^2 - 9 = 0\)

មើលដំណោះស្រាយ

ផលគុណកត្តាស្មើ \(0\) ៖

  • a. \(x = 5\) ឬ \(x = -\dfrac{7}{2}\)

  • b. \(x = \dfrac{2}{3}\) ឬ \(x = -\dfrac{5}{4}\)

  • c. \((x-4)(x+4) = 0 \implies x = \pm 4\)

  • d. \((2x-3)(2x+3) = 0 \implies x = \pm \dfrac{3}{2}\)

១៤លំហាត់ទី ១៤

ដោះស្រាយសមីការដោយដាក់ជាផលគុណកត្តា ៖

  1. \(x^2 - 5x = 0\)

  2. \(3x^2 + 6x = 0\)

  3. \((2x - 3)^2 - (x + 1)^2 = 0\)

  4. \((3x + 2)^2 - 25 = 0\)

មើលដំណោះស្រាយ

ដាក់ជាផលគុណកត្តា ៖

  • a. \(x(x-5) = 0 \implies x = 0\) ឬ \(x = 5\)

  • b. \(3x(x+2) = 0 \implies x = 0\) ឬ \(x = -2\)

  • c. \((x-4)(3x-2) = 0 \implies x = 4\) ឬ \(x = \dfrac{2}{3}\)

  • d. \((3x+2-5)(3x+2+5) = 0 \implies (3x-3)(3x+7) = 0 \implies x = 1\) ឬ \(x = -\dfrac{7}{3}\)

១៥លំហាត់ទី ១៥

ដោះស្រាយសមីការដោយដាក់ជាផលគុណកត្តា ៖

  1. \(x^2 - 7x + 12 = 0\)

  2. \(x^2 + 8x + 15 = 0\)

  3. \(2x^2 + 5x + 3 = 0\)

  4. \(x^2 - 2x - 8 = 0\)

មើលដំណោះស្រាយ

ត្រីធាដឺក្រេទី ២ ៖

  • a. \((x-3)(x-4) = 0 \implies x = 3\) ឬ \(x = 4\)

  • b. \((x+3)(x+5) = 0 \implies x = -3\) ឬ \(x = -5\)

  • c. \((2x+3)(x+1) = 0 \implies x = -\dfrac{3}{2}\) ឬ \(x = -1\)

  • d. \((x-4)(x+2) = 0 \implies x = 4\) ឬ \(x = -2\)

១៦លំហាត់ទី ១៦

ដោះស្រាយសមីការអមដោយលក្ខខណ្ឌកំណត់ (ភាគបែងមានអថេរ) ៖

  1. \(\dfrac{3}{x - 2} = \dfrac{5}{x + 4}\)

  2. \(\dfrac{2x}{x - 3} = 2 + \dfrac{6}{x - 3}\)

មើលដំណោះស្រាយ

លក្ខខណ្ឌកំណត់ ៖

  • a. \(x \ne 2, -4\) ៖ \(3(x+4) = 5(x-2) \implies 3x + 12 = 5x - 10 \implies 2x = 22 \implies x = 11\)

  • b. \(x \ne 3\) ៖ \(2x = 2(x-3) + 6 \implies 2x = 2x \implies 0x = 0\)។ ដូច្នេះគ្រប់ \(x \ne 3\)

១៧លំហាត់ទី ១៧

ដោះស្រាយសមីការសនិទាន ៖

  1. \(\dfrac{x + 3}{x - 1} = \dfrac{x - 2}{x - 3}\)

  2. \(\dfrac{x - 2}{x + 2} = \dfrac{x - 4}{x - 1}\)

មើលដំណោះស្រាយ

សមីការសនិទាន ៖

  • a. \(x \ne 1, 3\) ៖ \((x+3)(x-3) = (x-1)(x-2) \implies x^2 - 9 = x^2 - 3x + 2 \implies 3x = 11 \implies x = \dfrac{11}{3}\)

  • b. \(x \ne -2, 1\) ៖ \((x-2)(x-1) = (x+2)(x-4) \implies x^2 - 3x + 2 = x^2 - 2x - 8 \implies x = 10\)

១៨លំហាត់ទី ១៨

ពិភាក្សាតាមតម្លៃប៉ារ៉ាម៉ែត្រ \(m\) នូវចំនួនឫសនៃសមីការ ៖

\((m^2-4)x = m + 2 \iff (m-2)(m+2)x = m+2\) ៖

  • បើ \(m \ne \pm 2\) ៖ មានឫសតែមួយ \(x = \dfrac{1}{m-2}\)

២៦លំហាត់ទី ២៦

ផលបូកនៃពីរចំនួនស្មើនឹង \(84\) ហើយចំនួនមួយធំជាងចំនួនមួយទៀត \(16\)។ រកចំនួនទាំងពីរនោះ។

៣២លំហាត់ទី ៣២

ចំនួនមួយមានពីរខ្ទង់។ ផលបូកនៃលេខទាំងពីរខ្ទង់ស្មើ \(11\)។ បើគេត្រឡប់លេខខ្ទង់ទាំងពីរ នោះគេទទួលបានចំនួនថ្មីមួយដែលធំជាងចំនួនដើម \(45\)។ រកចំនួនដើមនោះ។

មើលដំណោះស្រាយ

តាងខ្ទង់ដប់ \(x\), ខ្ទង់រាយ \(11-x\) ៖
ចំនួនដើម \(10x + (11-x) = 9x + 11\)។
ចំនួនត្រឡប់ \(10(11-x) + x = 110 - 9x\)។
\((110 - 9x) - (9x + 11) = 45 \implies 99 - 18x = 45 \implies 18x = 54 \implies x = 3\)។

៣៣លំហាត់ទី ៣៣

\((2x+1) + x = 10 \implies 3x = 9 \implies x = 3\)។

៣៤លំហាត់ទី ៣៤

៣៥លំហាត់ទី ៣៥

បច្ចុប្បន្ន ម្តាយមានអាយុស្មើ ៣ ដងនៃអាយុកូនស្រី។ ក្នុងរយៈពេល ១២ ឆ្នាំទៀត ម្តាយនឹងមានអាយុស្មើ ២ ដងនៃអាយុកូនស្រី។ រកអាយុបច្ចុប្បន្នរបស់អ្នកទាំងពីរ។

៣៦លំហាត់ទី ៣៦

មើលដំណោះស្រាយ

៣៧លំហាត់ទី ៣៧

ត្រីកោណមួយមានមុំទាំងបីផ្ទៀងផ្ទាត់ ៖ មុំទីពីរធំជាងមុំទីមួយ \(15^\circ\) ហើយមុំទីបីធំជាងពីរដងនៃមុំទីមួយ \(5^\circ\)។ រករង្វាស់មុំទាំងបីនៃត្រីកោណ។

មើលដំណោះស្រាយ

មុំ \(A = x\), \(B = x + 15^\circ\), \(C = 2x + 5^\circ\) ៖
\(x + (x+15) + (2x+5) = 180^\circ \implies 4x + 20 = 180 \implies x = 40^\circ\)។
មុំទាំងបីគឺ \(40^\circ, 55^\circ, 85^\circ\)។

៤១លំហាត់ទី ៤១

ក្នុងកាបូបមួយមានកាក់ ២០០ រៀល និង ៥០០ រៀល សរុប ៣៥ កាក់ គិតជាប្រាក់សរុប ១៣០០០ រៀល។ តើមានកាក់ប្រភេទនីមួយៗប៉ុន្មាន?

មើលដំណោះស្រាយ

តាងកាក់ ៥០០ រៀលមាន \(x\), កាក់ ២០០ រៀលមាន \(35-x\) ៖
\(500x + 200(35-x) = 13000 \implies 300x + 7000 = 13000 \implies 300x = 6000 \implies x = 20\)។
កាក់ ៥០០ រៀលមាន ២០ និងកាក់ ២០០ រៀលមាន ១៥។

៤២លំហាត់ទី ៤២

ពូសុខលក់មាន់ និងទាបានសរុប ៤៥ ក្បាល។ មាន់មួយក្បាលតម្លៃ \(25000\) រៀល និងទាមួយក្បាលតម្លៃ \(30000\) រៀល ។ គាត់ទទួលបានប្រាក់សរុប \(1225000\) រៀល ។ រកចំនួនមាន់ និងចំនួនទាដែលបានលក់។

មើលដំណោះស្រាយ

មាន់ \(x\), ទា \(45-x\) ៖
\(25000x + 30000(45-x) = 1225000 \implies -5000x + 1350000 = 1225000 \implies 5000x = 125000 \implies x = 25\)។
មាន់ ២៥ ក្បាល និងទា ២០ ក្បាល។

៤៣លំហាត់ទី ៤៣

រថយន្តមួយបើកបរពីភ្នំពេញទៅកំពង់សោមចម្ងាយ \(230\text{ km}\)។ មួយម៉ោងដំបូងរថយន្តបើកបរដោយល្បឿន \(v\) បន្ទាប់មករថយន្តបង្កើនល្បឿនថែម \(10\text{ km/h}\) សម្រាប់រយៈពេល ២ ម៉ោងទៀតទើបដល់។ រកល្បឿន \(v\)។

មើលដំណោះស្រាយ

\(v(1) + (v+10)(2) = 230 \implies 3v + 20 = 230 \implies 3v = 210 \implies v = 70\text{ km/h}\)។

៤៤លំហាត់ទី ៤៤

អ្នកជិះកង់ម្នាក់ចេញដំណើរពី A ទៅ B ដោយល្បឿន \(15\text{ km/h}\)។ ២ ម៉ោងក្រោយមក អ្នកជិះម៉ូតូម្នាក់ចេញដំណើរតាមពីក្រោយដោយល្បឿន \(45\text{ km/h}\)។ តើអ្នកជិះម៉ូតូត្រូវចំណាយពេលប៉ុន្មានម៉ោងដើម្បីជិះទាន់អ្នកជិះកង់?

មើលដំណោះស្រាយ

តាងពេលជិះទាន់ \(t\) ម៉ោង ៖
\(45t = 15(t + 2) \implies 45t = 15t + 30 \implies 30t = 30 \implies t = 1\) ម៉ោង។

៤៥លំហាត់ទី ៤៥

ទូកម៉ាស៊ីនមួយបើកបរបញ្ច្រាសទឹកបានចម្ងាយ \(48\text{ km}\) ក្នុងរយៈពេល ៤ ម៉ោង។ បើល្បឿនខ្សែទឹកហូរគឺ \(3\text{ km/h}\) រកល្បឿនពិតរបស់ទូកក្នុងទឹកនឹង។

មើលដំណោះស្រាយ

ល្បឿនបញ្ច្រាសទឹក \(v - 3\) ៖
\(4(v - 3) = 48 \implies v - 3 = 12 \implies v = 15\text{ km/h}\)។

៤៦លំហាត់ទី ៤៦

ជាងម្នាក់ធ្វើការងារមួយចប់ក្នុងរយៈពេល ៦ ថ្ងៃ រីឯកូនជាងធ្វើការងារដដែលចប់ក្នុងរយៈពេល ១២ ថ្ងៃ។ បើអ្នកទាំងពីរធ្វើរួមគ្នា តើត្រូវចំណាយពេលប៉ុន្មានថ្ងៃទើបចប់?

មើលដំណោះស្រាយ

ក្នុង ១ ថ្ងៃធ្វើបាន \(\dfrac{1}{6} + \dfrac{1}{12} = \dfrac{3}{12} = \dfrac{1}{4}\) ការងារ។
ធ្វើរួមគ្នាចប់ក្នុងរយៈពេល \(4\) ថ្ងៃ។

៤៧លំហាត់ទី ៤៧

ទុយោទឹកពីរចាក់ទឹកចូលអាងមួយ។ ទុយោទីមួយចាក់ពេញក្នុង ៤ ម៉ោង ទុយោទីពីរចាក់ពេញក្នុង ៦ ម៉ោង។ បើបើកទុយោទាំងពីរព្រមគ្នារយៈពេល ១ ម៉ោង រួចបិទទុយោទីមួយ តើទុយោទីពីរត្រូវចំណាយពេលប៉ុន្មានម៉ោងទៀតទើបចាក់ពេញអាង?

មើលដំណោះស្រាយ

ក្នុង ១ ម៉ោងរួមគ្នា ៖ \(\dfrac{1}{4} + \dfrac{1}{6} = \dfrac{5}{12}\) អាង។
នៅសល់ \(1 - \dfrac{5}{12} = \dfrac{7}{12}\) អាង។
ទុយោទីពីរចំណាយពេល ៖ \(\dfrac{7/12}{1/6} = \dfrac{7}{2} = 3.5\) ម៉ោងទៀត។

៤៨លំហាត់ទី ៤៨

គេមានទឹកអំបិលកំហាប់ \(10\%\) ចំនួន \(300\text{ g}\)។ តើត្រូវបន្ថែមទឹកសុទ្ធប៉ុន្មានក្រាមដើម្បីឱ្យកំហាប់ទឹកអំបិលថយចុះមកនៅត្រឹម \(6\%\)?

មើលដំណោះស្រាយ

ម៉ាសអំបិល ៖ \(300 \times 10\% = 30\text{ g}\)។
តាងទឹកថែម \(x\text{ g}\) ៖
\(\dfrac{30}{300+x} = 0.06 \implies 30 = 18 + 0.06x \implies 0.06x = 12 \implies x = 200\text{ g}\)។

៤៩លំហាត់ទី ៤៩

គេមានទឹកអាស៊ីតកំហាប់ \(20\%\) និងទឹកអាស៊ីតកំហាប់ \(50\%\)។ តើត្រូវលាយទឹកអាស៊ីតប្រភេទនីមួយៗប៉ុន្មានលីត្រ ដើម្បីទទួលបានទឹកអាស៊ីតកំហាប់ \(30\%\) ចំនួន \(60\text{ L}\)?

មើលដំណោះស្រាយ

តាងទឹកអាស៊ីត \(20\%\) ចំនួន \(x\text{ L}\), ទឹកអាស៊ីត \(50\%\) ចំនួន \(60-x\text{ L}\) ៖
\(0.2x + 0.5(60-x) = 0.3(60) \implies -0.3x + 30 = 18 \implies 0.3x = 12 \implies x = 40\text{ L}\)។
យក \(20\%\) ចំនួន \(40\text{ L}\) និង \(50\%\) ចំនួន \(20\text{ L}\)។

៥០លំហាត់ទី ៥០

សិស្សមួយក្រុមជួលឡានមួយជិះកម្សាន្តដោយថ្លៃឈ្នួល \(120\$\)។ នៅថ្ងៃចេញដំណើរមានសិស្ស ៣ នាក់ខកខានមិនបានទៅ ធ្វើឱ្យសិស្សដែលនៅសល់ម្នាក់ៗត្រូវបង់បន្ថែម \(2\$\)។ តើដើមឡើយមានសិស្សប៉ុន្មាននាក់ក្នុងក្រុម?

មើលដំណោះស្រាយ

តាងសិស្សដើម \(x\) នាក់ ៖
\(\dfrac{120}{x-3} - \dfrac{120}{x} = 2 \implies 120\left(\dfrac{3}{x(x-3)}\right) = 2 \implies x(x-3) = 180\)។
\(x^2 - 3x - 180 = 0 \iff (x-15)(x+12) = 0 \implies x = 15\) នាក់។
