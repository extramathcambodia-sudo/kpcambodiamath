ប្រវត្តិនៃនិមិត្តសញ្ញាវិសមភាព និងការវិវត្តនៃវិសមីការ

ខណៈពេលដែលសមីការផ្តោតលើភាព «ស្មើគ្នា» វិសមីការផ្តោតលើទំនាក់ទំនង «មិនស្មើគ្នា» ឬ «ការប្រៀបធៀបធំជាង-តូចជាង» ដែលមានសារៈសំខាន់យ៉ាងខ្លាំងក្នុងការគ្រប់គ្រងដែនកំណត់ និងការបង្កើនប្រសិទ្ធភាព ៖

  • ថូម៉ាស ហារីយ៉ូត (Thomas Harriot, 1560–1621) ៖ គណិតវិទូ និងតារាវិទូជនជាតិអង់គ្លេស គឺជាអ្នកដំបូងបង្អស់ដែលបានបង្កើត និងណែនាំនិមិត្តសញ្ញា ធំជាង (\(>\)) និង តូចជាង (\(<\)) នៅក្នុងសៀវភៅ Artis Analyticae Praxis ដែលបានបោះពុម្ពក្រោយមរណភាពរបស់លោកនៅឆ្នាំ ១៦៣១។

  • ព្យែរ ប៊ូហ្គ័រ (Pierre Bouguer, 1698–1758) ៖ គណិតវិទូ និងរូបវិទូជនជាតិបារាំង បានបន្ថែមរបារផ្ដេកខាងក្រោមនិមិត្តសញ្ញាដើម្បីបង្កើតសញ្ញា ធំជាង ឬស្មើ (\(\ge\)) និង តូចជាង ឬស្មើ (\(\le\)) នៅឆ្នាំ ១៧៣៤។

  • ការវិវត្តក្នុងគណិតវិទ្យាទំនើប ៖ នៅក្នុងសតវត្សទី ២០ គណិតវិទូ John von Neumann និង George Dantzig បានអភិវឌ្ឍទ្រឹស្ដី ប្លង់លីនេអ៊ែរ (Linear Programming) ដោយប្រើប្រាស់ប្រព័ន្ធវិសមីការ ដើម្បីដោះស្រាយបញ្ហាសេដ្ឋកិច្ច ការគ្រប់គ្រងធនធាន ការដឹកជញ្ជូន និងការកាត់បន្ថយចំណាយក្នុងឧស្សាហកម្មយ៉ាងមានប្រសិទ្ធភាពខ្ពស់បំផុត។

សញ្ញាណវិសមភាព

វិសមភាព

វិសមភាព (Inequality) គឺជាល្បះគណិតវិទ្យាដែលតភ្ជាប់កន្សោមពីរដោយប្រើនិមិត្តសញ្ញា ៖

  • \(<\) ៖ តូចជាងដាច់ខាត (Strictly less than)

  • \(>\) ៖ ធំជាងដាច់ខាត (Strictly greater than)

  • \(\le\) ៖ តូចជាង ឬស្មើ (Less than or equal to)

  • \(\ge\) ៖ ធំជាង ឬស្មើ (Greater than or equal to)

លក្ខណៈនៃវិសមភាព

លក្ខណៈគ្រឹះនៃវិសមភាព

ចំពោះគ្រប់ចំនួនពិត \(a, b, c\) ៖

  1. លក្ខណៈបូក ឬដក ៖ បើបូក ឬដកចំនួនដូចគ្នាទៅលើអង្គទាំងពីរ ទិសដៅវិសមភាពមិនប្រែប្រួលឡើយ ៖

    \[a < b \iff a + c < b + c \quad{};\quad{} a < b \iff a - c < b - c\]

  2. លក្ខណៈគុណ ឬចែកនឹងចំនួនវិជ្ជមាន (\(c > 0\)) ៖ ទិសដៅវិសមភាពរក្សាទុកនៅដដែល ៖

    \[a < b \iff a \cdot c < b \cdot c \quad{};\quad{} \frac{a}{c} < \frac{b}{c}\]

  3. លក្ខណៈគុណ ឬចែកនឹងចំនួនអវិជ្ជមាន (\(c < 0\)) ៖ ទិសដៅវិសមភាព ត្រូវតែត្រឡប់បញ្រ្ចាសទិស ៖

    \[a < b \iff a \cdot c > b \cdot c \quad{};\quad{} \frac{a}{c} > \frac{b}{c}\]

កំហុសដែលត្រូវចងចាំដាច់ខាត

នៅពេល គុណ ឬចែកអង្គទាំងពីរនឹងចំនួនអវិជ្ជមាន ត្រូវតែប្តូរសញ្ញាវិសមភាព ៖

  • ពី \(<\) ទៅជា \(>\) (ឬពី \(>\) ទៅជា \(<\))

  • ពី \(\le\) ទៅជា \(\ge\) (ឬពី \(\ge\) ទៅជា \(\le\))

ឧទាហរណ៍ ៖ \(-2x < 6 \iff x > \dfrac{6}{-2} \iff x > -3\) (មិនមែន \(x < -3\) ទេ!)

និយមន័យ

វិសមីការដឺក្រេទី១មានមួយអញ្ញាត

វិសមីការដឺក្រេទី១មានមួយអញ្ញាត គឺជាវិសមីការដែលអាចបំប្លែងឱ្យមានទម្រង់ណាមួយក្នុងចំណោមទម្រង់ទាំងបួនខាងក្រោម ៖

\[ax + b > 0 \quad{};\quad{} ax + b < 0 \quad{};\quad{} ax + b \ge 0 \quad{};\quad{} ax + b \le 0\]
ដែល \(a, b \in \mathbb{R}\) និង \(a \ne 0\)។

ការបកស្រាយដំណោះស្រាយលើបន្ទាត់ចំនួន

ដំណោះស្រាយនៃវិសមីការអាចតាងដោយប្រមាណវិធីលើបន្ទាត់ចំនួន និងទម្រង់ចន្លោះ (Interval notation) ៖

វិសមភាព ការអាន ទម្រង់ចន្លោះ
\(x > a\) \(x\) ធំជាង \(a\) ដាច់ខាត \((a, +\infty)\)
\(x < a\) \(x\) តូចជាង \(a\) ដាច់ខាត \((-\infty, a)\)
\(x \ge a\) \(x\) ធំជាង ឬស្មើ \(a\) \([a, +\infty)\)
\(x \le a\) \(x\) តូចជាង ឬស្មើ \(a\) \((-\infty, a]\)
ឧទាហរណ៍

ដោះស្រាយវិសមីការខាងក្រោម រួចបកស្រាយដំណោះស្រាយលើបន្ទាត់ចំនួន ៖

  1. \(2x - 5 > 3\)

  2. \(-3x + 4 \ge 13\)

ដំណោះស្រាយ

  1. \(2x - 5 > 3 \iff 2x > 8 \iff x > 4\)។
    ចន្លោះដំណោះស្រាយ ៖ \(x \in (4, +\infty)\)។

    រូបភាពនេះកំពុងរៀបចំ

  2. \(-3x + 4 \ge 13 \iff -3x \ge 9 \iff x \le \dfrac{9}{-3} \iff x \le -3\) (ប្តូរសញ្ញាវិសមភាព)។
    ចន្លោះដំណោះស្រាយ ៖ \(x \in (-\infty, -3]\)។

    រូបភាពនេះកំពុងរៀបចំ

ដោះស្រាយវិសមីការ

ដោះស្រាយវិសមីការ ៖ \(\dfrac{2x - 1}{3} - \dfrac{x + 2}{2} < 1\)។

ប្រព័ន្ធវិសមីការ

ប្រព័ន្ធវិសមីការដឺក្រេទី១មានមួយអញ្ញាត គឺជាសំណុំនៃពីរ ឬច្រើនវិសមីការដែលមានអញ្ញាតតែមួយ។
ដំណោះស្រាយនៃប្រព័ន្ធវិសមីការ គឺជា ប្រសព្វ (Intersection) នៃសំណុំដំណោះស្រាយនៃវិសមីការនីមួយៗក្នុងប្រព័ន្ធ។

ឧទាហរណ៍

ដោះស្រាយប្រព័ន្ធវិសមីការ ៖

\[\begin{cases} 2x - 3 < 5 \\ 3x + 1 \ge -5 \end{cases}\]

ដំណោះស្រាយ

  • តាមវិសមីការទីមួយ ៖ \(2x < 8 \iff x < 4\)

  • តាមវិសមីការទីពីរ ៖ \(3x \ge -6 \iff x \ge -2\)

ប្រសព្វនៃដំណោះស្រាយទាំងពីរគឺ ៖ \(-2 \le x < 4\) ឬជាចន្លោះ \([-2, 4)\)។

ការដោះស្រាយចំណោទដោយប្រើវិសមីការ

ពាក្យគន្លឹះក្នុងចំណោទវិសមភាព

  • «យ៉ាងហោចណាស់», «មិនតិចជាង», «ចាប់ពី» \(\implies \ge\)

  • «យ៉ាងច្រើនបំផុត», «មិនលើសពី», «ត្រឹម» \(\implies \le\)

  • «លើសពី», «ធំជាង», «ច្រើនជាង» \(\implies >\)

  • «ក្រោម», «តិចជាង» \(\implies <\)

ឧទាហរណ៍

សិស្សម្នាក់ទទួលបានពិន្ទុតេស្តគណិតវិទ្យាពីរលើកដំបូងគឺ ៧៥ និង ៨២។ ដើម្បីទទួលបាននិទ្ទេសល្អ សិស្សនោះត្រូវមានពិន្ទុមធ្យមភាគយ៉ាងហោចណាស់ ៨០ ក្នុងតេស្តទាំងបីលើក។ តើតេស្តលើកទីបីគាត់ត្រូវទទួលបានពិន្ទុយ៉ាងតិចប៉ុន្មាន?

ដំណោះស្រាយ

  • តាង \(x\) ជាពិន្ទុតេស្តលើកទីបី (\(0 \le x \le 100\))។

  • មធ្យមភាគនៃតេស្តទាំងបីគឺ \(\dfrac{75 + 82 + x}{3}\)។

  • តាមបម្រាប់ ៖

    \[\frac{75 + 82 + x}{3} \ge 80 \iff 157 + x \ge 240 \iff x \ge 240 - 157 \iff x \ge 83\]

សន្និដ្ឋាន ៖ ក្នុងតេស្តលើកទីបី សិស្សនោះត្រូវទទួលបានពិន្ទុយ៉ាងតិច \(83\) ពិន្ទុ។

យុវជនម្នាក់មានប្រាក់ \(50000\) រៀល ។ គាត់ទិញសៀវភៅមួយក្បាលតម្លៃ \(14000\) រៀល ហើយប្រាក់ដែលនៅសល់គាត់ចង់ទិញប៊ិចដែលមួយដើមតម្លៃ \(3000\) រៀល ។ តើគាត់អាចទិញប៊ិចបានច្រើនបំផុតប៉ុន្មានដើម?

លំហាត់អនុវត្តន៍

១លំហាត់ទី ១

បំពេញសញ្ញា \(>\) ឬ \(<\) ក្នុងប្រអប់ \(\square\) ៖

  1. បើ \(a > b\) នោះ \(a + 7 \;\square\; b + 7\)

  2. បើ \(x < y\) នោះ \(x - 12 \;\square\; y - 12\)

  3. បើ \(m > n\) នោះ \(5m \;\square\; 5n\)

  4. បើ \(p < q\) នោះ \(-4p \;\square\; -4q\)

មើលដំណោះស្រាយ

បំពេញសញ្ញា ៖

  • a. \(a + 7 > b + 7\)

  • b. \(x - 12 < y - 12\)

  • c. \(5m > 5n\)

  • d. \(-4p > -4q\) (គុណនឹងចំនួនអវិជ្ជមាន)

២លំហាត់ទី ២

បំពេញសញ្ញាវិសមភាព ៖

  1. បើ \(a > b\) នោះ \(\dfrac{a}{3} \;\square\; \dfrac{b}{3}\)

  2. បើ \(x < y\) នោះ \(-\dfrac{x}{5} \;\square\; -\dfrac{y}{5}\)

  3. បើ \(m \ge n\) នោះ \(3 - 2m \;\square\; 3 - 2n\)

  4. បើ \(u \le v\) នោះ \(4u + 1 \;\square\; 4v + 1\)

មើលដំណោះស្រាយ

បំពេញសញ្ញា ៖

  • a. \(\dfrac{a}{3} > \dfrac{b}{3}\)

  • b. \(-\dfrac{x}{5} > -\dfrac{y}{5}\)

  • c. \(3 - 2m \le 3 - 2n\)

  • d. \(4u + 1 \le 4v + 1\)

៣លំហាត់ទី ៣

ដោះស្រាយវិសមីការ និងបកស្រាយដំណោះស្រាយលើបន្ទាត់ចំនួន ៖

  1. \(x + 8 > 15\)

  2. \(x - 7 \le 4\)

  3. \(3x \ge -18\)

  4. \(-4x < 24\)

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ ៖

  • a. \(x > 7 \implies (7, +\infty)\)

  • b. \(x \le 11 \implies (-\infty, 11]\)

  • c. \(x \ge -6 \implies [-6, +\infty)\)

  • d. \(x > -6 \implies (-6, +\infty)\)

៤លំហាត់ទី ៤

ដោះស្រាយវិសមីការទម្រង់ \(ax + b > c\) ៖

  1. \(2x + 5 \le 17\)

  2. \(3x - 8 > 13\)

  3. \(-5x + 7 < 32\)

  4. \(9 - 2x \ge 1\)

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ ៖

  • a. \(2x \le 12 \implies x \le 6\)

  • b. \(3x > 21 \implies x > 7\)

  • c. \(-5x < 25 \implies x > -5\)

  • d. \(-2x \ge -8 \implies x \le 4\)

៥លំហាត់ទី ៥

ដោះស្រាយវិសមីការដែលមានអញ្ញាតទាំងសងខាង ៖

  1. \(5x - 3 > 2x + 9\)

  2. \(7x + 4 \le 3x - 12\)

  3. \(4x - 15 \ge 9x + 5\)

  4. \(8 - 3x < 5x - 8\)

មើលដំណោះស្រាយ

អញ្ញាតទាំងសងខាង ៖

  • a. \(3x > 12 \implies x > 4\)

  • b. \(4x \le -16 \implies x \le -4\)

  • c. \(-5x \ge 20 \implies x \le -4\)

  • d. \(-8x < -16 \implies x > 2\)

៦លំហាត់ទី ៦

ដោះស្រាយវិសមីការដែលមានវង់ក្រចក ៖

  1. \(3(x - 2) \le 15\)

  2. \(4(2x + 3) > 28\)

  3. \(5(x - 1) \ge 3(x + 5)\)

  4. \(2(3x - 4) < 4(x + 1) + 2\)

មើលដំណោះស្រាយ

សមីការមានវង់ក្រចក ៖

  • a. \(x - 2 \le 5 \implies x \le 7\)

  • b. \(8x + 12 > 28 \implies 8x > 16 \implies x > 2\)

  • c. \(5x - 5 \ge 3x + 15 \implies 2x \ge 20 \implies x \ge 10\)

  • d. \(6x - 8 < 4x + 6 \implies 2x < 14 \implies x < 7\)

៧លំហាត់ទី ៧

ដោះស្រាយវិសមីការដែលមានសញ្ញាដកមុខវង់ក្រចក ៖

  1. \(12 - (3x + 4) \ge 2\)

  2. \(4x - (2x - 5) < 13\)

  3. \(3(x - 1) - 2(2x + 3) > 1\)

  4. \(5(2x - 3) - 4(3x - 2) \le -1\)

មើលដំណោះស្រាយ

សមីការមានសញ្ញាដក ៖

  • a. \(8 - 3x \ge 2 \implies -3x \ge -6 \implies x \le 2\)

  • b. \(2x + 5 < 13 \implies 2x < 8 \implies x < 4\)

  • c. \(3x - 3 - 4x - 6 > 1 \implies -x > 10 \implies x < -10\)

  • d. \(10x - 15 - 12x + 8 \le -1 \implies -2x \le 6 \implies x \ge -3\)

៨លំហាត់ទី ៨

ដោះស្រាយវិសមីការទសភាគ ៖

  1. \(0.4x + 1.6 \le 3.2\)

  2. \(1.2x - 0.8 > 0.4x + 1.6\)

  3. \(0.05x - 0.2 \ge 0.15x + 0.1\)

  4. \(0.3(x - 2) < 0.5(x + 1) - 1.1\)

មើលដំណោះស្រាយ

វិសមីការទសភាគ ៖

  • a. \(4x + 16 \le 32 \implies 4x \le 16 \implies x \le 4\)

  • b. \(12x - 8 > 4x + 16 \implies 8x > 24 \implies x > 3\)

  • c. \(5x - 20 \ge 15x + 10 \implies -10x \ge 30 \implies x \le -3\)

  • d. \(3(x-2) < 5(x+1) - 11 \implies 3x - 6 < 5x - 6 \implies -2x < 0 \implies x > 0\)

៩លំហាត់ទី ៩

ដោះស្រាយវិសមីការប្រភាគសាមញ្ញ ៖

  1. \(\dfrac{x}{3} + \dfrac{x}{4} > 7\)

  2. \(\dfrac{x}{2} - \dfrac{x}{5} \le 6\)

  3. \(\dfrac{3x}{4} - \dfrac{x}{3} \ge 5\)

  4. \(\dfrac{5x}{6} + \dfrac{x}{2} < 8\)

មើលដំណោះស្រាយ

វិសមីការប្រភាគសាមញ្ញ ៖

  • a. \(4x + 3x > 84 \implies 7x > 84 \implies x > 12\)

  • b. \(5x - 2x \le 60 \implies 3x \le 60 \implies x \le 20\)

  • c. \(9x - 4x \ge 60 \implies 5x \ge 60 \implies x \ge 12\)

  • d. \(5x + 3x < 48 \implies 8x < 48 \implies x < 6\)

១០លំហាត់ទី ១០

ដោះស្រាយវិសមីការប្រភាគ ៖

  1. \(\dfrac{x + 3}{4} \le \dfrac{x - 1}{3}\)

  2. \(\dfrac{2x - 5}{3} > \dfrac{x + 1}{2}\)

  3. \(\dfrac{3x - 2}{5} \ge \dfrac{2x + 1}{3}\)

  4. \(\dfrac{4x + 1}{6} < \dfrac{3x - 2}{4}\)

មើលដំណោះស្រាយ

វិសមីការប្រភាគ ៖

  • a. \(3(x+3) \le 4(x-1) \implies 3x + 9 \le 4x - 4 \implies x \ge 13\)

  • b. \(2(2x-5) > 3(x+1) \implies 4x - 10 > 3x + 3 \implies x > 13\)

  • c. \(3(3x-2) \ge 5(2x+1) \implies 9x - 6 \ge 10x + 5 \implies x \le -11\)

  • d. \(2(4x+1) < 3(3x-2) \implies 8x + 2 < 9x - 6 \implies x > 8\)

១១លំហាត់ទី ១១

ដោះស្រាយវិសមីការប្រភាគចម្រុះ ៖

  1. \(\dfrac{x - 2}{3} + \dfrac{x + 1}{4} > 2\)

  2. \(\dfrac{2x + 1}{5} - \dfrac{x - 2}{3} \le 1\)

  3. \(\dfrac{3x - 1}{4} - \dfrac{2x + 3}{6} \ge \dfrac{1}{12}\)

  4. \(\dfrac{x + 3}{2} - \dfrac{2x - 1}{3} < 1 - \dfrac{x}{6}\)

មើលដំណោះស្រាយ

វិសមីការប្រភាគចម្រុះ ៖

  • a. \(4(x-2) + 3(x+1) > 24 \implies 7x - 5 > 24 \implies 7x > 29 \implies x > \dfrac{29}{7}\)

  • b. \(3(2x+1) - 5(x-2) \le 15 \implies x + 13 \le 15 \implies x \le 2\)

  • c. \(3(3x-1) - 2(2x+3) \ge 1 \implies 5x - 9 \ge 1 \implies 5x \ge 10 \implies x \ge 2\)

  • d. \(3(x+3) - 2(2x-1) < 6 - x \implies -x + 11 < 6 - x \implies 11 < 6\) (គ្មានដំណោះស្រាយ)

១២លំហាត់ទី ១២

ដោះស្រាយវិសមីការប្រភាគ ៖

  1. \(\dfrac{2(x-1)}{3} - \dfrac{3(x+2)}{4} > \dfrac{x-4}{6}\)

  2. \(\dfrac{x}{3} - \dfrac{1}{2}\left(\dfrac{x}{4} - 1\right) \le \dfrac{7}{12}\)

មើលដំណោះស្រាយ

វិសមីការប្រភាគ ៖

  • a. \(8(x-1) - 9(x+2) > 2(x-4) \implies -x - 26 > 2x - 8 \implies 3x < -18 \implies x < -6\)

  • b. \(4x - 6\left(\dfrac{x-4}{4}\right) \le 7 \implies 4x - \dfrac{3}{2}x + 6 \le 7 \implies \dfrac{5}{2}x \le 1 \implies x \le \dfrac{2}{5}\)

១៣លំហាត់ទី ១៣

សិក្សាភាពមានដំណោះស្រាយនៃវិសមីការ ៖

  1. \(3(x - 2) + 2(x + 4) > 5x + 1\)

  2. \(2(2x - 1) - 4x \ge 5\)

  3. \(4(x + 1) - 2(2x - 3) \ge 10\)

  4. \(\dfrac{x - 1}{2} - \dfrac{x + 2}{3} < \dfrac{x - 7}{6}\)

មើលដំណោះស្រាយ

សិក្សាភាពមានដំណោះស្រាយ ៖

  • a. \(5x + 2 > 5x + 1 \implies 2 > 1\) (ពិតចំពោះគ្រប់ \(x \in \mathbb{R}\))

  • b. \(-2 \ge 5\) (មិនពិត \(\implies\) គ្មានដំណោះស្រាយ)

  • c. \(10 \ge 10\) (ពិតចំពោះគ្រប់ \(x \in \mathbb{R}\))

  • d. \(3(x-1) - 2(x+2) < x - 7 \implies x - 7 < x - 7\) (គ្មានដំណោះស្រាយ)

១៤លំហាត់ទី ១៤

រកគ្រប់ចំនួនគត់ធម្មជាតិ \(x\) ដែលផ្ទៀងផ្ទាត់ ៖

  1. \(3x - 5 < 10\)

  2. \(4x + 3 \le 2x + 11\)

មើលដំណោះស្រាយ

ចំនួនគត់ធម្មជាតិ (\(\mathbb{N}\)) ៖

  • a. \(3x < 15 \implies x < 5 \implies x \in \{0, 1, 2, 3, 4\}\)

  • b. \(2x \le 8 \implies x \le 4 \implies x \in \{0, 1, 2, 3, 4\}\)

១៥លំហាត់ទី ១៥

រកគ្រប់ចំនួនគត់វិជ្ជមាន \(x\) ដែលផ្ទៀងផ្ទាត់ ៖

  1. \(\dfrac{2x - 1}{3} \le 3\)

  2. \(x - \dfrac{x-1}{2} < 3\)

មើលដំណោះស្រាយ

ចំនួនគត់វិជ្ជមាន (\(\mathbb{N}^*\)) ៖

  • a. \(2x - 1 \le 9 \implies 2x \le 10 \implies x \le 5 \implies x \in \{1, 2, 3, 4, 5\}\)

  • b. \(2x - x + 1 < 6 \implies x < 5 \implies x \in \{1, 2, 3, 4\}\)

១៦លំហាត់ទី ១៦

រកចំនួនគត់ធំបំផុតនៃ \(x\) ដែលផ្ទៀងផ្ទាត់ ៖

  1. \(5 - 2x > -3\)

  2. \(\dfrac{3x - 4}{2} \le x + 1\)

មើលដំណោះស្រាយ

ចំនួនគត់ធំបំផុត ៖

  • a. \(-2x > -8 \implies x < 4 \implies x_{max} = 3\)

  • b. \(3x - 4 \le 2x + 2 \implies x \le 6 \implies x_{max} = 6\)

១៧លំហាត់ទី ១៧

រកចំនួនគត់តូចបំផុតនៃ \(x\) ដែលផ្ទៀងផ្ទាត់ ៖

  1. \(4x - 7 \ge 8\)

  2. \(\dfrac{2x + 5}{3} > 3\)

មើលដំណោះស្រាយ

ចំនួនគត់តូចបំផុត ៖

  • a. \(4x \ge 15 \implies x \ge 3.75 \implies x_{min} = 4\)

  • b. \(2x + 5 > 9 \implies 2x > 4 \implies x > 2 \implies x_{min} = 3\)

១៨លំហាត់ទី ១៨

ដោះស្រាយវិសមភាពឌុប ៖

  1. \(-3 < x + 4 \le 9\)

  2. \(5 \le 2x - 1 < 13\)

  3. \(-2 \le 3x + 4 \le 16\)

  4. \(1 < 4 - x \le 6\)

មើលដំណោះស្រាយ

វិសមភាពឌុប ៖

  • a. \(-7 < x \le 5\)

  • b. \(6 \le 2x < 14 \implies 3 \le x < 7\)

  • c. \(-6 \le 3x \le 12 \implies -2 \le x \le 4\)

  • d. \(-3 < -x \le 2 \implies -2 \le x < 3\)

១៩លំហាត់ទី ១៩

ដោះស្រាយវិសមភាពឌុប ៖

  1. \(-1 < \dfrac{2x - 3}{5} \le 3\)

  2. \(2 \le \dfrac{3x + 1}{4} < 7\)

មើលដំណោះស្រាយ

វិសមភាពឌុប ៖

  • a. \(-5 < 2x - 3 \le 15 \implies -2 < 2x \le 18 \implies -1 < x \le 9\)

  • b. \(8 \le 3x + 1 < 28 \implies 7 \le 3x < 27 \implies \dfrac{7}{3} \le x < 9\)

២០លំហាត់ទី ២០

ដោះស្រាយប្រព័ន្ធវិសមីការ ៖

  1. \(\begin{cases} 2x - 5 > 1 \\ 3x + 2 \le 17 \end{cases}\)

  2. \(\begin{cases} 4x + 3 \ge -5 \\ 2x - 7 < 1 \end{cases}\)

មើលដំណោះស្រាយ

ប្រព័ន្ធវិសមីការ ៖

  • a. \(x > 3\) និង \(x \le 5 \implies (3, 5]\)

  • b. \(x \ge -2\) និង \(x < 4 \implies [-2, 4)\)

២១លំហាត់ទី ២១

ដោះស្រាយប្រព័ន្ធវិសមីការ ៖

  1. \(\begin{cases} 3(x - 1) < 2x + 5 \\ 4x - 1 \ge 2(x + 3) \end{cases}\)

  2. \(\begin{cases} \dfrac{x}{2} + 1 > 3 \\ \dfrac{x - 1}{3} \le 2 \end{cases}\)

មើលដំណោះស្រាយ

ប្រព័ន្ធវិសមីការ ៖

  • a. \(x < 8\) និង \(2x \ge 7 \implies x \ge 3.5 \implies [3.5, 8)\)

  • b. \(x > 4\) និង \(x \le 7 \implies (4, 7]\)

២២លំហាត់ទី ២២

ដោះស្រាយប្រព័ន្ធវិសមីការ ៖

  1. \(\begin{cases} 2x - 1 > 5 \\ 3 - x \ge 4 \end{cases}\)

  2. \(\begin{cases} 5x - 2 \le 3x + 4 \\ 2x + 7 > x + 1 \end{cases}\)

មើលដំណោះស្រាយ

ប្រព័ន្ធវិសមីការ ៖

  • a. \(x > 3\) និង \(x \le -1 \implies\) គ្មានដំណោះស្រាយ

  • b. \(2x \le 6 \implies x \le 3\) និង \(x > -6 \implies (-6, 3]\)

២៣លំហាត់ទី ២៣

ដោះស្រាយវិសមីការផលិតផល និងផលចែកសញ្ញា ៖

  1. \((x - 3)(x + 2) > 0\)

  2. \((2x - 5)(x + 1) \le 0\)

ផលិតផលសញ្ញា ៖

  • a. ឫសគឺ \(-2\) និង \(3\)។ វិជ្ជមាននៅខាងក្រៅឫស ៖ \(x < -2\) ឬ \(x > 3\)

  • b. ឫសគឺ \(-1\) និង \(\dfrac{5}{2}\)។ អវិជ្ជមាននៅចន្លោះឫស ៖ \(-1 \le x \le \dfrac{5}{2}\)

២៤លំហាត់ទី ២៤

ដោះស្រាយវិសមីការសនិទាន ៖

  1. \(\dfrac{x - 4}{x + 1} > 0\)

  2. \(\dfrac{2x + 3}{x - 2} \le 0\)

មើលដំណោះស្រាយ

វិសមីការសនិទាន ៖

  • a. ផលចែកវិជ្ជមានកាលណាភាគយក និងភាគបែងមានសញ្ញាដូចគ្នា ៖ \(x < -1\) ឬ \(x > 4\)

  • b. សញ្ញាផ្ទុយ ៖ \(-\dfrac{3}{2} \le x < 2\) (\(x \ne 2\))

២៥លំហាត់ទី ២៥

ដោះស្រាយវិសមីការតម្លៃដាច់ខាត ៖

  1. \(|x| < 6\)

  2. \(|x| \ge 5\)

  3. \(|x - 3| \le 4\)

  4. \(|2x + 1| > 7\)

មើលដំណោះស្រាយ

តម្លៃដាច់ខាត ៖

  • a. \(-6 < x < 6\)

  • b. \(x \le -5\) ឬ \(x \ge 5\)

  • c. \(-4 \le x - 3 \le 4 \implies -1 \le x \le 7\)

  • d. \(2x + 1 > 7 \implies x > 3\) ឬ \(2x + 1 < -7 \implies x < -4\)

២៦លំហាត់ទី ២៦

ដោះស្រាយវិសមីការ ៖

  1. \(|3x - 2| < 8\)

  2. \(|4 - x| \ge 3\)

មើលដំណោះស្រាយ

តម្លៃដាច់ខាត ៖

  • a. \(-8 < 3x - 2 < 8 \implies -6 < 3x < 10 \implies -2 < x < \dfrac{10}{3}\)

  • b. \(|x - 4| \ge 3 \implies x - 4 \ge 3 \implies x \ge 7\) ឬ \(x - 4 \le -3 \implies x \le 1\)

២៧លំហាត់ទី ២៧

រកតម្លៃ \(m\) ដើម្បីឱ្យវិសមីការ \(mx > 4\) មានដំណោះស្រាយ \(x < 2\)។

មើលដំណោះស្រាយ

ដើម្បីឱ្យប្តូរសញ្ញាពី \(>\) ទៅជា \(<\) ត្រូវតែ \(m < 0\)។
\(x < \dfrac{4}{m} = 2 \implies m = 2\) (មិនយក ព្រោះត្រូវ \(m < 0\))។
ដូចនេះ គ្មានតម្លៃ \(m\) ឡើយ។

២៨លំហាត់ទី ២៨

រកតម្លៃ \(a\) ដើម្បីឱ្យប្រព័ន្ធ \(\begin{cases} x > a \\ x < 3 \end{cases}\) មានដំណោះស្រាយ។

មើលដំណោះស្រាយ

ដើម្បីឱ្យប្រព័ន្ធមានដំណោះស្រាយ ចន្លោះត្រូវជាន់គ្នា ៖ \(a < 3\)។

២៩លំហាត់ទី ២៩

រកតម្លៃ \(k\) ដើម្បីឱ្យគ្រប់ \(x \in [1, 4]\) សុទ្ធតែផ្ទៀងផ្ទាត់ \(2x - k \le 5\)។

មើលដំណោះស្រាយ

\(k \ge 2x - 5\) ចំពោះគ្រប់ \(x \in [1, 4]\)។
តម្លៃធំបំផុតនៃ \(2x - 5\) លើ \([1, 4]\) គឺនៅពេល \(x = 4\) ៖ \(2(4) - 5 = 3\)។
ដូច្នេះត្រូវឱ្យ \(k \ge 3\)។

៣០លំហាត់ទី ៣០

គេឱ្យ \(-1 \le x \le 3\) និង \(2 \le y \le 5\)។ រកដែនកំណត់នៃ ៖

  1. \(x + y\)

  2. \(x - y\)

  3. \(2x - 3y\)

  4. \(xy\)

មើលដំណោះស្រាយ

ដែនកំណត់ ៖

  • a. \(1 \le x + y \le 8\)

  • b. \(-2 \le -y \le -5 \implies -6 \le x - y \le 1\)

  • c. \(-2 \le 2x \le 6\) និង \(-15 \le -3y \le -6 \implies -17 \le 2x - 3y \le 0\)

  • d. \(-5 \le xy \le 15\)

៣១លំហាត់ទី ៣១

ផលបូកនៃពីរចំនួនគត់តគ្នាធំជាង \(55\)។ រកគូនៃចំនួនទាំងពីរដែលតូចជាងគេបំផុត។

មើលដំណោះស្រាយ

\(n + (n+1) > 55 \implies 2n > 54 \implies n > 27\)។
ចំនួនគត់តូចបំផុតគឺ \(n = 28\)។ គូនៃចំនួននោះគឺ \(28\) និង \(29\)។

៣២លំហាត់ទី ៣២

ផលបូកនៃបីចំនួនគត់សេសតៗគ្នាតូចជាង \(75\)។ រកតម្លៃធំបំផុតនៃចំនួនទាំងបីនោះ។

មើលដំណោះស្រាយ

\((2k-1) + (2k+1) + (2k+3) < 75 \implies 6k + 3 < 75 \implies 6k < 72 \implies k < 12\)។
យក \(k = 11\) ៖ ចំនួនទាំងបីគឺ \(21, 23, 25\)។

៣៣លំហាត់ទី ៣៣

ចតុកោណកែងមួយមានបណ្តោយវែងជាងទទឹង \(5\text{ cm}\)។ បើបរិមាត្ររបស់វាយ៉ាងតិច \(50\text{ cm}\) រកប្រវែងទទឹងនៃចតុកោណកែង។

មើលដំណោះស្រាយ

\(2(w + w + 5) \ge 50 \implies 4w + 10 \ge 50 \implies 4w \ge 40 \implies w \ge 10\text{ cm}\)។

៣៤លំហាត់ទី ៣៤

ត្រីកោណមួយមានបាតប្រវែង \(12\text{ cm}\)។ រកកម្ពស់ \(h\) ដើម្បីឱ្យផ្ទៃក្រឡារបស់វាធំជាង \(48\text{ cm}^2\)។

មើលដំណោះស្រាយ

\(S = \dfrac{1}{2}(12)h > 48 \implies 6h > 48 \implies h > 8\text{ cm}\)។

៣៥លំហាត់ទី ៣៥

ត្រីកោណសមបាតមួយមានបរិមាត្រតូចជាង \(40\text{ cm}\) និងបាតប្រវែង \(14\text{ cm}\)។ រកប្រវែងជ្រុងមួត \(x\) នៃត្រីកោណ។

មើលដំណោះស្រាយ

\(2x + 14 < 40 \implies 2x < 26 \implies x < 13\)។
តាមវិសមភាពត្រីកោណ ៖ \(2x > 14 \implies x > 7\)។
ដូច្នេះ \(7 < x < 13\text{ cm}\)។

៣៦លំហាត់ទី ៣៦

សិស្សម្នាក់ប្រឡងបានពិន្ទុ \(68, 76\) និង \(80\) ក្នុងតេស្ត ៣ លើក។ តើតេស្តលើកទី ៤ គាត់ត្រូវទទួលបានពិន្ទុយ៉ាងតិចប៉ុន្មាន ដើម្បីឱ្យមធ្យមភាគតេស្តទាំង ៤ យ៉ាងហោចណាស់ \(80\)?

មើលដំណោះស្រាយ

\(\dfrac{68 + 76 + 80 + x}{4} \ge 80 \implies 224 + x \ge 320 \implies x \ge 96\) ពិន្ទុ។

៣៧លំហាត់ទី ៣៧

ក្នុងថ្នាក់រៀនមួយ សិស្សម្នាក់ៗត្រូវបង់ថ្លៃទស្សនកិច្ច \(25\$\)។ បើថ្លៃជួលឡានសរុបគឺ \(650\$\) តើត្រូវមានសិស្សយ៉ាងហោចណាស់ប៉ុន្មាននាក់ចូលរួម ទើបមិនខាតប្រាក់?

មើលដំណោះស្រាយ

\(25n \ge 650 \implies n \ge 26\) នាក់។

៣៨លំហាត់ទី ៣៨

ពូហេងមានប្រាក់ \(100000\) រៀល ។ គាត់ទិញប្រេងសាំងអស់ \(30000\) រៀល ។ ប្រាក់ដែលនៅសល់គាត់ចង់ទិញកូនត្រីចិញ្ចឹមដែលមួយក្បាលថ្លៃ \(2500\) រៀល ។ តើគាត់អាចទិញកូនត្រីបានច្រើនបំផុតប៉ុន្មានក្បាល?

មើលដំណោះស្រាយ

\(30000 + 2500n \le 100000 \implies 2500n \le 70000 \implies n \le 28\) ក្បាល។

៣៩លំហាត់ទី ៣៩

ហាងមួយផ្តល់ជម្រើសបង់ប្រាក់ថ្លៃសេវាអ៊ីនធឺណិតពីរ ៖

  • គម្រោង A ៖ បង់ថ្លៃសេវាប្រចាំខែ \(15\$\) បូក \(0.05\$\) ក្នុង ១ ម៉ោងប្រើប្រាស់។

  • គម្រោង B ៖ បង់ថេរ \(25\$\) ក្នុងមួយខែប្រើប្រាស់មិនកំណត់ម៉ោង។

តើអតិថិជនត្រូវប្រើប្រាស់យ៉ាងហោចណាស់ប៉ុន្មានម៉ោងក្នុងមួយខែ ទើបគម្រោង B ចំណេញជាងគម្រោង A?

មើលដំណោះស្រាយ

\(15 + 0.05t > 25 \implies 0.05t > 10 \implies t > 200\) ម៉ោង។
ត្រូវប្រើលើសពី ២០០ ម៉ោង។

៤០លំហាត់ទី ៤០

ក្រុមហ៊ុនជួលរថយន្តពីរផ្តល់តម្លៃដូចខាងក្រោម ៖

  • ក្រុមហ៊ុនទីមួយ ៖ គិតថ្លៃដើម \(50\$\) បូក \(0.20\$/\text{km}\)។

  • ក្រុមហ៊ុនទីពីរ ៖ គិតថ្លៃដើម \(30\$\) បូក \(0.30\$/\text{km}\)។

តើអ្នកបើកបរត្រូវធ្វើដំណើរចម្ងាយលើសពីប៉ុន្មានគីឡូម៉ែត្រ ទើបក្រុមហ៊ុនទីមួយមានតម្លៃថោកជាង?

មើលដំណោះស្រាយ

\(50 + 0.20d < 30 + 0.30d \implies 0.10d > 20 \implies d > 200\text{ km}\)។

៤១លំហាត់ទី ៤១

តារាមានប្រាក់ច្រើនជាងសុខ \(15000\) រៀល ។ បើអ្នកទាំងពីរមានប្រាក់សរុបមិនលើសពី \(85000\) រៀល រកចំនួនប្រាក់ច្រើនបំផុតដែលសុខអាចមាន។

មើលដំណោះស្រាយ

តាងសុខ \(x\), តារា \(x + 15000\) ៖
\(2x + 15000 \le 85000 \implies 2x \le 70000 \implies x \le 35000\) រៀល ។

៤២លំហាត់ទី ៤២

អាងហែលទឹកមួយមានបណ្តោយ \(25\text{ m}\) និងទទឹង \(10\text{ m}\)។ បើគេចង់ឱ្យមាឌទឹកក្នុងអាងយ៉ាងហោចណាស់ \(375\text{ m}^3\) តើជម្រៅទឹកត្រូវមានយ៉ាងតិចប៉ុន្មានម៉ែត្រ?

មើលដំណោះស្រាយ

\(V = 25 \times 10 \times h \ge 375 \implies 250h \ge 375 \implies h \ge 1.5\text{ m}\)។

៤៣លំហាត់ទី ៤៣

រោងពុម្ពមួយចំណាយដើមទុនថេរ \(500\$\) ក្នុងការរៀបចំពុម្ពសៀវភៅ និងថ្លៃបោះពុម្ព \(2\$\) ក្នុងមួយក្បាល។ បើសៀវភៅលក់ចេញក្នុងតម្លៃ \(4.5\$\) ក្នុងមួយក្បាល តើត្រូវលក់សៀវភៅយ៉ាងហោចណាស់ប៉ុន្មានក្បាលទើបទទួលបានប្រាក់ចំណេញ?

មើលដំណោះស្រាយ

ចំណេញកាលណា ចំណូល \(>\) ចំណាយ ៖
\(4.5n > 500 + 2n \implies 2.5n > 500 \implies n > 200\)។
ត្រូវលក់យ៉ាងហោចណាស់ \(201\) ក្បាល។

៤៤លំហាត់ទី ៤៤

ជាងម្នាក់ត្រូវបានគេជួលឱ្យជួសជុលផ្ទះដោយផ្តល់ប្រាក់ឈ្នួល ៖ ប្រាក់ប្រចាំថ្ងៃ \(20\$\) បូក \(5\$\) ក្នុងមួយម៉ោងធ្វើការបន្ថែម។ បើគាត់ចង់ទទួលបានប្រាក់ឈ្នួលក្នុងមួយថ្ងៃមិនតិចជាង \(55\$\) តើគាត់ត្រូវធ្វើការបន្ថែមយ៉ាងហោចណាស់ប៉ុន្មានម៉ោង?

មើលដំណោះស្រាយ

\(20 + 5h \ge 55 \implies 5h \ge 35 \implies h \ge 7\) ម៉ោងបន្ថែម។

៤៥លំហាត់ទី ៤៥

ឡានដឹកទំនិញមួយមានទម្ងន់ទទេ \(2.5\) តោន ។ ស្ពានមួយអនុញ្ញាតឱ្យយានយន្តឆ្លងកាត់បានតែទម្ងន់សរុបមិនលើសពី \(8\) តោន ។ បើឡាននោះត្រូវដឹកបាវស្រូវដែលមួយបាវទម្ងន់ \(50\text{ kg}\) តើអាចផ្ទុកបាវស្រូវបានច្រើនបំផុតប៉ុន្មានបាវ?

មើលដំណោះស្រាយ

\(2500 + 50n \le 8000 \implies 50n \le 5500 \implies n \le 110\) បាវ។

៤៦លំហាត់ទី ៤៦

គេមានទឹកអាស៊ីតកំហាប់ \(30\%\) ចំនួន \(12\text{ L}\)។ តើត្រូវបន្ថែមទឹកសុទ្ធយ៉ាងតិចប៉ុន្មានលីត្រ ដើម្បីឱ្យកំហាប់ទឹកអាស៊ីតមិនលើសពី \(20\%\)?

មើលដំណោះស្រាយ

\(\dfrac{0.30 \times 12}{12 + x} \le 0.20 \implies 3.6 \le 2.4 + 0.2x \implies 0.2x \ge 1.2 \implies x \ge 6\text{ L}\)។

៤៧លំហាត់ទី ៤៧

គេចង់លាយកាហ្វេប្រភេទ A (តម្លៃ \(8\$/\text{kg}\)) និងកាហ្វេប្រភេទ B (តម្លៃ \(12\$/\text{kg}\)) ដើម្បីទទួលបានកាហ្វេល្បាយ \(20\text{ kg}\) ដែលមានតម្លៃមិនលើសពី \(10\$/\text{kg}\)។ តើត្រូវប្រើកាហ្វេប្រភេទ A យ៉ាងតិចប៉ុន្មានគីឡូក្រាម?

មើលដំណោះស្រាយ

តាងកាហ្វេ A មាន \(x\text{ kg}\), កាហ្វេ B មាន \(20-x\text{ kg}\) ៖
\(8x + 12(20-x) \le 10(20) \implies -4x + 240 \le 200 \implies 4x \ge 40 \implies x \ge 10\text{ kg}\)។

៤៨លំហាត់ទី ៤៨

រកគ្រប់ចំនួនគត់វិជ្ជមាន \(n\) ដែលផ្ទៀងផ្ទាត់ ៖ \(\dfrac{1}{3} < \dfrac{n}{18} < \dfrac{5}{6}\)។

មើលដំណោះស្រាយ

គុណនឹង \(18\) ៖ \(6 < n < 15 \implies n \in \{7, 8, 9, 10, 11, 12, 13, 14\}\)។

៤៩លំហាត់ទី ៤៩

ស្រាយបញ្ជាក់ថា ចំពោះគ្រប់ចំនួនពិតវិជ្ជមាន \(a\) និង \(b\) គេតែងតែបាន ៖

\[\frac{a+b}{2} \ge \sqrt{ab} \quad{} (\text{វិសមភាព AM-GM})\]

មើលដំណោះស្រាយ

\((\sqrt{a} - \sqrt{b})^2 \ge 0 \implies a - 2\sqrt{ab} + b \ge 0 \implies a + b \ge 2\sqrt{ab} \implies \dfrac{a+b}{2} \ge \sqrt{ab}\) (ពិត)។

៥០លំហាត់ទី ៥០

ស្រាយបញ្ជាក់ថា ចំពោះគ្រប់ចំនួនពិត \(x, y\) គេតែងតែបាន ៖

\[x^2 + y^2 \ge 2xy\]

មើលដំណោះស្រាយ

\((x - y)^2 \ge 0\) ចំពោះគ្រប់ \(x, y \in \mathbb{R}\) ៖
\(x^2 - 2xy + y^2 \ge 0 \implies x^2 + y^2 \ge 2xy\) (ពិត)។

សំណួរពហុជ្រើសរើស

ជ្រើសរើសចម្លើយត្រឹមត្រូវតែមួយ រួចចុច «ពិនិត្យ»។ ចម្លើយរបស់អ្នកត្រូវបានរក្សាទុកក្នុងកុំព្យូទ័រនេះ។
