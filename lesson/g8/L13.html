  • អរិយធម៌បុរាណ ៖ នៅបាប៊ីឡូន និងអេហ្ស៊ីបបុរាណ ការវាស់វែង និងបែងចែកដីកសិកម្មតាមដងទន្លេនីល និងទន្លេអឺប្រាត តម្រូវឱ្យមានក្បួនគណនាផ្ទៃ និងលក្ខណៈចតុកោណកែង ចតុកោណព្នាយ និងចតុកោណស្មើ។

ប្រលេឡូក្រាម (Parallelogram)

និយមន័យ និងលក្ខណៈ

ប្រលេឡូក្រាម

ប្រលេឡូក្រាម គឺជាចតុកោណដែលមានជ្រុងឈមស្របគ្នាពីរៗ ៖

\[AB \parallel CD \quad{} \text{និង} \quad{} AD \parallel BC\]

រូបភាពនេះកំពុងរៀបចំ

លក្ខណៈនៃប្រលេឡូក្រាម

ក្នុងប្រលេឡូក្រាមមួយ ៖

  1. ជ្រុងឈមប៉ុនគ្នាពីរៗ ៖ \(AB = CD\) និង \(AD = BC\)

  2. មុំឈមប៉ុនគ្នាពីរៗ ៖ \(\angle A = \angle C\) និង \(\angle B = \angle D\)

  3. មុំតគ្នាជាមុំបន្ថែមគ្នា ៖ \(\angle A + \angle B = 180^\circ\), \(\angle B + \angle C = 180^\circ\), \(\dots\)

  4. អង្កត់ទ្រូងទាំងពីរប្រសព្វគ្នាកាត់តាមចំណុចកណ្តាលរៀងគ្នា \(O\) (ហៅថា ផ្ចិតឆ្លុះ)

  5. អង្កត់ទ្រូងនីមួយៗចែកប្រលេឡូក្រាមជាពីរត្រីកោណប៉ុនគ្នា

លក្ខខណ្ឌសម្គាល់ប្រលេឡូក្រាម

សញ្ញាណសម្គាល់ប្រលេឡូក្រាម

ចតុកោណប៉ោងមួយជាប្រលេឡូក្រាម កាលណាវាផ្ទៀងផ្ទាត់លក្ខខណ្ឌណាមួយខាងក្រោម ៖

  1. មានជ្រុងឈមស្របគ្នាពីរៗ

  2. មានជ្រុងឈមប៉ុនគ្នាពីរៗ

  3. មានជ្រុងឈមមួយគូស្របគ្នាផង និងប៉ុនគ្នាផង

  4. មានមុំឈមប៉ុនគ្នាពីរៗ

  5. មានអង្កត់ទ្រូងកាត់គ្នាត្រង់ចំណុចកណ្តាលរៀងគ្នា

ដំណោះស្រាយ

ដោយសារ \(\angle A\) និង \(\angle B\) ជាមុំតគ្នានៃប្រលេឡូក្រាម នាំឱ្យវាជាមុំបន្ថែមគ្នា ៖

\[\angle A + \angle B = 180^\circ \iff (2x + 10^\circ) + (3x - 30^\circ) = 180^\circ\]
\[5x - 20^\circ = 180^\circ \iff 5x = 200^\circ \iff x = 40^\circ\]
ដូចនេះ ៖

  • \(\angle B = 3(40^\circ) - 30^\circ = 90^\circ\)

  • \(\angle C = \angle A = 90^\circ\) និង \(\angle D = \angle B = 90^\circ\)

  2. អង្កត់ទ្រូងទាំងពីរកែងគ្នាត្រង់ចំណុចកណ្តាល ៖ \(AC \bot BD\)

  3. អង្កត់ទ្រូងទាំងពីរជាកន្លះបន្ទាត់ពុះនៃមុំទាំងបួន

ចតុកោណព្នាយ \(ABCD\) មានបាត \(AB = 6\text{ cm}\) និងបាតធំ \(CD = 14\text{ cm}\)។ រកប្រវែងបាតមធ្យម \(MN\) និងប្រវែងកំណាត់កាត់ដោយអង្កត់ទ្រូងទាំងពីរ។

ដំណោះស្រាយ

  • ប្រវែងបាតមធ្យម \(MN\) ៖

    \[MN = \frac{AB + CD}{2} = \frac{6 + 14}{2} = \frac{20}{2} = 10\text{ cm}\]

  • តាង \(P, Q\) ជាចំណុចប្រសព្វនៃ \(MN\) ជាមួយ \(AC\) និង \(BD\)។ ក្នុង \(\Delta ABC\) ៖ \(MP = \frac{1}{2}AB = \frac{6}{2} = 3\text{ cm}\)។ ក្នុង \(\Delta BCD\) ៖ \(MQ = \frac{1}{2}CD = \frac{14}{2} = 7\text{ cm}\)។ កំណាត់នៅចន្លោះអង្កត់ទ្រូង ៖ \(PQ = MQ - MP = 7 - 3 = 4\text{ cm}\) (ស្មើនឹង \(\frac{CD - AB}{2}\)!)។

  1. ជ្រុងឈមនឹងជ្រុង \(AB\) គឺ \(\dots\) នាំឱ្យ \(AB = \dots\)

  2. ជ្រុងឈមនឹងជ្រុង \(AD\) គឺ \(\dots\) នាំឱ្យ \(AD = \dots\)

២លំហាត់ទី ២

៣លំហាត់ទី ៣

គេមានប្រលេឡូក្រាម \(MNPQ\) មួយដែល \(\angle M = 110^\circ\), \(MQ = 5\text{ cm}\) និង \(MN = 8\text{ cm}\)។ គណនា ៖

មើលដំណោះស្រាយ

\(MNPQ\) ជាប្រលេឡូក្រាម ៖

  • a. \(\angle P = \angle M = 110^\circ\)។ \(\angle Q = 180^\circ - 110^\circ = 70^\circ\)។

  • b. \(NP = MQ = 5\text{ cm}\) និង \(PQ = MN = 8\text{ cm}\)។

៤លំហាត់ទី ៤

ក្នុងប្រលេឡូក្រាម \(RSTV\) មាន \(\angle R = 67^\circ\)។

  1. គណនារង្វាស់មុំ \(\angle S, \angle T, \angle V\)។

  2. តើអង្កត់ទ្រូង \(RT\) និង \(SV\) មួយណាមានប្រវែងវែងជាង? ព្រោះអ្វី?

មើលដំណោះស្រាយ

  • a. \(\angle T = \angle R = 67^\circ\)។ \(\angle S = \angle V = 180^\circ - 67^\circ = 113^\circ\)។

  • b. អង្កត់ទ្រូង \(RT\) ឈមនឹងមុំទាល \(\angle S = 113^\circ\) នាំឱ្យ \(RT > SV\) (\(RT\) វែងជាងគេ)។

៥លំហាត់ទី ៥

ប្រលេឡូក្រាម \(ABCD\) មានអង្កត់ទ្រូង \(AC\) និង \(BD\) ដែល \(AC > BD\)។ ចូរកំណត់ថាតើមុំណាខ្លះជាមុំទាល និងមុំណាខ្លះជាមុំស្រួច?

មើលដំណោះស្រាយ

ក្នុងប្រលេឡូក្រាម អង្កត់ទ្រូងវែងឈមនឹងមុំទាល ហើយអង្កត់ទ្រូងខ្លីឈមនឹងមុំស្រួច។ ដោយសារ \(AC > BD\) នាំឱ្យមុំ \(\angle B\) និង \(\angle D\) ជាមុំទាល ហើយមុំ \(\angle A\) និង \(\angle C\) ជាមុំស្រួច។

៦លំហាត់ទី ៦

ប្រលេឡូក្រាម \(MNPQ\) មាន \(\angle M = 2(x + 10^\circ)\) និង \(\angle Q = 3x - 10^\circ\) (ជាមុំតគ្នា)។

  1. គណនាតម្លៃ \(x\)។

  2. គណនារង្វាស់មុំទាំងអស់នៃប្រលេឡូក្រាម។

មើលដំណោះស្រាយ

  • a. \(\angle M + \angle Q = 180^\circ \iff 2x + 20^\circ + 3x - 10^\circ = 180^\circ \iff 5x = 170^\circ \implies x = 34^\circ\)។

  • b. \(\angle M = 2(34^\circ + 10^\circ) = 88^\circ \implies \angle P = 88^\circ\)។ \(\angle Q = 3(34^\circ) - 10^\circ = 92^\circ \implies \angle N = 92^\circ\)។

៧លំហាត់ទី ៧

រកប្រវែងជ្រុងនៃប្រលេឡូក្រាម \(ABCD\) ដែលមាន \(AB = 3x + 2\), \(BC = 4x + 1\) និង \(CD = 5x - 2\) (គិតជា cm)។

មើលដំណោះស្រាយ

ជ្រុងឈមស្មើគ្នា ៖ \(AB = CD \iff 3x + 2 = 5x - 2 \implies 2x = 4 \implies x = 2\)។

  • \(AB = CD = 3(2) + 2 = 8\text{ cm}\)

  • \(BC = AD = 4(2) + 1 = 9\text{ cm}\)

៨លំហាត់ទី ៨

រករង្វាស់មុំនៃប្រលេឡូក្រាម \(ABCD\) ដែលមាន \(\angle A = 2x + 3^\circ\) និង \(\angle C = 3x - 27^\circ\)។

មើលដំណោះស្រាយ

មុំឈមស្មើគ្នា ៖ \(\angle A = \angle C \iff 2x + 3^\circ = 3x - 27^\circ \implies x = 30^\circ\)។ \(\angle A = \angle C = 2(30^\circ) + 3^\circ = 63^\circ\)។ \(\angle B = \angle D = 180^\circ - 63^\circ = 117^\circ\)។

៩លំហាត់ទី ៩

រករង្វាស់មុំនៃប្រលេឡូក្រាម \(ABCD\) ដែលមាន \(\angle A = \frac{2x}{5}\) និង \(\angle B = \frac{x}{2}\)។

មើលដំណោះស្រាយ

មុំតគ្នាជាមុំបន្ថែមគ្នា ៖ \(\angle A + \angle B = 180^\circ\) ៖

\[\frac{2x}{5} + \frac{x}{2} = 180^\circ \iff \frac{9x}{10} = 180^\circ \implies x = 200^\circ\]
\(\angle A = \angle C = \frac{2(200^\circ)}{5} = 80^\circ\)។ \(\angle B = \angle D = \frac{200^\circ}{2} = 100^\circ\)។

១០លំហាត់ទី ១០

រករង្វាស់មុំនៃប្រលេឡូក្រាម \(MNPQ\) ដែលមាន \(\angle M = \frac{2x}{3}\) និង \(\angle P = \frac{x}{2} + 20^\circ\)។

មើលដំណោះស្រាយ

\(\angle M = \angle P \iff \frac{2x}{3} = \frac{x}{2} + 20^\circ \iff \frac{x}{6} = 20^\circ \implies x = 120^\circ\)។ \(\angle M = \angle P = \frac{2(120^\circ)}{3} = 80^\circ\)។ \(\angle N = \angle Q = 180^\circ - 80^\circ = 100^\circ\)។

១១លំហាត់ទី ១១

រករង្វាស់មុំនៃប្រលេឡូក្រាម \(ABCD\) ដែលមាន \(\angle A = 2x + y\), \(\angle B = 2x + 3y - 20^\circ\) និង \(\angle C = 3x - y + 16^\circ\)។

មើលដំណោះស្រាយ

\(\angle A = \angle C \iff 2x + y = 3x - y + 16^\circ \implies x - 2y = -16^\circ\)។ \(\angle A + \angle B = 180^\circ \iff 4x + 4y - 20^\circ = 180^\circ \implies x + y = 50^\circ\)។ ដោះស្រាយប្រព័ន្ធ ៖ \(3y = 66^\circ \implies y = 22^\circ\) និង \(x = 28^\circ\)។ \(\angle A = \angle C = 2(28^\circ) + 22^\circ = 78^\circ\)។ \(\angle B = \angle D = 180^\circ - 78^\circ = 102^\circ\)។

១២លំហាត់ទី ១២

បើមុំមួយនៃប្រលេឡូក្រាមមានរង្វាស់ស្មើនឹងពីរដងនៃមុំមួយទៀតដែលជាប់នឹងវា។ ចូរគណនារង្វាស់មុំទាំងបួននៃប្រលេឡូក្រាម។

មើលដំណោះស្រាយ

តាងមុំមួយជា \(x\) មុំជាប់គ្នានោះជា \(2x\) ៖

\[x + 2x = 180^\circ \iff 3x = 180^\circ \implies x = 60^\circ\]
មុំទាំងបួនគឺ \(60^\circ, 120^\circ, 60^\circ, 120^\circ\)។

១៣លំហាត់ទី ១៣

បើមុំមួយនៃប្រលេឡូក្រាមមានរង្វាស់ស្មើនឹង \(2x + 20^\circ\) ហើយមុំតគ្នាមួយទៀតមានរង្វាស់ \(x - 50^\circ\)។ គណនាតម្លៃ \(x\)។

មើលដំណោះស្រាយ

មុំតគ្នាជាមុំបន្ថែមគ្នា ៖

\[(2x + 20^\circ) + (x - 50^\circ) = 180^\circ \iff 3x - 30^\circ = 180^\circ\]
\[3x = 210^\circ \implies x = 70^\circ\]

១៤លំហាត់ទី ១៤

ក្នុងប្រលេឡូក្រាម \(ABCD\) មាន \(AP\) និង \(BP\) ជាកន្លះបន្ទាត់ពុះមុំ \(\angle A\) និង \(\angle B\) កាត់គ្នាត្រង់ \(P\)។ បង្ហាញថា \(\angle APB = 90^\circ\)។

មើលដំណោះស្រាយ

ក្នុង \(\Delta APB\) ៖ \(\angle PAB = \frac{1}{2}\angle A\) និង \(\angle PBA = \frac{1}{2}\angle B\)។

\[\angle PAB + \angle PBA = \frac{\angle A + \angle B}{2} = \frac{180^\circ}{2} = 90^\circ\]
\(\implies \angle APB = 180^\circ - 90^\circ = 90^\circ\)។

១៥លំហាត់ទី ១៥

គេឱ្យប្រលេឡូក្រាម \(ABCD\)។ លើជ្រុង \(AB\) និង \(CD\) គេដៅចំណុច \(E\) និង \(F\) រៀងគ្នាដែល \(AE = CF\)។ បង្ហាញថា \(AECF\) ជាប្រលេឡូក្រាម។

មើលដំណោះស្រាយ

\(ABCD\) ជាប្រលេឡូក្រាម \(\implies AB \parallel CD \implies AE \parallel CF\)។ ម៉្យាងទៀត \(AE = CF\) (សម្មតិកម្ម)។ ចតុកោណ \(AECF\) មានជ្រុងឈមមួយគូស្របគ្នាផង និងស្មើគ្នាផង នាំឱ្យ \(AECF\) ជាប្រលេឡូក្រាម។

១៦លំហាត់ទី ១៦

គេឱ្យប្រលេឡូក្រាម \(ABCD\) មានអង្កត់ទ្រូងកាត់គ្នាត្រង់ \(O\)។ បន្ទាត់មួយគូសកាត់តាម \(O\) កាត់ \(AB\) ត្រង់ \(M\) និងកាត់ \(CD\) ត្រង់ \(N\)។ បង្ហាញថា \(OM = ON\)។

មើលដំណោះស្រាយ

ពិនិត្យ \(\Delta OAM\) និង \(\Delta OCN\) ៖ \(OA = OC\) (\(O\) ជាចំណុចកណ្តាល \(AC\))។ \(\angle OAM = \angle OCN\) (មុំឆ្លាស់ក្នុង ព្រោះ \(AB \parallel CD\))។ \(\angle AOM = \angle CON\) (មុំទល់កំពូល)។ \(\implies \Delta OAM \cong \Delta OCN\) (ម.ជ.ម) \(\implies OM = ON\)។

១៧លំហាត់ទី ១៧

គេឱ្យត្រីកោណ \(ABC\)។ \(M\) ជាចំណុចកណ្តាលនៃ \(BC\)។ លើបន្លាយនៃ \(AM\) គេដៅចំណុច \(D\) ឱ្យបាន \(MD = MA\)។ បង្ហាញថា \(ABDC\) ជាប្រលេឡូក្រាម។

មើលដំណោះស្រាយ

ចតុកោណ \(ABDC\) មានអង្កត់ទ្រូង \(AD\) និង \(BC\) កាត់គ្នាត្រង់ \(M\)។ ដោយ \(M\) ជាចំណុចកណ្តាល \(BC\) និង \(MA = MD\) នាំឱ្យអង្កត់ទ្រូងទាំងពីរកាត់គ្នាត្រង់ចំណុចកណ្តាលរៀងគ្នា។ ដូចនេះ \(ABDC\) ជាប្រលេឡូក្រាម។

១៨លំហាត់ទី ១៨

គេឱ្យចតុកោណកែង \(ABCD\) មាន \(AB = 8\text{ cm}\) និង \(BC = 6\text{ cm}\)។

  1. គណនាប្រវែងអង្កត់ទ្រូង \(AC\) និង \(BD\)។

  2. គណនាចម្ងាយពីចំណុចប្រសព្វ \(O\) នៃអង្កត់ទ្រូងទាំងពីរទៅកាន់កំពូលទាំងបួន។

មើលដំណោះស្រាយ

  • a. តាមពីតាករ ៖ \(AC = BD = \sqrt{8^2 + 6^2} = \sqrt{64 + 36} = 10\text{ cm}\)។

  • b. អង្កត់ទ្រូងចតុកោណកែងកាត់គ្នាត្រង់ចំណុចកណ្តាល ៖ \(OA = OB = OC = OD = \frac{10}{2} = 5\text{ cm}\)។

ចតុកោណកែង \(ABCD\) មានអង្កត់ទ្រូងកាត់គ្នាត្រង់ \(O\)។ ដឹងថា \(\angle AOB = 60^\circ\) និង \(AB = 5\text{ cm}\)។ គណនាប្រវែងអង្កត់ទ្រូង \(AC\)។

មើលដំណោះស្រាយ

ក្នុង \(\Delta ABC\) ៖ \(MN\) ជាបាតមធ្យម \(\implies MN \parallel AC\) និង \(MN = \frac{1}{2}AC\)។ ក្នុង \(\Delta ADC\) ៖ \(QP\) ជាបាតមធ្យម \(\implies QP \parallel AC\) និង \(QP = \frac{1}{2}AC\)។ \(\implies MN \parallel QP\) និង \(MN = QP \implies MNPQ\) ជាប្រលេឡូក្រាម។

៣០លំហាត់ទី ៣០

បង្ហាញថា បើចតុកោណ \(ABCD\) មានអង្កត់ទ្រូងកែងគ្នា (\(AC \bot BD\)) នោះប្រលេឡូក្រាមវ៉ារីញ៉ុង \(MNPQ\) ជាចតុកោណកែង។

៣១លំហាត់ទី ៣១

គេឱ្យចតុកោណព្នាយសមបាត \(ABCD\) (\(AB \parallel CD\)) ដែលមាន \(AC \bot BD\)។ បង្ហាញថា កម្ពស់នៃចតុកោណព្នាយស្មើនឹងប្រវែងបាតមធ្យមរបស់វា។

ក្នុងចតុកោណព្នាយសមបាត អង្កត់ទ្រូងកែងគ្នាបង្កើតបានត្រីកោណកែងសមបាតនៅខាងក្នុង។ កម្ពស់កាត់តាមចំណុចប្រសព្វចែកជាពីរកម្ពស់ស្មើនឹងកន្លះបាតនីមួយៗ ៖ \(h = \frac{AB}{2} + \frac{CD}{2} = \frac{AB + CD}{2}\) (ស្មើនឹងបាតមធ្យម)។

៤០លំហាត់ទី ៤០

គេឱ្យប្រលេឡូក្រាម \(ABCD\)។ បន្ទាត់ពុះនៃមុំក្នុងទាំងបួនប្រសព្វគ្នាបង្កើតបានជាចតុកោណមួយ។ បង្ហាញថា ចតុកោណនោះជាចតុកោណកែង។

មើលដំណោះស្រាយ

មុំតគ្នាបូកគ្នាបាន \(180^\circ \implies\) កន្លះមុំបូកគ្នាបាន \(90^\circ \implies\) មុំនីមួយៗនៃចតុកោណនោះស្មើនឹង \(180^\circ - 90^\circ = 90^\circ\)។ ចតុកោណដែលមានមុំបួនកែងជាចតុកោណកែង។

៤១លំហាត់ទី ៤១

គេឱ្យ \(\Delta ABC\) សមបាតត្រង់ \(A\)។ ចំណុច \(M\) ស្ថិតនៅលើបាត \(BC\)។ តាម \(M\) គូសបន្ទាត់ស្របនឹង \(AC\) កាត់ \(AB\) ត្រង់ \(D\) និងស្របនឹង \(AB\) កាត់ \(AC\) ត្រង់ \(E\)។

  1. បង្ហាញថា \(ADME\) ជាប្រលេឡូក្រាម។

  2. បង្ហាញថា \(\Delta DBM\) ជាត្រីកោណសមបាត។

  3. បង្ហាញថា ផលបូក \(MD + ME = AB\) (មិនប្រែប្រួល)។

មើលដំណោះស្រាយ

  • a. \(MD \parallel AC\) និង \(ME \parallel AB \implies ADME\) ជាប្រលេឡូក្រាម។

  • b. \(\angle B = \angle C = \angle DMB\) (មុំស្រប) \(\implies \Delta DBM\) សមបាតត្រង់ \(D \implies DB = DM\)។

  • c. \(MD + ME = DB + AD = AB\) (ថេរ)។

៤២លំហាត់ទី ៤២

គេឱ្យចតុកោណកែង \(ABCD\) និងចំណុច \(M\) មួយនៅក្នុងប្លង់។ បង្ហាញសមភាពប្រវែង ៖

\[MA^2 + MC^2 = MB^2 + MD^2\]

មើលដំណោះស្រាយ

គូសបន្ទាត់កាត់ \(M\) ស្របនឹងជ្រុងទាំងពីរ។ អនុវត្តពីតាករលើត្រីកោណកែងទាំង ៤ ដែលបង្កើតបាន ផលបូកការេនៃជ្រុងស្មើគ្នា \(\implies MA^2 + MC^2 = MB^2 + MD^2\)។

៤៣លំហាត់ទី ៤៣

គេឱ្យចតុកោណព្នាយ \(ABCD\) (\(AB \parallel CD\))។ \(I\) ជាចំណុចកណ្តាលនៃ \(AD\) និង \(K\) ជាចំណុចកណ្តាលនៃ \(BC\)។ បន្ទាត់ \(IK\) កាត់ \(BD\) ត្រង់ \(E\) និង \(AC\) ត្រង់ \(F\)។ បង្ហាញថា \(IE = FK\)។

មើលដំណោះស្រាយ

\(IE\) ជាបាតមធ្យមនៃ \(\Delta ABD \implies IE = \frac{1}{2}AB\)។ \(FK\) ជាបាតមធ្យមនៃ \(\Delta ABC \implies FK = \frac{1}{2}AB\)។ ដូចនេះ \(IE = FK\)។

៤៤លំហាត់ទី ៤៤

គេឱ្យប្រលេឡូក្រាម \(ABCD\) មានបរិមាត្រ \(48\text{ cm}\)។ ដឹងថា \(AB = \frac{3}{5}BC\)។ គណនាប្រវែងជ្រុងទាំងអស់នៃប្រលេឡូក្រាម។

មើលដំណោះស្រាយ

\(P = 2(AB + BC) = 48 \implies AB + BC = 24\)។ \(\frac{3}{5}BC + BC = 24 \iff \frac{8}{5}BC = 24 \implies BC = 15\text{ cm}\)។ \(AB = CD = 9\text{ cm}\) និង \(BC = AD = 15\text{ cm}\)។

៤៥លំហាត់ទី ៤៥

គេឱ្យចតុកោណស្មើ \(ABCD\) មាន \(\angle A = 120^\circ\) និងបរិមាត្រ \(32\text{ cm}\)។ គណនាប្រវែងអង្កត់ទ្រូងទាំងពីរ។

មើលដំណោះស្រាយ

ជ្រុង \(a = \frac{32}{4} = 8\text{ cm}\)។ \(\angle A = 120^\circ \implies \angle B = 60^\circ \implies \Delta ABC\) សម័ង្ស \(\implies AC = 8\text{ cm}\)។ \(BD = 2(8\frac{\sqrt{3}}{2}) = 8\sqrt{3}\text{ cm}\)។

៤៦លំហាត់ទី ៤៦

គេឱ្យការេ \(ABCD\) មានជ្រុងប្រវែង \(a\)។ លើជ្រុង \(BC\) ដៅចំណុច \(E\) និងលើបន្លាយ \(CD\) ដៅចំណុច \(F\) ឱ្យ \(DF = BE\)។

  1. បង្ហាញថា \(\Delta ABE \cong \Delta ADF\)។

  2. បង្ហាញថា \(\Delta AEF\) ជាត្រីកោណកែងសមបាត។

មើលដំណោះស្រាយ

  • a. \(\Delta ABE \cong \Delta ADF\) (ជ.ម.ជ ៖ \(AB = AD, BE = DF, \angle B = \angle D = 90^\circ\))។

  • b. \(AE = AF\) និង \(\angle EAF = \angle EAD + \angle DAF = \angle EAD + \angle BAE = 90^\circ \implies \Delta AEF\) កែងសមបាត។

៤៧លំហាត់ទី ៤៧

គេឱ្យ \(\Delta ABC\) សម័ង្ស។ ចំណុច \(M\) នៅខាងក្នុងត្រីកោណ។ គូស \(MD \parallel BC\), \(ME \parallel AC\), \(MF \parallel AB\) (\(D \in AB, E \in BC, F \in CA\))។ បង្ហាញថា ផលបូក \(MD + ME + MF\) ស្មើនឹងប្រវែងជ្រុងនៃ \(\Delta ABC\)។

មើលដំណោះស្រាយ

គូសបន្ទាត់ស្របបង្កើតជាប្រលេឡូក្រាម និងត្រីកោណសម័ង្សតូចៗ ផលបូកនៃប្រវែងទាំងបីស្មើនឹងប្រវែងជ្រុងត្រីកោណសម័ង្សធំ \(a\)។

៤៨លំហាត់ទី ៤៨

គេឱ្យប្រលេឡូក្រាម \(ABCD\)។ ពី \(A\) និង \(C\) គូសបន្ទាត់កែងនឹងអង្កត់ទ្រូង \(BD\) ត្រង់ \(H\) និង \(K\) រៀងគ្នា។

  1. បង្ហាញថា \(\Delta AHB \cong \Delta CKD\)។

  2. បង្ហាញថា \(AHCK\) ជាប្រលេឡូក្រាម។

មើលដំណោះស្រាយ

  • a. ត្រីកោណកែង \(\Delta AHB\) និង \(\Delta CKD\) មាន \(AB = CD\) និង \(\angle ABH = \angle CDK\) (ឆ្លាស់ក្នុង) \(\implies \Delta AHB \cong \Delta CKD\) (អ.ម)។

  • b. \(AH = CK\) និង \(AH \parallel CK\) (កែងនឹង \(BD\) ដូចគ្នា) \(\implies AHCK\) ជាប្រលេឡូក្រាម។

៤៩លំហាត់ទី ៤៩

គេឱ្យចតុកោណព្នាយសមបាត \(ABCD\) (\(AB \parallel CD, AB < CD\)) មាន \(AD = BC\)។ កម្ពស់ \(AH\) និង \(BK\) គូសទៅលើបាត \(CD\)។ បង្ហាញថា \(DH = CK = \frac{CD - AB}{2}\)។

មើលដំណោះស្រាយ

\(ABKH\) ជាចតុកោណកែង \(\implies HK = AB\)។ \(\Delta ADH \cong \Delta BCK\) (អ.ជ) \(\implies DH = CK\)។ \(DH + HK + CK = CD \iff 2DH + AB = CD \implies DH = \frac{CD - AB}{2}\)។

៥០លំហាត់ទី ៥០

គេឱ្យចតុកោណប៉ោង \(ABCD\) មួយ។ បង្ហាញថា បរិមាត្រនៃចតុកោណធំជាងផលបូកនៃអង្កត់ទ្រូងទាំងពីរ ប៉ុន្តែតូចជាងពីរដងនៃផលបូកនោះ ៖

\[AC + BD < AB + BC + CD + DA < 2(AC + BD)\]

មើលដំណោះស្រាយ

  • ក្នុង \(\Delta ABC, \Delta BCD, \Delta CDA, \Delta DAB\) តាមវិសមភាពត្រីកោណ ៖ \(AC < AB + BC, BD < BC + CD, \dots\) បូកចូលគ្នាបាន \(AC + BD < P\)។

  • តាង \(O\) ជាប្រសព្វអង្កត់ទ្រូង ៖ \(OA + OB > AB, OB + OC > BC, \dots\) បូកចូលគ្នាបាន \(2(AC + BD) > P \implies P < 2(AC + BD)\)។
