ការបង្កើត ប្លង់កូអរដោនេ (Cartesian Coordinate System) ត្រូវបានចាត់ទុកថាជាបដិវត្តន៍ដ៏អស្ចារ្យបំផុតមួយក្នុងប្រវត្តិសាស្ត្រគណិតវិទ្យា ដែលបានតភ្ជាប់ពីជគណិត និងធរណីមាត្រឱ្យក្លាយជាមុខវិជ្ជាតែមួយ ហៅថា ធរណីមាត្រវិភាគ (Analytic Geometry) ៖

  • រឺណេ ដេកាត (René Descartes, 1596–1650) ៖ ទស្សនវិទូ និងគណិតវិទូជនជាតិបារាំង។ រឿងព្រេងដំណាលថានៅពេលលោកគេងឈឺលើគ្រែ លោកបានសង្កេតឃើញសត្វរុយមួយក្បាលកំពុងវារលើពិដានបន្ទប់ ហើយបានគិតឃើញថា ទីតាំងរបស់រុយនៅគ្រប់ខណៈ អាចកំណត់បានយ៉ាងជាក់លាក់ដោយចម្ងាយកែងពីជញ្ជាំងកាត់កែងគ្នាទាំងពីរ។ នៅឆ្នាំ ១៦៣៧ លោកបានបោះពុម្ពស្នាដៃដ៏ល្បីល្បាញ La Géométrie ដែលបានណែនាំប្រព័ន្ធកូអរដោនេ (Cartesian) ដែលដាក់ឈ្មោះតាមឡាតាំងរបស់លោក (Cartesius)។

  • ព្យែរ ដឺ ហ្វែរម៉ា (Pierre de Fermat, 1601–1665) ៖ បានរកឃើញគំនិតស្រដៀងគ្នានេះដោយឯករាជ្យនៅប្រទេសបារាំងក្នុងពេលដំណាលគ្នា ដោយបានបង្ហាញថាសមីការពីជគណិតនីមួយៗអាចតាងដោយខ្សែកោងធរណីមាត្រក្នុងប្លង់។

  • អនុវត្តក្នុងបច្ចេកវិទ្យាទំនើប ៖ ប្លង់កូអរដោនេគឺជាគ្រឹះនៃប្រព័ន្ធផែនទីសកល (GPS) រូបភាពឌីជីថល (Pixels) ក្រាហ្វិកកុំព្យូទ័រ (Computer Graphics) ហ្គេម 3D និងការវិភាគទិន្នន័យក្នុងយុគសម័យបញ្ញាសិប្បនិម្មិត (AI)។

ប្លង់កូអរដោនេ

ប្លង់កូអរដោនេ (Cartesian Plane) បង្កើតឡើងដោយបន្ទាត់ចំនួនពីរដែលកាត់កែងគ្នាត្រង់ចំណុចគល់ \(O\) ៖

  • អ័ក្សដេក (\(x'Ox\)) ហៅថា អ័ក្សអាប់ស៊ីស (x-axis)។

  • អ័ក្សឈរ (\(y'Oy\)) ហៅថា អ័ក្សអរដោនេ (y-axis)។

  • ចំណុចប្រសព្វ \(O(0, 0)\) ហៅថា គល់តម្រុយ (Origin)។

អ័ក្សទាំងពីរបែងចែកប្លង់ជាបួនតំបន់ ហៅថា កាដ្រង់ (Quadrants) ៖

\(\bullet\) កាដ្រង់ទី I ៖ \(x > 0, y > 0\) (សញ្ញា \((+, +)\)) \(\bullet\) កាដ្រង់ទី II ៖ \(x < 0, y > 0\) (សញ្ញា \((-, +)\))
\(\bullet\) កាដ្រង់ទី III ៖ \(x < 0, y < 0\) (សញ្ញា \((-, -)\)) \(\bullet\) កាដ្រង់ទី IV ៖ \(x > 0, y < 0\) (សញ្ញា \((+, -)\))

រូបភាព ៖ ប្លង់កូអរដោនេកែង (Cartesian Plane) និងកាដ្រង់ទាំងបួន

កូអរដោនេនៃចំណុចមួយ

គូកូអរដោនេ

រាល់ចំណុច \(M\) ក្នុងប្លង់ ត្រូវបានកំណត់ដោយគូមានលំដាប់ \((x, y)\) ៖

\[M(x, y)\]
ដែល \(x\) ជា អាប់ស៊ីស (ចម្ងាយធៀបនឹងអ័ក្សឈរ) និង \(y\) ជា អរដោនេ (ចម្ងាយធៀបនឹងអ័ក្សដេក)។

  • ចំណុចនៅលើអ័ក្សអាប់ស៊ីស មានទម្រង់ \((x, 0)\)។

  • ចំណុចនៅលើអ័ក្សអរដោនេ មានទម្រង់ \((0, y)\)។

ឧទាហរណ៍

ចូរកំណត់កាដ្រង់ ឬអ័ក្សដែលចំណុចខាងក្រោមស្ថិតនៅ ៖ \(A(3, 4)\), \(B(-2, 5)\), \(C(-4, -3)\), \(D(5, -2)\), \(E(0, -3)\), \(F(4, 0)\)។

ដំណោះស្រាយ

  • \(A(3, 4)\) ស្ថិតក្នុងកាដ្រង់ទី I (\(x>0, y>0\))

  • \(B(-2, 5)\) ស្ថិតក្នុងកាដ្រង់ទី II (\(x<0, y>0\))

  • \(C(-4, -3)\) ស្ថិតក្នុងកាដ្រង់ទី III (\(x<0, y<0\))

  • \(D(5, -2)\) ស្ថិតក្នុងកាដ្រង់ទី IV (\(x>0, y<0\))

  • \(E(0, -3)\) ស្ថិតនៅលើអ័ក្សអរដោនេ (\(y'y\))

  • \(F(4, 0)\) ស្ថិតនៅលើអ័ក្សអាប់ស៊ីស (\(x'x\))

ចម្ងាយរវាងពីរចំណុច និងចំណុចកណ្តាល

ចម្ងាយរវាងពីរចំណុច

ចម្ងាយរវាងពីរចំណុច \(A(x_1, y_1)\) និង \(B(x_2, y_2)\) ក្នុងប្លង់កូអរដោនេគឺ ៖

\[AB = d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\]

កូអរដោនេចំណុចកណ្តាល

បើ \(I\) ជាចំណុចកណ្តាលនៃអង្កត់ \([AB]\) ដែល \(A(x_1, y_1)\) និង \(B(x_2, y_2)\) នោះកូអរដោនេនៃ \(I\) គឺ ៖

\[x_I = \frac{x_1 + x_2}{2} \quad{};\quad{} y_I = \frac{y_1 + y_2}{2}\]

ឧទាហរណ៍

គេឱ្យពីរចំណុច \(A(1, 2)\) និង \(B(5, 5)\)។

  1. គណនាប្រវែងអង្កត់ \(AB\)។

  2. រកកូអរដោនេចំណុចកណ្តាល \(I\) នៃ \([AB]\)។

ដំណោះស្រាយ

  1. \(AB = \sqrt{(5 - 1)^2 + (5 - 2)^2} = \sqrt{4^2 + 3^2} = \sqrt{16 + 9} = \sqrt{25} = 5\) ឯកតាប្រវែង។

  2. \(x_I = \dfrac{1 + 5}{2} = 3\) និង \(y_I = \dfrac{2 + 5}{2} = 3.5\)។ ដូចនេះ \(I(3, 3.5)\)។

ក្រាបនៃសមីការបន្ទាត់ \(y = ax + b\)

មេគុណប្រាប់ទិស និងសមីការបន្ទាត់

សមីការបន្ទាត់

បន្ទាត់ត្រង់ \((D)\) មិនស្របនឹងអ័ក្សអរដោនេ មានសមីការទូទៅ ៖

\[y = ax + b\]

  • \(a\) ហៅថា មេគុណប្រាប់ទិស (Slope / Gradient) នៃបន្ទាត់។

  • \(b\) ហៅថា អរដោនេដើម (\(y\)-intercept) (ជាចំណុចប្រសព្វរវាងបន្ទាត់ និងអ័ក្ស \(y\) គឺ \((0, b)\))។

រូបមន្តគណនាមេគុណប្រាប់ទិស

មេគុណប្រាប់ទិសនៃបន្ទាត់កាត់តាមពីរចំណុច \(A(x_1, y_1)\) និង \(B(x_2, y_2)\) (\(x_1 \ne x_2\)) គឺ ៖

\[a = \frac{y_2 - y_1}{x_2 - x_1} = \frac{\Delta y}{\Delta x}\]

  • បើ \(a > 0\) ៖ បន្ទាត់កើនពីឆ្វេងទៅស្តាំ (Slopes upward)។

  • បើ \(a < 0\) ៖ បន្ទាត់ចុះពីឆ្វេងទៅស្តាំ (Slopes downward)។

  • បើ \(a = 0\) ៖ បន្ទាត់ដេកស្របនឹងអ័ក្ស \(x\) មានសមីការ \(y = b\)។

  • បន្ទាត់ឈរកាត់កែងនឹងអ័ក្ស \(x\) គ្មានមេគុណប្រាប់ទិសទេ មានសមីការ \(x = k\)។

វិធីសង់ក្រាបនៃបន្ទាត់ត្រង់

ដើម្បីសង់ក្រាបនៃបន្ទាត់ \(y = ax + b\) គេត្រូវ ៖

  1. រកកូអរដោនេនៃពីរចំណុចផ្សេងគ្នានៅលើបន្ទាត់ (ជាទូទៅជ្រើសរើសចំណុចប្រសព្វនឹងអ័ក្សកូអរដោនេ ៖ ឱ្យ \(x = 0 \implies y = b\) និងឱ្យ \(y = 0 \implies x = -b/a\))។

  2. ដៅចំណុចទាំងពីរក្នុងប្លង់កូអរដោនេ។

  3. គូសបន្ទាត់ត្រង់កាត់តាមចំណុចទាំងពីរនោះ។

ឧទាហរណ៍

សង់ក្រាបនៃបន្ទាត់ \((D): y = 2x - 4\)។

ដំណោះស្រាយ

  • ឱ្យ \(x = 0 \implies y = 2(0) - 4 = -4 \implies A(0, -4)\)

  • ឱ្យ \(y = 0 \implies 2x - 4 = 0 \implies x = 2 \implies B(2, 0)\)

គេឱ្យបន្ទាត់ពីរ \((D_1): y = a_1 x + b_1\) និង \((D_2): y = a_2 x + b_2\) ៖

  1. បន្ទាត់ពីរស្របគ្នា (\((D_1) \parallel (D_2)\)) ៖

    \[(D_1) \parallel (D_2) \iff a_1 = a_2 \quad{}\text{និង}\quad{} b_1 \ne b_2\]

  2. បន្ទាត់ពីរត្រួតស៊ីគ្នា ៖

    \[(D_1) \equiv (D_2) \iff a_1 = a_2 \quad{}\text{និង}\quad{} b_1 = b_2\]

  3. បន្ទាត់ពីរកាត់កែងគ្នា (\((D_1) \perp (D_2)\)) ៖

    \[(D_1) \perp (D_2) \iff a_1 \cdot a_2 = -1\]

  4. បន្ទាត់ពីរកាត់គ្នា ៖ កាលណា \(a_1 \ne a_2\)។ កូអរដោនេនៃចំណុចប្រសព្វគឺជាដំណោះស្រាយនៃប្រព័ន្ធសមីការ ៖

    \[\begin{cases} y = a_1 x + b_1 \\ y = a_2 x + b_2 \end{cases}\]

ឧទាហរណ៍

  1. រកសមីការបន្ទាត់ \((D)\) ដែលស្របនឹងបន្ទាត់ \((L): y = 3x - 1\) ហើយកាត់តាមចំណុច \(A(2, 5)\)។

  2. រកកូអរដោនេចំណុចប្រសព្វរវាងបន្ទាត់ \((D_1): y = 2x + 1\) និង \((D_2): y = -x + 4\)។

ដំណោះស្រាយ

  1. ដោយ \((D) \parallel (L)\) នោះមេគុណប្រាប់ទិស \(a = 3\)។ សមីការមានរាង \(y = 3x + b\)។
    ដោយ \((D)\) កាត់តាម \(A(2, 5)\) នាំឱ្យ \(5 = 3(2) + b \iff 5 = 6 + b \iff b = -1\)។
    ដូចនេះសមីការគឺ \((D): y = 3x - 1\) (បន្ទាត់ត្រួតគ្នា)។

  2. ផ្ទៀងផ្ទាត់សមីការ ៖ \(2x + 1 = -x + 4 \iff 3x = 3 \iff x = 1\)។
    ជំនួស \(x = 1\) ចូល ៖ \(y = 2(1) + 1 = 3\)។ ចំណុចប្រសព្វគឺ \(M(1, 3)\)។

សង់ក្រាប និងរកចំណុចប្រសព្វ

គេឱ្យបន្ទាត់ពីរ \((D_1): y = x + 2\) និង \((D_2): y = -2x + 5\)។

  1. សង់ក្រាបនៃបន្ទាត់ទាំងពីរក្នុងតម្រុយតែមួយ

  2. រកកូអរដោនេចំណុចប្រសព្វនៃបន្ទាត់ទាំងពីរ

  • b. \(a = -2, b = 5\)

១៥លំហាត់ទី ១៥

មើលដំណោះស្រាយ

  • b. បាតប្រវែង \(6\), កម្ពស់ \(4\) នាំឱ្យ \(S = \dfrac{1}{2} \times 6 \times 4 = 12\) ឯកតាផ្ទៃ។

៤១លំហាត់ទី ៤១

សរសេរសមីការបន្ទាត់មេដ្យាទ័រនៃអង្កត់ \([AB]\) ដែល \(A(1, 3)\) និង \(B(5, 7)\)។

មើលដំណោះស្រាយ

ចំណុចកណ្តាល \(I(3, 5)\)។ មេគុណប្រាប់ទិស \(AB\) គឺ \(a_{AB} = \dfrac{7-3}{5-1} = 1\)។
មេគុណមេដ្យាទ័រគឺ \(a = -1\) ៖
\(y - 5 = -(x - 3) \implies y = -x + 8\)។

៤២លំហាត់ទី ៤២

សរសេរសមីការបន្ទាត់មេដ្យានចេញពីកំពូល \(A\) នៃត្រីកោណ \(ABC\) ដែល \(A(2, 5), B(-1, 1), C(3, 3)\)។

មើលដំណោះស្រាយ

ចំណុចកណ្តាលនៃ \([BC]\) គឺ \(M\left(\dfrac{-1+3}{2}, \dfrac{1+3}{2}\right) = (1, 2)\)។
មេដ្យានកាត់តាម \(A(2, 5)\) និង \(M(1, 2)\) ៖
\(a = \dfrac{2-5}{1-2} = 3 \implies y - 2 = 3(x - 1) \implies y = 3x - 1\)។

៤៣លំហាត់ទី ៤៣

រកចម្ងាយពីចំណុច \(A(0, 0)\) ទៅកាន់បន្ទាត់ \(3x + 4y - 12 = 0\) (ប្រើផ្ទៃក្រឡាត្រីកោណកែង)។

មើលដំណោះស្រាយ

បន្ទាត់កាត់អ័ក្សត្រង់ \(P(4, 0)\) និង \(Q(0, 3)\)។ អ៊ីប៉ូតេនុស \(PQ = 5\)។
\(S = \dfrac{1}{2} \times 4 \times 3 = 6\)។ ចម្ងាយ \(d = \dfrac{2S}{PQ} = \dfrac{12}{5} = 2.4\)។

៤៤លំហាត់ទី ៤៤

រថយន្តមួយធ្វើដំណើរដោយល្បឿនថេរ \(60\text{ km/h}\)។

  1. សរសេរសមីការតាងចម្ងាយ \(d\text{ (km)}\) ជាអនុគមន៍នៃពេល \(t\text{ (h)}\)

  2. សង់ក្រាបនៃសមីការនេះចំពោះ \(0 \le t \le 4\)

មើលដំណោះស្រាយ

ចលនារថយន្ត ៖

  • a. \(d = 60t\) (គិតជា \(\text{km}\))

  • b. ក្រាបជាអង្កត់ត្រង់កាត់តាម \((0, 0)\) និង \((4, 240)\)។

៤៥លំហាត់ទី ៤៥

អាងស្តុកទឹកមួយមានទឹកស្រាប់ \(200\text{ L}\)។ គេបើកទឹកបញ្ចូលបន្ថែមក្នុងអត្រា \(50\text{ L/min}\)។

  1. សរសេរសមីការតាងបរិមាណទឹក \(V\text{ (L)}\) ក្នុងអាងក្រោយពេល \(t\text{ (min)}\)

  2. រកបរិមាណទឹកក្រោយពេល ១០ នាទី

  3. តើត្រូវចំណាយពេលប៉ុន្មាននាទីទើបទឹកក្នុងអាងឡើងដល់ \(1000\text{ L}\)?

មើលដំណោះស្រាយ

អាងទឹក ៖

  • a. \(V = 50t + 200\)

  • b. \(t = 10 \implies V = 50(10) + 200 = 700\text{ L}\)

  • c. \(50t + 200 = 1000 \implies 50t = 800 \implies t = 16\) នាទី

៤៦លំហាត់ទី ៤៦

ក្រុមហ៊ុនទូរស័ព្ទមួយគិតថ្លៃសេវា ៖ ថ្លៃឈ្នួលប្រចាំខែ \(2\$\) បូក \(0.05\$\) ក្នុង ១ នាទីនៃការហៅ។

  1. សរសេរសមីការតាងប្រាក់ចំណាយសរុប \(y\$\) ចំពោះការហៅ \(x\) នាទី

  2. បើខែមួយគាត់ហៅអស់ ៨០ នាទី តើគាត់ត្រូវបង់ប្រាក់ប៉ុន្មាន?

  3. បើគាត់បង់ប្រាក់សរុប \(8.5\$\) តើគាត់បានហៅប៉ុន្មាននាទី?

មើលដំណោះស្រាយ

ទូរស័ព្ទ ៖

  • a. \(y = 0.05x + 2\)

  • b. \(x = 80 \implies y = 0.05(80) + 2 = 6\$\)

  • c. \(0.05x + 2 = 8.5 \implies 0.05x = 6.5 \implies x = 130\) នាទី

៤៧លំហាត់ទី ៤៧

រូបមន្តបំប្លែងសីតុណ្ហភាពពីអង្សាសេ (\(C\)) ទៅអង្សាហ្វារិនហៃ (\(F\)) គឺ \(F = \dfrac{9}{5}C + 32\)។

  1. កំណត់មេគុណប្រាប់ទិស និងអរដោនេដើមនៃសមីការនេះ

  2. គណនា \(F\) ពេល \(C = 25^\circ\text{C}\)

  3. រកសីតុណ្ហភាពដែលរង្វាស់ទាំងពីរមានតម្លៃស្មើគ្នា (\(F = C\))

មើលដំណោះស្រាយ

សីតុណ្ហភាព ៖

  • a. មេគុណប្រាប់ទិស \(a = \dfrac{9}{5} = 1.8\), អរដោនេដើម \(b = 32\)

  • b. \(C = 25 \implies F = \dfrac{9}{5}(25) + 32 = 45 + 32 = 77^\circ\text{F}\)

  • c. \(C = \dfrac{9}{5}C + 32 \implies -\dfrac{4}{5}C = 32 \implies C = -40^\circ\)

៤៨លំហាត់ទី ៤៨

រកតម្លៃ \(a\) និង \(b\) ដើម្បីឱ្យបន្ទាត់ \(y = ax + b\) កាត់តាមចំណុច \(A(2, 1)\) និងស្របនឹងបន្ទាត់ \(y = 3x + 4\)។

មើលដំណោះស្រាយ

ស្របនឹង \(y = 3x + 4 \implies a = 3\)។
កាត់តាម \(A(2, 1) \implies 1 = 3(2) + b \implies b = -5\)។
ដូចនេះ \(a = 3, b = -5\)។

៤៩លំហាត់ទី ៤៩

រកតម្លៃ \(m\) ដើម្បីឱ្យបន្ទាត់បីខាងក្រោមប្រសព្វគ្នាត្រង់ចំណុចតែមួយ (Concurrent lines) ៖

\[(D_1): y = 2x + 1 \quad{};\quad{} (D_2): y = -x + 7 \quad{};\quad{} (D_3): y = mx - 1\]

មើលដំណោះស្រាយ

ប្រសព្វនៃ \((D_1)\) និង \((D_2)\) ៖ \(2x + 1 = -x + 7 \implies 3x = 6 \implies x = 2, y = 5\)។
ជំនួស \((2, 5)\) ក្នុង \((D_3)\) ៖ \(5 = m(2) - 1 \implies 2m = 6 \implies m = 3\)។

៥០លំហាត់ទី ៥០

គេឱ្យចំណុច \(A(1, 2)\) និងបន្ទាត់ \((D): y = 2x - 3\)។ រកកូអរដោនេចំណុច \(H\) ជាចំណោលកែងនៃ \(A\) លើបន្ទាត់ \((D)\)។

មើលដំណោះស្រាយ

បន្ទាត់កាត់កែងនឹង \((D)\) កាត់តាម \(A(1, 2)\) មានមេគុណ \(a' = -\dfrac{1}{2}\) ៖
\((D'): y - 2 = -\dfrac{1}{2}(x - 1) \implies y = -\dfrac{1}{2}x + \dfrac{5}{2}\)។
ប្រសព្វរវាង \((D)\) និង \((D')\) ៖
\(2x - 3 = -\dfrac{1}{2}x + \dfrac{5}{2} \implies \dfrac{5}{2}x = \dfrac{11}{2} \implies x = \dfrac{11}{5} = 2.2\)។
\(y = 2(2.2) - 3 = 1.4 = \dfrac{7}{5}\)។
ដូចនេះ \(H\left(\dfrac{11}{5}, \dfrac{7}{5}\right)\)។
