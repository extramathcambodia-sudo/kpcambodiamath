មេរៀនទាំងអស់
ប្រវត្តិនៃទ្រឹស្ដីប្រូបាប និងការគណនាភាពចៃដន្យ

ទ្រឹស្ដី ប្រូបាប (Probability) បានកកើតឡើងចេញពីការចង់យល់ដឹង និងគ្រប់គ្រងភាពមិនច្បាស់លាស់ (Uncertainty) និងល្បែងភ្នាល់ចៃដន្យ ៖

  • ហ្សេរ៉ូឡាម៉ូ កាដាណូ (Girolamo Cardano, 1501–1576) ៖ គណិតវិទូ និងគ្រូពេទ្យជនជាតិអ៊ីតាលី បានសរសេរសៀវភៅ Liber de Ludo Aleae (សៀវភៅស្តីពីល្បែងគ្រាប់ឡុកឡាក់) ដែលជាស្នាដៃដំបូងបង្អស់ក្នុងការគណនាប្រូបាបនៃល្បែងគ្រាប់ឡុកឡាក់តាមរយៈការរាប់ចំនួនករណីអាច។

  • ការឆ្លើយឆ្លងរវាង ប៉ាស្កាល់ និង ហ្វែរម៉ា (1654) ៖ កំណើតពិតប្រាកដនៃទ្រឹស្ដីប្រូបាបទំនើប បានចាប់ផ្តើមនៅពេលដែល Chevalier de Méré (អ្នកលេងល្បែងជនជាតិបារាំង) បានចោទសួរ Blaise Pascal អំពី «បញ្ហាបែងចែកប្រាក់រង្វាន់ (Problem of Points)» នៅពេលល្បែងត្រូវផ្អាកកណ្តាលទី។ Pascal បានសរសេរសំបុត្រពិភាក្សាជាមួយ Pierre de Fermat ហើយអ្នកទាំងពីរបានបង្កើតគ្រឹះនៃទ្រឹស្ដីប្រូបាបគណិតវិទ្យា។

  • គ្រីស្ទៀន ហ៊ុយហ្គេន និង យ៉ាកុប ប៊ែរនូយី ៖ Christiaan Huygens បានបោះពុម្ពសៀវភៅសិក្សាប្រូបាបដំបូងបង្អស់នៅឆ្នាំ ១៦៥៧។ បន្ទាប់មក Jakob Bernoulli បានបង្កើត ច្បាប់នៃចំនួនធំ (Law of Large Numbers) នៅក្នុងសៀវភៅ Ars Conjectandi (១៧១៣)។

  • អង់ដ្រេ កូលម៉ូហ្គោរ៉ូវ (Andrey Kolmogorov, 1903–1987) ៖ គណិតវិទូជនជាតិរុស្ស៊ី បានបង្កើតប្រព័ន្ធស្វ័យស័ត្យ (Axiomatic foundation) នៃប្រូបាបនៅឆ្នាំ ១៩៣៣ ដែលធ្វើឱ្យប្រូបាបក្លាយជាផ្នែកមួយដ៏រឹងមាំ និងមានកិត្យានុភាពនៃគណិតវិទ្យាទំនើប។

ការពិសោធន៍ចៃដន្យ និងលំហសំណាក

  • ការពិសោធន៍ចៃដន្យ (Random Experiment) ៖ គឺជាសកម្មភាព ឬការពិសោធន៍ទាំងឡាយណាដែលគេដឹងមុននូវរាល់លទ្ធផលដែលអាចកើតមានទាំងអស់ ប៉ុន្តែមិនអាចដឹងមុនច្បាស់ថាលទ្ធផលណាមួយនឹងកើតឡើងពិតប្រាកដនោះឡើយ (ឧទាហរណ៍ ៖ ការបោះកាក់, ការបោះគ្រាប់ឡុកឡាក់, ការចាប់សន្លឹកឆ្នោត...)។

  • លំហសំណាក (Sample Space, តាងដោយ \(S\)) ៖ គឺជាសំណុំនៃរាល់លទ្ធផលដែលអាចកើតមានទាំងអស់នៃការពិសោធន៍ចៃដន្យមួយ។

  • ចំនួនករណីអាច (Total Outcomes) ៖ តាងដោយ \(n(S)\) គឺជាចំនួនធាតុទាំងអស់ដែលមាននៅក្នុងលំហសំណាក \(S\)។

ឧទាហរណ៍

ចូរកំណត់លំហសំណាក \(S\) និងចំនួនករណីអាច \(n(S)\) ចំពោះការពិសោធន៍ខាងក្រោម ៖

  1. បោះកាក់មួយម្តង

  2. បោះគ្រាប់ឡុកឡាក់មួយម្តង

  3. បោះកាក់មួយចំនួន ២ ដង

ដំណោះស្រាយ

  1. តាង \(H\) ជាខាងរូប (Head) និង \(T\) ជាខាងលេខ (Tail) ៖ \(S = \{H, T\} \implies n(S) = 2\)។

  2. គ្រាប់ឡុកឡាក់មាន ៦ មុខ ៖ \(S = \{1, 2, 3, 4, 5, 6\} \implies n(S) = 6\)។

  3. បោះកាក់ ២ ដង ៖ \(S = \{HH, HT, TH, TT\} \implies n(S) = 4\)។

ព្រឹត្តិការណ៍ (Events)

ព្រឹត្តិការណ៍

ព្រឹត្តិការណ៍ (Event, តាងដោយ \(A, B, C, \dots\)) គឺជាសំណុំរងនៃលំហសំណាក (\(A \subseteq S\))។

  • ចំនួនករណីស្រប ៖ តាងដោយ \(n(A)\) គឺជាចំនួនធាតុនៃព្រឹត្តិការណ៍ \(A\) (លទ្ធផលដែលយើងចង់បាន)។

  • ព្រឹត្តិការណ៍មិនអាចកើតមាន (Impossible Event) ៖ \(A = \emptyset\) (មាន \(n(A) = 0\))។ ឧទាហរណ៍ ៖ បោះគ្រាប់ឡុកឡាក់បានលេខ ៧។

  • ព្រឹត្តិការណ៍ប្រាកដ (Certain Event) ៖ \(A = S\) (មាន \(n(A) = n(S)\))។ ឧទាហរណ៍ ៖ បោះគ្រាប់ឡុកឡាក់បានលេខតូចជាង ៧។

  • ព្រឹត្តិការណ៍បំពេញ (Complementary Event, តាងដោយ \(\bar{A}\) ឬ \(A'\)) ៖ ជាព្រឹត្តិការណ៍ដែល «មិនមែន \(A\)» (\(A \cup \bar{A} = S\) និង \(A \cap \bar{A} = \emptyset\))។

និយមន័យប្រូបាបក្លាស៊ិក

រូបមន្តគណនាប្រូបាប

ប្រូបាបនៃព្រឹត្តិការណ៍ \(A\) គឺជាផលធៀបរវាងចំនួនករណីស្រប និងចំនួនករណីអាច ៖

\[P(A) = \frac{n(A)}{n(S)} = \frac{\text{ចំនួនករណីស្រប}}{\text{ចំនួនករណីអាច}}\]

លក្ខណៈសំខាន់ៗនៃប្រូបាប

  1. ចំពោះគ្រប់ព្រឹត្តិការណ៍ \(A\) ៖ \(0 \le P(A) \le 1\)

  2. ប្រូបាបនៃព្រឹត្តិការណ៍មិនអាចកើតមាន ៖ \(P(\emptyset) = 0\)

  3. ប្រូបាបនៃព្រឹត្តិការណ៍ប្រាកដ ៖ \(P(S) = 1\)

  4. ផលបូកប្រូបាបនៃព្រឹត្តិការណ៍ និងព្រឹត្តិការណ៍បំពេញរបស់វា ៖

    \[P(A) + P(\bar{A}) = 1 \iff P(\bar{A}) = 1 - P(A)\]

  5. ប្រូបាបអាចសរសេរជា ៖ ប្រភាគសម្រួលរួច, ចំនួនទសភាគ, ឬភាគរយ (\(P\% = P \times 100\%\))។

ឧទាហរណ៍

គេបោះគ្រាប់ឡុកឡាក់មួយគ្រាប់ដែលល្អស្មើដៃចំនួនមួយដង។ គណនាប្រូបាបនៃព្រឹត្តិការណ៍ ៖

  1. \(A\) ៖ «បោះបានលេខសេស»

  2. \(B\) ៖ «បោះបានលេខធំជាង ៤»

  3. \(C\) ៖ «បោះបានចំនួនបឋម»

  4. \(D\) ៖ «បោះបានពហុគុណនៃ ៣»

ដំណោះស្រាយ

លំហសំណាក \(S = \{1, 2, 3, 4, 5, 6\} \implies n(S) = 6\)។

  1. \(A = \{1, 3, 5\} \implies n(A) = 3 \implies P(A) = \dfrac{3}{6} = \dfrac{1}{2} = 50\%\)។

  2. \(B = \{5, 6\} \implies n(B) = 2 \implies P(B) = \dfrac{2}{6} = \dfrac{1}{3}\)។

  3. \(C = \{2, 3, 5\} \implies n(C) = 3 \implies P(C) = \dfrac{3}{6} = \dfrac{1}{2}\) (លេខ ១ មិនមែនបឋមទេ!)។

  4. \(D = \{3, 6\} \implies n(D) = 2 \implies P(D) = \dfrac{2}{6} = \dfrac{1}{3}\)។

ដ្យាក្រាមដើមឈើជួយរៀបរាប់គ្រប់លទ្ធផលដែលអាចកើតមានទាំងអស់សម្រាប់ការពិសោធន៍ដែលមាន ២ ឬ ៣ ដំណាក់កាល ៖

  • វិធានផលគុណ ៖ បើដំណាក់កាលទីមួយមាន \(m\) លទ្ធផល និងដំណាក់កាលទីពីរមាន \(k\) លទ្ធផល នោះការពិសោធន៍ទាំងមូលមាន \(n(S) = m \times k\) លទ្ធផល។

  2. គណនាប្រូបាបដែលបោះបានមុខរូប (H) យ៉ាងតិចពីរដង

ដំណោះស្រាយ

  1. \(n(S) = 2 \times 2 \times 2 = 2^3 = 8\) ករណី ៖

    \[S = \{HHH, HHT, HTH, HTT, THH, THT, TTH, TTT\}\]

  2. ព្រឹត្តិការណ៍ \(A\) ៖ «បាន H យ៉ាងតិច ២ ដង» មានន័យថា ២ ដង ឬ ៣ ដង ៖

    \[A = \{HHH, HHT, HTH, THH\} \implies n(A) = 4\]

មើលដំណោះស្រាយ

ផលបូក ៤ ៖ ៣ ករណី ; ៨ ៖ ៥ ករណី ; ១២ ៖ ១ ករណី \(\implies 9\) ករណី។
\(P = \dfrac{9}{36} = \dfrac{1}{4}\)។

៣០លំហាត់ទី ៣០

គេបោះគ្រាប់ឡុកឡាក់ ២ គ្រាប់។ គណនាប្រូបាបដែលផលបូកលេខទាំងពីរជាចំនួនបឋម។

មើលដំណោះស្រាយ

\(P = \dfrac{15}{36} = \dfrac{5}{12}\)។

៣១លំហាត់ទី ៣១

គេមានប័ណ្ណ ៥ សន្លឹក ចុះលេខ \(1, 2, 3, 4, 5\)។ គេដកប័ណ្ណ ២ សន្លឹកជាបន្តបន្ទាប់ដោយមិនដាក់ចូលវិញ។ គណនាប្រូបាបដែលប័ណ្ណទាំងពីរជាចំនួនគូ។

មើលដំណោះស្រាយ

គ្មានដាក់ចូលវិញ ៖ \(P = \dfrac{2}{5} \times \dfrac{1}{4} = \dfrac{2}{20} = \dfrac{1}{10}\)។

៣២លំហាត់ទី ៣២

មើលដំណោះស្រាយ

មានដាក់ចូលវិញ ៖ \(P = \dfrac{2}{5} \times \dfrac{2}{5} = \dfrac{4}{25}\)។

៣៣លំហាត់ទី ៣៣

ក្នុងប្រអប់មួយមានស្រោមសំបុត្រពណ៌ស ៧ និងពណ៌ខៀវ \(x\)។ បើគេដឹងថាប្រូបាបដែលចាប់បានស្រោមសំបុត្រពណ៌ខៀវគឺ \(\dfrac{3}{10}\) ចូររកចំនួន \(x\)។

មើលដំណោះស្រាយ

\(\dfrac{x}{7 + x} = \dfrac{3}{10} \implies 10x = 21 + 3x \implies 7x = 21 \implies x = 3\)។

៣៤លំហាត់ទី ៣៤

គណនាប្រូបាបដែលឆ្នាំមួយដែលជ្រើសរើសដោយចៃដន្យ គឺជាឆ្នាំបង្គ្រប់ (Leap year) ក្នុងចំណោមឆ្នាំពី ២០០១ ដល់ ២០២០។

មើលដំណោះស្រាយ

ពី ២០០១ ដល់ ២០២០ មាន ២០ ឆ្នាំ។ ឆ្នាំបង្គ្រប់ (ចែកដាច់នឹង ៤) គឺ ២០០៤, ២០០៨, ២០១២, ២០១៦, ២០២០ (៥ ឆ្នាំ) ៖
\(P = \dfrac{5}{20} = \dfrac{1}{4}\)។

៣៥លំហាត់ទី ៣៥

គេបោះកាក់មួយរហូតដល់ចេញខាងរូប (H) ឬបោះគ្រប់ ៣ ដងទើបឈប់។ សរសេរលំហសំណាកនៃល្បែងនេះ។

មើលដំណោះស្រាយ

\(S = \{H, TH, TTH, TTT\}\) (\(n(S) = 4\))។

៣៦លំហាត់ទី ៣៦

គេមានឃ្លី ៣ ពណ៌ ៖ ក្រហម ខៀវ និងលឿង។ គេដកឃ្លីមួយរួចកត់ត្រាពណ៌ ហើយដកឃ្លីមួយទៀត (ដោយដាក់ចូលវិញ)។ គណនាប្រូបាបដែលបានពណ៌ខុសគ្នាទាំងពីរដង។

មើលដំណោះស្រាយ

\(P(\) ពណ៌ដូចគ្នា \() = 3 \times \left(\dfrac{1}{3} \times \dfrac{1}{3}\right) = \dfrac{1}{3}\)។
\(P(\) ពណ៌ខុសគ្នា \() = 1 - \dfrac{1}{3} = \dfrac{2}{3}\)។

៣៧លំហាត់ទី ៣៧

ក្នុងថ្នាក់រៀនមួយ សិស្ស ៧០% ឆ្លងកាត់ការប្រឡងភាសាអង់គ្លេស និង ៦០% ឆ្លងកាត់ការប្រឡងកុំព្យូទ័រ។ បើ ៥០% ឆ្លងកាត់មុខវិជ្ជាទាំងពីរ រកប្រូបាបដែលសិស្សម្នាក់ជ្រើសរើសដោយចៃដន្យធ្លាក់ទាំងពីរមុខ។

មើលដំណោះស្រាយ

\(P(E \cup C) = 0.70 + 0.60 - 0.50 = 0.80\)។
\(P(\) ធ្លាក់ទាំងពីរ \() = 1 - 0.80 = 0.20 = 20\%\)។

៣៨លំហាត់ទី ៣៨

គេបោះគ្រាប់ឡុកឡាក់ ៣ គ្រាប់ព្រមគ្នា។

  1. រកចំនួនករណីអាចសរុប

  2. គណនាប្រូបាបដែលគ្រាប់ទាំងបីចេញលេខដូចគ្នាទាំងអស់

មើលដំណោះស្រាយ

ឡុកឡាក់ ៣ គ្រាប់ ៖

  • a. \(n(S) = 6^3 = 216\)

  • b. ដូចគ្នាទាំង ៣ ៖ \((1,1,1), \dots, (6,6,6)\) (៦ ករណី) \(\implies P = \dfrac{6}{216} = \dfrac{1}{36}\)

៣៩លំហាត់ទី ៣៩

តាមលំហាត់ទី ៣៨ គណនាប្រូបាបដែលផលបូកនៃគ្រាប់ឡុកឡាក់ទាំងបីស្មើនឹង ៤។

មើលដំណោះស្រាយ

ផលបូក ៤ ៖ \((1,1,2), (1,2,1), (2,1,1)\) (៣ ករណី) ៖

៤០លំហាត់ទី ៤០

តាមលំហាត់ទី ៣៨ គណនាប្រូបាបដែលផលបូកនៃគ្រាប់ឡុកឡាក់ទាំងបីស្មើនឹង ១៨។

មើលដំណោះស្រាយ

ផលបូក ១៨ ៖ \((6,6,6)\) (១ ករណី) ៖
\(P = \dfrac{1}{216}\)។

៤១លំហាត់ទី ៤១

គេជ្រើសរើសចំនួនគត់មួយពីចន្លោះ \([1, 100]\)។ គណនាប្រូបាបដែលចំនួននោះចែកដាច់នឹង ៣ ឬចែកដាច់នឹង ៥។

មើលដំណោះស្រាយ

ចែកដាច់នឹង ៣ (៣៣ ចំនួន), នឹង ៥ (២០ ចំនួន), នឹង ១៥ (៦ ចំនួន) ៖
\(N = 33 + 20 - 6 = 47 \implies P = \dfrac{47}{100}\)។

៤២លំហាត់ទី ៤២

គេជ្រើសរើសចំនួនគត់មួយពីចន្លោះ \([1, 100]\)។ គណនាប្រូបាបដែលចំនួននោះចែកដាច់នឹងទាំង ៣ និង ៥ (ចែកដាច់នឹង ១៥)។

មើលដំណោះស្រាយ

ចែកដាច់នឹង ១៥ មាន ៦ ចំនួន \(\implies P = \dfrac{6}{100} = \dfrac{3}{50}\)។

៤៣លំហាត់ទី ៤៣

ក្នុងរោងចក្រមួយ ផលិតផលត្រូវបានពិនិត្យគុណភាព។ ក្នុងចំណោម ១០០០ ផលិតផល មាន ២០ ផលិតផលមានបញ្ហាបច្ចេកទេស។ គណនាប្រូបាបដែលអតិថិជនម្នាក់ទិញចំផលិតផលគ្មានបញ្ហា។

មើលដំណោះស្រាយ

\(P = \dfrac{1000 - 20}{1000} = \dfrac{980}{1000} = 0.98 = 98\%\)។

៤៤លំហាត់ទី ៤៤

អ្នកបាញ់កាំភ្លើងម្នាក់បាញ់ចំគោលដៅដោយប្រូបាប \(0.8\)។ បើគាត់បាញ់ ២ គ្រាប់ដោយឯករាជ្យ គណនាប្រូបាបដែល ៖

  1. គាត់បាញ់ចំគោលដៅទាំង ២ គ្រាប់

  2. គាត់បាញ់ខុសទាំង ២ គ្រាប់

  3. គាត់បាញ់ចំគោលដៅយ៉ាងតិច ១ គ្រាប់

មើលដំណោះស្រាយ

បាញ់កាំភ្លើង ៖

  • a. ចំទាំងពីរ ៖ \(0.8 \times 0.8 = 0.64\)

  • b. ខុសទាំងពីរ ៖ \(0.2 \times 0.2 = 0.04\)

  • c. ចំយ៉ាងតិចមួយ ៖ \(1 - 0.04 = 0.96\)

៤៥លំហាត់ទី ៤៥

ប្រព័ន្ធសុវត្ថិភាពមួយមានសោរលេខកូដសម្ងាត់ ៣ ខ្ទង់ (ពី 0 ដល់ 9)។ គណនាប្រូបាបដែលជនខិលខូចម្នាក់ទាយត្រូវលេខកូដសម្ងាត់ក្នុងការសាកល្បងលើកដំបូង។

មើលដំណោះស្រាយ

កូដ ៣ ខ្ទង់មាន \(10^3 = 1000\) ករណី ៖
\(P = \dfrac{1}{1000} = 0.001\)។

៤៦លំហាត់ទី ៤៦

ក្នុងប្រអប់មួយមានស្រោមជើងពណ៌ខ្មៅ ៤ គូ និងពណ៌ស ៦ គូដែលច្របល់ចូលគ្នា។ គេចាប់យកស្រោមជើង ២ មួយចំហៀងៗដោយចៃដន្យក្នុងទីងងឹត។ គណនាប្រូបាបដែលចាប់បានស្រោមជើងពណ៌ដូចគ្នា។

មើលដំណោះស្រាយ

ស្រោមជើងសរុប ២០ (ខ្មៅ ៨, ស ១២) ៖
\(P(\) ដូចគ្នា \() = \dfrac{8}{20}\times\dfrac{7}{19} + \dfrac{12}{20}\times\dfrac{11}{19} = \dfrac{56 + 132}{380} = \dfrac{188}{380} = \dfrac{47}{95}\)។

៤៧លំហាត់ទី ៤៧

គេមានសិស្ស ៣ នាក់។ គណនាប្រូបាបដែលសិស្សទាំង ៣ នាក់កើតក្នុងថ្ងៃខុសៗគ្នាក្នុងសប្តាហ៍។

មើលដំណោះស្រាយ

\(P = \dfrac{7}{7} \times \dfrac{6}{7} \times \dfrac{5}{7} = \dfrac{30}{49}\)។

៤៨លំហាត់ទី ៤៨

គណនាប្រូបាបដែលសិស្សយ៉ាងតិច ២ នាក់ក្នុងចំណោម ៣ នាក់កើតក្នុងថ្ងៃតែមួយនៃសប្តាហ៍។

មើលដំណោះស្រាយ

\(P = 1 - \dfrac{30}{49} = \dfrac{19}{49}\)។

៤៩លំហាត់ទី ៤៩

បង្ហាញថា បើ \(A\) និង \(B\) ជាពីរព្រឹត្តិការណ៍មិនចុះសម្រុងគ្នា (\(A \cap B = \emptyset\)) នោះ \(P(A \cup B) = P(A) + P(B)\)។

មើលដំណោះស្រាយ

ដោយ \(A \cap B = \emptyset\) នោះ \(n(A \cup B) = n(A) + n(B)\)។
ចែកនឹង \(n(S)\) ៖ \(\dfrac{n(A \cup B)}{n(S)} = \dfrac{n(A)}{n(S)} + \dfrac{n(B)}{n(S)} \implies P(A \cup B) = P(A) + P(B)\) (ពិត)។

៥០លំហាត់ទី ៥០

បង្ហាញថា ចំពោះពីរព្រឹត្តិការណ៍ \(A\) និង \(B\) ណាមួយ គេតែងតែបានរូបមន្តបូកប្រូបាប ៖

\[P(A \cup B) = P(A) + P(B) - P(A \cap B)\]

មើលដំណោះស្រាយ

តាមទ្រឹស្តីសំណុំ ៖ \(n(A \cup B) = n(A) + n(B) - n(A \cap B)\)។
ចែកអង្គទាំងពីរនឹង \(n(S)\) គេបាន ៖
\(P(A \cup B) = P(A) + P(B) - P(A \cap B)\) (ពិត)។
