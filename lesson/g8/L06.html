ការវិវត្តពីប្រភាគលេខ (Numerical Fractions) ទៅជា ប្រភាគពីជគណិត ឬកន្សោមសនិទាន (Rational Expressions) គឺជាជំហានគន្លឹះមួយក្នុងការអភិវឌ្ឍពីជគណិតទំនើប ៖

  • អាល់ការ៉ាជី (Al-Karaji, 953–1029 នៃ គ.ស.)៖ គណិតវិទូ និងវិស្វករជនជាតិពែរ្ស បានសរសេរសៀវភៅដ៏ល្បីល្បាញ Al-Fakhri។ គាត់គឺជាមនុស្សដំបូងគេបង្អស់ដែលបានរំដោះពីជគណិតចេញពីធរណីមាត្រ ដោយបានបង្កើតក្បួននព្វន្តសម្រាប់ពីជគណិត រួមទាំងការធ្វើប្រមាណវិធីបូក ដក គុណ ចែកលើកន្សោមពីជគណិត និងប្រភាគពីជគណិត (ស្វ័យគុណអវិជ្ជមាននៃអញ្ញាត)។

  • សតវត្សទី ១៧ និងគណិតវិទ្យាវិភាគ៖ គណិតវិទូ Isaac Newton និង Gottfried Wilhelm Leibniz បានយកកន្សោមសនិទានមកប្រើប្រាស់ជាមូលដ្ឋានក្នុងការសិក្សាអនុគមន៍សនិទាន (Rational Functions) ក្នុងគណិតវិទ្យាវិភាគ (Calculus) ជាពិសេសការស្វែងរកចំណុចមិនកំណត់ (Singularities) និងបន្ទាត់អាស៊ីមតូត (Asymptotes)។

  • សារៈសំខាន់ក្នុងការអនុវត្តជាក់ស្តែង ៖ ក្នុងជីវភាព និងបច្ចេកវិទ្យា កន្សោមសនិទានត្រូវបានប្រើប្រាស់យ៉ាងទូលំទូលាយក្នុងការគណនាល្បឿនមធ្យម ភាពធន់អគ្គិសនីតជាខ្នែង (Parallel Resistance) និងការគណនាទិន្នផលការងាររួមគ្នារវាងមនុស្ស ឬម៉ាស៊ីនច្រើន។

កន្សោមសនិទាន

កន្សោមសនិទាន (Rational Expression) គឺជាកន្សោមពីជគណិតដែលមានទម្រង់ជាប្រភាគ ៖

\[\frac{A}{B}\]
ដែល \(A\) និង \(B\) ជាពហុធា ហើយ \(B\) ជាពហុធាមិនសូន្យ (\(B \ne 0\))។

  • \(A\) ហៅថា ភាគយក (Numerator)

  • \(B\) ហៅថា ភាគបែង (Denominator)

  • ពហុធា \(P\) ណាមួយក៏ជាកន្សោមសនិទានដែរ ព្រោះ \(P = \dfrac{P}{1}\)។

កន្សោមណាខ្លះជាកន្សោមសនិទាន?

  1. \(\dfrac{2x+1}{x-3}\)

  2. \(\dfrac{x^2-5}{4}\)

  3. \(\dfrac{\sqrt{x}+1}{x-2}\)

  4. \(\dfrac{3}{x^2+1}\)

ដំណោះស្រាយ

  • a, b, d ជាកន្សោមសនិទាន ពីព្រោះភាគយក និងភាគបែងជាពហុធា។

  • c មិនមែនជាកន្សោមសនិទានទេ ពីព្រោះភាគយកមាន \(\sqrt{x}\) មិនមែនជាពហុធា។

លក្ខខណ្ឌកំណត់ (ដែនកំណត់) នៃកន្សោមសនិទាន

លក្ខខណ្ឌកំណត់

កន្សោមសនិទាន \(\dfrac{A}{B}\) មានន័យ (ឬអាចគណនាបាន) កាលណា ភាគបែងខុសពីសូន្យ (\(B \ne 0\))។
តម្លៃនៃអថេរណាដែលធ្វើឱ្យភាគបែង \(B = 0\) ហៅថា តម្លៃធ្វើឱ្យកន្សោមគ្មានន័យ (ឬតម្លៃមិនយក)។

ឧទាហរណ៍

រកលក្ខខណ្ឌកំណត់នៃកន្សោមសនិទានខាងក្រោម ៖

  1. \(A = \dfrac{5x}{x - 4}\)

  2. \(B = \dfrac{2x + 1}{x^2 - 9}\)

ដំណោះស្រាយ

  1. កន្សោម \(A\) មានន័យកាលណា \(x - 4 \ne 0 \iff x \ne 4\)។

  2. កន្សោម \(B\) មានន័យកាលណា \(x^2 - 9 \ne 0 \iff (x-3)(x+3) \ne 0 \iff x \ne 3\) និង \(x \ne -3\)។

កំណត់លក្ខខណ្ឌនៃកន្សោមសនិទាន

រកលក្ខខណ្ឌកំណត់នៃកន្សោមសនិទាន ៖

\[P = \frac{3x - 5}{x^2 - 4x + 3}\]

ការសម្រួលកន្សោមសនិទាន

លក្ខណៈគ្រឹះនៃការសម្រួល

បើ \(\dfrac{A}{B}\) ជាកន្សោមសនិទាន និង \(K\) ជាពហុធាមិនសូន្យ នោះ ៖

\[\frac{A \cdot K}{B \cdot K} = \frac{A}{B}\]
ដើម្បីសម្រួលកន្សោមសនិទាន គេត្រូវ ៖

  1. ដាក់ភាគយក និងភាគបែងជាផលគុណកត្តា។

  2. សម្រួលកត្តារួមរវាងភាគយក និងភាគបែងចោល។

កំហុសដែលសិស្សឧស្សាហ៍ជួបប្រទះ

កុំសម្រួលតួបូក ឬដក!

\[\frac{x + 5}{x + 2} \ne \frac{5}{2} \quad{} (\text{ខុសធ្ងន់ធ្ងរ!})\]
ការសម្រួលអាចធ្វើទៅបាន តែចំពោះកត្តាគុណរួមប៉ុណ្ណោះ។

ឧទាហរណ៍

សម្រួលកន្សោមសនិទានខាងក្រោម ៖

  1. \(A = \dfrac{6x^2y}{9xy^3}\)

  2. \(B = \dfrac{x^2 - 4}{x^2 + 4x + 4}\)

ដំណោះស្រាយ

  1. \(A = \dfrac{3xy \cdot 2x}{3xy \cdot 3y^2} = \dfrac{2x}{3y^2}\) (ចំពោះ \(x \ne 0, y \ne 0\))។

  2. \(B = \dfrac{(x-2)(x+2)}{(x+2)^2} = \dfrac{x-2}{x+2}\) (ចំពោះ \(x \ne -2\))។

សម្រួលកន្សោមសនិទាន

សម្រួលកន្សោមសនិទាន ៖

\[Q = \frac{x^2 - 5x + 6}{x^2 - 9}\]

វិធីគុណ និងវិធីចែកកន្សោមសនិទាន

វិធីគុណ និងចែក

  • វិធីគុណ ៖ គេគុណភាគយកនឹងភាគយក ហើយគុណភាគបែងនឹងភាគបែង ៖

    \[\frac{A}{B} \times \frac{C}{D} = \frac{A \cdot C}{B \cdot D} \quad{} (B \ne 0, D \ne 0)\]

  • វិធីចែក ៖ គេគុណប្រភាគទីមួយនឹងប្រភាគចម្រាសនៃប្រភាគទីពីរ ៖

    \[\frac{A}{B} \div \frac{C}{D} = \frac{A}{B} \times \frac{D}{C} = \frac{A \cdot D}{B \cdot C} \quad{} (B \ne 0, C \ne 0, D \ne 0)\]

ឧទាហរណ៍

គណនា និងសម្រួលលទ្ធផល ៖

  1. \(P = \dfrac{x^2 - 1}{x + 2} \times \dfrac{3x + 6}{x + 1}\)

  2. \(Q = \dfrac{x^2 - 4}{x^2 - 1} \div \dfrac{x - 2}{x + 1}\)

ដំណោះស្រាយ

  1. \(P = \dfrac{(x-1)(x+1)}{x+2} \times \dfrac{3(x+2)}{x+1} = \dfrac{3(x-1)(x+1)(x+2)}{(x+2)(x+1)} = 3(x-1)\)។

  2. \(Q = \dfrac{(x-2)(x+2)}{(x-1)(x+1)} \times \dfrac{x+1}{x-2} = \dfrac{x+2}{x-1}\)។

វិធីបូក និងវិធីដកកន្សោមសនិទាន

បូក-ដកភាគបែងដូចគ្នា

ដើម្បីបូក ឬដកកន្សោមសនិទានដែលមានភាគបែងដូចគ្នា គេបូក ឬដកតែភាគយក ហើយរក្សាទុកភាគបែងនៅដដែល ៖

\[\frac{A}{B} + \frac{C}{B} = \frac{A + C}{B} \quad{};\quad{} \frac{A}{B} - \frac{C}{B} = \frac{A - C}{B}\]

កន្សោមសនិទានដែលមានភាគបែងខុសគ្នា

បូក-ដកភាគបែងខុសគ្នា

ដើម្បីបូក ឬដកកន្សោមសនិទានដែលមានភាគបែងខុសគ្នា គេត្រូវ ៖

  1. រកភាគបែងរួមតូចបំផុត (LCM នៃភាគបែង) ដោយដាក់ភាគបែងទាំងអស់ជាផលគុណកត្តា។

  2. តម្រូវភាគបែងនៃកន្សោមនីមួយៗទៅជាភាគបែងរួម។

  3. ធ្វើប្រមាណវិធីបូក ឬដកភាគយក រួចសម្រួលលទ្ធផលបើអាច។

ឧទាហរណ៍

គណនាកន្សោមខាងក្រោម ៖

  1. \(A = \dfrac{2x}{x-3} - \dfrac{6}{x-3}\)

  2. \(B = \dfrac{3}{x+2} + \dfrac{2}{x-1}\)

ដំណោះស្រាយ

  1. \(A = \dfrac{2x - 6}{x-3} = \dfrac{2(x-3)}{x-3} = 2\)។

  2. ភាគបែងរួមគឺ \((x+2)(x-1)\) ៖

    \[B = \frac{3(x-1) + 2(x+2)}{(x+2)(x-1)} = \frac{3x - 3 + 2x + 4}{(x+2)(x-1)} = \frac{5x + 1}{(x+2)(x-1)}\]

កន្សោមសនិទានជាន់គ្នា (Complex Rational Expressions)

កន្សោមជាន់គ្នា

កន្សោមសនិទានជាន់គ្នា គឺជាកន្សោមដែលភាគយក ឬភាគបែង ឬទាំងពីរ មានផ្ទុកប្រភាគ។
វិធីសម្រួល ៖ គេគណនាភាគយក និងភាគបែងឱ្យទៅជាប្រភាគទោល រួចយកភាគយកចែកនឹងភាគបែង។

ឧទាហរណ៍

សម្រួលកន្សោមជាន់គ្នា ៖ \(K = \dfrac{1 - \dfrac{1}{x}}{1 + \dfrac{1}{x}}\)។

ដំណោះស្រាយ

\[K = \frac{\dfrac{x-1}{x}}{\dfrac{x+1}{x}} = \frac{x-1}{x} \times \frac{x}{x+1} = \frac{x-1}{x+1} \quad{} (x \ne 0, x \ne -1)\]

គណនាកន្សោមសនិទាន

គណនា និងសម្រួល ៖

\[S = \frac{1}{x-1} - \frac{2}{x^2-1}\]

លំហាត់អនុវត្តន៍

១លំហាត់ទី ១

រកលក្ខខណ្ឌកំណត់នៃកន្សោមសនិទានខាងក្រោម ៖

  1. \(\dfrac{3}{2x - 6}\)

  2. \(\dfrac{x + 1}{x^2 - 16}\)

  3. \(\dfrac{5x - 2}{x^2 + 4}\)

  4. \(\dfrac{2x}{x^2 - 5x + 6}\)

មើលដំណោះស្រាយ

លក្ខខណ្ឌកំណត់ ៖

  • a. \(2x - 6 \ne 0 \iff x \ne 3\)

  • b. \(x^2 - 16 \ne 0 \iff x \ne \pm 4\)

  • c. \(x^2 + 4 > 0\) ជានិច្ច នាំឱ្យមានន័យចំពោះគ្រប់ \(x \in \mathbb{R}\)

  • d. \(x^2 - 5x + 6 \ne 0 \iff (x-2)(x-3) \ne 0 \iff x \ne 2\) និង \(x \ne 3\)

២លំហាត់ទី ២

រកតម្លៃនៃ \(x\) ដែលធ្វើឱ្យកន្សោមសនិទានខាងក្រោមស្មើនឹងសូន្យ ៖

  1. \(\dfrac{3x - 12}{x + 5}\)

  2. \(\dfrac{x^2 - 9}{x + 3}\)

  3. \(\dfrac{x^2 - 4x + 3}{x - 1}\)

  4. \(\dfrac{2x + 7}{x^2 + 1}\)

មើលដំណោះស្រាយ

តម្លៃ \(x\) ធ្វើឱ្យកន្សោមស្មើ \(0\) ៖

  • a. \(3x - 12 = 0 \iff x = 4\) (ផ្ទៀងផ្ទាត់ \(4+5 \ne 0\))

  • b. \(x^2 - 9 = 0 \iff x = \pm 3\)។ ដោយ \(x \ne -3\) នោះយកតែ \(x = 3\)

  • c. \(x^2 - 4x + 3 = 0 \iff x = 1\) ឬ \(x = 3\)។ ដោយ \(x \ne 1\) នោះយកតែ \(x = 3\)

  • d. \(2x + 7 = 0 \iff x = -\dfrac{7}{2}\)

៣លំហាត់ទី ៣

រកតម្លៃនៃកន្សោមសនិទានខាងក្រោម ៖

  1. \(A = \dfrac{x^2 - 1}{x + 2}\) ចំពោះ \(x = 3\) និង \(x = -1\)

  2. \(B = \dfrac{2x - y}{x + 2y}\) ចំពោះ \(x = 4, y = -1\)

មើលដំណោះស្រាយ

គណនាតម្លៃលេខ ៖

  • a. \(x = 3 \implies A = \dfrac{9-1}{3+2} = \dfrac{8}{5}\) ; \(x = -1 \implies A = \dfrac{1-1}{-1+2} = 0\)

  • b. \(x = 4, y = -1 \implies B = \dfrac{8 - (-1)}{4 + 2(-1)} = \dfrac{9}{2}\)

៤លំហាត់ទី ៤

សម្រួលកន្សោមសនិទានខាងក្រោម ៖

  1. \(\dfrac{15x^3y^2}{25x^2y^4}\)

  2. \(\dfrac{-36a^4b^3c}{54a^2b^5c^2}\)

  3. \(\dfrac{48x^5(y-1)^2}{32x^3(y-1)}\)

  4. \(\dfrac{-18(a+b)^3}{27(a+b)}\)

មើលដំណោះស្រាយ

សម្រួលកន្សោម ៖

  • a. \(\dfrac{3x}{5y^2}\)

  • b. \(\dfrac{-2a^2}{3b^2c}\)

  • c. \(\dfrac{3x^2(y-1)}{2}\)

  • d. \(-\dfrac{2(a+b)^2}{3}\)

៥លំហាត់ទី ៥

សម្រួលកន្សោមសនិទានដោយទាញកត្តារួម ៖

  1. \(\dfrac{4x - 12}{6x - 18}\)

  2. \(\dfrac{5a^2 + 10ab}{15ab + 30b^2}\)

  3. \(\dfrac{x^2 - xy}{x^2 - y^2}\)

  4. \(\dfrac{3x^2 - 6x}{x^2 - 4}\)

មើលដំណោះស្រាយ

ទាញកត្តារួម ៖

  • a. \(\dfrac{4(x-3)}{6(x-3)} = \dfrac{2}{3}\)

  • b. \(\dfrac{5a(a+2b)}{15b(a+2b)} = \dfrac{a}{3b}\)

  • c. \(\dfrac{x(x-y)}{(x-y)(x+y)} = \dfrac{x}{x+y}\)

  • d. \(\dfrac{3x(x-2)}{(x-2)(x+2)} = \dfrac{3x}{x+2}\)

៦លំហាត់ទី ៦

សម្រួលកន្សោមសនិទានដោយប្រើ \(a^2 - b^2\) ៖

  1. \(\dfrac{x^2 - 49}{x + 7}\)

  2. \(\dfrac{4x^2 - 25}{2x - 5}\)

  3. \(\dfrac{9a^2 - 16b^2}{3a + 4b}\)

  4. \(\dfrac{x^4 - 16}{x^2 + 4}\)

មើលដំណោះស្រាយ

ប្រើ \(a^2 - b^2\) ៖

  • a. \(\dfrac{(x-7)(x+7)}{x+7} = x - 7\)

  • b. \(\dfrac{(2x-5)(2x+5)}{2x-5} = 2x + 5\)

  • c. \(\dfrac{(3a-4b)(3a+4b)}{3a+4b} = 3a - 4b\)

  • d. \(\dfrac{(x^2-4)(x^2+4)}{x^2+4} = x^2 - 4\)

៧លំហាត់ទី ៧

សម្រួលកន្សោមសនិទានដោយប្រើការេប្រាកដ ៖

  1. \(\dfrac{x^2 + 6x + 9}{x^2 - 9}\)

  2. \(\dfrac{x^2 - 8x + 16}{x^2 - 16}\)

  3. \(\dfrac{4x^2 - 12x + 9}{4x^2 - 9}\)

  4. \(\dfrac{x^2 + 2xy + y^2}{x^2 - y^2}\)

មើលដំណោះស្រាយ

ការេប្រាកដ ៖

  • a. \(\dfrac{(x+3)^2}{(x-3)(x+3)} = \dfrac{x+3}{x-3}\)

  • b. \(\dfrac{(x-4)^2}{(x-4)(x+4)} = \dfrac{x-4}{x+4}\)

  • c. \(\dfrac{(2x-3)^2}{(2x-3)(2x+3)} = \dfrac{2x-3}{2x+3}\)

  • d. \(\dfrac{(x+y)^2}{(x-y)(x+y)} = \dfrac{x+y}{x-y}\)

៨លំហាត់ទី ៨

សម្រួលកន្សោមសនិទានដោយប្រើផលបូក-ដកគូប ៖

  1. \(\dfrac{x^3 - 8}{x^2 + 2x + 4}\)

  2. \(\dfrac{x^3 + 27}{x + 3}\)

  3. \(\dfrac{8a^3 - 1}{4a^2 + 2a + 1}\)

  4. \(\dfrac{x^3 - 125}{x^2 - 25}\)

មើលដំណោះស្រាយ

ផលបូក-ដកគូប ៖

  • a. \(\dfrac{(x-2)(x^2+2x+4)}{x^2+2x+4} = x - 2\)

  • b. \(\dfrac{(x+3)(x^2-3x+9)}{x+3} = x^2 - 3x + 9\)

  • c. \(\dfrac{(2a-1)(4a^2+2a+1)}{4a^2+2a+1} = 2a - 1\)

  • d. \(\dfrac{(x-5)(x^2+5x+25)}{(x-5)(x+5)} = \dfrac{x^2+5x+25}{x+5}\)

៩លំហាត់ទី ៩

សម្រួលកន្សោមសនិទានដោយបំបែកតួកណ្តាល ៖

  1. \(\dfrac{x^2 + 5x + 6}{x^2 + 7x + 12}\)

  2. \(\dfrac{x^2 - 7x + 10}{x^2 - 4}\)

  3. \(\dfrac{2x^2 + 5x + 2}{2x^2 - 3x - 2}\)

  4. \(\dfrac{3x^2 - 7x + 2}{x^2 - 4}\)

មើលដំណោះស្រាយ

បំបែកតួកណ្តាល ៖

  • a. \(\dfrac{(x+2)(x+3)}{(x+3)(x+4)} = \dfrac{x+2}{x+4}\)

  • b. \(\dfrac{(x-2)(x-5)}{(x-2)(x+2)} = \dfrac{x-5}{x+2}\)

  • c. \(\dfrac{(2x+1)(x+2)}{(2x+1)(x-2)} = \dfrac{x+2}{x-2}\)

  • d. \(\dfrac{(3x-1)(x-2)}{(x-2)(x+2)} = \dfrac{3x-1}{x+2}\)

១០លំហាត់ទី ១០

សម្រួលកន្សោមដែលមានសញ្ញាផ្ទុយ ៖

  1. \(\dfrac{a - b}{b - a}\)

  2. \(\dfrac{x - 3}{9 - x^2}\)

  3. \(\dfrac{(2-x)^2}{x-2}\)

  4. \(\dfrac{4 - x^2}{x^2 - 3x + 2}\)

មើលដំណោះស្រាយ

សញ្ញាផ្ទុយ ៖

  • a. \(\dfrac{a-b}{-(a-b)} = -1\)

  • b. \(\dfrac{x-3}{-(x-3)(x+3)} = -\dfrac{1}{x+3}\)

  • c. \(\dfrac{(x-2)^2}{x-2} = x - 2\)

  • d. \(\dfrac{-(x-2)(x+2)}{(x-1)(x-2)} = -\dfrac{x+2}{x-1} = \dfrac{x+2}{1-x}\)

១១លំហាត់ទី ១១

គណនាផលគុណកន្សោមសនិទាន ៖

  1. \(\dfrac{4x^2}{3y} \times \dfrac{9y^2}{8x^3}\)

  2. \(\dfrac{-15a^3b}{14c^2} \times \dfrac{28c^3}{-25ab^2}\)

មើលដំណោះស្រាយ

គុណកន្សោមសនិទាន ៖

  • a. \(\dfrac{36x^2y^2}{24x^3y} = \dfrac{3y}{2x}\)

  • b. \(\dfrac{(-15)(-28)a^3bc^3}{(14)(25)ab^2c^2} = \dfrac{420a^3bc^3}{350ab^2c^2} = \dfrac{6a^2c}{5b}\)

១២លំហាត់ទី ១២

គណនាផលគុណកន្សោមសនិទាន ៖

  1. \(\dfrac{x^2 - 4}{x + 3} \times \dfrac{x^2 - 9}{x + 2}\)

  2. \(\dfrac{x^2 - 25}{x^2 + 6x + 9} \times \dfrac{x + 3}{x - 5}\)

មើលដំណោះស្រាយ

គុណកន្សោមសនិទាន ៖

  • a. \(\dfrac{(x-2)(x+2)}{x+3} \times \dfrac{(x-3)(x+3)}{x+2} = (x-2)(x-3)\)

  • b. \(\dfrac{(x-5)(x+5)}{(x+3)^2} \times \dfrac{x+3}{x-5} = \dfrac{x+5}{x+3}\)

១៣លំហាត់ទី ១៣

គណនាផលគុណ ៖

  1. \(\dfrac{a^2 - ab}{a^2 + ab} \times \dfrac{a^2b + ab^2}{a^2 - b^2}\)

  2. \(\dfrac{x^2 - 4x + 4}{x^2 - 1} \times \dfrac{x^2 + x}{x - 2}\)

មើលដំណោះស្រាយ

គុណកន្សោម ៖

  • a. \(\dfrac{a(a-b)}{a(a+b)} \times \dfrac{ab(a+b)}{(a-b)(a+b)} = \dfrac{ab}{a+b}\)

  • b. \(\dfrac{(x-2)^2}{(x-1)(x+1)} \times \dfrac{x(x+1)}{x-2} = \dfrac{x(x-2)}{x-1}\)

១៤លំហាត់ទី ១៤

គណនាផលចែកកន្សោមសនិទាន ៖

  1. \(\dfrac{12x^4}{25y^3} \div \dfrac{18x^2}{35y}\)

  2. \(\dfrac{-16a^3b^2}{21c^4} \div \dfrac{24a^2b}{35c^2}\)

មើលដំណោះស្រាយ

ចែកកន្សោមសនិទាន ៖

  • a. \(\dfrac{12x^4}{25y^3} \times \dfrac{35y}{18x^2} = \dfrac{420x^4y}{450x^2y^3} = \dfrac{14x^2}{15y^2}\)

  • b. \(\dfrac{-16a^3b^2}{21c^4} \times \dfrac{35c^2}{24a^2b} = -\dfrac{10ab}{9c^2}\)

១៥លំហាត់ទី ១៥

គណនាផលចែកកន្សោមសនិទាន ៖

  1. \(\dfrac{x^2 - 16}{x - 3} \div \dfrac{x + 4}{x^2 - 9}\)

  2. \(\dfrac{x^2 - 4x + 3}{x^2 + 5x + 6} \div \dfrac{x - 1}{x + 2}\)

មើលដំណោះស្រាយ

ចែកកន្សោមសនិទាន ៖

  • a. \(\dfrac{(x-4)(x+4)}{x-3} \times \dfrac{(x-3)(x+3)}{x+4} = (x-4)(x+3)\)

  • b. \(\dfrac{(x-1)(x-3)}{(x+2)(x+3)} \times \dfrac{x+2}{x-1} = \dfrac{x-3}{x+3}\)

១៦លំហាត់ទី ១៦

គណនាផលចែកកន្សោមសនិទាន ៖

  1. \(\dfrac{x^3 - 1}{x + 2} \div \dfrac{x^2 + x + 1}{x^2 - 4}\)

  2. \(\dfrac{a^2 - b^2}{a^3 + b^3} \div \dfrac{a - b}{a^2 - ab + b^2}\)

មើលដំណោះស្រាយ

ចែកកន្សោមសនិទាន ៖

  • a. \(\dfrac{(x-1)(x^2+x+1)}{x+2} \times \dfrac{(x-2)(x+2)}{x^2+x+1} = (x-1)(x-2)\)

  • b. \(\dfrac{(a-b)(a+b)}{(a+b)(a^2-ab+b^2)} \times \dfrac{a^2-ab+b^2}{a-b} = 1\)

១៧លំហាត់ទី ១៧

គណនាប្រមាណវិធីគុណ និងចែកចម្រុះ ៖

  1. \(\dfrac{x^2 - 9}{x^2 - 1} \times \dfrac{x + 1}{x - 3} \div \dfrac{x + 3}{x - 1}\)

  2. \(\dfrac{a^2 - 4}{a^2 + 2a} \div \dfrac{a - 2}{a^3} \times \dfrac{a + 1}{a^2 - 1}\)

មើលដំណោះស្រាយ

គុណ-ចែកចម្រុះ ៖

  • a. \(\dfrac{(x-3)(x+3)}{(x-1)(x+1)} \times \dfrac{x+1}{x-3} \times \dfrac{x-1}{x+3} = 1\)

  • b. \(\dfrac{(a-2)(a+2)}{a(a+2)} \times \dfrac{a^3}{a-2} \times \dfrac{a+1}{(a-1)(a+1)} = \dfrac{a^2}{a-1}\)

១៨លំហាត់ទី ១៨

គណនាផលបូកកន្សោមសនិទានដែលមានភាគបែងដូចគ្នា ៖

  1. \(\dfrac{5x - 3}{x + 4} + \dfrac{2x + 11}{x + 4}\)

  2. \(\dfrac{x^2 + 3}{x - 2} + \dfrac{5x - 17}{x - 2}\)

មើលដំណោះស្រាយ

បូកភាគបែងដូចគ្នា ៖

  • a. \(\dfrac{5x-3+2x+11}{x+4} = \dfrac{7x+8}{x+4}\)

  • b. \(\dfrac{x^2+5x-14}{x-2} = \dfrac{(x-2)(x+7)}{x-2} = x + 7\)

១៩លំហាត់ទី ១៩

គណនាផលដកកន្សោមសនិទានដែលមានភាគបែងដូចគ្នា ៖

  1. \(\dfrac{7x + 5}{x - 3} - \dfrac{4x - 4}{x - 3}\)

  2. \(\dfrac{x^2 + 4x}{x + 2} - \dfrac{3x + 2}{x + 2}\)

មើលដំណោះស្រាយ

ដកភាគបែងដូចគ្នា ៖

  • a. \(\dfrac{7x+5-4x+4}{x-3} = \dfrac{3x+9}{x-3}\)

  • b. \(\dfrac{x^2+4x-3x-2}{x+2} = \dfrac{x^2+x-2}{x+2} = \dfrac{(x-1)(x+2)}{x+2} = x - 1\)

២០លំហាត់ទី ២០

គណនាកន្សោមដែលមានភាគបែងជាចំនួនផ្ទុយគ្នា ៖

  1. \(\dfrac{3x}{x - 5} + \dfrac{15}{5 - x}\)

  2. \(\dfrac{x^2}{x - 2} + \dfrac{4}{2 - x}\)

មើលដំណោះស្រាយ

ភាគបែងផ្ទុយគ្នា ៖

  • a. \(\dfrac{3x}{x-5} - \dfrac{15}{x-5} = \dfrac{3(x-5)}{x-5} = 3\)

  • b. \(\dfrac{x^2-4}{x-2} = \dfrac{(x-2)(x+2)}{x-2} = x + 2\)

២១លំហាត់ទី ២១

រកភាគបែងរួមតូចបំផុត (LCM) នៃបណ្តាភាគបែងខាងក្រោម ៖

  1. \(6x^2y\) និង \(8xy^3\)

  2. \((x - 1)(x + 2)\) និង \((x + 2)(x + 3)\)

  3. \(x^2 - 4\) និង \(x^2 + 4x + 4\)

  4. \(x^2 - 9\) និង \(2x - 6\)

មើលដំណោះស្រាយ

រក LCM នៃភាគបែង ៖

  • a. \(\text{LCM} = 24x^2y^3\)

  • b. \(\text{LCM} = (x-1)(x+2)(x+3)\)

៣៦លំហាត់ទី ៣៦

គណនាតម្លៃនៃកន្សោម \(P = \dfrac{x-y}{x+y}\) ដោយដឹងថា \(x^2 + y^2 = 6xy\) និង \(x > y > 0\)។

៤៤លំហាត់ទី ៤៤

រថយន្តមួយបើកបរពីទីក្រុង A ទៅ B ចម្ងាយ \(d\text{ km}\) ដោយល្បឿន \(v_1\text{ km/h}\) ហើយត្រឡប់មកវិញដោយល្បឿន \(v_2\text{ km/h}\)។

  1. សរសេរកន្សោមតាងរយៈពេលសរុបនៃការធ្វើដំណើរ

  2. បង្ហាញថាល្បឿនមធ្យមនៃការធ្វើដំណើរទាំងមូលគឺ \(v_{avg} = \dfrac{2v_1 v_2}{v_1 + v_2}\)

មើលដំណោះស្រាយ

ចលនារថយន្ត ៖

  • a. \(t = \dfrac{d}{v_1} + \dfrac{d}{v_2} = d\left(\dfrac{v_1+v_2}{v_1 v_2}\right)\)

  • b. \(v_{avg} = \dfrac{2d}{t} = \dfrac{2d}{d\frac{v_1+v_2}{v_1 v_2}} = \dfrac{2v_1 v_2}{v_1 + v_2}\)

  2. រកកន្សោមតាងរយៈពេលដែលទុយោទាំងពីរចាក់ពេញអាងរួមគ្នា

មើលដំណោះស្រាយ

ទុយោទឹក ៖

  • a. \(Q = \dfrac{1}{x} + \dfrac{1}{x+3} = \dfrac{2x+3}{x(x+3)}\) អាង/ម៉ោង

  • b. \(T = \dfrac{1}{Q} = \dfrac{x(x+3)}{2x+3}\) ម៉ោង

៤៦លំហាត់ទី ៤៦

បើ \(\dfrac{x}{a} = \dfrac{y}{b} = \dfrac{z}{c}\) ចូរស្រាយបញ្ជាក់ថា ៖

\[\frac{x^2+y^2+z^2}{(ax+by+cz)^2} = \frac{1}{a^2+b^2+c^2}\]

មើលដំណោះស្រាយ

\((ax+by+cz)^2 = [k(a^2+b^2+c^2)]^2 = k^2(a^2+b^2+c^2)^2\)

៤៩លំហាត់ទី ៤៩

បើ \(xyz = 1\) ចូរគណនាតម្លៃនៃ ៖

\[P = \frac{1}{1 + x + xy} + \frac{1}{1 + y + yz} + \frac{1}{1 + z + zx}\]

មើលដំណោះស្រាយ

ដោយ \(xyz = 1\) ៖ ជំនួស \(z = \dfrac{1}{xy}\) ក្នុងតួទីពីរ និងទីបី រួចសម្រួលភាគបែងដូចគ្នា គេបាន \(P = 1\)។

៥០លំហាត់ទី ៥០

ដោះស្រាយសមីការសនិទាន ៖

\[\frac{x+1}{x-1} - \frac{x-1}{x+1} = \frac{8}{x^2-1}\]

មើលដំណោះស្រាយ

លក្ខខណ្ឌ \(x \ne \pm 1\) ៖
\(\dfrac{(x+1)^2 - (x-1)^2}{x^2-1} = \dfrac{8}{x^2-1} \implies \dfrac{4x}{x^2-1} = \dfrac{8}{x^2-1} \implies 4x = 8 \implies x = 2\) (យក)

សំណួរពហុជ្រើសរើស

ជ្រើសរើសចម្លើយត្រឹមត្រូវតែមួយ រួចចុច «ពិនិត្យ»។ ចម្លើយរបស់អ្នកត្រូវបានរក្សាទុកក្នុងកុំព្យូទ័រនេះ។
