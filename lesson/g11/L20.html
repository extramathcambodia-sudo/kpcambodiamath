ការអនុវត្តដេរីវេចំពោះសមីការ

ដោយប្រើក្រាបនៃអនុគមន៍ \(y = f(x)\) គេអាចបញ្ជាក់បានដោយងាយពីអត្ថិភាពឫស ទីតាំងឫសធៀបនឹងចំនួន និងចំនួនឫសនៃសមីការ \(f(x) = \lambda\) ទៅតាមតម្លៃប៉ារ៉ាម៉ែត្រ \(\lambda\) ។

ការអនុវត្តដេរីវេចំពោះសមីការដឺក្រេទី 3

ឧទាហរណ៍

អនុគមន៍ \(y = f(x) = x^3 + 3x^2 - 2\) មានក្រាប \(C\) ។

  1. សង់ក្រាប \(C\) នៃអនុគមន៍ \(f\) ។

  2. សិក្សាដោយប្រើក្រាបហ្វិកទៅតាមតម្លៃប៉ារ៉ាម៉ែត្រ \(\lambda\) អត្ថិភាពនិងចំនួនឫសនៃសមីការ \(x^3 + 3x^2 - 2 = \lambda\) ។

ដំណោះស្រាយ

  1. សង់ក្រាបនៃ \(f\) ៖ ដែនកំណត់ \(D = \mathbb{R}\) ។ ដេរីវេ \(f'(x) = 3x^2 + 6x = 3x(x + 2)\) ។ បើ \(f'(x) = 0\) នោះ \(x = 0\) ឬ \(x = -2\) ។ ចំពោះ \(x = 0\) គេបាន \(f(0) = -2\) និងចំពោះ \(x = -2\) គេបាន \(f(-2) = 2\) ។ លីមីតចុងដែនកំណត់ ៖ \(\displaystyle\lim_{x \to -\infty} f(x) = \lim_{x \to -\infty} x^3\left(1 + \frac{3}{x} - \frac{2}{x^3}\right) = -\infty\) និង \(\displaystyle\lim_{x \to +\infty} f(x) = +\infty\) ។

    ក្រាបប្រសព្វអ័ក្ស \(y'oy\) \(\Rightarrow x = 0\), \(y = -2\) ។ ក្រាបប្រសព្វអ័ក្ស \(x'ox\) \(\Rightarrow y = 0\) ៖

    \[\begin{aligned} x^3 + 3x^2 - 2 = 0 &\Leftrightarrow x^2(x + 1) + 2(x^2 - 1) = 0\\ &\Leftrightarrow (x + 1)(x^2 + 2x - 2) = 0 \end{aligned}\]
    នាំឱ្យ \(x = -1\) ឬ \((x + 1)^2 = 3\) គឺ \(x = -1 \pm\sqrt{3}\) ។

  2. សិក្សាទៅតាមតម្លៃ \(\lambda\) អត្ថិភាពនិងចំនួនឫសនៃសមីការ ។ គេបាន \(x^3 + 3x^2 - 2 = \lambda\) \((1)\) ជាសមីការអាប់ស៊ីសនៃចំណុចប្រសព្វរវាងក្រាប \(C\) និងបន្ទាត់ \(D : y = \lambda\) ។ សង់បន្ទាត់ \(D\) នៅក្នុងតម្រុយតែមួយ ហើយនៅត្រង់ផ្នែកណាមួយដែលជួបក្រាប \(C\) បានច្រើនចំណុចបំផុត ។ ចំនួនឫសនៃសមីការ ស្មើនឹងចំនួនចំណុចប្រសព្វរវាង \(C\) និង \(D\) ។

    • បើ \(\lambda > 2\) នោះសមីការ \((1)\) មានឫសតែ \(1\) គត់ ។

    • បើ \(\lambda = 2\) នោះសមីការ \((1)\) មានឫសឌុបនិងឫសមួយផ្សេងទៀត ។

    • បើ \(-2 < \lambda < 2\) នោះសមីការ \((1)\) មានឫស \(3\) ផ្សេងគ្នា ។

    • បើ \(\lambda = -2\) នោះសមីការ \((1)\) មានឫសឌុបនិងឫសមួយផ្សេងទៀត ។

    • បើ \(\lambda < -2\) នោះសមីការ \((1)\) មានឫសតែ \(1\) គត់ ។

លំហាត់គំរូ

សិក្សាដោយប្រើក្រាបហ្វិកទៅតាមតម្លៃ \(m\) អត្ថិភាពនិងទីតាំងឫសនៃសមីការ \(x^3 - 3x - m = 0\) ធៀបនឹងចំនួន \(0\) និង \(1\) ។

ដំណោះស្រាយ

ជំហានទី \(1\) ៖ សង់ក្រាបនៃអនុគមន៍ \(y = x^3 - 3x\) ។ គេបាន \(y' = 3x^2 - 3\) ។ បើ \(y' = 0\), \(3x^2 - 3 = 0 \Leftrightarrow x^2 = 1 \Rightarrow x = \pm 1\) ។ ចំពោះ \(x = -1\) គេបាន \(y = 2\) និងចំពោះ \(x = 1\) គេបាន \(y = -2\) ។ \(\displaystyle\lim_{x \to +\infty}(x^3 - 3x) = +\infty\), \(\displaystyle\lim_{x \to -\infty}(x^3 - 3x) = -\infty\) ។

ក្រាបប្រសព្វអ័ក្ស \((x'ox) \Rightarrow y = 0\) ៖ \(x^3 - 3x = 0 \Leftrightarrow x(x^2 - 3) = 0 \Leftrightarrow x = 0\) ឬ \(x = \pm\sqrt{3}\) ។

ជំហានទី \(2\) ៖ បំប្លែងសមីការឱ្យមានរាង \(f(x) = m\) ៖ \(x^3 - 3x = m\) ។

ជំហានទី \(3\) ៖ សង់បន្ទាត់ដេកមានសមីការ \(y = m\) នៅក្នុងតម្រុយតែមួយហើយនៅត្រង់ផ្នែកណាដែលបន្ទាត់ជួបក្រាបបានច្រើនចំណុចបំផុត ។

ជំហានទី \(4\) ៖ ប្រើក្រាបដើម្បីសិក្សាទៅតាមតម្លៃ \(m\) នូវអត្ថិភាពនិងទីតាំងឫសធៀបនឹងចំនួន \(0\) និង \(1\) ។ សន្មត \(x_1, x_2, x_3\) ជាឫសនៃសមីការដែល \(x_1 \le x_2 \le x_3\) ។

  • បើ \(m > 2\) នោះសមីការមានឫសតែមួយគត់ \(x_3\) ដែល \(0 < 1 < x_3\) ។

  • បើ \(m = 2\) នោះសមីការមានឫសដែល \(x_1 = x_2 = -1 < 0 < 1 < x_3\) ។

  • បើ \(0 < m < 2\) នោះសមីការមានឫសបីផ្សេងគ្នាដែល \(x_1 < x_2 < 0 < 1 < x_3\) ។

  • បើ \(m = 0\) នោះសមីការមានឫសបីផ្សេងគ្នាដែល \(x_1 < x_2 = 0 < 1 < x_3\) ។

  • បើ \(-2 < m < 0\) នោះសមីការមានឫសបីផ្សេងគ្នាដែល \(x_1 < 0 < x_2 < 1 < x_3\) ។

  • បើ \(m = -2\) នោះសមីការមានឫសដែល \(x_1 < 0 < 1 = x_2 = x_3\) ។

  • បើ \(m < -2\) នោះសមីការមានឫសតែមួយគត់ដែល \(x_1 < 0 < 1\) ។

ជាទូទៅ

សមីការ \(ax^3 + bx^2 + cx + d = \lambda\) មានឫសជាអាប់ស៊ីសនៃចំណុចប្រសព្វរវាងក្រាបនៃ \(y = ax^3 + bx^2 + cx + d\) និងបន្ទាត់មានសមីការ \(y = \lambda\) ។

ប្រតិបត្តិ

អនុគមន៍ \(y = x^3 - 3x + 2\) មានក្រាប \(C\) ។ រកតម្លៃ \(a\) ដើម្បីឱ្យសមីការ \(x^3 - 3x + 2 = a\) ៖ ក. មានឫសបីផ្សេងគ្នា ។ ខ. មានឫសវិជ្ជមានពីរផ្សេងគ្នា និងឫសអវិជ្ជមានមួយទៀត ។

មើលចម្លើយ

ក. \(0 < a < 4\) ខ. \(0 < a < 2\) ។

ការអនុវត្តដេរីវេចំពោះសមីការប៊ីការេ

ឧទាហរណ៍

អនុគមន៍ \(y = x^4 - 2x^2\) មានក្រាប \(C\) ។

  1. សង់ក្រាប \(C\) នៃអនុគមន៍ ។

  2. ដោយប្រើក្រាប \((C)\) សិក្សាទៅតាមតម្លៃ \(m\) អត្ថិភាពនិងចំនួនឫសនៃសមីការ \(x^4 - 2x^2 - m = 0\) ។

ដំណោះស្រាយ

  1. \(y' = 4x^3 - 4x = 4x(x^2 - 1)\) ។ \(y' = 0 \Leftrightarrow x = 0\) ឬ \(x = \pm 1\) ។ ចំពោះ \(x = 0\), \(y = 0\) និងចំពោះ \(x = \pm 1\), \(y = -1\) ។ \(\displaystyle\lim_{x \to \pm\infty}(x^4 - 2x^2) = \lim_{x \to \pm\infty} x^4\left(1 - \frac{2}{x^2}\right) = +\infty\) ។

    បើ \(x = 0\) នាំឱ្យ \(y = 0\) ។ បើ \(y = 0\), \(x^2(x^2 - 2) = 0\) នាំឱ្យ \(x = 0\) ឬ \(x = \pm\sqrt{2}\) ។

  2. សមីការ \(x^4 - 2x^2 = m\) ៖

    • បើ \(m > 0\) នោះសមីការមានឫស \(2\) ផ្សេងគ្នា ។

    • បើ \(m = 0\) នោះសមីការមានឫស \(4\) គឺ \(0\) ជាឫសឌុប និងឫសពីរផ្សេងទៀតត្រង់ \(x = \pm\sqrt{2}\) ។

    • បើ \(-1 < m < 0\) នោះសមីការមានឫស \(4\) ផ្សេងគ្នា ។

    • បើ \(m = -1\) នោះសមីការមានឫសឌុប \(2\) ត្រង់ \(x = \pm 1\) ។

    • បើ \(m < -1\) នោះសមីការគ្មានឫស ។

លំហាត់គំរូ

គេឱ្យអនុគមន៍ \(f(x) = x^4 - 2x^2 + 2\) និងក្រាប \(C\) ។ សិក្សាទៅតាមតម្លៃប៉ារ៉ាម៉ែត្រ \(\lambda\) អត្ថិភាពនិងទីតាំងឫសនៃសមីការ \(x^4 - 2x^2 + 2 = \lambda\) ធៀបនឹងចំនួន \(-1\) និង \(1\) តាមក្រាប ។

ដំណោះស្រាយ

ជំហានទី \(1\) ៖ សមីការមានរាង \(x^4 - 2x^2 + 2 = \lambda\) ។ អនុគមន៍ \(f\) មានអប្បបរមា \(f(\pm 1) = 1\) និងអតិបរមាធៀប \(f(0) = 2\) ។

ជំហានទី \(2\) ៖ សង់បន្ទាត់ដេកមានសមីការ \(y = \lambda\) ។

ជំហានទី \(3\) ៖ សន្មត \(x_1, x_2, x_3\) និង \(x_4\) ជាឫសនៃសមីការដែល \(x_1 \le x_2 \le x_3 \le x_4\) ។ សិក្សាដោយប្រើក្រាបទៅតាមតម្លៃ \(\lambda\) ៖

  • បើ \(\lambda > 2\) នោះសមីការមានឫសពីរផ្សេងគ្នាដែល \(x_1 < -1 < 1 < x_2\) ។

  • បើ \(\lambda = 2\) នោះសមីការមានឫសបួនដែល \(x_1 < -1 < x_2 = x_3 = 0 < 1 < x_4\) ។

  • បើ \(1 < \lambda < 2\) នោះសមីការមានឫសបួនផ្សេងគ្នាដែល \(x_1 < -1 < x_2 < x_3 < 1 < x_4\) ។

  • បើ \(\lambda = 1\) នោះសមីការមានឫសបួនដែល \(x_1 = x_2 = -1 < x_3 = x_4 = 1\) ។

  • បើ \(\lambda < 1\) នោះសមីការគ្មានឫសទេ ។

ជាទូទៅ

សមីការ \(ax^4 + bx^2 + c = \lambda\) មានឫសជាអាប់ស៊ីសនៃចំណុចប្រសព្វរវាងក្រាបនៃ \(y = ax^4 + bx^2 + c\) និងបន្ទាត់មានសមីការ \(y = \lambda\) ។

ប្រតិបត្តិ

គេឱ្យក្រាបនៃអនុគមន៍ \(y = x^4 - 4x^2 + 3\) ។ រកតម្លៃ \(m\) ដើម្បីឱ្យសមីការ \(x^4 - 4x^2 = m - 3\) ៖ ក. មានឫសបួនផ្សេងគ្នា ។ ខ. មានឫសពីរផ្សេងគ្នានៅក្រៅចន្លោះ \([-2, 2]\) ។

មើលចម្លើយ

ក. \(-1 < m < 3\) ខ. \(m > 3\) ។

ការអនុវត្តដេរីវេចំពោះវិសមីការ

ការអនុវត្តដេរីវេចំពោះវិសមីការដឺក្រេទី 3

ឧទាហរណ៍

បង្ហាញថាវិសមីការ \(x^3 + x + 2 > 0\) ផ្ទៀងផ្ទាត់ចំពោះ \(x > -1\) ។

របៀបទី \(1\) ៖ ប្រើប្រាស់អនុគមន៍ \(y = x^3 + x + 2\) ។ \(y' = 3x^2 + 1 > 0\) ចំពោះ \(\forall x \in \mathbb{R}\) ។ \(y'' = 6x\), បើ \(y'' = 0\), \(6x = 0 \Rightarrow x = 0\) ។ \(\displaystyle\lim_{x \to +\infty}(x^3 + x + 2) = +\infty\), \(\displaystyle\lim_{x \to -\infty}(x^3 + x + 2) = -\infty\) ។ បើ \(x = 0\), \(y = 2\) ។ បើ \(y = 0\), \(x^3 + x + 2 = 0\) សមមូល \((x + 1)(x^2 - x + 2) = 0\) ឬ \(x = -1\) ព្រោះសមីការ \(x^2 - x + 2 = 0\) គ្មានឫស ។ តាមក្រាបគ្រប់ចំណុច \((x, y)\) ដែលមាន \(y > 0\) ត្រូវស្ថិតនៅផ្នែកខាងលើអ័ក្សអាប់ស៊ីស ហើយត្រូវគ្នានឹង \(x > -1\) ។ ដូច្នេះ វិសមីការ \(x^3 + x + 2 > 0\) ផ្ទៀងផ្ទាត់ចំពោះ \(x > -1\) ។

របៀបទី \(2\) ៖ ប្រើទិសដៅអថេរភាពនៃអនុគមន៍ \(y = x^3 + x + 2\) ។ គេបាន \(y' = 3x^2 + 1 > 0\), \(\forall x \in \mathbb{R}\) \(\Rightarrow\) អនុគមន៍ \(y\) ជាអនុគមន៍កើនលើ \(\mathbb{R}\) ។ បើ \(x > -1 \Rightarrow y(x) > y(-1)\) (លក្ខណៈអនុគមន៍កើន) ។ ដោយ \(y(-1) = (-1)^3 + (-1) + 2 = 0\) \(\Rightarrow y(x) > 0\) ។ ដូច្នេះ វិសមីការ \(x^3 + x + 2 > 0\) ផ្ទៀងផ្ទាត់ចំពោះ \(x > -1\) ។

លំហាត់គំរូ

អនុគមន៍ \(y = f(x) = x^3 - 3x + 2\) មានក្រាប \(C\) ។

  1. ដោះស្រាយវិសមីការ \(x^3 - 3x + 2 < 0\) តាមក្រាប ។

  2. បង្ហាញថា \(0 \le x^3 - 3x + 2 \le 4\) ចំពោះ \(x \in [-2, 2]\) ។

ដំណោះស្រាយ

  1. តាមក្រាប គ្រប់ចំណុច \((x, y)\) នៃក្រាបដែលមាន \(y < 0\) ត្រូវស្ថិតនៅផ្នែកខាងក្រោមអ័ក្សអាប់ស៊ីស ហើយត្រូវគ្នានឹង \(x < -2\) ។ ដូច្នេះ វិសមីការមានសំណុំចម្លើយ \(S = (-\infty, -2)\) ។

  2. របៀបទី \(1\) ៖ តាមក្រាប ចំណុច \((x, y)\) នៃក្រាបដែលមាន \(x \in [-2, 2]\) ត្រូវស្ថិតលើក្រាបដែលនៅខាងលើអ័ក្សអាប់ស៊ីស ជួបអ័ក្សអាប់ស៊ីសត្រង់ \(x = -2\) និង \(x = 1\) ហើយជួបបន្ទាត់ \(y = 4\) ត្រង់ \(x = -1\) និង \(x = 2\) ។ ដូច្នេះ \(0 \le y = x^3 - 3x + 2 \le 4\) ចំពោះ \(x \in [-2, 2]\) ។

    របៀបទី \(2\) ៖ ដោយមិនប្រើក្រាប (ករណីគ្មានក្រាប) ៖ ប្រើតារាងអថេរភាព ។ ដេរីវេ \(y' = 3x^2 - 3\) ។ បើ \(y' = 0\), \(3x^2 - 3 = 0 \Leftrightarrow x = \pm 1\) ។ តម្លៃបរមា ៖ \(y(-1) = 4\), \(y(1) = 0\) ។

    តាមតារាងអថេរភាពនៃអនុគមន៍ខាងលើ គេបាន ៖ \(0 \le y = x^3 - 3x + 2 \le 4\) ចំពោះ \(x \in [-2, 2]\) ។

ជាទូទៅ

  • វិសមីការ \(ax^3 + bx^2 + cx + d > 0\) មានសំណុំឫសជាសំណុំតម្លៃអាប់ស៊ីស \(x\) នៃចំណុចនៅលើក្រាបតាងអនុគមន៍ \(y = ax^3 + bx^2 + cx + d\) ដែលស្ថិតនៅផ្នែកខាងលើអ័ក្សអាប់ស៊ីស ។

  • វិសមីការ \(ax^3 + bx^2 + cx + d < 0\) មានសំណុំឫសជាសំណុំតម្លៃអាប់ស៊ីស \(x\) នៃចំណុចនៅលើក្រាបតាងអនុគមន៍ \(y = ax^3 + bx^2 + cx + d\) ដែលស្ថិតនៅផ្នែកខាងក្រោមអ័ក្សអាប់ស៊ីស ។

ប្រតិបត្តិ

អនុគមន៍ \(y = -x^3 + 3x - 2\) មានក្រាប \(C\) ។ ក. រកសំណុំឫសនៃវិសមីការ \(-x^3 + 3x - 2 \le 0\) តាមក្រាប ។ ខ. បង្ហាញថា \(-4 \le -x^3 + 3x - 2 \le 0\) ចំពោះ \(-2 \le x \le 2\) ។

មើលចម្លើយ

ក. \(-x^3 + 3x - 2 = -(x - 1)^2(x + 2) \le 0\) ៖ \(x \in [-2, +\infty)\) ខ. លើ \([-2, 2]\) អនុគមន៍មានតម្លៃធំបំផុត \(y(-2) = y(1) = 0\) និងតម្លៃតូចបំផុត \(y(-1) = y(2) = -4\) ។

ការអនុវត្តដេរីវេចំពោះវិសមីការដែលអង្គទី 1 ជាកន្សោមប៊ីការេ

ឧទាហរណ៍

គេឱ្យក្រាប \(C\) នៃ \(y = -x^4 - 2x^2 + 3\) ។ រកសំណុំឫសនៃវិសមីការ \(-x^4 - 2x^2 + 3 \ge 0\) តាមក្រាបហ្វិក ។

តាមក្រាប ចំណុច \((x, y)\) នៃក្រាបដែលមាន \(y \ge 0\) ត្រូវស្ថិតនៅផ្នែកខាងលើ ឬជួបនឹងអ័ក្សអាប់ស៊ីស ហើយត្រូវគ្នានឹង \(-1 \le x \le 1\) ។ ដូច្នេះ វិសមីការមានសំណុំឫស \(S = [-1, 1]\) ។

លំហាត់គំរូ

អនុគមន៍ \(y = -\dfrac{1}{2}x^4 + 3x^2 - \dfrac{5}{2}\) មានក្រាប \(C\) ។

  1. ដោះស្រាយវិសមីការ \(-\dfrac{1}{2}x^4 + 3x^2 - \dfrac{5}{2} < 0\) តាមក្រាប ។

  2. បង្ហាញថា \(0 < -\dfrac{1}{2}x^4 + 3x^2 - \dfrac{5}{2} \le 2\) ចំពោះ \(x \in (-\sqrt{5}, -1) \cup (1, \sqrt{5})\) តាមក្រាប ។

ដំណោះស្រាយ

  1. តាមក្រាប វិសមីការ \(-\dfrac{1}{2}x^4 + 3x^2 - \dfrac{5}{2} < 0\) មានសំណុំឫស \(S = (-\infty, -\sqrt{5}) \cup (-1, 1) \cup (\sqrt{5}, +\infty)\) ។

  2. តាមក្រាប ចំណុច \((x, y)\) នៃក្រាប \(C\) ដែលមាន \(0 < y \le 2\) ត្រូវស្ថិតនៅផ្នែកខាងលើអ័ក្សអាប់ស៊ីស ហើយប៉ះនឹងបន្ទាត់ \(y = 2\) ដែលត្រូវគ្នានឹង \(x \in (-\sqrt{5}, -1) \cup (1, \sqrt{5})\) ។ ដូច្នេះ \(0 < -\dfrac{1}{2}x^4 + 3x^2 - \dfrac{5}{2} \le 2\) ចំពោះ \(x \in (-\sqrt{5}, -1) \cup (1, \sqrt{5})\) ។

ជាទូទៅ

  • វិសមីការ \(ax^4 + bx^2 + c > 0\) មានសំណុំឫសជាសំណុំតម្លៃអាប់ស៊ីស \(x\) នៃចំណុចនៅលើក្រាបតាងអនុគមន៍ \(y = ax^4 + bx^2 + c\) ដែលស្ថិតនៅផ្នែកខាងលើអ័ក្សអាប់ស៊ីស ។

ប្រតិបត្តិ

អនុគមន៍ \(y = x^4 - 2x^2 + 1\) មានក្រាប \(C\) ។ ក. ដោះស្រាយវិសមីការ \(x^4 - 2x^2 + 1 > 0\) តាមក្រាប ។ ខ. បង្ហាញថា \(0 \le x^4 - 2x^2 + 1 \le 1\) ចំពោះ \(x \in [-\sqrt{2}, \sqrt{2}]\) ។

មើលចម្លើយ

ក. \(x \in \mathbb{R} - \{\pm 1\}\) ខ. លើ \([-\sqrt{2}, \sqrt{2}]\) អនុគមន៍មានតម្លៃតូចបំផុត \(y(\pm 1) = 0\) និងតម្លៃធំបំផុត \(y(0) = y(\pm\sqrt{2}) = 1\) ។

មេរៀនសង្ខេប ជំពូកទី ៥

មេរៀនសង្ខេប

  1. បើ \(x \to a\) ហើយ \(f(x) \to b\) នោះកំណត់សរសេរដោយ \(\displaystyle\lim_{x \to a} f(x) = b\) ។

  2. \(\displaystyle\lim_{x \to a} c = c\) ចំពោះគ្រប់ចំនួនថេរ \(c\) ។ \(\displaystyle\lim_{x \to a} x = a\) ។

  3. \(\displaystyle\lim_{x \to a}[f(x) \pm g(x)] = \lim_{x \to a} f(x) \pm \lim_{x \to a} g(x)\) ។ \(\displaystyle\lim_{x \to a}[f(x)\times g(x)] = \lim_{x \to a} f(x)\times\lim_{x \to a} g(x)\) ។

  4. \(\displaystyle\lim_{x \to a}\frac{f(x)}{g(x)} = \frac{\lim_{x \to a} f(x)}{\lim_{x \to a} g(x)}\) បើ \(\displaystyle\lim_{x \to a} g(x) \ne 0\) ។

  5. បើ \(\displaystyle\lim_{x \to x_0^-} f(x) = L\) នោះ \(L\) ជាលីមីតខាងឆ្វេងនៃ \(y = f(x)\) ។ បើ \(\displaystyle\lim_{x \to x_0^+} f(x) = R\) នោះ \(R\) ជាលីមីតខាងស្ដាំនៃ \(y = f(x)\) ។ \(f\) មានលីមីតត្រង់ \(x_0\) លុះត្រាតែ \(\displaystyle\lim_{x \to x_0^-} f(x) = \lim_{x \to x_0^+} f(x)\) ។

  6. លីមីតនៃអនុគមន៍ពហុធានៅត្រង់អនន្ត គឺជាលីមីតនៃតួដែលមានដឺក្រេធំជាងគេ ។ លីមីតនៃអនុគមន៍សនិទាននៅត្រង់អនន្ត គឺជាផលធៀបរវាងលីមីតនៃតួដែលមានដឺក្រេធំជាងគេនៅភាគយក និងលីមីតនៃតួដែលមានដឺក្រេធំជាងគេនៅភាគបែង ។

  7. ផលធៀប \(\dfrac{\Delta y}{\Delta x} = \dfrac{f(b) - f(a)}{b - a}\) ជាអត្រាបម្រែបម្រួលមធ្យមនៃ \(y = f(x)\) កាលណា \(x\) បម្រែបម្រួលពី \(a\) ទៅ \(b\) ។

  8. \(f'(a) = \displaystyle\lim_{h \to 0}\frac{f(a + h) - f(a)}{h}\) ជាដេរីវេនៃអនុគមន៍ \(y = f(x)\) នៅត្រង់ \(x = a\) ។

អនុគមន៍ \(y = x^3 - 3x^2\) មានក្រាប \(C\) ។ ក. សង់ក្រាប \(C\) នៃអនុគមន៍ ។ ខ. សិក្សាទៅតាមតម្លៃប៉ារ៉ាម៉ែត្រ \(m\) នូវអត្ថិភាព និងចំនួនឫសនៃសមីការ \(x^3 - 3x^2 = m\) តាមក្រាប ។

មើលដំណោះស្រាយ

ក. អតិបរមាធៀប \(y(0) = 0\), អប្បបរមាធៀប \(y(2) = -4\) ។ ខ. បើ \(m > 0\) ឬ \(m < -4\) ៖ ឫស \(1\) ។ បើ \(m = 0\) ៖ ឫសឌុប \(x = 0\) និងឫស \(x = 3\) ។ បើ \(-4 < m < 0\) ៖ ឫស \(3\) ផ្សេងគ្នា ។ បើ \(m = -4\) ៖ ឫសឌុប \(x = 2\) និងឫស \(x = -1\) ។

២លំហាត់ទី ២

អនុគមន៍ \(f\) កំណត់ដោយ \(f(x) = x^3 - 6x + 5\) ។ ក. សង់ក្រាបនៃ \(f\) ។ ខ. សិក្សាលើក្រាបទៅតាមតម្លៃ \(a\) នូវអត្ថិភាព និងសញ្ញាឫសនៃសមីការ \(x^3 - 6x + 5 - a = 0\) ។

មើលដំណោះស្រាយ

ក. អតិបរមាធៀប \(f(-\sqrt{2}) = 5 + 4\sqrt{2}\), អប្បបរមាធៀប \(f(\sqrt{2}) = 5 - 4\sqrt{2}\), \(f(0) = 5\) ។ ខ. \(a > 5 + 4\sqrt{2}\) ៖ ឫសវិជ្ជមានមួយ ។ \(a = 5 + 4\sqrt{2}\) ៖ ឫសឌុបអវិជ្ជមាន និងឫសវិជ្ជមានមួយ ។ \(5 < a < 5 + 4\sqrt{2}\) ៖ ឫសអវិជ្ជមានពីរ និងឫសវិជ្ជមានមួយ ។ \(a = 5\) ៖ ឫស \(0\), \(\pm\sqrt{6}\) ។ \(5 - 4\sqrt{2} < a < 5\) ៖ ឫសវិជ្ជមានពីរ និងឫសអវិជ្ជមានមួយ ។ \(a = 5 - 4\sqrt{2}\) ៖ ឫសឌុបវិជ្ជមាន និងឫសអវិជ្ជមានមួយ ។ \(a < 5 - 4\sqrt{2}\) ៖ ឫសអវិជ្ជមានមួយ ។

៣លំហាត់ទី ៣

គេឱ្យសមីការ \(2x^3 - 3x^2 - 12x - k = 0\) ដែលមានអញ្ញាត \(x\) និងប៉ារ៉ាម៉ែត្រ \(k\) ។ ក. រកតម្លៃ \(k\) ដើម្បីឱ្យសមីការមានឫសបីផ្សេងគ្នា ។ ខ. រកតម្លៃ \(k\) ដើម្បីឱ្យសមីការមានឫសវិជ្ជមានពីរផ្សេងគ្នា និងឫសអវិជ្ជមានមួយទៀត ។

មើលដំណោះស្រាយ

តាង \(g(x) = 2x^3 - 3x^2 - 12x\) មានអតិបរមាធៀប \(g(-1) = 7\) និងអប្បបរមាធៀប \(g(2) = -20\) ។ ក. \(-20 < k < 7\) ខ. \(-20 < k < 0\) ។

៤លំហាត់ទី ៤

អនុគមន៍ \(f\) កំណត់ដោយ \(f(x) = x^3 - 3x + 1\) មានក្រាប \(C\) ។ ក. សង់ក្រាប \(C\) នៃ \(f\) ។ ខ. សិក្សាលើក្រាបទៅតាមតម្លៃ \(p\) នូវអត្ថិភាព និងទីតាំងឫសនៃសមីការ \(f(x) = p\) ធៀបនឹងចំនួន \(-1\) និង \(1\) ។

មើលដំណោះស្រាយ

ក. អតិបរមាធៀប \(f(-1) = 3\), អប្បបរមាធៀប \(f(1) = -1\) ។ ខ. \(p > 3\) ៖ \(-1 < 1 < x_1\) ។ \(p = 3\) ៖ \(x_1 = x_2 = -1 < 1 < x_3\) ។ \(-1 < p < 3\) ៖ \(x_1 < -1 < x_2 < 1 < x_3\) ។ \(p = -1\) ៖ \(x_1 < -1 < 1 = x_2 = x_3\) ។ \(p < -1\) ៖ \(x_1 < -1 < 1\) ។

៥លំហាត់ទី ៥

ក. សង់ក្រាបនៃអនុគមន៍ \(y = \dfrac{3}{2}x^4 + \dfrac{1}{2}x^2 - 4\) ។ ខ. សិក្សាលើក្រាបទៅតាមតម្លៃ \(m\) នូវអត្ថិភាព និងទីតាំងឫសនៃសមីការ \(\dfrac{3}{2}x^4 + \dfrac{1}{2}x^2 - 4 - m = 0\) ធៀបនឹង \(-1\) និង \(2\) ។

មើលដំណោះស្រាយ

ក. អប្បបរមា \(y(0) = -4\) ។ \(y(\pm 1) = -2\), \(y(\pm 2) = 22\) ។ ខ. \(m < -4\) ៖ គ្មានឫស ។ \(m = -4\) ៖ ឫសឌុប \(x = 0\) ។ \(-4 < m < -2\) ៖ \(-1 < x_1 < x_2 < 2\) ។ \(m = -2\) ៖ \(x_1 = -1\), \(x_2 = 1\) ។ \(-2 < m < 22\) ៖ \(x_1 < -1 < x_2 < 2\) ។ \(m = 22\) ៖ \(x_1 = -2 < -1\), \(x_2 = 2\) ។ \(m > 22\) ៖ \(x_1 < -1\) និង \(x_2 > 2\) ។

៦លំហាត់ទី ៦

គេឱ្យសមីការ \(-2x^4 + 3x^2 - 1 = a\) ។ ក. រកតម្លៃ \(a\) ដើម្បីឱ្យសមីការមានឫសបួនផ្សេងគ្នា ។ ខ. រកតម្លៃ \(a\) ដើម្បីឱ្យសមីការគ្មានឫស ។

មើលដំណោះស្រាយ

អនុគមន៍ \(y = -2x^4 + 3x^2 - 1\) មានអតិបរមា \(y\left(\pm\dfrac{\sqrt{3}}{2}\right) = \dfrac{1}{8}\) និងអប្បបរមាធៀប \(y(0) = -1\) ។ ក. \(-1 < a < \dfrac{1}{8}\) ខ. \(a > \dfrac{1}{8}\) ។

៧លំហាត់ទី ៧

ក. សង់ក្រាបនៃអនុគមន៍ \(f(x) = -\dfrac{1}{3}x^3 + 2x^2 - 3x - 1\) ។ ខ. ដោះស្រាយវិសមីការ \(f(x) + 1 \le 0\) តាមក្រាប ។

មើលដំណោះស្រាយ

ក. អប្បបរមាធៀប \(f(1) = -\dfrac{7}{3}\), អតិបរមាធៀប \(f(3) = -1\) ។ ខ. \(f(x) + 1 = -\dfrac{x}{3}(x - 3)^2 \le 0\) ៖ \(x \in [0, +\infty)\) ។

៨លំហាត់ទី ៨

អនុគមន៍ \(y = x^3 + 3x^2 - 4\) មានក្រាប \(C\) ។ ក. សង់ក្រាប \(C\) នៃអនុគមន៍ ។ ខ. បង្ហាញថា \(x^3 + 3x^2 - 4 \le 0\) ចំពោះ \(x \le -2\) ។

មើលដំណោះស្រាយ

ក. អតិបរមាធៀប \(y(-2) = 0\), អប្បបរមាធៀប \(y(0) = -4\) ។ ខ. \(x^3 + 3x^2 - 4 = (x - 1)(x + 2)^2 \le 0\) ព្រោះ \(x - 1 < 0\) និង \((x + 2)^2 \ge 0\) ចំពោះ \(x \le -2\) ។

៩លំហាត់ទី ៩

គេឱ្យក្រាប \(C\) នៃអនុគមន៍ \(y = \dfrac{1}{2}x^4 + x^2 - \dfrac{3}{2}\) ។ ក. ដោះស្រាយវិសមីការ \(\dfrac{1}{2}x^4 + x^2 - \dfrac{3}{2} \ge 0\) តាមក្រាប ។ ខ. បង្ហាញថា \(\dfrac{1}{2}x^4 + x^2 - \dfrac{3}{2} < 0\) ចំពោះ \(x \in (-1, 1)\) ។

មើលដំណោះស្រាយ

\(y = \dfrac{1}{2}(x^2 + 3)(x^2 - 1)\) ៖ ក. \(x \in (-\infty, -1] \cup [1, +\infty)\) ខ. ចំពោះ \(x \in (-1, 1)\), \(x^2 - 1 < 0\) ដូច្នេះ \(y < 0\) ។

១០លំហាត់ទី ១០

\(f\) ជាអនុគមន៍កំណត់ដោយ \(f(x) = -x^4 + 2x^2 - 2\) ។ ក. សង់ក្រាបនៃ \(f\) ។ ខ. ដោះស្រាយទ្វេវិសមីការ \(-2 \le f(x) \le -1\) តាមក្រាប រួចតាមពីជគណិត ។ គ. បង្ហាញថា \(f(x) < -2\) ចំពោះ \(x \in (-\infty, -\sqrt{2}) \cup (\sqrt{2}, +\infty)\) តាមក្រាប ។

មើលដំណោះស្រាយ

ក. អតិបរមា \(f(\pm 1) = -1\), អប្បបរមាធៀប \(f(0) = -2\) ។ ខ. \(f(x) \le -1\) ពិតជានិច្ច ព្រោះ \(f(x) + 1 = -(x^2 - 1)^2 \le 0\) ។ \(f(x) \ge -2 \Leftrightarrow x^2(2 - x^2) \ge 0 \Leftrightarrow x \in [-\sqrt{2}, \sqrt{2}]\) ។ គ. ចំពោះ \(|x| > \sqrt{2}\), \(f(x) + 2 = x^2(2 - x^2) < 0\) ។

១១លំហាត់ទី ១១

ក. សង់ក្រាប \(C_1\) នៃ \(y = 3x^4 + 1\) និង \(C_2\) នៃ \(y = 8x^3 - 18x^2\) នៅក្នុងតម្រុយតែមួយ ។ ខ. បង្ហាញថា \(3x^4 + 1 > 8x^3 - 18x^2\) ចំពោះ \(x \ge 0\) តាមក្រាប ។ គ. រកដេរីវេនៃអនុគមន៍ \(f(x) = 3x^4 - 8x^3 + 18x^2 + 1\) និងគណនា \(f(0)\) ។ ឃ. បង្ហាញថា \(f(x) > 0\) ចំពោះ \(x \ge 0\) ហើយទាញបញ្ជាក់ថា \(3x^4 + 1 > 8x^3 - 18x^2\) ចំពោះ \(x \ge 0\) ។

មើលដំណោះស្រាយ

គ. \(f'(x) = 12x^3 - 24x^2 + 36x = 12x(x^2 - 2x + 3)\) និង \(f(0) = 1\) ។ ឃ. ដោយ \(x^2 - 2x + 3 = (x - 1)^2 + 2 > 0\) នោះ \(f'(x) \ge 0\) ចំពោះ \(x \ge 0\) ។ \(f\) កើនលើ \([0, +\infty)\) នាំឱ្យ \(f(x) \ge f(0) = 1 > 0\) ។ ដូច្នេះ \(3x^4 + 1 > 8x^3 - 18x^2\) ចំពោះ \(x \ge 0\) ។
