អនុគមន៍កើន និង អនុគមន៍ចុះ

ការសិក្សាលើទិសដៅអថេរភាពនៃអនុគមន៍ គឺជាការកំណត់ចន្លោះដែលអនុគមន៍កើន ឬចុះ ដោយផ្អែកលើសញ្ញានៃដេរីវេទីមួយ \(f'(x)\)។

និយមន័យ និងទ្រឹស្តីបទគ្រឹះ

ជាទូទៅ

គេឱ្យ \(f\) ជាអនុគមន៍ជាប់លើចន្លោះ \([a, b]\) និងមានដេរីវេលើចន្លោះបើក \((a, b)\)៖

  • បើគ្រប់ \(x \in (a, b), f'(x) > 0\) នោះអនុគមន៍ \(f\) ជាអនុគមន៍កើនដាច់ខាត លើចន្លោះ \([a, b]\)។

  • បើគ្រប់ \(x \in (a, b), f'(x) < 0\) នោះអនុគមន៍ \(f\) ជាអនុគមន៍ចុះដាច់ខាត លើចន្លោះ \([a, b]\)។

  • បើគ្រប់ \(x \in (a, b), f'(x) = 0\) នោះអនុគមន៍ \(f\) ជាអនុគមន៍ថេរ លើចន្លោះ \([a, b]\)។

សម្រាយបញ្ជាក់៖ យកពីរតម្លៃ \(x_1, x_2 \in [a, b]\) តាមចិត្តដែល \(x_1 < x_2\)។ ដោយសារអនុគមន៍ \(f\) ជាប់លើចន្លោះបិទ \([x_1, x_2]\) និងមានដេរីវេលើចន្លោះបើក \((x_1, x_2)\) តាមទ្រឹស្តីបទតម្លៃមធ្យម (MVT) មានចំនួនពិត \(c \in (x_1, x_2)\) មួយយ៉ាងតិចដែលផ្ទៀងផ្ទាត់៖

\[\dfrac{f(x_2) - f(x_1)}{x_2 - x_1} = f'(c) \iff f(x_2) - f(x_1) = f'(c)(x_2 - x_1)\]
ដោយ \(x_1 < x_2 \implies x_2 - x_1 > 0\)៖

  • បើគ្រប់ \(x \in (a, b), f'(x) > 0\) នោះ \(f'(c) > 0\) នាំឱ្យ \(f(x_2) - f(x_1) > 0 \implies f(x_1) < f(x_2)\)។ ដូចនេះ \(f\) ជាអនុគមន៍កើនដាច់ខាតលើ \([a, b]\)។

  • បើគ្រប់ \(x \in (a, b), f'(x) < 0\) នោះ \(f'(c) < 0\) នាំឱ្យ \(f(x_2) - f(x_1) < 0 \implies f(x_1) > f(x_2)\)។ ដូចនេះ \(f\) ជាអនុគមន៍ចុះដាច់ខាតលើ \([a, b]\)។

  • បើគ្រប់ \(x \in (a, b), f'(x) = 0\) នោះ \(f'(c) = 0\) នាំឱ្យ \(f(x_2) - f(x_1) = 0 \implies f(x_1) = f(x_2)\)។ ដូចនេះ \(f\) ជាអនុគមន៍ថេរលើ \([a, b]\)។ \(\blacksquare\)

ចំណុចប្រសព្វសំខាន់ (Critical Numbers)

ចំនួនប្រសព្វសំខាន់

ចំនួន \(c\) ក្នុងដែនកំណត់នៃអនុគមន៍ \(f\) ហៅថាជា ចំនួនប្រសព្វសំខាន់ (Critical Number) កាលណា \(f'(c) = 0\) ឬ \(f'(c)\) មិនមាន។ ចំណុច \(P(c, f(c))\) ហៅថា ចំណុចប្រសព្វសំខាន់ (Critical Point)។

ឧទាហរណ៍

សិក្សាទិសដៅអថេរភាព និងរកចន្លោះកើន ចុះ នៃអនុគមន៍ \(f(x) = 2x^3 - 3x^2 - 12x + 5\)។

ដំណោះស្រាយ

- ដែនកំណត់៖ \(D = \mathbb{R}\)។ - ដេរីវេទីមួយ៖ \(f'(x) = 6x^2 - 6x - 12 = 6(x^2 - x - 2) = 6(x+1)(x-2)\)។ - ឱ្យ \(f'(x) = 0 \iff 6(x+1)(x-2) = 0 \implies x = -1 \) ឬ \( x = 2\)។ - តារាងសញ្ញា \(f'(x)\)៖

\(x\) \(-\infty\) \(-1\) \(2\) \(+\infty\)
\(f'(x)\) \(+\) \(0\) \(-\) \(0\) \(+\)

សន្និដ្ឋាន៖ - អនុគមន៍ \(f\) កើនលើចន្លោះ \((-\infty, -1]\) និង \([2, +\infty)\) ពីព្រោះ \(f'(x) > 0\)។ - អនុគមន៍ \(f\) ចុះលើចន្លោះ \([-1, 2]\) ពីព្រោះ \(f'(x) < 0\)។

ភាពប៉ោង និងភាពផត (Concavity)

ជាទូទៅ

គេឱ្យអនុគមន៍ \(f\) មានដេរីវេទីពីរ \(f''(x)\) លើចន្លោះ \(I\)៖

  • បើគ្រប់ \(x \in I, f''(x) > 0\) នោះក្រាបនៃ \(f\) ផត (ប៉ោងឡើងលើ / Concave Up) លើ \(I\) (ខ្សែកោងស្ថិតនៅខាងលើបន្ទាត់ប៉ះ)។

  • បើគ្រប់ \(x \in I, f''(x) < 0\) នោះក្រាបនៃ \(f\) ប៉ោង (ប៉ោងចុះក្រោម / Concave Down) លើ \(I\) (ខ្សែកោងស្ថិតនៅខាងក្រោមបន្ទាត់ប៉ះ)។

សម្រាយបញ្ជាក់៖ តាង \((T)\) ជាបន្ទាត់ប៉ះក្រាប \(y = f(x)\) ត្រង់ \(x_0 \in I\) មានសមីការ \(y_T = f(x_0) + f'(x_0)(x - x_0)\)។ ពិនិត្យគម្លាតបញ្ឈររវាងខ្សែកោង និងបន្ទាត់ប៉ះ៖ \(g(x) = f(x) - y_T = f(x) - f(x_0) - f'(x_0)(x - x_0)\)។ តាមទ្រឹស្តីបទតម្លៃមធ្យម អនុវត្តលើ \(f(x) - f(x_0)\) មាន \(c_1\) នៅចន្លោះ \(x_0\) និង \(x\) ដែល \(f(x) - f(x_0) = f'(c_1)(x - x_0)\)។ គេបាន៖

\[g(x) = [f'(c_1) - f'(x_0)](x - x_0)\]
អនុវត្តទ្រឹស្តីបទតម្លៃមធ្យមម្តងទៀតលើអនុគមន៍ \(f'\) ចន្លោះ \(x_0\) និង \(c_1\) មាន \(c\) នៅចន្លោះ \(x_0\) និង \(c_1\) ដែល៖
\[f'(c_1) - f'(x_0) = f''(c)(c_1 - x_0)\]
ដោយ \(c_1\) ស្ថិតនៅចន្លោះ \(x_0\) និង \(x\) នាំឱ្យ \((c_1 - x_0)\) និង \((x - x_0)\) មានសញ្ញាដូចគ្នា ហេតុនេះ \((c_1 - x_0)(x - x_0) > 0\) ចំពោះគ្រប់ \(x \neq x_0\)។ នាំឱ្យ \(g(x) = f''(c)(c_1 - x_0)(x - x_0)\) មានសញ្ញាដូចគ្នានឹង \(f''(c)\)៖

  • បើ \(f''(x) > 0\) នោះ \(g(x) > 0 \iff f(x) > y_T\) (ខ្សែកោងស្ថិតនៅខាងលើបន្ទាត់ប៉ះ \(\implies\) ក្រាបផតឡើងលើ)។

  • បើ \(f''(x) < 0\) នោះ \(g(x) < 0 \iff f(x) < y_T\) (ខ្សែកោងស្ថិតនៅខាងក្រោមបន្ទាត់ប៉ះ \(\implies\) ក្រាបប៉ោងចុះក្រោម)។ \(\blacksquare\)

ចំណុចរបត់ (Inflection Point)

ជាទូទៅ

ចំណុច \(I(x_0, f(x_0))\) ហៅថា ចំណុចរបត់ នៃក្រាបតាងអនុគមន៍ \(f\) កាលណាដេរីវេទីពីរ \(f''(x_0) = 0\) (ឬ គ្មានដេរីវេទីពីរ) ហើយ \(f''(x)\) ផ្លាស់ប្តូរសញ្ញានៅពេលឆ្លងកាត់ចំណុច \(x_0\)។

ការបកស្រាយ និងសម្រាយបញ្ជាក់៖ តាមនិយមន័យធរណីមាត្រ ចំណុចរបត់គឺជាចំណុចដែលខ្សែកោងផ្លាស់ប្តូរភាពកោងពីផតទៅប៉ោង (ឬពីប៉ោងទៅផត)៖

  • នៅពេល \(x < x_0\) ប្រសិនបើ \(f''(x) > 0\) (ក្រាបផតឡើងលើ) ហើយនៅពេល \(x > x_0\) នាំឱ្យ \(f''(x) < 0\) (ក្រាបប៉ោងចុះក្រោម) ឬច្រាសមកវិញ។

  • បើ \(f''\) ជាអនុគមន៍ជាប់ត្រង់ \(x_0\) នោះការផ្លាស់ប្តូរសញ្ញាពីវិជ្ជមានទៅអវិជ្ជមាន (ឬច្រាសមកវិញ) តម្រូវឱ្យ \(f''\) កាត់តម្លៃ \(0\) តាមទ្រឹស្តីបទតម្លៃកណ្តាល ពោលគឺ \(f''(x_0) = 0\)។

  • ត្រង់ចំណុចរបត់នេះ បន្ទាត់ប៉ះផ្លាស់ប្តូរទីតាំងពីស្ថិតនៅក្រោមខ្សែកោងទៅនៅខាងលើខ្សែកោង (ឬច្រាសមកវិញ) ពោលគឺ បន្ទាត់ប៉ះកាត់ខ្សែកោង ត្រង់ចំណុចរបត់ \(I\) នោះ។ \(\blacksquare\)

រកចន្លោះប៉ោង ចន្លោះផត និងកូអរដោនេចំណុចរបត់នៃក្រាប \(f(x) = x^3 - 6x^2 + 9x + 1\)។

ដំណោះស្រាយ

- ដេរីវេទីមួយ៖ \(f'(x) = 3x^2 - 12x + 9\) - ដេរីវេទីពីរ៖ \(f''(x) = 6x - 12 = 6(x - 2)\) - ឱ្យ \(f''(x) = 0 \iff 6(x - 2) = 0 \implies x = 2\) - ចំពោះ \(x < 2 \implies f''(x) < 0 \implies\) ក្រាបប៉ោងចុះក្រោម (Concave Down) លើ \((-\infty, 2)\) - ចំពោះ \(x > 2 \implies f''(x) > 0 \implies\) ក្រាបផតឡើងលើ (Concave Up) លើ \((2, +\infty)\) - ដោយ \(f''(x)\) ប្តូរសញ្ញាឆ្លងកាត់ \(x = 2\) នោះក្រាបមានចំណុចរបត់ត្រង់ \(x = 2\)៖ \(y = f(2) = 2^3 - 6(2)^2 + 9(2) + 1 = 8 - 24 + 18 + 1 = 3 \implies I(2, 3)\)។

ចំណុចអតិបរមា និង អប្បបរមា (Extrema)

តេស្តដេរីវេទី ១ និង តេស្តដេរីវេទី ២

វិធីសាស្ត្រ តេស្តដេរីវេទី ១ (\(f'(x)\)) តេស្តដេរីវេទី ២ (\(f''(x)\)) ប្រភេទបរមា
អតិបរមាធៀប \(f'(x)\) ប្តូរសញ្ញាពី \((+)\) ទៅ \((-)\) ឆ្លងកាត់ \(x_0\) \(f'(x_0) = 0\) និង \(f''(x_0) < 0\) \(M(x_0, f(x_0))\)
អប្បបរមាធៀប \(f'(x)\) ប្តូរសញ្ញាពី \((-)\) ទៅ \((+)\) ឆ្លងកាត់ \(x_0\) \(f'(x_0) = 0\) និង \(f''(x_0) > 0\) \(m(x_0, f(x_0))\)
គ្មានបរមា \(f'(x)\) មិនប្តូរសញ្ញា \(f'(x_0)=0\) និង \(f''(x_0)=0\) (មិនអាចសន្និដ្ឋាន) គ្មានបរមា

បរមាដាច់ខាតលើចន្លោះបិទ \([a, b]\)

ដើម្បីរកតម្លៃអតិបរមាដាច់ខាត និងអប្បបរមាដាច់ខាតនៃអនុគមន៍ជាប់ \(f\) លើចន្លោះបិទ \([a, b]\)៖

  1. រកតម្លៃ \(f(c)\) ចំពោះគ្រប់ចំនួនប្រសព្វសំខាន់ \(c \in (a, b)\) ដែល \(f'(c) = 0\) ឬ \(f'(c)\) គ្មាន។

  2. គណនាតម្លៃនៃអនុគមន៍ត្រង់ចុងចន្លោះ៖ \(f(a)\) និង \(f(b)\)។

  3. តម្លៃធំបំផុតក្នុងចំណោមតម្លៃទាំងនេះ ជា អតិបរមាដាច់ខាត ហើយតម្លៃតូចបំផុតជា អប្បបរមាដាច់ខាត។

ទ្រឹស្តីបទរ៉ូល និងទ្រឹស្តីបទតម្លៃមធ្យម

ទ្រឹស្តីបទរ៉ូល (Rolle’s Theorem)

ជាទូទៅ

បើអនុគមន៍ \(f\) ផ្ទៀងផ្ទាត់លក្ខខណ្ឌទាំង ៣៖

  1. \(f\) ជាប់លើចន្លោះបិទ \([a, b]\)

  2. \(f\) មានដេរីវេលើចន្លោះបើក \((a, b)\)

  3. \(f(a) = f(b)\)

នោះមានយ៉ាងហោចណាស់ចំនួនមួយ \(c \in (a, b)\) ដែល \(f'(c) = 0\) (មានបន្ទាត់ប៉ះដេក)។

សម្រាយបញ្ជាក់៖ ដោយសារអនុគមន៍ \(f\) ជាប់លើចន្លោះបិទ \([a, b]\) តាមទ្រឹស្តីបទតម្លៃបរមា (Extreme Value Theorem) អនុគមន៍ \(f\) ត្រូវតែមានតម្លៃអតិបរមាដាច់ខាត \(M\) និងតម្លៃអប្បបរមាដាច់ខាត \(m\) លើ \([a, b]\)៖

  • ករណីទី ១៖ បើ \(M = m\) នោះអនុគមន៍ \(f\) ជាអនុគមន៍ថេរលើ \([a, b]\) ពោលគឺ \(f(x) = M\) គ្រប់ \(x \in [a, b]\)។ ហេតុនេះ \(f'(c) = 0\) ចំពោះគ្រប់ចំនួន \(c \in (a, b)\)។

  • ករណីទី ២៖ បើ \(M > m\) ដោយសារលក្ខខណ្ឌ \(f(a) = f(b)\) តម្លៃបរមាទាំងពីរ \(M\) និង \(m\) មិនអាចកើតឡើងដំណាលគ្នានៅចុងចន្លោះ \(a\) និង \(b\) បានឡើយ។ ដូច្នេះយ៉ាងហោចណាស់មានបរមាមួយ (\(M\) ឬ \(m\)) ត្រូវតែកើតឡើងត្រង់ចំណុច \(c \in (a, b)\) ខាងក្នុងចន្លោះ។ ដោយ \(f\) មានដេរីវេត្រង់ \(c\) នោះតាមទ្រឹស្តីបទ Fermat ចំពោះតម្លៃបរមាធៀប នាំឱ្យ \(f'(c) = 0\)។

ដូចនេះ ជានិច្ចកាលមានយ៉ាងហោចណាស់ \(c \in (a, b)\) មួយដែល \(f'(c) = 0\)។ \(\blacksquare\)

ទ្រឹស្តីបទតម្លៃមធ្យម (Mean Value Theorem - MVT)

ជាទូទៅ

បើអនុគមន៍ \(f\) ជាប់លើ \([a, b]\) និងមានដេរីវេលើ \((a, b)\) នោះមានយ៉ាងហោចណាស់ចំនួនមួយ \(c \in (a, b)\) ដែល៖

\[f'(c) = \dfrac{f(b) - f(a)}{b - a} \iff f(b) - f(a) = f'(c)(b - a)\]
ន័យធរណីមាត្រ៖ មានចំណុចយ៉ាងហោចណាស់មួយលើខ្សែកោង ដែលបន្ទាត់ប៉ះត្រង់ចំណុចនោះស្របនឹងខ្សែធ្នូតភ្ជាប់ចំណុចចុង \((a, f(a))\) និង \((b, f(b))\)។

សម្រាយបញ្ជាក់៖ បន្ទាត់ធ្នូតកាត់តាមចំណុច \(A(a, f(a))\) និង \(B(b, f(b))\) មានសមីការ \(y = f(a) + \dfrac{f(b)-f(a)}{b-a}(x - a)\)។ ពិចារណាលើអនុគមន៍ជំនួយ \(g(x)\) តាងឱ្យគម្លាតបញ្ឈររវាងខ្សែកោង និងបន្ទាត់ធ្នូត៖

\[g(x) = f(x) - f(a) - \dfrac{f(b) - f(a)}{b - a}(x - a)\]

  1. \(g\) ជាប់លើចន្លោះបិទ \([a, b]\) (ផលដកនៃអនុគមន៍ជាប់)។

  2. \(g\) មានដេរីវេលើចន្លោះបើក \((a, b)\) ដោយ \(g'(x) = f'(x) - \dfrac{f(b) - f(a)}{b - a}\)។

  3. គណនាតម្លៃត្រង់ចុងចន្លោះ៖ \(g(a) = f(a) - f(a) - 0 = 0\) \(g(b) = f(b) - f(a) - \dfrac{f(b) - f(a)}{b - a}(b - a) = 0 \implies g(a) = g(b) = 0\)។

អនុគមន៍ \(g\) ផ្ទៀងផ្ទាត់លក្ខខណ្ឌទាំង ៣ នៃទ្រឹស្តីបទរ៉ូល ដូច្នេះមាន \(c \in (a, b)\) មួយយ៉ាងតិចដែល \(g'(c) = 0\)៖

\[g'(c) = 0 \iff f'(c) - \dfrac{f(b) - f(a)}{b - a} = 0 \iff f'(c) = \dfrac{f(b) - f(a)}{b - a} \quad{} \blacksquare\]

វិធានឡូពីតាល់ (L’Hôpital’s Rule)

ទម្រង់មិនកំណត់ \(\dfrac{0}{0}\) និង \(\dfrac{\infty}{\infty}\)

ជាទូទៅ

ឧបមាថា \(f\) និង \(g\) មានដេរីវេលើចន្លោះបើកដែលមានចំណុច \(a\) (លើកលែងត្រង់ \(a\)) ហើយ \(g'(x) \neq 0\)។ បើ \(\lim_{x \to a} f(x) = 0\) និង \(\lim_{x \to a} g(x) = 0\) ឬ \(\lim_{x \to a} f(x) = \pm\infty\) និង \(\lim_{x \to a} g(x) = \pm\infty\) នោះ៖

\[\lim_{x \to a} \dfrac{f(x)}{g(x)} = \lim_{x \to a} \dfrac{f'(x)}{g'(x)}\]
(លុះត្រាតែលីមីតខាងស្តាំមាន ឬស្មើ \(\pm\infty\))។

សម្រាយបញ្ជាក់ (ចំពោះទម្រង់មិនកំណត់ \(\frac{0}{0}\))៖ ឧបមាថា \(\lim_{x \to a} f(x) = 0\) និង \(\lim_{x \to a} g(x) = 0\)។ យើងកំណត់បន្ថែមតម្លៃ \(f(a) = 0\) និង \(g(a) = 0\) ដើម្បីឱ្យ \(f\) និង \(g\) ក្លាយជាអនុគមន៍ជាប់ត្រង់ \(a\)។ ចំពោះ \(x > a\) (ករណី \(x < a\) ស្រាយដូចគ្នា) អនុគមន៍ \(f\) និង \(g\) ជាប់លើ \([a, x]\) និងមានដេរីវេលើ \((a, x)\)។ តាមទ្រឹស្តីបទតម្លៃមធ្យមកូស៊ី (Cauchy’s Extended MVT) មាន \(c \in (a, x)\) មួយដែល៖

\[\dfrac{f(x) - f(a)}{g(x) - g(a)} = \dfrac{f'(c)}{g'(c)} \iff \dfrac{f(x)}{g(x)} = \dfrac{f'(c)}{g'(c)} \quad{} (\text{ព្រោះ } f(a)=g(a)=0)\]
នៅពេល \(x \to a^+\) ដោយសារ \(a < c < x\) តាមទ្រឹស្តីបទគៀប នាំឱ្យ \(c \to a^+\) ដែរ។ យកលីមីតនៃអង្គទាំងពីរកាលណា \(x \to a^+\) គេទាញបាន៖
\[\lim_{x \to a^+} \dfrac{f(x)}{g(x)} = \lim_{c \to a^+} \dfrac{f'(c)}{g'(c)} = \lim_{x \to a^+} \dfrac{f'(x)}{g'(x)}\]
ដូចគ្នាដែរចំពោះលីមីតខាងឆ្វេង (\(x \to a^-\)) នាំឱ្យបានរូបមន្តទូទៅ៖ \(\lim_{x \to a} \dfrac{f(x)}{g(x)} = \lim_{x \to a} \dfrac{f'(x)}{g'(x)}\)។ \(\blacksquare\)

ទម្រង់មិនកំណត់ដទៃទៀត

  • ទម្រង់ \(0 \cdot \infty\)៖ សរសេរ \(f(x) \cdot g(x) = \dfrac{f(x)}{1/g(x)}\) ដើម្បីបម្លែងជា \(\dfrac{0}{0}\) ឬ \(\dfrac{\infty}{\infty}\)។

  • ទម្រង់ \(\infty - \infty\)៖ តម្រូវភាគបែងរួម ឬបំបែកជាផលគុណដើម្បីបម្លែងជាផលធៀប។

  • ទម្រង់ស្វ័យគុណ \(1^\infty, 0^0, \infty^0\)៖ តាង \(y = [f(x)]^{g(x)} \implies \ln y = g(x) \ln f(x)\) រួចគណនាលីមីតនៃ \(\ln y\) តាមទម្រង់ \(0 \cdot \infty\) រួចទាញរក \(\lim y = e^L\)។

ឧទាហរណ៍

គណនាលីមីតខាងក្រោមតាមវិធានឡូពីតាល់៖

  1. \(\lim\limits_{x \to 0} \dfrac{e^{2x} - 1}{\sin(3x)}\)

  2. \(\lim\limits_{x \to 0} \dfrac{x - \sin x}{x^3}\)

  3. \(\lim\limits_{x \to +\infty} x e^{-x}\)

ដំណោះស្រាយ

  1. រាង \(\dfrac{0}{0}\)៖

    \[\lim\limits_{x \to 0} \dfrac{e^{2x} - 1}{\sin(3x)} = \lim\limits_{x \to 0} \dfrac{2e^{2x}}{3\cos(3x)} = \dfrac{2(1)}{3(1)} = \dfrac{2}{3}\]

  2. រាង \(\dfrac{0}{0}\)៖ តាមវិធានឡូពីតាល់លើកទីមួយ

    \[\lim\limits_{x \to 0} \dfrac{x - \sin x}{x^3} = \lim\limits_{x \to 0} \dfrac{1 - \cos x}{3x^2} \quad{} \left(\text{រាង } \dfrac{0}{0}\right)\]
    អនុវត្តវិធានឡូពីតាល់លើកទីពីរ៖
    \[= \lim\limits_{x \to 0} \dfrac{\sin x}{6x} = \dfrac{1}{6} \lim\limits_{x \to 0} \dfrac{\sin x}{x} = \dfrac{1}{6}\]

  3. រាង \(\infty \cdot 0\)៖ សរសេរជាផលធៀប

    \[\lim\limits_{x \to +\infty} x e^{-x} = \lim\limits_{x \to +\infty} \dfrac{x}{e^x} \quad{} \left(\text{រាង } \dfrac{\infty}{\infty}\right)\]
    អនុវត្តវិធានឡូពីតាល់៖
    \[= \lim\limits_{x \to +\infty} \dfrac{1}{e^x} = 0\]

អនុវត្តន៍ក្នុងការគណនាតម្លៃបរមា (Applied Optimization)

វិធីសាស្ត្រ ៥ ជំហានក្នុងការដោះស្រាយចំណោទបរមា

  1. អានប្រធានឱ្យយល់ច្បាស់ គូររូបតាង (បើមាន) និងកំណត់អថេរព្រមទាំងលក្ខខណ្ឌរបស់វា។

  2. កំណត់កន្សោមអនុគមន៍ដែលត្រូវរកបរមា (អតិបរមា ឬអប្បបរមា)។

  3. បង្កើតសមីការទំនាក់ទំនង (សម្មតិកម្ម) ដើម្បីបំប្លែងអនុគមន៍នោះឱ្យមានតែមួយអថេរ។

  4. គណនាដេរីវេទីមួយ \(f'(x)\) រកចំនួនប្រសព្វសំខាន់ \(f'(x) = 0\) ក្នុងដែនកំណត់។

  5. ប្រើតេស្តដេរីវេទីមួយ ឬទីពីរ ដើម្បីបញ្ជាក់ថាតម្លៃនោះជាអតិបរមា ឬអប្បបរមាពិតប្រាកដ រួចឆ្លើយសំនួរ។

កសិករម្នាក់មានសំណាញ់លួសប្រវែង \(120\) m សម្រាប់ធ្វើរបងព័ទ្ធដីចតុកោណកែងមួយកន្លែង ដោយមានជញ្ជាំងថ្មត្រង់មួយជ្រុងស្រាប់ (មិនបាច់ធ្វើរបងលើជ្រុងនោះទេ)។ ចូរកំណត់វិមាត្រនៃដីដើម្បីឱ្យផ្ទៃក្រឡាទទួលបានធំបំផុត។

ដំណោះស្រាយ

តាង \(x\) ជាប្រវែងជ្រុងទាំងពីរដែលកែងនឹងជញ្ជាំង (\(x > 0\))។ ជ្រុងស្របនឹងជញ្ជាំងមានប្រវែង \(y = 120 - 2x\) (ដោយ \(120 - 2x > 0 \implies 0 < x < 60\))។ ផ្ទៃក្រឡាដីចតុកោណកែងគឺ៖

\[A(x) = x \cdot y = x(120 - 2x) = 120x - 2x^2\]
ដេរីវេទីមួយ៖ \(A'(x) = 120 - 4x\) ឱ្យ \(A'(x) = 0 \iff 120 - 4x = 0 \implies x = 30\) m។ ដេរីវេទីពីរ៖ \(A''(x) = -4 < 0 \implies\) ផ្ទៃក្រឡាមានតម្លៃអតិបរមាពិតប្រាកដត្រង់ \(x = 30\) m។ វិមាត្រដីគឺ៖ ទទឹង \(x = 30\) m និងបណ្តោយ \(y = 120 - 2(30) = 60\) m។ ផ្ទៃក្រឡាអតិបរមាគឺ \(A_{\max} = 30 \times 60 = 1800\text{ m}^2\)។

ចលនាក្នុងរូបវិទ្យា និងអត្រាបម្រែបម្រួលប្រទាក់ក្រឡា

អនុវត្តន៍លើចលនាត្រង់ (Kinematics)

បើវត្ថុមួយផ្លាស់ទីលើបន្ទាត់ត្រង់មួយ មានសមីការទីតាំង \(s(t)\) នៅខណៈពេល \(t\) (\(t \ge 0\))៖

  • ល្បឿនខណៈ (Velocity)៖ \(v(t) = s'(t) = \dfrac{ds}{dt}\)

  • ល្បឿនស្កាលែរ (Speed)៖ \(|v(t)|\)

  • សំទុះខណៈ (Acceleration)៖ \(a(t) = v'(t) = s''(t) = \dfrac{d^2s}{dt^2}\)

  • វត្ថុឈប់ស្ងៀម (ឬប្តូរទិសដៅ) នៅពេល \(v(t) = 0\)។

  • វត្ថុផ្លាស់ទីស្ទុះលឿន (Speeding Up) កាលណា \(v(t) \cdot a(t) > 0\)។

  • វត្ថុផ្លាស់ទីយឺត (Slowing Down) កាលណា \(v(t) \cdot a(t) < 0\)។

លំហាត់ទី ៣ ៖ ដែនកំណត់ \(D = \mathbb{R} \setminus \{1\}\)។

\[\begin{aligned} f'(x) &= \frac{(2x - 4)(x - 1) - (x^2 - 4x + 4)(1)}{(x - 1)^2} \\ &= \frac{x^2 - 2x}{(x - 1)^2} = \frac{x(x - 2)}{(x - 1)^2} \end{aligned}\]
\(f'(x) = 0 \iff x = 0\) ឬ \(x = 2\)។

  • \(f\) កើនលើ \((-\infty, 0) \cup (2, +\infty)\)

  • \(f\) ចុះលើ \((0, 1) \cup (1, 2)\)

  • អតិបរមាធៀបត្រង់ \(x = 0\) គឺ \(f(0) = -4\)

  • អប្បបរមាធៀបត្រង់ \(x = 2\) គឺ \(f(2) = 0\)

លំហាត់ទី ៤ ៖ ចំពោះ \(x > 0\) ៖ \(f'(x) = 1 - \dfrac{4}{x^2} = \dfrac{x^2 - 4}{x^2}\)។
\(f'(x) = 0 \iff x^2 = 4 \implies x = 2\) (ព្រោះ \(x > 0\))។
ដោយ \(f''(x) = \dfrac{8}{x^3} > 0\) គ្រប់ \(x > 0\) នាំឱ្យ \(f\) មានអប្បបរមាធៀបត្រង់ \(x = 2\) គឺ ៖

\[f(2) = 2 + \frac{4}{2} = 4\]

លំហាត់ទី ៥ ៖ គេមាន \(f'(x) = (x)' e^{-x} + x(e^{-x})' = e^{-x} - x e^{-x} = (1 - x)e^{-x}\)។
ដោយ \(e^{-x} > 0\) គ្រប់ \(x \in \mathbb{R}\) នោះសញ្ញា \(f'(x)\) អាស្រ័យនឹង \((1 - x)\) ៖

\(3(t^2 - 6t + 8) = 0 \iff 3(t - 2)(t - 4) = 0 \iff t = 2\text{ s}\) ឬ \(t = 4\text{ s}\)។

លំហាត់ទី ៤៤ ៖ ចលនាស្ទុះលឿនកាលណា \(v(t) \cdot a(t) > 0\) និងយឺតកាលណា \(v(t) \cdot a(t) < 0\) ៖
- \(v(t) = 3(t - 2)(t - 4)\)
- \(a(t) = 6(t - 3)\)
សញ្ញានៃផលគុណ \(v(t)a(t)\) ៖

  • \(v(t)a(t) > 0 \iff t \in (2, 3) \cup (4, +\infty)\) ៖ ចលនាស្ទុះលឿន

  • \(v(t)a(t) < 0 \iff t \in (0, 2) \cup (3, 4)\) ៖ ចលនាយឺត

លំហាត់ទី ៤៥ ៖ គេមាន \(h(t) = 80t - 5t^2\) ៖
- ល្បឿន \(v(t) = 80 - 10t = 0 \iff t = 8\text{ s}\) ៖

\[\begin{aligned} h_{\max} &= 80(8) - 5(64) = 320\text{ m} \end{aligned}\]
- ធ្លាក់ដល់ដីពេល \(t = 16\text{ s}\) ៖
\[v(16) = 80 - 10(16) = -80\text{ m/s}\]
ល្បឿនពេលប៉ះដីគឺ \(80\text{ m/s}\)។

លំហាត់ទី ៤៦ ៖ មាឌស្វ៊ែរ ៖ \(V = \dfrac{4}{3}\pi r^3\)។
ដេរីវេធៀបនឹងពេល \(t\) ៖ \(\dfrac{dV}{dt} = 4\pi r^2 \dfrac{dr}{dt}\)។
ជំនួស \(\dfrac{dV}{dt} = 400\pi\) និង \(r = 10\text{ cm}\) ៖

\[\begin{aligned} 400\pi &= 4\pi(10^2) \frac{dr}{dt} \iff 400\pi = 400\pi \frac{dr}{dt} \\ &\implies \frac{dr}{dt} = 1\text{ cm/s} \end{aligned}\]

លំហាត់ទី ៤៧ ៖ ផ្ទៃក្រឡារង្វង់ ៖ \(A = \pi r^2\)។
ដេរីវេធៀបនឹង \(t\) ៖ \(\dfrac{dA}{dt} = 2\pi r \dfrac{dr}{dt}\)។
នៅពេល \(r = 2\text{ m} = 200\text{ cm}\) និង \(\dfrac{dr}{dt} = 30\text{ cm/s}\) ៖

\[\begin{aligned} \frac{dA}{dt} &= 2\pi(200)(30) \\ &= 12000\pi\text{ cm}^2/\text{s} = 1.2\pi\text{ m}^2/\text{s} \end{aligned}\]

លំហាត់ទី ៤៨ ៖ ធុងកោនកម្ពស់ \(4\text{ m}\) កាំ \(2\text{ m}\) នាំឱ្យ \(\dfrac{r}{h} = \dfrac{2}{4} = \dfrac{1}{2} \implies r = \dfrac{h}{2}\)។
មាឌទឹកក្នុងធុង ៖ \(V = \dfrac{1}{3}\pi r^2 h = \dfrac{1}{3}\pi \left(\frac{h}{2}\right)^2 h = \dfrac{\pi}{12}h^3\)។
ដេរីវេធៀបនឹង \(t\) ៖ \(\dfrac{dV}{dt} = \dfrac{\pi}{4}h^2 \dfrac{dh}{dt}\)។
នៅពេល \(h = 3\text{ m}\) និង \(\dfrac{dV}{dt} = 2\text{ m}^3/\text{min}\) ៖

\[\begin{aligned} 2 &= \frac{\pi}{4}(3^2) \frac{dh}{dt} \\ \implies \frac{dh}{dt} &= \frac{8}{9\pi}\text{ m/min} \end{aligned}\]

លំហាត់ទី ៤៩ ៖ តាង \(x\) ជាចម្ងាយជើងជណ្ដើរ និង \(y\) ជាកម្ពស់ចុងលើ ៖ \(x^2 + y^2 = 10^2 = 100\)។
ដេរីវេធៀបនឹង \(t\) ៖ \(2x\dfrac{dx}{dt} + 2y\dfrac{dy}{dt} = 0 \implies x\dfrac{dx}{dt} + y\dfrac{dy}{dt} = 0\)។
នៅពេល \(x = 6\text{ m} \implies y = \sqrt{100 - 36} = 8\text{ m}\)។
ជំនួស \(\dfrac{dx}{dt} = 2\text{ m/s}\) ចូល ៖

\[\begin{aligned} 6(2) + 8\frac{dy}{dt} &= 0 \\ \implies \frac{dy}{dt} &= -\frac{12}{8} = -1.5\text{ m/s} \end{aligned}\]
ដូចនេះ ចុងលើនៃជណ្ដើររអិលចុះក្នុងល្បឿន \(1.5\text{ m/s}\)។

លំហាត់ទី ៥០ ៖ ក្រោយ \(t = 2\text{ h}\) ៖ \(x = 40\text{ km}, y = 30\text{ km}\)។
\(z = \sqrt{40^2 + 30^2} = 50\text{ km}\)។
ដេរីវេ \(z^2 = x^2 + y^2\) ៖

\[\begin{aligned} z\frac{dz}{dt} &= x\frac{dx}{dt} + y\frac{dy}{dt} \\ 50\frac{dz}{dt} &= 40(20) + 30(15) = 1250 \\ \implies \frac{dz}{dt} &= 25\text{ km/h} \end{aligned}\]
