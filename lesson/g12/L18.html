មាឌសូលីតបរិវត្ត

សញ្ញាណគ្រឹះ និងការបែងចែកជាស៊ីឡាំងស្តើង

សញ្ញាណនៃសូលីតបរិវត្ត៖ (សៀវភៅពុម្ពទំព័រ ៥០-៥១)
គេឱ្យអនុគមន៍ \(y = f(x)\) ជាប់លើចន្លោះ \([a, b]\) ។ រង្វិលនៃផ្ទៃ \(\Gamma\) ខណ្ឌដោយក្រាប \(f\) និងអ័ក្សអាប់ស៊ីសចន្លោះ \(x = a\) និង \(x = b\) ជុំវិញអ័ក្ស \(x'Ox\) បង្កើតបានជាសូលីតបរិវត្តមួយ។
ការបែងចែករកមាឌ៖

  • ចែក \([a, b]\) ជា \(n\) ចំណែកទទឹង \(\Delta x\) ស្មើៗគ្នា។

  • ផ្ទៃថាសមុខកាត់៖ \(\mathcal{A}(x_k) = \pi [f(x_k)]^2\)

  • មាឌស៊ីឡាំងស្ដើង៖ \(\Delta V_k = \pi [f(x_k)]^2 \Delta x\)

  • មាឌសរុប៖ \(V \approx \displaystyle\sum_{k=1}^n \pi [f(x_k)]^2 \Delta x\)

កាលណា \(n \to +\infty \implies \Delta x \to 0\) គេបានមាឌសូលីតបរិវត្ត៖

\[V = \lim_{n \to +\infty} \sum_{k=1}^n \pi [f(x_k)]^2 \Delta x = \pi \int_a^b [f(x)]^2 \, dx\]

សម្គាល់

ចំណាំ៖ រូបមន្តខាងលើបង្ហាញថាមាឌសូលីតបរិវត្ត គឺស្មើនឹងផលបូកអាំងតេក្រាលនៃផ្ទៃក្រឡាថាសមុខកាត់ \(\mathcal{A}(x) = \pi [f(x)]^2\) ពី \(x = a\) ដល់ \(x = b\) ៖

\[V = \int_a^b \mathcal{A}(x) \, dx = \pi \int_a^b [f(x)]^2 \, dx\]

វិធីសាស្ត្របន្ទះមូល (The Disk Method)

រូបមន្តវិធីសាស្ត្របន្ទះមូល (The Disk Method)

  1. រង្វិលជុំវិញអ័ក្សអាប់ស៊ីស \(Ox\)៖ បើ \(f\) ជាអនុគមន៍ជាប់ និងមិនអវិជ្ជមានលើ \([a, b]\) នោះមាឌសូលីតបរិវត្តដែលកើតពីការរង្វិលជុំវិញអ័ក្ស \(Ox\) នៃដែនប្លង់ខណ្ឌដោយក្រាប \((C): y = f(x)\) អ័ក្ស \(Ox\) និងបន្ទាត់ឈរ \(x = a\) , \(x = b\) គឺ៖

    \[V_{Ox} = \pi \int_a^b \big[ f(x) \big]^2 \, dx \quad{} (\text{ឯកតាមាឌ})\]

  2. រង្វិលជុំវិញអ័ក្សអ័រដោណេ \(Oy\)៖ បើ \(g\) ជាអនុគមន៍ជាប់ និងមិនអវិជ្ជមានលើ \([c, d]\) នោះមាឌសូលីតបរិវត្តដែលកើតពីការរង្វិលជុំវិញអ័ក្ស \(Oy\) នៃដែនប្លង់ខណ្ឌដោយក្រាប \(x = g(y)\) អ័ក្ស \(Oy\) និងបន្ទាត់ដេក \(y = c\) , \(y = d\) គឺ៖

    \[V_{Oy} = \pi \int_c^d \big[ g(y) \big]^2 \, dy \quad{} (\text{ឯកតាមាឌ})\]

a. រង្វិលជុំវិញអ័ក្ស \(Ox\)


\(\mathcal{A}(x) = \pi [f(x)]^2 \implies V_{Ox} = \pi \int_a^b [f(x)]^2 \, dx\)

b. រង្វិលជុំវិញអ័ក្ស \(Oy\)


\(\mathcal{A}(y) = \pi [g(y)]^2 \implies V_{Oy} = \pi \int_c^d [g(y)]^2 \, dy\)

ឧទាហរណ៍

គណនាមាឌសូលីតបរិវត្តដែលកើតពីការរង្វិលជុំវិញអ័ក្ស \(Ox\) នៃដែនប្លង់ខណ្ឌដោយក្រាប \(y = \sqrt{x}\) អ័ក្ស \(Ox\) និងបន្ទាត់ឈរ \(x = 4\) ។

ចម្លើយ

កម្រិតព្រំដែនគឺពី \(x = 0\) ដល់ \(x = 4\) ។
តាមរូបមន្តវិធីសាស្ត្របន្ទះមូល៖

\[V = \pi \int_0^4 (\sqrt{x})^2 \, dx = \pi \int_0^4 x \, dx = \pi \left[ \frac{x^2}{2} \right]_0^4 = \pi \left( \frac{16}{2} - 0 \right) = 8\pi \quad{} (\text{ឯកតាមាឌ})\]

រូបមន្តមាឌស្វ៊ែរ

ស្រាយបញ្ជាក់ថាមាឌនៃស្វ៊ែរកាំ \(R\) គឺ \(V = \dfrac{4}{3}\pi R^3\) ។

ចម្លើយ

ស្វ៊ែរកាំ \(R\) កើតពីការរង្វិលជុំវិញអ័ក្ស \(Ox\) នៃកន្លះរង្វង់ខាងលើ \(y = \sqrt{R^2 - x^2}\) លើចន្លោះ \([-R, R]\) ។
គេបាន៖

\[V = \pi \int_{-R}^R (\sqrt{R^2 - x^2})^2 \, dx = \pi \int_{-R}^R (R^2 - x^2) \, dx\]
ដោយអនុគមន៍ \(f(x) = R^2 - x^2\) ជាអនុគមន៍គូ៖
\[V = 2\pi \int_0^R (R^2 - x^2) \, dx = 2\pi \left[ R^2 x - \frac{x^3}{3} \right]_0^R = 2\pi \left( R^3 - \frac{R^3}{3} \right) = 2\pi \left( \frac{2}{3}R^3 \right) = \frac{4}{3}\pi R^3\]
ដូចនេះ មាឌស្វ៊ែរកាំ \(R\) គឺ \(V = \dfrac{4}{3}\pi R^3\) ។

វិធីសាស្ត្រក្រវិល (The Washer Method)

វិលជុំវិញអ័ក្ស \(Ox\)

បើ \(f(x) \ge g(x) \ge 0\) លើចន្លោះ \([a, b]\) នោះមាឌ \(V\) នៃសូលីតបរិវត្តដែលកើតពីការរង្វិលជុំវិញអ័ក្ស \(Ox\) នៃដែនប្លង់ខណ្ឌដោយខ្សែកោងពីរ \((C_1): y = f(x)\) និង \((C_2): y = g(x)\) ចន្លោះ \(x = a\) និង \(x = b\) ត្រូវបានកំណត់ដោយ៖

\[V = \pi \int_a^b \Big( \big[ f(x) \big]^2 - \big[ g(x) \big]^2 \Big) \, dx \quad{} (\text{ឯកតាមាឌ})\]


ផ្ទៃក្រឡាក្រវិល \(A(x) = \pi \big[ R^2(x) - r^2(x) \big] \implies V = \pi \int_a^b \Big( [f(x)]^2 - [g(x)]^2 \Big) \, dx\)

វិលជុំវិញអ័ក្ស \(Oy\)

បើ \(f(y) \ge g(y) \ge 0\) លើចន្លោះ \([c, d]\) នោះមាឌ \(V\) នៃសូលីតបរិវត្តដែលកើតពីការរង្វិលជុំវិញអ័ក្ស \(Oy\) នៃដែនប្លង់ខណ្ឌដោយ \(x = f(y)\) និង \(x = g(y)\) ចន្លោះ \(y = c\) និង \(y = d\) ត្រូវបានកំណត់ដោយ៖

\[V = \pi \int_c^d \Big( \big[ f(y) \big]^2 - \big[ g(y) \big]^2 \Big) \, dy \quad{} (\text{ឯកតាមាឌ})\]


ផ្ទៃក្រឡាក្រវិល \(A(y) = \pi \big[ R^2(y) - r^2(y) \big] \implies V = \pi \int_c^d \Big( [f(y)]^2 - [g(y)]^2 \Big) \, dy\)

ឧទាហរណ៍

គណនាមាឌសូលីតបរិវត្តដែលកើតពីការរង្វិលជុំវិញអ័ក្ស \(Ox\) នៃដែនប្លង់ខណ្ឌដោយប៉ារ៉ាបូល \(y = x^2\) និងបន្ទាត់ \(y = 2x\) ។

ចម្លើយ

រកអាប់ស៊ីសចំណុចប្រសព្វ៖ \(x^2 = 2x \iff x(x - 2) = 0 \iff x = 0 \quad{} \) ឬ \( \quad{} x = 2\) ។
លើចន្លោះ \([0, 2]\) គេបាន \(2x \ge x^2 \ge 0\) ។
តាមរូបមន្តវិធីសាស្ត្រក្រវិល៖

\[V = \pi \int_0^2 \Big( (2x)^2 - (x^2)^2 \Big) \, dx = \pi \int_0^2 (4x^2 - x^4) \, dx\]
\[V = \pi \left[ \frac{4x^3}{3} - \frac{x^5}{5} \right]_0^2 = \pi \left( \frac{32}{3} - \frac{32}{5} \right) = 32\pi \left( \frac{5 - 3}{15} \right) = \frac{64\pi}{15} \quad{} (\text{ឯកតាមាឌ})\]

ការគណនាប្រវែងធ្នូនៃខ្សែកោង (Arc Length)

ការទាញយករូបមន្តតាមត្រីកោណឌីផេរ៉ង់ស្យែល

សញ្ញាណនៃប្រវែងធ្នូ៖ (សៀវភៅពុម្ពទំព័រ ៥៧)
គេមានអនុគមន៍ \(y = f(x)\) ជាប់ និងមានដេរីវេលើ \([a, b]\) ហើយមានក្រាប \(C\) ។
គេចែកចន្លោះ \([a, b]\) ជា \(n\) ចំណែក រួចយកចំណុច \(P_0(x, f(x))\) និង \(P_1(x+\Delta x, f(x+\Delta x))\) ៖

  • កំណើនលើអ័ក្សឈរ៖ \(\Delta y = f(x + \Delta x) - f(x)\)

  • ប្រវែងអង្កត់ធ្នូ \(P_0 P_1\) គឺ៖ \(\Delta L = P_0 P_1 = \sqrt{(\Delta x)^2 + (\Delta y)^2} = \sqrt{1 + \left(\frac{\Delta y}{\Delta x}\right)^2} \cdot \Delta x\)

  • កាលណា \(\Delta x \to 0\) នោះ \(\dfrac{\Delta y}{\Delta x} \to \dfrac{dy}{dx} = f'(x)\) ហើយឌីផេរ៉ង់ស្យែលប្រវែងធ្នូគឺ៖

    \[dL = \sqrt{1 + \left(\frac{dy}{dx}\right)^2} \, dx = \sqrt{1 + [f'(x)]^2} \, dx\]

ផលបូកនៃប្រវែងធ្នូទាំងអស់ខិតទៅរកប្រវែងធ្នូពិតប្រាកដ \(L\) នៃក្រាប \(C\) ចន្លោះ \(x = a\) និង \(x = b\) ៖

\[L = \int_a^b \sqrt{1 + [f'(x)]^2} \, dx\]

រូបមន្តទូទៅ

រូបមន្តប្រវែងធ្នូ

  1. បើខ្សែកោងមានសមីការ \(y = f(x)\) ដែល \(f'\) ជាប់លើចន្លោះ \([a, b]\) នោះប្រវែងធ្នូ \(L\) ពី \(x = a\) ដល់ \(x = b\) ត្រូវបានកំណត់ដោយ៖

    \[L = \int_a^b \sqrt{1 + \big[ f'(x) \big]^2} \, dx = \int_a^b \sqrt{1 + \left(\frac{dy}{dx}\right)^2} \, dx \quad{} (\text{ឯកតាប្រវែង})\]

  2. បើខ្សែកោងមានសមីការ \(x = g(y)\) ដែល \(g'\) ជាប់លើចន្លោះ \([c, d]\) នោះប្រវែងធ្នូ \(L\) ពី \(y = c\) ដល់ \(y = d\) ត្រូវបានកំណត់ដោយ៖

    \[L = \int_c^d \sqrt{1 + \big[ g'(y) \big]^2} \, dy = \int_c^d \sqrt{1 + \left(\frac{dx}{dy}\right)^2} \, dy \quad{} (\text{ឯកតាប្រវែង})\]

ចម្លើយ

ដេរីវេនៃអនុគមន៍៖

\[y' = f'(x) = \frac{4\sqrt{2}}{3} \cdot \frac{3}{2} x^{\frac{3}{2} - 1} = 2\sqrt{2} x^{\frac{1}{2}} = 2\sqrt{2}\sqrt{x}\]
គេបាន៖
\[1 + (y')^2 = 1 + (2\sqrt{2}\sqrt{x})^2 = 1 + 8x\]
តាមរូបមន្តប្រវែងធ្នូ៖

    \(V = \pi \displaystyle\int_1^3 (2x + 1)^2 \, dx\)

ដំណោះស្រាយ

  1. \(f(x) = x^2\) និង \(g(x) = 4x - x^2\) ៖

    អាប់ស៊ីសប្រសព្វ ៖ \(4x - x^2 = x^2 \iff x = 0, 2\)

    លើ \([0, 2]\) ៖ \(g(x) \ge f(x) \ge 0\)

    \(V = \pi \displaystyle\int_0^2 ((4x - x^2)^2 - x^4) dx\)

    \(= \pi \left[ \frac{16x^3}{3} - 2x^4 \right]_0^2 = \frac{32\pi}{3}\)

    ដូចនេះ៖ \(\boxed{V = \frac{32\pi}{3}}\)

  2. \(f(x) = x^2 - 2x + 3\) និង \(g(x) = 9 - x\) ៖

    អាប់ស៊ីសប្រសព្វ ៖ \(x = -2, 3\)

    លើ \([-2, 3]\) ៖ \(g(x) \ge f(x) \ge 0\)

    \(V = \pi \displaystyle\int_{-2}^3 (-x^4 + 4x^3 - 9x^2 - 6x + 72) dx\)

    \(= \pi \left[ -\frac{x^5}{5} + x^4 - 3x^3 - 3x^2 + 72x \right]_{-2}^3\)

  2. \(y = x^3 - 3x\) លើ \([-1, 2]\) ៖

    \(x^3 - 3x = 0 \iff x \in \{-\sqrt{3}, 0, \sqrt{3}\}\)

    លើ \([-1, 0]\) ៖ \(y \ge 0\), លើ \([0, \sqrt{3}]\) ៖ \(y \le 0\), លើ \([\sqrt{3}, 2]\) ៖ \(y \ge 0\)

    \(\mathcal{A} = \frac{5}{4} + \frac{9}{4} + \frac{1}{4} = \frac{15}{4}\)

    ដូចនេះ៖ \(\boxed{\mathcal{A} = \frac{15}{4}}\)

  3. \(y = -x^2 + 4x\) និង \(y = x\) ៖

    \(-x^2 + 4x = x \iff x = 0, 3\)

    លើ \([0, 3]\) ៖ \(-x^2 + 4x \ge x\)

    \(\mathcal{A} = \displaystyle\int_0^3 (3x - x^2) dx = \frac{9}{2}\)

    ដូចនេះ៖ \(\boxed{\mathcal{A} = \frac{9}{2}}\)

  4. \(y = \sqrt{x}\) និង \(y = x^2\) ៖

    \(\sqrt{x} = x^2 \iff x = 0, 1\)

    លើ \([0, 1]\) ៖ \(\sqrt{x} \ge x^2\)

    \(\mathcal{A} = \displaystyle\int_0^1 (\sqrt{x} - x^2) dx = \frac{1}{3}\)

    ដូចនេះ៖ \(\boxed{\mathcal{A} = \frac{1}{3}}\)

លំហាត់ជំពូកទី ៥

គណនាមាឌសូលីតបរិវត្តដែលកើតពីការរង្វិលជុំវិញអ័ក្ស \(Ox\) នៃដែនប្លង់ខណ្ឌដោយ៖

  1. \(y = x^2\) និង \(y = 4\)

  2. \(y = \sqrt{x}\) និង \(y = x\)

  3. \(y = \sin x\) លើចន្លោះ \([0, \pi]\)

ដំណោះស្រាយ

  1. \(y = x^2\) និង \(y = 4\) ជុំវិញ \(Ox\) ៖

    អាប់ស៊ីសប្រសព្វ ៖ \(x = \pm 2\)

    \(V = \pi \displaystyle\int_{-2}^2 (16 - x^4) dx\)

    \(= 2\pi \left[ 16x - \frac{x^5}{5} \right]_0^2 = \frac{256\pi}{5}\)

    ដូចនេះ៖ \(\boxed{V = \frac{256\pi}{5}}\)

  2. \(y = \sqrt{x}\) និង \(y = x\) ជុំវិញ \(Ox\) ៖

    អាប់ស៊ីសប្រសព្វ ៖ \(x = 0, 1\)

    \(V = \pi \displaystyle\int_0^1 (x - x^2) dx = \frac{\pi}{6}\)

    ដូចនេះ៖ \(\boxed{V = \frac{\pi}{6}}\)

  3. \(y = \sin x\) លើ \([0, \pi]\) ជុំវិញ \(Ox\) ៖

    \(V = \pi \displaystyle\int_0^\pi \sin^2 x \, dx\)

    \(= \frac{\pi}{2}\left[ x - \frac{\sin 2x}{2} \right]_0^\pi = \frac{\pi^2}{2}\)

    ដូចនេះ៖ \(\boxed{V = \frac{\pi^2}{2}}\)

លំហាត់ជំពូកទី ៦

គណនាប្រវែងធ្នូននៃខ្សែកោងខាងក្រោម៖

  1. \(y = \dfrac{1}{3}(x^2 + 2)^{\frac{3}{2}}\) ពី \(x = 0\) ដល់ \(x = 3\)

  2. \(y = \ln(\cos x)\) ពី \(x = 0\) ដល់ \(x = \dfrac{\pi}{4}\)

  3. \(y = \dfrac{x^4}{16} + \dfrac{1}{2x^2}\) ពី \(x = 1\) ដល់ \(x = 2\)

ដំណោះស្រាយ

  1. \(y = \frac{1}{3}(x^2 + 2)^{3/2}\) ពី \(x = 0\) ដល់ \(3\) ៖

    \(y' = x\sqrt{x^2 + 2} \implies 1 + (y')^2 = (x^2 + 1)^2\)

    \(L = \displaystyle\int_0^3 (x^2 + 1) dx = \left[ \frac{x^3}{3} + x \right]_0^3 = 12\)

    ដូចនេះ៖ \(\boxed{L = 12}\)

  2. \(y = \ln(\cos x)\) ពី \(x = 0\) ដល់ \(\frac{\pi}{4}\) ៖

    \(y' = -\tan x \implies 1 + (y')^2 = \frac{1}{\cos^2 x}\)

    \(L = \displaystyle\int_0^{\pi/4} \frac{dx}{\cos x} = \ln(1 + \sqrt{2})\)

    ដូចនេះ៖ \(\boxed{L = \ln(1 + \sqrt{2})}\)

  3. \(y = \frac{x^4}{16} + \frac{1}{2x^2}\) ពី \(x = 1\) ដល់ \(2\) ៖

    \(y' = \frac{x^3}{4} - \frac{1}{x^3}\)

    \(1 + (y')^2 = \left( \frac{x^3}{4} + \frac{1}{x^3} \right)^2\)

    \(L = \displaystyle\int_1^2 \left( \frac{x^3}{4} + \frac{1}{x^3} \right) dx = \frac{21}{16}\)

    ដូចនេះ៖ \(\boxed{L = \frac{21}{16}}\)

លំហាត់ជំពូកទី ៧ (BacII Integral Sequence)

គេឱ្យស្វ៊ីត \((I_n)\) កំណត់ចំពោះគ្រប់ \(n \in \mathbb{N}\) ដោយ \(I_n = \displaystyle\int_0^1 (1 - x^2)^n \, dx\) ។

  1. គណនា \(I_0\) និង \(I_1\) ។

  2. ដោយប្រើអាំងតេក្រាលដោយផ្នែក ចូរបង្ហាញថា \((2n + 1)I_n = 2n I_{n-1}\) ចំពោះគ្រប់ \(n \ge 1\) ។

  3. ទាញរកតម្លៃនៃ \(I_2\) និង \(I_3\) ។

ដំណោះស្រាយ

  1. គណនា \(I_0\) និង \(I_1\) ៖

    • \(I_0 = \displaystyle\int_0^1 1 \, dx = 1 \implies\) \(\boxed{I_0 = 1}\)

    • \(I_1 = \displaystyle\int_0^1 (1 - x^2) dx = \left[ x - \frac{x^3}{3} \right]_0^1 = \frac{2}{3}\)

      នាំឱ្យ \(\boxed{I_1 = \frac{2}{3}}\)

  2. បង្ហាញថា \((2n + 1)I_n = 2n I_{n-1}\) ៖

    • តាង \(\begin{cases} u = (1 - x^2)^n \\ dv = dx \end{cases}\)

      \(\implies \begin{cases} du = -2nx(1 - x^2)^{n-1}dx \\ v = x \end{cases}\)

    • \(I_n = \Big[ x(1 - x^2)^n \Big]_0^1 + 2n \displaystyle\int_0^1 x^2(1 - x^2)^{n-1}dx\)

      \(= 2n(I_{n-1} - I_n)\)

    • \(\implies (2n + 1)I_n = 2n I_{n-1}\) (ពិត)

  3. ទាញរកតម្លៃ \(I_2\) និង \(I_3\) ៖

    • \(I_2 = \frac{4}{5}I_1 = \frac{4}{5} \cdot \frac{2}{3} = \frac{8}{15} \implies\) \(\boxed{I_2 = \frac{8}{15}}\)

    • \(I_3 = \frac{6}{7}I_2 = \frac{6}{7} \cdot \frac{8}{15} = \frac{16}{35} \implies\) \(\boxed{I_3 = \frac{16}{35}}\)
