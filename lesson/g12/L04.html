លំហាត់ស្រាវជ្រាវ និង កម្រិតខ្ពស់

  1. ចូរសរសេរកន្សោមនីមួយៗខាងក្រោមជាទម្រង់ពិជគណិត \(x + iy\) ៖

    1. \((9 - 3i) + (-4 + 5i)\)

    2. \((5 - i) - (6 - 2i)\)

    3. \((4 - i)(3 + 2i)\)

    4. \((3 + 2i)^3\)

    5. \(\frac{1+i}{\sqrt{2}-\sqrt{2}i}\)

    6. \(\frac{1+i}{1+3i}\)

    7. \(\frac{(1+i)(1-2i)}{2-4i}\)

  2. ចូរដោះស្រាយសមីការលីនេអ៊ែរខាងក្រោមក្នុងសំណុំ \(\mathbb{C}\) ៖

    1. \((1 + i)z = 3 + i\)

    2. \((3 - 4i)(z - 1) = 10 - 5i\)

    3. \((2 + i)(z - 7 + 3i) = 15 - 10i\)

    4. \((3 + 5i)(z + 2 - 5i) = 6 + 3i\)

  3. ចូរកំណត់តម្លៃនៃចំនួនពិត \(a\) និង \(b\) ដែលបំពេញសមភាពនីមួយៗខាងក្រោម៖

    1. \(\frac{a}{3 + i} + \frac{b}{1 + 2i} = 1 - i\)

    2. \(\frac{2 - 3i}{2a + bi} = 3 + 2i\)

    3. \((a + bi)^2 = 8 + 6i\)

  4. ចូរដោះស្រាយសមីការដឺក្រេទីពីរក្នុងសំណុំចំនួនកុំផ្លិច \(\mathbb{C}\) ៖

    1. \(z^2 + 2z + 2 = 0\)

    2. \(4z^2 - 4z + 17 = 0\)

    3. \(z^2 + 6z + 34 = 0\)

    4. \(z^2 - 2\sqrt{3}z + 4 = 0\)

  5. ចូរដោះស្រាយសមីការដឺក្រេទីពីរខាងក្រោមក្នុងសំណុំ \(\mathbb{C}\) ៖

    1. \(z^2 - 4iz - 4 = 0\)

    2. \(z^2 + iz + 6 = 0\)

    3. \(z^2 + 8iz - 17 = 0\)

    4. \(z^2 - (3 + 2i)z + 5 + i = 0\)

  6. ចូរកំណត់ឫសការេនៃចំនួនកុំផ្លិចខាងក្រោមជាទម្រង់ពិជគណិត \(x + iy\) ៖

    1. \(Z_1 = 3 + 4i\)

    2. \(Z_2 = -8 - 6i\)

    3. \(Z_3 = -15 + 8i\)

    4. \(Z_4 = 5 - 12i\)

  7. ចូរដោះស្រាយប្រព័ន្ធសមីការខាងក្រោមក្នុង \(\mathbb{C} \times \mathbb{C}\) ៖

    1. \(\begin{cases} z_1 + z_2 = 3 + i \\ 2z_1 - iz_2 = 5 \end{cases}\)

    2. \(\begin{cases} (1+i)z_1 + z_2 = 2 \\ z_1 - iz_2 = 1+i \end{cases}\)

  8. ចំពោះគ្រប់ចំនួនកុំផ្លិច \(z \in \mathbb{C}\) ចូរបង្ហាញថា៖

    1. \(A = z^2 - \overline{z}^2\) គឺជាចំនួននិម្មិតសុទ្ធ។

    2. \(B = z^n + \overline{z}^n\) គឺជាចំនួនពិតសុទ្ធ ចំពោះគ្រប់ \(n \in \mathbb{N}\)។

    3. \(C = \frac{z - \overline{z}}{1 + |z|^2}\) គឺជាចំនួននិម្មិតសុទ្ធ។

  9. គេមាន \(X = (2 - \sqrt{5}i)^n + (2 + \sqrt{5}i)^n\) និង \(Y = (2 - \sqrt{5}i)^n - (2 + \sqrt{5}i)^n\) ដែល \(n \in \mathbb{N}\)។

    1. បង្ហាញថា \(X\) គឺជាចំនួនពិតសុទ្ធ។

    2. បង្ហាញថា \(Y\) គឺជាចំនួននិម្មិតសុទ្ធ។

  10. ចូរគណនាម៉ូឌុលនៃចំនួនកុំផ្លិចនីមួយៗខាងក្រោម៖

    1. \(z_1 = \frac{(2+i)(1-3i)}{3+4i}\)

    2. \(z_2 = \frac{(1+i\sqrt{3})^4}{(1-i)^6}\)

    3. \(z_3 = 1+\cos\alpha + i\sin\alpha\)

  11. ចូរសរសេរចំនួនកុំផ្លិចខាងក្រោមជាទម្រង់ត្រីកោណមាត្រ \(r(\cos\theta + i\sin\theta)\) ៖

    1. \(4\) \(-6\)

    2. \(2i\) \(-3i\)

    3. \(1 + i\) \(2 - 2i\)

    4. \(-\sqrt{3} + i\) \(2\sqrt{3} + 2i\)

  12. សរសេរជាទម្រង់ពិជគណិតនៃចំនួនកុំផ្លិចខាងក្រោម (សម្គាល់៖ \(\cis \alpha =\cos\alpha+i\sin\alpha\)) ៖

    1. \(2\,\cis\left(\frac{\pi}{2}\right)\)

    2. \(8\,\cis\left(\frac{\pi}{4}\right)\)

    3. \(4\,\cis\left(\frac{\pi}{6}\right)\)

    4. \(\sqrt{2}\,\cis\left(-\frac{\pi}{4}\right)\)

    5. \(\sqrt{3}\,\cis\left(\frac{2\pi}{3}\right)\)

    6. \(5\,\cis \pi\)

  13. គេឱ្យ \(z_1 = 2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)\) និង \(z_2 = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)\)។

    1. គណនាផលគុណ \(z_1 z_2\) និងផលចែក \(\frac{z_1}{z_2}\) ជាទម្រង់ត្រីកោណមាត្រ។

    2. សរសេរ \(z_1, z_2\) ជាទម្រង់ពិជគណិត រួចទាញរកទម្រង់ពិជគណិតនៃ \(\frac{z_1}{z_2}\)។

    3. ទាញរកតម្លៃប្រាកដនៃ \(\cos\frac{\pi}{12}\) និង \(\sin\frac{\pi}{12}\)។

  14. ដោយប្រើទ្រឹស្តីបទដឺម័រ (De Moivre’s Theorem) ចូររកចម្លើយសាមញ្ញនៃ៖

    1. \(\left(\sqrt{2}\,\cis \frac{\pi}{5}\right)^{10}\)

    2. \(\left(\cis \frac{\pi}{12}\right)^{36}\)

    3. \(\left(\sqrt{2}\,\cis \frac{\pi}{8}\right)^{12}\)

    4. \(\left(2\,\cis \frac{5\pi}{6}\right)^6\)

  15. ដោយប្រើទ្រឹស្តីបទដឺម័រ ចូរគណនាកន្សោមខាងក្រោមជាទម្រង់ពិជគណិត \(x+iy\) ៖

    1. \((1 + i)^{16}\)

    2. \((1 - i\sqrt{3})^{11}\)

    3. \((\sqrt{3} + i)^{10}\)

    4. \(\left(\frac{1+i}{\sqrt{3}-i}\right)^{12}\)

  16. ចូរសរសេរ \(z = 2 - 2\sqrt{3}i\) ជាទម្រង់ត្រីកោណមាត្រ។

    1. រកតម្លៃទាំងអស់នៃ \(n \in \mathbb{N}\) ដែលធ្វើឱ្យ \(z^n\) ជាចំនួនពិត។

    2. រកតម្លៃទាំងអស់នៃ \(n \in \mathbb{N}\) ដែលធ្វើឱ្យ \(z^n\) ជានិម្មិតសុទ្ធ។

  17. គេមានចំនួនកុំផ្លិច \(Z = \frac{-1 + i}{1 + i\sqrt{3}}\)។

    1. ចូរកំណត់ផ្នែកពិត និងផ្នែកនិម្មិតនៃ \(Z\) ជាទម្រង់ពិជគណិត។

    2. សរសេរ \(-1+i\) និង \(1+i\sqrt{3}\) ជាទម្រង់ប៉ូលែរ រួចទាញរកទម្រង់ត្រីកោណមាត្រនៃ \(Z\)។

    3. ទាញបង្ហាញថា \(\cos\frac{5\pi}{12} = \frac{\sqrt{3}-1}{2\sqrt{2}}\) ហើយកំណត់តម្លៃប្រាកដនៃ \(\sin\frac{5\pi}{12}\)។

  18. គេឱ្យចំនួនកុំផ្លិច \(u = (1+i)(1+i\sqrt{3})\)។

    1. សរសេរ \(u\) ជាទម្រង់ពិជគណិត។

    2. សរសេរ \(1+i\) និង \(1+i\sqrt{3}\) ជាទម្រង់ត្រីកោណមាត្រ រួចទាញរកទម្រង់ត្រីកោណមាត្រនៃ \(u\)។

    3. ទាញរកតម្លៃប្រាកដនៃ \(\cos\frac{7\pi}{12}\) និង \(\sin\frac{7\pi}{12}\)។

    4. គណនា \(u^6\)។

  19. គេមានចំនួនកុំផ្លិច \(z = \sqrt{1+\sqrt{2}} + i\sqrt{\sqrt{2}-1}\) និង \(Z = z^4\)។

    1. គណនា \(z^2\) រួចទាញរក \(Z\) ជាទម្រង់ពិជគណិត។

    2. សរសេរ \(Z\) ជាទម្រង់ត្រីកោណមាត្រ។

    3. ទាញរកតម្លៃប្រាកដនៃ \(\cos\frac{\pi}{8}\) និង \(\sin\frac{\pi}{8}\)។

  20. គេឱ្យចំនួនកុំផ្លិច \(z_1 = -1+i\), \(z_2 = \sqrt{6}-i\sqrt{2}\) និង \(z_3 = -\sqrt{6}-\sqrt{2} + i(\sqrt{6}-\sqrt{2})\)។

    1. សរសេរ \(z_1\) និង \(z_2\) ជាទម្រង់ត្រីកោណមាត្រ។

    2. បង្ហាញថា \(z_3 = z_1 \overline{z_2}\) រួចទាញរកម៉ូឌុល និងអាគុយម៉ង់នៃ \(z_3\)។

    3. ទាញរកតម្លៃប្រាកដនៃ \(\cos\left(\frac{11\pi}{12}\right)\) និង \(\sin\left(\frac{11\pi}{12}\right)\)។

    4. គណនា \(z_3^{18}\)។

  21. គេឱ្យចំនួនកុំផ្លិច \(u = 4\sqrt{3} + 4i\)។

    1. គណនាម៉ូឌុល និងអាគុយម៉ង់នៃ \(u\)។

    2. រកឫសការេនៃ \(u\) ជាទម្រង់ត្រីកោណមាត្រ។

    3. រកឫសការេនៃ \(u\) ជាទម្រង់ពិជគណិត។

    4. ទាញរកតម្លៃប្រាកដនៃ \(\cos\frac{\pi}{12}\) និង \(\sin\frac{\pi}{12}\)។

  22. ចូរកំណត់ឫសគូបទាំងអស់ក្នុងសំណុំ \(\mathbb{C}\) នៃចំនួនកុំផ្លិចនីមួយៗខាងក្រោម៖

    1. \(Z_1 = -27\)

    2. \(Z_2 = 8i\)

    3. \(Z_3 = -1 + i\)

  23. គេឱ្យសមីការ \(z^5 - 1 = 0\) លើសំណុំ \(\mathbb{C}\)។

    1. រកឫសទាំង ៥ នៃសមីការជាទម្រង់ត្រីកោណមាត្រ។

    2. តាង \(\omega = \cos\frac{2\pi}{5} + i\sin\frac{2\pi}{5}\)។ បង្ហាញថា \(1 + \omega + \omega^2 + \omega^3 + \omega^4 = 0\)។

    3. ទាញបង្ហាញថា \(\cos\frac{2\pi}{5} + \cos\frac{4\pi}{5} = -\frac{1}{2}\)។

    4. គណនាតម្លៃប្រាកដនៃ \(\cos\frac{2\pi}{5}\) និង \(\sin\frac{2\pi}{5}\)។

  24. តាង \(j = -\frac{1}{2} + i\frac{\sqrt{3}}{2} = e^{i\frac{2\pi}{3}}\) ជាឫសគូបមិនពិតនៃ \(1\)។

    1. បង្ហាញថា \(j^2 = \overline{j}\) និង \(1 + j + j^2 = 0\)។

    2. គណនាតម្លៃនៃកន្សោម \(A = (1 - j + j^2)(1 + j - j^2)\)។

    3. ចំពោះគ្រប់ចំនួនពិត \(a, b, c\) ចូរបង្ហាញថា៖ \((a + b + c)(a + bj + cj^2)(a + bj^2 + cj) = a^3 + b^3 + c^3 - 3abc\)។

  25. ដោយប្រើកន្សោម \((\cos\theta + i\sin\theta)^3 = \cos 3\theta + i\sin 3\theta\) ៖

លំហាត់ ៤១៖ លក្ខខណ្ឌត្រីកោណសម័ង្ស
\(\triangle ABC\) សម័ង្ស \(\iff \frac{z_3-z_1}{z_2-z_1} = e^{\pm i\pi/3} \iff \left(\frac{z_3-z_1}{z_2-z_1}\right)^2 - \frac{z_3-z_1}{z_2-z_1} + 1 = 0\)
\(\iff (z_3-z_1)^2 - (z_3-z_1)(z_2-z_1) + (z_2-z_1)^2 = 0\)
ពន្លាតនិងបង្រួមគេបាន៖
\(z_1^2 + z_2^2 + z_3^2 = z_1 z_2 + z_2 z_3 + z_3 z_1\) (ពិត)

លំហាត់ ៤២៖ សំណុំចំណុចនៃ \(Z = \frac{z-2i}{z+1}\)
\(Z = \frac{(x+iy-2i)(x+1-iy)}{(x+1)^2+y^2} = \frac{(x^2+x+y^2-2y) + i(y-2x-2)}{(x+1)^2+y^2}\)

  1. \(Z \in \mathbb{R} \iff y - 2x - 2 = 0 \iff y = 2x + 2\) (បន្ទាត់ ដកចំណុច \((-1, 0)\))

  2. \(Z \in i\mathbb{R} \iff x^2+x+y^2-2y = 0 \iff \left(x+\frac{1}{2}\right)^2 + (y-1)^2 = \frac{5}{4}\) (រង្វង់ផ្ចិត \((-\frac{1}{2}, 1)\) កាំ \(\frac{\sqrt{5}}{2}\) ដក \((-1, 0)\))

លំហាត់ ៤៣៖ ពហុធា \(P(z)\)
\(P(i) = i^4 - 2i^3 + 3i^2 - 2i + 2 = 1 + 2i - 3 - 2i + 2 = 0\)
ដោយមេគុណជាចំនួនពិត នោះ \(-i\) ក៏ជាឫស \(\implies z^2+1\) ជាកត្តា។
ចែកពហុធា៖ \(P(z) = (z^2+1)(z^2-2z+2)\)
\(z^2-2z+2 = 0 \iff (z-1)^2 = -1 \implies z = 1 \pm i\)
ដូចនេះ \( z \in \{i,\; -i,\; 1+i,\; 1-i\}\)

លំហាត់ ៤៤៖ សមីការ \((z+i)^n = (z-i)^n\)

  1. \(|z+i| = |z-i| \implies z\) ស្មើចម្ងាយពី \(-i\) និង \(i \implies z \in \mathbb{R}\)

  2. \(\frac{z+i}{z-i} = e^{i\frac{2k\pi}{n}} \implies z+i = e^{i\frac{2k\pi}{n}}(z-i)\)
    \(\implies z = i\frac{e^{i\frac{2k\pi}{n}}+1}{e^{i\frac{2k\pi}{n}}-1} = i\frac{2\cos\frac{k\pi}{n}e^{i\frac{k\pi}{n}}}{2i\sin\frac{k\pi}{n}e^{i\frac{k\pi}{n}}} = \cot\left(\frac{k\pi}{n}\right)\)
    ចំពោះ \(k = 1, 2, \dots, n-1\)

  3. ករណី \(n=5\)៖ ឫសទាំង ៤ គឺ \(\cot\frac{\pi}{5}, \cot\frac{2\pi}{5}, -\cot\frac{2\pi}{5}, -\cot\frac{\pi}{5}\)
    ដោយ \(\tan\frac{\pi}{5} = \sqrt{5-2\sqrt{5}}\) និង \(\tan\frac{2\pi}{5} = \sqrt{5+2\sqrt{5}}\) គេបាន
    \(\cot\frac{\pi}{5} = \frac{1}{\sqrt{5-2\sqrt{5}}} = \sqrt{\frac{5+2\sqrt{5}}{5}},\; \cot\frac{2\pi}{5} = \frac{1}{\sqrt{5+2\sqrt{5}}} = \sqrt{\frac{5-2\sqrt{5}}{5}}\)

លំហាត់ ៤៥៖ ផលគុណស៊ីនុស
\(z^{2n+1}-1 = (z-1)\prod_{k=1}^{2n}(z - e^{i\frac{2k\pi}{2n+1}})\)
ចែកនឹង \(z-1\) រួចផ្គុំគូកត្តាឆ្លាស់ \(k\) និង \(2n+1-k\)៖
\(\prod_{k=1}^n \left|1 - e^{i\frac{2k\pi}{2n+1}}\right|^2 = 2n+1\)
ដោយ \(|1-e^{i 2\theta}| = 2\sin\theta \implies \prod_{k=1}^n \left(2\sin\frac{k\pi}{2n+1}\right)^2 = 2n+1\)
\(\implies \prod_{k=1}^n \sin\left(\frac{k\pi}{2n+1}\right) = \frac{\sqrt{2n+1}}{2^n}\) (រូបមន្តផលគុណស៊ីនុសដ៏ល្បី)

លំហាត់ ៤៦៖ វិសមភាពត្រីកោណ និងបរមា
(ក) \(|z_1+z_2|^2 = |z_1|^2+|z_2|^2+2\text{Re}(z_1\bar{z}_2) \le |z_1|^2+|z_2|^2+2|z_1||z_2| = (|z_1|+|z_2|)^2\)
សមភាពកើតមាន \(\iff \text{Re}(z_1\bar{z}_2)=|z_1\bar{z}_2| \iff z_1\bar{z}_2\ge 0\) (ពោលគឺ \(z_1, z_2\) មានទិសដៅដូចគ្នា ឬមួយស្មើសូន្យ)។
(ខ) \(|z_1| = |(z_1-z_2)+z_2| \le |z_1-z_2|+|z_2|\) និងដូចគ្នា \(|z_2| \le |z_1-z_2|+|z_1|\)
\(\implies ||z_1|-|z_2|| \le |z_1-z_2|\)
(គ) យក \(z_1=z,\ z_2=\frac{3}{z}\)៖ \(||z| - |3/z|| \le |z - 3/z| = 2\)
\(\implies -2 \le |z| - \frac{3}{|z|} \le 2\)
- \(|z| - \frac{3}{|z|} \le 2 \implies |z|^2 - 2|z| - 3 \le 0 \implies |z| \le 3\)
- \(|z| - \frac{3}{|z|} \ge -2 \implies |z|^2 + 2|z| - 3 \ge 0 \implies |z| \ge 1\)
ដូចនេះ \( 1 \le |z| \le 3\)។ តម្លៃទាំងពីរត្រូវបានសម្រេច៖ \(z=1\) ឱ្យ \(|1-3|=2\) និង \(z=3\) ឱ្យ \(|3-1|=2\) \(\implies |z|_{\min} = 1,\; |z|_{\max} = 3\)

លំហាត់ ៤៧៖ \(u+v+w=0\) លើរង្វង់ឯកតា

  1. \(\frac{1}{u}+\frac{1}{v}+\frac{1}{w} = \bar{u}+\bar{v}+\bar{w} = \overline{u+v+w} = 0\)

  2. \(uv+vw+wu = uvw\left(\frac{1}{w}+\frac{1}{u}+\frac{1}{v}\right) = 0\)

  3. \((u+v+w)^2 = u^2+v^2+w^2+2(uv+vw+wu) \implies u^2+v^2+w^2 = 0\)
    \(u, v, w\) ជាឫសនៃ \(Z^3 - 0Z^2 + 0Z - uvw = 0 \iff Z^3 = uvw\)
    \(\implies u^3 = v^3 = w^3 = uvw\)
    មុំរវាងពួកវាគឺ \(\frac{2\pi}{3} \implies\) បង្កើតបានជាត្រីកោណសម័ង្ស។

លំហាត់ ៤៨៖ ប្រព័ន្ធសមីការ
\(\sum z_k = 1,\; \prod z_k = 1,\; |z_k|=1\)
\(\sum z_1 z_2 = z_1 z_2 z_3 \sum \frac{1}{z_k} = 1 \cdot \overline{\sum z_k} = 1\)
\(z_1, z_2, z_3\) ជាឫសនៃពហុធា៖
\(Z^3 - Z^2 + Z - 1 = 0 \iff (Z-1)(Z^2+1) = 0\)
\(\implies Z \in \{1,\; i,\; -i\}\)
ដូចនេះ \( \{z_1, z_2, z_3\} = \{1,\; i,\; -i\}\) (៦ ចម្លើយតាមបម្លាស់ប្តូរ)

លំហាត់ ៤៩៖ ទ្រឹស្តីបទណាប៉ូឡេអុង
តាង \(\rho = e^{i\pi/3}\) និង \(\omega = e^{-i\pi/3} = \bar{\rho}\)។ គេមាន \(\rho+\omega = 1\), \(\rho\omega = 1\), \(\rho^2 = \rho - 1\)។
ដោយ \(ABC\) តាមទិសដៅវិជ្ជមាន ត្រីកោណ \(BCD\) នៅក្រៅ \(\implies z_D - z_B = \omega(z_C - z_B)\)
\(\implies z_D = (1-\omega)z_B + \omega z_C = \rho z_B + \omega z_C\)
\(P = \frac{z_B+z_C+z_D}{3} = \frac{(1+\rho)z_B + (1+\omega)z_C}{3}\)
ដូចគ្នា \(Q = \frac{(1+\rho)z_C + (1+\omega)z_A}{3}\), \(R = \frac{(1+\rho)z_A + (1+\omega)z_B}{3}\)
\(3(Q-P) = (1+\omega)z_A - (1+\rho)z_B + (\rho-\omega)z_C\)
\(3(R-P) = (1+\rho)z_A + (\omega-\rho)z_B - (1+\omega)z_C\)
គុណ \(3(Q-P)\) នឹង \(\rho\)៖ \(\rho(1+\omega) = \rho+1\), \(-\rho(1+\rho) = 1-2\rho = \omega-\rho\), \(\rho(\rho-\omega) = \rho-2 = -(1+\omega)\)
\(\implies R-P = \rho(Q-P) = e^{i\pi/3}(Q-P) \implies PQ = PR\) និង \((\overrightarrow{PQ},\overrightarrow{PR}) = \frac{\pi}{3}\)
ដូចនេះ \( \triangle PQR\) ជាត្រីកោណសម័ង្ស (ទ្រឹស្តីបទណាប៉ូឡេអុង)។

លំហាត់ ៥០៖ ផលបូកមេគុណទ្វេធា

  1. \(Z_n = \sum_{k=0}^n \binom{n}{k} e^{ikx} = (1+e^{ix})^n\)

  2. \(1+e^{ix} = e^{ix/2}(e^{-ix/2}+e^{ix/2}) = 2\cos\left(\frac{x}{2}\right)e^{ix/2}\)

  3. \(Z_n = \left[2\cos\left(\frac{x}{2}\right)e^{ix/2}\right]^n = 2^n\cos^n\left(\frac{x}{2}\right)e^{i\frac{nx}{2}}\)
    \(\implies C_n = 2^n\cos^n\left(\frac{x}{2}\right)\cos\left(\frac{nx}{2}\right)\)
    \(\implies S_n = 2^n\cos^n\left(\frac{x}{2}\right)\sin\left(\frac{nx}{2}\right)\)

  4. អនុវត្ត \(x = \frac{\pi}{3}\)៖
    \(\sum_{k=0}^n \binom{n}{k}\cos\left(\frac{k\pi}{3}\right) = 2^n\cos^n\left(\frac{\pi}{6}\right)\cos\left(\frac{n\pi}{6}\right)\)
