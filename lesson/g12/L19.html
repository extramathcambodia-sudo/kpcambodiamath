មេរៀនទាំងអស់

សញ្ញាណសមីការដីផេរ៉ង់ស្យែលលំដាប់១

និយមន័យ

:

  • សមីការឌីផេរ៉ងស្យែលលំដាប់ទី \(1\) ជាទំនាក់ទំនងរវាងអនុគមន៍ ដេរីវេទី \(1\) របស់អនុគមន៍នេះ អថេរ និង ចំនួនថេរ។

  • ចម្លើយនៃសមីការឌីផេរ៉ង់ស្យែល ជាអនុគមន៍មួយដែលអនុគមន៍នេះ និងដេរីវេរបស់វាផ្ទៀងផ្ទាត់សមីការ។

  • លំដាប់នៃសមីការឌីផេរ៉ង់ស្យែល គឺជាលំដាប់នៃដេរីវេខ្ពស់ជាងគេក្នុងសមីការ។

ឧទាហរណ៍

គេមានអនុគមន៍ \(y=ke^{-3x}\) កំណត់លើ \(\mathbb{R}\) ចំពោះគ្រប់ចំនួនពិត \(k\) ។ សរសេរសមីការឌីផេរ៉ង់ស្យែលដែលមាន \(y=ke^{-3x}\) ជាចម្លើយទូទៅ។

ដំណោះស្រាយ

គេមានអនុគមន៍ \(y = ke^{-3x}\) កំណត់លើ \(\mathbb{R}\) (\(k\) ជាចំនួនពិតថេរ)។
ធ្វើដេរីវេលើអង្គទាំងពីរធៀបនឹងអថេរ \(x\) ៖

\[y' = (ke^{-3x})' = k(-3)e^{-3x} = -3ke^{-3x}\]
ដោយសារ \(y = ke^{-3x}\) នោះគេជំនួសចូលបាន ៖
\[y' = -3y \iff y' + 3y = 0\]
ដូចនេះ សមីការឌីផេរ៉ង់ស្យែលដែលមាន \(y = ke^{-3x}\) ជាចម្លើយទូទៅគឺ \(y' + 3y = 0\)។

ឧទាហរណ៍

បង្ហាញថាអនុគមន៍ខាងក្រោម ជាចម្លើយនៃសមីការឌីផេរ៉ង់ស្យែលត្រូវគ្នារបស់វា ៖

  1. អនុគមន៍ \(y=ke^{-\frac{x}{2}}\) សមីការ \(2y'+y=0\)

  2. អនុគមន៍ \(y=5\tan 5x\) សមីការ \(y'-y^2=25\)

ដំណោះស្រាយ

  1. គេមាន \(y = ke^{-\frac{x}{2}}\)។ គណនាដេរីវេទីមួយ ៖

    \[y' = k \left(-\frac{1}{2}\right)e^{-\frac{x}{2}} = -\frac{1}{2}ke^{-\frac{x}{2}} = -\frac{1}{2}y\]
    ជំនួស \(y'\) ចូលក្នុងអង្គខាងឆ្វេងនៃសមីការ \(2y' + y\) ៖
    \[2y' + y = 2\left(-\frac{1}{2}y\right) + y = -y + y = 0\]
    សមីការផ្ទៀងផ្ទាត់។ ដូចនេះ អនុគមន៍ \(y = ke^{-\frac{x}{2}}\) ពិតជាចម្លើយនៃសមីការ \(2y' + y = 0\)។

  2. គេមាន \(y = 5\tan 5x\)។ គណនាដេរីវេទីមួយ ៖

    \[y' = 5 \cdot 5(1 + \tan^2 5x) = 25(1 + \tan^2 5x) = 25 + 25\tan^2 5x\]
    ដោយ \(y^2 = (5\tan 5x)^2 = 25\tan^2 5x\) នាំឱ្យ ៖
    \[y' = 25 + y^2 \iff y' - y^2 = 25\]
    សមីការផ្ទៀងផ្ទាត់។ ដូចនេះ អនុគមន៍ \(y = 5\tan 5x\) ជាចម្លើយនៃសមីការ \(y' - y^2 = 25\)។

ដំណោះស្រាយសមីការដីផេរ៉ង់ស្យែលលំដាប់១

សមីការមានទម្រង់ \(\dfrac{dy}{dx}=f(x)\)

ជាទូទៅ

  • សរសេរ \(\dfrac{dy}{dx}=f(x)\) ជាទម្រង់ \(dy=f(x)dx\)

  • រកអាំងតេក្រាលអង្គទាំងពីរ : \(\int dy=\int f(x)dx\) ឬ \(y=\int f(x)dx+c\) , \(c\) ជាចំនួនថេរ

  • \(y=\int f(x)dx+c\) ជាចម្លើយទូទៅនៃសមីការឌីផេរ៉ង់ស្យែល \(\dfrac{dy}{dx}=f(x)\)

  • រកចម្លើយពិសេសតាមលក្ខខណ្ឌដើម \(y(x_0)=y_0\) គឺយក \(x_0\) និង \(y_0\) ទៅជំនួសក្នុងចម្លើយទូទៅ រួចទាញយក \(c=y_0-F(x_0)\)
    \(y=\int f(x)dx+y_0-F(x_0)\) ជាចម្លើយពិសេសតាមលក្ខខណ្ឌ \(y(x_0)=y_0\) ។

ឧទាហរណ៍

ដោះស្រាយសមីការខាងក្រោម៖

  1. \(y'=\dfrac{2x}{x^2+1}\)

  2. \(y'=6x^2+4x+5\)

  3. \(y'=xe^{x^2}\)

ដំណោះស្រាយ

  1. សមីការ \(y' = \dfrac{2x}{x^2+1} \iff \dfrac{dy}{dx} = \dfrac{2x}{x^2+1} \iff dy = \dfrac{2x}{x^2+1}\,dx\)។
    ធ្វើអាំងតេក្រាលលើអង្គទាំងពីរ ៖

    \[y = \int \frac{2x}{x^2+1}\,dx = \int \frac{d(x^2+1)}{x^2+1} = \ln(x^2+1) + C \quad{} (C \in \mathbb{R})\]
    (ដោយសារ \(x^2+1 > 0\) ចំពោះគ្រប់ \(x \in \mathbb{R}\) នោះពុំបាច់ដាក់តម្លៃដាច់ខាតឡើយ)។
    ដូចនេះ ចម្លើយទូទៅគឺ \(y = \ln(x^2+1) + C\) (\(C\) ជាចំនួនថេរ)។

  2. សមីការ \(y' = 6x^2 + 4x + 5 \iff dy = (6x^2 + 4x + 5)\,dx\)។
    ធ្វើអាំងតេក្រាលលើអង្គទាំងពីរ ៖

    \[y = \int (6x^2 + 4x + 5)\,dx = 2x^3 + 2x^2 + 5x + C \quad{} (C \in \mathbb{R})\]
    ដូចនេះ ចម្លើយទូទៅគឺ \(y = 2x^3 + 2x^2 + 5x + C\) (\(C\) ជាចំនួនថេរ)។

  3. សមីការ \(y' = xe^{x^2} \iff dy = xe^{x^2}\,dx\)។
    ធ្វើអាំងតេក្រាលលើអង្គទាំងពីរ ៖

    \[y = \int xe^{x^2}\,dx = \frac{1}{2}\int e^{x^2}\,d(x^2) = \frac{1}{2}e^{x^2} + C \quad{} (C \in \mathbb{R})\]
    ដូចនេះ ចម្លើយទូទៅគឺ \(y = \frac{1}{2}e^{x^2} + C\) (\(C\) ជាចំនួនថេរ)។

សមីការមានទម្រង់ \(g(y)\dfrac{dy}{dx}=f(x)\)

និយមន័យ

សមីការឌីផេរ៉ង់ស្យែលលំដាប់ទី \(1\) ដែលអាចញែកអថេរបាន ជាសមីការដែលក្រោយពីសម្រួលរួច មានទម្រង់ទូទៅ : \(g(y)\dfrac{dy}{dx}=f(x)\) ។

ជាទូទៅ

ដើម្បីដោះស្រាយសមីការឌីផេរ៉ង់ស្យែលលំដាប់ទី \(1\) ដែលអាចញែកអថេរបានគេត្រូវ៖

  • សរសេរសមីការឳ្យទៅជារាង :\(g(y)\dfrac{dy}{dx}=f(x)\)

  • ធ្វើអាំងតេក្រាលលើអង្គទាំង \(2\) ធៀបនឹងអថេរ \(x\) :
    \(\int g(y)dy=\int f(x)dx\) សមមូល \(G(y)=F(x)+c\) (\(c\) ជាចំនួនថេរណាមួយក៏បាន)
    \(G(y)\) ជាព្រីមីទីវនៃអនុគមន៍ \(g(y)\) និង \(F(x)\) ជាព្រីមីទីវនៃអនុគមន៍ \(f(x)\) ។

ឧទាហរណ៍

ក្នុងចំណោមសមីការខាងក្រោម តើសមីការណាខ្លះដែលអាចញែកអថេរបាន ?

  1. \(\dfrac{dy}{dx}=\dfrac{2x(y+1)}{y}\)

  2. \(\dfrac{dy}{dx}=\dfrac{y}{x}+\dfrac{x}{y}\)

  3. \(\dfrac{dy}{dx}=\ln (xy)\)

  4. \(\dfrac{dy}{dx}=e^{x+y}\)

ដោះស្រាយសមីការដែលញែកអថេរបាន តាមលក្ខខណ្ឌដើម \(y(2)=0\) ។

ដំណោះស្រាយ

  • **ការសម្គាល់សមីការដែលអាចញែកអថេរបាន ៖**

    1. \(\dfrac{dy}{dx} = \dfrac{2x(y+1)}{y} \iff \dfrac{y}{y+1}\,dy = 2x\,dx\) \(\implies\) អាចញែកអថេរបាន។

    2. \(\dfrac{dy}{dx} = \dfrac{y^2+x^2}{xy}\) \(\implies\) មិនអាចញែកអថេរបានដោយផ្ទាល់ (ជាសមីការអូម៉ូសែន)។

    3. \(\dfrac{dy}{dx} = \ln(xy) = \ln x + \ln y\) \(\implies\) មិនអាចញែកអថេរបាន។

    4. \(\dfrac{dy}{dx} = e^{x+y} = e^x \cdot e^y \iff e^{-y}\,dy = e^x\,dx\) \(\implies\) អាចញែកអថេរបាន។

  • **ដោះស្រាយសមីការដែលញែកបានតាមលក្ខខណ្ឌ \(y(2)=0\) ៖**

    • ចំពោះសមីការ (១) ៖ \(\dfrac{y}{y+1}\,dy = 2x\,dx \iff \left(1 - \dfrac{1}{y+1}\right)dy = 2x\,dx\)

      \[\int \left(1 - \frac{1}{y+1}\right)dy = \int 2x\,dx \iff y - \ln|y+1| = x^2 + C\]
      ជំនួស \(x = 2, y = 0\) ៖ \(0 - \ln|1| = 2^2 + C \implies 0 = 4 + C \implies C = -4\)។
      ដូចនេះ ចម្លើយពិសេសគឺ \(y - \ln|y+1| = x^2 - 4\)។

    • ចំពោះសមីការ (៤) ៖ \(e^{-y}\,dy = e^x\,dx \implies -e^{-y} = e^x + C\)។
      ជំនួស \(x = 2, y = 0\) ៖ \(-e^0 = e^2 + C \implies -1 = e^2 + C \implies C = -1 - e^2\)។
      គេបាន \(-e^{-y} = e^x - 1 - e^2 \iff e^{-y} = 1 + e^2 - e^x \iff y = -\ln(1 + e^2 - e^x)\)។

ឧទាហរណ៍

ក្នុងចំណោមសមីការខាងក្រោម តើសមីការណាខ្លះដែលអាចញែកអថេរបាន ?

  1. \(y'=3+y\)

  2. \(\dfrac{dy}{dx}=\sin(x+y)\)

  3. \(y'=y^2-4\)

  4. \(\dfrac{dy}{dx}=\dfrac{y+1}{xy}+y\)

ដោះស្រាយសមីការដែលញែកអថេរបាន តាមលក្ខខណ្ឌដើម \(y(0)=-2\) ។

ដំណោះស្រាយ

  • **ការសម្គាល់សមីការដែលអាចញែកអថេរបាន ៖**

    1. \(y' = 3+y \iff \dfrac{dy}{y+3} = dx\) \(\implies\) អាចញែកអថេរបាន។

    2. \(\dfrac{dy}{dx} = \sin(x+y)\) \(\implies\) មិនអាចញែកអថេរបាន។

    3. \(y' = y^2-4 \iff \dfrac{dy}{y^2-4} = dx\) \(\implies\) អាចញែកអថេរបាន។

    4. \(\dfrac{dy}{dx} = \dfrac{y+1+xy^2}{xy}\) \(\implies\) មិនអាចញែកអថេរបាន។

  • **ដោះស្រាយសមីការដែលញែកបានតាមលក្ខខណ្ឌ \(y(0) = -2\) ៖**

    • ចំពោះសមីការ (១) ៖ \(\dfrac{dy}{y+3} = dx \implies \ln|y+3| = x + C\)។
      ជំនួស \(x = 0, y = -2\) ៖ \(\ln|-2+3| = 0 + C \implies C = \ln 1 = 0\)។
      នាំឱ្យ \(\ln(y+3) = x \iff y+3 = e^x \iff y = e^x - 3\)។

    • ចំពោះសមីការ (៣) ៖ \(y' = y^2 - 4\)។
      សង្កេតឃើញថា ចំពោះអនុគមន៍ថេរ \(y(x) \equiv -2\) នោះ \(y' = 0\) ហើយ \((-2)^2 - 4 = 0\) ផ្ទៀងផ្ទាត់សមីការភ្លាមៗ និងផ្ទៀងផ្ទាត់លក្ខខណ្ឌ \(y(0) = -2\)។
      ដូចនេះ ចម្លើយពិសេសគឺអនុគមន៍ថេរ \(y = -2\)។

សមីការឌីផេរ៉ង់ស្យែលលីនេអ៊ែលំដាប់ទី \(1\) មេគុណថេរអូម៉ូសែន (អង្គទី \(2\) ស្មើសូន្យ)

និយមន័យ

និយមន័យ

សមីការឌីផេរ៉ង់ស្យែលលីនេអ៊ែលំដាប់ទី 1 មេគុណថេរអូម៉ូសែន (អង្គទី 2 ស្មើសូន្យ) ជាសមីការដែលមានរាងទូទៅ ៖

\[y'+ay=0 \quad{} (a \text{ ជាចំនួនថេរពិត})\]
ចម្លើយទូទៅនៃសមីការគឺ \(y = A e^{-ax}\) ដែល \(A\) ជាចំនួនថេរពិតណាមួយ។

របៀបដោះស្រាយសមីការ \(y'+ay=0\)

គេអាចសរសេរ ៖

\[y' = -ay \iff \frac{dy}{dx} = -ay\]
តាមវិធីញែកអថេរ គេបាន \(\dfrac{dy}{y} = -a\,dx\)។
ធ្វើអាំងតេក្រាលលើអង្គទាំងពីរ ៖
\[\begin{aligned} \int \frac{dy}{y} &= \int -a\,dx\\ \ln|y| &= -ax + c\\ |y| &= e^{-ax+c} = e^c \cdot e^{-ax}\\ y &= \pm e^c \cdot e^{-ax} \end{aligned}\]
តាង \(A = \pm e^c\) (ជាចំនួនថេរពិតមិនសូន្យ រួមទាំង \(A=0\) ចំពោះចម្លើយ \(y \equiv 0\)) គេបាន ៖
\[y = A e^{-ax} \quad{} (A \in \mathbb{R})\]
ដូចនេះ \(y = A e^{-ax}\) ជាចម្លើយទូទៅនៃសមីការឌីផេរ៉ង់ស្យែលលីនេអ៊ែលំដាប់ទី 1 អូម៉ូសែន។

ឧទាហរណ៍

រកចម្លើយទូទៅនៃសមីការ \(y'+y=0\) ។ រកចម្លើយពិសេសនៃសមីការនេះ តាមលក្ខខណ្ឌ \(y(0)=-1 , y(0)=1, y(1)=1\) រួចសង់ខ្សែកោងតាងអនុគមន៍ចម្លើយនីមួយៗ។

ដំណោះស្រាយ

សមីការ \(y' + y = 0\) មានរាង \(y' + ay = 0\) ដែល \(a = 1\)។
ចម្លើយទូទៅនៃសមីការគឺ ៖

\[y = Ce^{-x} \quad{} (C \in \mathbb{R})\]

  • បើ \(y(0) = -1 \implies Ce^0 = -1 \implies C = -1 \implies y_1 = -e^{-x}\)

  • បើ \(y(0) = 1 \implies Ce^0 = 1 \implies C = 1 \implies y_2 = e^{-x}\)

  • បើ \(y(1) = 1 \implies Ce^{-1} = 1 \implies C = e \implies y_3 = e \cdot e^{-x} = e^{1-x}\)

ឧទាហរណ៍

ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែល \(-y'+2y=0\) តាមលក្ខខណ្ឌ \(y(3)=-2\) ។

ដំណោះស្រាយ

គេមាន \(-y' + 2y = 0 \iff y' - 2y = 0\) (ទម្រង់ \(y' + ay = 0\) ដែល \(a = -2\))។
ចម្លើយទូទៅគឺ ៖

\[y = Ce^{-(-2)x} = Ce^{2x} \quad{} (C \in \mathbb{R})\]
តាមលក្ខខណ្ឌដើម \(y(3) = -2\) គេបាន ៖
\[Ce^{2(3)} = -2 \iff Ce^6 = -2 \iff C = -2e^{-6}\]
ជំនួស \(C\) ចូលក្នុងចម្លើយទូទៅ ៖
\[y = (-2e^{-6})e^{2x} = -2e^{2x-6} = -2e^{2(x-3)}\]
ដូចនេះ ចម្លើយពិសេសដែលត្រូវរកគឺ \(y = -2e^{2(x-3)}\)។

ឧទាហរណ៍

រកអនុគមន៍ចម្លើយនៃសមីការ \(3y'+6y=0\) ដែលខ្សែកោងតាងអនុគមន៍ចម្លើយនេះកាត់តាមចំណុច \((-4,2)\) ។

ដំណោះស្រាយ

ចែកអង្គទាំងពីរនៃសមីការនឹង 3 គេបាន ៖

\[3y' + 6y = 0 \iff y' + 2y = 0\]
ចម្លើយទូទៅគឺ \(y = Ce^{-2x}\) (\(C \in \mathbb{R}\))។
ដោយខ្សែកោងតាងអនុគមន៍ចម្លើយកាត់តាមចំណុច \((-4, 2)\) នោះគេបាន \(y(-4) = 2\) ៖
\[Ce^{-2(-4)} = 2 \iff Ce^8 = 2 \iff C = 2e^{-8}\]
ជំនួស \(C\) ចូលក្នុងចម្លើយទូទៅ ៖
\[y = (2e^{-8})e^{-2x} = 2e^{-2(x+4)}\]
ដូចនេះ អនុគមន៍ចម្លើយដែលត្រូវរកគឺ \(y = 2e^{-2(x+4)}\)។

សមីការឌីផេរ៉ង់ស្យែលលីនេអ៊ែលំដាប់ទី ១ មេគុណថេរមិនអូម៉ូសែន (អង្គទី ២ ខុសពីសូន្យ)

និយមន័យ

សមីការឌីផេរ៉ង់ស្យែលលីនេអ៊ែលំដាប់ទី ១ មេគុណថេរ(អង្គទី ២ ខុសពីសូន្យ) ជាសមីការដែលមានរាងទូទៅ \(y' +ay=p(x), \ \ \ a\) ជាចំនួនថេរ និង \(p(x)\) ជាអនុគមន៍នៃ \(x\)។

ជាទូទៅ

របៀបដោះស្រាយសមីការ \(y'+ay=p(x)\)
ដើម្បីដោះស្រាយ សមីការឌីផេរ៉ង់ស្យែលលីនេអ៊ែលំដាប់ទី ១ មេគុណថេរមិនអូម៉ូសែន \(y' +ay=p(x)\) ដែល \(p(x)\neq 0\) គេត្រូវ ៖

  1. រកអនុគមន៍ចម្លើយទូទៅនៃសមីការ \(y'+ay=0\) តាងដោយ \(y_c=Ae^{-ax}\)

  2. រកអនុគមន៍ចម្លើយពិសេសនៃសមីការ \(y'+ay=p(x)\) តាងដោយ \(y_p\) ដែល \(y_p\) មានរាងដូច \(p(x)\)
    ex: \(p(x)\) ដឺក្រេទី ១ តាង \(y_p=ax+b\) , \(a, b\in \mathbb{R}, a\neq 0\)
    \(p(x)\) ដឺក្រេទី ២ តាង \(y_p=ax^2+bx+c\) ដែល \(a, b, c \in \mathbb{R}, a\neq 0\)

  3. ចម្លើយទូទៅនៃសមីការ \(y'+ay=p(x)\) គឺអនុគមន៍ \(y\) ដែល \(y=y_c+y_p\)

ដំណោះស្រាយសមីការ \(y'+ay=p(x)\) តាមវិធីបម្រែបម្រួលចំនួនថេរ

ជាទូទៅ

ដើម្បីដោះស្រាយសមីការ \(y'+ay=p(x) \ \ :(E),\ \ p(x)\neq0\) នោះគេត្រូវ៖

  1. រកចម្លើយទូទៅនៃសមីការ \(y'+ay=0\) គឺ មានរាង \(y=Ae^{-ax}\) (\(A\) ជាចំនួនថេរណាមួយក៏បាន)

  2. ក្នុងចម្លើយ \(y=Ae^{-ax}\) ជំនួសចំនួនថេរ \(A\) ដោយអនុគមន៍ \(A(x)\)

  3. ពី \(y=A(x)e^{-ax}\) ទាញរក \(y'\) រួចយក \(y\) និង \(y'\) ជំនួសក្នងសមីការ \(y'+ay=p(x)\)
    ដើម្បីទាញរក \(A(x)\) គេបាន ៖
    \(y=A(x)e^{-ax} \ \ \ \ \ \ \Rightarrow \ \ \ \ \ y'=A'(x)e^{-ax}-aA(x)e^{-ax}\)

    \[\begin{aligned} (E) \ \ : \ \ y'+ay&=p(x)\\ A'(x)e^{-ax}-aA(x)e^{-ax}+aA(x)e^{-ax}&=p(x)\\ A'(x)e^{-ax}&=p(x)\\ A'(x)&=e^{ax}p(x)\\ \Rightarrow \ \ \ A(x)&=\int{e^{ax}p(x)dx}+c\\ \text{ដូចនេះ} \ \ y&=e^{-ax}\left[\int{e^{ax}p(x)dx}+c\right] \end{aligned}\]
    ចម្លើយទូទៅនៃ \((E)\) គឺ   \(y=ce^{-ax}+e^{-ax}\int{e^{ax}p(x)dx}\)   
    ដែល \(y_c=ce^{-ax}\) និង \(y_p=e^{-ax}\int{e^{ax}p(x)dx}\)

ឧទាហរណ៍

ដោះស្រាយសមីការ   \(y'+y=2e^x \ \ \ \ (E)\)

ដំណោះស្រាយ

សមីការ \((E) : y' + y = 2e^x\) ជាសមីការលីនេអ៊ែលំដាប់ទី១ មិនអូម៉ូសែន។
របៀបទី១ ៖ តាមវិធីមេគុណមិនកំណត់ (\(y = y_c + y_p\))

  • ចម្លើយនៃសមីការអូម៉ូសែន \(y' + y = 0\) គឺ \(y_c = Ce^{-x}\) (\(C\) ជាចំនួនថេរ)។

  • រកចម្លើយពិសេស \(y_p\) ៖ ដោយអង្គទីពីរគឺ \(p(x) = 2e^x\) គេតាង \(y_p = Ae^x\)។
    គណនា \(y_p' = Ae^x\) រួចជំនួសចូលក្នុង \((E)\) ៖

    \[Ae^x + Ae^x = 2e^x \iff 2Ae^x = 2e^x \iff 2A = 2 \iff A = 1\]
    នាំឱ្យ \(y_p = e^x\)។

  • ដូចនេះ ចម្លើយទូទៅគឺ \(y = y_c + y_p = Ce^{-x} + e^x\) (\(C \in \mathbb{R}\))។

របៀបទី២ ៖ តាមវិធីបម្រែបម្រួលចំនួនថេរ

  • តាង \(y = C(x)e^{-x} \implies y' = C'(x)e^{-x} - C(x)e^{-x}\)។

  • ជំនួសចូលក្នុង \((E)\) ៖

    \[C'(x)e^{-x} - C(x)e^{-x} + C(x)e^{-x} = 2e^x \iff C'(x)e^{-x} = 2e^x \iff C'(x) = 2e^{2x}\]

  • នាំឱ្យ \(C(x) = \int 2e^{2x}\,dx = e^{2x} + C_0\) (\(C_0 \in \mathbb{R}\))។

  • ជំនួស \(C(x)\) ត្រឡប់មកវិញ ៖ \(y = (e^{2x} + C_0)e^{-x} = e^x + C_0 e^{-x}\)។

ដូចនេះ ចម្លើយទូទៅនៃសមីការគឺ \(y = Ce^{-x} + e^x\) (\(C\) ជាចំនួនថេរ)។

  6. គេមានសមីការឌីផេរ៉ង់ស្យែល \((E) \ \ : \ \ y'+2y=x^2\) ។

    1. កំណត់ពហុធា \(g\) មានដឺក្រេទី \(2\) ដែលជាចម្លើយពិសេសនៃ \((E)\) ។

    2. តាង \(h\) ជាអនុគមន៍ដែល \(h(x)=f(x)-g(x)\) ។ បើ \(h\) ជាចម្លើយនៃសមីការឌីផេរ៉ង់ស្យែល \(y'+2y=0\) នោះបង្ហាញថា \(f\) ជាចម្លើយទូទៅនៃសមីការ \((E)\) ។

    3. ដោះស្រាយសមីការ \(y'+2y=0\) រួចទាញរកអនុគមន៍ \(f\) ដែលជាចម្លើយទូទៅនៃ \((E)\)។

  7. គេមានសមីការឌីផេរ៉ង់ស្យែល \((E) \ \ : \ \ y'-2y=\dfrac{-2}{1+e^{-2x}}\)

    1. ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែល \(y'-2y=0\) ដែលផ្ទៀងផ្ទាត់ \(y(0)=1\) ។

    2. តាង \(f\) ជាអនុគមន៍មានដេរីវេ \(\mathbb{R}\) ដែល \(f(x)=e^{2x}g(x)\) ។ គណនា \(f'(x)\) ជាអនុគមន៍នៃ \(g(x)\) និង \(g'(x)\) ។

    3. បង្ហាញថាបើ \(f\) ជាចម្លើយនៃ \((E)\) លុះត្រាតែ \(g'(x)=\dfrac{-2e^{-2x}}{1+e^{-2x}}\) ។

    4. ទាញរកកន្សោម \(g(x)\) រួច \(f(x)\) ដែល \(f\) ជាចម្លើយនៃ \((E)\) ។

  8. គេមានសមីការឌីផេរ៉ង់ស្យែល \((E) \ \ : \ \ y'+y=xe^{-x}\)

    1. ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែល \((E_0) \ : \ y'+y=0\) ។

    2. រកចំនួនពិត \(m\) និង \(n\) ដើម្បីឱ្យអនុគមន៍ \(g(x)=(mx^2+nx)e^{-x}\) ជាចម្លើយពិសេសនៃសមីការ \((E)\) ។

    3. ទាញរកចម្លើយទូទៅនៃសមីការ \((E)\) រួចកំណត់ចម្លើយ \(f\) នៃ \((E)\) ដែលផ្ទៀងផ្ទាត់លក្ខខណ្ឌ \(y(0)=2\) ។

  9. ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែល :

    1. \(\dfrac{dy}{dx}-y=e^{3x}\)

    4. \(y'+y=\sin x\)

    1. \(y'-3y=3x+2\)

លំហាត់ទី ១

ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែលខាងក្រោម ៖

ក  \(y' = 2x^2 - x + 1\)
ខ  \(y' = e^{-2x}\)
គ  \(y' = \dfrac{2x}{x^2+1}\)
ឃ  \(y' = \dfrac{x}{x^2-1}\)   \((-1,1)\)
ង  \(xy' = 1\)   \((0,+\infty)\)

ដំណោះស្រាយ

ក  \(y' = 2x^2 - x + 1 \implies y = \int (2x^2 - x + 1)\,dx\) ៖
ដូចនេះ ៖ \(\boxed{y = \dfrac{2}{3}x^3 - \dfrac{1}{2}x^2 + x + C}\)

ខ  \(y' = e^{-2x} \implies y = \int e^{-2x}\,dx\) ៖
ដូចនេះ ៖ \(\boxed{y = -\dfrac{1}{2}e^{-2x} + C}\)

គ  \(y' = \dfrac{2x}{x^2+1} \implies y = \int \dfrac{2x}{x^2+1}\,dx\) ៖
ដូចនេះ ៖ \(\boxed{y = \ln(x^2+1) + C}\)

ឃ  \(y' = \dfrac{x}{x^2-1}\) លើ \((-1, 1)\) ៖
\(y = \dfrac{1}{2}\int \dfrac{2x}{x^2-1}\,dx = \dfrac{1}{2}\ln|x^2-1| + C\)។
ដោយ \(x \in (-1, 1) \implies |x^2-1| = 1-x^2\) ៖
ដូចនេះ ៖ \(\boxed{y = \dfrac{1}{2}\ln(1-x^2) + C}\)

ង  \(xy' = 1 \iff y' = \dfrac{1}{x} \implies y = \ln x + C\)។
ដូចនេះ ៖ \(\boxed{y = \ln x + C}\)

លំហាត់ទី ២

ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែលតាមលក្ខខណ្ឌដែលឱ្យ ៖

ក  \(\dfrac{y'}{y} = \cos x \ , \ y\left(\dfrac{\pi}{2}\right) = e\)
ខ  \(y' = e^{2x} \ , \ y(0) = 5\)
គ  \((3x^2-2)y' = 6x \ , \ y(1) = 4\)
ឃ  \(\dfrac{y'}{\tan x} = 1 \ , \ y(0) = 0\)

ដំណោះស្រាយ

ក  \(\dfrac{y'}{y} = \cos x \ , \ y\left(\dfrac{\pi}{2}\right) = e\)
\(\ln|y| = \sin x + c \iff y = Ce^{\sin x}\)។
\(y\left(\dfrac{\pi}{2}\right) = Ce^1 = e \implies C = 1\)។  ដូចនេះ ៖ \(\boxed{y = e^{\sin x}}\)

ខ  \(y' = e^{2x} \ , \ y(0) = 5\)
\(y = \dfrac{1}{2}e^{2x} + C \implies \dfrac{1}{2} + C = 5 \implies C = \dfrac{9}{2}\)។
ដូចនេះ ៖ \(\boxed{y = \dfrac{1}{2}e^{2x} + \dfrac{9}{2}}\)

គ  \((3x^2-2)y' = 6x \ , \ y(1) = 4\)
\(y = \ln|3x^2-2| + C \implies \ln|1| + C = 4 \implies C = 4\)។
ដូចនេះ ៖ \(\boxed{y = \ln|3x^2-2| + 4}\)

ឃ  \(\dfrac{y'}{\tan x} = 1 \implies y' = \tan x \ , \ y(0) = 0\)
\(y = -\ln|\cos x| + C \implies -\ln(1) + C = 0 \implies C = 0\)។
ដូចនេះ ៖ \(\boxed{y = -\ln|\cos x|}\)

លំហាត់ទី ៣

ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែលលីនេអ៊ែលំដាប់ទី \(1\) (\(y' + ay = 0\)) ៖

ក  \(\dfrac{dy}{dx} + 2y = 0\)
ខ  \(3\dfrac{dy}{dx} + y = 0\)
គ  \(2y' - 3y = 0\)
ឃ  \(y' + y\sqrt{2} = 0\)

ដំណោះស្រាយ

ក  \(\dfrac{dy}{dx} + 2y = 0\) (\(a = 2\)) ៖
ដូចនេះ ៖ \(\boxed{y = Ce^{-2x} \quad{} (C \in \mathbb{R})}\)

ខ  \(3y' + y = 0 \iff y' + \dfrac{1}{3}y = 0\) (\(a = \dfrac{1}{3}\)) ៖
ដូចនេះ ៖ \(\boxed{y = Ce^{-\frac{1}{3}x} \quad{} (C \in \mathbb{R})}\)

គ  \(2y' - 3y = 0 \iff y' - \dfrac{3}{2}y = 0\) (\(a = -\dfrac{3}{2}\)) ៖
ដូចនេះ ៖ \(\boxed{y = Ce^{\frac{3}{2}x} \quad{} (C \in \mathbb{R})}\)

ឃ  \(y' + y\sqrt{2} = 0\) (\(a = \sqrt{2}\)) ៖
ដូចនេះ ៖ \(\boxed{y = Ce^{-x\sqrt{2}} \quad{} (C \in \mathbb{R})}\)

លំហាត់ទី ៤

ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែលតាមលក្ខខណ្ឌដើម ៖

ក  \(-y' + 2y = 0 \ , \ y(3) = -2\)
ខ  \(2y' + y = 0 \ , \ y(\ln 4) = \dfrac{1}{5}\)
គ  \(7y' + 4y = 0 \ , \ y(7) = e^{-4}\)
ឃ  \(2y' - 5y = 0 \ , \ y(1) = -3\)

ដំណោះស្រាយ

ក  \(-y' + 2y = 0 \iff y' - 2y = 0\) (\(a = -2\)) ៖
\(y = Ce^{2x} \ , \ y(3) = -2 \implies C = -2e^{-6}\)។
ដូចនេះ ៖ \(\boxed{y = -2e^{2(x-3)}}\)

ខ  \(2y' + y = 0 \iff y' + \dfrac{1}{2}y = 0\) ៖
\(y = Ce^{-\frac{1}{2}x} \ , \ y(\ln 4) = \dfrac{C}{2} = \dfrac{1}{5} \implies C = \dfrac{2}{5}\)។
ដូចនេះ ៖ \(\boxed{y = \dfrac{2}{5}e^{-\frac{1}{2}x}}\)

គ  \(7y' + 4y = 0 \iff y' + \dfrac{4}{7}y = 0\) ៖
\(y = Ce^{-\frac{4}{7}x} \ , \ y(7) = Ce^{-4} = e^{-4} \implies C = 1\)។
ដូចនេះ ៖ \(\boxed{y = e^{-\frac{4}{7}x}}\)

ឃ  \(2y' - 5y = 0 \iff y' - \dfrac{5}{2}y = 0\) ៖
\(y = Ce^{\frac{5}{2}x} \ , \ y(1) = Ce^{5/2} = -3 \implies C = -3e^{-5/2}\)។
ដូចនេះ ៖ \(\boxed{y = -3e^{\frac{5}{2}(x-1)}}\)

លំហាត់ទី ៥

បង្ហាញថាអនុគមន៍នីមួយៗខាងក្រោមជាចម្លើយនៃសមីការឌីផេរ៉ង់ស្យែលនៅខាងស្តាំ ៖

ក  \(y = x + e^x \ , \ y' - y = 1 - x\)
ខ  \(y = e^{3x} - x - 1 \ , \ y' - 3y = 3x + 2\)
គ  \(y = \sin x + \cos x \ , \ y' + y = 2\cos x\)
ឃ  \(y = x + \ln x \ , \ xy' - y = 1 - \ln x\)

ដំណោះស្រាយ

ក  \(y = x + e^x \implies y' = 1 + e^x\) ៖
\(y' - y = (1 + e^x) - (x + e^x) = 1 - x\)។
ដូចនេះ ៖ \(y = x + e^x\) ជាចម្លើយ

ខ  \(y = e^{3x} - x - 1 \implies y' = 3e^{3x} - 1\) ៖
\(y' - 3y = (3e^{3x} - 1) - 3(e^{3x} - x - 1) = 3x + 2\)។
ដូចនេះ ៖ \(y = e^{3x} - x - 1\) ជាចម្លើយ

គ  \(y = \sin x + \cos x \implies y' = \cos x - \sin x\) ៖
\(y' + y = (\cos x - \sin x) + (\sin x + \cos x) = 2\cos x\)។
ដូចនេះ ៖ \(y = \sin x + \cos x\) ជាចម្លើយ

ឃ  \(y = x + \ln x \implies y' = 1 + \dfrac{1}{x}\) ៖
\(xy' - y = x\left(1 + \dfrac{1}{x}\right) - (x + \ln x) = 1 - \ln x\)។
ដូចនេះ ៖ \(y = x + \ln x\) ជាចម្លើយ

លំហាត់ទី ៦

សមីការឌីផេរ៉ង់ស្យែល \((E) : y' + 2y = x^2\)

ក  កំណត់ពហុធា \(g(x) = ax^2 + bx + c\) ជាចម្លើយពិសេសនៃ \((E)\)។
ខ  បង្ហាញ \(f\) ជាចម្លើយ \((E) \iff h = f - g\) ជាចម្លើយនៃ \(y' + 2y = 0\)។
គ  ដោះស្រាយ \(y' + 2y = 0\) រួចទាញរកចម្លើយទូទៅនៃ \((E)\)។

ដំណោះស្រាយ

ក  \(g'(x) = 2ax + b\)។ ជំនួសចូល \((E)\) ៖
\(2ax^2 + (2a+2b)x + (b+2c) = x^2\)
\(\implies a = \dfrac{1}{2} \ , \ b = -\dfrac{1}{2} \ , \ c = \dfrac{1}{4}\)។
ដូចនេះ ៖ \(\boxed{g(x) = \dfrac{1}{2}x^2 - \dfrac{1}{2}x + \dfrac{1}{4}}\)

ខ  \(h' + 2h = (f'+2f) - (g'+2g) = x^2 - x^2 = 0\) (ពិត)។

គ  \(y' + 2y = 0 \implies h(x) = Ce^{-2x}\)។
ដូចនេះ ៖ \(\boxed{f(x) = Ce^{-2x} + \dfrac{1}{2}x^2 - \dfrac{1}{2}x + \dfrac{1}{4}}\)

លំហាត់ទី ៧

គេមានសមីការឌីផេរ៉ង់ស្យែល \((E) : y' - 2y = \dfrac{-2}{1+e^{-2x}}\)

ក  ដោះស្រាយ \(y' - 2y = 0\) ដែល \(y(0) = 1\)។
ខ  តាង \(f(x) = e^{2x}g(x)\)។ គណនា \(f'(x)\)។
គ  បង្ហាញ \(f\) ជាចម្លើយ \((E) \iff g'(x) = \dfrac{-2e^{-2x}}{1+e^{-2x}}\)។
ឃ  រកកន្សោម \(g(x)\) រួចទាញរក \(f(x)\)។

ដំណោះស្រាយ

ក  \(y' - 2y = 0 \implies y = Ce^{2x}\)។
\(y(0) = 1 \implies C = 1\)។  ដូចនេះ ៖ \(\boxed{y = e^{2x}}\)

ខ  ដេរីវេផលគុណ ៖ \(\boxed{f'(x) = 2e^{2x}g(x) + e^{2x}g'(x)}\)

គ  \(f'(x) - 2f(x) = e^{2x}g'(x) = \dfrac{-2}{1+e^{-2x}}\)
\(\iff\) \(\boxed{g'(x) = \dfrac{-2e^{-2x}}{1+e^{-2x}}}\)

ឃ  \(g(x) = \int \dfrac{-2e^{-2x}}{1+e^{-2x}}\,dx = \ln(1+e^{-2x}) + C\)។
ដូចនេះ ៖ \(\boxed{f(x) = e^{2x}\ln(1+e^{-2x}) + Ce^{2x}}\)

លំហាត់ទី ៨

គេមានសមីការឌីផេរ៉ង់ស្យែល \((E) : y' + y = xe^{-x}\)

ក  ដោះស្រាយសមីការ \((E_0) : y' + y = 0\)។
ខ  រក \(m, n\) ដើម្បី \(g(x) = (mx^2+nx)e^{-x}\) ជាចម្លើយ \((E)\)។
គ  រកចម្លើយទូទៅនៃ \((E)\) រួចរក \(f\) ដែល \(y(0) = 2\)។

ដំណោះស្រាយ

ក  \((E_0) : y' + y = 0 \implies\) \(\boxed{y_0 = Ce^{-x}}\)

ខ  \(g'(x) + g(x) = (2mx+n)e^{-x} = xe^{-x}\)
\(\implies 2m = 1 \implies m = \dfrac{1}{2} \ , \ n = 0\)។
ដូចនេះ ៖ \(\boxed{g(x) = \dfrac{1}{2}x^2 e^{-x}}\)

គ  ចម្លើយទូទៅនៃ \((E)\) គឺ ៖
\(y = y_0 + g(x) = \left(C + \dfrac{1}{2}x^2\right)e^{-x}\)។
\(y(0) = 2 \implies C = 2\)។
ដូចនេះ ៖ \(\boxed{f(x) = \left(2 + \dfrac{1}{2}x^2\right)e^{-x}}\)

លំហាត់ទី ៩

ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែលមិនអូម៉ូសែន ៖

ក  \(\dfrac{dy}{dx} - y = e^{3x}\)
ខ  \(\dfrac{dy}{dx} + y = x - 1\)
គ  \(y' + y = xe^x\)
ឃ  \(y' + y = \sin x\)

ដំណោះស្រាយ

ក  \(y' - y = e^{3x}\)
ចម្លើយអូម៉ូសែន ៖ \(y_h = Ce^x\)។
រកចម្លើយពិសេស \(y_p = Ae^{3x} \implies 3Ae^{3x} - Ae^{3x} = e^{3x} \implies A = \dfrac{1}{2}\)។
ដូចនេះ ៖ \(\boxed{y = Ce^x + \dfrac{1}{2}e^{3x}}\)

ខ  \(y' + y = x - 1\)
ចម្លើយអូម៉ូសែន ៖ \(y_h = Ce^{-x}\)។
យក \(y_p = ax + b \implies a + ax + b = x - 1 \implies a = 1, b = -2\)។
ដូចនេះ ៖ \(\boxed{y = Ce^{-x} + x - 2}\)

គ  \(y' + y = xe^x\)
ចម្លើយអូម៉ូសែន ៖ \(y_h = Ce^{-x}\)។
យក \(y_p = (ax+b)e^x \implies y_p' + y_p = (2ax + a + 2b)e^x = xe^x \implies a = \dfrac{1}{2}, b = -\dfrac{1}{4}\)។
ដូចនេះ ៖ \(\boxed{y = Ce^{-x} + \left(\dfrac{1}{2}x - \dfrac{1}{4}\right)e^x}\)

ឃ  \(y' + y = \sin x\)
ចម្លើយអូម៉ូសែន ៖ \(y_h = Ce^{-x}\)។
យក \(y_p = A\cos x + B\sin x \implies y_p' + y_p = (B+A)\cos x + (B-A)\sin x = \sin x \implies A = -\dfrac{1}{2}, B = \dfrac{1}{2}\)។
ដូចនេះ ៖ \(\boxed{y = Ce^{-x} - \dfrac{1}{2}\cos x + \dfrac{1}{2}\sin x}\)

លំហាត់ទី ១០

ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែលតាមលក្ខខណ្ឌដើម ៖

ក  \(y' - y = 1 \ , \ y(0) = 1\)
ខ  \(y' + 2y = 1 \ , \ y(0) = 0\)

ដំណោះស្រាយ

ក  \(y' - y = 1 \ , \ y(0) = 1\)
ចម្លើយទូទៅ ៖ \(y = Ce^x - 1\)។
\(y(0) = 1 \implies C - 1 = 1 \implies C = 2\)។
ដូចនេះ ៖ \(\boxed{y = 2e^x - 1}\)

ខ  \(y' + 2y = 1 \ , \ y(0) = 0\)
ចម្លើយទូទៅ ៖ \(y = Ce^{-2x} + \dfrac{1}{2}\)។
\(y(0) = 0 \implies C + \dfrac{1}{2} = 0 \implies C = -\dfrac{1}{2}\)។
ដូចនេះ ៖ \(\boxed{y = \dfrac{1}{2}\left(1 - e^{-2x}\right)}\)

លំហាត់ទី ១១

ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែលខាងក្រោម ៖

ក  \(y' - 3y = 3x + 2\)
ខ  \(xy' - y = 1 - \ln x\)
គ  \(y' + 2y = e^{-2x}\)
ឃ  \(y' + y = 2e^x\)
ង  \(y' + y = \cos x + \sin x\)
ច  \(y' + 2y = 2x^2 - 3\)
ឆ  \(y' + 5y = 20 \ , \ y(0) = 2\)
ជ  \(y' + y = 1 \ , \ y(0) = 0\)

ដំណោះស្រាយ

ក  \(y' - 3y = 3x + 2\)
ចម្លើយអូម៉ូសែន ៖ \(y_h = Ce^{3x}\)។
ចម្លើយពិសេស ៖ \(y_p = -x - 1\)។
ដូចនេះ ៖ \(\boxed{y = Ce^{3x} - x - 1}\)

ខ  \(xy' - y = 1 - \ln x\)
ចែកនឹង \(x^2\) ៖ \(\left(\dfrac{y}{x}\right)' = \dfrac{1 - \ln x}{x^2} = \left(\dfrac{\ln x}{x}\right)'\)។
ដូចនេះ ៖ \(\boxed{y = Cx + \ln x}\)

គ  \(y' + 2y = e^{-2x}\)
ចម្លើយអូម៉ូសែន ៖ \(y_h = Ce^{-2x}\)។
ចម្លើយពិសេស ៖ \(y_p = xe^{-2x}\)។
ដូចនេះ ៖ \(\boxed{y = (x + C)e^{-2x}}\)

ឃ  \(y' + y = 2e^x\)
ចម្លើយអូម៉ូសែន ៖ \(y_h = Ce^{-x}\)។
ចម្លើយពិសេស ៖ \(y_p = e^x\)។
ដូចនេះ ៖ \(\boxed{y = Ce^{-x} + e^x}\)

ង  \(y' + y = \cos x + \sin x\)
ចម្លើយអូម៉ូសែន ៖ \(y_h = Ce^{-x}\)។
ចម្លើយពិសេស ៖ \(y_p = \sin x\)។
ដូចនេះ ៖ \(\boxed{y = Ce^{-x} + \sin x}\)

ច  \(y' + 2y = 2x^2 - 3\)
ចម្លើយអូម៉ូសែន ៖ \(y_h = Ce^{-2x}\)។
ចម្លើយពិសេស ៖ \(y_p = x^2 - x - 1\)។
ដូចនេះ ៖ \(\boxed{y = Ce^{-2x} + x^2 - x - 1}\)

ឆ  \(y' + 5y = 20 \ , \ y(0) = 2\)
ចម្លើយទូទៅ ៖ \(y = Ce^{-5x} + 4\)។
\(y(0) = 2 \implies C + 4 = 2 \implies C = -2\)។
ដូចនេះ ៖ \(\boxed{y = 4 - 2e^{-5x}}\)

ជ  \(y' + y = 1 \ , \ y(0) = 0\)
ចម្លើយទូទៅ ៖ \(y = Ce^{-x} + 1\)។
\(y(0) = 0 \implies C + 1 = 0 \implies C = -1\)។
ដូចនេះ ៖ \(\boxed{y = 1 - e^{-x}}\)
