    ដោយប្រើនិយមន័យចូរបង្ហាញថា៖

    1. \(\lim_{x \to -2}\frac{x^2-1}{x+1}=-3\)
      តាមនិយមន័យ៖ \(\forall \varepsilon > 0, |f(x)-L| < \varepsilon\)
      \(\begin{aligned} |f(x)-L| < \varepsilon &\Leftrightarrow \left|\frac{x^2-1}{x+1}-(-3)\right| < \varepsilon\\ &\Leftrightarrow \left|\frac{(x+2)(x+1)}{x+1}\right| < \varepsilon\\ &\Leftrightarrow |x+2| < \varepsilon = \alpha \end{aligned}\)
      យក \(\alpha = \varepsilon > 0\) នោះ \(\forall |x+2| < \alpha\) នាំឱ្យ \(|f(x)-L| < \varepsilon\) ។
      ដូចនេះ

    2. \(\lim_{x \to a}(mx+b) = ma+b\)
      តាមនិយមន័យ៖ \(\forall \varepsilon > 0, |f(x)-L| < \varepsilon\)
      \(\begin{aligned} |f(x)-L| < \varepsilon &\Leftrightarrow |(mx+b)-(ma+b)| < \varepsilon\\ &\Leftrightarrow |m(x-a)| < \varepsilon\\ &\Leftrightarrow |m||x-a| < \varepsilon\\ &\Leftrightarrow |x-a| < \frac{\varepsilon}{|m|} \quad{} (m\neq 0) \end{aligned}\)
      យក \(\alpha = \frac{\varepsilon}{|m|} > 0\) នោះ \(\forall |x-a| < \alpha\) នាំឱ្យ \(|f(x)-L| < \varepsilon\) ។
      ដូចនេះ

    3. \(\lim_{x \to 0}\sqrt[3]{x} = 0\)
      តាមនិយមន័យ៖ \(\forall \varepsilon > 0, |f(x)-L| < \varepsilon\)
      \(\begin{aligned} |f(x)-L| < \varepsilon &\Leftrightarrow |\sqrt[3]{x}-0| < \varepsilon\\ &\Leftrightarrow |\sqrt[3]{x}| < \varepsilon\\ &\Leftrightarrow |x| < \varepsilon^3 \end{aligned}\)
      យក \(\alpha = \varepsilon^3 > 0\) នោះ \(\forall |x| < \alpha\) នាំឱ្យ \(|f(x)-L| < \varepsilon\) ។
      ដូចនេះ

    4. \(\lim_{x \to 2} \sqrt{x} =\sqrt{2}\)
      តាមនិយមន័យ៖ \(\forall \varepsilon > 0, |f(x)-L| < \varepsilon\)
      \(\begin{aligned} |f(x)-L| < \varepsilon &\Leftrightarrow |\sqrt{x}-\sqrt{2}| < \varepsilon\\ &\Leftrightarrow \frac{|x-2|}{\sqrt{x}+\sqrt{2}} < \varepsilon \end{aligned}\)
      យក \(1 < x < 3\) នោះ \(\sqrt{x}+\sqrt{2} > 1+\sqrt{2} > 2\)៖
      \(\frac{|x-2|}{\sqrt{x}+\sqrt{2}} < \frac{|x-2|}{2} < \varepsilon \Leftrightarrow |x-2| < 2\varepsilon\)
      យក \(\alpha = \min(1, 2\varepsilon) > 0\) នោះ \(\forall |x-2| < \alpha\) នាំឱ្យ \(|f(x)-L| < \varepsilon\) ។
      ដូចនេះ

    1. \(\lim_{x \to 2^-}\sqrt{(x-2)(x-3)}= 0\)
      តាមនិយមន័យ៖ \(\forall \varepsilon > 0, |f(x)-L| < \varepsilon\)
      \(\begin{aligned} |f(x)-0| < \varepsilon &\Leftrightarrow |\sqrt{(x-2)(x-3)}| < \varepsilon\\ &\Leftrightarrow |x-2||x-3| < \varepsilon^2 \quad{} (*) \end{aligned}\)
      ដោយ \(x \to 2^-\) យក \(1 < x < 2\)៖
      \(\begin{aligned} 1 < x < 2 &\Leftrightarrow -2 < x-3 < -1\\ &\Leftrightarrow 1 < |x-3| < 2 \quad{} (**) \end{aligned}\)
      តាម \((*)\) និង \((**)\) យើងបាន៖
      \(|x-2||x-3| < 2|x-2| < \varepsilon^2 \Leftrightarrow |x-2| < \frac{\varepsilon^2}{2}\)
      យក \(\alpha = \frac{\varepsilon^2}{2} > 0\) នោះ \(\forall |x-2| < \alpha\) នាំឱ្យ \(|f(x)-L| < \varepsilon\) ។
      ដូចនេះ

    2. \(\lim_{x \to 2}\frac{x^2-1}{x}=\frac{3}{2}\)
      តាមនិយមន័យ៖ \(\forall \varepsilon > 0, |f(x)-L| < \varepsilon\)
      \(\begin{aligned} \left|\frac{x^2-1}{x}-\frac{3}{2}\right| &= \left|\frac{2x^2-3x-2}{2x}\right|\\ &= \frac{|x-2||2x+1|}{|2x|} < \varepsilon \quad{} (*) \end{aligned}\)
      យក \(1 < x < 3\)៖
      \(\bullet\) \(2 < 2x < 6 \Rightarrow |2x| > 2 \Rightarrow \frac{1}{|2x|} < \frac{1}{2}\)
      \(\bullet\) \(3 < 2x+1 < 7 \Rightarrow |2x+1| < 7\)
      តាម \((*)\) នាំឱ្យ៖
      \(\frac{|x-2||2x+1|}{|2x|} < \frac{7|x-2|}{2} < \varepsilon \Leftrightarrow |x-2| < \frac{2\varepsilon}{7}\)
      យក \(\alpha = \min\left(1, \frac{2\varepsilon}{7}\right) > 0\) នោះនាំឱ្យ \(|f(x)-L| < \varepsilon\) ។
      ដូចនេះ

    4. \(\lim_{x \to + \infty}\frac{3x+1}{x} = 3\)

    ដោយប្រើនិយមន័យចូរបង្ហាញថា៖

    1. \(\lim\limits_{x\to 2^-}\frac{3x-1}{x-2} =-\infty\)
      តាមនិយមន័យ៖ \(\forall M > 0, f(x) < -M\)
      \(\begin{aligned} \frac{3x-1}{x-2} < -M &\Leftrightarrow 3+\frac{5}{x-2} < -M\\ &\Leftrightarrow \frac{5}{x-2} < -(M+3)\\ &\Leftrightarrow \frac{5}{2-x} > M+3 \quad{} (x < 2)\\ &\Leftrightarrow 2-x < \frac{5}{M+3} \end{aligned}\)
      យក \(\alpha = \frac{5}{M+3} > 0\) នោះ \(\forall 0 < 2-x < \alpha\) នាំឱ្យ \(f(x) < -M\) ។
      ដូចនេះ

    2. \(\lim\limits_{x\to 2^+}\frac{4x+1}{x-2} = +\infty\)
      តាមនិយមន័យ៖ \(\forall M > 0, f(x) > M\)
      \(\begin{aligned} \frac{4x+1}{x-2} > M &\Leftrightarrow 4+\frac{9}{x-2} > M\\ &\Leftarrow \frac{9}{x-2} > M \quad{} (x > 2)\\ &\Leftrightarrow x-2 < \frac{9}{M} \end{aligned}\)
      យក \(\alpha = \frac{9}{M} > 0\) នោះ \(\forall 0 < x-2 < \alpha\) នាំឱ្យ \(f(x) > M\) ។
      ដូចនេះ

    3. \(\lim_{x \to - \infty}\frac{x^2-2}{x^2+2} = 1\)
      តាមនិយមន័យ៖ \(\forall \varepsilon > 0, |f(x)-L| < \varepsilon\)
      \(\begin{aligned} |f(x)-1| < \varepsilon &\Leftrightarrow \left|\frac{x^2-2}{x^2+2}-1\right| < \varepsilon\\ &\Leftrightarrow \frac{4}{x^2+2} < \frac{4}{x^2} < \varepsilon\\ &\Leftrightarrow x^2 > \frac{4}{\varepsilon} \Leftrightarrow |x| > \frac{2}{\sqrt{\varepsilon}} \end{aligned}\)
      ដោយ \(x \to -\infty \Rightarrow |x| = -x > \frac{2}{\sqrt{\varepsilon}} \Leftrightarrow x < -\frac{2}{\sqrt{\varepsilon}}\)
      យក \(N = \frac{2}{\sqrt{\varepsilon}} > 0\) នោះ \(\forall x < -N\) នាំឱ្យ \(|f(x)-1| < \varepsilon\) ។
      ដូចនេះ

    4. \(\lim_{x \to + \infty}\frac{3x+1}{x} = 3\)
      តាមនិយមន័យ៖ \(\forall \varepsilon > 0, |f(x)-L| < \varepsilon\)
      \(\begin{aligned} |f(x)-3| < \varepsilon &\Leftrightarrow \left|\frac{3x+1}{x}-3\right| < \varepsilon\\ &\Leftrightarrow \frac{1}{|x|} < \varepsilon \Leftrightarrow |x| > \frac{1}{\varepsilon} \end{aligned}\)
      ដោយ \(x \to +\infty \Rightarrow |x| = x > \frac{1}{\varepsilon}\)
      យក \(N = \frac{1}{\varepsilon} > 0\) នោះ \(\forall x > N\) នាំឱ្យ \(|f(x)-3| < \varepsilon\) ។
      ដូចនេះ

    5. \(\lim_{x \to - \infty}(x^2-x-1) =+\infty\)
      តាមនិយមន័យ៖ \(\forall M > 0, f(x) > M\)
      \(\begin{aligned} x^2-x-1 > M &\Leftrightarrow \left(x-\frac{1}{2}\right)^2 - \frac{5}{4} > M\\ &\Leftrightarrow \left(x-\frac{1}{2}\right)^2 > M+\frac{5}{4}\\ &\Leftrightarrow \left|x-\frac{1}{2}\right| > \sqrt{M+\frac{5}{4}} \end{aligned}\)
      ដោយ \(x \to -\infty \Rightarrow \left|x-\frac{1}{2}\right| = \frac{1}{2}-x > \sqrt{M+\frac{5}{4}}\)
      \(\Rightarrow x < \frac{1}{2}-\sqrt{M+\frac{5}{4}} < -\sqrt{M}\)
      យក \(N = \sqrt{M+\frac{5}{4}} > 0\) នោះ \(\forall x < -N\) នាំឱ្យ \(f(x) > M\) ។
      ដូចនេះ

    6. \(\lim_{x \to + \infty}\frac{x^2+3}{2-x} =-\infty\)
      តាមនិយមន័យ៖ \(\forall M > 0, f(x) < -M\)
      \(\begin{aligned} \frac{x^2+3}{2-x} < -M &\Leftrightarrow -(x+2) + \frac{7}{2-x} < -M \end{aligned}\)
      ចំពោះ \(x > 3\) នោះ \(\frac{7}{2-x} < 0\) នាំឱ្យ៖
      \(-(x+2) < -M \Leftrightarrow x > M-2\)
      យក \(N = M+2 > 0\) នោះ \(\forall x > N\) នាំឱ្យ \(f(x) < -M\) ។
      ដូចនេះ

    គណនាតម្លៃ \(\alpha > 0\) ទៅតាមតម្លៃ \(\varepsilon\) នីមួយៗដែលគេឱ្យ៖

    1. \(\lim_{x \to 2}(x^2+x-6) = 0 \quad{} (\varepsilon = 10^{-7})\)
      តាមនិយមន័យ៖ \(|(x^2+x-6)-0| < \varepsilon\)
      \(\Leftrightarrow |x+3||x-2| < \varepsilon \quad{} (*)\)
      ដោយ \(x \to 2\) យក \(1 < x < 3 \Rightarrow |x+3| < 6 \quad{} (**)\)
      តាម \((*)\) និង \((**)\) យើងបាន៖
      \(6|x-2| < \varepsilon \Leftrightarrow |x-2| < \frac{\varepsilon}{6} = \alpha\)
      តែ \(\varepsilon = 10^{-7} \Rightarrow \alpha = \frac{10^{-7}}{6}\)
      ដូចនេះ បើ \(\varepsilon = 10^{-7}\) នោះ \(\alpha = \frac{10^{-7}}{6}\)

    2. \(\lim_{x \to -3}(x^2+x-6) = 0 \quad{} (\varepsilon = 10^{-9})\)
      តាមនិយមន័យ៖ \(|(x^2+x-6)-0| < \varepsilon\)
      \(\Leftrightarrow |x+3||x-2| < \varepsilon \quad{} (*)\)
      ដោយ \(x \to -3\) យក \(-4 < x < -2 \Rightarrow |x-2| < 6 \quad{} (**)\)
      តាម \((*)\) និង \((**)\) យើងបាន៖
      \(6|x+3| < \varepsilon \Leftrightarrow |x+3| < \frac{\varepsilon}{6} = \alpha\)
      តែ \(\varepsilon = 10^{-9} \Rightarrow \alpha = \frac{10^{-9}}{6}\)
      ដូចនេះ បើ \(\varepsilon = 10^{-9}\) នោះ \(\alpha = \frac{10^{-9}}{6}\)

    3. \(\lim_{x \to -1}(3-4x) = 7 \quad{} (\varepsilon = 2\times 10^{-2})\)
      តាមនិយមន័យ៖ \(|(3-4x)-7| < \varepsilon\)
      \(\Leftrightarrow |-4(x+1)| < \varepsilon \Leftrightarrow |x+1| < \frac{\varepsilon}{4} = \alpha\)
      តែ \(\varepsilon = 2\times 10^{-2} \Rightarrow \alpha = \frac{2\times 10^{-2}}{4} = \frac{10^{-2}}{2}\)
      ដូចនេះ បើ \(\varepsilon = 2\times 10^{-2}\) នោះ \(\alpha = \frac{10^{-2}}{2}\)

    4. \(\lim_{x \to 3}x^2 = 9 \quad{} (\varepsilon = 5\times 10^{-3})\)
      តាមនិយមន័យ៖ \(|x^2-9| < \varepsilon\)
      \(\Leftrightarrow |x+3||x-3| < \varepsilon \quad{} (*)\)
      ដោយ \(x \to 3\) យក \(2 < x < 4 \Rightarrow |x+3| < 7 \quad{} (**)\)
      តាម \((*)\) និង \((**)\) យើងបាន៖
      \(7|x-3| < \varepsilon \Leftrightarrow |x-3| < \frac{\varepsilon}{7} = \alpha\)
      តែ \(\varepsilon = 5\times 10^{-3} \Rightarrow \alpha = \frac{5\times 10^{-3}}{7}\)
      ដូចនេះ បើ \(\varepsilon = 5\times 10^{-3}\) នោះ \(\alpha = \frac{5\times 10^{-3}}{7}\)

    5. \(\lim_{x \to -2}\frac{x^2-4}{x+2} = -4 \quad{} (\varepsilon = 10^{-2})\)
      តាមនិយមន័យ៖ \(\left|\frac{x^2-4}{x+2}-(-4)\right| < \varepsilon\)
      \(\Leftrightarrow \left|\frac{(x+2)^2}{x+2}\right| = |x+2| < \varepsilon = \alpha\)
      តែ \(\varepsilon = 10^{-2} \Rightarrow \alpha = 10^{-2}\)
      ដូចនេះ បើ \(\varepsilon = 10^{-2}\) នោះ \(\alpha = 10^{-2}\)

    6. \(\lim_{x \to -2}(2+5x) = -8 \quad{} (\varepsilon = 2\times 10^{-2})\)
      តាមនិយមន័យ៖ \(|(2+5x)-(-8)| < \varepsilon\)
      \(\Leftrightarrow |5(x+2)| < \varepsilon \Leftrightarrow |x+2| < \frac{\varepsilon}{5} = \alpha\)
      តែ \(\varepsilon = 2\times 10^{-2} \Rightarrow \alpha = \frac{2\times 10^{-2}}{5}\)
      ដូចនេះ បើ \(\varepsilon = 2\times 10^{-2}\) នោះ \(\alpha = \frac{2\times 10^{-2}}{5}\)

    2. \(\lim_{x\to 0}\frac{(e^x-1)(e^{2x}-1)\cdots(e^{nx}-1)}{x^n}\) , រាង \(\tfrac{0}{0}\)
      \(\begin{aligned} \text{យើងបាន } &= \lim_{x\to 0}\prod_{k=1}^n \frac{e^{kx}-1}{x} \\ &= \lim_{x\to 0}\prod_{k=1}^n\left(k\cdot\frac{e^{kx}-1}{kx}\right) \\ &= \prod_{k=1}^n (k\cdot 1) = 1\cdot 2\cdots n = n! \end{aligned}\)

    3. \(\lim_{x\to 1}\left(\frac{n}{1-x^n}-\frac{1}{1-x}\right)\) , រាង \(\infty-\infty\)
      តម្រូវភាគបែងរួម៖
      \(\frac{n-(1+x+\cdots+x^{n-1})}{1-x^n}\)
      \(= \frac{(1-x)+(1-x^2)+\cdots+(1-x^{n-1})}{1-x^n}\)
      សម្រួលនឹង \(1-x\)៖
      \(\begin{aligned} \text{យើងបាន } &= \lim_{x\to 1}\frac{1+(1+x)+\cdots+(1+x+\cdots+x^{n-2})}{1+x+\cdots+x^{n-1}} \\ &= \frac{1+2+\cdots+(n-1)}{n} \\ &= \frac{\frac{n(n-1)}{2}}{n} = \frac{n-1}{2} \end{aligned}\)

    4. \(\lim_{n\to +\infty}\frac{n^2-1}{1+2+3+\cdots+n}\) , រាង \(\tfrac{\infty}{\infty}\)
      យើងមាន \(1+2+3+\cdots+n = \frac{n(n+1)}{2}\)៖
      \(\begin{aligned} \text{យើងបាន } &= \lim_{n\to +\infty}\frac{2(n^2-1)}{n(n+1)} \\ &= \lim_{n\to +\infty}\frac{2n^2\left(1-\frac{1}{n^2}\right)}{n^2\left(1+\frac{1}{n}\right)} \\ &= \frac{2(1-0)}{1+0} = 2 \end{aligned}\)

    លំហាត់

    សិក្សាភាពជាប់ ឬរកប៉ារ៉ាម៉ែត្រ ដើម្បីឱ្យអនុគមន៍ខាងក្រោមជាប់ត្រង់ចំណុចដែលគេឲ្យ៖

    1. \(f(x)=\begin{cases}\dfrac{x^2-x-2}{x-2} & \text{បើ } x\ne 2\\ 3 & \text{បើ } x=2\end{cases}\) ត្រង់ \(x=2\)

    2. \(f(x)=\begin{cases}\dfrac{|x|}{x} & \text{បើ } x\ne 0\\ 1 & \text{បើ } x=0\end{cases}\) ត្រង់ \(x=0\)

    3. \(f(x)=\begin{cases}\dfrac{x^3-8}{x-2} & \text{បើ } x\ne 2\\ k & \text{បើ } x=2\end{cases}\) ; រក \(k\)

    4. \(f(x)=\begin{cases}ax+1 & \text{បើ } x\le 2\\ x^2-1 & \text{បើ } x>2\end{cases}\) ; រក \(a\)

    1. គេមាន \(f(2)=3\) ។
      \(\lim\limits_{x\to 2}\dfrac{x^2-x-2}{x-2}=\lim\limits_{x\to 2}\dfrac{(x-2)(x+1)}{x-2}=\lim\limits_{x\to 2}(x+1)=3\) ។
      ដោយ \(\lim\limits_{x\to 2}f(x)=f(2)=3\)
      ដូចនេះ \(f\) ជាប់ត្រង់ \(x=2\)

    2. គេមាន \(f(0)=1\) ។
      \(\lim\limits_{x\to 0^+}\dfrac{|x|}{x}=\lim\limits_{x\to 0^+}\dfrac{x}{x}=1\) និង \(\lim\limits_{x\to 0^-}\dfrac{|x|}{x}=\lim\limits_{x\to 0^-}\dfrac{-x}{x}=-1\) ។
      ដោយលីមីតឆ្វេងខុសពីលីមីតស្ដាំ \(\lim\limits_{x\to 0}f(x)\) គ្មាន ។
      ដូចនេះ \(f\) ដាច់ត្រង់ \(x=0\) (តែ \(f\) ជាប់ខាងស្ដាំត្រង់ \(0\))

    3. \(\lim\limits_{x\to 2}\dfrac{x^3-8}{x-2}=\lim\limits_{x\to 2}\dfrac{(x-2)(x^2+2x+4)}{x-2}=\lim\limits_{x\to 2}(x^2+2x+4)=12\) ។
      \(f\) ជាប់ត្រង់ \(2\) លុះត្រាតែ \(f(2)=\lim\limits_{x\to 2}f(x)\) ។
      ដូចនេះ

    4. \(f(2)=2a+1\) និង \(\lim\limits_{x\to 2^-}f(x)=\lim\limits_{x\to 2^-}(ax+1)=2a+1\) ។
      \(\lim\limits_{x\to 2^+}f(x)=\lim\limits_{x\to 2^+}(x^2-1)=3\) ។
      \(f\) ជាប់ត្រង់ \(2\) លុះត្រាតែ \(2a+1=3\) ។
      ដូចនេះ

    1. បង្ហាញថាសមីការ \(x^5+x-1=0\) មានឫសតែមួយគត់ក្នុងចន្លោះ \(]0, 1[\) ។

    2. បង្ហាញថាសមីការ \(\ln x+x=0\) មានឫសតែមួយគត់ក្នុងចន្លោះ \(\left]\dfrac{1}{e}, 1\right[\) ។

    3. រកអាស៊ីមតូតនៃខ្សែកោងតាងអនុគមន៍ \(f(x)=\dfrac{x^2+x+1}{x+1}\) ។

    4. រកអាស៊ីមតូតនៃខ្សែកោងតាងអនុគមន៍ \(g(x)=\dfrac{3x-1}{x+2}\) ។

    1. តាង \(f(x)=x^5+x-1\) ជាអនុគមន៍ពហុធា ដូចនេះជាប់លើ \([0, 1]\) ។
      \(f(0)=-1<0\) និង \(f(1)=1>0\) នាំឱ្យ \(f(0)\cdot f(1)<0\) ។
      \(f'(x)=5x^4+1>0\) នាំឱ្យ \(f\) កើនដាច់ខាត ។
      ដូចនេះ សមីការមានឫសតែមួយគត់ក្នុង \(]0, 1[\)

    2. តាង \(f(x)=\ln x+x\) ជាប់លើ \(]0,+\infty[\) ដូចនេះជាប់លើ \(\left[\frac{1}{e},1\right]\) ។
      \(f\left(\frac{1}{e}\right)=-1+\frac{1}{e}<0\) (ព្រោះ \(\frac{1}{e}<1\)) និង \(f(1)=0+1=1>0\) ។
      \(f'(x)=\frac{1}{x}+1>0\) នាំឱ្យ \(f\) កើនដាច់ខាត ។
      ដូចនេះ សមីការមានឫសតែមួយគត់ក្នុង \(\left]\frac{1}{e}, 1\right[\)

    3. ដែនកំណត់ \(D=\mathbb{R}\setminus\{-1\}\) ។ ចែកពហុធាបាន \(f(x)=x+\dfrac{1}{x+1}\) ។
      \(\bullet\) \(\lim\limits_{x\to -1^+}f(x)=+\infty\) និង \(\lim\limits_{x\to -1^-}f(x)=-\infty\) នាំឱ្យ \(x=-1\) ជាអាស៊ីមតូតឈរ ។
      \(\bullet\) \(\lim\limits_{x\to\pm\infty}\left[f(x)-x\right]=\lim\limits_{x\to\pm\infty}\dfrac{1}{x+1}=0\) នាំឱ្យ \(y=x\) ជាអាស៊ីមតូតទ្រេត ។
      ដូចនេះ \(x=-1\) និង \(y=x\)

    4. ដែនកំណត់ \(D=\mathbb{R}\setminus\{-2\}\) ។ គេសរសេរ \(g(x)=3-\dfrac{7}{x+2}\) ។
      \(\bullet\) \(\lim\limits_{x\to\pm\infty}g(x)=3\) នាំឱ្យ \(y=3\) ជាអាស៊ីមតូតដេក ។
      \(\bullet\) \(\lim\limits_{x\to -2^+}g(x)=-\infty\) និង \(\lim\limits_{x\to -2^-}g(x)=+\infty\) នាំឱ្យ \(x=-2\) ជាអាស៊ីមតូតឈរ ។
      ដូចនេះ \(x=-2\) និង \(y=3\)
