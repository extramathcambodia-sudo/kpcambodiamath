កោនិក៣ ផ្នែកសំណួរពហុជ្រើសរើស ១០០
ក្នុងមេរៀននេះ
  1. ១. សមីការទូទៅនៃប៉ារ៉ាបូល
  2. ២. ការផ្លាស់ប្តូរទៅសមីការស្តង់ដារ (Completing the Square)
  3. ៣. ចម្លើយ និងដំណោះស្រាយ
  4. សំណួរពហុជ្រើសរើស
មេរៀនទាំងអស់
និយមន័យ

ប៉ារ៉ាបូលគឺជាសំណុំចំណុច \(P(x,y)\) នៅក្នុងប្លង់ ដែលមានចម្ងាយស្មើពីចំណុចនឹង \(F\) (Focus) មួយទៅនិងបន្ទាត់នឹង \(\Delta\) មួយ (Directrix) នៅក្នុងប្លង់នោះ។

  • \(F\) (Focus) នោះហៅថា កំណុំ

  • បន្ទាត់នឹង \(\Delta\) ហៅថា បន្ទាត់ប្រាប់ទិស (Directrix line)

  • បន្ទាត់ដែលកាត់តាមកំណុំហើយកែងនឹងបន្ទាត់ប្រាប់ទិសហៅថា អ័ក្សឆ្លុះ នៃប៉ារ៉ាបូល។

  • \(V\) ជាចំណុចកណ្តាលដែលភ្ជាប់រវាងកំណុំ \(F\) និងបន្ទាត់ប្រាប់ទិស \(\Delta\)។

  • គ្រប់ចំណុច \(P(x,y)\) ស្ថិតនៅលើប៉ារ៉ាបូលមានកំណុំ \(F\) និងបន្ទាត់ប្រាប់ទិស \(\Delta\) គេបាន \(PF = d(P,\Delta)\)។

ក្នុងមេរៀននេះ យើងសិក្សាតែប៉ារ៉ាបូលដែលមាន អ័ក្សឆ្លុះដេក និង អ័ក្សឆ្លុះឈរ តែប៉ុណ្ណោះ ។

១. ប៉ារ៉ាបូលបើកបញ្ឈរ (Vertical Parabola)

ក. ទម្រង់ \(x^2 = 4py\) (កំពូលនៅ \((0, 0)\))

លក្ខណៈ/សមីការ \(x^2=4py\)
អ័ក្សឆ្លុះ \(x = 0\) (អ័ក្ស \(y\))
កំពូល (Vertex) \((0, 0)\)
កំណុំ (Focus) \((0, p)\)
បន្ទាត់ប្រាប់ទិស (Directrix) \(y = -p\)
ទិសដៅបើក លើ (\(p>0\)) / ក្រោម (\(p<0\))

ឧទាហរណ៍

រកកូអរដោនេកំពូល កំណុំ និងសមីការបន្ទាត់ប្រាប់ទិសនៃប៉ារ៉ាបូល \(x^2 = 12y\) រួចសង់ក្រាប។

ចម្លើយ

សមីការ \(x^2 = 12y\) មានទម្រង់ស្តង់ដា \(x^2 = 4py\) ដែលជាប៉ារ៉ាបូលមានអ័ក្សឆ្លុះឈរ (ត្រួតលើអ័ក្ស \(y\)) និងមានកំពូលនៅគល់តម្រុយ \(V(0, 0)\)។

  • តាមសមីការ \(4p = 12 \implies p = 3 > 0\) នាំឱ្យប៉ារ៉ាបូលបើកទៅលើ។

  • កំពូល៖ \(V(0, 0)\)

  • កំណុំ៖ \(F(0, p) = F(0, 3)\)

  • សមីការបន្ទាត់ប្រាប់ទិស៖ \(y = -p \iff y = -3\)

  • អ័ក្សឆ្លុះ៖ \(x = 0\) (អ័ក្សអរដោនេ \(y\))

រកកូអរដោនេកំពូល កំណុំ និងសមីការបន្ទាត់ប្រាប់ទិសនៃប៉ារ៉ាបូល រួចសង់ក្រាបតាងប៉ារ៉ាបូលនីមួយៗខាងក្រោម៖

  1. \(x^2 = 8y\)

  2. \(x^2 = -6y\)

ចម្លើយខ្លី

  1. \(V(0, 0), \, F(0, 2), \, \Delta: y = -2\)

  2. \(V(0, 0), \, F\!\left(0, -\dfrac{3}{2}\right), \, \Delta: y = \dfrac{3}{2}\)

ខ. ទម្រង់ \((x-h)^2 = 4p(y-k)\) (កំពូលនៅ \((h, k)\))

លក្ខណៈ/សមីការ \((x-h)^2 = 4p(y-k)\)
អ័ក្សឆ្លុះ (Symetry) \(x = h\)
កំពូល (Vertex) \((h, k)\)
កំណុំ (Focus) \((h, k+p)\)
បន្ទាត់ប្រាប់ទិស (Directrix) \(y = k-p\)
ទិសដៅបើក លើ (\(p>0\)) / ក្រោម (\(p<0\))

ឧទាហរណ៍

រកកូអរដោនេកំពូល កំណុំ និងសមីការបន្ទាត់ប្រាប់ទិសនៃប៉ារ៉ាបូល \((x-3)^2 = 8(y+1)\) រួចសង់ក្រាប។

ចម្លើយ

សមីការ \((x-3)^2 = 8(y+1)\) មានទម្រង់ស្តង់ដា \((x-h)^2 = 4p(y-k)\) ដែលមានអ័ក្សឆ្លុះស្របនឹងអ័ក្ស \(y\)។

  • តាមសមីការ យើងបាន៖ \(h = 3, \; k = -1 \implies\) កំពូល \(V(h, k) = V(3, -1)\)។

  • \(4p = 8 \implies p = 2 > 0\) នាំឱ្យប៉ារ៉ាបូលបើកទៅលើ។

  • កំណុំ៖ \(F(h, k+p) = F(3, -1+2) = F(3, 1)\)។

  • សមីការបន្ទាត់ប្រាប់ទិស៖ \(y = k - p = -1 - 2 \iff y = -3\)។

  • អ័ក្សឆ្លុះ៖ \(x = h \iff x = 3\)។

រកកូអរដោនេកំពូល កំណុំ និងសមីការបន្ទាត់ប្រាប់ទិសនៃប៉ារ៉ាបូល រួចសង់ក្រាបតាងប៉ារ៉ាបូលនីមួយៗខាងក្រោម៖

  1. \((x-2)^2= 4(y-3)\)

  2. \((x-1)^2+ 8(y+2)=0\)

ចម្លើយខ្លី

  1. \(V(2, 3), \, F(2, 4), \, \Delta: y = 2\)

  2. \(V(1, -2), \, F(1, -4), \, \Delta: y = 0\)

២. សមីការស្តង់ដានៃប៉ារ៉ាបូលដែលមានអ័ក្សឆ្លុះដេក (Horizontal Parabola)

ក. ទម្រង់ \(y^2 = 4px\) (កំពូលនៅគល់តម្រុយ \((0, 0)\))

លក្ខណៈ/សមីការ \(y^2 = 4px\)
អ័ក្សឆ្លុះ \(y = 0\) (អ័ក្ស \((Ox)\))

កំណុំ (Focus) \((p, 0)\)

រកកូអរដោនេកំពូល កំណុំ និងសមីការបន្ទាត់ប្រាប់ទិសនៃប៉ារ៉ាបូល \(y^2 = -8x\) រួចសង់ក្រាប។

ចម្លើយ

សមីការ \(y^2 = -8x\) មានទម្រង់ស្តង់ដា \(y^2 = 4px\) ដែលជាប៉ារ៉ាបូលមានអ័ក្សឆ្លុះដេក (ត្រួតលើអ័ក្ស \(x\)) និងកំពូល \(V(0, 0)\)។

  • តាមសមីការ \(4p = -8 \implies p = -2 < 0\) នាំឱ្យប៉ារ៉ាបូលបើកទៅឆ្វេង។

  • កំពូល៖ \(V(0, 0)\)

  • កំណុំ៖ \(F(p, 0) = F(-2, 0)\)

  • សមីការបន្ទាត់ប្រាប់ទិស៖ \(x = -p \iff x = 2\)

  • អ័ក្សឆ្លុះ៖ \(y = 0\) (អ័ក្សអាប់ស៊ីស \(x\))

  1. \(y^2 = 4x\)

  2. \(y^2 +12x = 0\)

  2. \(V(0, 0), \, F(-3, 0), \, \Delta: x = 3\)

ចម្លើយ

សមីការ \((y-1)^2 = -4(x+2)\) មានទម្រង់ស្តង់ដា \((y-k)^2 = 4p(x-h)\) ដែលជាប៉ារ៉ាបូលមានអ័ក្សឆ្លុះស្របនឹងអ័ក្ស \(x\)។

  • តាមសមីការ យើងបាន៖ \(h = -2, \; k = 1 \implies\) កំពូល \(V(h, k) = V(-2, 1)\)។

  • \(4p = -4 \implies p = -1 < 0\) នាំឱ្យប៉ារ៉ាបូលបើកទៅឆ្វេង។

  • កំណុំ៖ \(F(h+p, k) = F(-2+(-1), 1) = F(-3, 1)\)។

  • សមីការបន្ទាត់ប្រាប់ទិស៖ \(x = h - p = -2 - (-1) \iff x = -1\)។

  • អ័ក្សឆ្លុះ៖ \(y = k \iff y = 1\)។

គេមានសមីការ \((x-2)^2 = 12(y-1)\) ជាសមីការប៉ារ៉ាបូល។ រកកូអរដោនេកំពូល កំណុំ សមីការអ័ក្សឆ្លុះ និងសមីការបន្ទាត់ប្រាប់ទិសនៃប៉ារ៉ាបូល រួចសង់ក្រាប។

ចម្លើយ

សមីការដែលឱ្យ៖ \((x-2)^2 = 12(y-1)\)

  • ប្រៀបធៀបនឹងសមីការស្តង់ដា៖ \((x-h)^2 = 4p(y-k)\) ជាប៉ារ៉ាបូលដែលមានអ័ក្សឆ្លុះឈរ (ស្របនឹងអ័ក្ស \(y\))។

  • គេបាន៖

    \[h = 2, \quad{} k = 1, \quad{} 4p = 12 \implies p = 3 > 0 \quad{} (\text{ប៉ារ៉ាបូលបើកទៅលើ})\]

  • កំពូល៖ \(V(h, k) = V(2, 1)\)

  • កំណុំ៖ \(F(h, k+p) = F(2, 1+3) = F(2, 4)\)

  • សមីការអ័ក្សឆ្លុះ៖ \(x = h \iff x = 2\)

  • សមីការបន្ទាត់ប្រាប់ទិស (\(\Delta\))៖ \(y = k - p = 1 - 3 \iff y = -2\)

  • ចំណុចជំនួយសម្រាប់សង់ក្រាប៖

    • យក \(y = 4\) (កម្ពស់កំណុំ \(F\)) នាំឱ្យ៖

      \[(x-2)^2 = 12(4-1) = 36 \implies x - 2 = \pm 6 \implies x = 8 \;\text{ឬ}\; x = -4\]
      នាំឱ្យប៉ារ៉ាបូលកាត់តាមចំណុច \((-4, 4)\) និង \((8, 4)\) (ចុងទាំងសងខាងនៃអង្កត់កាត់កំណុំ Latus Rectum ប្រវែង \(4p = 12\))។

    • ចំណុចប្រសព្វជាមួយអ័ក្ស \(Oy\) (\(x=0\))៖ \((0-2)^2 = 12(y-1) \implies 4 = 12(y-1) \implies y = \dfrac{4}{3}\)។

ចម្លើយ

សមីការដែលឱ្យ៖ \((y+1)^2 = -8(x-1)\)

  • ប្រៀបធៀបនឹងសមីការស្តង់ដា៖ \((y-k)^2 = 4p(x-h)\) ជាប៉ារ៉ាបូលដែលមានអ័ក្សឆ្លុះដេក (ស្របនឹងអ័ក្ស \(x\))។

  • គេបាន៖

    \[h = 1, \quad{} k = -1, \quad{} 4p = -8 \implies p = -2 < 0 \quad{} (\text{ប៉ារ៉ាបូលបើកទៅឆ្វេង})\]

  • កំពូល៖ \(V(h, k) = V(1, -1)\)

  • កំណុំ៖ \(F(h+p, k) = F(1 - 2, -1) = F(-1, -1)\)

  • សមីការអ័ក្សឆ្លុះ៖ \(y = k \iff y = -1\)

  • សមីការបន្ទាត់ប្រាប់ទិស (\(\Delta\))៖ \(x = h - p = 1 - (-2) \iff x = 3\)

  • ចំណុចជំនួយសម្រាប់សង់ក្រាប៖

    • យក \(x = -1\) (អាប់ស៊ីសកំណុំ \(F\)) នាំឱ្យ៖

      \[(y+1)^2 = -8(-1-1) = 16 \implies y + 1 = \pm 4 \implies y = 3 \;\text{ឬ}\; y = -5\]
      នាំឱ្យប៉ារ៉ាបូលកាត់តាមចំណុច \((-1, 3)\) និង \((-1, -5)\) (ចុងទាំងសងខាងនៃអង្កត់កាត់កំណុំ Latus Rectum ប្រវែង \(|4p| = 8\))។

    • ចំណុចប្រសព្វជាមួយអ័ក្ស \(Oy\) (\(x=0\))៖ \((y+1)^2 = -8(0-1) = 8 \implies y = -1 \pm 2\sqrt{2} \approx 1.83 \;\) ឬ \(\; -3.83\)។

ចម្លើយ

សមីការដែលឱ្យ៖ \(\left(y - \dfrac{1}{2}\right)^2 = -4(x+1)\)

  • ប្រៀបធៀបនឹងសមីការស្តង់ដា៖ \((y-k)^2 = 4p(x-h)\) ជាប៉ារ៉ាបូលដែលមានអ័ក្សឆ្លុះដេក (ស្របនឹងអ័ក្ស \(x\))។

  • គេបាន៖

    \[h = -1, \quad{} k = \frac{1}{2}, \quad{} 4p = -4 \implies p = -1 < 0 \quad{} (\text{ប៉ារ៉ាបូលបើកទៅឆ្វេង})\]

  • កំពូល៖ \(V(h, k) = V\left(-1, \dfrac{1}{2}\right)\)

  • កំណុំ៖ \(F(h+p, k) = F\left(-1 - 1, \dfrac{1}{2}\right) = F\left(-2, \dfrac{1}{2}\right)\)

  • សមីការអ័ក្សឆ្លុះ៖ \(y = k \iff y = \dfrac{1}{2}\)

  • សមីការបន្ទាត់ប្រាប់ទិស (\(\Delta\))៖ \(x = h - p = -1 - (-1) \iff x = 0\) (អ័ក្សអរដោនេ \(Oy\))

  • ចំណុចជំនួយសម្រាប់សង់ក្រាប៖

    • យក \(x = -2\) (អាប់ស៊ីសកំណុំ \(F\)) នាំឱ្យ៖

      \[\left(y - \frac{1}{2}\right)^2 = -4(-2+1) = 4 \implies y - \frac{1}{2} = \pm 2 \implies y = \frac{5}{2} = 2.5 \;\text{ឬ}\; y = -\frac{3}{2} = -1.5\]
      នាំឱ្យប៉ារ៉ាបូលកាត់តាមចំណុច \(\left(-2, \dfrac{5}{2}\right)\) និង \(\left(-2, -\dfrac{3}{2}\right)\) (ចុងទាំងសងខាងនៃអង្កត់កាត់កំណុំ Latus Rectum ប្រវែង \(|4p| = 4\))។

លំហាត់

សង់ក្រាបតាងប៉ារ៉ាបូលខាងក្រោម៖

  1. សមីការ៖ \((x+2)^2=8(y-3)\)

    • កំពូល \(V(h, k)\): \(V(-2, 3)\)

    • កំណុំ \(F(h, k+p)\): \(F(-2, 5)\)

  2. សមីការ៖ \((x-4)^2=-12y\)

    • កំពូល \(V(h, k)\): \(V(4, 0)\)

    • កំណុំ \(F(h, k+p)\): \(F(4, -3)\)

    • បន្ទាត់ប្រាប់ទិស \(\Delta\): \(y = 3\)

  3. សមីការ៖ \((y+1)^2=4x\)

    • កំពូល \(V(h, k)\): \(V(0, -1)\)

    • បន្ទាត់ប្រាប់ទិស \(\Delta\): \(x = -1\)

សមីការទូទៅនៃប៉ារ៉ាបូល

លក្ខណៈ ប៉ារ៉ាបូលឈរ (Vertical Parabola) ប៉ារ៉ាបូលដេក (Horizontal Parabola)
សមីការទូទៅ \(\mathbf{Ax^2 + Dx + Ey + F = 0}\) \(\mathbf{Cy^2 + Dx + Ey + F = 0}\)
លក្ខខណ្ឌ \(C=0\) និង \(A \neq 0\) \(A=0\) និង \(C \neq 0\)
អ័ក្សឆ្លុះ ឈរ (\(x = h\)) ដេក (\(y = k\))

ការផ្លាស់ប្តូរទៅសមីការស្តង់ដារ (Completing the Square)

គោលគំនិតសំខាន់នៃការដោះស្រាយសមីការទូទៅគឺការបំប្លែងវាទៅជា សមីការស្តង់ដារ ដោយប្រើវិធី បំពេញការ៉េ (Completing the Square)។

១. ប៉ារ៉ាបូលឈរ

ប៉ារ៉ាបូលឈរមានតួ \(x^2\)។ យើងត្រូវបំពេញការ៉េលើតួ \(x\) ដូចខាងក្រោម៖

\[\begin{aligned} Ax^2 + Dx &= -(Ey + F) \\ A\left(x^2 + \frac{D}{A}x\right) &= -E\left(y + \frac{F}{E}\right) \\ \left(x - h\right)^2 &= 4p\left(y - k\right) \end{aligned}\]

២. ប៉ារ៉ាបូលដេក

ប៉ារ៉ាបូលដេកមានតួ \(y^2\)។ យើងត្រូវបំពេញការ៉េលើតួ \(y\) ដូចខាងក្រោម៖

\[\begin{aligned} Cy^2 + Ey &= -(Dx + F) \\ C\left(y^2 + \frac{E}{C}y\right) &= -D\left(x + \frac{F}{D}\right) \\ \left(y - k\right)^2 &= 4p\left(x - h\right) \end{aligned}\]

ឧទាហរណ៍

បំប្លែងសមីការទូទៅនៃប៉ារ៉ាបូល \(x^2 - 4x - 8y + 12 = 0\) ទៅជាសមីការស្តង់ដា រួចកំណត់កូអរដោនេកំពូល និងកំណុំ។

ចម្លើយ

សមីការដែលឱ្យ៖ \(x^2 - 4x - 8y + 12 = 0\)

  • រក្សាទុកតួដែលមានអថេរ \(x\) នៅអង្គខាងឆ្វេង ហើយផ្ទេរតួផ្សេងទៀតទៅអង្គខាងស្តាំ៖

    \[x^2 - 4x = 8y - 12\]

  • បំពេញការ៉េអង្គខាងឆ្វេង ដោយបន្ថែម \(\left(\frac{-4}{2}\right)^2 = 4\) ទៅអង្គទាំងសងខាង៖

    \[x^2 - 4x + 4 = 8y - 12 + 4 \iff (x - 2)^2 = 8y - 8\]

  • ដាក់មេគុណ \(8\) ជាកត្តារួមនៅអង្គខាងស្តាំ៖

    \[(x - 2)^2 = 8(y - 1)\]

  • នេះជាសមីការស្តង់ដានៃប៉ារ៉ាបូលឈរ \((x-h)^2 = 4p(y-k)\) ដែលមាន៖

    • កំពូល៖ \(V(h, k) = V(2, 1)\)

    • \(4p = 8 \implies p = 2\) នាំឱ្យកំណុំ \(F(h, k+p) = F(2, 1+2) = F(2, 3)\)

ឧទាហរណ៍

រកសមីការនៃប៉ារ៉ាបូលដែលមាន អ័ក្សឆ្លុះស្របនឹងអ័ក្សអរដោនេ ហើយក្រាបកាត់តាមបីចំណុច \((2,1)\), \((5,-5)\) និង \((10,5)\)។

ដោយអ័ក្សឆ្លុះស្របនឹងអ័ក្សអរដោនេ (\(Oy\)) នោះសមីការទូទៅមានទម្រង់៖ \(x^2 + Dx + Ey + F = 0\) (\(E \neq 0\))។

ជំនួសកូអរដោនេនៃចំណុចទាំងបី \((2,1)\), \((5,-5)\) និង \((10,5)\) ចូលក្នុងសមីការ៖

\[\begin{cases} 2^2 + 2D + E + F = 0 \iff 2D + E + F = -4 &(1) \\ 5^2 + 5D - 5E + F = 0 \iff 5D - 5E + F = -25 &(2) \\ 10^2 + 10D + 5E + F = 0 \iff 10D + 5E + F = -100 &(3) \end{cases}\]

  • យក \((2) - (1) \implies 3D - 6E = -21 \iff D - 2E = -7 \quad{} (4)\)

  • យក \((3) - (2) \implies 5D + 10E = -75 \iff D + 2E = -15 \quad{} (5)\)

  • បូក \((4)\) និង \((5)\) អង្គនិងអង្គ៖ \(2D = -22 \implies D = -11\)

  • ជំនួស \(D = -11\) ចូល \((5)\) បាន \(E = -2\) រួចជំនួសចូល \((1)\) បាន \(F = 20\)

ដូចនេះ សមីការទូទៅគឺ៖ \(\mathbf{x^2 - 11x - 2y + 20 = 0}\) និងស្តង់ដារ៖ \(\left(x - \dfrac{11}{2}\right)^2 = 2\left(y + \dfrac{41}{8}\right)\)។

ឧទាហរណ៍

រកសមីការនៃប៉ារ៉ាបូលដែលមាន អ័ក្សឆ្លុះស្របនឹងអ័ក្សអាប់ស៊ីស ហើយក្រាបកាត់តាមបីចំណុច \((0,0)\), \((-3,-6)\) និង \((-8,4)\)។

ដោយអ័ក្សឆ្លុះស្របនឹងអ័ក្សអាប់ស៊ីស (\(Ox\)) នោះសមីការទូទៅមានទម្រង់៖ \(y^2 + Dx + Ey + F = 0\) (\(D \neq 0\))។

ជំនួសកូអរដោនេនៃចំណុចទាំងបី \((0,0)\), \((-3,-6)\) និង \((-8,4)\) ចូលក្នុងសមីការ៖

\[\begin{cases} 0^2 + 0D + 0E + F = 0 \implies F = 0 &(1) \\ (-6)^2 - 3D - 6E + F = 0 \iff 36 - 3D - 6E = 0 \iff D + 2E = 12 &(2) \\ 4^2 - 8D + 4E + F = 0 \iff 16 - 8D + 4E = 0 \iff 2D - E = 4 &(3) \end{cases}\]

  • កំណុំ \(F(1, 1 + 1) = F(1, 2)\)

រកសមីការបន្ទាត់ប៉ះទៅនឹងក្រាបនៃប៉ារ៉ាបូល \(y^2=2x\) ដែលកាត់តាមចំណុច \((-4,1)\)។

ដំណោះស្រាយ

តាងបន្ទាត់ប៉ះកាត់តាមចំណុច \((-4, 1)\) មានមេគុណប្រាប់ទិស \(m\) ៖

\[y - 1 = m(x + 4) \iff x = \frac{y - 1}{m} - 4 \quad{} (m \neq 0)\]
ជំនួស \(x\) ចូលក្នុងសមីការប៉ារ៉ាបូល \(y^2 = 2x\) ៖
\[y^2 = 2\left(\frac{y - 1}{m} - 4\right) \iff m y^2 - 2y + (8m + 2) = 0\]
ដើម្បីឱ្យបន្ទាត់ប៉ះក្រាបប៉ារ៉ាបូល លុះត្រាតែសមីការមានឫសឌុប (\(\Delta' = 0\)) ៖
\[\Delta' = (-1)^2 - m(8m + 2) = 1 - 8m^2 - 2m = 0 \iff 8m^2 + 2m - 1 = 0\]
ដោះស្រាយសមីការដឺក្រេទីពីរ ៖
\[(4m - 1)(2m + 1) = 0 \implies m_1 = \frac{1}{4}, \quad{} m_2 = -\frac{1}{2}\]

  • ចំពោះ \(m = \frac{1}{4}\) ៖ \(y - 1 = \frac{1}{4}(x + 4) \iff x - 4y + 8 = 0\)

  • ចំពោះ \(m = -\frac{1}{2}\) ៖ \(y - 1 = -\frac{1}{2}(x + 4) \iff x + 2y + 2 = 0\)

ដូចនេះ សមីការបន្ទាត់ប៉ះទាំងពីរគឺ ៖ \(\boxed{x - 4y + 8 = 0}\) និង \(\boxed{x + 2y + 2 = 0}\)

លំហាត់ទី ៤

តាង \(m\) និង \(b\) ជាចំនួនពិតពីរខុសពីសូន្យ។ បើបន្ទាត់ \(y=mx+b\) ប៉ះប៉ារ៉ាបូល \(y^2=4px\) ត្រង់ចំណុចមួយ។ បង្ហាញថា បន្ទាត់ប៉ះទៅនឹងប៉ារ៉ាបូល \(y^2 = 4px\) ត្រង់ចំណុច \(P(x_1,y_1)\) មានមេគុណប្រាប់ទិសស្មើនឹង \(\frac{y_1}{2x_1}\) ។

ដំណោះស្រាយ

ដោយចំណុច \(P(x_1, y_1)\) ស្ថិតនៅលើប៉ារ៉ាបូល \(y^2 = 4px\) នាំឱ្យសមីការផ្ទៀងផ្ទាត់ ៖

\[y_1^2 = 4px_1 \implies 2p = \frac{y_1^2}{2x_1}\]
យកដេរីវេធៀបនឹង \(x\) លើអង្គទាំងសងខាងនៃសមីការ \(y^2 = 4px\) ៖
\[2y \cdot y' = 4p \implies y' = \frac{4p}{2y} = \frac{2p}{y}\]
មេគុណប្រាប់ទិសនៃបន្ទាត់ប៉ះត្រង់ចំណុច \(P(x_1, y_1)\) គឺតម្លៃដេរីវេត្រង់ \(x_1\) ៖
\[m = y'(x_1) = \frac{2p}{y_1}\]
ជំនួស \(2p = \frac{y_1^2}{2x_1}\) ចូលក្នុងកន្សោម \(m\) ៖
\[m = \frac{\frac{y_1^2}{2x_1}}{y_1} = \frac{y_1}{2x_1}\]
ដូចនេះ បន្ទាត់ប៉ះត្រង់ចំណុច \(P(x_1, y_1)\) មានមេគុណប្រាប់ទិសស្មើនឹង \(\boxed{m = \frac{y_1}{2x_1}}\) (ត្រូវបានស្រាយបំភ្លឺ)។

លំហាត់ទី ៥

រកសមីការនៃប៉ារ៉ាបូលដែលមាន អ័ក្សឆ្លុះស្របនឹងអ័ក្សអរដោនេ និងក្រាបកាត់តាមចំណុច \((2,5)\), \((-2,-3)\) និង \((1,6)\)។

ដំណោះស្រាយ

ប៉ារ៉ាបូលមានអ័ក្សឆ្លុះស្របនឹងអ័ក្សអរដោនេ (\(y\)) មានសមីការទូទៅ ៖

\[y = ax^2 + bx + c \quad{} (a \neq 0)\]
ដោយក្រាបកាត់តាមចំណុចទាំងបី យើងជំនួសកូអរដោនេចូល ៖
\[\begin{aligned} (2, 5) &: 4a + 2b + c = 5 \\ (-2, -3) &: 4a - 2b + c = -3 \\ (1, 6) &: a + b + c = 6 \end{aligned}\]
ដកសមីការទីមួយ និងទីពីរ ៖ \(4b = 8 \implies b = 2\)។
ជំនួស \(b = 2\) ចូល ៖
\[\begin{cases} 4a + c = 5 - 2(2) = 1 \\ a + c = 6 - 2 = 4 \end{cases} \implies 3a = -3 \implies a = -1, \quad{} c = 5\]
សមីការប៉ារ៉ាបូលគឺ ៖ \(y = -x^2 + 2x + 5 \iff y = -(x-1)^2 + 6 \iff (x - 1)^2 = -(y - 6)\)។
ដូចនេះ សមីការស្តង់ដាគឺ \(\boxed{(x - 1)^2 = -(y - 6)}\) (ឬ \(y = -x^2 + 2x + 5\))

លំហាត់ទី ៦

រកសមីការនៃប៉ារ៉ាបូលដែលមាន អ័ក្សឆ្លុះជាអ័ក្សដេក និងក្រាបកាត់តាមចំណុច \((-1,1)\), \((11,-2)\) និង \((5,-1)\)។

ដំណោះស្រាយ

ប៉ារ៉ាបូលមានអ័ក្សឆ្លុះជាអ័ក្សដេក មានសមីការទូទៅ ៖

\[x = ay^2 + by + c \quad{} (a \neq 0)\]
ជំនួសចំណុចទាំងបីចូល ៖
\[\begin{aligned} (-1, 1) &: a + b + c = -1 \\ (11, -2) &: 4a - 2b + c = 11 \\ (5, -1) &: a - b + c = 5 \end{aligned}\]
ដកសមីការទីមួយ និងទីបី ៖ \(2b = -6 \implies b = -3\)។
ជំនួស \(b = -3\) ចូល ៖
\[\begin{cases} a + c = -1 - (-3) = 2 \\ 4a + c = 11 + 2(-3) = 5 \end{cases} \implies 3a = 3 \implies a = 1, \quad{} c = 1\]
សមីការប៉ារ៉ាបូលគឺ ៖ \(x = y^2 - 3y + 1 \iff x + \frac{5}{4} = \left(y - \frac{3}{2}\right)^2\)។
ដូចនេះ សមីការស្តង់ដាគឺ \(\boxed{\left(y - \frac{3}{2}\right)^2 = x + \frac{5}{4}}\) (ឬ \(x = y^2 - 3y + 1\))

លំហាត់ទី ៧

ក្រុមហ៊ុនទូរគមនាគមន៍មួយបានរចនា ចានផ្កាយរណប (Satellite Dish) រាងប៉ារ៉ាបូល ដែលមានទទឹងសរុប \(W = 2.4\text{ m}\) និងជម្រៅ \(D = 0.45\text{ m}\) នៅចំកណ្តាល។

ក កំណត់សមីការស្តង់ដារនៃប៉ារ៉ាបូលនេះ (កំពូល \(V(0,0)\))។

ខ គណនាចម្ងាយ \(p\) (ចម្ងាយរវាងកំពូលនិងកំណុំ)។

គ តើឧបករណ៍ចាប់សញ្ញាត្រូវដាក់នៅចម្ងាយប៉ុន្មានម៉ែត្រពីបាតចាន?

ដំណោះស្រាយ

ក កំណត់សមីការស្តង់ដារ ៖
ចាត់ទុកកំពូល \(V\) ស្ថិតនៅ \((0, 0)\) និងអ័ក្សឆ្លុះជាអ័ក្សឈរ (\(y\)) បើកឡើងលើ ៖

\[x^2 = 4py\]
ទទឹងសរុប \(W = 2.4\text{ m} \implies\) ពាក់កណ្តាលទទឹង \(x = 1.2\text{ m}\)។
គែមចានមានកូអរដោនេ \((1.2, 0.45)\) ៖
\[(1.2)^2 = 4p(0.45) \implies 1.44 = 1.8p\]
\[\implies p = 0.8\text{ m}\]
សមីការស្តង់ដាគឺ ៖ \(x^2 = 4(0.8)y \iff x^2 = 3.2y\)។
ដូចនេះ \(\boxed{x^2 = 3.2y}\)

ខ គណនាចម្ងាយ \(p\) ៖
តាមការគណនាខាងលើ ៖

\[p = \frac{1.44}{1.8} = 0.8\text{ m}\]
ដូចនេះ \(\boxed{p = 0.8\text{ m}}\)

គ ទីតាំងឧបករណ៍ចាប់សញ្ញា ៖
ដើម្បីទទួលបានសញ្ញាខ្លាំងបំផុត ឧបករណ៍ចាប់សញ្ញាត្រូវដាក់នៅចំកំណុំ \(F(0, p) = F(0, 0.8\text{m})\)។
ដូចនេះ ឧបករណ៍ត្រូវដាក់នៅចម្ងាយ \(\boxed{0.8\text{ m}}\) ពីបាតចាន (កំពូល) តាមអ័ក្សឆ្លុះ។

លំហាត់ទី ៨

ស្ពានព្យួរមួយមានខ្សែកាបសំខាន់រាងប៉ារ៉ាបូល។ កំពូល \(V\) ស្ថិតនៅចំកណ្តាលស្ពានកម្ពស់ \(2\text{ m}\) ពីផ្លូវ។ បង្គោលទ្រទាំងពីរមានចម្ងាយ \(200\text{ m}\) ពីគ្នានិងមានកម្ពស់ \(50\text{ m}\) ពីផ្លូវ។

ដំណោះស្រាយ

ក ប្រព័ន្ធកូអរដោនេ ៖
ជ្រើសរើសផ្លូវស្ពានជាអ័ក្សដេក (\(x\)) និងអ័ក្សឆ្លុះនៃស្ពានជាអ័ក្សឈរ (\(y\))។ កំពូលស្ថិតនៅ \(V(0, 2)\)។ បង្គោលទាំងពីរស្ថិតនៅចម្ងាយ \(100\text{ m}\) សងខាងគល់អ័ក្ស គឺចំណុច \((-100, 50)\) និង \((100, 50)\)។

ខ រកសមីការតំណាងឱ្យខ្សែកាប ៖
សមីការប៉ារ៉ាបូលបើកឡើងលើ ៖ \((x - 0)^2 = 4p(y - 2)\)។
កាត់តាមចំណុចកំពូលបង្គោល \((100, 50)\) ៖

\[100^2 = 4p(50 - 2) \implies 10000 = 4p(48)\]
\[\implies 4p = \frac{10000}{48} = \frac{625}{3}\]
សមីការ ៖ \(x^2 = \frac{625}{3}(y - 2) \iff y = \frac{3}{625}x^2 + 2\)។
ដូចនេះ \(\boxed{y = \frac{3}{625}x^2 + 2}\)

គ គណនាកម្ពស់ខ្សែកាបនៅ \(75\text{ m}\) ពីបង្គោល ៖
ចម្ងាយ \(75\text{ m}\) ពីបង្គោលមួយ (\(x = 100\)) នាំឱ្យ ៖

\[x = 100 - 75 = 25\text{ m}\]
ជំនួស \(x = 25\) ចូលក្នុងសមីការ ៖
\[y = \frac{3}{625}(625) + 2 = 3 + 2 = 5\text{ m}\]
ដូចនេះ កម្ពស់ខ្សែកាបគឺ \(\boxed{5\text{ m}}\) ពីផ្លូវស្ពាន។

លំហាត់ទី ៩

រថយន្តពន្លត់អគ្គីភ័យបាញ់ទឹកចេញពីកម្ពស់ \(1.5\text{ m}\) ពីដី។ ផ្លូវទឹកមានរាងជាប៉ារ៉ាបូល \(y = -0.01x^2 + 0.8x + 1.5\) (\(x,y\) គិតជាម៉ែត្រ)។

ដំណោះស្រាយ

ក ចម្ងាយដេកឆ្ងាយបំផុត (ពេល \(y = 0\)) ៖

\[-0.01x^2 + 0.8x + 1.5 = 0\]
\[\iff x^2 - 80x - 150 = 0\]
\(\Delta' = 40^2 - (-150) = 1600 + 150 = 1750\)
\[x = 40 + \sqrt{1750} \approx 40 + 41.83 = 81.83\text{ m}\]
ដូចនេះ ចម្ងាយដេកឆ្ងាយបំផុតគឺ \(\boxed{x \approx 81.83\text{ m}}\)

ខ កម្ពស់អតិបរមា ៖
អាប់ស៊ីសនៃកំពូល ៖ \(x_V = -\frac{b}{2a} = -\frac{0.8}{2(-0.01)} = 40\text{ m}\)។
កម្ពស់អតិបរមា ៖

\[y_{\max} = -0.01(40^2) + 0.8(40) + 1.5 = 17.5\text{ m}\]
ដូចនេះ \(\boxed{y_{\max} = 17.5\text{ m}}\)

គ ចម្ងាយដើម្បីបាញ់ដល់កំពូលផ្ទះកម្ពស់ \(6\text{ m}\) ៖
លក្ខខណ្ឌ \(y \ge 6\) ៖

\[-0.01x^2 + 0.8x + 1.5 \ge 6\]
\[\iff x^2 - 80x + 450 \le 0\]
\(\Delta' = 1600 - 450 = 1150\) នាំឱ្យ ៖ \(x \in [40 - \sqrt{1150}, \; 40 + \sqrt{1150}] \approx [6.09\text{ m}, \; 73.91\text{ m}]\) ដូចនេះ ផ្ទះត្រូវស្ថិតនៅចម្ងាយពី \(6.09\text{ m}\) ដល់ \(73.91\text{ m}\)

លំហាត់ទី ១០

កញ្ចក់ឆ្លុះពន្លឺព្រះអាទិត្យរាងប៉ារ៉ាបូលដេក មានបន្ទាត់ប្រាប់ទិស \(x = 2\) និងកំណុំ \(F(10, 5)\)។

ដំណោះស្រាយ

ក បន្ទាត់ប្រាប់ទិសឈរ \(x = 2\) និងកំណុំ \(F(10, 5)\) មាន \(x_F = 10 > 2\) នាំឱ្យប៉ារ៉ាបូលជាប្រភេទ ដេក បើកទៅស្តាំ។
ដូចនេះ ប៉ារ៉ាបូលដេក បើកទៅស្តាំ

ខ កំពូល \(V(h, k)\) ជាចំណុចកណ្តាល ៖ \(h = \frac{2 + 10}{2} = 6, \; k = 5 \implies V(6, 5)\)។
ដូចនេះ \(\boxed{V(6, 5)}\)

គ ប៉ារ៉ាម៉ែត្រ \(p = 10 - 6 = 4 > 0\) នាំឱ្យ ៖

\[(y - 5)^2 = 4(4)(x - 6)\]
\[\iff (y - 5)^2 = 16(x - 6)\]
ដូចនេះ \(\boxed{(y - 5)^2 = 16(x - 6)}\)

ឃ ទទឹងបញ្ឈរសរុប \(10\text{ m} \implies 2|y - 5| = 10 \implies y - 5 = \pm 5\) ៖

\[(\pm 5)^2 = 16(x - 6) \iff 25 = 16(x - 6)\]
\[\implies x - 6 = \frac{25}{16} = 1.5625\text{ m}\]
ដូចនេះ ប្រវែងដេកគឺ \(\boxed{1.5625\text{ m}}\)

លំហាត់ទី ១១

យន្តហោះដ្រូនហោះតាមគន្លងប៉ារ៉ាបូលដែលមានសមីការទូទៅ \(4x^2 - 16x - y + 15 = 0\) (\(x,y\) គិតជា \(\text{km}\))។

ដំណោះស្រាយ

ក សមីការស្តង់ដារ ៖
\(4(x^2 - 4x + 4) = y - 15 + 16 \iff 4(x - 2)^2 = y + 1 \iff (x - 2)^2 = \frac{1}{4}(y + 1)\)។
ដូចនេះ \(\boxed{(x - 2)^2 = \frac{1}{4}(y + 1)}\)

ខ កម្ពស់អប្បបរមា ៖
កំពូល \(V(2, -1)\) នាំឱ្យកម្ពស់ទាបបំផុតគឺ ៖

\[y_{\min} = -1\text{ km}\]
ដូចនេះ \(\boxed{y_{\min} = -1\text{ km}}\)

គ កម្ពស់ដំបូងត្រង់ \(x = 0\) ៖
\(y = 4(0)^2 - 16(0) + 15 = 15\text{ km}\)។
ដូចនេះ \(\boxed{y = 15\text{ km}}\)

លំហាត់ទី ១២

ទ្វារចូលសង្វៀនកីឡារាងប៉ារ៉ាបូលដេក មានកំណុំ \(F(2, -3)\) និងបន្ទាត់ប្រាប់ទិស \(x = 6\)។

ក បន្ទាត់ប្រាប់ទិសឈរ \(x = 6\) និង \(x_F = 2 < 6\) នាំឱ្យប៉ារ៉ាបូលជាប្រភេទ ដេក បើកទៅឆ្វេង។
ដូចនេះ ប៉ារ៉ាបូលដេក បើកទៅឆ្វេង

ខ កំពូល \(V(h, k)\) ជាចំណុចកណ្តាល ៖ \(h = \frac{2 + 6}{2} = 4, \; k = -3 \implies V(4, -3)\)។
ដូចនេះ \(\boxed{V(4, -3)}\)

គ \(p = x_F - h = 2 - 4 = -2\) នាំឱ្យប្រវែងឡាទុសរ៉ិចទុម (ទទឹងបញ្ឈរ) គឺ ៖

\[4|p| = 4|-2| = 8\text{ m}\]
ដូចនេះ ទទឹងបញ្ឈរសរុបគឺ \(\boxed{8\text{ m}}\)

ឃ សមីការស្តង់ដា ៖

\[(y - (-3))^2 = 4(-2)(x - 4)\]
\[\iff (y + 3)^2 = -8(x - 4)\]
ដូចនេះ \(\boxed{(y + 3)^2 = -8(x - 4)}\)
