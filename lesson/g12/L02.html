ម៉ូឌុលនៃចំនួនកុំផ្លិច

គេឱ្យចំនួនកុំផ្លិច \(z=a+bi\) និង ចំណុច \(M\) ជារូបភាពនៃ \(z\) ក្នុងប្លង់ \((xoy)\)។ \(OM\) ហៅថាម៉ូឌុលនៃចំនួនកុំផ្លិច យើងនឹងគណនាម៉ូឌុលនេះ។ រូបភាពខាងក្រោមយើងមានត្រីកោណ \(OMN\) ជាត្រីកោណកែងត្រង់ \(N\)។ តាមទ្រឹស្ដីបទពីតាគ័រយើងបាន \(OM^2=ON^2+NM^2\Rightarrow OM^2=a^2+b^2\Longleftrightarrow OM=\sqrt{a^2+b^2}\)។ ដូចនេះ \(OM=\sqrt{a^2+b^2}\) ជាម៉ូឌុលនៃចំនួនកុំផ្លិច \(z=a+bi\)។

ម៉ូឌុលនៃចំនួនកុំផ្លិច

គន្លឹះដោះស្រាយ៖ ម៉ូឌុលនៃចំនួនកុំផ្លិច \(z=a+bi\) តាងដោយ \(|z|\) និងកំណត់ដោយរូបមន្ត \(|z| = \sqrt{a^2+b^2}\)។ ម៉ូឌុលជានិច្ចកាលជាចំនួនពិតវិជ្ជមាន ឬសូន្យ។

ដំណោះស្រាយលម្អិត៖

  1. តាង \(z = 4-3i\) នោះ \(|z| = \sqrt{4^2 + (-3)^2} = \sqrt{16+9} = \sqrt{25} = 5\)

  2. តាង \(z = -4-3i\) នោះ \(|z| = \sqrt{(-4)^2 + (-3)^2} = \sqrt{16+9} = \sqrt{25} = 5\)

  3. តាង \(z = 4+3i\) នោះ \(|z| = \sqrt{4^2 + 3^2} = \sqrt{16+9} = \sqrt{25} = 5\)

  4. តាង \(z = -4+3i\) នោះ \(|z| = \sqrt{(-4)^2 + 3^2} = \sqrt{16+9} = \sqrt{25} = 5\)

ជាទូទៅ

បើគេមាន \(z,z_1,z_2\) ជាបីចំនួនកុំផ្លិចនោះ យើងបានលក្ខណៈមួយចំនួនដូចខាងក្រោមផ្ទៀងផ្ទាត់ ៖

  1. \(|z|=|-z|=|\bar{z}|\)

  2. \(|z|^2=z\cdot \bar{z}\)

  3. \(|z_1\cdot z_2|=|z_1||z_2|\)

  4. \(\left|\dfrac{z_1}{z_2}\right|=\dfrac{|z_1|}{|z_2|};\quad{} z_2\ne 0\)

  5. \(|z_1+z_2|\le |z_1|+|z_2|\)

សម្រាយបញ្ជាក់៖
តាង \(z = a + bi\), \(z_1 = a_1 + b_1i\), និង \(z_2 = a_2 + b_2i\) ដែល \(a, b, a_1, b_1, a_2, b_2 \in \mathbb{R}\) ។

  1. \(|z| = |-z| = |\bar{z}|\)
    តាមរូបមន្តម៉ូឌុល \(|z| = \sqrt{a^2 + b^2}\) នោះយើងបាន៖
    ម៉ូឌុលនៃ \(z\) គឺ \(|z| = \sqrt{a^2 + b^2}\)
    ចំនួនផ្ទុយ \(-z = -a - bi \Rightarrow |-z| = \sqrt{(-a)^2 + (-b)^2} = \sqrt{a^2 + b^2}\)
    ចំនួនឆ្លាស់ \(\bar{z} = a - bi \Rightarrow |\bar{z}| = \sqrt{a^2 + (-b)^2} = \sqrt{a^2 + b^2}\)
    ដូចនេះ \(|z| = |-z| = |\bar{z}|\) ។

  2. \(|z|^2 = z \cdot \bar{z}\)
    ផលគុណ \(z \cdot \bar{z} = (a + bi)(a - bi) = a^2 - (bi)^2 = a^2 - b^2i^2 = a^2 + b^2\)
    ម្យ៉ាងទៀត \(|z|^2 = (\sqrt{a^2 + b^2})^2 = a^2 + b^2\)
    ដូចនេះ \(|z|^2 = z \cdot \bar{z}\) ។

  3. \(|z_1 \cdot z_2| = |z_1||z_2|\)
    តាមលក្ខណៈ (b) ៖ \(|z_1 \cdot z_2|^2 = (z_1 \cdot z_2)(\overline{z_1 \cdot z_2}) = (z_1 \cdot z_2)(\bar{z}_1 \cdot \bar{z}_2) = (z_1\bar{z}_1)(z_2\bar{z}_2) = |z_1|^2 |z_2|^2 = (|z_1||z_2|)^2\)
    ទាញឫសការេ (ដោយសារម៉ូឌុលជាចំនួនមិនអវិជ្ជមាន) នោះ \(|z_1 \cdot z_2| = |z_1||z_2|\) ។

  4. \(\left|\dfrac{z_1}{z_2}\right| = \dfrac{|z_1|}{|z_2|}\)
    ស្រដៀងនឹងចំណុច (c) ដែរ៖ \(\left| \dfrac{z_1}{z_2} \right|^2 = \left(\dfrac{z_1}{z_2}\right) \overline{\left(\dfrac{z_1}{z_2}\right)} = \dfrac{z_1 \cdot \bar{z}_1}{z_2 \cdot \bar{z}_2} = \dfrac{|z_1|^2}{|z_2|^2} = \left(\dfrac{|z_1|}{|z_2|}\right)^2\)
    ទាញឫសការេ នោះ \(\left|\dfrac{z_1}{z_2}\right| = \dfrac{|z_1|}{|z_2|}\) ។

  5. \(|z_1 + z_2| \le |z_1| + |z_2|\)
    តាមលក្ខណៈ (b) ៖ \(|z_1 + z_2|^2 = (z_1 + z_2)(\overline{z_1 + z_2}) = (z_1 + z_2)(\bar{z}_1 + \bar{z}_2) = z_1\bar{z}_1 + z_1\bar{z}_2 + z_2\bar{z}_1 + z_2\bar{z}_2\)
    \(= |z_1|^2 + |z_2|^2 + (z_1\bar{z}_2 + \overline{z_1\bar{z}_2}) = |z_1|^2 + |z_2|^2 + 2\Re(z_1\bar{z}_2)\)
    ដោយ \(\Re(w) \le |w|\) នាំឱ្យ \(2\Re(z_1\bar{z}_2) \le 2|z_1\bar{z}_2| = 2|z_1||\bar{z}_2| = 2|z_1||z_2|\)
    ដូចនេះ \(|z_1 + z_2|^2 \le |z_1|^2 + |z_2|^2 + 2|z_1||z_2| = (|z_1| + |z_2|)^2\)
    ទាញឫសការេ នោះ \(|z_1 + z_2| \le |z_1| + |z_2|\) ។

ដំណោះស្រាយ

គន្លឹះដោះស្រាយ៖ ប្រើរូបមន្តម៉ូឌុល \(|a+bi| = \sqrt{a^2+b^2}\) ដើម្បីគណនាអង្គនីមួយៗ រួចប្រៀបធៀបគ្នាដើម្បីផ្ទៀងផ្ទាត់។

ដំណោះស្រាយលម្អិត៖ គេមាន \(z=4-3i, z_1=2-i, z_2=3+2i\)

  1. \(|z|=|-z|=|\bar{z}|\)

    \(|z| = |4-3i| = \sqrt{16+9} = 5\)

    \(|-z| = |-4+3i| = \sqrt{(-4)^2+3^2} = 5\)

    \(|\bar{z}| = |4+3i| = \sqrt{4^2+3^2} = 5\)

    ដូចនេះ \(|z|=|-z|=|\bar{z}|\) ពិត។

  2. \(|z|^2=z\cdot \bar{z}\)

    \(|z|^2 = 5^2 = 25\)

    \(z\cdot \bar{z} = (4-3i)(4+3i) = 4^2 + 3^2 = 16+9 = 25\)

    ដូចនេះ \(|z|^2=z\cdot \bar{z}\) ពិត។

  3. \(|z_1\cdot z_2|=|z_1|\cdot |z_2|\)

    \(z_1 \cdot z_2 = (2-i)(3+2i) = 6+4i-3i-2i^2 = 8+i \implies |z_1 \cdot z_2| = \sqrt{8^2+1^2} = \sqrt{65}\)

    \(|z_1| = \sqrt{2^2+(-1)^2} = \sqrt{5}\) និង \(|z_2| = \sqrt{3^2+2^2} = \sqrt{13}\) \(\implies |z_1|\cdot |z_2| = \sqrt{5}\cdot \sqrt{13} = \sqrt{65}\)

    ដូចនេះ \(|z_1\cdot z_2|=|z_1|\cdot |z_2|\) ពិត។

  4. \(\left|\dfrac{z_1}{z_2}\right|=\dfrac{|z_1|}{|z_2|}\)

    \(\left|\dfrac{z_1}{z_2}\right| = \left|\dfrac{2-i}{3+2i}\right| = \left|\dfrac{(2-i)(3-2i)}{3^2+2^2}\right| = \left|\dfrac{6-4i-3i+2i^2}{13}\right| = \left|\dfrac{4-7i}{13}\right| = \sqrt{\left(\dfrac{4}{13}\right)^2+\left(\dfrac{-7}{13}\right)^2} = \sqrt{\dfrac{16+49}{169}} = \dfrac{\sqrt{65}}{13}\)

    \(\dfrac{|z_1|}{|z_2|} = \dfrac{\sqrt{5}}{\sqrt{13}} = \dfrac{\sqrt{5}\cdot \sqrt{13}}{13} = \dfrac{\sqrt{65}}{13}\)

    ដូចនេះ \(\left|\dfrac{z_1}{z_2}\right|=\dfrac{|z_1|}{|z_2|}\) ពិត។

  5. \(|z_1+z_2|\le |z_1|+|z_2|\)

    \(z_1+z_2 = (2-i)+(3+2i) = 5+i \implies |z_1+z_2| = \sqrt{5^2+1^2} = \sqrt{26} \approx 5{,}10\)

    \(|z_1|+|z_2| = \sqrt{5}+\sqrt{13} \approx 2{,}24+3{,}61 = 5{,}85\)

    ដូចនេះ \(|z_1+z_2|\le |z_1|+|z_2|\) ពិត។

អាគុយម៉ង់នៃចំនួនកុំផ្លិច

គេមានចំនួនកុំផ្លិច \(z=a+bi\) ស្ថិតនៅក្នុងប្លង់កុំផ្លិច។ តាងវ៉ិចទ័រ \(\overrightarrow{OM}\) ជារូបភាពនៃ \(z\) ។ មុំដែលកំណត់ដោយ \((\overrightarrow{Ox},\overrightarrow{OM})\) ហៅថាអាគុយម៉ង់នៃចំនួនកុំផ្លិច \(z\) តាងដោយ \(\arg(z)\)។ បើ \(\varphi\) ជាអាគុយម៉ង់មួយនៃ \(z\) នោះគេបាន \(\arg(z)=\varphi+2k\pi,\quad{} k\in \mathbb{Z}\)។ \(N\) ជាចំណោលកែងនៃចំណុច \(M\) លើអ័ក្ស \((Ox)\) ក្នុងត្រីកោណកែង \(OMN\) កែងត្រង់ \(N\) គេបាន \(\cos \varphi =\dfrac{a}{r}\) និង \(\sin \varphi =\dfrac{b}{r}\) ដែល \(r=\sqrt{a^2+b^2}\) ជាម៉ូឌុលនៃ \(z\)។

អាគុយម៉ង់នៃចំនួនកុំផ្លិច

បើ \(z=a+bi\ne 0\) មានម៉ូឌុល \(r=|z|\) នោះមុំ \(\varphi\) ដែលផ្ទៀងផ្ទាត់ \(\cos\varphi=\dfrac{a}{r}\) និង \(\sin\varphi=\dfrac{b}{r}\) ហៅថាអាគុយម៉ង់មួយនៃ \(z\) ហើយគេសរសេរ \(\arg(z)=\varphi +2k\pi,\ k\in \mathbb{Z}\)។ អាគុយម៉ង់ដែលស្ថិតក្នុងចន្លោះ \((-\pi,\pi]\) ហៅថាអាគុយម៉ង់ចម្បង។

របៀបកំណត់អាគុយម៉ង់ \(\theta\) តាមកាដ្រង់ (ASTC)

ដើម្បីកំណត់អាគុយម៉ង់ \(\theta\) នៃចំនួនកុំផ្លិច \(z=a+bi\) (\(z \ne 0\)) យើងតាង \(\alpha\in\left(0,\dfrac{\pi}{2}\right)\) ជាមុំស្រួចដែល \(\tan\alpha=\left|\dfrac{b}{a}\right|\) (\(a\ne 0,\ b\ne 0\))៖

  1. គណនាម៉ូឌុល \(r = |z| = \sqrt{a^2+b^2}\)។

  2. ប្រើរូបមន្ត \(\cos\theta = \dfrac{a}{r}\) និង \(\sin\theta = \dfrac{b}{r}\) ដោយផ្ទៀងផ្ទាត់សញ្ញាតាមកាដ្រង់៖

    • កាដ្រង់ទី១ (\(a>0, b>0\))៖ \(\theta = \alpha\) ស្ថិតក្នុង \(\left(0, \dfrac{\pi}{2}\right)\) (អនុគមន៍ទាំងអស់វិជ្ជមាន All \(>0\))

    • កាដ្រង់ទី២ (\(a<0, b>0\))៖ \(\theta = \pi - \alpha\) ស្ថិតក្នុង \(\left(\dfrac{\pi}{2}, \pi\right)\) (\(\sin > 0\))

    • កាដ្រង់ទី៣ (\(a<0, b<0\))៖ \(\theta = -(\pi - \alpha)\) ឬ \(\theta = \pi + \alpha\) (\(\tan > 0\))

    • កាដ្រង់ទី៤ (\(a>0, b<0\))៖ \(\theta = -\alpha\) ឬ \(\theta = 2\pi - \alpha\) (\(\cos > 0\))

ឧទាហរណ៍

ចូរកំណត់ម៉ូឌុល និងអាគុយម៉ង់នៃចំនួនកុំផ្លិចខាងក្រោម៖

  1. \(z_1=1+i\sqrt{3}\)

  2. \(z_2=-1+i\)

  3. \(z_3=\sqrt{3}-i\)

ដំណោះស្រាយ

គន្លឹះដោះស្រាយ៖ ១. រកម៉ូឌុល \(r = \sqrt{a^2+b^2}\) ២. គណនា \(\cos\theta = \frac{a}{r}\) និង \(\sin\theta = \frac{b}{r}\) ៣. កំណត់មុំ \(\theta\) តាមកាដ្រង់ (ASTC) ដែលជាអាគុយម៉ង់នៃ \(z\)។

ដំណោះស្រាយលម្អិត៖

  1. \(z_1=1+i\sqrt{3}\)

    \(r = \sqrt{1^2+(\sqrt{3})^2} = \sqrt{1+3} = 2\)

    \(\cos\theta = \dfrac{1}{2},\ \sin\theta = \dfrac{\sqrt{3}}{2}\) (កាដ្រង់ទី១) \(\implies \arg(z_1) = \dfrac{\pi}{3}+2k\pi\)

  2. \(z_2=-1+i\)

    \(r = \sqrt{(-1)^2+1^2} = \sqrt{2}\)

    \(\cos\theta = -\dfrac{\sqrt{2}}{2},\ \sin\theta = \dfrac{\sqrt{2}}{2}\) (កាដ្រង់ទី២) \(\implies \arg(z_2) = \pi-\dfrac{\pi}{4} = \dfrac{3\pi}{4}+2k\pi\)

  3. \(z_3=\sqrt{3}-i\)

    \(r = \sqrt{(\sqrt{3})^2+(-1)^2} = \sqrt{3+1} = 2\)

    \(\cos\theta = \dfrac{\sqrt{3}}{2},\ \sin\theta = -\dfrac{1}{2}\) (កាដ្រង់ទី៤) \(\implies \arg(z_3) = -\dfrac{\pi}{6}+2k\pi\)

លក្ខណៈនៃអាគុយម៉ង់ (Properties of Argument)

ចំពោះចំនួនកុំផ្លិចមិនសូន្យ \(z_1, z_2\) និង \(n \in \mathbb{Z}\) យើងមានលក្ខណៈសំខាន់ៗដូចខាងក្រោម៖

  1. អាគុយម៉ង់នៃផលគុណ៖ \(\arg(z_1 z_2) \equiv \arg(z_1) + \arg(z_2) \pmod{2\pi}\)

  2. អាគុយម៉ង់នៃផលចែក៖ \(\arg\left(\dfrac{z_1}{z_2}\right) \equiv \arg(z_1) - \arg(z_2) \pmod{2\pi}\)

  3. អាគុយម៉ង់នៃស្វ័យគុណ៖ \(\arg(z^n) \equiv n \cdot \arg(z) \pmod{2\pi}\)

  4. អាគុយម៉ង់នៃចំនួនកុំផ្លិចឆ្លាស់៖ \(\arg(\overline{z}) \equiv -\arg(z) \pmod{2\pi}\)

ចូរគណនាម៉ូឌុល និងរកអាគុយម៉ង់មួយនៃចំនួនកុំផ្លិចខាងក្រោម៖

  1. \(\sqrt{3}+i\)

  2. \(-2-2i\)

  3. \(-3i\)

  4. \(-5\)


ទម្រង់ត្រីកោណមាត្រនៃចំនួនកុំផ្លិច

ចំនួនកុំផ្លិច \(z=a+bi\) ជាទម្រង់ពិជគណិត យើងអាចសរសេរ \(z\) ទៅជាទម្រង់មួយផ្សេងទៀត។ ដោយ \(\cos \varphi =\dfrac{a}{r}\Rightarrow a=r\cos \varphi\) និង \(\sin \varphi=\dfrac{b}{r}\Rightarrow b=r\sin \varphi\) បើយើងជំនួសតម្លៃ \(a=r\cos \varphi\) និង \(b=r\sin \varphi\) ក្នុងចំនួនកុំផ្លិច \(z=a+bi\)​ គេបាន\(z=a+bi=r\cos \varphi+ir\sin \varphi=r(\cos \varphi+i\sin \varphi)\)។

ទម្រង់ត្រីកោណមាត្រនៃចំនួនកុំផ្លិច

ចំនួនកុំផ្លិច \(z=a+bi\) អាចសរសេរជាទម្រង់ត្រីកោណមាត្រ \(z=r(\cos \varphi+i\sin \varphi)\)។

ឧទាហរណ៍

ចូរសរសេរចំនួនកុំផ្លិចខាងក្រោមជាទម្រង់ត្រីកោណមាត្រ៖

  1. \(z_1=2+2i\)

  2. \(z_2=-\sqrt{3}+i\)

  3. \(z_3=-8-8i\)

  4. \(z_4=1-i\sqrt{3}\)

ដំណោះស្រាយ

គន្លឹះដោះស្រាយ៖ អនុវត្តរូបមន្ត \(r = \sqrt{a^2+b^2}\) និង \(\cos\theta = \frac{a}{r}\), \(\sin\theta = \frac{b}{r}\) ដូចលំហាត់មុនដែរ។ បើចំនួននោះជាចំនួនពិតសុទ្ធ ឬនិម្មិតសុទ្ធ មុំ \(\theta\) អាចរកបានយ៉ាងងាយគឺ \(0, \pi\) (សម្រាប់ពិតសុទ្ធ) ឬ \(\frac{\pi}{2}, -\frac{\pi}{2}\) (សម្រាប់និម្មិតសុទ្ធ)។

ដំណោះស្រាយលម្អិត៖

  1. \(z_1=2+2i\)

    \(r = \sqrt{2^2+2^2} = \sqrt{8} = 2\sqrt{2}\)

    \(z_1 = 2\sqrt{2}\left(\dfrac{\sqrt{2}}{2} + i\dfrac{\sqrt{2}}{2}\right) = 2\sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)\)

  2. \(z_2=-\sqrt{3}+i\)

    \(r = \sqrt{(-\sqrt{3})^2+1^2} = \sqrt{4} = 2\)

    \(z_2 = 2\left(-\dfrac{\sqrt{3}}{2} + i\dfrac{1}{2}\right) = 2\left(\cos\dfrac{5\pi}{6} + i\sin\dfrac{5\pi}{6}\right)\)

  3. \(z_3=-8-8i\)

    \(r = \sqrt{(-8)^2+(-8)^2} = \sqrt{128} = 8\sqrt{2}\)

    \(z_3 = 8\sqrt{2}\left(-\dfrac{\sqrt{2}}{2} - i\dfrac{\sqrt{2}}{2}\right) = 8\sqrt{2}\left[\cos\left(-\dfrac{3\pi}{4}\right) + i\sin\left(-\dfrac{3\pi}{4}\right)\right]\)

  4. \(z_4=1-i\sqrt{3}\)

    \(r = \sqrt{1^2+(-\sqrt{3})^2} = \sqrt{4} = 2\)

    \(z_4 = 2\left(\dfrac{1}{2} - i\dfrac{\sqrt{3}}{2}\right) = 2\left[\cos\left(-\dfrac{\pi}{3}\right) + i\sin\left(-\dfrac{\pi}{3}\right)\right]\)

ប្រតិបត្តិ

ចូរសរសេរចំនួនកុំផ្លិចខាងក្រោមជាទម្រង់ត្រីកោណមាត្រ៖

  1. \(z_1=1+i\)

  2. \(z_2=-1-i\sqrt{3}\)

  3. \(z_3=4i\)

  4. \(z_4=-2\sqrt{3}+2i\)


ផលគុណចំនួនកុំផ្លិចតាមទម្រង់ត្រីកោណមាត្រ

ជាទូទៅ

បើគេមានចំនួនកុំផ្លិច \(z_1=r_1(\cos \varphi_1+i\sin \varphi_1)\) និង \(z_2=r_2(\cos \varphi_2+i\sin \varphi_2)\) នោះគេបាន៖
\(z_1z_2=r_1r_2\left[\cos(\varphi_1+\varphi_2)+i\sin (\varphi_1+\varphi_2)\right]\)។

សម្រាយបញ្ជាក់៖
យើងមាន \(z_1=r_1(\cos \varphi_1+i\sin \varphi_1)\) និង \(z_2=r_2(\cos \varphi_2+i\sin \varphi_2)\)។

\[\begin{aligned} z_1z_2 &= [r_1(\cos \varphi_1+i\sin \varphi_1)] \cdot [r_2(\cos \varphi_2+i\sin \varphi_2)] \\ &= r_1r_2 \big[(\cos\varphi_1\cos\varphi_2 - \sin\varphi_1\sin\varphi_2)\\ &\qquad{}\quad{} + i(\sin\varphi_1\cos\varphi_2 + \cos\varphi_1\sin\varphi_2)\big] \end{aligned}\]
តាមរូបមន្តត្រីកោណមាត្រ៖
\[\begin{aligned} \cos(\varphi_1+\varphi_2) &= \cos\varphi_1\cos\varphi_2 - \sin\varphi_1\sin\varphi_2\\ \sin(\varphi_1+\varphi_2) &= \sin\varphi_1\cos\varphi_2 + \cos\varphi_1\sin\varphi_2 \end{aligned}\]
ដូចនេះយើងបាន៖ \(z_1z_2 = r_1r_2\left[\cos(\varphi_1+\varphi_2) + i\sin(\varphi_1+\varphi_2)\right]\)។

ឧទាហរណ៍

គេមានចំនួនកុំផ្លិចជាទម្រង់ពិជគណិត \(z_1=2\sqrt{3}-2i\) និង \(z_2=-1+i\sqrt{3}\)។ ប្រើទម្រង់ត្រីកោណមាត្រនៃ \(z_1\) និង \(z_2\) ។ គណនាផលគុណ \(z_1z_2\)។

ដំណោះស្រាយ

គន្លឹះដោះស្រាយ៖ ពេលយើងមានចំនួនកុំផ្លិចជាទម្រង់ត្រីកោណមាត្រពីរ \(z_1 = r_1(\cos\theta_1 + i\sin\theta_1)\) និង \(z_2 = r_2(\cos\theta_2 + i\sin\theta_2)\) នោះផលគុណមានរូបមន្ត៖

\[z_1 z_2 = r_1 r_2 [\cos(\theta_1+\theta_2) + i\sin(\theta_1+\theta_2)]\]
(គុណម៉ូឌុល និងបូកអាគុយម៉ង់)។

ដំណោះស្រាយលម្អិត៖ បំប្លែង \(z_1\) និង \(z_2\) ជាទម្រង់ត្រីកោណមាត្រសិន៖

ចំពោះ \(z_1 = 2\sqrt{3}-2i\)៖

\[\begin{aligned} r_1 &= \sqrt{(2\sqrt{3})^2 + (-2)^2} = \sqrt{12+4} = \sqrt{16} = 4\\ z_1 &= 4\left(\dfrac{\sqrt{3}}{2} - \dfrac{1}{2}i\right) = 4\left[\cos\left(-\dfrac{\pi}{6}\right) + i\sin\left(-\dfrac{\pi}{6}\right)\right] \end{aligned}\]
ចំពោះ \(z_2 = -1+i\sqrt{3}\)៖
\[\begin{aligned} r_2 &= \sqrt{(-1)^2 + (\sqrt{3})^2} = \sqrt{1+3} = \sqrt{4} = 2\\ z_2 &= 2\left(-\dfrac{1}{2} + i\dfrac{\sqrt{3}}{2}\right) = 2\left(\cos\dfrac{2\pi}{3} + i\sin\dfrac{2\pi}{3}\right) \end{aligned}\]
គណនាផលគុណ \(z_1 z_2\)៖
\[z_1 z_2 = (4 \times 2)\left[\cos\left(-\dfrac{\pi}{6} + \dfrac{2\pi}{3}\right) + i\sin\left(-\dfrac{\pi}{6} + \dfrac{2\pi}{3}\right)\right]\]
ដោយ \(-\dfrac{\pi}{6} + \dfrac{2\pi}{3} = \dfrac{-\pi+4\pi}{6} = \dfrac{3\pi}{6} = \dfrac{\pi}{2}\)
ដូចនេះ \(z_1 z_2 = 8\left(\cos\dfrac{\pi}{2} + i\sin\dfrac{\pi}{2}\right) = 8(0 + i) = 8i\) ។

ប្រតិបត្តិ

គេមានចំនួនកុំផ្លិចជាទម្រង់ពិជគណិត \(z_1=1+i\) និង \(z_2=-1+i\sqrt{3}\)។ ប្រើទម្រង់ត្រីកោណមាត្រនៃ \(z_1\) និង \(z_2\) ។ គណនាផលគុណ \(z_1z_2\)។


ផលចែកចំនួនកុំផ្លិចតាមទម្រង់ត្រីកោណមាត្រ

ជាទូទៅ

បើគេមានចំនួនកុំផ្លិច \(z_1=r_1(\cos \varphi_1+i\sin \varphi_1)\) និង \(z_2=r_2(\cos \varphi_2+i\sin \varphi_2)\) នោះគេបាន៖
\(\dfrac{z_1}{z_2}=\dfrac{r_1}{r_2}\left[\cos(\varphi_1-\varphi_2)+i\sin (\varphi_1-\varphi_2)\right]\)។

សម្រាយបញ្ជាក់៖
យើងមាន \(z_1=r_1(\cos \varphi_1+i\sin \varphi_1)\) និង \(z_2=r_2(\cos \varphi_2+i\sin \varphi_2)\) ដែល \(z_2 \ne 0\)។

\[\begin{aligned} \frac{z_1}{z_2} &= \frac{r_1(\cos \varphi_1+i\sin \varphi_1)}{r_2(\cos \varphi_2+i\sin \varphi_2)} \\ &= \frac{r_1}{r_2} \cdot \frac{(\cos \varphi_1+i\sin \varphi_1)(\cos \varphi_2-i\sin \varphi_2)}{(\cos \varphi_2+i\sin \varphi_2)(\cos \varphi_2-i\sin \varphi_2)} \\ &= \frac{r_1}{r_2} \cdot \frac{(\cos\varphi_1\cos\varphi_2 + \sin\varphi_1\sin\varphi_2) + i(\sin\varphi_1\cos\varphi_2 - \cos\varphi_1\sin\varphi_2)}{\cos^2\varphi_2 + \sin^2\varphi_2} \end{aligned}\]
ដោយ \(\cos^2\varphi_2 + \sin^2\varphi_2 = 1\) និងតាមរូបមន្តត្រីកោណមាត្រ៖ \(\cos(\varphi_1-\varphi_2) = \cos\varphi_1\cos\varphi_2 + \sin\varphi_1\sin\varphi_2\) ហើយ \(\sin(\varphi_1-\varphi_2) = \sin\varphi_1\cos\varphi_2 - \cos\varphi_1\sin\varphi_2\)។
ដូចនេះយើងបាន៖ \(\dfrac{z_1}{z_2} = \dfrac{r_1}{r_2}\left[\cos(\varphi_1-\varphi_2) + i\sin(\varphi_1-\varphi_2)\right]\)។

ឧទាហរណ៍

គេមានចំនួនកុំផ្លិចជាទម្រង់ពិជគណិត \(z_1=i\) និង \(z_2=\dfrac{\sqrt{3}}{2}+\dfrac{i}{2}\)។ ប្រើទម្រង់ត្រីកោណមាត្រនៃ \(z_1\) និង \(z_2\) ។ គណនាផលចែក \(\dfrac{z_1}{z_2}\)។

ដំណោះស្រាយ

គន្លឹះដោះស្រាយ៖ ចំពោះផលចែកជាទម្រង់ត្រីកោណមាត្រ យើងប្រើរូបមន្ត៖ \(\dfrac{z_1}{z_2} = \dfrac{r_1}{r_2}[\cos(\theta_1-\theta_2) + i\sin(\theta_1-\theta_2)]\) ។ (ចែកម៉ូឌុល និងដកអាគុយម៉ង់)។

ដំណោះស្រាយលម្អិត៖ បំប្លែង \(z_1\) និង \(z_2\) ជាទម្រង់ត្រីកោណមាត្រ៖

ចំពោះ \(z_1 = i\) មាន \(r_1=1\) និង \(\theta_1 = \dfrac{\pi}{2}\)។ ដូច្នេះ \(z_1 = 1\left(\cos\dfrac{\pi}{2} + i\sin\dfrac{\pi}{2}\right)\)

ចំពោះ \(z_2 = \dfrac{\sqrt{3}}{2} + \dfrac{1}{2}i\) \(r_2 = \sqrt{\left(\dfrac{\sqrt{3}}{2}\right)^2 + \left(\dfrac{1}{2}\right)^2} = \sqrt{\dfrac{3}{4} + \dfrac{1}{4}} = 1\) មុំ \(\theta_2\) ដែល \(\cos\theta_2 = \dfrac{\sqrt{3}}{2}\) និង \(\sin\theta_2 = \dfrac{1}{2}\) គឺ \(\theta_2 = \dfrac{\pi}{6}\)។ ដូច្នេះ \(z_2 = 1\left(\cos\dfrac{\pi}{6} + i\sin\dfrac{\pi}{6}\right)\)

គណនាផលចែក \(\dfrac{z_1}{z_2}\)៖ \(\dfrac{z_1}{z_2} = \dfrac{1}{1}\left[\cos\left(\dfrac{\pi}{2} - \dfrac{\pi}{6}\right) + i\sin\left(\dfrac{\pi}{2} - \dfrac{\pi}{6}\right)\right]\) ដោយ \(\dfrac{\pi}{2} - \dfrac{\pi}{6} = \dfrac{3\pi-\pi}{6} = \dfrac{2\pi}{6} = \dfrac{\pi}{3}\) ដូចនេះ \(\dfrac{z_1}{z_2} = \cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3} = \dfrac{1}{2} + i\dfrac{\sqrt{3}}{2}\) ។

សញ្ញាណកាត់ \(\cis\theta\) និង \(e^{i\theta}\) (សញ្ញាណអយល័រ)

ដើម្បីងាយស្រួលសរសេរ គេកំណត់តាង \(\cis\theta=e^{i\theta}=\cos\theta+i\sin\theta\)។ ដូចនេះទម្រង់ត្រីកោណមាត្រ \(z=r(\cos\theta+i\sin\theta)\) អាចសរសេរខ្លីៗ \(z=r\cis\theta=re^{i\theta}\) (ទម្រង់អិចស្ប៉ូណង់ស្យែល)។ តាមរូបមន្តផលគុណ និងផលចែកខាងលើ គេបាន៖

\[e^{i\alpha}\cdot e^{i\beta}=e^{i(\alpha+\beta)},\qquad{} \dfrac{e^{i\alpha}}{e^{i\beta}}=e^{i(\alpha-\beta)},\qquad{} \overline{e^{i\theta}}=e^{-i\theta},\qquad{} |e^{i\theta}|=1\]

បំប្លែងវិលជុំវិញគល់តម្រុយនៃប្លង់កុំផ្លិច

ជាទូទៅ

គេមានចំនួនកុំផ្លិច \(z=r(\cos \varphi+i\sin \varphi)\) បើ \(M'(z')\) ជារូបភាពនៃ \(M(z)\) តាមបំប្លែងវិលផ្ចិត \(O\) ( \(O\) ជាគល់តម្រុយ) និង មុំ \(\alpha\)​ នោះ \(z'=(\cos \alpha+i\sin \alpha)z\)។

សម្រាយបញ្ជាក់៖
តាង \(M(z)\) និង \(M'(z')\) ជារូបភាពក្នុងប្លង់កុំផ្លិច។ តាមនិយមន័យបំប្លែងវិលផ្ចិត \(O\) និងមុំ \(\alpha\) គឺ៖

\[\begin{cases} OM' = OM \\ (\overrightarrow{OM}, \overrightarrow{OM'}) = \alpha \end{cases}\]
បើ \(z = r(\cos\theta + i\sin\theta)\) នោះ \(z'\) មានម៉ូឌុល \(r' = OM' = OM = r\) និងអាគុយម៉ង់ \(\theta' = \theta + \alpha\)។
ដូចនេះ \(z' = r[\cos(\theta+\alpha) + i\sin(\theta+\alpha)]\)
ទាញបាន \(z' = [\cos\alpha + i\sin\alpha] \cdot [r(\cos\theta + i\sin\theta)] = (\cos\alpha+i\sin\alpha)z\)។

លំហាត់ ២៖ ស្រាយបញ្ជាក់លក្ខណៈកុំផ្លិចឆ្លាស់
តាង \(z_1 = a_1 + b_1i\) និង \(z_2 = a_2 + b_2i\) ដែល \(a_1, b_1, a_2, b_2 \in \mathbb{R}\)។

  1. \(\overline{z_1+z_2} = \overline{(a_1+a_2) + (b_1+b_2)i}\)
    \(= (a_1+a_2) - (b_1+b_2)i\)
    \(= (a_1 - b_1i) + (a_2 - b_2i) = \overline{z_1} + \overline{z_2}\) (ពិត)

  2. \(z_1 z_2 = (a_1 a_2 - b_1 b_2) + (a_1 b_2 + a_2 b_1)i\)
    \(\implies \overline{z_1 z_2} = (a_1 a_2 - b_1 b_2) - (a_1 b_2 + a_2 b_1)i\)
    ម៉្យាងទៀត \(\overline{z_1} \cdot \overline{z_2} = (a_1 - b_1i)(a_2 - b_2i)\)
    \(= a_1 a_2 - a_1 b_2i - a_2 b_1i + b_1 b_2 i^2\)
    \(= (a_1 a_2 - b_1 b_2) - (a_1 b_2 + a_2 b_1)i = \overline{z_1 z_2}\) (ពិត)

  3. \(\overline{\left(\frac{z_1}{z_2}\right)} = \frac{\overline{z_1}}{\overline{z_2}}\) (\(z_2 \ne 0\))៖
    តាង \(w = \frac{z_1}{z_2} \iff z_1 = w z_2\)
    តាមលក្ខណៈ (b)៖ \(\overline{z_1} = \overline{w z_2} = \overline{w} \cdot \overline{z_2}\)
    ដោយ \(z_2 \ne 0 \implies \overline{z_2} \ne 0\) គេទាញបាន៖
    \(\overline{w} = \frac{\overline{z_1}}{\overline{z_2}} \iff \overline{\left(\frac{z_1}{z_2}\right)} = \frac{\overline{z_1}}{\overline{z_2}}\) (ពិត)

  2. \(z = (1+i)^4 \implies |z| = |1+i|^4 = (\sqrt{1^2+1^2})^4 = (\sqrt{2})^4 = 4\)

  3. \(z = \sqrt{2}-i\sqrt{7} \implies |z| = \sqrt{(\sqrt{2})^2+(-\sqrt{7})^2} = \sqrt{2+7} = 3\)

លំហាត់ ១៦៖ ស្រាយបញ្ជាក់លក្ខណៈម៉ូឌុល
ចំពោះ \(z = a+bi \implies |z| = \sqrt{a^2+b^2}\)៖
\(\bar{z} = a-bi \implies |\bar{z}| = \sqrt{a^2+(-b)^2} = \sqrt{a^2+b^2}\)
\(-z = -a-bi \implies |-z| = \sqrt{(-a)^2+(-b)^2} = \sqrt{a^2+b^2}\)
ដូចនេះ \( |z| = |\bar{z}| = |-z|\)

លំហាត់ ១៧៖ គណនាអាគុយម៉ង់

  1. \(z = 1+i\sqrt{3} = 2\left(\frac{1}{2}+i\frac{\sqrt{3}}{2}\right) \implies \arg(z) = \frac{\pi}{3}\)

  2. \(z = -\sqrt{2}-i\sqrt{2} = 2\left(-\frac{\sqrt{2}}{2}-i\frac{\sqrt{2}}{2}\right) \implies \arg(z) = -\frac{3\pi}{4}\)

  3. \(z = 5 = 5(1+0i) \implies \arg(z) = 0\)

  4. \(z = -3i = 3(0-i) \implies \arg(z) = -\frac{\pi}{2}\)

លំហាត់ ១៨៖ អាគុយម៉ង់នៃផលគុណ និងផលចែក
\(z_1 = \sqrt{3}+i \implies \arg(z_1) = \frac{\pi}{6}\)
\(z_2 = 1+i \implies \arg(z_2) = \frac{\pi}{4}\)
\(\arg(z_1 z_2) = \frac{\pi}{6}+\frac{\pi}{4} = \frac{5\pi}{12}\)
\(\arg\left(\frac{z_1}{z_2}\right) = \frac{\pi}{6}-\frac{\pi}{4} = -\frac{\pi}{12}\)

លំហាត់ ១៩៖ ទម្រង់ត្រីកោណមាត្រ

  1. \(z_1 = -4 = 4(\cos\pi+i\sin\pi)\)

  2. \(z_2 = 3i = 3\left(\cos\frac{\pi}{2}+i\sin\frac{\pi}{2}\right)\)

  3. \(z_3 = -1+i\sqrt{3} = 2\left(\cos\frac{2\pi}{3}+i\sin\frac{2\pi}{3}\right)\)

  4. \(z_4 = \sqrt{6}-i\sqrt{2} = 2\sqrt{2}\left[\cos\left(-\frac{\pi}{6}\right)+i\sin\left(-\frac{\pi}{6}\right)\right]\)

លំហាត់ ២០៖ គណនា \(z^2, z^4\)
\(z = 2\left(\cos\frac{\pi}{4}+i\sin\frac{\pi}{4}\right)\)៖
\(z^2 = 2^2\left(\cos\frac{2\pi}{4}+i\sin\frac{2\pi}{4}\right) = 4\left(\cos\frac{\pi}{2}+i\sin\frac{\pi}{2}\right) = 4i\)
\(z^4 = 2^4\left(\cos\frac{4\pi}{4}+i\sin\frac{4\pi}{4}\right) = 16(\cos\pi+i\sin\pi) = -16\)

លំហាត់ ២១៖ បំប្លែងត្រីកោណមាត្រ
\(z = \frac{(1+i\sqrt{3})(1+i)}{1-i} = \frac{2e^{i\pi/3} \cdot \sqrt{2}e^{i\pi/4}}{\sqrt{2}e^{-i\pi/4}} = 2e^{i(\frac{\pi}{3}+\frac{\pi}{4}+\frac{\pi}{4})} = 2e^{i\frac{5\pi}{6}}\)
\(= 2\left(\cos\frac{5\pi}{6}+i\sin\frac{5\pi}{6}\right)\)

លំហាត់ ២២៖ កំណត់ \(a, b\)
\(2\left(\cos\frac{2\pi}{3}+i\sin\frac{2\pi}{3}\right) = 2\left(-\frac{1}{2}+i\frac{\sqrt{3}}{2}\right) = -1+i\sqrt{3}\)
\(\implies a+bi = -1+i\sqrt{3} \implies a = -1,\; b = \sqrt{3}\)

លំហាត់ ២៣៖ ស្វ័យគុណទី ១០
\(z = \sqrt{2}-i\sqrt{2}\)៖

  1. \(z = 2\left(\frac{\sqrt{2}}{2}-i\frac{\sqrt{2}}{2}\right) = 2\left[\cos\left(-\frac{\pi}{4}\right)+i\sin\left(-\frac{\pi}{4}\right)\right]\)

  2. \(z^{10} = 2^{10}\left[\cos\left(-\frac{10\pi}{4}\right)+i\sin\left(-\frac{10\pi}{4}\right)\right]\)
    \(= 1024\left[\cos\left(-\frac{5\pi}{2}\right)+i\sin\left(-\frac{5\pi}{2}\right)\right] = 1024(0-i) = -1024i\)

លំហាត់ ២៤៖ អាគុយម៉ង់នៃ \(\bar{z}\)
\(z = -1-i = \sqrt{2}\left(\cos\frac{5\pi}{4}+i\sin\frac{5\pi}{4}\right)\)
\(\bar{z} = -1+i = \sqrt{2}\left(\cos\frac{3\pi}{4}+i\sin\frac{3\pi}{4}\right) \implies \arg(\bar{z}) = \frac{3\pi}{4}\)

លំហាត់ ២៥៖ ផលគុណមុំដឺក្រេ
\(z_1 = 3\cis(20^\circ),\; z_2 = 2\cis(40^\circ)\)
\(z_1 z_2 = 6\cis(20^\circ+40^\circ) = 6\cis(60^\circ)\)
\(= 6\left(\cos 60^\circ+i\sin 60^\circ\right) = 6\left(\frac{1}{2}+i\frac{\sqrt{3}}{2}\right) = 3+3i\sqrt{3}\)

លំហាត់ ២៦៖ ទម្រង់ \(r\cis\varphi\)
\(z = \frac{2(\cos\pi+i\sin\pi)}{4(\cos\frac{\pi}{3}+i\sin\frac{\pi}{3})} = \frac{1}{2}\left[\cos\left(\pi-\frac{\pi}{3}\right)+i\sin\left(\pi-\frac{\pi}{3}\right)\right]\)
\(= \frac{1}{2}\left(\cos\frac{2\pi}{3}+i\sin\frac{2\pi}{3}\right)\)

លំហាត់ ២៧៖ ទម្រង់ត្រីកោណមាត្រត្រឹមត្រូវ
\(z = \cos\alpha - i\sin\alpha\)
ដោយ \(\cos(-\alpha) = \cos\alpha\) និង \(\sin(-\alpha) = -\sin\alpha\) គេបាន៖
\(z = \cos(-\alpha) + i\sin(-\alpha)\) (ដែលមាន \(r = 1 > 0\))

លំហាត់ ២៨៖ ចំណុចបង្វិល \(M'\)
\(z = 1+i\sqrt{3} = 2e^{i\pi/3}\)
\(z' = z e^{i\pi/3} = 2e^{i 2\pi/3} = 2\left(-\frac{1}{2}+i\frac{\sqrt{3}}{2}\right) = -1+i\sqrt{3}\)
ដូចនេះ \( M'(-1, \sqrt{3})\)

លំហាត់ ២៩៖ ស្រាយបញ្ជាក់ \(\bar{z} = 1/z\)
ដោយ \(|z| = 1 \implies |z|^2 = 1\)
តាមរូបមន្ត \(|z|^2 = z \cdot \bar{z}\) គេបាន៖
\(z \cdot \bar{z} = 1 \implies \bar{z} = \frac{1}{z}\) (ពិត)

លំហាត់ ៣០៖ គណនា \((1+i)^{10}\)
\(1+i = \sqrt{2}e^{i\pi/4}\)
\(z = (1+i)^{10} = (\sqrt{2})^{10} e^{i 10\pi/4} = 32 e^{i 5\pi/2}\)
- ទម្រង់ត្រីកោណមាត្រ៖ \(z = 32\left(\cos\frac{\pi}{2}+i\sin\frac{\pi}{2}\right)\)
- ទម្រង់ពិជគណិត៖ \(z = 32(0+i) = 32i\)

លំហាត់ ៣១៖ ម៉ូឌុល \(1+\cos\theta+i\sin\theta\)
\(z = 2\cos^2\frac{\theta}{2} + 2i\sin\frac{\theta}{2}\cos\frac{\theta}{2} = 2\cos\frac{\theta}{2}\left(\cos\frac{\theta}{2}+i\sin\frac{\theta}{2}\right)\)
ដោយ \(-\pi < \theta < \pi \implies -\frac{\pi}{2} < \frac{\theta}{2} < \frac{\pi}{2} \implies \cos\frac{\theta}{2} > 0\)
ដូចនេះ \( |z| = 2\cos\frac{\theta}{2}\)

លំហាត់ ៣២៖ រក \(z\) ពីម៉ូឌុល និងអាគុយម៉ង់
\(z = 3\left(\cos\frac{5\pi}{6}+i\sin\frac{5\pi}{6}\right) = 3\left(-\frac{\sqrt{3}}{2}+i\frac{1}{2}\right) = -\frac{3\sqrt{3}}{2}+\frac{3}{2}i\)

លំហាត់ ៣៣៖ កំណត់មុំបង្វិល \(\theta\)
\(z' = z e^{i\theta} \implies e^{i\theta} = \frac{z'}{z} = \frac{-1+i}{1+i} = \frac{(-1+i)(1-i)}{2} = \frac{2i}{2} = i\)
\(\implies \cos\theta+i\sin\theta = i \implies \theta = \frac{\pi}{2}\)
