មេរៀនទាំងអស់

ឌីផេរ៉ង់ស្យែល និងការគណនាតម្លៃប្រហែល

និយមន័យឌីផេរ៉ង់ស្យែល

ឧបមាថា \(y = f(x)\) ជាអនុគមន៍មានដេរីវេលើចន្លោះ \(I\) ហើយ \(x \in I\)។

ឌីផេរ៉ង់ស្យែល

  • ឌីផេរ៉ង់ស្យែលនៃអថេរឯករាជ្យ \(x\)៖ គឺ \(dx = \Delta x\)។

  • ឌីផេរ៉ង់ស្យែលនៃអនុគមន៍ \(y\) ត្រង់ \(x\)៖ គឺតាងដោយ \(dy\) ឬ \(df(x)\) ហើយកំណត់ដោយ៖

    \[dy = f'(x) \cdot \Delta x = f'(x)dx\]

ការគណនាតម្លៃប្រហែលលីនេអ៊ែរ (Linear Approximation)

កាលណា \(\Delta x\) មានតម្លៃកៀកនឹងសូន្យ (\(\Delta x \to 0\)) នោះកំណើននៃអនុគមន៍ \(\Delta y\) មានតម្លៃប្រហាក់ប្រហែលនឹងឌីផេរ៉ង់ស្យែល \(dy\)៖

\[\Delta y \approx dy \iff f(x_0 + \Delta x) - f(x_0) \approx f'(x_0)\Delta x\]

ជាទូទៅ

រូបមន្តតម្លៃប្រហែល៖

\[f(x_0 + \Delta x) \approx f(x_0) + f'(x_0)\Delta x\]

សម្រាយបញ្ជាក់៖ តាមនិយមន័យដេរីវេនៃអនុគមន៍ \(f\) ត្រង់ចំណុច \(x_0\) គេមាន៖

\[f'(x_0) = \lim_{\Delta x \to 0} \dfrac{f(x_0 + \Delta x) - f(x_0)}{\Delta x} = \lim_{\Delta x \to 0} \dfrac{\Delta y}{\Delta x}\]
តាមនិយមន័យលីមីត កាលណា \(\Delta x \to 0\) ផលធៀប \(\dfrac{\Delta y}{\Delta x}\) ខុសគ្នាពី \(f'(x_0)\) ដោយបរិមាណអនន្តតូច \(\alpha(\Delta x)\) មួយ ពោលគឺ៖
\[\dfrac{\Delta y}{\Delta x} = f'(x_0) + \alpha(\Delta x) \quad{} \text{ដែល } \lim_{\Delta x \to 0} \alpha(\Delta x) = 0\]
គុណអង្គទាំងពីរនឹង \(\Delta x\) គេបានកំណើននៃអនុគមន៍៖
\[\Delta y = f(x_0 + \Delta x) - f(x_0) = f'(x_0)\Delta x + \alpha(\Delta x)\Delta x\]
ដោយសារឌីផេរ៉ង់ស្យែលគឺ \(dy = f'(x_0)\Delta x\) នោះ \(\Delta y = dy + \alpha(\Delta x)\Delta x\)។ នៅពេល \(\Delta x\) មានតម្លៃតូចបំផុតកៀកនឹងសូន្យ (\(\Delta x \to 0\)) នោះផលគុណ \(\alpha(\Delta x)\Delta x\) ជាអនន្តតូចលំដាប់ខ្ពស់ធៀបនឹង \(\Delta x\) ដែលមានតម្លៃតូចស្ទើរតែស្មើសូន្យ អាចចោលបាន។ នាំឱ្យគេបានតម្លៃប្រហែល \(\Delta y \approx dy\)៖
\[f(x_0 + \Delta x) - f(x_0) \approx f'(x_0)\Delta x \iff f(x_0 + \Delta x) \approx f(x_0) + f'(x_0)\Delta x \quad{} \blacksquare\]

កំហុសលម្អៀងធៀប និងភាគរយ (Relative & Percentage Errors)

បើ \(x\) ត្រូវបានវាស់វែងដោយមានកំហុសអតិបរមា \(dx\) (ឬ \(\Delta x\)) នោះ៖

  • កំហុសដាច់ខាត (Absolute Error)៖ \(|\Delta y| \approx |dy| = |f'(x)dx|\)

  • កំហុសធៀប (Relative Error)៖ \(\dfrac{|\Delta y|}{|y|} \approx \dfrac{|dy|}{|y|} = \dfrac{|f'(x)dx|}{|f(x)|}\)

  • កំហុសជាភាគរយ (Percentage Error)៖ \(\dfrac{|dy|}{|y|} \times 100\%\)

ឧទាហរណ៍

ប្រើឌីផេរ៉ង់ស្យែល ដើម្បីគណនាតម្លៃប្រហែលនៃ \(\sqrt{26}\) និង \(\sqrt[3]{28}\)។

ដំណោះស្រាយ

  1. ចំពោះ \(\sqrt{26}\)៖ តាង \(f(x) = \sqrt{x} \implies f'(x) = \dfrac{1}{2\sqrt{x}}\)។ ជ្រើសរើស \(x_0 = 25\) និង \(\Delta x = 1\) (\(26 = 25 + 1\))។ គេបាន \(f(25) = \sqrt{25} = 5\) និង \(f'(25) = \dfrac{1}{2\sqrt{25}} = \dfrac{1}{10} = 0.1\)។ តាមរូបមន្ត៖

    \[\sqrt{26} = f(25+1) \approx f(25) + f'(25) \cdot (1) = 5 + 0.1(1) = 5.1\]

  2. ចំពោះ \(\sqrt[3]{28}\)៖ តាង \(f(x) = \sqrt[3]{x} = x^{1/3} \implies f'(x) = \dfrac{1}{3\sqrt[3]{x^2}}\)។ ជ្រើសរើស \(x_0 = 27\) និង \(\Delta x = 1\) (\(28 = 27 + 1\))។ គេបាន \(f(27) = \sqrt[3]{27} = 3\) និង \(f'(27) = \dfrac{1}{3\sqrt[3]{27^2}} = \dfrac{1}{3 \times 9} = \dfrac{1}{27} \approx 0.037\)។ តាមរូបមន្ត៖

    \[\sqrt[3]{28} \approx 3 + \dfrac{1}{27} \approx 3.037\]

វិសមភាពកំណើនមានកំណត់ (Finite Increment Inequality)

ជាទូទៅ

បើអនុគមន៍ \(f\) ជាប់លើចន្លោះបិទ \([a, b]\) មានដេរីវេលើចន្លោះបើក \((a, b)\) ហើយមានពីរចំនួនពិត \(m\) និង \(M\) ដែល \(m \le f'(x) \le M\) ចំពោះគ្រប់ \(x \in (a, b)\) នោះ៖

\[m(b - a) \le f(b) - f(a) \le M(b - a)\]

ជាពិសេស បើគ្រប់ \(x \in (a, b), |f'(x)| \le M\) នោះ \(|f(b) - f(a)| \le M |b - a|\)។

សម្រាយបញ្ជាក់៖ ដោយសារអនុគមន៍ \(f\) ជាប់លើ \([a, b]\) និងមានដេរីវេលើ \((a, b)\) តាមទ្រឹស្តីបទតម្លៃមធ្យម (MVT) មានចំនួនពិត \(c \in (a, b)\) មួយដែល៖

\[\dfrac{f(b) - f(a)}{b - a} = f'(c) \iff f(b) - f(a) = f'(c)(b - a)\]
តាមបម្រាប់ \(m \le f'(x) \le M\) ចំពោះគ្រប់ \(x \in (a, b)\) ហេតុនេះវិសមភាពនេះក៏ពិតចំពោះ \(x = c \in (a, b)\) ដែរ ពោលគឺ៖
\[m \le f'(c) \le M\]
ដោយសារ \(a < b \implies b - a > 0\) គុណអង្គទាំងបីនៃវិសមភាពនឹង \((b - a)\) (សញ្ញាវិសមភាពមិនប្រែប្រួល) គេបាន៖
\[m(b - a) \le f'(c)(b - a) \le M(b - a)\]
ជំនួស \(f'(c)(b - a) = f(b) - f(a)\) ចូល គេទាញបានវិសមភាពកំណើនមានកំណត់៖
\[m(b - a) \le f(b) - f(a) \le M(b - a)\]
ចំពោះករណីពិសេស៖ បើ \(|f'(x)| \le M \iff -M \le f'(x) \le M\) នោះតាមលទ្ធផលខាងលើ៖
\[-M(b - a) \le f(b) - f(a) \le M(b - a) \iff |f(b) - f(a)| \le M|b - a| \quad{} \blacksquare\]

ឧទាហរណ៍

បង្ហាញថាចំពោះគ្រប់ចំនួនពិត \(x > 0\) គេបាន \(\sin x \le x\) និង \(\dfrac{x}{1+x} \le \ln(1+x) \le x\)។

ដំណោះស្រាយ

  1. ពិនិត្យអនុគមន៍ \(f(t) = \sin t\) លើ \([0, x]\) (\(x > 0\))។ អនុគមន៍ \(f\) ជាប់លើ \([0, x]\) និងមានដេរីវេ \(f'(t) = \cos t\)។ ដោយ \(\cos t \le 1\) គ្រប់ \(t\) នោះតាមវិសមភាពកំណើនមានកំណត់៖

    \[f(x) - f(0) \le 1 \cdot (x - 0) \iff \sin x - 0 \le x \iff \sin x \le x\]

  2. ពិនិត្យ \(g(t) = \ln(1+t)\) លើ \([0, x]\) (\(x > 0\))។ ដេរីវេគឺ \(g'(t) = \dfrac{1}{1+t}\)។ ចំពោះគ្រប់ \(t \in [0, x]\) គេបាន \(0 \le t \le x \iff 1 \le 1+t \le 1+x \iff \dfrac{1}{1+x} \le g'(t) \le 1\)។ តាមវិសមភាពកំណើនមានកំណត់៖

    \[\dfrac{1}{1+x}(x - 0) \le g(x) - g(0) \le 1(x - 0) \iff \dfrac{x}{1+x} \le \ln(1+x) \le x\]

អនុវត្តន៍ក្នុងសេដ្ឋកិច្ច និងពាណិជ្ជកម្ម

ក្នុងការវិភាគសេដ្ឋកិច្ច ដេរីវេត្រូវបានប្រើប្រាស់យ៉ាងទូលំទូលាយដើម្បីគណនាតម្លៃ «ម៉ាជីណល (Marginal)» ដែលតំណាងឱ្យអត្រាបម្រែបម្រួលនៃថ្លៃដើម ចំណូល ឬប្រាក់ចំណេញ ធៀបនឹងបរិមាណផលិតផល \(x\)។

ទស្សនទានគ្រឹះនៃពាក្យ «ម៉ាជីណល (Marginal)»

ក្នុងសេដ្ឋកិច្ចវិទ្យា ពាក្យថា «ម៉ាជីណល (Marginal)» សំដៅលើ «ការបន្ថែម ១ ឯកតាទៀត»៖

  • ក្នុងជីវិតជាក់ស្ដែង បរិមាណផលិតផល \(x\) ត្រូវបានផលិតជាចំនួនគត់ (\(x \in \mathbb{N}\) ដូចជា \(1, 2, 3, \dots\) គ្រឿង)។

  • ប្រសិនបើក្រុមហ៊ុនផលិតបាន \(x\) គ្រឿងរួចហើយ ហើយចង់ផលិតបន្ថែម ១ គ្រឿងទៀត (គឺគ្រឿងទី \(x+1\)) នោះការប្រែប្រួលថ្លៃដើមពិតប្រាកដគឺ៖

    \[\Delta C = C(x+1) - C(x)\]

  • តាមរូបមន្តតម្លៃប្រហែលនៃឌីផេរ៉ង់ស្យែល កាលណា \(\Delta x = 1\) (តូចធៀបនឹងផលិតផលសរុបរាប់រយរាប់ពាន់គ្រឿង) គេបាន៖

    \[\Delta C \approx dC = C'(x)\Delta x = C'(x) \cdot 1 = C'(x)\]

សេចក្តីសន្និដ្ឋានសំខាន់

តម្លៃដេរីវេ \(C'(x_0)\) គឺជាការប៉ាន់ស្មានដ៏ល្អបំផុត និងរហ័សបំផុតនៃថ្លៃដើមក្នុងការផលិតទំនិញ ១ ឯកតាបន្ថែមទៀត (គឺឯកតាទី \(x_0+1\))។ ដូចគ្នាដែរ ចំពោះចំណូលម៉ាជីណល \(R'(x_0)\) និងប្រាក់ចំណេញម៉ាជីណល \(P'(x_0)\)។

និយមន័យអនុគមន៍សេដ្ឋកិច្ចគ្រឹះ

  • អនុគមន៍ថ្លៃដើមសរុប \(C(x)\) (Total Cost)៖ ជាប្រាក់ចំណាយសរុបដើម្បីផលិតទំនិញចំនួន \(x\) ឯកតា។ ជាទូទៅ វាផ្សំឡើងពីពីរផ្នែក៖

    \[C(x) = FC + VC(x)\]
    ដែល \(FC = C(0)\) ជាថ្លៃដើមថេរ (Fixed Cost ដូចជា ថ្លៃជួលទីតាំង ថ្លៃម៉ាស៊ីន) និង \(VC(x)\) ជាថ្លៃដើមប្រែប្រួល (Variable Cost ដូចជា ថ្លៃវត្ថុធាតុដើម ពលកម្ម)។

  • អនុគមន៍ថ្លៃដើមម៉ាជីណល \(C'(x)\) (Marginal Cost)៖ ជាអត្រាបម្រែបម្រួលនៃថ្លៃដើមធៀបនឹងបរិមាណផលិតផល \(x\)។ តម្លៃ \(C'(x_0)\) ជាការប៉ាន់ស្មាននៃថ្លៃដើមផលិតទំនិញឯកតាទី \((x_0+1)\)។

  • អនុគមន៍ថ្លៃដើមមធ្យម \(\overline{C}(x)\) (Average Cost)៖ ជាថ្លៃដើមជាមធ្យមក្នុងមួយឯកតា៖

    \[\overline{C}(x) = \dfrac{C(x)}{x}\]
    ថ្លៃដើមមធ្យមមានកម្រិតអប្បបរមាត្រង់ចំណុចដែល \(C'(x) = \overline{C}(x)\) (ថ្លៃដើមម៉ាជីណល ស្មើ ថ្លៃដើមមធ្យម)។

  • អនុគមន៍ចំណូលសរុប \(R(x)\) (Total Revenue)៖ ជាប្រាក់ចំណូលសរុបពីការលក់ទំនិញ \(x\) ឯកតា៖

    \[R(x) = x \cdot p(x)\]
    ដែល \(p(x)\) ជាថ្លៃលក់ក្នុងមួយឯកតា (ហៅថា អនុគមន៍តម្រូវការ Demand Function)។

  • អនុគមន៍ចំណូលម៉ាជីណល \(R'(x)\) (Marginal Revenue)៖ ជាការប៉ាន់ស្មានប្រាក់ចំណូលបន្ថែមដែលទទួលបានពីការលក់ទំនិញឯកតាទី \((x_0+1)\)៖

    \[R(x_0+1) - R(x_0) \approx R'(x_0)\]

  • អនុគមន៍ប្រាក់ចំណេញ \(P(x)\) (Profit)៖

    \[P(x) = R(x) - C(x)\]
    ប្រាក់ចំណេញទទួលបានអតិបរមាកាលណា \(P'(x) = 0 \iff R'(x) = C'(x)\) (ចំណូលម៉ាជីណល ស្មើ ថ្លៃដើមម៉ាជីណល) និង \(P''(x) < 0\)។

ការបកស្រាយលម្អិតលើទ្រឹស្ដីសំខាន់ៗ

១. ហេតុអ្វីថ្លៃដើមមធ្យម \(\overline{C}(x)\) អប្បបរមាត្រង់ \(C'(x) = \overline{C}(x)\)?

  • សម្រាយបញ្ជាក់តាមគណិតវិទ្យា៖ តាមរូបមន្តដេរីវេផលចែក គេបាន៖

    \[\overline{C}'(x) = \left(\dfrac{C(x)}{x}\right)' = \dfrac{C'(x)\cdot x - C(x)\cdot 1}{x^2} = \dfrac{C'(x) - \dfrac{C(x)}{x}}{x} = \dfrac{C'(x) - \overline{C}(x)}{x}\]
    ដើម្បីឱ្យ \(\overline{C}(x)\) មានបរមា (អប្បបរមា) គេត្រូវឱ្យ \(\overline{C}'(x) = 0\) នាំឱ្យ៖
    \[C'(x) - \overline{C}(x) = 0 \iff C'(x) = \overline{C}(x)\]

  • ន័យវិចារណញាណសេដ្ឋកិច្ច (Economic Intuition)៖

    • ប្រសិនបើ \(C'(x) < \overline{C}(x)\) (ផលិតផលថ្មីចំណាយតិចជាងមធ្យម) \(\implies\) ថ្លៃដើមមធ្យមនឹងធ្លាក់ចុះ (\(\overline{C}(x)\) ចុះ)។

    • ប្រសិនបើ \(C'(x) > \overline{C}(x)\) (ផលិតផលថ្មីចំណាយច្រើនជាងមធ្យម) \(\implies\) ថ្លៃដើមមធ្យមនឹងកើនឡើង (\(\overline{C}(x)\) កើន)។

    • ដូចនេះ ថ្លៃដើមមធ្យមធ្លាក់ដល់កម្រិតទាបបំផុត (អប្បបរមា) ចំពេលដែល \(C'(x) = \overline{C}(x)\)។

២. ន័យសេដ្ឋកិច្ចនៃលក្ខខណ្ឌចំណេញអតិបរមា \(R'(x) = C'(x)\)

  • ប្រសិនបើ \(R'(x) > C'(x)\) ៖ ការលក់ ១ គ្រឿងទៀតបានចំណូលច្រើនជាងថ្លៃដើមផលិត \(\implies\) ក្រុមហ៊ុនគួរតែបន្តផលិតបន្ថែមដើម្បីបង្កើនប្រាក់ចំណេញ។

  • ប្រសិនបើ \(R'(x) < C'(x)\) ៖ ការផលិត ១ គ្រឿងទៀតចំណាយថ្លៃដើមលើសប្រាក់ចំណូល \(\implies\) គ្រឿងនោះនាំឱ្យខាត ក្រុមហ៊ុនត្រូវកាត់បន្ថយការផលិត។

  • ដូចនេះ ប្រាក់ចំណេញកើនឡើងដល់កម្រិតខ្ពស់បំផុត (អតិបរមា) នៅត្រង់ចំណុចតុល្យភាព \(R'(x) = C'(x)\)។

ប្រៀបធៀបថ្លៃដើមពិត និងថ្លៃដើមម៉ាជីណល

ក្រុមហ៊ុនមួយមានអនុគមន៍ថ្លៃដើមសរុប \(C(x) = 500 + 10x + 0.05x^2\) (គិតជាដុល្លារ)។

  1. រកអនុគមន៍ថ្លៃដើមម៉ាជីណល \(C'(x)\)។

  2. បើបច្ចុប្បន្នផលិតបាន \(x = 100\) គ្រឿង ចូរប្រើថ្លៃដើមម៉ាជីណលដើម្បីប៉ាន់ស្មានថ្លៃដើមក្នុងការផលិតគ្រឿងទី \(101\)។

  3. គណនាថ្លៃដើមពិតប្រាកដក្នុងការផលិតគ្រឿងទី \(101\) រួចប្រៀបធៀបលទ្ធផលទាំងពីរ។

ដំណោះស្រាយ

  1. អនុគមន៍ថ្លៃដើមម៉ាជីណល៖ \(C'(x) = (500 + 10x + 0.05x^2)' = 10 + 0.1x\)។

  2. ការប៉ាន់ស្មានថ្លៃដើមនៃគ្រឿងទី \(101\) តាមដេរីវេ (ត្រង់ \(x = 100\))៖

    \[C'(100) = 10 + 0.1(100) = 10 + 10 = \$20\]
    ដូច្នេះ ការផលិតគ្រឿងទី \(101\) ចំណាយប្រហែល \(\$20\)។

  3. ថ្លៃដើមពិតប្រាកដក្នុងការផលិតគ្រឿងទី \(101\)៖

    • ថ្លៃដើមផលិត \(100\) គ្រឿង៖ \(C(100) = 500 + 10(100) + 0.05(100)^2 = 500 + 1000 + 500 = \$2000\)។

    • ថ្លៃដើមផលិត \(101\) គ្រឿង៖ \(C(101) = 500 + 10(101) + 0.05(101)^2 = 500 + 1010 + 510.05 = \$2020.05\)។

    • ថ្លៃដើមពិតនៃគ្រឿងទី \(101\) គឺ៖

      \[\Delta C = C(101) - C(100) = 2020.05 - 2000 = \$20.05\]

    ការប្រៀបធៀប៖ តម្លៃពិតប្រាកដគឺ \(\$20.05\) រីឯតម្លៃប៉ាន់ស្មានតាមដេរីវេគឺ \(\$20.00\) ដោយមានកំហុសខុសគ្នាត្រឹមតែ \(\$0.05\) (០.២៥%) ប៉ុណ្ណោះ។ នេះបង្ហាញថា ថ្លៃដើមម៉ាជីណលផ្តល់នូវការប៉ាន់ស្មានយ៉ាងរហ័ស និងសុក្រឹតខ្ពស់។

ការរកប្រាក់ចំណេញអតិបរមា

រោងចក្រមួយចំណាយប្រាក់សរុបក្នុងការផលិតទំនិញ \(x\) គ្រឿងតាមសមីការ \(C(x) = 1000 + 20x + 0.1x^2\) (ពាន់រៀល) ហើយលក់ចេញវិញក្នុងតម្លៃមួយគ្រឿង \(p(x) = 80 - 0.1x\) (ពាន់រៀល)។

  1. កំណត់អនុគមន៍ចំណូល \(R(x)\) និងអនុគមន៍ប្រាក់ចំណេញ \(P(x)\)។

  2. កំណត់បរិមាណទំនិញ \(x\) ដែលត្រូវផលិតដើម្បីឱ្យប្រាក់ចំណេញទទួលបានអតិបរមា។

ដំណោះស្រាយ

  1. ចំណូលសរុប៖ \(R(x) = x \cdot p(x) = x(80 - 0.1x) = 80x - 0.1x^2\)។ ប្រាក់ចំណេញ៖ \(P(x) = R(x) - C(x) = (80x - 0.1x^2) - (1000 + 20x + 0.1x^2) = -0.2x^2 + 60x - 1000\)។

  2. ដេរីវេទីមួយនៃប្រាក់ចំណេញ៖ \(P'(x) = -0.4x + 60\)។ ឱ្យ \(P'(x) = 0 \iff -0.4x + 60 = 0 \implies x = \dfrac{60}{0.4} = 150\) គ្រឿង។ ដេរីវេទីពីរ៖ \(P''(x) = -0.4 < 0 \implies\) ប្រាក់ចំណេញទទួលបានអតិបរមាត្រង់ \(x = 150\) គ្រឿង។ ប្រាក់ចំណេញអតិបរមានោះគឺ \(P(150) = -0.2(150)^2 + 60(150) - 1000 = -4500 + 9000 - 1000 = 3500\) ពាន់រៀល (៣.៥ លានរៀល)។

អាស៊ីមតូតនៃខ្សែកោង និងចំណុចឆ្លុះ

អាស៊ីមតូតឈរ អាស៊ីមតូតដេក និងអាស៊ីមតូតទ្រេត

  • អាស៊ីមតូតឈរ (Vertical Asymptote)៖ បន្ទាត់ \(x = x_0\) ជាអាស៊ីមតូតឈរនៃក្រាប \(y = f(x)\) កាលណា \(\lim_{x \to x_0^+} f(x) = \pm\infty\) ឬ \(\lim_{x \to x_0^-} f(x) = \pm\infty\)។

  • អាស៊ីមតូតដេក (Horizontal Asymptote)៖ បន្ទាត់ \(y = y_0\) ជាអាស៊ីមតូតដេកនៃក្រាប \(y = f(x)\) កាលណា \(\lim_{x \to +\infty} f(x) = y_0\) ឬ \(\lim_{x \to -\infty} f(x) = y_0\)។

  • អាស៊ីមតូតទ្រេត (Oblique / Slant Asymptote)៖ បន្ទាត់ \((d) : y = ax + b\) (\(a \neq 0\)) ជាអាស៊ីមតូតទ្រេតនៃក្រាប \(y = f(x)\) កាលណា \(\lim_{x \to \pm\infty} [f(x) - (ax+b)] = 0\)។

ផ្ចិតឆ្លុះ និងអ័ក្សឆ្លុះនៃខ្សែកោង

ជាទូទៅ

  • ផ្ចិតឆ្លុះ៖ ចំណុច \(I(a, b)\) ជាផ្ចិតឆ្លុះនៃក្រាប \((C) : y = f(x)\) លុះត្រាតែចំពោះគ្រប់ \(x \in D\) គេបាន \(2a - x \in D\) និង៖

    \[f(2a - x) + f(x) = 2b\]
    (ចំពោះអនុគមន៍សនិទាន \(y = \dfrac{ax+b}{cx+d}\) ផ្ចិតឆ្លុះជាចំណុចប្រសព្វនៃអាស៊ីមតូតទាំងពីរ \(I\left(-\dfrac{d}{c}, \dfrac{a}{c}\right)\))។

  • អ័ក្សឆ្លុះ៖ បន្ទាត់ \(\Delta : x = a\) ជាអ័ក្សឆ្លុះនៃក្រាប \((C) : y = f(x)\) លុះត្រាតែចំពោះគ្រប់ \(x \in D\) គេបាន \(2a - x \in D\) និង៖

    \[f(2a - x) = f(x)\]

សម្រាយបញ្ជាក់៖

  • ១. ចំពោះផ្ចិតឆ្លុះ \(I(a, b)\)៖ យកចំណុច \(M(x, y) \in (C) \iff y = f(x)\)។ តាង \(M'(x', y')\) ជាចំណុចឆ្លុះនៃ \(M\) ធៀបនឹងផ្ចិត \(I(a, b)\)។ នោះ \(I\) ជាចំណុចកណ្តាលនៃអង្កត់ \([MM']\)៖

    \[\begin{cases} \dfrac{x + x'}{2} = a \\ \dfrac{y + y'}{2} = b \end{cases} \iff \begin{cases} x' = 2a - x \\ y' = 2b - y \end{cases}\]

លំហាត់ទី ៥ ៖ តាង \(f(x) = \sqrt{x} \implies f'(x) = \dfrac{1}{2\sqrt{x}}\)។
ជ្រើសរើស \(x_0 = 36 \implies \Delta x = 1\)។
តាមរូបមន្ត \(f(x_0 + \Delta x) \approx f(x_0) + f'(x_0)\Delta x\) ៖

\[\begin{aligned} \sqrt{37} &\approx \sqrt{36} + \frac{1}{2\sqrt{36}}(1) \\ &= 6 + \frac{1}{12} \approx 6.0833 \end{aligned}\]

លំហាត់ទី ១២ ៖ ផ្ទៃក្រឡាការ៉េ ៖ \(S = x^2 \implies dS = 2x dx\)។
ជាមួយ \(x = 10\text{ cm}\) និង \(|dx| \le 0.05\text{ cm}\) ៖

  • កំហុសដាច់ខាត ៖ \(|dS| = 2(10)(0.05) = 1\text{ cm}^2\)

  • កំហុសជាភាគរយ ៖
    \(\dfrac{|dS|}{S} = \dfrac{2|dx|}{x} = \dfrac{2(0.05)}{10} = 1\%\)

លំហាត់ទី ១៣ ៖ មាឌស្វ៊ែរ ៖ \(V = \dfrac{4}{3}\pi r^3 \implies dV = 4\pi r^2 dr\)។
កំហុសជាភាគរយក្នុងការគណនាមាឌ ៖

\[\begin{aligned} \frac{|dV|}{V} &= \frac{4\pi r^2 |dr|}{\frac{4}{3}\pi r^3} = 3\frac{|dr|}{r} \\ &= 3\left(\frac{0.02}{6}\right) = 0.01 = 1\% \end{aligned}\]

លំហាត់ទី ១៤ ៖ មាឌបាឡុង ៖ \(V = \dfrac{4}{3}\pi r^3 \implies dV = 4\pi r^2 dr\)។
