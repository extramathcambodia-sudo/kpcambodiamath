អ៊ីពែរបូល (Hyperbola)

កោនិក២ ផ្នែកសំណួរពហុជ្រើសរើស ១០០
ក្នុងមេរៀននេះ
  1. ១. សមីការទូទៅនៃអ៊ីពែរបូល
  2. ២. ចម្លើយ និងដំណោះស្រាយ
  3. សំណួរពហុជ្រើសរើស
មេរៀនទាំងអស់

គេយក ប្លង់មួយ កាត់ កោណបរិវត្តន៍ទ្វេ (Double Cone) ដោយប្លង់នោះកាត់ ទាំងកំណាត់ខាងលើ និងកំណាត់ខាងក្រោម នៃកោណ ប៉ុន្តែ មិនកាត់តាមផ្ចិត នៃកោណនោះទេ នោះផ្នែកប្រសព្វដែលបានជារូបធរណីមាត្រមួយហៅថា អ៊ីពែរបូល។ ដូច្នេះ អ៊ីពែរបូល គឺជា កោនិកមួយ។ អ៊ីពែរបូល (Hyperbola) គឺជាទម្រង់ធរណីមាត្រមួយប្រភេទនៃ ផ្នែកកោណ (Conic Section) ដែលមាន ខ្សែកោងពីរដាច់ពីគ្នា (សាខា) ដាក់ទល់មុខគ្នា ហើយមើលទៅដូចជាប៉ារ៉ាបូលឆ្លុះ។

១. និយមន័យ (Definition)

និយមន័យ

អ៊ីពែរបូល គឺជាសំណុំនៃចំណុច \(P(x, y)\) នៅក្នុងប្លង់ ដែលផលដកដាច់ខាតនៃចម្ងាយពីចំណុច \(P\) ទៅកាន់ចំណុចនឹងពីរ (កំណុំ \(F_1\) និង \(F_2\)) មានតម្លៃថេរជានិច្ច:

\[|PF_1 - PF_2| = 2a\]
ដែល \(2a\) គឺជាប្រវែងនៃអ័ក្សទទឹង (Transverse Axis)។

២. ធាតុសំខាន់ៗ

សំណើ

  • ផ្ចិត (Center): \(I(h, k)\)

  • កំពូល (Vertices): ចម្ងាយ \(a\) ពីផ្ចិត តាងដោយ \(V\)

  • កំណុំ (Foci): ចម្ងាយ \(c\) ពីផ្ចិត តាងដោយ \(F\), ដែល \(c^2 = a^2 + b^2\)

  • អ័ក្សទទឹង (Transverse Axis) និង អ័ក្សឆ្លាស់ (Conjugate Axis): កំណត់ដោយ \(a\) និង \(b\)។

៣. សមីការស្តង់ដារ (Standard Equations)

ក. ផ្ចិតនៅ \(I(0, 0)\)
ទម្រង់ សមីការ និង លក្ខណៈ ក្រាប
ផ្ដេក \(\displaystyle \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\)
\(\bullet\) កំពូល៖ \(V_1(-a, 0) \,,\, V_2(a, 0)\)
\(\bullet\) កំណុំ៖ \(F_1(-c, 0) \,,\, F_2(c, 0)\) (\(c^2 = a^2 + b^2\))
\(\bullet\) អាស៊ីមតូត៖ \(y = \pm \dfrac{b}{a}x\)
បញ្ឈរ \(\displaystyle \frac{y^2}{a^2} - \frac{x^2}{b^2} = 1\)
\(\bullet\) កំពូល៖ \(V_1(0, -a) \,,\, V_2(0, a)\)
\(\bullet\) កំណុំ៖ \(F_1(0, -c) \,,\, F_2(0, c)\) (\(c^2 = a^2 + b^2\))
\(\bullet\) អាស៊ីមតូត៖ \(y = \pm \dfrac{a}{b}x\)
ឧទាហរណ៍

គេឱ្យសមីការអ៊ីពែរបូល \(\dfrac{x^2}{16} - \dfrac{y^2}{9} = 1\)។ រកកូអរដោនេកំពូល កំណុំ និងសមីការអាស៊ីមតូតទាំងពីរ។

ចម្លើយ

សមីការ \(\dfrac{x^2}{16} - \dfrac{y^2}{9} = 1\) មានទម្រង់ស្តង់ដា \(\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1\) ដែលជាអ៊ីពែរបូលមានអ័ក្សទទឹងដេក (នៅលើអ័ក្ស \(x\)) និងផ្ចិតនៅគល់តម្រុយ \(I(0, 0)\)។

  • \(a^2 = 16 \implies a = 4\) និង \(b^2 = 9 \implies b = 3\)

  • \(c^2 = a^2 + b^2 = 16 + 9 = 25 \implies c = 5\)

  • កំពូលទាំងពីរ៖ \(V_1(-a, 0) = V_1(-4, 0)\) និង \(V_2(a, 0) = V_2(4, 0)\)

  • កំណុំទាំងពីរ៖ \(F_1(-c, 0) = F_1(-5, 0)\) និង \(F_2(c, 0) = F_2(5, 0)\)

  • សមីការអាស៊ីមតូតទាំងពីរ៖ \(y = \pm \dfrac{b}{a}x \iff y = \pm \dfrac{3}{4}x\)

ខ. ផ្ចិតនៅ \(I(h, k)\)

សំណើ

  1. អ័ក្សទទឹងដេក (Horizontal Transverse Axis):

    \[\frac{(x-h)^2}{a^2} - \frac{(y-k)^2}{b^2} = 1\]

    • ផ្ចិត: \(I(h,k)\)

    • កំពូល: \(V_1(h-a, k) \,,\, V_2(h+a, k)\)

    • កំណុំ: \(F_1(h-c, k) \,,\, F_2(h+c, k)\)

    • អាស៊ីមតូត: \(y - k = \pm \dfrac{b}{a}(x - h)\)

  2. អ័ក្សទទឹងឈរ (Vertical Transverse Axis):

    \[\frac{(y-k)^2}{a^2} - \frac{(x-h)^2}{b^2} = 1\]

    • ផ្ចិត: \(I(h,k)\)

    • កំពូល: \(V_1(h, k-a) \,,\, V_2(h, k+a)\)

    • កំណុំ: \(F_1(h, k-c) \,,\, F_2(h, k+c)\)

    • អាស៊ីមតូត: \(y - k = \pm \dfrac{a}{b}(x - h)\)

អនុវត្ត សង្ខេបខ្លឹមសារ

លក្ខណៈ / អ័ក្សទទឹង អ័ក្សទទឹងដេក (ស្របអ័ក្ស \(x\)) អ័ក្សទទឹងឈរ (ស្របអ័ក្ស \(y\))
សមីការស្តង់ដា \(\dfrac{(x-h)^2}{a^2} - \dfrac{(y-k)^2}{b^2} = 1\) \(\dfrac{(y-k)^2}{a^2} - \dfrac{(x-h)^2}{b^2} = 1\)
ផ្ចិត \(I(h, k)\) \(I(h, k)\)
កូអរដោនេកំពូលទាំងពីរ \(V_1,V_2\) \(V_1(h-a, k) \,,\, V_2(h+a, k)\) \(V_1(h, k-a) \,,\, V_2(h, k+a)\)
តម្លៃ \(c\) \(c = \sqrt{a^2+b^2} \;\; (c^2 = a^2+b^2)\) \(c = \sqrt{a^2+b^2} \;\; (c^2 = a^2+b^2)\)
កូអរដោនេកំណុំ \(F_1, F_2\) \(F_1(h-c, k) \,,\, F_2(h+c, k)\) \(F_1(h, k-c) \,,\, F_2(h, k+c)\)
សមីការអាស៊ីមតូតទាំងពីរ \(y - k = \pm\dfrac{b}{a}(x-h)\) \(y - k = \pm\dfrac{a}{b}(x-h)\)
ក្រាប រូបភាព (មើលក្នុងសៀវភៅ)

ចម្លើយ

សមីការ \(\dfrac{(x-2)^2}{16} - \dfrac{(y+1)^2}{9} = 1\) មានទម្រង់ស្តង់ដា \(\dfrac{(x-h)^2}{a^2} - \dfrac{(y-k)^2}{b^2} = 1\) ដែលជាអ៊ីពែរបូលមានអ័ក្សទទឹងស្របនឹងអ័ក្ស \(x\)។

  • ផ្ចិត៖ \(I(h, k) = I(2, -1)\)

  • \(a^2 = 16 \implies a = 4\) និង \(b^2 = 9 \implies b = 3\)

  • \(c^2 = a^2 + b^2 = 16 + 9 = 25 \implies c = 5\)

  • កំពូលទាំងពីរ៖ \(V(h \pm a, k) \implies V_1(2-4, -1) = V_1(-2, -1)\) និង \(V_2(2+4, -1) = V_2(6, -1)\)

  • កំណុំទាំងពីរ៖ \(F(h \pm c, k) \implies F_1(2-5, -1) = F_1(-3, -1)\) និង \(F_2(2+5, -1) = F_2(7, -1)\)

  • សមីការអាស៊ីមតូតទាំងពីរ៖ \(y - k = \pm \frac{b}{a}(x - h) \iff y + 1 = \pm \frac{3}{4}(x - 2)\)

  • ប្រៀបធៀបនឹងសមីការស្តង់ដា៖ \(\dfrac{(x-h)^2}{a^2} - \dfrac{(y-k)^2}{b^2} = 1\) ជាអ៊ីពែរបូលដែលមានអ័ក្សទទឹងដេក (នៅលើបន្ទាត់ \(y = -1\))។

  • គេបាន៖ \(h = 0, \; k = -1, \; a^2 = \frac{1}{4} \implies a = \frac{1}{2}, \; b^2 = 1 \implies b = 1\)

  • \(c = \sqrt{a^2 + b^2} = \sqrt{\frac{1}{4} + 1} = \frac{\sqrt{5}}{2} \approx 1.12\)

  • ផ្ចិត៖ \(I(h, k) = I(0, -1)\)

  • កំពូលទាំងពីរ៖ \(V(h \pm a, k) \implies V_1\left(-\dfrac{1}{2}, -1\right)\) និង \(V_2\left(\dfrac{1}{2}, -1\right)\)

  • កំណុំទាំងពីរ៖ \(F(h \pm c, k) \implies F_1\left(-\dfrac{\sqrt{5}}{2}, -1\right)\) និង \(F_2\left(\dfrac{\sqrt{5}}{2}, -1\right)\)

  • សមីការអាស៊ីមតូតទាំងពីរ៖ \(y - k = \pm \frac{b}{a}(x - h) \iff y + 1 = \pm 2x \implies D_1: y = 2x - 1, \; D_2: y = -2x - 1\)

ដូចនេះ សមីការស្តង់ដាគឺ \(\boxed{\frac{(y-1)^2}{16} - \frac{(x-3)^2}{9} = 1}\)

លំហាត់ទី ១២ ៖ ទីតាំងកប៉ាល់តាមប្រព័ន្ធ LORAN

កប៉ាល់មួយកំពុងធ្វើដំណើរស្របនឹងឆ្នេរត្រង់ជាប់មាត់សមុទ្រ ហើយមានចម្ងាយ \(160\text{ km}\) ពីមាត់សមុទ្រ។ កប៉ាល់នេះបានបង្ហាញនូវសញ្ញាគ្រោះថ្នាក់ដែលត្រូវទទួលដោយស្ថានីយពីរ \(A\) និង \(B\) ហើយមានចម្ងាយពីគ្នា \(320\text{ km}\) ដូចរូប។ តាមការវាស់រយៈពេលខុសគ្នាដោយមន្ត្រីស្ថានីយក្នុងការចាប់បានសញ្ញាគ្រោះថ្នាក់កំណត់ឃើញថា កប៉ាល់នេះនៅជិតស្ថានីយ \(B\) ជាងស្ថានីយ \(A\) ចម្ងាយ \(256\text{ km}\)។ តើកប៉ាល់នេះមានទីតាំងនៅត្រង់ចំណុចណា?

ដំណោះស្រាយ

  • កំណត់ច្រាំងសមុទ្រជាអ័ក្ស \(x\) ៖ ស្ថានីយ \(A(-160, 0)\) និង \(B(160, 0)\) នាំឱ្យ \(c = 160\)។

  • ផលដកចម្ងាយ \(d_A - d_B = 2a = 256 \implies a = 128\)។

  • \(b^2 = c^2 - a^2 = 160^2 - 128^2 = (160-128)(160+128) = 32 \times 288 = 9216 \implies b = 96\)។

  • សមីការអ៊ីពែរបូល (ខ្នែងជិត \(B\) គឺ \(x > 0\)) ៖ \(\frac{x^2}{128^2} - \frac{y^2}{96^2} = 1\)

  • កប៉ាល់នៅចម្ងាយ \(y = 160\text{ km}\) ពីឆ្នេរ ៖ \(\frac{x^2}{128^2} = 1 + \frac{160^2}{96^2} = 1 + \left(\frac{5}{3}\right)^2 = \frac{34}{9} \implies x = \frac{128\sqrt{34}}{3} \approx 128\sqrt{3.7}\)

ដូចនេះ ទីតាំងកប៉ាល់គឺ \(\boxed{\left(\frac{128\sqrt{34}}{3}, \; 160\right) \approx (128\sqrt{3.7}, \; 160)}\)

លំហាត់ទី ១៣

រកសមីការស្តង់ដានៃអ៊ីពែរបូលដែលចំពោះគ្រប់ចំណុចនៅលើអ៊ីពែរបូលមានផលដកចម្ងាយរបស់វាពីចំណុច \((-3,0)\) និង \((-3, -3)\) ស្មើនឹង \(2\)។

ដំណោះស្រាយ

  • ចំណុចនឹងទាំងពីរជាកំណុំ ៖ \(F_1(-3, 0)\) និង \(F_2(-3, -3) \implies\) អ័ក្សទទឹងឈរ \(x = -3\)។

  • ផ្ចិត \(I\left(-3, \frac{0 + (-3)}{2}\right) = I\left(-3, -\frac{3}{2}\right)\)។

  • ចម្ងាយរវាងកំណុំ ៖ \(2c = |0 - (-3)| = 3 \implies c = \frac{3}{2}\)។

  • ផលដកចម្ងាយថេរ ៖ \(2a = 2 \implies a = 1 \implies a^2 = 1\)។

  • \(b^2 = c^2 - a^2 = \left(\frac{3}{2}\right)^2 - 1^2 = \frac{9}{4} - 1 = \frac{5}{4}\)។

  • សមីការស្តង់ដា ៖ \(\frac{(y-k)^2}{a^2} - \frac{(x-h)^2}{b^2} = 1\)

ដូចនេះ សមីការស្តង់ដាគឺ \(\boxed{\frac{\left(y + \frac{3}{2}\right)^2}{1} - \frac{(x + 3)^2}{\frac{5}{4}} = 1}\)

លំហាត់ទី ១៤

រកសមីការស្តង់ដានៃអ៊ីពែរបូលដែលចំពោះគ្រប់ចំណុចនៅលើអ៊ីពែរបូលមានផលដកចម្ងាយរបស់វាពីចំណុច \((2,2)\) និង \((10,2)\) ស្មើនឹង \(6\)។

ដំណោះស្រាយ

  • ចំណុចនឹងទាំងពីរជាកំណុំ ៖ \(F_1(2, 2)\) និង \(F_2(10, 2) \implies\) អ័ក្សទទឹងដេក \(y = 2\)។

  • ផ្ចិត \(I\left(\frac{2 + 10}{2}, 2\right) = I(6, 2)\)។

  • ចម្ងាយរវាងកំណុំ ៖ \(2c = |10 - 2| = 8 \implies c = 4\)។

  • ផលដកចម្ងាយថេរ ៖ \(2a = 6 \implies a = 3 \implies a^2 = 9\)។

  • \(b^2 = c^2 - a^2 = 4^2 - 3^2 = 16 - 9 = 7\)។

  • សមីការស្តង់ដា ៖ \(\frac{(x-h)^2}{a^2} - \frac{(y-k)^2}{b^2} = 1\)

ដូចនេះ សមីការស្តង់ដាគឺ \(\boxed{\frac{(x-6)^2}{9} - \frac{(y-2)^2}{7} = 1}\)

លំហាត់ទី ១៥

បង្ហាញថាបន្ទាត់ប៉ះទៅនឹង \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\) ត្រង់ចំណុច \((x_0, y_0)\) មានសមីការ \(\frac{x_0x}{a^2} - \frac{y_0y}{b^2} = 1\)។

ដំណោះស្រាយ

  • យកដេរីវេធៀបនឹង \(x\) លើ \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\) ៖ \(\frac{2x}{a^2} - \frac{2yy'}{b^2} = 0 \implies y' = \frac{b^2x}{a^2y}\)។

  • ត្រង់ចំណុចប៉ះ \((x_0, y_0)\) មេគុណប្រាប់ទិសគឺ \(m = y'(x_0) = \frac{b^2x_0}{a^2y_0}\)។

  • សមីការបន្ទាត់ប៉ះ ៖ \(y - y_0 = \frac{b^2x_0}{a^2y_0}(x - x_0) \iff \frac{y_0(y - y_0)}{b^2} = \frac{x_0(x - x_0)}{a^2}\)

    \[\iff \frac{x_0x}{a^2} - \frac{y_0y}{b^2} = \frac{x_0^2}{a^2} - \frac{y_0^2}{b^2}\]

  • ដោយ \((x_0, y_0)\) នៅលើអ៊ីពែរបូល នាំឱ្យ \(\frac{x_0^2}{a^2} - \frac{y_0^2}{b^2} = 1\) (ពិត)។

ដូចនេះ សមីការបន្ទាត់ប៉ះគឺ \(\boxed{\frac{x_0x}{a^2} - \frac{y_0y}{b^2} = 1}\) (ត្រូវបានស្រាយបំភ្លឺ)

លំហាត់ទី ១៦

កំណុំទាំងពីរនៃអ៊ីពែរបូលគឺ \(F_1(0,3)\) និង \(F_2(0,-3)\) ហើយ \(P\) ជាចំណុចមួយនៅលើអ៊ីពែរបូលដែលមានផលដកចម្ងាយរបស់វាពីចំណុច \(F_1\) និង \(F_2\) ស្មើនឹង \(2\) ឯកតា។ ប្រើនិយមន័យនៃអ៊ីពែរបូលទាញរកសមីការស្តង់ដានៃអ៊ីពែរបូលនោះ។

ដំណោះស្រាយ

  • កំណុំ \(F_1(0, 3)\) និង \(F_2(0, -3)\) នៅលើអ័ក្សឈរ នាំឱ្យផ្ចិត \(O(0, 0)\) និង \(c = 3\)។

  • តាមនិយមន័យផលដកចម្ងាយ ៖ \(|PF_1 - PF_2| = 2a = 2 \implies a = 1 \implies a^2 = 1\)។

  • \(b^2 = c^2 - a^2 = 3^2 - 1^2 = 9 - 1 = 8\)។

  • សមីការស្តង់ដានៃអ៊ីពែរបូលឈរ ៖ \(\frac{y^2}{a^2} - \frac{x^2}{b^2} = 1\)

ដូចនេះ សមីការស្តង់ដាគឺ \(\boxed{\frac{y^2}{1} - \frac{x^2}{8} = 1}\)

លំហាត់ទី ១៧

រកសមីការនៃអ៊ីពែរបូលដែលមានកំណុំ \((\pm 4,0)\) ហើយតម្លៃនៃផលដកចម្ងាយពីចំណុចមួយនៅលើអ៊ីពែរបូលទៅកំណុំទាំងពីរស្មើនឹង \(4\)។

ដំណោះស្រាយ

  • កំណុំ \(F(\pm 4, 0)\) នៅលើអ័ក្សដេក នាំឱ្យផ្ចិត \(O(0, 0)\) និង \(c = 4\)។

  • ផលដកចម្ងាយថេរ ៖ \(2a = 4 \implies a = 2 \implies a^2 = 4\)។

  • \(b^2 = c^2 - a^2 = 4^2 - 2^2 = 16 - 4 = 12\)។

  • សមីការស្តង់ដានៃអ៊ីពែរបូលដេក ៖ \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\)

ដូចនេះ សមីការស្តង់ដាគឺ \(\boxed{\frac{x^2}{4} - \frac{y^2}{12} = 1}\)

លំហាត់ទី ១៨

រកសមីការបន្ទាត់ប៉ះទៅនឹងអ៊ីពែរបូល \(9x^2 - 4y^2 = 36\) ដែលកាត់តាមចំណុច \((1,0)\)។

ដំណោះស្រាយ

  • សមីការបន្ទាត់កាត់តាម \((1, 0)\) មានមេគុណប្រាប់ទិស \(m\) ៖ \(y = m(x - 1)\)។

  • ជំនួសក្នុង \(9x^2 - 4y^2 = 36\) ៖

    \[9x^2 - 4m^2(x-1)^2 = 36 \iff (9 - 4m^2)x^2 + 8m^2x - (4m^2 + 36) = 0\]

  • លក្ខខណ្ឌប៉ះ គឺសមីការមានឫសឌុប (\(\Delta' = 0\)) ៖

    \[\Delta' = 16m^4 + (9 - 4m^2)(4m^2 + 36) = 0 \iff 324 - 108m^2 = 0 \implies m = \pm\sqrt{3}\]

ដូចនេះ សមីការបន្ទាត់ប៉ះទាំងពីរគឺ \(\boxed{\sqrt{3}x \pm y - \sqrt{3} = 0}\)

លំហាត់ទី ១៩ ៖ គន្លងភាគល្អិតអាល់ហ្វា

អ្នករូបវិទ្យាបានរកឃើញថា នៅពេលភាគល្អិតអាល់ហ្វាត្រូវបានគេបាញ់ឆ្ពោះទៅណ្វៃយ៉ូនៃអាតូមមួយ វាបានច្រានចេញពីណ្វៃយ៉ូតាមគន្លងអ៊ីពែរបូល។ រូបខាងក្រោមនេះបង្ហាញពីគន្លងនៃភាគល្អិតដែលចាប់ផ្តើមឆ្ពោះទៅគល់អ័ក្សកូអរដោនេតាមបន្ទាត់មួយមានសមីការ \(y = \frac{1}{2}x\) ហើយធ្លាក់មក \(3\) ឯកតាពីណ្វៃយ៉ូ។ ចូររកសមីការនៃគន្លង។

ដំណោះស្រាយ

  • អាស៊ីមតូត \(y = \frac{1}{2}x \implies \frac{b}{a} = \frac{1}{2} \implies a = 2b\)។

  • ណ្វៃយ៉ូនៅកំណុំ \((c, 0)\) នាំឱ្យចម្ងាយជិតបំផុតទៅកំពូលគឺ \(c - a = 3\)។

  • \(c = \sqrt{a^2 + b^2} = \sqrt{4b^2 + b^2} = \sqrt{5}b\)។

  • \(\sqrt{5}b - 2b = 3 \implies b = \frac{3}{\sqrt{5}-2} = 3(\sqrt{5}+2)\)។

  • \(a = 2b = 6(\sqrt{5}+2)\)។

  • សមីការស្តង់ដានៃគន្លងអ៊ីពែរបូល ៖ \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\)

ដូចនេះ សមីការគន្លងគឺ ៖ \(\boxed{\frac{x^2}{36(\sqrt{5}+2)^2} - \frac{y^2}{9(\sqrt{5}+2)^2} = 1}\)
