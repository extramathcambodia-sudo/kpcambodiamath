មេរៀនទាំងអស់

ម៉ូដែលគណិតវិទ្យា និងអនុវត្តន៍ក្នុងវិទ្យាសាស្ត្រ

សមីការឌីផេរ៉ង់ស្យែល គឺជាឧបករណ៍គណិតវិទ្យាដ៏មានឥទ្ធិពលបំផុត ក្នុងការបង្កើតគំរូ (Mathematical Modeling) ដើម្បីសិក្សាពីបាតុភូតធម្មជាតិ បម្រែបម្រួលរូបវិទ្យា ជីវសាស្ត្រ និងសេដ្ឋកិច្ច។

កំណើនប្រជាជន និងបម្រែបម្រួលបរិមាណ

និយមន័យ

បើអត្រាបម្រែបម្រួលនៃចំនួនប្រជាជន \(P(t)\) នៅខណៈពេល \(t\) សមាមាត្រទៅនឹងចំនួនប្រជាជនដែលមាននៅពេលនោះ នោះគេបានសមីការឌីផេរ៉ង់ស្យែល ៖

\[\frac{dP}{dt} = kP \quad{} (k > 0 \text{ ជាថេរអត្រាកំណើន})\]
ចម្លើយទូទៅនៃសមីការនេះគឺ ៖
\[P(t) = P_0 e^{kt}\]
ដែល \(P_0 = P(0)\) ជាចំនួនប្រជាជននៅខណៈដើម \(t = 0\)។

ជាទូទៅ

រយៈពេលដែលចំនួនប្រជាជនកើនឡើងទ្វេដង (Doubling Time \(T_d\)) ៖
គេឱ្យ \(P(T_d) = 2P_0 \iff P_0 e^{k T_d} = 2P_0 \iff e^{k T_d} = 2\)។
ទាញបាន ៖

\[T_d = \frac{\ln 2}{k}\]

ការបំបែកធាតុវិទ្យុសកម្ម និងកន្លះជីវិត

និយមន័យ

អត្រានៃការបំបែកធាតុវិទ្យុសកម្ម \(N(t)\) គឺសមាមាត្រទៅនឹងបរិមាណសារធាតុដែលនៅសល់ ៖

\[\frac{dN}{dt} = -\lambda N \quad{} (\lambda > 0 \text{ ជាថេរបំបែក ឬ Decay constant})\]
ចម្លើយទូទៅនៃសមីការនេះគឺ ៖
\[N(t) = N_0 e^{-\lambda t}\]
ដែល \(N_0 = N(0)\) ជាបរិមាណសារធាតុនៅខណៈដើម \(t = 0\)។

ជាទូទៅ

កន្លះជីវិតនៃសារធាតុវិទ្យុសកម្ម (Half-life \(T_{1/2}\)) ៖
កន្លះជីវិត គឺជារយៈពេលដែលសារធាតុវិទ្យុសកម្មថយចុះអស់ពាក់កណ្តាលនៃបរិមាណដើម ៖

\[N(T_{1/2}) = \frac{N_0}{2} \iff N_0 e^{-\lambda T_{1/2}} = \frac{N_0}{2} \iff e^{-\lambda T_{1/2}} = \frac{1}{2}\]
ទាញបានរូបមន្តទំនាក់ទំនង ៖
\[T_{1/2} = \frac{\ln 2}{\lambda} \quad{} \text{ឬ} \quad{} \lambda = \frac{\ln 2}{T_{1/2}}\]

ច្បាប់ត្រជាក់នៃញូតុន

និយមន័យ

ច្បាប់ត្រជាក់នៃញូតុនចែងថា ៖ អត្រាបម្រែបម្រួលសីតុណ្ហភាពនៃអង្គធាតុមួយ សមាមាត្រទៅនឹងផលដកនៃសីតុណ្ហភាពរបស់អង្គធាតុ និងសីតុណ្ហភាពនៃមជ្ឈដ្ឋានជុំវិញ ៖

\[\frac{dT}{dt} = -k(T - T_m) \quad{} (k > 0)\]
ដែល \(T(t)\) ជាសីតុណ្ហភាពនៃអង្គធាតុនៅខណៈពេល \(t\), \(T_m\) ជាសីតុណ្ហភាពថេរនៃមជ្ឈដ្ឋានជុំវិញ, និង \(k\) ជាមេគុណត្រជាក់។

ជាទូទៅ

តាមវិធីញែកអថេរ គេបាន ៖

\[\frac{dT}{T - T_m} = -k\,dt \implies \ln|T - T_m| = -kt + C \implies T(t) - T_m = A e^{-kt}\]
បើនៅខណៈ \(t = 0\), \(T(0) = T_0\) (សីតុណ្ហភាពដើម) នោះ \(A = T_0 - T_m\)។ ដូចនេះ ៖
\[T(t) = T_m + (T_0 - T_m)e^{-kt}\]

ចលនារបស់វត្ថុក្នុងមជ្ឈដ្ឋានទប់

និយមន័យ

អង្គធាតុមួយមានម៉ាស \(m\) ធ្លាក់ចុះក្រោមក្រោមអំពើនៃកម្លាំងទំនាញ \(P = mg\) និងកម្លាំងទប់នៃខ្យល់ \(F_r = -kv\) (\(k > 0\) ជាមេគុណកកិត)។ តាមច្បាប់ទី២ ញូតុន ៖

\[m\frac{dv}{dt} = mg - kv \iff \frac{dv}{dt} + \frac{k}{m}v = g\]

ជាទូទៅ

សមីការ \(\dfrac{dv}{dt} + \dfrac{k}{m}v = g\) ជាសមីការលីនេអ៊ែលំដាប់ទី១ មិនអូម៉ូសែន ៖

  • ចម្លើយនៃសមីការអូម៉ូសែន ៖ \(v_c = C e^{-\frac{k}{m}t}\)

  • ចម្លើយពិសេសថេរ ៖ \(v_p = \dfrac{mg}{k}\)

  • ចម្លើយទូទៅ ៖ \(v(t) = \dfrac{mg}{k} + C e^{-\frac{k}{m}t}\)

  • បើល្បឿនដើម \(v(0) = 0\) នោះ \(C = -\dfrac{mg}{k}\) នាំឱ្យ ៖

    \[v(t) = \frac{mg}{k}\left(1 - e^{-\frac{k}{m}t}\right)\]

  • កាលណា \(t \to +\infty\), ល្បឿនខិតទៅរក ល្បឿនព្រំដែន (Terminal Velocity) ៖

    \[v_{\text{lim}} = \lim_{t \to +\infty} v(t) = \frac{mg}{k}\]

លំយោលមេកានិចនៃប្រព័ន្ធរ៉ឺស័រ

និយមន័យ

ប្រព័ន្ធម៉ាស-រ៉ឺស័រមានម៉ាស \(m\), ថេរកម្រាញរ៉ឺស័រ \(k > 0\), និងកម្លាំងទប់កកិត \(c \ge 0\) ផ្ទៀងផ្ទាត់សមីការឌីផេរ៉ង់ស្យែលលំដាប់ទី២ ៖

\[m y'' + c y' + k y = 0\]

  1. លំយោលសេរីគ្មានកកិត (\(c = 0\)) ៖ \(m y'' + k y = 0 \iff y'' + \omega_0^2 y = 0\) ដែល \(\omega_0 = \sqrt{\frac{k}{m}}\) ជាប្រេកង់កែង។
    ចម្លើយទូទៅ ៖ \(y(t) = A\cos\omega_0 t + B\sin\omega_0 t\)។

  2. លំយោលខ្សោយ (\(c^2 - 4mk < 0\)) ៖ ចលនាថយចុះជាលំយោល ៖

    \[y(t) = e^{-\alpha t}(A\cos\beta t + B\sin\beta t) \quad{} \text{ដែល } \alpha = \frac{c}{2m}\]

ឧទាហរណ៍គំរូ និងវិធីសាស្ត្រដោះស្រាយ

ឧទាហរណ៍

(កំណើនបាក់តេរី) នៅក្នុងមន្ទីរពិសោធន៍មួយ គេសង្កេតឃើញថាបាក់តេរីកើនឡើងតាមច្បាប់កំណើនអិចស្ប៉ូណង់ស្យែល \(\dfrac{dP}{dt} = kP\)។ នៅពេលចាប់ផ្តើមពិសោធន៍ (\(t = 0\)) គេរាប់ឃើញមានបាក់តេរីចំនួន \(1000\) កោសិកា។ រយៈពេល \(3\) ម៉ោងក្រោយមក បរិមាណបាក់តេរីកើនឡើងដល់ \(4000\) កោសិកា។

  1. កំណត់កន្សោម \(P(t)\) ជាអនុគមន៍នៃពេល \(t\) (គិតជាម៉ោង)។

  2. រកចំនួនបាក់តេរីក្រោយពេលកន្លងផុតទៅ \(5\) ម៉ោង។

  3. តើរយៈពេលប៉ុន្មានម៉ោង ទើបចំនួនបាក់តេរីកើនដល់ \(16000\) កោសិកា?

ដំណោះស្រាយ

  1. សមីការ \(\dfrac{dP}{dt} = kP\) មានចម្លើយទូទៅ \(P(t) = P_0 e^{kt}\)។
    នៅពេល \(t = 0\), \(P(0) = 1000 \implies P_0 = 1000\)។ ដូចនេះ \(P(t) = 1000 e^{kt}\)។
    នៅពេល \(t = 3\), \(P(3) = 4000\) នាំឱ្យ ៖

    \[1000 e^{3k} = 4000 \iff e^{3k} = 4 \iff 3k = \ln 4 \iff k = \frac{\ln 4}{3} = \frac{2\ln 2}{3}\]
    ដូចនេះ កន្សោមអនុគមន៍គឺ ៖
    \[P(t) = 1000 e^{\left(\frac{\ln 4}{3}\right)t} = 1000 \cdot 4^{t/3}\]

  2. ក្រោយពេល \(t = 5\) ម៉ោង ៖

    \[P(5) = 1000 \cdot 4^{5/3} = 1000 \cdot \sqrt[3]{4^5} = 1000 \cdot 4\sqrt[3]{16} = 1000 \cdot 8\sqrt[3]{2} \approx 10080 \text{ កោសិកា}\]

  3. រក \(t\) ដើម្បីឱ្យ \(P(t) = 16000\) ៖

    \[1000 \cdot 4^{t/3} = 16000 \iff 4^{t/3} = 16 = 4^2 \iff \frac{t}{3} = 2 \iff t = 6 \text{ ម៉ោង}\]
    ដូចនេះ រយៈពេល \(6\) ម៉ោង ទើបចំនួនបាក់តេរីកើនដល់ \(16000\) កោសិកា។

ឧទាហរណ៍

(ច្បាប់ត្រជាក់នៃញូតុន) កាហ្វេក្តៅមួយពែងទើបឆុងរួចមានសីតុណ្ហភាព \(95^\circ\text{C}\) ត្រូវបានគេយកមកដាក់លើតុក្នុងបន្ទប់ដែលមានសីតុណ្ហភាពថេរ \(20^\circ\text{C}\)។ រយៈពេល \(5\) នាទីក្រោយមក សីតុណ្ហភាពកាហ្វេថយចុះនៅត្រឹម \(70^\circ\text{C}\)។

  1. រកសមីការសីតុណ្ហភាព \(T(t)\) ជាអនុគមន៍នៃពេល \(t\) (គិតជានាទី)។

  2. គណនាសីតុណ្ហភាពកាហ្វេក្រោយពេលដាក់ចោល \(15\) នាទី។

  3. តើត្រូវចំណាយពេលប៉ុន្មាននាទី ទើបសីតុណ្ហភាពកាហ្វេថយចុះមកដល់ \(40^\circ\text{C}\)?

ដំណោះស្រាយ

  1. តាមច្បាប់ត្រជាក់នៃញូតុន ៖ \(\dfrac{dT}{dt} = -k(T - T_m)\) ដែល \(T_m = 20^\circ\text{C}\)។
    ចម្លើយទូទៅគឺ ៖ \(T(t) = 20 + (T_0 - 20)e^{-kt}\)។
    ដោយ \(T(0) = 95^\circ\text{C}\) នាំឱ្យ \(T(t) = 20 + 75e^{-kt}\)។
    នៅពេល \(t = 5\), \(T(5) = 70^\circ\text{C}\) នាំឱ្យ ៖

    \[20 + 75e^{-5k} = 70 \iff 75e^{-5k} = 50 \iff e^{-5k} = \frac{50}{75} = \frac{2}{3}\]
    នាំឱ្យ \(-5k = \ln\left(\dfrac{2}{3}\right) = -\ln\left(\dfrac{3}{2}\right) \implies k = \dfrac{1}{5}\ln\left(\dfrac{3}{2}\right) \approx 0.0811\)។
    ដូចនេះ សមីការសីតុណ្ហភាពគឺ ៖
    \[T(t) = 20 + 75\left(\frac{2}{3}\right)^{t/5}\]

  2. ក្រោយពេល \(t = 15\) នាទី ៖

    \[T(15) = 20 + 75\left(\frac{2}{3}\right)^{15/5} = 20 + 75\left(\frac{2}{3}\right)^3 = 20 + 75 \cdot \frac{8}{27} = 20 + \frac{200}{9} \approx 42.22^\circ\text{C}\]

  3. រកពេល \(t\) ដែល \(T(t) = 40^\circ\text{C}\) ៖

    \[20 + 75e^{-kt} = 40 \iff 75e^{-kt} = 20 \iff e^{-kt} = \frac{20}{75} = \frac{4}{15}\]
    យកលោការីតនេពែ ៖
    \[-kt = \ln\left(\frac{4}{15}\right) \implies t = \frac{\ln(15/4)}{k} = \frac{\ln(3.75)}{0.0811} \approx 16.3 \text{ នាទី}\]
    ដូចនេះ ត្រូវចំណាយពេលប្រហែល \(16.3\) នាទី។

ឧទាហរណ៍

(ការបំបែកធាតុវិទ្យុសកម្ម និងកាបូន-១៤) ធាតុវិទ្យុសកម្មប៉ូឡូញ៉ូម \(^{210}\text{Po}\) មានកន្លះជីវិត \(140\) ថ្ងៃ។ សន្មតថាបរិមាណវិទ្យុសកម្មបំបែកទៅតាមសមីការ \(\dfrac{dN}{dt} = -\lambda N\)។ គេមានសំណាកប៉ូឡូញ៉ូមដើម \(N_0 = 12\text{ mg}\)។

  1. គណនាថេរបំបែក \(\lambda\) នៃប៉ូឡូញ៉ូម \(^{210}\text{Po}\)។

  2. រកបរិមាណប៉ូឡូញ៉ូមដែលនៅសល់ក្រោយពេល \(70\) ថ្ងៃ។

  3. តើរយៈពេលប៉ុន្មានថ្ងៃ ទើបសំណាកនោះបំបែកអស់ \(90\%\) នៃបរិមាណដើម?

ដំណោះស្រាយ

  1. តាមរូបមន្តទំនាក់ទំនងរវាងកន្លះជីវិត និងថេរបំបែក ៖

    \[\lambda = \frac{\ln 2}{T_{1/2}} = \frac{\ln 2}{140} \approx 0.00495 \text{ ថ្ងៃ}^{-1}\]

  2. ចម្លើយទូទៅគឺ \(N(t) = N_0 e^{-\lambda t} = 12 e^{-\left(\frac{\ln 2}{140}\right)t} = 12 \cdot 2^{-t/140}\)។
    ក្រោយពេល \(t = 70\) ថ្ងៃ ៖

    \[N(70) = 12 \cdot 2^{-70/140} = 12 \cdot 2^{-1/2} = \frac{12}{\sqrt{2}} = 6\sqrt{2} \approx 8.49\text{ mg}\]
    ដូចនេះ នៅសល់ប៉ូឡូញ៉ូមប្រហែល \(8.49\text{ mg}\)។

  3. កាលណាសំណាកបំបែកអស់ \(90\%\) នោះបរិមាណដែលនៅសល់គឺ \(10\%\) នៃ \(N_0\) ពោលគឺ ៖

    \[N(t) = 0.1 N_0 \iff N_0 e^{-\lambda t} = 0.1 N_0 \iff e^{-\lambda t} = 0.1 \iff -\lambda t = \ln(0.1) = -\ln 10\]
    នាំឱ្យ ៖
    \[t = \frac{\ln 10}{\lambda} = \frac{\ln 10}{\frac{\ln 2}{140}} = 140 \cdot \frac{\ln 10}{\ln 2} \approx 140 \cdot 3.3219 \approx 465 \text{ ថ្ងៃ}\]
    ដូចនេះ ត្រូវចំណាយពេលប្រហែល \(465\) ថ្ងៃ។

ឧទាហរណ៍

(ចលនាធ្លាក់ក្នុងមជ្ឈដ្ឋានមានកកិត និងល្បឿនព្រំដែន) វត្ថុមួយមានម៉ាស \(m = 5\text{ kg}\) ត្រូវបានទម្លាក់ពីលើកំពូលអគារខ្ពស់មួយដោយគ្មានល្បឿនដើម (\(v(0) = 0\))។ ក្នុងពេលធ្លាក់ វត្ថុរងកម្លាំងទប់នៃខ្យល់ \(F_r = -kv\) ដែល \(k = 10\text{ kg/s}\) (យក \(g = 9.8\text{ m/s}^2\))។

  1. បង្កើតសមីការឌីផេរ៉ង់ស្យែលនៃចលនា និងកំណត់កន្សោមល្បឿន \(v(t)\)។

  2. គណនាល្បឿនព្រំដែន (Terminal Velocity) \(v_{\text{lim}}\) នៃវត្ថុនោះ។

  3. គណនាល្បឿនវត្ថុនៅខណៈ \(t = 2\text{ s}\)។

ដំណោះស្រាយ

  1. តាមច្បាប់ទីពីរញូតុន ៖ \(m\dfrac{dv}{dt} = mg - kv \iff \dfrac{dv}{dt} + \dfrac{k}{m}v = g\)។
    ជំនួស \(m = 5\text{ kg}, k = 10\text{ kg/s}, g = 9.8\text{ m/s}^2\) ៖

    \[\frac{dv}{dt} + 2v = 9.8\]
    សមីការនេះមានចម្លើយទូទៅ ៖ \(v(t) = Ce^{-2t} + \dfrac{9.8}{2} = Ce^{-2t} + 4.9\)។
    ដោយល្បឿនដើម \(v(0) = 0 \implies C + 4.9 = 0 \implies C = -4.9\)។
    ដូចនេះ កន្សោមល្បឿនគឺ ៖
    \[v(t) = 4.9(1 - e^{-2t}) \text{ (m/s)}\]

  2. ល្បឿនព្រំដែននៅពេល \(t \to +\infty\) គឺ ៖

    \[v_{\text{lim}} = \lim_{t \to +\infty} 4.9(1 - e^{-2t}) = 4.9\text{ m/s}\]

  3. នៅខណៈ \(t = 2\text{ s}\) ៖

    \[v(2) = 4.9(1 - e^{-4}) \approx 4.9(1 - 0.0183) = 4.9 \times 0.9817 \approx 4.81\text{ m/s}\]

ឧទាហរណ៍

(សៀគ្វីអគ្គិសនី RL) សៀគ្វីអគ្គិសនីមួយរួមមានរេស៊ីស្តង់ \(R = 12\,\Omega\) និងប៊ូប៊ីនមានអាំងឌុចតង់ \(L = 3\text{ H}\) តភ្ជាប់ជាស៊េរីជាមួយប្រភពតង់ស្យុងថេរ \(E = 60\text{ V}\)។ សមីការឌីផេរ៉ង់ស្យែលតាងអាំងតង់ស៊ីតេចរន្ត \(i(t)\) គឺ ៖

\[L\frac{di}{dt} + Ri = E\]
ដោយដឹងថានៅខណៈដើម \(t = 0\) គ្មានចរន្តឆ្លងកាត់ (\(i(0) = 0\))។

  1. រកកន្សោមអាំងតង់ស៊ីតេចរន្ត \(i(t)\) ជាអនុគមន៍នៃពេល \(t\)។

  2. គណនាអាំងតង់ស៊ីតេចរន្តនៅពេលរបបអចិន្ត្រៃយ៍ (\(t \to +\infty\))។

  3. គណនាតម្លៃចរន្តនៅខណៈ \(t = 0.5\text{ s}\)។

ដំណោះស្រាយ

  1. ជំនួសតម្លៃ \(L = 3, R = 12, E = 60\) ចូលក្នុងសមីការ ៖

    \[3\frac{di}{dt} + 12i = 60 \iff \frac{di}{dt} + 4i = 20\]
    ចម្លើយនៃសមីការអូម៉ូសែន \(\dfrac{di}{dt} + 4i = 0\) គឺ \(i_c = Ce^{-4t}\)។
    ចម្លើយពិសេសថេរគឺ \(i_p = \dfrac{20}{4} = 5\)។
    នាំឱ្យចម្លើយទូទៅគឺ ៖ \(i(t) = Ce^{-4t} + 5\)។
    ដោយសារ \(i(0) = 0 \implies C + 5 = 0 \implies C = -5\)។
    ដូចនេះ កន្សោមអាំងតង់ស៊ីតេចរន្តគឺ ៖
    \[i(t) = 5(1 - e^{-4t}) \text{ (A)}\]

  2. នៅរបបអចិន្ត្រៃយ៍ (\(t \to +\infty\)) ៖

    \[I_{\text{max}} = \lim_{t \to +\infty} 5(1 - e^{-4t}) = 5\text{ A}\]

  3. នៅខណៈ \(t = 0.5\text{ s}\) ៖

    \[i(0.5) = 5(1 - e^{-4 \times 0.5}) = 5(1 - e^{-2}) \approx 5(1 - 0.1353) = 5 \times 0.8647 \approx 4.32\text{ A}\]

លំហាត់អនុវត្តន៍

  1. (វិទ្យុសកម្មកាបូន-១៤) ធាតុវិទ្យុសកម្មកាបូន \(^{14}\text{C}\) មានកន្លះជីវិត \(T_{1/2} = 5730 \) ឆ្នាំ ។ នៅក្នុងកំណាយបុរាណវិទ្យាមួយ គេរកឃើញបំណែកឈើបុរាណមួយ ដែលមានបរិមាណ \(^{14}\text{C}\) នៅសល់តែ \(35\%\) នៃបរិមាណដែលមានក្នុងរុក្ខជាតិរស់នៅបច្ចុប្បន្នប៉ុណ្ណោះ។ គណនាអាយុកាលនៃបំណែកឈើបុរាណនោះ។

  2. (ល្បឿនធ្លាក់នៃឆត្រយោង) អ្នកលោតឆត្រយោងម្នាក់មានម៉ាសសរុបរួមទាំងឆត្រ \(m = 80\text{ kg}\) លោតចេញពីយន្តហោះ។ កម្លាំងទប់នៃខ្យល់គឺ \(F_r = -kv\) ដែល \(k = 16\text{ kg/s}\) (យក \(g = 9.8\text{ m/s}^2\))។

    1. សរសេរសមីការឌីផេរ៉ង់ស្យែលនៃចលនា និងកំណត់ល្បឿន \(v(t)\) ជាអនុគមន៍នៃ \(t\) បើល្បឿនដើម \(v(0) = 0\)។

    2. គណនាល្បឿនព្រំដែន (Terminal velocity) របស់អ្នកលោតឆត្រយោង។

    3. គណនាល្បឿននៅខណៈ \(t = 5\text{ s}\)។

  3. (សីតុណ្ហភាពដែកក្តៅ) ដុំដែកមួយត្រូវបានដុតកម្តៅរហូតដល់ \(800^\circ\text{C}\) រួចគេទម្លាក់វាទៅក្នុងធុងទឹកត្រជាក់ដែលមានសីតុណ្ហភាពថេរ \(25^\circ\text{C}\)។ រយៈពេល \(2\) នាទីក្រោយមក សីតុណ្ហភាពដុំដែកថយចុះមកនៅត្រឹម \(200^\circ\text{C}\)។

    1. កំណត់សមីការសីតុណ្ហភាព \(T(t)\) នៃដុំដែក។

    2. តើរយៈពេលប៉ុន្មាននាទី ទើបសីតុណ្ហភាពដុំដែកថយមកត្រឹម \(50^\circ\text{C}\)?

  4. (លំយោលរ៉ឺស័រ) វត្ថុមួយមានម៉ាស \(m = 2\text{ kg}\) ភ្ជាប់នឹងរ៉ឺស័រដែលមានថេរកម្រាញ \(k = 50\text{ N/m}\) និងកម្លាំងទប់កកិត \(c = 12\text{ N}\cdot\text{s/m}\)។ នៅខណៈដើម \(t = 0\) គេទាញវត្ថុឱ្យឃ្លាតពីទីតាំងលំនឹងប្រវែង \(0.5\text{ m}\) ទៅខាងស្តាំ រួចលែងដោយគ្មានល្បឿនដើម។

    1. បង្កើតសមីការឌីផេរ៉ង់ស្យែលតាងចលនារបស់វត្ថុ។

    2. ដោះស្រាយសមីការដើម្បីរកសមីការទីតាំង \(y(t)\) នៃវត្ថុ។

    3. កំណត់ខណៈពេលដែលវត្ថុឆ្លងកាត់ទីតាំងលំនឹងជាលើកដំបូង។

  5. (សៀគ្វីអគ្គិសនី RLC) សៀគ្វីតភ្ជាប់ជាស៊េរីមានរេស៊ីស្តង់ \(R = 10\,\Omega\), អាំងឌុចតង់ \(L = 0.5\text{ H}\), និងកាប៉ាស៊ីទ័រ \(C = 0.02\text{ F}\) ភ្ជាប់នឹងប្រភពតង់ស្យុងថេរ \(E = 12\text{ V}\)។ សមីការបន្ទុកអគ្គិសនី \(q(t)\) គឺ ៖

    \[L q'' + R q' + \frac{1}{C} q = E\]
    ដោយដឹងថាបន្ទុកដើម \(q(0) = 0\) និងចរន្តដើម \(i(0) = q'(0) = 0\)។ ចូរកំណត់កន្សោមបន្ទុកអគ្គិសនី \(q(t)\) និងចរន្តអគ្គិសនី \(i(t) = q'(t)\)។

ដូចនេះ ៖ \(\boxed{y = (C_1 x + C_2)e^{3x}}\)

ខ កំណត់អនុគមន៍ \(f(x)\) ៖
\(f(0) = C_2 = 2\)។
\(f'(x) = [C_1 + 3(C_1 x + C_2)]e^{3x}\)។
\(f'(0) = C_1 + 3(2) = 7 \implies C_1 = 1\)។
ដូចនេះ ៖ \(\boxed{f(x) = (x + 2)e^{3x}}\)

គ សិក្សាអថេរភាពនៃ \(f(x)\) ៖
\(f'(x) = (1 + 3x + 6)e^{3x} = (3x + 7)e^{3x}\)។
ដោយ \(e^{3x} > 0 \implies f'(x) = 0 \iff x = -\dfrac{7}{3}\)។
- លើ \(\left(-\infty, -\dfrac{7}{3}\right)\) ៖ \(f'(x) < 0 \implies f\) ចុះ
- លើ \(\left(-\dfrac{7}{3}, +\infty\right)\) ៖ \(f'(x) > 0 \implies f\) កើន
អប្បបរមាធៀប ៖ \(f\left(-\dfrac{7}{3}\right) = -\dfrac{1}{3}e^{-7}\)។
ដូចនេះ ៖ \(f\) មានអប្បបរមា \(-\dfrac{1}{3}e^{-7}\) ត្រង់ \(x = -\dfrac{7}{3}\)

វិញ្ញាសាត្រៀមទី៣

គេឱ្យសមីការ \((E) \ : \ y'' + 4y = 3\sin x\) ៖

  1. រកចម្លើយទូទៅនៃ \((E_0) \ : \ y'' + 4y = 0\)

  2. រកចំនួនពិត \(A\) ដើម្បីឱ្យ \(y_p = A\sin x\) ជាចម្លើយពិសេសនៃ \((E)\)

  3. ទាញរកចម្លើយទូទៅ រួចកំណត់ចម្លើយដែល \(y(0) = 0\) និង \(y'\left(\dfrac{\pi}{2}\right) = 1\)

ដំណោះស្រាយ

ក ចម្លើយទូទៅនៃ \((E_0)\) ៖
\(r^2 + 4 = 0 \implies r = \pm 2i\)។
ដូចនេះ ៖ \(\boxed{y_h = C_1\cos 2x + C_2\sin 2x}\)

ខ កំណត់តម្លៃ \(A\) ៖
\(y_p'' = -A\sin x\)។ ជំនួសចូល \((E)\) ៖
\(-A\sin x + 4A\sin x = 3\sin x \iff 3A = 3 \implies A = 1\)។
ដូចនេះ ៖ \(\boxed{A = 1 \ \implies y_p = \sin x}\)

គ ចម្លើយទូទៅ និងចម្លើយពិសេស ៖
\(y = C_1\cos 2x + C_2\sin 2x + \sin x\)។
\(y(0) = C_1 = 0\)។
\(y'(x) = 2C_2\cos 2x + \cos x\)។
\(y'\left(\dfrac{\pi}{2}\right) = 2C_2\cos\pi + \cos\dfrac{\pi}{2} = -2C_2 = 1 \implies C_2 = -\dfrac{1}{2}\)។
ដូចនេះ ៖ \(\boxed{y = -\dfrac{1}{2}\sin 2x + \sin x}\)

វិញ្ញាសាត្រៀមទី៤

គេមានសមីការ \((E) \ : \ y' + y = \cos x - \sin x\) ៖

  1. បង្ហាញថា \(y_p = \cos x\) ជាចម្លើយពិសេសមួយនៃ \((E)\)

  2. រកចម្លើយទូទៅនៃសមីការ \((E)\)

  3. កំណត់ចម្លើយ \(f(x)\) នៃ \((E)\) ដែលផ្ទៀងផ្ទាត់ \(f(\pi) = -2\)

ដំណោះស្រាយ

ក បង្ហាញថា \(y_p = \cos x\) ជាចម្លើយពិសេស ៖
\(y_p' = -\sin x\)។ ជំនួសចូលអង្គខាងឆ្វេងនៃ \((E)\) ៖
\(y_p' + y_p = -\sin x + \cos x = \cos x - \sin x\)
ស្មើអង្គខាងស្តាំនៃ \((E)\) (ពិត)។
ដូចនេះ ៖ \(y_p = \cos x\) ជាចម្លើយពិសេស

ខ រកចម្លើយទូទៅនៃសមីការ \((E)\) ៖
សមីការអូម៉ូសែន ៖ \(y' + y = 0 \implies y_h = Ce^{-x}\)។
ដូចនេះ ៖ \(\boxed{y = Ce^{-x} + \cos x \quad{} (C \in \mathbb{R})}\)

គ កំណត់អនុគមន៍ \(f(x)\) ៖
តាម \(f(\pi) = -2\) ៖
\(Ce^{-\pi} + \cos\pi = -2 \iff Ce^{-\pi} - 1 = -2\)
\(Ce^{-\pi} = -1 \iff C = -e^{\pi}\)។
ជំនួស \(C\) ចូល ៖ \(f(x) = -e^{\pi}e^{-x} + \cos x\)។
ដូចនេះ ៖ \(\boxed{f(x) = -e^{\pi - x} + \cos x}\)

វិញ្ញាសាត្រៀមទី៥

គេឱ្យសមីការ \((E) \ : \ y'' + 2y' + 2y = 0\) ៖

  1. រកឫសនៃសមីការសម្គាល់ និងទាញរកចម្លើយទូទៅនៃ \((E)\)

  2. រកចម្លើយ \(f(x)\) ដែលក្រាបកាត់តាម \(A(0, 1)\) និងបន្ទាត់ប៉ះត្រង់ \(A\) ស្របនឹងបន្ទាត់ \(y = x\)

ដំណោះស្រាយ

ក សមីការសម្គាល់ និងចម្លើយទូទៅ ៖
\(r^2 + 2r + 2 = 0 \implies \Delta' = 1 - 2 = -1 = i^2\)
\(\implies r = -1 \pm i\) (\(\alpha = -1, \beta = 1\))។
ដូចនេះ ៖ \(\boxed{y = e^{-x}(C_1\cos x + C_2\sin x)}\)

ខ កំណត់អនុគមន៍ចម្លើយ \(f(x)\) ៖
កាត់តាម \(A(0, 1) \implies f(0) = C_1 = 1\)។
បន្ទាត់ប៉ះត្រង់ \(A\) ស្របនឹង \(y = x \implies f'(0) = 1\)។
\(f'(x) = e^{-x}[(-C_1 + C_2)\cos x - (C_1 + C_2)\sin x]\)។
\(f'(0) = -C_1 + C_2 = 1 \implies -1 + C_2 = 1 \implies C_2 = 2\)។
ដូចនេះ ៖ \(\boxed{f(x) = e^{-x}(\cos x + 2\sin x)}\)
