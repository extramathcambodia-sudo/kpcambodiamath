មេរៀនទាំងអស់

ប្រមូលផ្តុំវិញ្ញាសាប្រឡងសញ្ញាបត្រមធ្យមសិក្សាទុតិយភូមិ ពីឆ្នាំ២០១៤ ដល់ ២០២៦ និងវិញ្ញាសាត្រៀមជ្រើសរើសពិសេស អមដោយកន្លែងកត់ត្រាដំណោះស្រាយ ៖

ផ្នែកទី១ ៖ ប្រធានវិញ្ញាសាប្រឡងផ្លូវការ (២០១៤ - ២០២៦)

  1. (បាក់ឌុប ២០១៤)

    1. ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y' - 3y = 0\)។

    2. រកអនុគមន៍ចម្លើយ \(f(x)\) នៃសមីការ \((E)\) ដែលផ្ទៀងផ្ទាត់ \(f(0) = 2\)។

  2. (បាក់ឌុប ២០១៥)

    1. ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y'' - 4y' + 3y = 0\)។

    2. រកចម្លើយពិសេសមួយនៃ \((E)\) ដោយដឹងថា \(y(0) = 1\) និង \(y'(0) = 5\)។

  3. (បាក់ឌុប ២០១៦) គេមានសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y'' + 2y' + y = 0\)។

    1. រកចម្លើយទូទៅនៃសមីការ \((E)\)។

    2. រកចម្លើយពិសេស \(g(x)\) នៃ \((E)\) ដែលក្រាបរបស់វាកាត់តាមចំណុច \(A(0, 3)\) ហើយមានមេគុណប្រាប់ទិសនៃបន្ទាត់ប៉ះត្រង់ចំណុចនោះស្មើនឹង \(-1\)។

  4. (បាក់ឌុប ២០១៧) គេឱ្យសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y'' + 9y = 0\)។

    1. រកចម្លើយទូទៅនៃសមីការ \((E)\)។

    2. រកអនុគមន៍ចម្លើយ \(f(x)\) មួយនៃ \((E)\) ដែលផ្ទៀងផ្ទាត់ \(f\left(\dfrac{\pi}{6}\right) = 2\) និង \(f'\left(\dfrac{\pi}{6}\right) = 0\)។

  5. (បាក់ឌុប ២០១៨) គេមានសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y' + 2y = 4x\)។

    1. រកចំនួនពិត \(a\) និង \(b\) ដើម្បីឱ្យ \(y_p = ax + b\) ជាចម្លើយពិសេសនៃសមីការ \((E)\)។

    2. ដោះស្រាយសមីការអូម៉ូសែន \((E_0) \ : \ y' + 2y = 0\)។

    3. ទាញរកចម្លើយទូទៅនៃសមីការ \((E)\) រួចកំណត់ចម្លើយដែលផ្ទៀងផ្ទាត់ \(y(0) = 1\)។

  6. (បាក់ឌុប ២០១៩) គេមានសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y'' - 2y' + 5y = 0\)។

    1. សរសេរសមីការសម្គាល់នៃ \((E)\) រួចរកឫសរបស់វា។

    2. ទាញរកចម្លើយទូទៅនៃសមីការ \((E)\)។

    3. កំណត់ចម្លើយពិសេស \(f(x)\) ដែលផ្ទៀងផ្ទាត់ \(f(0) = 1\) និង \(f'(0) = 3\)។

  7. (បាក់ឌុប ២០២០) គេមានសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y'' - 5y' + 6y = 6x - 5\)។

    1. កំណត់ពហុធាដឺក្រេទី១ \(P(x) = ax + b\) ជាចម្លើយពិសេសនៃ \((E)\)។

    2. រកចម្លើយទូទៅនៃសមីការ \((E_0) \ : \ y'' - 5y' + 6y = 0\)។

    3. ទាញរកចម្លើយទូទៅនៃ \((E)\)។

  8. (បាក់ឌុប ២០២១)

    1. ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ 2y' + y = 0\)។

    2. កំណត់អនុគមន៍ \(f(x)\) ជាចម្លើយនៃ \((E)\) ដោយដឹងថាក្រាបរបស់វាប៉ះនឹងបន្ទាត់ \(y = -x + 2\) ត្រង់ចំណុចដែលមានអាប់ស៊ីស \(x = 0\)។

  9. (បាក់ឌុប ២០២២) គេឱ្យសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y'' + 4y' + 4y = 8e^{2x}\)។

    1. រកចម្លើយទូទៅនៃសមីការអូម៉ូសែន \((E_0) \ : \ y'' + 4y' + 4y = 0\)។

    2. កំណត់ចំនួនពិត \(A\) ដើម្បីឱ្យ \(y_p = A e^{2x}\) ជាចម្លើយពិសេសនៃសមីការ \((E)\)។

    3. ទាញរកចម្លើយទូទៅនៃសមីការ \((E)\) រួចកំណត់ចម្លើយដែល \(y(0) = 2\) និង \(y'(0) = 0\)។

  10. (បាក់ឌុប ២០២៣) គេឱ្យសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y' + 3y = e^{-3x}\)។

    1. ដោះស្រាយសមីការអូម៉ូសែន \(y' + 3y = 0\)។

    2. តាមវិធីបម្រែបម្រួលចំនួនថេរ ចូររកចម្លើយទូទៅនៃសមីការ \((E)\)។

    3. កំណត់ចម្លើយពិសេសនៃសមីការ \((E)\) ដែលផ្ទៀងផ្ទាត់ \(y(0) = 5\)។

  11. (បាក់ឌុប ២០២៤) គេមានសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y'' + 16y = 4\cos 2x\)។

    1. ដោះស្រាយសមីការអូម៉ូសែន \(y'' + 16y = 0\)។

    2. កំណត់ចំនួនពិត \(k\) ដើម្បីឱ្យ \(y_p = k\cos 2x\) ជាចម្លើយពិសេសនៃ \((E)\)។

    3. សរសេរចម្លើយទូទៅនៃ \((E)\) រួចកំណត់ចម្លើយដែល \(y(0) = 1\) និង \(y'\left(\dfrac{\pi}{4}\right) = 0\)។

  12. (បាក់ឌុប ២០២៥) (១០ពិន្ទុ)

    1. ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y'' = 3y - 2y'\)។

    2. រកចម្លើយពិសេសមួយនៃសមីការ \((E)\) ដែល \(y(0) = 1\) និង \(y'(1) = e\)  (\(e\) ជាចំនួនពិតដែល \(\ln\,e = 1\))។

  13. (បាក់ឌុប ២០២៦) (១៥ពិន្ទុ) គេមានសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ 2y' + y = 0\)។

    1. កំណត់ចម្លើយ \(f(x)\) នៃសមីការឌីផេរ៉ង់ស្យែល \((E)\) លើ \(\mathbb{R}\)។

    2. កំណត់ចម្លើយនៃ \((E)\) ដែលផ្ទៀងផ្ទាត់លក្ខខណ្ឌខាងក្រោមបើមាន ៖
      \(a.\; f(1) = 1\) ; \(b.\; f(2) = (f(1))^2\) ; \(c.\; \lim\limits_{x \to -\infty} f(x) = +\infty\)

ផ្នែកទី២ ៖ វិញ្ញាសាត្រៀមប្រឡងបាក់ឌុបជ្រើសរើសពិសេស

  1. (វិញ្ញាសាត្រៀមទី១) គេឱ្យសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y' - 2y = -4x + 6\)។

    1. កំណត់ចំនួនពិត \(m\) និង \(n\) ដើម្បីឱ្យពហុធា \(g(x) = mx + n\) ជាចម្លើយពិសេសនៃ \((E)\)។

    2. ដោះស្រាយសមីការ \(y' - 2y = 0\)។

    3. ទាញរកចម្លើយទូទៅនៃសមីការ \((E)\) រួចកំណត់ចម្លើយដែលក្រាបកាត់តាមគល់តម្រុយ \(O(0, 0)\)។

  2. (វិញ្ញាសាត្រៀមទី២) គេឱ្យសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y'' - 6y' + 9y = 0\)។

    1. សរសេរសមីការសម្គាល់ និងទាញរកចម្លើយទូទៅនៃ \((E)\)។

    2. កំណត់អនុគមន៍ចម្លើយ \(f(x)\) ដែលផ្ទៀងផ្ទាត់ \(f(0) = 2\) និង \(f'(0) = 7\)។

    3. សិក្សាអថេរភាព និងទិសដៅអថេរនៃអនុគមន៍ \(f(x)\) លើកម្រិត \(\mathbb{R}\)។

  3. (វិញ្ញាសាត្រៀមទី៣) គេឱ្យសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y'' + 4y = 3\sin x\)។

    1. រកចម្លើយទូទៅនៃសមីការអូម៉ូសែន \((E_0) \ : \ y'' + 4y = 0\)។

    2. រកចំនួនពិត \(A\) ដើម្បីឱ្យ \(y_p = A\sin x\) ជាចម្លើយពិសេសនៃ \((E)\)។

    3. ទាញរកចម្លើយទូទៅនៃ \((E)\) រួចកំណត់ចម្លើយដែល \(y(0) = 0\) និង \(y'\left(\dfrac{\pi}{2}\right) = 1\)។

  4. (វិញ្ញាសាត្រៀមទី៤) គេមានសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y' + y = \cos x - \sin x\)។

    1. បង្ហាញថាអនុគមន៍ \(y_p = \cos x\) ជាចម្លើយពិសេសមួយនៃ \((E)\)។

    2. រកចម្លើយទូទៅនៃសមីការ \((E)\)។

    3. កំណត់ចម្លើយ \(f(x)\) នៃ \((E)\) ដែលផ្ទៀងផ្ទាត់ \(f(\pi) = -2\)។

  5. (វិញ្ញាសាត្រៀមទី៥) គេឱ្យសមីការឌីផេរ៉ង់ស្យែល \((E) \ : \ y'' + 2y' + 2y = 0\)។

    1. រកឫសនៃសមីការសម្គាល់ និងទាញរកចម្លើយទូទៅនៃសមីការ \((E)\)។

    2. រកចម្លើយ \(f(x)\) នៃ \((E)\) ដែលក្រាបកាត់តាម \(A(0, 1)\) និងមានបន្ទាត់ប៉ះត្រង់ \(A\) ស្របនឹងបន្ទាត់ \(y = x\)។
