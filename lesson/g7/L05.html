ប្រវត្តិនៃចំនួនទសភាគ និងចំណុចទសភាគ

ប្រព័ន្ធចំនួនទសភាគមានដើមកំណើត និងការវិវត្តយ៉ាងយូរអង្វែងក្នុងប្រវត្តិសាស្ត្រគណិតវិទ្យាពិភពលោក។ នៅប្រទេសចិនបុរាណ ចាប់តាំងពីសតវត្សទី៤ មុន គ.ស. គណិតវិទូបានប្រើប្រាស់បន្ទះរាប់ទសភាគក្នុងការវាស់វែងប្រវែង ទម្ងន់ និងមាឌយ៉ាងសុក្រឹត។

នៅក្នុងពិភពឥស្លាម នាសតវត្សទី១០ គណិតវិទូស៊ីរី Abu’l-Hasan al-Uqlidisi បានសរសេរក្បួនគណនាប្រភាគទសភាគជាលើកដំបូងក្នុងសៀវភៅរបស់គាត់។ លុះដល់សតវត្សទី១៥ គណិតវិទូពែរ្សដ៏ល្បីល្បាញ Jamshid al-Kashi បានគណនាតម្លៃនៃចំនួន \(\pi\) ដោយប្រើប្រាស់ខ្ទង់ទសភាគរហូតដល់ ១៦ ខ្ទង់យ៉ាងត្រឹមត្រូវអស្ចារ្យ។

នៅទ្វីបអឺរ៉ុប គណិតវិទូ និងវិស្វករជនជាតិហូឡង់ Simon Stevin (១៥៤៨–១៦២០) បានបោះពុម្ពផ្សាយសៀវភៅដ៏មានឥទ្ធិពលឈ្មោះថា De Thiende (ភាគដប់) ក្នុងឆ្នាំ ១៥៨៥ ដោយបានពន្យល់ពីសារសំខាន់នៃប្រព័ន្ធទសភាគក្នុងការសម្រួលដល់ការគណនាពាណិជ្ជកម្ម និងវិស្វកម្ម។

រហូតមកដល់ឆ្នាំ ១៦១៧ គណិតវិទូស្កុតឡែនដ៏ឆ្នើម John Napier (អ្នករកឃើញអនុគមន៍លោការីត) បានបង្កើតការប្រើប្រាស់សញ្ញាចុចទសភាគ (Decimal Point) ឬក្បៀស ដើម្បីខណ្ឌចែករវាងផ្នែកគត់ និងផ្នែកទសភាគ ដែលធ្វើឱ្យការកត់ត្រាមានភាពសាមញ្ញ ងាយស្រួលយល់ និងត្រូវបានប្រើប្រាស់ជាសកលរហូតមកដល់បច្ចុប្បន្ន។

  • ឬគុណពង្រីកប្រភាគឱ្យមានភាគបែងជា \(10, 100, 1000, \dots\)។

ចំនួនទសភាគខួប (Periodic/Repeating Decimals)

ចំនួនទសភាគខួប គឺជាចំនួនទសភាគដែលមានលេខ ឬក្រុមលេខនៅផ្នែកទសភាគកើតឡើងដដែលៗមិនចេះចប់។ គេប្រើរបារបន្ទាត់ផ្ដេកពីលើលេខដើម្បីតាងខួប ៖

\[0.333\dots = 0.\overline{3}, \qquad{} 0.2727\dots = 0.\overline{27}, \qquad{} 1.41666\dots = 1.41\overline{6}\]
ក្បួនបំប្លែងទសភាគខួបជាប្រភាគ ៖

  • ខួប ១ ខ្ទង់ ៖ \(0.\overline{a} = \dfrac{a}{9}\) (ឧ. \(0.\overline{7} = \dfrac{7}{9}\))

  • ខួប ២ ខ្ទង់ ៖ \(0.\overline{ab} = \dfrac{ab}{99}\) (ឧ. \(0.\overline{45} = \dfrac{45}{99} = \dfrac{5}{11}\))

ឧទាហរណ៍

ក. បំប្លែងប្រភាគ \(\frac{3}{8}\) និង \(\frac{7}{20}\) ជាចំនួនទសភាគ។
ខ. បំប្លែងចំនួនទសភាគកំណត់ \(0.35\) និងទសភាគខួប \(0.\overline{6}\) ជាប្រភាគបង្រួមមិនបាន។

ដំណោះស្រាយ

ដំណោះស្រាយលម្អិត៖

  1. បំប្លែងជាចំនួនទសភាគ ៖

    • \(\dfrac{3}{8} = \dfrac{3 \times 125}{8 \times 125} = \dfrac{375}{1000} = 0.375\)

    • \(\dfrac{7}{20} = \dfrac{7 \times 5}{20 \times 5} = \dfrac{35}{100} = 0.35\)

  2. បំប្លែងជាប្រភាគ ៖

    • \(0.35 = \dfrac{35}{100} = \dfrac{35 \div 5}{100 \div 5} = \dfrac{7}{20}\)

    • តាង \(x = 0.\overline{6} = 0.666\dots \implies 10x = 6.666\dots\)
      យក \(10x - x = 6 \implies 9x = 6 \implies x = \dfrac{6}{9} = \dfrac{2}{3}\)។

បំប្លែងប្រភាគ និងទសភាគ

១. បំប្លែងប្រភាគខាងក្រោមជាចំនួនទសភាគ ៖ \(\dfrac{4}{5}, \quad{} \dfrac{9}{25}, \quad{} \dfrac{5}{8}, \quad{} \dfrac{11}{40}\)។
២. បំប្លែងចំនួនទសភាគខាងក្រោមជាប្រភាគបង្រួមមិនបាន ៖ \(0.64, \quad{} 1.75, \quad{} 0.\overline{5}, \quad{} 0.\overline{18}\)។

វិធីបូក និងវិធីដកចំនួនទសភាគ

វិធាននៃវិធីបូក និងវិធីដកចំនួនទសភាគ

  2. បន្ថែមលេខសូន្យនៅខាងចុងផ្នែកទសភាគដើម្បីឱ្យមានចំនួនខ្ទង់ស្មើគ្នា (បើចាំបាច់)។

  3. អនុវត្តវិធីបូក ឬដកដូចចំនួនគត់ រួចដាក់ចំណុចទសភាគក្នុងផលបូក/ផលដកឱ្យត្រង់នឹងចំណុចទសភាគនៃតួខាងលើ។

  4. ចំពោះចំនួនទសភាគមានសញ្ញា (\(+\) និង \(-\)) អនុវត្តតាមក្បួនសញ្ញានៃចំនួនគត់រ៉ឺឡាទីប។

៤០លំហាត់ទី ៤០

ដោះស្រាយសមីការលើសំណុំចំនួនទសភាគ ៖

៤១លំហាត់ទី ៤១

ដោះស្រាយសមីការ ៖

  • \(\dfrac{x}{1.5} = 4.2 \Rightarrow x = 4.2 \times 1.5 = 6.3\)

  • \(3.2x - 1.4 = 1.8x + 4.2 \Rightarrow 1.4x = 5.6 \Rightarrow x = 4\)

៤២លំហាត់ទី ៤២

បើ \(a = 3.5\) និង \(b = 1.2\) ចូរគណនាតម្លៃនៃ ៖

  1. \(2a - 3b\)

  2. \(a^2 - b^2\)

  3. \((a + b)(a - b)\)

មើលដំណោះស្រាយ

គណនាតម្លៃ (\(a = 3.5, b = 1.2\)) ៖

  • \(2a - 3b = 2(3.5) - 3(1.2) = 7 - 3.6 = 3.4\)

  • \(a^2 - b^2 = 3.5^2 - 1.2^2 = 12.25 - 1.44 = 10.81\)

  • \((a + b)(a - b) = (4.7)(2.3) = 10.81\)

៤៣លំហាត់ទី ៤៣

បំពេញចំនួនក្នុងប្រអប់ \(\Box\) ៖

  2. \(\Box - 3.85 = 7.15\)

  3. \(2.5 \times \Box = 20\)

  • \(4.25 + \mathbf{5.75} = 10\)

  • \(\mathbf{11} - 3.85 = 7.15\)

  • \(2.5 \times \mathbf{8} = 20\)

៤៤លំហាត់ទី ៤៤

គណនាផលបូកដោយប្រើលក្ខណៈងាយស្រួល ៖

\[\begin{aligned} S &= (1.25 + 3.75) + (4.8 + 5.2) + (8.45 + 1.55) \\ &= 5 + 10 + 10 = 25 \end{aligned}\]

៤៥លំហាត់ទី ៤៥

សិស្សម្នាក់ទិញសៀវភៅ ៤ ក្បាល តម្លៃ \(2.75\$\) ក្នុងមួយក្បាល និងប៊ិច ៦ ដើម តម្លៃ \(0.65\$\) ក្នុងមួយដើម។ គាត់ឱ្យក្រដាសប្រាក់ \(20\$\) ទៅអ្នកលក់។ គណនាប្រាក់អាប់ដែលគាត់ត្រូវទទួលបាន។

មើលដំណោះស្រាយ

គណនាប្រាក់អាប់ ៖

  • តម្លៃសៀវភៅ ៤ ក្បាល ៖ \(4 \times 2.75 = 11\$\)

  • តម្លៃប៊ិច ៦ ដើម ៖ \(6 \times 0.65 = 3.90\$\)

  • ចំណាយសរុប ៖ \(11 + 3.90 = 14.90\$\)

  • ប្រាក់អាប់ត្រូវទទួលបាន ៖
    \(20 - 14.90 = 5.10\$\)

៤៦លំហាត់ទី ៤៦

រថយន្តមួយធ្វើដំណើរដោយល្បឿនមធ្យម \(65.5\text{ km/h}\)។

  1. គណនាចម្ងាយផ្លូវដែលរថយន្តធ្វើបានក្នុងរយៈពេល \(3.5\) ម៉ោង ។

  2. តើរថយន្តត្រូវចំណាយពេលប៉ុន្មានម៉ោងដើម្បីធ្វើដំណើរបានចម្ងាយ \(262\text{ km}\)?

មើលដំណោះស្រាយ

គណនាចម្ងាយ និងរយៈពេល ៖

  • ចម្ងាយក្នុងរយៈពេល \(3.5\text{ h}\) ៖
    \(d = 65.5 \times 3.5 = 229.25\text{ km}\)

  • រយៈពេលសម្រាប់ចម្ងាយ \(262\text{ km}\) ៖
    \(t = 262 \div 65.5 = 4\) ម៉ោង

៤៧លំហាត់ទី ៤៧

ធុងប្រេងមួយមានប្រេង \(45.6\) លីត្រ ។ គេរំលែកប្រេងនោះដាក់ដបតូចៗដែលមួយដបផ្ទុកបាន \(0.75\) លីត្រ ។

  1. តើគេអាចច្រកបានដបពេញចំនួនប៉ុន្មានដប?

  2. តើនៅសល់ប្រេងប៉ុន្មានលីត្រទៀត?

មើលដំណោះស្រាយ

គណនាចំនួនដប និងប្រេងនៅសល់ ៖

  • ព្រោះ \(45.6 \div 0.75 = 60.8\)
    \(\Rightarrow\) គេច្រកបានដបពេញចំនួន \(60\) ដប

  • ចំណុះក្នុង \(60\) ដបគឺ \(60 \times 0.75 = 45\text{ L}\)

  • ប្រេងនៅសល់ ៖ \(45.6 - 45 = 0.6\) លីត្រ

៤៨លំហាត់ទី ៤៨

បន្ទប់រាងចតុកោណកែងមួយមានបណ្ដោយ \(6.4\text{ m}\) និងទទឹង \(4.5\text{ m}\)។ គេចង់ក្រាលការ៉ូបន្ទប់នោះដោយការ៉ូការ៉េមានជ្រុងប្រវែង \(0.4\text{ m}\)។ គណនាចំនួនការ៉ូដែលត្រូវប្រើប្រាស់។

មើលដំណោះស្រាយ

គណនាចំនួនការ៉ូត្រូវប្រើ ៖

  • ក្រឡាផ្ទៃបន្ទប់ ៖ \(S_1 = 6.4 \times 4.5 = 28.8\text{ m}^2\)

  • ក្រឡាផ្ទៃការ៉ូ ១ ផ្ទាំង ៖ \(S_2 = 0.4 \times 0.4 = 0.16\text{ m}^2\)

  • ចំនួនការ៉ូ ៖ \(28.8 \div 0.16 = 180\) សន្លឹក

៤៩លំហាត់ទី ៤៩

កម្ដៅនៅក្នុងទូទឹកកកមួយពេលដំបូងគឺ \(-4.5^\circ\text{C}\)។ នៅពេលដាច់ចរន្តអគ្គិសនី សីតុណ្ហភាពបានកើនឡើង \(8.8^\circ\text{C}\)។ ពេលចរន្តអគ្គិសនីមកវិញ សីតុណ្ហភាពបានធ្លាក់ចុះទៅវិញ \(10.2^\circ\text{C}\)។ គណនាសីតុណ្ហភាពចុងក្រោយក្នុងទូទឹកកក។

\[\begin{aligned} T &= -4.5 + 8.8 - 10.2 \\ &= 4.3 - 10.2 = -5.9^\circ\text{C} \end{aligned}\]
