មេរៀនទាំងអស់
ប្រវត្តិ និងការកកើតនៃសញ្ញាណរង្វាស់មុំ

សញ្ញាណនៃ «មុំ» និងការវាស់មុំ មានប្រវត្តិសាស្ត្រយ៉ាងយូរលង់តាំងពីរាប់ពាន់ឆ្នាំមុនគ្រិស្តសករាជ។ ជនជាតិបាប៊ីឡូនបុរាណ (Babylonians) គឺជាមនុស្សដំបូងគេដែលបានបែងចែករង្វង់មូលពេញលេញមួយជា \(360\) ចំណែកស្មើគ្នា ដែលក្រោយមកត្រូវបានហៅថា «ដឺក្រេ» (\(^\circ\))។ ការជ្រើសរើសយកលេខ \(360\) នេះ គឺដោយសារពួកគេប្រើប្រព័ន្ធរាប់គោល ៦០ (Sexagesimal system) ហើយមួយឆ្នាំតាមប្រតិទិនបុរាណមានប្រហែល ៣៦០ ថ្ងៃ។

លុះមកដល់សតវត្សទី ២ មុនគ្រិស្តសករាជ តារាវិទូ និងគណិតវិទូក្រិកលោក Hipparchus of Nicaea (ប្រហែល ១៩០–១២០ មុន គ.ស.) ដែលត្រូវបានគេប្រសិទ្ធនាមថា «បិតានៃត្រីកោណមាត្រ» បានបង្កើតតារាងខ្សែធ្នូដំបូងគេដើម្បីគណនាមុំ និងចម្ងាយនៃផ្កាយលើមេឃ។ នាពេលបច្ចុប្បន្ន រង្វាស់មុំបានដើរតួនាទីយ៉ាងសំខាន់មិនអាចខ្វះបានក្នុងវិស័យនាវាចរណ៍ ប្រព័ន្ធរុករកផ្កាយរណប (GPS) វិស្វកម្មសំណង់ និងស្ថាបត្យកម្មទំនើប។

សញ្ញាណទូទៅនៃមុំ

នៅក្នុងធរណីមាត្រ មុំ គឺជាភាវៈធរណីមាត្រគ្រឹះមួយដែលមានលក្ខណៈសម្គាល់ ៖

  • និយមន័យ ៖ មុំ កើតឡើងពីកន្លះបន្ទាត់ពីរដែលមានគល់រួមគ្នា។

  • ធាតុនៃមុំ ៖ គល់រួមហៅថា កំពូល (Vertex) ហើយកន្លះបន្ទាត់ទាំងពីរហៅថា ជ្រុង (Sides) នៃមុំ។

  • និមិត្តសញ្ញា ៖ មុំកំណត់សរសេរដោយ \(\angle AOB\) ឬ \(\widehat{AOB}\) (អក្សរកំពូលនៅកណ្ដាលជានិច្ច)។

  • ឯកតារង្វាស់ ៖ ដឺក្រេ (\(^\circ\)), មីនុត (\('\)), សឺកុង (\(''\)) ដោយ \(1^\circ = 60'\) និង \(1' = 60''\)។

សញ្ញាណមុំ និងធាតុនៃមុំ

សញ្ញាណមុំ និងការវាស់មុំ

  • មុំ (Angle) ៖ ជាផ្នែកមួយនៃប្លង់កំណត់ដោយកន្លះបន្ទាត់ពីរដែលមានគល់រួម។

  • ចំណុច \(O\) ហៅថា កំពូល។ កន្លះបន្ទាត់ \([Ox)\) និង \([Oy)\) ហៅថា ជ្រុង នៃមុំ។

  • តាងដោយ ៖ \(\angle xOy\) ឬ \(\angle yOx\) ឬ \(\angle O\)។

  • ឧបករណ៍វាស់មុំ ៖ រ៉ាប៉ទ័រ (Protractor) ប្រើសម្រាប់វាស់ និងសង់មុំពី \(0^\circ\) ដល់ \(180^\circ\)។

ប្រភេទនៃមុំ និងឯកតាមុំ

ចំណាត់ថ្នាក់ប្រភេទមុំ និងឯកតា

  • មុំស្រួច (Acute) ៖ មុំដែលមានរង្វាស់តូចជាង \(90^\circ\) (\(0^\circ < \alpha < 90^\circ\))។

  • មុំកែង (Right) ៖ មុំដែលមានរង្វាស់ស្មើនឹង \(90^\circ\) (\(\alpha = 90^\circ\))។

  • មុំទាល (Obtuse) ៖ មុំដែលមានរង្វាស់ធំជាង \(90^\circ\) និងតូចជាង \(180^\circ\) (\(90^\circ < \alpha < 180^\circ\))។

  • មុំរាប (Straight) ៖ មុំដែលមានរង្វាស់ស្មើនឹង \(180^\circ\) (\(\alpha = 180^\circ\)) (ជ្រុងទាំងពីរជាកន្លះបន្ទាត់ឈម)។

  • ទំនាក់ទំនងឯកតា ៖ \(1^\circ = 60'\) (មីនុត), \(1' = 60''\) (សឺកុង) \(\implies 1^\circ = 3600''\)។

  • មុំជាប់គ្នា (Adjacent Angles) ៖ មុំពីរដែលមានកំពូលរួម មានជ្រុងមួយរួម ហើយជ្រុងពីរទៀតនៅសងខាងជ្រុងរួមនោះ។

  • មុំបំពេញ (Complementary Angles) ៖ មុំពីរដែលមានផលបូករង្វាស់ស្មើនឹង \(90^\circ\) (\(\alpha + \beta = 90^\circ\))។

  • មុំបន្ថែម (Supplementary Angles) ៖ មុំពីរដែលមានផលបូករង្វាស់ស្មើនឹង \(180^\circ\) (\(\alpha + \beta = 180^\circ\))។

មុំទល់កំពូល

មុំទល់កំពូល និងទ្រឹស្ដីបទ

  • មុំទល់កំពូល (Vertically Opposite Angles) ៖ មុំពីរហៅថាមុំទល់កំពូល កាលណាជ្រុងនៃមុំមួយជាកន្លះបន្ទាត់ឈមនឹងជ្រុងនៃមុំមួយទៀត។

  • ទ្រឹស្ដីបទគ្រឹះ ៖ មុំទល់កំពូលពីរ តែងតែមានរង្វាស់ស្មើគ្នាជានិច្ច។

  • បន្ទាត់ពីរ \(xx'\) និង \(yy'\) កាត់គ្នាត្រង់ \(O\) បង្កើតបានគូមុំទល់កំពូលពីរគូ ៖

    \[\widehat{xOy} = \widehat{x'Oy'} \qquad{} \text{និង} \qquad{} \widehat{xOy'} = \widehat{x'Oy}\]

រូបភាពនេះកំពុងរៀបចំ

ឧទាហរណ៍

បន្ទាត់ពីរ \(AB\) និង \(CD\) ប្រសព្វគ្នាត្រង់ \(O\) ដោយដឹងថា \(\widehat{AOC} = 65^\circ\)។
គណនារង្វាស់មុំ ៖ \(\widehat{BOD}, \quad{} \widehat{AOD}, \quad{} \) និង \( \quad{} \widehat{BOC}\)។

ដំណោះស្រាយ

ដំណោះស្រាយលម្អិត៖
 ដោយ \(\widehat{BOD}\) និង \(\widehat{AOC}\) ជាមុំទល់កំពូល នាំឱ្យ ៖ \(\widehat{BOD} = \widehat{AOC} = 65^\circ\)។
 ដោយ \(\widehat{AOD}\) និង \(\widehat{AOC}\) ជាមុំជាប់បន្ថែម នាំឱ្យ ៖ \(\widehat{AOD} = 180^\circ - 65^\circ = 115^\circ\)។
 ដោយ \(\widehat{BOC}\) និង \(\widehat{AOD}\) ជាមុំទល់កំពូល នាំឱ្យ ៖ \(\widehat{BOC} = \widehat{AOD} = 115^\circ\)។
ដូចនេះ \(\boxed{\widehat{BOD} = 65^\circ, \quad{} \widehat{AOD} = 115^\circ, \quad{} \widehat{BOC} = 115^\circ}\)

មុំទល់កំពូល

១. បន្ទាត់ពីរប្រសព្វគ្នាកំណត់បានមុំមួយមានរង្វាស់ \(48^\circ\)។ គណនារង្វាស់មុំ ៣ ផ្សេងទៀត។

កន្លះបន្ទាត់ពុះមុំ និងការសង់មុំ

កន្លះបន្ទាត់ពុះមុំ និងលក្ខណៈ

  • កន្លះបន្ទាត់ពុះមុំ (Angle Bisector) ៖ ជាកន្លះបន្ទាត់ដែលមានគល់ជាកំពូលនៃមុំ ស្ថិតនៅចន្លោះជ្រុងទាំងពីរ ហើយចែកមុំនោះជាពីរមុំប៉ុនគ្នា ៖

    \[[Ot) \text{ ជាកន្លះបន្ទាត់ពុះនៃ } \angle xOy \iff \widehat{xOt} = \widehat{tOy} = \frac{\widehat{xOy}}{2}\]

  • លក្ខណៈសំខាន់ ៖ កន្លះបន្ទាត់ពុះនៃមុំពីរជាប់គ្នាបន្ថែមគ្នា កែងគ្នាជានិច្ច (បង្កើតបានមុំកែង \(90^\circ\))។

រូបភាពនេះកំពុងរៀបចំ

ឧទាហរណ៍

  1. គេឱ្យ \(\angle AOB = 84^\circ\) និង \([OC)\) ជាកន្លះបន្ទាត់ពុះនៃ \(\angle AOB\)។ គណនារង្វាស់មុំ \(\angle AOC\)។

  2. បង្ហាញថាកន្លះបន្ទាត់ពុះនៃមុំពីរជាប់គ្នាបន្ថែមគ្នា កែងគ្នា។

ដំណោះស្រាយ

ដំណោះស្រាយលម្អិត៖
 ដោយ \([OC)\) ជាកន្លះបន្ទាត់ពុះនៃ \(\angle AOB\) នាំឱ្យ ៖ \(\angle AOC = \frac{\angle AOB}{2} = \frac{84^\circ}{2} = 42^\circ\)។ ដូចនេះ \(\boxed{\angle AOC = 42^\circ}\)
 តាង \(\angle xOy\) និង \(\angle yOz\) ជាមុំពីរជាប់គ្នាបន្ថែមគ្នា (\(\angle xOy + \angle yOz = 180^\circ\))។
តាង \(Om, On\) ជាកន្លះបន្ទាត់ពុះរៀងគ្នា នាំឱ្យ ៖ \(\angle mOn = \frac{\angle xOy}{2} + \frac{\angle yOz}{2} = \frac{\angle xOy + \angle yOz}{2} = \frac{180^\circ}{2} = 90^\circ\)។
ដូចនេះ កន្លះបន្ទាត់ពុះទាំងពីរ កែងគ្នាជានិច្ច (\(Om \perp On\))

កន្លះបន្ទាត់ពុះមុំ

១. គេឱ្យ \(\angle MNP = 130^\circ\) និង \([NQ)\) ជាកន្លះបន្ទាត់ពុះ។ គណនា \(\angle MNQ\)។

យើងមាន \(\begin{cases} x + y = 180^\circ \\ x - y = 50^\circ \end{cases}\)
បូកអង្គនិងអង្គ ៖ \(2x = 230^\circ \Rightarrow x = 115^\circ\)
នាំឱ្យ \(y = 180^\circ - 115^\circ = 65^\circ\)
ដូចនេះ មុំទាំងពីរគឺ \(115^\circ\) និង \(65^\circ\)។

មើលដំណោះស្រាយ

តាងមុំទាំងពីរដោយ \(x\) និង \(y\) ៖
\(\frac{x}{2} = \frac{y}{3} = \frac{x+y}{2+3} = \frac{90^\circ}{5} = 18^\circ\)

  • \(x = 2 \times 18^\circ = 36^\circ\)

  • \(y = 3 \times 18^\circ = 54^\circ\)

ដូចនេះ មុំទាំងពីរមានរង្វាស់ \(36^\circ\) និង \(54^\circ\)។

មុំពីរជាមុំបន្ថែមគ្នា ហើយផលធៀបនៃរង្វាស់មុំទាំងពីរគឺ \(4 : 5\)។ គណនារង្វាស់មុំនីមួយៗ។

មើលដំណោះស្រាយ

តាងមុំទាំងពីរដោយ \(x\) និង \(y\) ៖
\(\frac{x}{4} = \frac{y}{5} = \frac{x+y}{4+5} = \frac{180^\circ}{9} = 20^\circ\)

  • \(x = 4 \times 20^\circ = 80^\circ\)

  • \(y = 5 \times 20^\circ = 100^\circ\)

ដូចនេះ មុំទាំងពីរគឺ \(80^\circ\) និង \(100^\circ\)។

១៧លំហាត់ទី ១៧

  1. គណនាតម្លៃនៃ \(x\)

  2. រកមុំ \(\angle AOB\) និង \(\angle BOC\)

មើលដំណោះស្រាយ

  • ក. មុំជាប់បន្ថែមមានផលបូក \(180^\circ\) ៖
    \(3x + 2x = 180^\circ \Rightarrow 5x = 180^\circ \Rightarrow x = 36^\circ\)

  • ខ. រង្វាស់មុំ ៖
    \(\angle AOB = 3 \times 36^\circ = 108^\circ\)
    \(\angle BOC = 2 \times 36^\circ = 72^\circ\)

    \((x + 15^\circ) + 2x = 90^\circ \Rightarrow 3x = 75^\circ \Rightarrow x = 25^\circ\)

  • ខ. រង្វាស់មុំ ៖
    \(\angle MON = 25^\circ + 15^\circ = 40^\circ\)

២១លំហាត់ទី ២១

  1. គណនាតម្លៃនៃ \(x\)

  2. គណនារង្វាស់មុំទាំងពីរនោះ

មើលដំណោះស្រាយ

  • ក. មុំទល់កំពូលមានរង្វាស់ស្មើគ្នា ៖
    \(4x - 20^\circ = 2x + 30^\circ \Rightarrow 2x = 50^\circ \Rightarrow x = 25^\circ\)

  • ខ. រង្វាស់មុំនីមួយៗ ៖
    \(4(25^\circ) - 20^\circ = 100^\circ - 20^\circ = 80^\circ\)

២២លំហាត់ទី ២២

បន្ទាត់ពីរប្រសព្វគ្នាកំណត់បានមុំជាប់បន្ថែមពីរមានរង្វាស់ \((5x - 10^\circ)\) និង \((3x + 30^\circ)\)។
គណនាតម្លៃនៃ \(x\) និងរង្វាស់មុំទាំងពីរនោះ។

មើលដំណោះស្រាយ

ផលបូកមុំជាប់បន្ថែមស្មើ \(180^\circ\) ៖
\((5x - 10^\circ) + (3x + 30^\circ) = 180^\circ\)
\(8x + 20^\circ = 180^\circ \Rightarrow 8x = 160^\circ \Rightarrow x = 20^\circ\)
រង្វាស់មុំទាំងពីរ ៖

  • \(5(20^\circ) - 10^\circ = 90^\circ\)

  • \(3(20^\circ) + 30^\circ = 90^\circ\)

២៥លំហាត់ទី ២៥

បង្ហាញថាមុំ \(\angle mOn = 90^\circ\) (កន្លះបន្ទាត់ពុះទាំងពីរកែងគ្នា)។

មើលដំណោះស្រាយ

យើងមាន \(\angle xOz + \angle zOy = 180^\circ\) (មុំជាប់បន្ថែម)។
ដោយ \([Om)\) និង \([On)\) ជាកន្លះបន្ទាត់ពុះ ៖
\(\angle mOz = \frac{\angle xOz}{2}\) និង \(\angle zOn = \frac{\angle zOy}{2}\)
នាំឱ្យ \(\angle mOn = \angle mOz + \angle zOn = \frac{\angle xOz + \angle zOy}{2} = \frac{180^\circ}{2} = 90^\circ\)
ដូចនេះ កន្លះបន្ទាត់ពុះទាំងពីរកែងគ្នា (\(Om \perp On\))។

  1. គណនារង្វាស់មុំ \(\angle AOB\)

  2. តើ \(OA\) និង \(OB\) កែងគ្នាដែរឬទេ?

មើលដំណោះស្រាយ

  • ក. រង្វាស់មុំ \(\angle AOB\) ៖
    \(\angle AOB = 180^\circ - (\angle xOA + \angle yOB) = 180^\circ - (40^\circ + 50^\circ) = 90^\circ\)

  • ខ. ដោយ \(\angle AOB = 90^\circ\) នោះកន្លះបន្ទាត់ \(OA\) និង \(OB\) កែងគ្នា (\(OA \perp OB\))។

២៨លំហាត់ទី ២៨

រកមុំមួយដែលស្មើនឹង ៤ ដងនៃមុំបំពេញរបស់វា។

មើលដំណោះស្រាយ

តាមបម្រាប់ ៖ \(x = 4(90^\circ - x) \Rightarrow x = 360^\circ - 4x\)
\(5x = 360^\circ \Rightarrow x = 72^\circ\)

មើលដំណោះស្រាយ

មើលដំណោះស្រាយ

តាមបម្រាប់ ៖
\((180^\circ - \alpha) - 3(90^\circ - \alpha) = 10^\circ\)
\(180^\circ - \alpha - 270^\circ + 3\alpha = 10^\circ\)
\(2\alpha - 90^\circ = 10^\circ \Rightarrow 2\alpha = 100^\circ \Rightarrow \alpha = 50^\circ\)។

៣៣លំហាត់ទី ៣៣

គេឱ្យបន្ទាត់បី \(AB, CD, EF\) ប្រសព្វគ្នាត្រង់ចំណុច \(O\) តែមួយ។

  1. តើមានគូមុំទល់កំពូលចំនួនប៉ុន្មានគូ?

  2. បើដឹងថា \(\angle AOC = 40^\circ\) និង \(\angle COE = 75^\circ\) គណនា \(\angle EOB\) និង \(\angle BOD\)។

មើលដំណោះស្រាយ

  • ក. ចំនួនគូមុំទល់កំពូល ៖ \(3 \times 2 = 6\) គូ។

  • ខ. ដោយ \(A, O, B\) រត់ត្រង់ជួរគ្នា ៖
    \(\angle EOB = 180^\circ - (\angle AOC + \angle COE) = 180^\circ - (40^\circ + 75^\circ) = 65^\circ\)
    \(\angle BOD = \angle AOC = 40^\circ\) (មុំទល់កំពូល)។

៣៤លំហាត់ទី ៣៤

បន្ទាត់ពីរ \(d_1\) និង \(d_2\) កាត់គ្នាត្រង់ \(O\)។ ផលបូករង្វាស់មុំពីរក្នុងចំណោមមុំទាំងបួនស្មើ \(100^\circ\)។
គណនារង្វាស់មុំទាំងបួនដែលមានកំពូល \(O\)។

មើលដំណោះស្រាយ

ផលបូកមុំពីរស្មើ \(100^\circ\) គឺជាមុំទល់កំពូល ៖
\(\angle 1 = \angle 2 = \frac{100^\circ}{2} = 50^\circ\)
មុំពីរទៀតជាមុំជាប់បន្ថែម ៖
\(\angle 3 = \angle 4 = 180^\circ - 50^\circ = 130^\circ\)
ដូចនេះ មុំទាំងបួនគឺ \(50^\circ, 130^\circ, 50^\circ, 130^\circ\)។

៣៥លំហាត់ទី ៣៥

បន្ទាត់ពីរ \(d_1\) និង \(d_2\) កាត់គ្នាត្រង់ \(O\)។ ផលបូករង្វាស់មុំបីក្នុងចំណោមមុំទាំងបួនស្មើ \(250^\circ\)។
គណនារង្វាស់មុំនីមួយៗ។

មើលដំណោះស្រាយ

ផលបូកមុំទាំងបួនជុំវិញចំណុចមួយស្មើ \(360^\circ\) ៖
មុំទីបួន ៖ \(360^\circ - 250^\circ = 110^\circ\)
មុំទល់កំពូលរបស់វា ៖ \(110^\circ\)
មុំពីរទៀតស្មើគ្នា ៖ \(\frac{360^\circ - 2(110^\circ)}{2} = \frac{140^\circ}{2} = 70^\circ\)
ដូចនេះ មុំទាំងបួនគឺ \(110^\circ, 70^\circ, 110^\circ, 70^\circ\)។

៣៦លំហាត់ទី ៣៦

គេឱ្យមុំកែង \(\angle xOy = 90^\circ\)។ ក្នុងមុំនេះគេគូសកន្លះបន្ទាត់ \(OA\) និង \(OB\) ដោយ \(\angle xOA = 30^\circ\) និង \(\angle yOB = 30^\circ\)។

  1. គណនារង្វាស់មុំ \(\angle AOB\)

  2. បង្ហាញថាកន្លះបន្ទាត់ពុះនៃ \(\angle xOy\) ក៏ជាកន្លះបន្ទាត់ពុះនៃ \(\angle AOB\) ដែរ។

មើលដំណោះស្រាយ

  • ក. \(\angle AOB = 90^\circ - (\angle xOA + \angle yOB) = 90^\circ - (30^\circ + 30^\circ) = 30^\circ\)

  • ខ. តាង \(Ot\) ជាកន្លះបន្ទាត់ពុះនៃ \(\angle xOy \Rightarrow \angle xOt = 45^\circ\)។
    \(\angle AOt = 45^\circ - 30^\circ = 15^\circ\)
    \(\angle tOB = 45^\circ - 30^\circ = 15^\circ\)
    ដោយ \(\angle AOt = \angle tOB = 15^\circ\) នោះ \(Ot\) ក៏ជាកន្លះបន្ទាត់ពុះនៃ \(\angle AOB\) ដែរ។

៣៧លំហាត់ទី ៣៧

គេឱ្យមុំ \(\angle xOy = 110^\circ\)។ គូសកន្លះបន្ទាត់ពុះ \([Ot)\) នៃ \(\angle xOy\)។ គូសកន្លះបន្ទាត់ \(Ot'\) ជាកន្លះបន្ទាត់ឈមនឹង \(Ot\)។
គណនារង្វាស់មុំ \(\angle xOt'\) និង \(\angle yOt'\)។

មើលដំណោះស្រាយ

\([Ot)\) ជាពុះមុំ \(\angle xOy \Rightarrow \angle xOt = \angle tOy = \frac{110^\circ}{2} = 55^\circ\)។
ដោយ \(Ot'\) ឈមនឹង \(Ot\) នាំឱ្យ ៖

  • \(\angle xOt' = 180^\circ - 55^\circ = 125^\circ\)

  • \(\angle yOt' = 180^\circ - 55^\circ = 125^\circ\)

៣៨លំហាត់ទី ៣៨

គេឱ្យ \(\angle AOB = 60^\circ\)។ គូសកន្លះបន្ទាត់ \(OC\) ជាកន្លះបន្ទាត់ឈមនឹង \(OA\)។

  1. គណនា \(\angle BOC\)

  2. គូសកន្លះបន្ទាត់ពុះ \(OD\) នៃ \(\angle BOC\)។ គណនា \(\angle AOD\)។

មើលដំណោះស្រាយ

  • ក. \(\angle BOC = 180^\circ - \angle AOB = 180^\circ - 60^\circ = 120^\circ\)

  • ខ. \(OD\) ជាពុះមុំនៃ \(\angle BOC \Rightarrow \angle BOD = \frac{120^\circ}{2} = 60^\circ\)
    \(\angle AOD = \angle AOB + \angle BOD = 60^\circ + 60^\circ = 120^\circ\)

៣៩លំហាត់ទី ៣៩

ត្រីកោណ \(ABC\) មួយមាន \(\angle A = 50^\circ\) និង \(\angle B = 70^\circ\)។
ដឹងថាផលបូកមុំក្នុងត្រីកោណស្មើ \(180^\circ\)។ គណនា \(\angle C\) និងមុំក្រៅត្រង់កំពូល \(C\)។

មើលដំណោះស្រាយ

ផលបូកមុំក្នុងត្រីកោណស្មើ \(180^\circ\) ៖
\(\angle C = 180^\circ - (50^\circ + 70^\circ) = 60^\circ\)
មុំក្រៅត្រង់កំពូល \(C\) គឺ ៖
\(180^\circ - 60^\circ = 120^\circ\) (ឬ \(\angle A + \angle B = 120^\circ\))។

៤០លំហាត់ទី ៤០

មុំជុំវិញចំណុចមួយត្រូវបានបែងចែកជា ៥ មុំស្មើៗគ្នា។ គណនារង្វាស់មុំនីមួយៗ និងប្រាប់ប្រភេទមុំ។

មើលដំណោះស្រាយ

ផលបូកមុំជុំវិញចំណុចមួយស្មើ \(360^\circ\) ៖
រង្វាស់មុំនីមួយៗ ៖ \(\frac{360^\circ}{5} = 72^\circ\)
ដោយ \(72^\circ < 90^\circ\) នាំឱ្យមុំនីមួយៗជាមុំស្រួច។

៤១លំហាត់ទី ៤១

គេឱ្យមុំបួនជុំវិញចំណុចមួយមានរង្វាស់ \(x, 2x, 3x, 4x\)។ គណនាតម្លៃនៃ \(x\) និងរង្វាស់មុំនីមួយៗ។

មើលដំណោះស្រាយ

ផលបូកមុំជុំវិញចំណុចមួយស្មើ \(360^\circ\) ៖
\(x + 2x + 3x + 4x = 360^\circ \Rightarrow 10x = 360^\circ \Rightarrow x = 36^\circ\)
រង្វាស់មុំនីមួយៗ ៖

  • \(x = 36^\circ\)

  • \(2x = 72^\circ\)

  • \(3x = 108^\circ\)

  • \(4x = 144^\circ\)

៤២លំហាត់ទី ៤២

គេឱ្យមុំ \(\angle xOy = 70^\circ\)។ គូសកន្លះបន្ទាត់ពុះ \([Oz)\) នៃ \(\angle xOy\)។ គូសកន្លះបន្ទាត់ពុះ \([Ot)\) នៃ \(\angle xOz\)។
គណនារង្វាស់មុំ \(\angle tOy\)។

មើលដំណោះស្រាយ

\([Oz)\) ជាពុះមុំ \(\angle xOy \Rightarrow \angle xOz = \angle zOy = \frac{70^\circ}{2} = 35^\circ\)។
\([Ot)\) ជាពុះមុំ \(\angle xOz \Rightarrow \angle zOt = \frac{35^\circ}{2} = 17.5^\circ\)។
\(\angle tOy = \angle zOt + \angle zOy = 17.5^\circ + 35^\circ = 52.5^\circ = 52^\circ 30'\)។

៤៣លំហាត់ទី ៤៣

គេឱ្យមុំជាប់គ្នាពីរ \(\angle AOB = 50^\circ\) និង \(\angle BOC = 70^\circ\)។ តាង \(Ox, Oy\) ជាកន្លះបន្ទាត់ពុះនៃ \(\angle AOB\) និង \(\angle BOC\) រៀងគ្នា។
គណនារង្វាស់មុំ \(\angle xOy\)។

មើលដំណោះស្រាយ

\(Ox, Oy\) ជាកន្លះបន្ទាត់ពុះនៃមុំជាប់គ្នា ៖
\(\angle xOy = \frac{\angle AOB}{2} + \frac{\angle BOC}{2} = \frac{50^\circ + 70^\circ}{2} = \frac{120^\circ}{2} = 60^\circ\)។

៤៤លំហាត់ទី ៤៤

គេឱ្យមុំជាប់គ្នាពីរ \(\angle AOB\) និង \(\angle BOC\) ដោយ \(\angle AOC = 100^\circ\)។ តាង \(Ox, Oy\) ជាកន្លះបន្ទាត់ពុះនៃ \(\angle AOB\) និង \(\angle BOC\) រៀងគ្នា។
គណនារង្វាស់មុំ \(\angle xOy\)។

មើលដំណោះស្រាយ

\(Ox, Oy\) ជាកន្លះបន្ទាត់ពុះនៃមុំជាប់គ្នា ៖
\(\angle xOy = \frac{\angle AOB + \angle BOC}{2} = \frac{\angle AOC}{2} = \frac{100^\circ}{2} = 50^\circ\)។

៤៥លំហាត់ទី ៤៥

បង្ហាញថាក្នុងមុំជាប់គ្នាពីរ កន្លះបន្ទាត់ពុះនៃមុំទាំងពីរ បង្កើតបានមុំមួយដែលមានរង្វាស់ស្មើនឹងពាក់កណ្ដាលនៃផលបូករង្វាស់មុំទាំងពីរនោះ។

មើលដំណោះស្រាយ

តាងមុំជាប់គ្នាពីរគឺ \(\angle AOB\) និង \(\angle BOC\) ហើយ \(Ox, Oy\) ជាកន្លះបន្ទាត់ពុះរៀងគ្នា។
យើងមាន \(\angle xOB = \frac{1}{2}\angle AOB\) និង \(\angle BOy = \frac{1}{2}\angle BOC\)
\(\angle xOy = \angle xOB + \angle BOy = \frac{1}{2}(\angle AOB + \angle BOC)\)
ពិតជាស្មើនឹងពាក់កណ្ដាលនៃផលបូករង្វាស់មុំទាំងពីរ។

៤៦លំហាត់ទី ៤៦

គេឱ្យ \(\angle xOy = 80^\circ\) និង \(\angle yOz = 40^\circ\) ជាមុំជាប់គ្នា។ គណនាមុំរវាងកន្លះបន្ទាត់ពុះនៃ \(\angle xOy\) និងកន្លះបន្ទាត់ឈមនៃ \(Oy\)។

មើលដំណោះស្រាយ

តាង \(Ot\) ជាពុះមុំនៃ \(\angle xOy \Rightarrow \angle yOt = \frac{80^\circ}{2} = 40^\circ\)។
តាង \(Oy'\) ជាកន្លះបន្ទាត់ឈមនៃ \(Oy \Rightarrow \angle yOy' = 180^\circ\)។
មុំរវាង \(Ot\) និង \(Oy'\) គឺ ៖
\(\angle tOy' = 180^\circ - \angle yOt = 180^\circ - 40^\circ = 140^\circ\)។

៤៧លំហាត់ទី ៤៧

គេឱ្យបន្ទាត់ពីរប្រសព្វគ្នាត្រង់ \(O\) បង្កើតបានមុំបួន។ បង្ហាញថាកន្លះបន្ទាត់ពុះនៃមុំទល់កំពូលពីរ គឺជាកន្លះបន្ទាត់ឈមគ្នា (រត់ត្រង់ជួរគ្នាជាបន្ទាត់តែមួយ)។

មើលដំណោះស្រាយ

តាងមុំទល់កំពូលពីរគឺ \(\angle AOB\) និង \(\angle A'OB'\)។
តាង \(Ot\) និង \(Ot'\) ជាកន្លះបន្ទាត់ពុះរៀងគ្នា ៖
\(\angle AOt = \frac{1}{2}\angle AOB = \frac{1}{2}\angle A'OB' = \angle A'Ot'\)
\(\angle tOA' + \angle A'Ot' = (180^\circ - \angle AOt) + \angle AOt = 180^\circ\)
នាំឱ្យ \(Ot\) និង \(Ot'\) បង្កើតបានជាបន្ទាត់ត្រង់តែមួយ (កន្លះបន្ទាត់ឈមគ្នា)។

៤៨លំហាត់ទី ៤៨

គេឱ្យមុំរាប \(\angle AOB = 180^\circ\)។ លើកន្លះប្លង់តែមួយដែលមានព្រំដែនបន្ទាត់ \(AB\) គេគូសកន្លះបន្ទាត់ \(OC\) និង \(OD\) ដោយ \(\angle AOC = 40^\circ\) និង \(\angle BOD = 50^\circ\)។

  1. គណនា \(\angle COD\)

  2. តើ \(OC\) និង \(OD\) កែងគ្នាដែរឬទេ?

មើលដំណោះស្រាយ

  • ក. \(\angle COD = 180^\circ - (\angle AOC + \angle BOD) = 180^\circ - (40^\circ + 50^\circ) = 90^\circ\)

  • ខ. ដោយ \(\angle COD = 90^\circ\) នោះកន្លះបន្ទាត់ \(OC\) និង \(OD\) កែងគ្នា (\(OC \perp OD\))។

៤៩លំហាត់ទី ៤៩

មុំមួយមានរង្វាស់ស្មើនឹង \(x\)។ រកតម្លៃ \(x\) បើដឹងថាមុំបន្ថែមនៃ \(x\) ធំជាង ៤ ដងនៃមុំបំពេញនៃ \(x\) ចំនួន \(15^\circ\)។

មើលដំណោះស្រាយ

សមីការ ៖ \((180^\circ - x) - 4(90^\circ - x) = 15^\circ\)
\(180^\circ - x - 360^\circ + 4x = 15^\circ\)
\(3x - 180^\circ = 15^\circ \Rightarrow 3x = 195^\circ \Rightarrow x = 65^\circ\)
