មេរៀនទាំងអស់
ប្រវត្តិនៃភាគរយ និងនិមិត្តសញ្ញា \(\%\)

គំនិតនៃភាគរយមានដើមកំណើតតាំងពីសម័យបុរាណយូរលង់ណាស់មកហើយ។ នៅក្នុងចក្រភពរ៉ូមបុរាណ មុនពេលប្រព័ន្ធទសភាគត្រូវបានបង្កើតឡើង ការគណនាពន្ធដារ និងការដេញថ្លៃទំនិញត្រូវបានគិតជាប្រភាគនៃ \(100\)។ ជាអាទិ៍ អធិរាជរ៉ូម៉ាំង Augustus បានបង្កើតពន្ធមួយហៅថា centesima rerum venalium ដែលជាពន្ធមួយភាគរយ (\(1/100\)) លើរាល់ទំនិញដែលបានលក់ក្នុងការដេញថ្លៃ។

ពាក្យថា «ភាគរយ» ក្នុងភាសាអង់គ្លេសគឺ Percent ដែលក្លាយមកពីភាសាឡាតាំង Per Centum មានន័យថា «ក្នុងមួយរយ» ឬ «លើមួយរយ»។

ចំណែកនិមិត្តសញ្ញា \(\%\) វិញ ពុំមែនកើតឡើងភ្លាមៗនោះទេ គឺវាបានវិវត្តជាបន្តបន្ទាប់ពីភាសាអ៊ីតាលីកាត់ per cento។ នៅក្នុងសតវត្សទី១៥ អ្នកចម្លងឯកសារបានសរសេរកាត់ថា p cento ឬ p 100។ លុះដល់សតវត្សទី១៧ ការសរសេរបានក្លាយទៅជា \(p\frac{o}{o}\) រួចបន្តិចម្ដងៗអក្សរ \(p\) ត្រូវបានលុបបំបាត់ ដោយបន្សល់ទុកតែសញ្ញារង្វង់ពីរ និងបន្ទាត់ទ្រេត \(\%\) ដែលយើងប្រើប្រាស់រហូតដល់សព្វថ្ងៃ។

បច្ចុប្បន្ន ភាគរយគឺជាឧបករណ៍គណិតវិទ្យាដ៏មានឥទ្ធិពលបំផុតមួយ ដែលត្រូវបានប្រើប្រាស់ជារៀងរាល់ថ្ងៃក្នុងវិស័យពាណិជ្ជកម្ម ធនាគារ (ការប្រាក់) ស្ថិតិ វិទ្យាសាស្ត្រ និងការរស់នៅប្រចាំថ្ងៃ។

សញ្ញាណភាគរយ

ភាគរយ

ភាគរយ គឺជាប្រភាគពិសេសមួយដែលមានភាគបែងស្មើនឹង \(100\)។
គេប្រើនិមិត្តសញ្ញា \(\%\) (អានថា ភាគរយ) ដើម្បីតំណាងឱ្យភាគរយ ៖

\[\frac{r}{100} = r\% \qquad{} (r \in \mathbb{R})\]
ឧទាហរណ៍ ៖ \(\dfrac{25}{100} = 25\%\) (ម្ភៃប្រាំភាគរយ), \(\dfrac{50}{100} = 50\%\) (ហាសិបភាគរយ)។

ឧទាហរណ៍

ក្នុងថ្នាក់រៀនមួយមានសិស្សសរុប \(100\) នាក់ ក្នុងនោះមានសិស្សស្រី \(56\) នាក់។

  1. រកភាគរយនៃសិស្សស្រីធៀបនឹងសិស្សសរុប។

  2. រកភាគរយនៃសិស្សប្រុសធៀបនឹងសិស្សសរុប។

ដំណោះស្រាយ

ដំណោះស្រាយលម្អិត៖

  1. សិស្សស្រីមាន \(56\) នាក់ ក្នុងចំណោម \(100\) នាក់ ៖ \(\dfrac{56}{100} = 56\%\)។
    ដូចនេះ សិស្សស្រីមានចំនួន \(56\%\) នៃសិស្សសរុប។

  2. ចំនួនសិស្សប្រុសគឺ \(100 - 56 = 44\) នាក់។
    ភាគរយសិស្សប្រុសគឺ \(\dfrac{44}{100} = 44\%\)។
    ដូចនេះ សិស្សប្រុសមានចំនួន \(44\%\) នៃសិស្សសរុប។

សញ្ញាណភាគរយ

១. សរសេរប្រភាគដែលមានភាគបែង \(100\) ខាងក្រោមជានិមិត្តសញ្ញាភាគរយ ៖

  1. \(\dfrac{9}{100}\)

  2. \(\dfrac{37}{100}\)

  3. \(\dfrac{85.5}{100}\)

  4. \(\dfrac{120}{100}\)

២. ក្នុងកន្ត្រកមួយមានផ្លែឈើសរុប \(100\) ផ្លែ ក្នុងនោះមានផ្លែប៉ោម \(35\) ផ្លែ ផ្លែក្រូច \(45\) ផ្លែ និងនៅសល់ជាផ្លែស្វាយ។ រកភាគរយនៃផ្លែឈើនីមួយៗ។

ការបំប្លែងរវាងភាគរយ ប្រភាគ និងចំនួនទសភាគ

វិធាននៃការបំប្លែង

  • ប្ដូរភាគរយជាប្រភាគ ៖ សរសេរភាគរយជាប្រភាគដែលមានភាគបែង \(100\) រួចសម្រួលឱ្យអស់ ៖

    \[P\% = \frac{P}{100}\]

  • ប្ដូរភាគរយជាចំនួនទសភាគ ៖ យកចំនួននោះចែកនឹង \(100\) (រំកិលក្បៀសទៅឆ្វេង ២ ខ្ទង់) ៖

    \[P\% = P \div 100\]

  • ប្ដូរប្រភាគ ឬចំនួនទសភាគជាភាគរយ ៖ យកប្រភាគ ឬចំនួនទសភាគនោះទៅគុណនឹង \(100\%\) ៖

    \[x = (x \times 100)\%\]

ឧទាហរណ៍

ក. ប្ដូរ \(48\%\) និង \(12.5\%\) ជាប្រភាគបង្រួមមិនបាន។
ខ. ប្ដូរ \(65\%\) និង \(3.2\%\) ជាចំនួនទសភាគ។
គ. ប្ដូរប្រភាគ \(\dfrac{3}{4}\) និង \(\dfrac{5}{8}\) ជាភាគរយ។
ឃ. ប្ដូរចំនួនទសភាគ \(0.45\) និង \(1.35\) ជាភាគរយ។

ដំណោះស្រាយ

ដំណោះស្រាយលម្អិត៖

  1. \(48\% = \dfrac{48}{100} = \dfrac{48 \div 4}{100 \div 4} = \dfrac{12}{25}\) និង \(12.5\% = \dfrac{12.5}{100} = \dfrac{125}{1000} = \dfrac{1}{8}\)

  2. \(65\% = \dfrac{65}{100} = 0.65\) និង \(3.2\% = \dfrac{3.2}{100} = 0.032\)

  3. \(\dfrac{3}{4} = \left(\dfrac{3}{4} \times 100\right)\% = (3 \times 25)\% = 75\%\) និង \(\dfrac{5}{8} = \left(\dfrac{5}{8} \times 100\right)\% = 62.5\%\)

  4. \(0.45 = (0.45 \times 100)\% = 45\%\) និង \(1.35 = (1.35 \times 100)\% = 135\%\)

ការបំប្លែងតម្លៃ

១. ប្ដូរភាគរយខាងក្រោមជាប្រភាគបង្រួមមិនបាន ៖ \(15\%, \quad{} 64\%, \quad{} 120\%, \quad{} 0.8\%\)។
២. ប្ដូរភាគរយខាងក្រោមជាចំនួនទសភាគ ៖ \(8\%, \quad{} 42.5\%, \quad{} 175\%, \quad{} 0.05\%\)។
៣. ប្ដូរប្រភាគ និងចំនួនទសភាគខាងក្រោមជាភាគរយ ៖ \(\dfrac{7}{10}, \quad{} \dfrac{3}{20}, \quad{} 0.08, \quad{} 2.15\)។

ការស្វែងរកភាគរយនៃចំនួនមួយ

រូបមន្តគណនាភាគរយនៃចំនួនមួយ

ដើម្បីរក \(P\%\) នៃចំនួន \(B\) គេត្រូវយកភាគរយ \(P\%\) (សរសេរជាប្រភាគ \(\frac{P}{100}\) ឬទសភាគ) គុណនឹងចំនួន \(B\) ៖

\[\text{តម្លៃដែលត្រូវរក } A = \frac{P}{100} \times B = (P \div 100) \times B\]

ឧទាហរណ៍

ក. គណនា \(25\%\) នៃប្រាក់ \(80~000\) រៀល ។
ខ. ក្នុងចំណោមសិស្ស \(450\) នាក់ មានសិស្ស \(60\%\) ចូលចិត្តលេងកីឡាបាល់ទាត់។ តើសិស្សចូលចិត្តបាល់ទាត់មានប៉ុន្មាននាក់?

ដំណោះស្រាយ

ដំណោះស្រាយលម្អិត៖

  1. \(25\%\) នៃ \(80~000\) គឺ ៖

    \[\frac{25}{100} \times 80~000 = \frac{1}{4} \times 80~000 = 20~000\text{ រៀល}\]

  2. ចំនួនសិស្សដែលចូលចិត្តបាល់ទាត់គឺ ៖

    \[\frac{60}{100} \times 450 = 0.6 \times 450 = 270\text{ នាក់}\]

គណនាភាគរយនៃចំនួនមួយ

១. គណនា ៖

  1. \(15\%\) នៃ \(400\text{ kg}\)

  2. \(30\%\) នៃ \(1~200\text{ m}\)

  3. \(7.5\%\) នៃ \(600~000\) ៛

២. ក្នុងសាលាមួយមានសិស្សសរុប \(800\) នាក់ ។ ក្នុងនោះសិស្សពូកែមាន \(12\%\)។ តើសាលានោះមានសិស្សពូកែប៉ុន្មាននាក់?

ការសរសេរបរិមាណមួយជាភាគរយនៃបរិមាណមួយទៀត

រូបមន្តគណនា

ដើម្បីសរសេរបរិមាណ \(A\) ជាភាគរយនៃបរិមាណ \(B\) (ដែល \(A\) និង \(B\) មានខ្នាតដូចគ្នា) ៖

\[P\% = \left(\frac{A}{B} \times 100\right)\%\]
ចំណាំ ៖ ប្រសិនបើបរិមាណទាំងពីរមានខ្នាតខុសគ្នា ត្រូវបំប្លែងឱ្យទៅជាខ្នាតតែមួយជាមុនសិន។

កម្មវិធីអនុវត្តជាក់ស្ដែងក្នុងជីវភាពរស់នៅ

ពាណិជ្ជកម្ម និងហិរញ្ញវត្ថុ

  • ប្រាក់ចំណេញ និងប្រាក់ខាត ៖

    \[\text{ភាគរយចំណេញ} = \frac{\text{ប្រាក់ចំណេញ}}{\text{ថ្លៃដើម}} \times 100\%, \qquad{} \text{ភាគរយខាត} = \frac{\text{ប្រាក់ខាត}}{\text{ថ្លៃដើម}} \times 100\%\]

  • ការបញ្ចុះតម្លៃ (Discount) ៖

    \[\text{ប្រាក់បញ្ចុះ} = \text{អត្រាបញ្ចុះ} \times \text{ថ្លៃដើម}, \qquad{} \text{ថ្លៃលក់} = \text{ថ្លៃដើម} - \text{ប្រាក់បញ្ចុះ}\]

  • កម្រៃជើងសារ (Commission) ៖

    \[\text{ប្រាក់កម្រៃ} = \text{អត្រាកម្រៃ} \times \text{តម្លៃលក់បាន}\]

  • ការប្រាក់ទោល (Simple Interest) ៖

    \[I = P \times r \times t\]
    ដែល \(I\) ៖ ការប្រាក់, \(P\) ៖ ប្រាក់ដើម (Principal), \(r\) ៖ អត្រាការប្រាក់ប្រចាំឆ្នាំ (Rate), \(t\) ៖ រយៈពេលគិតជាឆ្នាំ (Time)។
    ប្រាក់សរុបត្រូវទទួល (ឬសង) ៖ \(A = P + I\)។

មើលដំណោះស្រាយ

គណនាភាគរយកំណើនប្រាក់ខែ ៖

  • កំណើនប្រាក់ខែ ៖ \(290 - 250 = 40\$\)

  • ភាគរយកំណើន ៖
    \(\dfrac{40}{250} \times 100\% = 16\%\)

៣៤លំហាត់ទី ៣៤

តម្លៃសាំងមួយលីត្របានធ្លាក់ចុះពី \(4~500\) ៛ មកត្រឹម \(4~050\) ៛ ។ រកភាគរយនៃការធ្លាក់ចុះនៃថ្លៃសាំង។

មើលដំណោះស្រាយ

គណនាភាគរយធ្លាក់ចុះថ្លៃសាំង ៖

  • ថ្លៃថយចុះ ៖ \(4\,500 - 4\,050 = 450\) ៛

  • ភាគរយថយចុះ ៖
    \(\dfrac{450}{4\,500} \times 100\% = 10\%\)

៣៥លំហាត់ទី ៣៥

ទីក្រុងមួយមានប្រជាជន \(120~000\) នាក់ក្នុងឆ្នាំមុន។ ឆ្នាំនេះចំនួនប្រជាជនកើនដល់ \(129~600\) នាក់។ រកអត្រាកំណើនប្រជាជនគិតជាភាគរយ។

មើលដំណោះស្រាយ

គណនាអត្រាកំណើនប្រជាជន ៖

  • កំណើនប្រជាជន ៖
    \(129\,600 - 120\,000 = 9\,600\) នាក់

  • អត្រាកំណើន ៖
    \(\dfrac{9\,600}{120\,000} \times 100\% = 8\%\)

៣៦លំហាត់ទី ៣៦

រោងចក្រមួយផលិតបានផលិតផល \(2~500\) កំប៉ុងក្នុងមួយថ្ងៃ។ បន្ទាប់ពីបំពាក់ម៉ាស៊ីនថ្មី ការផលិតកើនឡើងបាន \(16\%\)។ តើរោងចក្រនោះផលិតបានប៉ុន្មានកំប៉ុងក្នុងមួយថ្ងៃនាពេលបច្ចុប្បន្ន?

មើលដំណោះស្រាយ

គណនាចំនួនផលិតផលបច្ចុប្បន្ន ៖

  • ចំនួនផលិតផលកើនឡើង ៖
    \(2\,500 \times 16\% = 400\) កំប៉ុង

  • ផលិតផលសរុបបច្ចុប្បន្ន ៖
    \(2\,500 + 400 = 2\,900\) កំប៉ុង/ថ្ងៃ

៣៧លំហាត់ទី ៣៧

ពូសៅទិញទោចក្រយានយន្តមួយគ្រឿងតម្លៃ \(1~200\$\) រួចលក់ចេញវិញបានថ្លៃ \(1~440\$\)។ រកភាគរយប្រាក់ចំណេញរបស់គាត់។

មើលដំណោះស្រាយ

គណនាភាគរយប្រាក់ចំណេញ ៖

  • ប្រាក់ចំណេញ ៖ \(1\,440 - 1\,200 = 240\$\)

  • ភាគរយចំណេញ ៖
    \(\dfrac{240}{1\,200} \times 100\% = 20\%\)

៣៨លំហាត់ទី ៣៨

អាជីវករម្នាក់ទិញផ្លែក្រូចមួយកន្ត្រកតម្លៃ \(80~000\) ៛ ។ ដោយសារផ្លែឈើខូចខ្លះ គាត់លក់ចេញវិញបានតែ \(68~000\) ៛ ។ រកភាគរយប្រាក់ខាត។

មើលដំណោះស្រាយ

គណនាភាគរយប្រាក់ខាត ៖

  • ប្រាក់ខាត ៖ \(80\,000 - 68\,000 = 12\,000\) ៛

  • ភាគរយខាត ៖
    \(\dfrac{12\,000}{80\,000} \times 100\% = 15\%\)

៣៩លំហាត់ទី ៣៩

ហាងមួយទិញកង្ហារមួយគ្រឿងតម្លៃដើម \(24\$\) ហើយចង់លក់ចំណេញ \(25\%\)។ តើហាងនោះត្រូវដាក់លក់កង្ហារក្នុងតម្លៃប៉ុន្មាន?

មើលដំណោះស្រាយ

គណនាតម្លៃលក់កង្ហារ ៖

  • ប្រាក់ចំណេញ ៖ \(24 \times 25\% = 6\$\)

  • តម្លៃលក់ត្រូវដាក់ ៖ \(24 + 6 = 30\$\)

៤០លំហាត់ទី ៤០

ឈ្មួញម្នាក់លក់ទំនិញមួយក្នុងតម្លៃ \(180~000\) ៛ ដោយទទួលរងការខាតបង់ \(10\%\) នៃថ្លៃដើម។ រកថ្លៃដើមនៃទំនិញនោះ។

មើលដំណោះស្រាយ

គណនាថ្លៃដើមនៃទំនិញ ៖ ព្រោះលក់ខាត \(10\%\) នាំឱ្យតម្លៃលក់ស្មើ \(90\%\) នៃថ្លៃដើម ៖

\[\text{ថ្លៃដើម} = 180\,000 \div 90\% = 200\,000\text{ ៛}\]

៤១លំហាត់ទី ៤១

ហាងលក់សម្លៀកបំពាក់មួយប្រកាសបញ្ចុះតម្លៃ \(20\%\) លើគ្រប់មុខទំនិញ។ បើខោខូវប៊យមួយមានតម្លៃដើម \(35\$\) តើអតិថិជនត្រូវទិញក្នុងតម្លៃប៉ុន្មាន?

មើលដំណោះស្រាយ

គណនាតម្លៃទិញក្រោយបញ្ចុះតម្លៃ ៖ តម្លៃទិញស្មើ \(80\%\) នៃតម្លៃដើម ៖

\[35 \times (1 - 0.20) = 35 \times 0.80 = 28\$\]

៤២លំហាត់ទី ៤២

ម៉ាស៊ីនកុំព្យូទ័រមួយគ្រឿងដាក់លក់តម្លៃ \(650\$\)។ នាឱកាសបុណ្យចូលឆ្នាំ ហាងបានលក់វាត្រឹមតែ \(546\$\)។ រកភាគរយនៃការបញ្ចុះតម្លៃ។

មើលដំណោះស្រាយ

គណនាភាគរយបញ្ចុះតម្លៃកុំព្យូទ័រ ៖

  • ទឹកប្រាក់បញ្ចុះ ៖ \(650 - 546 = 104\$\)

  • ភាគរយបញ្ចុះ ៖
    \(\dfrac{104}{650} \times 100\% = 16\%\)

៤៣លំហាត់ទី ៤៣

ទូរស័ព្ទមួយគ្រឿងមានតម្លៃស្លាក \(400\$\)។ ហាងបញ្ចុះតម្លៃ \(15\%\) ហើយប្រសិនបើបង់ប្រាក់សុទ្ធ ហាងបញ្ចុះបន្ថែម \(5\%\) ទៀតលើតម្លៃដែលបានបញ្ចុះរួច។ តើអ្នកទិញត្រូវបង់ប្រាក់សុទ្ធប៉ុន្មាន?

មើលដំណោះស្រាយ

គណនាប្រាក់សុទ្ធត្រូវបង់ ៖

  • តម្លៃក្រោយបញ្ចុះ \(15\%\) ៖
    \(400 \times (1 - 0.15) = 340\$\)

  • តម្លៃក្រោយបញ្ចុះថែម \(5\%\) ៖
    \(340 \times (1 - 0.05) = 340 \times 0.95 = 323\$\)

៤៤លំហាត់ទី ៤៤

ភ្នាក់ងារលក់អចលនទ្រព្យម្នាក់ទទួលបានកម្រៃជើងសារ \(3\%\) លើតម្លៃដីដែលលក់បាន។ បើគាត់ជួយលក់ដីមួយកន្លែងបានប្រាក់ \(85~000\$\) តើគាត់ទទួលបានប្រាក់កម្រៃជើងសារប៉ុន្មាន?

មើលដំណោះស្រាយ

គណនាកម្រៃជើងសារ ៖ ប្រាក់កម្រៃជើងសារដែលទទួលបាន ៖

\[85\,000 \times 3\% = 85\,000 \times 0.03 = 2\,550\$\]

៤៥លំហាត់ទី ៤៥

អ្នកតំណាងចែកចាយម្នាក់លក់ផលិតផលបានទឹកប្រាក់សរុប \(12~000\$\) ហើយទទួលបានប្រាក់កម្រៃជើងសារចំនួន \(720\$\)។ រកអត្រាភាគរយនៃកម្រៃជើងសារនោះ។

មើលដំណោះស្រាយ

គណនាអត្រាភាគរយកម្រៃជើងសារ ៖ អត្រាភាគរយនៃកម្រៃជើងសារ ៖

\[\frac{720}{12\,000} \times 100\% = 6\%\]

៤៦លំហាត់ទី ៤៦

លោកចាន់ផ្ញើប្រាក់សន្សំ \(4~000~000\) ៛ នៅធនាគារក្នុងអត្រាការប្រាក់ទោល \(6.5\%\) ក្នុងមួយឆ្នាំ។ រកការប្រាក់ដែលគាត់ទទួលបានក្រោយរយៈពេល ៖

  1. \(1\) ឆ្នាំ

  2. \(3\) ឆ្នាំ

មើលដំណោះស្រាយ

គណនាការប្រាក់ទោល (\(P = 4\,000\,000\) ៛ \(, r = 6.5\%\)) ៖

  • ក្រោយ \(1\) ឆ្នាំ ៖
    \(I = 4\,000\,000 \times 0.065 \times 1 = 260\,000\) ៛

  • ក្រោយ \(3\) ឆ្នាំ ៖
    \(I = 260\,000 \times 3 = 780\,000\) ៛

៤៧លំហាត់ទី ៤៧

អ្នកស្រីមុំខ្ចីប្រាក់ពីគ្រឹះស្ថានមីក្រូហិរញ្ញវត្ថុចំនួន \(5~000\$\) ក្នុងអត្រាការប្រាក់ទោល \(8\%\) ក្នុងមួយឆ្នាំ ក្នុងរយៈពេល \(2\) ឆ្នាំ ។

  1. រកការប្រាក់សរុបដែលត្រូវបង់

  2. រកប្រាក់សរុបទាំងដើមទាំងការប្រាក់ដែលត្រូវសង

មើលដំណោះស្រាយ

គណនាការប្រាក់ និងប្រាក់សរុប ៖

  • ការប្រាក់សរុប (\(2\) ឆ្នាំ ) ៖
    \(I = 5\,000 \times 0.08 \times 2 = 800\$\)

  • ប្រាក់សរុបត្រូវសង ៖
    \(A = 5\,000 + 800 = 5\,800\$\)

៤៨លំហាត់ទី ៤៨

គេយកប្រាក់ \(8~000~000\) ៛ ទៅផ្ញើធនាគារក្នុងអត្រាការប្រាក់ទោល \(7\%\) ក្នុងមួយឆ្នាំ។ រកការប្រាក់ដែលទទួលបានក្នុងរយៈពេល ៖

  1. \(6\) ខែ

  2. \(18\) ខែ

មើលដំណោះស្រាយ

គណនាការប្រាក់ (\(P = 8\,000\,000\) ៛ \(, r = 7\%\)) ៖

  • រយៈពេល \(6\) ខែ \( = 0.5\) ឆ្នាំ ៖
    \(I = 8\,000\,000 \times 0.07 \times 0.5 = 280\,000\) ៛

  • រយៈពេល \(18\) ខែ \( = 1.5\) ឆ្នាំ ៖
    \(I = 8\,000\,000 \times 0.07 \times 1.5 = 840\,000\) ៛

៤៩លំហាត់ទី ៤៩

វិនិយោគិនម្នាក់ដាក់ប្រាក់ចំនួន \(10~000\$\) ក្នុងគម្រោងមួយ។ ក្រោយរយៈពេល \(4\) ឆ្នាំ គាត់ទទួលបានការប្រាក់សរុប \(2~400\$\)។ រកអត្រាការប្រាក់ប្រចាំឆ្នាំនៃគម្រោងនោះ។

មើលដំណោះស្រាយ

គណនាអត្រាការប្រាក់ប្រចាំឆ្នាំ ៖ រូបមន្ត \(I = P \times r \times t\) នាំឱ្យ ៖

\[r = \frac{I}{P \times t} = \frac{2\,400}{10\,000 \times 4} = 0.06 = 6\%\]

៥០លំហាត់ទី ៥០

លោកសុផលបានបែងចែកប្រាក់ចំណូលប្រចាំខែ \(600\$\) របស់គាត់ដូចខាងក្រោម ៖ \(40\%\) សម្រាប់ចំណាយម្ហូបអាហារ និងការរស់នៅ, \(25\%\) សម្រាប់ថ្លៃផ្ទះ និងទឹកភ្លើង, \(15\%\) សម្រាប់ការសិក្សារបស់កូន, \(10\%\) សម្រាប់កម្សាន្ត និងនៅសល់សម្រាប់សន្សំទុក។

  1. គណនាទឹកប្រាក់ចំណាយលើផ្នែកនីមួយៗ

  2. រកភាគរយ និងទឹកប្រាក់ដែលគាត់សន្សំបានក្នុងមួយខែ

មើលដំណោះស្រាយ

គណនាការបែងចែកប្រាក់ចំណូល \(600\$\) ៖

  • ចំណាយម្ហូបអាហារ (\(40\%\)) ៖ \(600 \times 0.40 = 240\$\)

  • ថ្លៃផ្ទះ/ទឹកភ្លើង (\(25\%\)) ៖ \(600 \times 0.25 = 150\$\)

  • ការសិក្សាកូន (\(15\%\)) ៖ \(600 \times 0.15 = 90\$\)

  • កម្សាន្ត (\(10\%\)) ៖ \(600 \times 0.10 = 60\$\)

  • ភាគរយសន្សំ ៖ \(100\% - 90\% = 10\%\)

  • ប្រាក់សន្សំ ៖ \(600 \times 10\% = 60\$\)
