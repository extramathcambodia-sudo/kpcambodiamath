មេរៀនទាំងអស់
ប្រវត្តិ និងការវិវត្តនៃទ្រឹស្ដីប្រូបាប

«ប្រូបាប» (Probability) គឺជាផ្នែកមួយដ៏សំខាន់នៃគណិតវិទ្យាទំនើប ដែលសិក្សាអំពីរង្វាស់នៃភាពមិនប្រាកដប្រជា និងឱកាសនៃការកើតឡើងនៃព្រឹត្តិការណ៍នានា។ ទ្រឹស្ដីប្រូបាបបានចាប់បដិសន្ធិឡើងជាផ្លូវការនៅពាក់កណ្ដាលសតវត្សទី ១៧ (ឆ្នាំ ១៦៥៤) តាមរយៈការឆ្លើយឆ្លងសំបុត្ររវាងគណិតវិទូបារាំងពីររូបដ៏ល្បីល្បាញ គឺលោក ប្លែស ប៉ាស្កាល់ (Blaise Pascal) និងលោក ព្យែរ ដឺ ហ្វែរម៉ា (Pierre de Fermat) អំពីល្បែងគ្រាប់ឡុកឡាក់។ ក្រោយមក គណិតវិទូជាច្រើនដូចជា Bernoulli, Laplace និង Kolmogorov បានបន្តអភិវឌ្ឍទ្រឹស្ដីនេះឱ្យក្លាយជាវិទ្យាសាស្ត្រដ៏រឹងមាំ។

ក្នុងយុគសម័យបច្ចុប្បន្ន ប្រូបាបដើរតួនាទីយ៉ាងសំខាន់ក្នុងការព្យាករណ៍អាកាសធាតុ ការគ្រប់គ្រងហានិភ័យហិរញ្ញវត្ថុ ទីផ្សារភាគហ៊ុន ការធានារ៉ាប់រង ការស្រាវជ្រាវវេជ្ជសាស្ត្រ ព្រមទាំងបច្ចេកវិទ្យាបញ្ញាសិប្បនិម្មិត (AI)។ លើសពីនេះ ការយល់ដឹងពីប្រូបាបជួយឱ្យយើងចេះគិតពិចារណាដោយហេតុផល វាយតម្លៃឱកាស និងធ្វើការសម្រេចចិត្តដ៏ត្រឹមត្រូវក្នុងជីវភាពរស់នៅប្រចាំថ្ងៃ។

សញ្ញាណទូទៅនៃប្រូបាប

នៅក្នុងការសិក្សាប្រូបាបថ្នាក់ទី ៧ យើងត្រូវស្វែងយល់នូវចំណុចគ្រឹះសំខាន់ៗ ៖

  • វិញ្ញាសាចៃដន្យ (Random Experiment) ៖ សកម្មភាពដែលគេដឹងលទ្ធផលអាចកើតមានទាំងអស់ តែមិនអាចដឹងមុននូវលទ្ធផលជាក់ស្ដែង។

  • លទ្ធផល និងលំហសំណាក (\(S\)) ៖ សំណុំនៃគ្រប់លទ្ធផលដែលអាចកើតមានទាំងអស់។ ចំនួនករណីអាចតាងដោយ \(n(S)\)។

  • ព្រឹត្តិការណ៍ (\(A\)) ៖ សំណុំរងនៃលំហសំណាក (\(A \subseteq S\))។ ចំនួនករណីស្របតាងដោយ \(n(A)\)។

  • ប្រូបាប (\(P(A)\)) ៖ រង្វាស់ឱកាសកើតឡើងនៃព្រឹត្តិការណ៍ \(A\) កំណត់ដោយ \(P(A) = \frac{n(A)}{n(S)}\) ដោយ \(0 \le P(A) \le 1\)។

វិញ្ញាសាចៃដន្យ

វិញ្ញាសាចៃដន្យ ៖ សញ្ញាណ និងឧទាហរណ៍

  • និយមន័យ ៖ វិញ្ញាសាចៃដន្យ (Random Experiment) គឺជាសកម្មភាព ឬការពិសោធន៍ដែលគេមិនអាចដឹងលទ្ធផលជាមុនបានឡើយ។

  • លក្ខណៈ ៖ គេដឹងគ្រប់ករណីដែលអាចកើតឡើង តែមិនអាចទស្សន៍ទាយលទ្ធផលជាក់ស្ដែងបានត្រឹមត្រូវ \(100\%\) ឡើយ។

  • ឧទាហរណ៍ ៖ ការបោះកាក់ (ចេញរូប ឬលេខ), ការបោះគ្រាប់ឡុកឡាក់ (\(1\) ដល់ \(6\)), ការចាប់បាល់ពីក្នុងថង់។

ឧទាហរណ៍

ចូរបញ្ជាក់ថាតើសកម្មភាពខាងក្រោមណាខ្លះជាវិញ្ញាសាចៃដន្យ ៖
ក. បោះកាក់មួយឡើងលើ រួចកត់ត្រាមុខកាក់ដែលផ្ងារ។ ខ. ដាំទឹកបរិសុទ្ធឱ្យពុះនៅសម្ពាធធម្មតា។
គ. ចាប់យកសន្លឹកឆ្នោតមួយសន្លឹកចេញពីប្រអប់ឆ្នោតផ្សងសំណាង។

 គ. ជាវិញ្ញាសាចៃដន្យ ព្រោះមិនអាចដឹងមុនថានឹងចាប់បានលេខរង្វាន់អ្វីឡើយ។

វិញ្ញាសាចៃដន្យ

១. ក្នុងចំណោម «ការបោះឡុកឡាក់» និង «ការទម្លាក់ដុំថ្មពីលើចុះក្រោម» តើមួយណាជាវិញ្ញាសាចៃដន្យ?
២. ចូរបង្ហាញឧទាហរណ៍ចំនួនពីរនៃវិញ្ញាសាចៃដន្យក្នុងជីវភាពរស់នៅប្រចាំថ្ងៃ។

លទ្ធផលដែលអាចកើតមាន និងលំហសំណាក

លទ្ធផល និងលំហសំណាក \(S\)

  • លទ្ធផល (Outcome) ៖ ករណីនីមួយៗដែលអាចកើតមានឡើងនៅក្នុងវិញ្ញាសាមួយ។

  • លំហសំណាក (Sample Space, \(S\)) ៖ សំណុំនៃគ្រប់លទ្ធផលដែលអាចកើតមានទាំងអស់។

  • ចំនួនករណីអាច (\(n(S)\)) ៖ ចំនួនធាតុទាំងអស់នៃលំហសំណាក \(S\)។

  • ឧទាហរណ៍ ៖ បោះកាក់មួយ ៖ \(S = \{\) រូប \(, \) លេខ \(\} \implies n(S) = 2\) ; បោះឡុកឡាក់ ៖ \(S = \{1, 2, 3, 4, 5, 6\} \implies n(S) = 6\)។

រូបភាពនេះកំពុងរៀបចំ

ឧទាហរណ៍

គេមានថង់មួយផ្ទុកបាល់ ៣ គ្រាប់ ៖ ក្រហម (\(R\)), បៃតង (\(G\)), លឿង (\(Y\))។ គេចាប់បាល់មួយដោយចៃដន្យ។
ក. សរសេរលំហសំណាក \(S\) និងរកចំនួនករណីអាច \(n(S)\)។
ខ. បើគេចាប់បាល់មួយរួចដាក់ចូលវិញ ហើយចាប់ម្ដងទៀត តើមានលទ្ធផលប៉ុន្មានករណីដែលអាចកើតមាន?

ដំណោះស្រាយ

ដំណោះស្រាយលម្អិត៖
 ក. លំហសំណាក ៖ \(S = \{R, G, Y\} \implies\) \(n(S) = 3\) ករណី។
 ខ. លើកទី១ មាន \(3\) លទ្ធផល លើកទី២ មាន \(3\) លទ្ធផល \(\implies n(S) = 3 \times 3 = 9\) ករណី។ ដូចនេះ \(n(S) = 9\) ករណី

លទ្ធផល និងលំហសំណាក

១. គេបង្វិលថាសមួយដែលមានលេខ \(1, 2, 3, 4, 5\)។ សរសេរលំហសំណាក \(S\) និងរក \(n(S)\)។
២. ក្នុងប្រអប់មួយមានប័ណ្ណអក្សរនៃពាក្យ «\(MATH\)»។ គេចាប់យកប័ណ្ណមួយដោយចៃដន្យ។ រកចំនួនករណីអាច។

ព្រឹត្តិការណ៍

ព្រឹត្តិការណ៍ និងប្រភេទព្រឹត្តិការណ៍

  • និយមន័យ ៖ ព្រឹត្តិការណ៍ (Event, \(A\)) គឺជាសំណុំនៃលទ្ធផលស្របតាមលក្ខខណ្ឌកំណត់ (\(A \subseteq S\))។ ចំនួនករណីស្របតាងដោយ \(n(A)\)។

  • ព្រឹត្តិការណ៍ជាក់លាក់ ៖ ព្រឹត្តិការណ៍ដែលកើតឡើងពិតប្រាកដជានិច្ច (\(A = S \implies n(A) = n(S)\))។

  • ព្រឹត្តិការណ៍មិនអាចកើតមាន ៖ ព្រឹត្តិការណ៍ដែលមិនអាចកើតមានដាច់ខាត (\(A = \emptyset \implies n(A) = 0\))។

  • ព្រឹត្តិការណ៍ផ្ទុយ (\(\overline{A}\)) ៖ ជាព្រឹត្តិការណ៍ដែល «មិនកើត \(A\)» ដោយ \(n(\overline{A}) = n(S) - n(A)\)។

រូបភាពនេះកំពុងរៀបចំ

ឧទាហរណ៍

គេបោះគ្រាប់ឡុកឡាក់មួយម្ដង។ គេកំណត់ព្រឹត្តិការណ៍ ៖
\(A\) ៖ «បោះបានលេខគូ», \(B\) ៖ «បោះបានលេខធំជាង ៦», \(C\) ៖ «បោះបានលេខតូចជាង ៧»។
ក. សរសេរលទ្ធផលនៃព្រឹត្តិការណ៍ \(A\) និងរក \(n(A)\)។ ខ. បញ្ជាក់ប្រភេទនៃព្រឹត្តិការណ៍ \(B\) និង \(C\)។

ដំណោះស្រាយ

ដំណោះស្រាយលម្អិត៖
 លំហសំណាក ៖ \(S = \{1, 2, 3, 4, 5, 6\} \implies n(S) = 6\)។
 ព្រឹត្តិការណ៍ \(A = \{2, 4, 6\} \implies\) \(n(A) = 3\) ករណី
 ព្រឹត្តិការណ៍ \(B = \emptyset\) ជាព្រឹត្តិការណ៍មិនអាចកើតមាន ព្រោះឡុកឡាក់គ្មានលេខធំជាង ៦ ឡើយ។
 ព្រឹត្តិការណ៍ \(C = \{1, 2, 3, 4, 5, 6\} = S\) ជាព្រឹត្តិការណ៍ជាក់លាក់។

ព្រឹត្តិការណ៍

១. គេបោះគ្រាប់ឡុកឡាក់មួយ។ កំណត់ចំនួនករណីស្របនៃព្រឹត្តិការណ៍ ៖
ក. \(A\) ៖ «បោះបានលេខសេស» ខ. \(B\) ៖ «បោះបានលេខជាពហុគុណនៃ ៣»
២. បើ \(A\) ជាព្រឹត្តិការណ៍ «បោះបានលេខ ២» តើព្រឹត្តិការណ៍ផ្ទុយ \(\overline{A}\) មានប៉ុន្មានករណី?

សញ្ញាណប្រូបាប និងរូបមន្តគណនា

រូបមន្តប្រូបាប និងលក្ខណៈគ្រឹះ

  • រូបមន្តប្រូបាប ៖ បើគ្រប់លទ្ធផលមានឱកាសកើតឡើងស្មើគ្នា ប្រូបាបនៃព្រឹត្តិការណ៍ \(A\) គឺ ៖

    \(P(A) = \dfrac{n(A)}{n(S)} = \dfrac{\text{ចំនួនករណីស្រប}}{\text{ចំនួនករណីអាច}}\)

  • លក្ខណៈសំខាន់ៗ ៖

    • \(0 \le P(A) \le 1\) ជានិច្ច  ព្រឹត្តិការណ៍មិនអាចកើតមាន ៖ \(P(\emptyset) = 0\)

    • ព្រឹត្តិការណ៍ជាក់លាក់ ៖ \(P(S) = 1\)  ព្រឹត្តិការណ៍ផ្ទុយ ៖ \(P(\overline{A}) = 1 - P(A)\)

រូបភាពនេះកំពុងរៀបចំ

ឧទាហរណ៍

គេបោះគ្រាប់ឡុកឡាក់មួយគ្រាប់ម្ដង។ គណនាប្រូបាបនៃព្រឹត្តិការណ៍ខាងក្រោម ៖
ក. \(A\) ៖ «បោះបានលេខ ៥» ខ. \(B\) ៖ «បោះបានលេខគូ» និងព្រឹត្តិការណ៍ផ្ទុយ \(\overline{B}\)។

ដំណោះស្រាយ

ដំណោះស្រាយលម្អិត៖
 លំហសំណាក ៖ \(S = \{1, 2, 3, 4, 5, 6\} \implies n(S) = 6\)។
 ក. \(A = \{5\} \implies n(A) = 1 \implies\) \(\boxed{P(A) = \dfrac{1}{6}}\)
 ខ. \(B = \{2, 4, 6\} \implies n(B) = 3 \implies\) \(\boxed{P(B) = \dfrac{3}{6} = \dfrac{1}{2}}\)
ប្រូបាបព្រឹត្តិការណ៍ផ្ទុយ ៖ \(P(\overline{B}) = 1 - P(B) = 1 - \dfrac{1}{2} = \dfrac{1}{2}\)។ ដូចនេះ \(\boxed{P(\overline{B}) = \dfrac{1}{2}}\)

ការគណនាប្រូបាប

១. គេបោះកាក់មួយ។ គណនាប្រូបាបដែលបោះបានខាងរូប។
២. ក្នុងប្រអប់មានឃ្លីក្រហម ៤ និងឃ្លីខៀវ ៦។ ចាប់យកឃ្លីមួយដោយចៃដន្យ។ គណនាប្រូបាបបានឃ្លីក្រហម។

ការគណនាប្រូបាបជាប្រភាគ ទសភាគ និងភាគរយ

ទម្រង់នៃប្រូបាប និងការទស្សន៍ទាយ

  • ទម្រង់ទាំងបីនៃប្រូបាប ៖ ជាប្រភាគសម្រួល (ឧ. \(\frac{1}{4}\)), ជាទសភាគ (ឧ. \(0.25\)), ជាភាគរយ (ឧ. \(25\%\))។

  • ចំនួនដងរំពឹងទុក (Expected Frequency) ៖ បើធ្វើវិញ្ញាសា \(N\) ដង ចំនួនដងរំពឹងទុកនៃ \(A\) គឺ ៖ \(E = N \times P(A)\)។

រូបភាពនេះកំពុងរៀបចំ

ឧទាហរណ៍

ក. គណនាប្រូបាបសិស្សនោះជាស្រី (ជាប្រភាគ ទសភាគ ភាគរយ)។ ខ. គណនាប្រូបាបជាប្រុស។

ដំណោះស្រាយ

ដំណោះស្រាយលម្អិត៖
 សិស្សសរុប ៖ \(n(S) = 20\), សិស្សស្រី ៖ \(n(G) = 12\)។
ប្រូបាបជាស្រី ៖ \(P(G) = \dfrac{12}{20} = \dfrac{3}{5} = 0.6 = 60\%\)។ ដូចនេះ \(\boxed{P(G) = \dfrac{3}{5} = 0.6 = 60\%}\)
 សិស្សប្រុស ៖ \(n(B) = 20 - 12 = 8 \implies P(B) = \dfrac{8}{20} = \dfrac{2}{5} = 0.4 = 40\%\)។ ដូចនេះ \(\boxed{P(B) = 40\%}\)

ទម្រង់ប្រូបាប និងការទស្សន៍ទាយ

២. គេបោះកាក់មួយ \(200\) ដង។ តើគេរំពឹងថានឹងបានខាងរូបប្រហែលប៉ុន្មានដង?

  1. គណនាប្រូបាបចាប់បានផ្លែក្រូច (ជាទសភាគ)

  2. គណនាប្រូបាបចាប់បានផ្លែស្វាយ (ជាទសភាគ)

មើលដំណោះស្រាយ

សរុប ២៤ ផ្លែ ៖

  • \(P(\) ក្រូច \() = \frac{8}{24} \approx 0.333\)

  • \(P(\) ស្វាយ \() = \frac{10}{24} \approx 0.417\)

៣៥លំហាត់ទី ៣៥

យោងតាមទិន្នន័យកន្ត្រកផ្លែឈើក្នុងលំហាត់ទី ៣៤ ៖

  1. គណនាប្រូបាបចាប់បានផ្លែប៉ោម (ជាភាគរយ)

  2. គណនាប្រូបាបចាប់បានផ្លែឈើមិនមែនប៉ោម

មើលដំណោះស្រាយ

  • \(P(\) ប៉ោម \() = \frac{6}{24} = 25\%\)

  • \(P(\) មិនមែនប៉ោម \() = 100\% - 25\% = 75\%\)

៣៦លំហាត់ទី ៣៦

គេបោះកាក់មួយចំនួន \(300\) ដង ៖

  1. គណនាចំនួនដងរំពឹងទុកដែលបោះបានខាងរូប

  2. បើជាក់ស្ដែងបោះបានខាងរូប \(142\) ដង រកចំនួនដងដែលចេញខាងលេខ

មើលដំណោះស្រាយ

បោះ ៣០០ ដង ៖

  • រំពឹងចេញរូប ៖ \(300 \times \frac{1}{2} = 150\) ដង

  • ចេញលេខជាក់ស្ដែង ៖ \(300 - 142 = 158\) ដង

៣៧លំហាត់ទី ៣៧

គេបោះគ្រាប់ឡុកឡាក់មួយចំនួន \(120\) ដង ៖

  1. គណនាចំនួនដងរំពឹងទុកដែលចេញលេខ ២

  2. គណនាចំនួនដងរំពឹងទុកដែលចេញលេខគូ

មើលដំណោះស្រាយ

បោះ ១២០ ដង ៖

  • ចេញលេខ ២ ៖ \(120 \times \frac{1}{6} = 20\) ដង

  • ចេញលេខគូ ៖ \(120 \times \frac{1}{2} = 60\) ដង

៣៨លំហាត់ទី ៣៨

ប្រអប់មួយមានអំពូលភ្លើង ១០០ គ្រាប់ ក្នុងនោះមានអំពូលខូច ៥ គ្រាប់ ៖

  1. គណនាប្រូបាបចាប់ប៉ះអំពូលខូច

  2. គណនាប្រូបាបចាប់ប៉ះអំពូលល្អ

មើលដំណោះស្រាយ

  • \(P(\) ខូច \() = \frac{5}{100} = 0.05\)

  • \(P(\) ល្អ \() = 1 - 0.05 = 0.95\)

៣៩លំហាត់ទី ៣៩

ក្នុងពិធីចាប់ឆ្នោតមួយមានសន្លឹកឆ្នោត ៥០០ សន្លឹក ដែលមានរង្វាន់ ២៥ សន្លឹក ៖

  1. គណនាប្រូបាបចាប់បានសន្លឹកមានរង្វាន់

  2. គណនាប្រូបាបចាប់បានសន្លឹកគ្មានរង្វាន់

មើលដំណោះស្រាយ

  • \(P(\) រង្វាន់ \() = \frac{25}{500} = 0.05 = 5\%\)

  • \(P(\) គ្មាន \() = 1 - 0.05 = 0.95 = 95\%\)

៤០លំហាត់ទី ៤០

ក្រុមហ៊ុនមួយផលិតម៉ាស៊ីនគិតលេខដោយមានអត្រាខូច \(2\%\) ៖

  1. រកប្រូបាបដែលទិញបានម៉ាស៊ីនល្អ

  2. ក្នុងចំណោមម៉ាស៊ីន \(500\) គ្រឿង រំពឹងថានឹងមានម៉ាស៊ីនខូចប៉ុន្មានគ្រឿង?

មើលដំណោះស្រាយ

  • \(P(\) ល្អ \() = 100\% - 2\% = 98\%\)

  • ម៉ាស៊ីនខូច ៖ \(500 \times 0.02 = 10\) គ្រឿង

៤១លំហាត់ទី ៤១

ព្យាករណ៍ឧតុនិយមប្រកាសថា ឱកាសភ្លៀងធ្លាក់នៅរាជធានីភ្នំពេញគឺ \(65\%\) ៖

  1. រកប្រូបាបដែលគ្មានភ្លៀងធ្លាក់គិតជាភាគរយ

  2. សរសេរប្រូបាបគ្មានភ្លៀងធ្លាក់ជាប្រភាគសម្រួល

មើលដំណោះស្រាយ

  • \(P(\) គ្មានភ្លៀង \() = 100\% - 65\% = 35\%\)

  • ជាប្រភាគ ៖ \(\frac{35}{100} = \frac{7}{20}\)

៤២លំហាត់ទី ៤២

បុគ្គលិកម្នាក់ជិះម៉ូតូទៅធ្វើការ។ ប្រូបាបដែលគាត់ជួបភ្លើងក្រហមនៅស្ដុបគឺ \(0.35\) ៖

  1. រកប្រូបាបដែលគាត់មិនជួបភ្លើងក្រហម

  2. បើគាត់ធ្វើដំណើរ ១០០ ថ្ងៃ រំពឹងថានឹងជួបភ្លើងក្រហមប៉ុន្មានថ្ងៃ?

មើលដំណោះស្រាយ

  • \(P = 1 - 0.35 = 0.65\)

  • រំពឹងជួប ៖ \(100 \times 0.35 = 35\) ថ្ងៃ

៤៣លំហាត់ទី ៤៣

ក្នុងថង់មួយមានបាល់ក្រហម ៤, បៃតង ៦, លឿង ២។ គេចាប់បាល់មួយ ៖

  1. គណនាប្រូបាបចាប់បានបាល់ក្រហម ឬបៃតង

  2. គណនាប្រូបាបចាប់បានបាល់មិនមែនលឿង

មើលដំណោះស្រាយ

សរុប ១២ គ្រាប់ ៖

  • \(P(\) ក្រហម ឬ បៃតង \() = \frac{10}{12} = \frac{5}{6}\)

  • \(P(\) មិនមែនលឿង \() = 1 - \frac{2}{12} = \frac{5}{6}\)

៤៤លំហាត់ទី ៤៤

គេមានបៀមួយហ៊ូ (៥២ សន្លឹក)។ គេដកបៀមួយសន្លឹកដោយចៃដន្យ ៖

  1. គណនាប្រូបាបដកបានសន្លឹកអាត់ (Ace)

  2. គណនាប្រូបាបដកបានសន្លឹកពណ៌ក្រហម (បេះដូង ឬការ៉ូ)

មើលដំណោះស្រាយ

បៀ ៥២ សន្លឹក ៖

  • \(P(\) អាត់ \() = \frac{4}{52} = \frac{1}{13}\)

  • \(P(\) ក្រហម \() = \frac{26}{52} = \frac{1}{2}\)

៤៥លំហាត់ទី ៤៥

យោងតាមបៀ ៥២ សន្លឹកក្នុងលំហាត់ទី ៤៤ ៖

  1. គណនាប្រូបាបដកបានសន្លឹកកូដ (King, Queen, Jack)

  2. គណនាប្រូបាបដកបានសន្លឹកប៊ិច (Spade)

មើលដំណោះស្រាយ

  • \(P(\) កូដ J,Q,K \() = \frac{12}{52} = \frac{3}{13}\)

  • \(P(\) ប៊ិច \() = \frac{13}{52} = \frac{1}{4}\)

៤៦លំហាត់ទី ៤៦

សិស្សម្នាក់ឆ្លើយសំណួរពហុជ្រើសរើស (MCQ) ដែលមាន ៤ ជម្រើសដោយគ្រាន់តែស្មាន ៖

  1. គណនាប្រូបាបដែលសិស្សនោះឆ្លើយត្រូវ

  2. គណនាប្រូបាបដែលសិស្សនោះឆ្លើយខុស

មើលដំណោះស្រាយ

MCQ ៤ ជម្រើស ៖

  • \(P(\) ត្រូវ \() = \frac{1}{4} = 25\%\)

  • \(P(\) ខុស \() = \frac{3}{4} = 75\%\)

៤៧លំហាត់ទី ៤៧

កាក់មួយមិនស្មើដៃ (Biased coin) មានប្រូបាបចេញខាងរូប \(P(\) រូប \() = 0.6\) ៖

  1. រកប្រូបាបចេញខាងលេខ \(P(\) លេខ \()\)

  2. បើបោះកាក់នេះ \(50\) ដង រំពឹងថានឹងចេញខាងលេខប៉ុន្មានដង?

មើលដំណោះស្រាយ

  • \(P(\) លេខ \() = 1 - 0.6 = 0.4\)

  • រំពឹងចេញលេខ ៖ \(50 \times 0.4 = 20\) ដង

៤៨លំហាត់ទី ៤៨

គ្រូពេទ្យម្នាក់ធ្វើរោគវិនិច្ឆ័យដោយមានអត្រាត្រឹមត្រូវ \(95\%\) ៖

  1. រកប្រូបាបដែលការធ្វើរោគវិនិច្ឆ័យអាចមានកំហុស

  2. ក្នុងចំណោមអ្នកជំងឺ \(200\) នាក់ រំពឹងថានឹងធ្វើរោគវិនិច្ឆ័យត្រូវប៉ុន្មាននាក់?

មើលដំណោះស្រាយ

  • \(P(\) កំហុស \() = 100\% - 95\% = 5\%\)

  • រំពឹងត្រូវ ៖ \(200 \times 0.95 = 190\) នាក់

៤៩លំហាត់ទី ៤៩

ធុងមួយមានបាល់ពណ៌ក្រហម និងសសរុប ៥០ គ្រាប់។ ប្រូបាបចាប់បានបាល់ក្រហមគឺ \(0.28\) ៖

  1. គណនាចំនួនបាល់ពណ៌ក្រហមក្នុងធុង

  2. គណនាចំនួនបាល់ពណ៌សក្នុងធុង

មើលដំណោះស្រាយ

  • បាល់ក្រហម ៖ \(50 \times 0.28 = 14\) គ្រាប់

  • បាល់ស ៖ \(50 - 14 = 36\) គ្រាប់

៥០លំហាត់ទី ៥០

គេបង្វិលថាសព្រួញមួយដែលមាន ៣ ពណ៌ ៖ ផ្ទៃក្រហមស្មើនឹង \(\frac{1}{2}\) នៃថាស, ផ្ទៃខៀវស្មើនឹង \(\frac{1}{3}\) នៃថាស និងនៅសល់ជាផ្ទៃលឿង ៖

  1. គណនាប្រូបាបដែលព្រួញចង្អុលចំផ្ទៃពណ៌លឿង

  2. បើបង្វិល ៦០ ដង រំពឹងថាព្រួញចង្អុលចំផ្ទៃពណ៌ខៀវប៉ុន្មានដង?

មើលដំណោះស្រាយ

  • \(P(\) លឿង \() = 1 - \left(\frac{1}{2} + \frac{1}{3}\right) = \frac{1}{6}\)

  • រំពឹងចេញខៀវ ៖ \(60 \times \frac{1}{3} = 20\) ដង

សំណួរពហុជ្រើសរើស
