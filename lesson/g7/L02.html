មេរៀនទាំងអស់
ប្រវត្តិនៃទ្រឹស្ដីតួចែក និងចំនួនបឋម

ទ្រឹស្ដីចំនួន (Number Theory) គឺជាផ្នែកមួយដ៏ចំណាស់ និងបរិសុទ្ធបំផុតនៃគណិតវិទ្យា ដែលត្រូវបានគេប្រសិទ្ធនាមថា "មហាក្សត្រីនៃគណិតវិទ្យា" (Queen of Mathematics)៖

  • Pythagoras (៥៧០–៤៩៥ មុន គ.ស.)៖ គណិតវិទូក្រិកបុរាណ និងសាលារបស់គាត់បានចាប់ផ្ដើមចាត់ថ្នាក់ចំនួនជាចំនួនគូ ចំនួនសេស និងបានរកឃើញ "ចំនួនល្អឥតខ្ចោះ" (Perfect Numbers) ដូចជាលេខ \(6\) (\(1+2+3=6\)) និងលេខ \(28\) (\(1+2+4+7+14=28\)) ដែលស្មើនឹងផលបូកនៃតួចែកពិតរបស់វា។

  • Euclid នៃអាឡិចសង់ទ្រី (ប្រហែល ៣០០ មុន គ.ស.)៖ នៅក្នុងសៀវភៅដ៏ល្បីល្បាញ "Elements" (ក្បាលទី ៧ ដល់ ៩) អឺគ្លីដបានបង្កើត ទ្រឹស្ដីបទគ្រឹះនៃនព្វន្ត (Fundamental Theorem of Arithmetic) ដែលបញ្ជាក់ថា "គ្រប់ចំនួនគត់ធំជាង \(1\) អាចបំបែកជាផលគុណកត្តាបឋមបានតែមួយគត់"។ គាត់ក៏បានបង្កើត ក្បួនដោះស្រាយអឺគ្លីដ (Euclidean Algorithm) ដើម្បីរកតួចែករួមធំបំផុត (GCD) ដែលនៅតែជាក្បួនគណនាលឿនបំផុតរហូតដល់សព្វថ្ងៃ។

  • Eratosthenes (២៧៦–១៩៤ មុន គ.ស.)៖ ប្រធានបណ្ណាល័យអាឡិចសង់ទ្រី បានបង្កើតវិធីសាស្ត្រចម្រោះរកចំនួនបឋមដ៏ល្បី ហៅថា "រនាមអេរ៉ាតូស្ទែន" (Sieve of Eratosthenes)។

  • សារសំខាន់ក្នុងយុគសម័យឌីជីថល៖ ចំនួនបឋមដ៏ធំៗដែលមានរាប់លានខ្ទង់ គឺជាឆ្អឹងខ្នងនៃប្រព័ន្ធសម្ងាត់ឌីជីថលទំនើប (RSA Cryptography) ដែលការពារសុវត្ថិភាពទិន្នន័យអ៊ីនធឺណិត ប្រតិបត្តិការធនាគារអេឡិចត្រូនិក និងបច្ចេកវិទ្យា Blockchain នាពេលបច្ចុប្បន្ន។

ពហុគុណរួមតូចបំផុត (Least Common Multiple - LCM ឬ PPCM) នៃពីរ ឬច្រើនចំនួនមិនសូន្យ គឺជាចំនួនគត់ធម្មជាតិតូចជាងគេបំផុត (ក្រៅពីសូន្យ) ដែលជាពហុគុណរួមនៃចំនួនទាំងនោះ។

វិធីរកពហុគុណរួមតូចបំផុត

ដើម្បីរកពហុគុណរួមតូចបំផុតនៃពីរ ឬច្រើនចំនួន៖

  1. បំបែកចំនួននីមួយៗជាផលគុណកត្តាបឋម។

  2. ជ្រើសរើសយក គ្រប់កត្តាទាំងអស់ (ទាំងកត្តារួម និងកត្តាមិនរួម) ដោយយក និទស្សន្តធំជាងគេ រួចគុណបញ្ចូលគ្នា។

ចំពោះពីរចំនួនគត់ធម្មជាតិ \(a\) និង \(b\) គេបាន៖

\[a \times b = PGCD(a, b) \times PPCM(a, b)\]

ឧទាហរណ៍

រកពហុគុណរួមតូចបំផុតនៃ \(6\) និង \(8\)។

ដំណោះស្រាយ

ដំណោះស្រាយលម្អិត៖

  • បំបែកជាផលគុណកត្តាបឋម៖

    \[\begin{aligned} 6 &= 2 \times 3 \\ 8 &= 2^3 \end{aligned}\]

  • ជ្រើសរើសគ្រប់កត្តាដោយយកនិទស្សន្តធំជាងគេ៖

    • កត្តា \(2\) ៖ និទស្សន្តធំជាងគេគឺ \(3 \implies 2^3 = 8\)

    • កត្តា \(3\) ៖ និទស្សន្តធំជាងគេគឺ \(1 \implies 3^1 = 3\)

  • គុណបញ្ចូលគ្នា៖

    \[PPCM(6, 8) = 2^3 \times 3 = 8 \times 3 = 24\]

ដូចនេះ \(PPCM(6, 8) = 24\)។

៣៩លំហាត់ទី ៣៩

គេមានកន្សោម \(A = n^2 + n\) ចំពោះគ្រប់ចំនួនគត់ធម្មជាតិ \(n\)។ បង្ហាញថា \(A\) តែងតែជាចំនួនគត់គូ (ចែកដាច់នឹង \(2\)) ជានិច្ច។

មើលដំណោះស្រាយ

បង្ហាញថា \(A = n^2 + n\) ជាចំនួនគូជានិច្ច ៖

\[\begin{aligned} A &= n(n + 1) \end{aligned}\]
ដោយសារ \(n\) និង \(n + 1\) ជាពីរចំនួនគត់ធម្មជាតិតគ្នា នោះក្នុងចំណោមពីរចំនួននេះ ត្រូវតែមានចំនួនមួយជាចំនួនគូជានិច្ច។
ផលគុណនៃចំនួនគត់ណាមួយជាមួយចំនួនគូ តែងតែជាចំនួនគូ។
ដូចនេះ \(A = n(n+1)\) តែងតែជាចំនួនគត់គូ (ចែកដាច់នឹង \(2\)) ជានិច្ច។

៤០លំហាត់ទី ៤០

បង្ហាញថាផលគុណនៃបីចំនួនគត់ធម្មជាតិតគ្នាតែងតែចែកដាច់នឹង \(6\) ជានិច្ច។

មើលដំណោះស្រាយ

បង្ហាញថាផលគុណបីចំនួនគត់តគ្នាចែកដាច់នឹង \(6\) ជានិច្ច ៖ តាងផលគុណដោយ \(P = n(n+1)(n+2)\)។

  • ក្នុងចំណោមបីចំនួនតគ្នា មានយ៉ាងតិចចំនួនមួយជាចំនួនគូ \(\implies P\) ចែកដាច់នឹង \(2\)។

  • ក្នុងចំណោមបីចំនួនតគ្នា មានមួយចែកដាច់នឹង \(3\) \(\implies P\) ចែកដាច់នឹង \(3\)។

  • ដោយសារ \(PGCD(2, 3) = 1\) នោះ \(P\) ចែកដាច់នឹង \(2 \times 3 = 6\) ជានិច្ច។

៤១លំហាត់ទី ៤១

រកគ្រប់ចំនួនគត់ធម្មជាតិ \(n\) ដើម្បីឱ្យកន្សោម \(\dfrac{n + 6}{n}\) ជាចំនួនគត់ធម្មជាតិ។

មើលដំណោះស្រាយ

រកចំនួន \(n \in \mathbb{N}\) ដើម្បីឱ្យ \(\dfrac{n + 6}{n} \in \mathbb{N}\) ៖

\[\begin{aligned} \frac{n + 6}{n} &= 1 + \frac{6}{n} \quad{} (n \neq 0) \end{aligned}\]
ដើម្បីឱ្យកន្សោមនេះជាចំនួនគត់ធម្មជាតិ លុះត្រាតែ \(n\) ជាតួចែកនៃ \(6\)។
ដូចនេះ \(\boxed{n \in \{1, 2, 3, 6\}}\)។

៤២លំហាត់ទី ៤២

រកគ្រប់ចំនួនគត់ធម្មជាតិ \(n\) ដើម្បីឱ្យកន្សោម \(\dfrac{2n + 15}{n + 1}\) ជាចំនួនគត់ធម្មជាតិ។

មើលដំណោះស្រាយ

រកចំនួន \(n \in \mathbb{N}\) ដើម្បីឱ្យ \(\dfrac{2n + 15}{n + 1} \in \mathbb{N}\) ៖

\[\begin{aligned} \frac{2n + 15}{n + 1} &= \frac{2(n + 1) + 13}{n + 1} = 2 + \frac{13}{n + 1} \end{aligned}\]
កន្សោមជាចំនួនគត់ លុះត្រាតែ \(n + 1\) ជាតួចែកនៃ \(13\)។
ព្រោះ \(13\) ជាចំនួនបឋម \(\implies n + 1 \in \{1, 13\}\) ៖

  • \(n + 1 = 1 \implies n = 0\)

  • \(n + 1 = 13 \implies n = 12\)

ដូចនេះ \(\boxed{n \in \{0, 12\}}\)។

៤៣លំហាត់ទី ៤៣

រកគ្រប់គូនៃចំនួនគត់ធម្មជាតិ \((a, b)\) ដែលផ្ទៀងផ្ទាត់លក្ខខណ្ឌ ៖ \(PGCD(a, b) = 6\) និង \(a + b = 36\)។

មើលដំណោះស្រាយ

រក \((a, b)\) ដែល \(PGCD(a, b) = 6\) និង \(a + b = 36\) ៖ តាង \(a = 6a', \; b = 6b'\) ដែល \(PGCD(a', b') = 1\)។

\[\begin{aligned} 6a' + 6b' &= 36 \implies a' + b' = 6 \end{aligned}\]
គូ \((a', b')\) បឋមរវាងគ្នាដែលមានផលបូក \(6\) គឺ \((1, 5)\) និង \((5, 1)\)។
ដូចនេះ \(\boxed{(a, b) \in \{(6, 30), (30, 6)\}}\)។

៤៤លំហាត់ទី ៤៤

រកគ្រប់គូនៃចំនួនគត់ធម្មជាតិ \((a, b)\) ដែលផ្ទៀងផ្ទាត់លក្ខខណ្ឌ ៖ \(PGCD(a, b) = 5\) និង \(a \times b = 150\)។

មើលដំណោះស្រាយ

រក \((a, b)\) ដែល \(PGCD(a, b) = 5\) និង \(a \times b = 150\) ៖ តាង \(a = 5a', \; b = 5b'\) ដែល \(PGCD(a', b') = 1\)។

\[\begin{aligned} 5a' \times 5b' &= 150 \implies 25a'b' = 150 \implies a'b' = 6 \end{aligned}\]
គូ \((a', b')\) បឋមរវាងគ្នាដែលមានផលគុណ \(6\) គឺ \((1, 6), (2, 3), (3, 2), (6, 1)\)។
ដូចនេះ \(\boxed{(a, b) \in \{(5, 30), (10, 15), (15, 10), (30, 5)\}}\)។

៤៥លំហាត់ទី ៤៥

រកចំនួនគត់ធម្មជាតិតូចបំផុតដែលមានតួចែកចំនួន ១២ តួ។

មើលដំណោះស្រាយ

រកចំនួនតូចបំផុតដែលមានតួចែកចំនួន \(12\) តួ ៖ តាមរូបមន្តចំនួនតួចែក \((a_1 + 1)(a_2 + 1)\dots = 12\) ៖

  • \(12 = 12 \implies N = 2^{11} = 2048\)

  • \(12 = 6 \times 2 \implies N = 2^5 \times 3^1 = 96\)

  • \(12 = 4 \times 3 \implies N = 2^3 \times 3^2 = 72\)

  • \(12 = 3 \times 2 \times 2 \implies N = 2^2 \times 3^1 \times 5^1 = 60\)

តម្លៃតូចបំផុតគឺ \(\boxed{60}\)។

៤៦លំហាត់ទី ៤៦

គេឱ្យចំនួន \(N = 2^x \times 3^y\) ដែល \(x, y \in \mathbb{N}^*\)។ បើចំនួន \(N\) មានតួចែកសរុបចំនួន \(8\) តួ ហើយ \(N\) ចែកដាច់នឹង \(6\) រកតម្លៃនៃ \(N\)។

មើលដំណោះស្រាយ

គេឱ្យ \(N = 2^x \times 3^y\) មានតួចែក \(8\) តួ ហើយ \(N\) ចែកដាច់នឹង \(6\) ៖

  • ចំនួនតួចែក ៖ \((x + 1)(y + 1) = 8\)

  • ព្រោះ \(x, y \ge 1 \implies (x+1, y+1) \in \{(2, 4), (4, 2)\}\)
    \(\implies (x, y) \in \{(1, 3), (3, 1)\}\)

  • បើ \((x, y) = (1, 3) \implies N = 2^1 \times 3^3 = \mathbf{54}\)

  • បើ \((x, y) = (3, 1) \implies N = 2^3 \times 3^1 = \mathbf{24}\)

ដូចនេះ \(N = 24\) ឬ \(N = 54\)។

៤៧លំហាត់ទី ៤៧

បង្ហាញថាបើ \(p\) ជាចំនួនបឋមធំជាង \(3\) នោះ \(p^2 - 1\) តែងតែចែកដាច់នឹង \(24\) ជានិច្ច។

មើលដំណោះស្រាយ

បង្ហាញថាបើ \(p > 3\) ជាចំនួនបឋម នោះ \(p^2 - 1\) ចែកដាច់នឹង \(24\) ៖

\[\begin{aligned} p^2 - 1 &= (p - 1)(p + 1) \end{aligned}\]

  • \(p\) ជាចំនួនសេស \(\implies p - 1\) និង \(p + 1\) ជាពីរចំនួនគូជាប់គ្នា នាំឱ្យផលគុណចែកដាច់នឹង \(2 \times 4 = 8\)។

  • ក្នុងចំណោម \(p-1, p, p+1\) មានមួយចែកដាច់នឹង \(3\) តែ \(p\) ជាចំនួនបឋមធំជាង \(3\) នាំឱ្យ \((p-1)(p+1)\) ចែកដាច់នឹង \(3\)។

  • ដោយសារ \(PGCD(8, 3) = 1\) នោះ \(p^2 - 1\) ចែកដាច់នឹង \(8 \times 3 = 24\) ជានិច្ច។

៤៨លំហាត់ទី ៤៨

រកចំនួនបឋម \(p\) ទាំងអស់ដែលធ្វើឱ្យ \(p + 10\) និង \(p + 14\) សុទ្ធតែជាចំនួនបឋម។

មើលដំណោះស្រាយ

រកចំនួនបឋម \(p\) ដែលធ្វើឱ្យ \(p + 10\) និង \(p + 14\) ជាចំនួនបឋម ៖

  • បើ \(p = 2 \implies p + 10 = 12\) (មិនបឋម)

  • បើ \(p = 3 \implies p + 10 = 13\) (បឋម), \(p + 14 = 17\) (បឋម) \(\implies p = 3\) ផ្ទៀងផ្ទាត់។

  • បើ \(p > 3 \implies p = 3k + 1\) ឬ \(p = 3k + 2\) ៖

    • \(p = 3k + 1 \implies p + 14 = 3k + 15 = 3(k+5) > 3\) ចែកដាច់នឹង \(3\) (មិនបឋម)

    • \(p = 3k + 2 \implies p + 10 = 3k + 12 = 3(k+4) > 3\) ចែកដាច់នឹង \(3\) (មិនបឋម)

ដូចនេះ ចំនួនបឋមដែលត្រូវរកគឺ \(\boxed{p = 3}\)។

៤៩លំហាត់ទី ៤៩

បង្ហាញថាកន្សោម \(B = 5^{2n+1} + 2^{2n+1}\) ចែកដាច់នឹង \(7\) ចំពោះគ្រប់ចំនួនគត់ធម្មជាតិ \(n\)។

មើលដំណោះស្រាយ

បង្ហាញថា \(B = 5^{2n+1} + 2^{2n+1}\) ចែកដាច់នឹង \(7\) ចំពោះគ្រប់ \(n \in \mathbb{N}\) ៖ តាមរូបមន្តឯកសណ្ឋាន ចំពោះស្វ័យគុណសេស \(m = 2n + 1\) ៖

\[\begin{aligned} a^m + b^m &= (a + b)(a^{m-1} - a^{m-2}b + \dots + b^{m-1}) \end{aligned}\]
ជំនួស \(a = 5, \; b = 2\) ៖
\[\begin{aligned} 5^{2n+1} + 2^{2n+1} &= (5 + 2) \cdot Q = 7 \cdot Q \quad{} (Q \in \mathbb{N}) \end{aligned}\]
ដោយសារកន្សោមមានកត្តា \(7\) នោះ \(B\) តែងតែចែកដាច់នឹង \(7\) ជានិច្ច។

៥០លំហាត់ទី ៥០

គេសរសេរចំនួន \(A = 1234567891011\dots 99100\) (ដោយយកចំនួនគត់ពី \(1\) ដល់ \(100\) មកតម្រៀបជាប់គ្នា)។

  1. តើចំនួន \(A\) មានប៉ុន្មានខ្ទង់?

  2. តើចំនួន \(A\) ចែកដាច់នឹង \(3\) ឬទេ? ចែកដាច់នឹង \(9\) ឬទេ?

មើលដំណោះស្រាយ

គេសរសេរចំនួន \(A = 1234567891011\dots 99100\) ៖

  • ចំនួនខ្ទង់នៃចំនួន \(A\) ៖
    – ពី \(1\) ដល់ \(9\) មាន ៖ \(9 \times 1 = 9\) ខ្ទង់
    – ពី \(10\) ដល់ \(99\) មាន ៖ \(90 \times 2 = 180\) ខ្ទង់
    – ចំនួន \(100\) មាន ៖ \(3\) ខ្ទង់
    \(\implies\) សរុបមាន \(9 + 180 + 3 = \mathbf{192}\) ខ្ទង់។

  • ភាពចែកដាច់នឹង \(3\) និង \(9\) ៖
    ផលបូកលេខខ្ទង់នៃ \(A\) គឺ \(S = 450 + 450 + 1 = 901\)។
    ដោយសារ \(901\) មានផលបូកលេខខ្ទង់ \(9+0+1 = 10\) មិនចែកដាច់នឹង \(3\) និងមិនចែកដាច់នឹង \(9\) ទេ
    \(\implies A\) មិនចែកដាច់នឹង \(3\) ឡើយ ហើយក៏មិនចែកដាច់នឹង \(9\) ដែរ។
