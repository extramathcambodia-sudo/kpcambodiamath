មេរៀនទាំងអស់
ប្រវត្តិនៃវិសមីការ និងអ្នកប្រាជ្ញ Cauchy-Schwarz

គំនិតនៃវិសមីការ (Inequalities) បានកើតឡើងស្របគ្នាជាមួយនឹងការវិវត្តនៃសមីការ ដើម្បីដោះស្រាយបញ្ហាដែនកំណត់ ការប៉ាន់ប្រមាណកំហុស និងការបង្កើនប្រសិទ្ធភាពធនធាន។ និមិត្តសញ្ញាធំជាង (\(>\)) និងតូចជាង (\(<\)) ត្រូវបានណែនាំជាលើកដំបូងដោយគណិតវិទូជនជាតិអង់គ្លេស ថូម៉ាស ហារីយ៉ូត (Thomas Harriot, ១៥៦០–១៦២១) ក្នុងសៀវភៅដែលបោះពុម្ពក្រោយមរណភាពរបស់លោកក្នុងឆ្នាំ ១៦៣១។

នៅសតវត្សទី ១៩ វិសមីការបានក្លាយជាឧបករណ៍គ្រឹះមិនអាចខ្វះបានក្នុងការវិភាគគណិតវិទ្យាទំនើប។ គណិតវិទូបារាំង អូហ្គីស្ទីន-ល្វី កូស៊ី (Augustin-Louis Cauchy, ១៧៨៩–១៨៥៧), គណិតវិទូអាល្លឺម៉ង់ Hermann Schwarz និងគណិតវិទូរុស្ស៊ី Viktor Bunyakovsky បានបង្កើតឡើងនូវ «វិសមីការកូស៊ី-ស្វាស (Cauchy-Schwarz Inequality)» ដ៏ល្បីល្បាញ ៖

\[\left(\sum_{i=1}^n a_i b_i\right)^2 \le \left(\sum_{i=1}^n a_i^2\right) \left(\sum_{i=1}^n b_i^2\right)\]
ដែលជាវិសមីការគ្រឹះបំផុតក្នុងពិភពធរណីមាត្រ ពីជគណិតលីនេអ៊ែរ រូបវិទ្យាកង់ទិច និងទ្រឹស្ដីប្រូបាប៊ីលីតេ។

ក្នុងប្រវត្តិសាស្ត្រខ្មែរ វិស្វករធារាសាស្ត្រនាសម័យអង្គរត្រូវធានាឱ្យបាននូវវិសមីការជាក់ស្ដែង ៖ កម្ពស់ទឹកក្នុងបារាយណ៍ត្រូវស្ថិតក្នុងចន្លោះសុវត្ថិភាព \(h_{\min} \le h \le h_{\max}\) ដើម្បីកុំឱ្យស្ងួតហួតហែងនៅរដូវប្រាំង និងកុំឱ្យបាក់ទំនប់ដោយសម្ពាធទឹកជន់នារដូវវស្សា។

សញ្ញាណ និងលក្ខណៈនៃវិសមីការ

និយមន័យវិសមីការ

វិសមីការ គឺជាប្រយោគគណិតវិទ្យាដែលបង្ហាញពីទំនាក់ទំនងមិនស្មើគ្នារវាងកន្សោមពីរ ដោយប្រើប្រាស់សញ្ញា \(<, \le, >, \ge\)។

លក្ខណៈគ្រឹះនៃវិសមីការ

ចំពោះគ្រប់ចំនួនពិត \(a, b, c\) ៖

  • លក្ខណៈបូក ៖ បើ \(a < b\) នោះ \(a + c < b + c\)។

  • លក្ខណៈគុណនឹងចំនួនវិជ្ជមាន ៖ បើ \(a < b\) និង \(c > 0\) នោះ \(ac < bc\)។

  • លក្ខណៈគុណនឹងចំនួនអវិជ្ជមាន ៖ បើ \(a < b\) និង \(c < 0\) នោះ \(ac > bc\) (ត្រូវត្រឡប់ទិសដៅវិសមីការ)។

  • លក្ខណៈឆ្លង ៖ បើ \(a < b\) និង \(b < c\) នោះ \(a < c\)។

សញ្ញានៃទ្វេធាដឺក្រេទីមួយ \(ax + b\)

ទ្វេធា \(P(x) = ax + b\) (\(a \neq 0\)) មានឫស \(x_0 = -\dfrac{b}{a}\)។ តារាងសញ្ញានៃទ្វេធា ៖

\(x\) \(-\infty\) \(-\dfrac{b}{a}\) \(+\infty\)
\(ax + b\) សញ្ញាផ្ទុយ \(a\) \(0\) សញ្ញាដូច \(a\)

សញ្ញានៃត្រីធាដឺក្រេទីពីរ \(ax^2 + bx + c\)

ចំពោះត្រីធា \(f(x) = ax^2 + bx + c\) (\(a \neq 0\)) ដែលមានឌីសគ្រីមីណង់ \(\Delta = b^2 - 4ac\) ៖

  • បើ \(\Delta < 0\) ៖ \(f(x)\) មានសញ្ញាដូច \(a\) ជានិច្ច ចំពោះគ្រប់ \(x \in \mathbb{R}\)។

  • បើ \(\Delta = 0\) ៖ \(f(x)\) មានសញ្ញាដូច \(a\) គ្រប់ \(x \neq -\dfrac{b}{2a}\) ហើយស្មើ \(0\) ត្រង់ \(x = -\dfrac{b}{2a}\)។

  • បើ \(\Delta > 0\) ៖ \(f(x)\) មានឫសពីរ \(x_1 < x_2\)។ តារាងសញ្ញា ៖

\(x\) \(-\infty\) \(x_1\) \(x_2\) \(+\infty\)
\(ax^2+bx+c\) សញ្ញាដូច \(a\) \(0\) សញ្ញាផ្ទុយ \(a\) \(0\) សញ្ញាដូច \(a\)

វិធានចងចាំ ៖ «ក្នុងចន្លោះឫសសញ្ញាផ្ទុយ \(a\), ក្រៅចន្លោះឫសសញ្ញាដូច \(a\)»។

វិសមីការសនិទាន និងវិសមីការតម្លៃដាច់ខាត

  • វិសមីការសនិទាន ៖ \(\dfrac{P(x)}{Q(x)} \ge 0\) ដោះស្រាយដោយសង់តារាងសញ្ញារួមនៃកត្តាទាំងអស់ (ដោយដាក់លក្ខខណ្ឌភាគបែង \(Q(x) \neq 0\))។

  • វិសមីការតម្លៃដាច់ខាត ៖

    • \(|A| \le B \iff -B \le A \le B\) (លក្ខខណ្ឌ \(B \ge 0\))

    • \(|A| \ge B \iff A \ge B \quad{} \) ឬ \( \quad{} A \le -B\)

    • \(|A| \le |B| \iff A^2 \le B^2 \iff (A-B)(A+B) \le 0\)

លំហាត់អនុវត្តន៍

១លំហាត់ទី ១

ដោះស្រាយវិសមីការដឺក្រេទីមួយមានមួយអញ្ញាត ៖

  1. \(2x - 5 > 3\)

  2. \(3x + 4 \le 19\)

  3. \(-2x + 7 \ge 1\)

  4. \(5 - 4x < 17\)

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការដឺក្រេទីមួយមានមួយអញ្ញាត ៖
ក.  \(2x - 5 > 3\)
\(\iff 2x > 3 + 5 \iff 2x > 8 \iff x > \dfrac{8}{2} = 4\)
ដូចនេះ សំណុំចម្លើយគឺ \(S = (4, +\infty)\)។
ខ.  \(3x + 4 \le 19\)
\(\iff 3x \le 19 - 4 \iff 3x \le 15 \iff x \le \dfrac{15}{3} = 5\)
ដូចនេះ សំណុំចម្លើយគឺ \(S = (-\infty, 5]\)។
គ.  \(-2x + 7 \ge 1\)
\(\iff -2x \ge 1 - 7 \iff -2x \ge -6\)
ចែកអង្គទាំងសងខាងនឹង \(-2 < 0\) (ប្តូរសញ្ញាវិសមភាព) ៖
\(\iff x \le \dfrac{-6}{-2} = 3\)
ដូចនេះ សំណុំចម្លើយគឺ \(S = (-\infty, 3]\)។
ឃ.  \(5 - 4x < 17\)
\(\iff -4x < 17 - 5 \iff -4x < 12\)
ចែកអង្គទាំងសងខាងនឹង \(-4 < 0\) (ប្តូរសញ្ញាវិសមភាព) ៖
\(\iff x > \dfrac{12}{-4} = -3\)
ដូចនេះ សំណុំចម្លើយគឺ \(S = (-3, +\infty)\)។

២លំហាត់ទី ២

ដោះស្រាយវិសមីការ និងតាងចម្លើយលើបន្ទាត់ចំនួន ៖

  1. \(3(x - 2) \le 2(x + 1) + 4\)

  2. \(4(2x - 1) - 3(x + 2) > 5\)

  3. \(\dfrac{x - 1}{2} - \dfrac{x + 2}{3} \ge 1\)

  4. \(\dfrac{2x + 1}{4} - \dfrac{3x - 1}{2} < \dfrac{1}{2}\)

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ និងតាងចម្លើយលើបន្ទាត់ចំនួន ៖
ក.  \(3(x - 2) \le 2(x + 1) + 4\)
\(\iff 3x - 6 \le 2x + 2 + 4 \iff 3x - 6 \le 2x + 6\)
\(\iff 3x - 2x \le 6 + 6 \iff x \le 12\)
ចម្លើយជាចន្លោះ ៖ \(x \in (-\infty, 12]\)។
ខ.  \(4(2x - 1) - 3(x + 2) > 5\)
\(\iff 8x - 4 - 3x - 6 > 5 \iff 5x - 10 > 5\)
\(\iff 5x > 15 \iff x > 3\)
ចម្លើយជាចន្លោះ ៖ \(x \in (3, +\infty)\)។
គ.  \(\dfrac{x - 1}{2} - \dfrac{x + 2}{3} \ge 1\)
តម្រូវភាគបែងរួម \(6\) ៖
\(\iff \dfrac{3(x - 1) - 2(x + 2)}{6} \ge \dfrac{6}{6}\)
\(\iff 3x - 3 - 2x - 4 \ge 6 \iff x - 7 \ge 6 \iff x \ge 13\)
ចម្លើយជាចន្លោះ ៖ \(x \in [13, +\infty)\)។
ឃ.  \(\dfrac{2x + 1}{4} - \dfrac{3x - 1}{2} < \dfrac{1}{2}\)
តម្រូវភាគបែងរួម \(4\) ៖
\(\iff (2x + 1) - 2(3x - 1) < 2\)
\(\iff 2x + 1 - 6x + 2 < 2 \iff -4x + 3 < 2\)
\(\iff -4x < -1 \iff x > \dfrac{1}{4}\)
ចម្លើយជាចន្លោះ ៖ \(x \in \left(\dfrac{1}{4}, +\infty\right)\)។

៣លំហាត់ទី ៣

ដោះស្រាយវិសមីការ ៖

  1. \(\dfrac{2x-3}{5} \ge \dfrac{x+1}{2} - 1\)

  2. \(x - \dfrac{3x-1}{4} \le 2 + \dfrac{x}{3}\)

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ ៖
ក.  \(\dfrac{2x-3}{5} \ge \dfrac{x+1}{2} - 1\)
គុណអង្គទាំងសងខាងនឹង \(10\) ៖
\(2(2x - 3) \ge 5(x + 1) - 10\)
\(\iff 4x - 6 \ge 5x + 5 - 10 \iff 4x - 6 \ge 5x - 5\)
\(\iff 4x - 5x \ge -5 + 6 \iff -x \ge 1 \iff x \le -1\)
ដូចនេះ \(x \in (-\infty, -1]\)។
ខ.  \(x - \dfrac{3x-1}{4} \le 2 + \dfrac{x}{3}\)
គុណអង្គទាំងសងខាងនឹង \(12\) ៖
\(12x - 3(3x - 1) \le 24 + 4x\)
\(\iff 12x - 9x + 3 \le 24 + 4x \iff 3x + 3 \le 24 + 4x\)
\(\iff 3x - 4x \le 24 - 3 \iff -x \le 21 \iff x \ge -21\)

មើលដំណោះស្រាយ

ក.  \(f(x) = 2x - 6\) ៖
ឫស \(2x - 6 = 0 \iff x = 3\)។ មេគុណ \(a = 2 > 0\)។
- បើ \(x < 3\) នោះ \(f(x) < 0\)
- បើ \(x = 3\) នោះ \(f(x) = 0\)
- បើ \(x > 3\) នោះ \(f(x) > 0\)។
ខ.  \(g(x) = -3x + 12\) ៖
ឫស \(-3x + 12 = 0 \iff x = 4\)។ មេគុណ \(a = -3 < 0\)។
- បើ \(x < 4\) នោះ \(g(x) > 0\)
- បើ \(x = 4\) នោះ \(g(x) = 0\)
- បើ \(x > 4\) នោះ \(g(x) < 0\)។
គ.  \(h(x) = 5x + 10\) ៖
ឫស \(5x + 10 = 0 \iff x = -2\)។ មេគុណ \(a = 5 > 0\)។
- បើ \(x < -2\) នោះ \(h(x) < 0\)
- បើ \(x = -2\) នោះ \(h(x) = 0\)
- បើ \(x > -2\) នោះ \(h(x) > 0\)។
ឃ.  \(k(x) = -4x - 8\) ៖
ឫស \(-4x - 8 = 0 \iff x = -2\)។ មេគុណ \(a = -4 < 0\)។
- បើ \(x < -2\) នោះ \(k(x) > 0\)

- បើ \(x > -2\) នោះ \(k(x) < 0\)។

មើលដំណោះស្រាយ

សិក្សាសញ្ញានៃកន្សោមផលគុណ ៖
ក.  \(P(x) = (x - 2)(x + 3)\) ៖
ឫសគឺ \(x = -3, x = 2\)។ មេគុណនាំមុខ \(a = 1 > 0\)។
- \(P(x) > 0\) ចំពោះ \(x \in (-\infty, -3) \cup (2, +\infty)\)
- \(P(x) = 0\) ចំពោះ \(x \in \{-3, 2\}\)
- \(P(x) < 0\) ចំពោះ \(x \in (-3, 2)\)។
ខ.  \(Q(x) = (2x - 1)(3 - x)\) ៖
ឫសគឺ \(x = \dfrac{1}{2}, x = 3\)។ មេគុណនាំមុខ \(2(-1) = -2 < 0\)។
- \(Q(x) > 0\) ចំពោះ \(x \in \left(\dfrac{1}{2}, 3\right)\)
- \(Q(x) = 0\) ចំពោះ \(x \in \left\{\dfrac{1}{2}, 3\right\}\)
- \(Q(x) < 0\) ចំពោះ \(x \in \left(-\infty, \dfrac{1}{2}\right) \cup (3, +\infty)\)។
គ.  \(R(x) = x(x - 4)(2x + 6) = 2x(x - 4)(x + 3)\) ៖
ឫសគឺ \(x = -3, x = 0, x = 4\) (តម្រៀបតាមលំដាប់កើន)។
មេគុណនាំមុខ \(2 > 0\) ៖
- \(R(x) < 0\) លើ \((-\infty, -3) \cup (0, 4)\)
- \(R(x) = 0\) ត្រង់ \(x \in \{-3, 0, 4\}\)
- \(R(x) > 0\) លើ \((-3, 0) \cup (4, +\infty)\)។
ឃ.  \(S(x) = (1 - x)(2x + 4)(x - 5) = -2(x - 1)(x + 2)(x - 5)\) ៖
ឫសគឺ \(x = -2, x = 1, x = 5\)។ មេគុណនាំមុខ \(-2 < 0\) ៖
- \(S(x) > 0\) លើ \((-\infty, -2) \cup (1, 5)\)

១០លំហាត់ទី ១០

  2. \(g(x) = -x^2 + 4x - 3\)

  3. \(h(x) = x^2 - 4x + 4\)

  4. \(k(x) = 2x^2 + x + 3\)

មើលដំណោះស្រាយ

សិក្សាសញ្ញានៃត្រីធាដឺក្រេទីពីរ \(f(x) = ax^2 + bx + c\) ៖
ក.  \(f(x) = x^2 - 5x + 6\) ៖
\(\Delta = (-5)^2 - 4(1)(6) = 25 - 24 = 1 > 0\)
សមីការមានឫសពីរ ៖ \(x_1 = 2, x_2 = 3\)។ មេគុណ \(a = 1 > 0\) ៖
- \(f(x) > 0\) លើ \((-\infty, 2) \cup (3, +\infty)\)
- \(f(x) = 0\) ត្រង់ \(x \in \{2, 3\}\)
- \(f(x) < 0\) លើ \((2, 3)\)។
ខ.  \(g(x) = -x^2 + 4x - 3\) ៖
\(\Delta' = 2^2 - (-1)(-3) = 4 - 3 = 1 > 0\)
សមីការមានឫសពីរ ៖ \(x_1 = 1, x_2 = 3\)។ មេគុណ \(a = -1 < 0\) ៖
- \(g(x) > 0\) លើចន្លោះឫស \((1, 3)\)
- \(g(x) = 0\) ត្រង់ \(x \in \{1, 3\}\)
- \(g(x) < 0\) លើ \((-\infty, 1) \cup (3, +\infty)\)។
គ.  \(h(x) = x^2 - 4x + 4 = (x - 2)^2\) ៖
\(\Delta' = (-2)^2 - (1)(4) = 0\)។
- \(h(x) = 0\) ត្រង់ \(x = 2\)
- \(h(x) > 0\) ចំពោះគ្រប់ \(x \ne 2\) (\(x \in \mathbb{R} \setminus \{2\}\))។
ឃ.  \(k(x) = 2x^2 + x + 3\) ៖
\(\Delta = 1^2 - 4(2)(3) = 1 - 24 = -23 < 0\)។
ដោយ \(a = 2 > 0\) និង \(\Delta < 0\) នោះ \(k(x)\) មានសញ្ញាដូច \(a\) ជានិច្ច ៖
\(k(x) > 0\) ចំពោះគ្រប់ \(x \in \mathbb{R}\)។

ខ.  \(x^2 - 2x + 4 \le 0\)
\(\Delta' = (-1)^2 - 1(4) = 1 - 4 = -3 < 0\) និង \(a = 1 > 0\)។
នាំឱ្យ \(x^2 - 2x + 4 > 0\) ចំពោះគ្រប់ \(x \in \mathbb{R}\)។
ដូចនេះ គ្មានតម្លៃ \(x\) ណាធ្វើឱ្យកន្សោម \(\le 0\) ទេ ៖ \(S = \emptyset\)។
គ.  \(-x^2 + 2x - 3 < 0 \iff x^2 - 2x + 3 > 0\)
\(\Delta' = 1 - 3 = -2 < 0\) និង \(a = 1 > 0\)។
ដូចនេះ វិសមីការផ្ទៀងផ្ទាត់គ្រប់ \(x \in \mathbb{R}\) ៖ \(S = \mathbb{R}\)។
ឃ.  \(2x^2 - 3x + 5 \ge 0\)
\(\Delta = (-3)^2 - 4(2)(5) = 9 - 40 = -31 < 0\) និង \(a = 2 > 0\)។
ដូចនេះ វិសមីការផ្ទៀងផ្ទាត់គ្រប់ \(x \in \mathbb{R}\) ៖ \(S = \mathbb{R}\)។

១៤លំហាត់ទី ១៤

ដោះស្រាយវិសមីការ ៖

មើលដំណោះស្រាយ

ដូចនេះ \(x \in (-\infty, -4] \cup [4, +\infty)\)។

ដូចនេះ \(x \in (-\sqrt{7}, \sqrt{7})\)។
គ.  \(4x^2 - 9 \le 0 \iff (2x - 3)(2x + 3) \le 0\)
ឫសគឺ \(x = -\dfrac{3}{2}, x = \dfrac{3}{2}\) ៖
ដូចនេះ \(x \in \left[-\dfrac{3}{2}, \dfrac{3}{2}\right]\)។
ឃ.  \(3x^2 - 5x > 0 \iff x(3x - 5) > 0\)
ឫសគឺ \(x = 0, x = \dfrac{5}{3}\) ៖
ដូចនេះ \(x \in (-\infty, 0) \cup \left(\dfrac{5}{3}, +\infty\right)\)។

១៥លំហាត់ទី ១៥

  2. \(\dfrac{2x + 1}{x - 4} \le 0\)

  3. \(\dfrac{3 - x}{x + 2} \ge 0\)

  4. \(\dfrac{5x - 2}{2 - x} < 0\)

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការសនិទាន ៖
ក.  \(\dfrac{x - 2}{x + 3} > 0\)
លក្ខខណ្ឌភាគបែង ៖ \(x + 3 \ne 0 \iff x \ne -3\)។
សញ្ញានៃប្រភាគដូចគ្នានឹងសញ្ញានៃផលគុណ \((x - 2)(x + 3) > 0\) ៖
ដូចនេះ \(x \in (-\infty, -3) \cup (2, +\infty)\)។
ខ.  \(\dfrac{2x + 1}{x - 4} \le 0\)
លក្ខខណ្ឌ ៖ \(x \ne 4\)។
ភាគយកស្មើ \(0\) ត្រង់ \(x = -\dfrac{1}{2}\)។
សញ្ញាអវិជ្ជមាននៅចន្លោះឫស ៖
ដូចនេះ \(x \in \left[-\dfrac{1}{2}, 4\right)\) (ចំណាំ ៖ \(x = 4\) មិនយកទេព្រោះជាភាគបែង)។
គ.  \(\dfrac{3 - x}{x + 2} \ge 0 \iff \dfrac{x - 3}{x + 2} \le 0\) (គុណនឹង \(-1\))
លក្ខខណ្ឌ ៖ \(x \ne -2\)។
ដូចនេះ \(x \in (-2, 3]\)។
ឃ.  \(\dfrac{5x - 2}{2 - x} < 0 \iff \dfrac{5x - 2}{x - 2} > 0\) (គុណនឹង \(-1\))
លក្ខខណ្ឌ ៖ \(x \ne 2\)។ ឫសភាគយកគឺ \(x = \dfrac{2}{5}\)។
ដូចនេះ \(x \in \left(-\infty, \dfrac{2}{5}\right) \cup (2, +\infty)\)។

១៦លំហាត់ទី ១៦

ដោះស្រាយវិសមីការសនិទាន ៖

  1. \(\dfrac{x^2 - 4}{x + 1} \le 0\)

  2. \(\dfrac{x^2 - 5x + 6}{x - 1} > 0\)

  3. \(\dfrac{x + 3}{x^2 - 9} \ge 0\)

  4. \(\dfrac{2x^2 - x - 1}{x^2 - 4} < 0\)

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការសនិទាន ៖
ក.  \(f(x) = \dfrac{x^2 - 4}{x + 1} \le 0 \iff \dfrac{(x - 2)(x + 2)}{x + 1} \le 0\)
លក្ខខណ្ឌ ៖ \(x \ne -1\)។ ឫសភាគយកគឺ \(x = -2, x = 2\)។

រូបភាពនេះកំពុងរៀបចំ

ដូចនេះ \(x \in (-\infty, -2] \cup (-1, 2]\)។
ខ.  \(\dfrac{x^2 - 5x + 6}{x - 1} > 0 \iff \dfrac{(x - 2)(x - 3)}{x - 1} > 0\)
លក្ខខណ្ឌ ៖ \(x \ne 1\)។ ឫសភាគយកគឺ \(x = 2, x = 3\)។
តម្រៀបឫស ៖ \(1, 2, 3\)។
ដូចនេះ \(x \in (1, 2) \cup (3, +\infty)\)។
គ.  \(\dfrac{x + 3}{x^2 - 9} \ge 0\)
លក្ខខណ្ឌ ៖ \(x^2 - 9 \ne 0 \iff x \ne \pm 3\)។
បំបែកភាគបែង ៖ \(\dfrac{x + 3}{(x + 3)(x - 3)} \ge 0\)
សម្រួលតួ \((x + 3)\) ដោយសារ \(x \ne -3\) ៖
\(\iff \dfrac{1}{x - 3} \ge 0 \iff x - 3 > 0 \iff x > 3\)។
ដូចនេះ \(x \in (3, +\infty)\)។
ឃ.  \(g(x) = \dfrac{2x^2 - x - 1}{x^2 - 4} < 0 \iff \dfrac{(2x + 1)(x - 1)}{(x - 2)(x + 2)} < 0\)
លក្ខខណ្ឌ ៖ \(x \ne \pm 2\)។ ឫសទាំង ៤ តាមលំដាប់ ៖ \(-2, -\dfrac{1}{2}, 1, 2\)។

រូបភាពនេះកំពុងរៀបចំ

ដូចនេះ \(x \in \left(-2, -\dfrac{1}{2}\right) \cup (1, 2)\)។

ដោះស្រាយវិសមីការសនិទាន (បោះអង្គមកម្ខាងរួចតម្រូវភាគបែង) ៖

  1. \(\dfrac{x + 1}{x - 2} \ge 2\)

  2. \(\dfrac{2x - 1}{x + 3} < 1\)

  3. \(\dfrac{1}{x} \le 1\)

  4. \(\dfrac{2}{x - 1} > \dfrac{3}{x + 2}\)

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការសនិទាន ៖
ក.  \(\dfrac{x + 1}{x - 2} \ge 2 \iff \dfrac{x + 1}{x - 2} - 2 \ge 0\)
\(\iff \dfrac{x + 1 - 2(x - 2)}{x - 2} \ge 0 \iff \dfrac{-x + 5}{x - 2} \ge 0\)
\(\iff \dfrac{x - 5}{x - 2} \le 0\) (លក្ខខណ្ឌ \(x \ne 2\))។
ដូចនេះ \(x \in (2, 5]\)។
ខ.  \(\dfrac{2x - 1}{x + 3} < 1 \iff \dfrac{2x - 1}{x + 3} - 1 < 0\)
\(\iff \dfrac{2x - 1 - (x + 3)}{x + 3} < 0 \iff \dfrac{x - 4}{x + 3} < 0\)
(លក្ខខណ្ឌ \(x \ne -3\))។
ដូចនេះ \(x \in (-3, 4)\)។
គ.  \(\dfrac{1}{x} \le 1 \iff \dfrac{1}{x} - 1 \le 0 \iff \dfrac{1 - x}{x} \le 0 \iff \dfrac{x - 1}{x} \ge 0\)
លក្ខខណ្ឌ ៖ \(x \ne 0\)។ ឫសភាគយក \(x = 1\)។
ដូចនេះ \(x \in (-\infty, 0) \cup [1, +\infty)\)។
ឃ.  \(\dfrac{2}{x - 1} > \dfrac{3}{x + 2} \iff \dfrac{2}{x - 1} - \dfrac{3}{x + 2} > 0\)
\(\iff \dfrac{2(x + 2) - 3(x - 1)}{(x - 1)(x + 2)} > 0 \iff \dfrac{2x + 4 - 3x + 3}{(x - 1)(x + 2)} > 0\)
\(\iff \dfrac{-x + 7}{(x - 1)(x + 2)} > 0 \iff \dfrac{x - 7}{(x - 1)(x + 2)} < 0\)
លក្ខខណ្ឌ ៖ \(x \ne 1, x \ne -2\)។ ឫសភាគយក \(x = 7\)។
ឫសទាំង ៣ តាមលំដាប់ ៖ \(-2, 1, 7\)។
ដូចនេះ \(x \in (-\infty, -2) \cup (1, 7)\)។

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ ៖ \(\dfrac{x^2 - 3x + 2}{x^2 + 3x + 2} \ge 0\)
ដាក់ជាផលគុណកត្តា ៖
ភាគយក ៖ \(x^2 - 3x + 2 = (x - 1)(x - 2)\)
ភាគបែង ៖ \(x^2 + 3x + 2 = (x + 1)(x + 2)\)
លក្ខខណ្ឌ ៖ \(x \ne -1\) និង \(x \ne -2\)។
វិសមីការក្លាយជា ៖ \(f(x) = \dfrac{(x - 1)(x - 2)}{(x + 1)(x + 2)} \ge 0\)
ឫសភាគយកគឺ \(1, 2\) និងឫសភាគបែងគឺ \(-2, -1\)។
តារាងសញ្ញា ៖

រូបភាពនេះកំពុងរៀបចំ

តាមតារាងសញ្ញា វិសមីការ \(f(x) \ge 0\) លុះត្រាតែ ៖
\(x \in (-\infty, -2) \cup (-1, 1] \cup [2, +\infty)\)។
ដូចនេះ សំណុំចម្លើយគឺ \(x \in (-\infty, -2) \cup (-1, 1] \cup [2, +\infty)\)។

១៩លំហាត់ទី ១៩

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ ៖ \(\dfrac{x^2 + 2x - 3}{x^2 - 4x + 4} \le 0\)
ដាក់ជាផលគុណកត្តា ៖
\(f(x) = \dfrac{(x - 1)(x + 3)}{(x - 2)^2} \le 0\)

ឫសភាគយកគឺ \(-3, 1\) និងឫសភាគបែងគឺ \(2\)។
តារាងសញ្ញា ៖

តាមតារាងសញ្ញា វិសមីការ \(f(x) \le 0\) លុះត្រាតែ ៖
\(x \in [-3, 1]\) (ចំណាំ ៖ \(x = 2\) មិនយកព្រោះជាភាគបែង)។
ដូចនេះ សំណុំចម្លើយគឺ \(x \in [-3, 1]\)។

២០លំហាត់ទី ២០

ដោះស្រាយវិសមីការដែលមានតម្លៃដាច់ខាតរាង \(|A| \le B\) ៖

  1. \(|x - 3| \le 4\)

  2. \(|2x + 1| < 5\)

  3. \(|3x - 2| \le 7\)

  4. \(|5 - 2x| < 3\)

មើលដំណោះស្រាយ

វិសមីការដែលមានតម្លៃដាច់ខាតរាង \(|A| \le B\) ៖
រូបមន្ត ៖ \(|A| \le B \iff -B \le A \le B\) (លក្ខខណ្ឌ \(B \ge 0\))។
ក.  \(|x - 3| \le 4\)
\(\iff -4 \le x - 3 \le 4 \iff -1 \le x \le 7\)
ដូចនេះ \(x \in [-1, 7]\)។
ខ.  \(|2x + 1| < 5\)
\(\iff -5 < 2x + 1 < 5 \iff -6 < 2x < 4 \iff -3 < x < 2\)
ដូចនេះ \(x \in (-3, 2)\)។
គ.  \(|3x - 2| \le 7\)
\(\iff -7 \le 3x - 2 \le 7 \iff -5 \le 3x \le 9 \iff -\dfrac{5}{3} \le x \le 3\)
ដូចនេះ \(x \in \left[-\dfrac{5}{3}, 3\right]\)។
ឃ.  \(|5 - 2x| < 3\)
\(\iff -3 < 5 - 2x < 3 \iff -8 < -2x < -2\)
ចែកនឹង \(-2 < 0\) ៖ \(4 > x > 1 \iff 1 < x < 4\)
ដូចនេះ \(x \in (1, 4)\)។

២១លំហាត់ទី ២១

ដោះស្រាយវិសមីការដែលមានតម្លៃដាច់ខាតរាង \(|A| \ge B\) ៖

  1. \(|x + 2| \ge 3\)

  2. \(|2x - 5| > 7\)

  3. \(|4 - 3x| \ge 5\)

  4. \(|3x + 1| > 10\)

មើលដំណោះស្រាយ

វិសមីការតម្លៃដាច់ខាតរាង \(|A| \ge B\) ៖
រូបមន្ត ៖ \(|A| \ge B \iff A \le -B \) ឬ \( A \ge B\)។
ក.  \(|x + 2| \ge 3\)
\(\iff x + 2 \le -3 \) ឬ \( x + 2 \ge 3\)
\(\iff x \le -5 \) ឬ \( x \ge 1\)
ដូចនេះ \(x \in (-\infty, -5] \cup [1, +\infty)\)។
ខ.  \(|2x - 5| > 7\)
\(\iff 2x - 5 < -7 \) ឬ \( 2x - 5 > 7\)
\(\iff 2x < -2 \) ឬ \( 2x > 12 \iff x < -1 \) ឬ \( x > 6\)
ដូចនេះ \(x \in (-\infty, -1) \cup (6, +\infty)\)។
គ.  \(|4 - 3x| \ge 5\)
\(\iff 4 - 3x \le -5 \) ឬ \( 4 - 3x \ge 5\)
\(\iff -3x \le -9 \iff x \ge 3\) ឬ \(-3x \ge 1 \iff x \le -\dfrac{1}{3}\)
ដូចនេះ \(x \in \left(-\infty, -\dfrac{1}{3}\right] \cup [3, +\infty)\)។
ឃ.  \(|3x + 1| > 10\)
\(\iff 3x + 1 < -10 \) ឬ \( 3x + 1 > 10\)
\(\iff 3x < -11 \iff x < -\dfrac{11}{3}\) ឬ \(3x > 9 \iff x > 3\)
ដូចនេះ \(x \in \left(-\infty, -\dfrac{11}{3}\right) \cup (3, +\infty)\)។

២២លំហាត់ទី ២២

ដោះស្រាយវិសមីការតម្លៃដាច់ខាតរាង \(|A| < |B|\) (លើកជាការ៉េអង្គសងខាង) ៖

  1. \(|x - 1| \le |x + 3|\)

  2. \(|2x + 1| > |x - 4|\)

  3. \(|3x - 2| \le |2x + 3|\)

  4. \(|x + 5| > |2x - 1|\)

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការតម្លៃដាច់ខាតរាង \(|A| < |B|\) ៖
រូបមន្ត ៖ \(|A| < |B| \iff A^2 < B^2 \iff (A - B)(A + B) < 0\)។
ក.  \(|x - 1| \le |x + 3|\)
\(\iff (x - 1)^2 \le (x + 3)^2 \iff x^2 - 2x + 1 \le x^2 + 6x + 9\)
\(\iff -8x \le 8 \iff x \ge -1\)
ដូចនេះ \(x \in [-1, +\infty)\)។
ខ.  \(|2x + 1| > |x - 4|\)
\(\iff (2x + 1)^2 - (x - 4)^2 > 0\)
\(\iff [(2x + 1) - (x - 4)][(2x + 1) + (x - 4)] > 0\)
\(\iff (x + 5)(3x - 3) > 0 \iff 3(x + 5)(x - 1) > 0\)
ដូចនេះ \(x \in (-\infty, -5) \cup (1, +\infty)\)។
គ.  \(|3x - 2| \le |2x + 3|\)
\(\iff [(3x - 2) - (2x + 3)][(3x - 2) + (2x + 3)] \le 0\)
\(\iff (x - 5)(5x + 1) \le 0\)
ដូចនេះ \(x \in \left[-\dfrac{1}{5}, 5\right]\)។
ឃ.  \(|x + 5| > |2x - 1|\)
\(\iff [(x + 5) - (2x - 1)][(x + 5) + (2x - 1)] > 0\)
\(\iff (-x + 6)(3x + 4) > 0 \iff (x - 6)(3x + 4) < 0\)
ដូចនេះ \(x \in \left(-\dfrac{4}{3}, 6\right)\)។

២៣លំហាត់ទី ២៣

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ ៖ \(|x^2 - 5x| < 6\)
\(\iff -6 < x^2 - 5x < 6 \iff \begin{cases} x^2 - 5x > -6 \\ x^2 - 5x < 6 \end{cases}\)
1. \(x^2 - 5x + 6 > 0 \iff (x - 2)(x - 3) > 0\)
\(\implies x \in (-\infty, 2) \cup (3, +\infty)\)
2. \(x^2 - 5x - 6 < 0 \iff (x + 1)(x - 6) < 0\)
\(\implies x \in (-1, 6)\)
ប្រសព្វចម្លើយទាំងពីរ ៖
\(x \in (-1, 2) \cup (3, 6)\)។

លក្ខខណ្ឌចាំបាច់ ៖ \(3x \ge 0 \iff x \ge 0\)។
នៅពេល \(x \ge 0\) វិសមីការសមមូលនឹង ៖
\(-3x \le x^2 - 4 \le 3x \iff \begin{cases} x^2 + 3x - 4 \ge 0 \\ x^2 - 3x - 4 \le 0 \end{cases}\)

\(\implies x \in (-\infty, -4] \cup [1, +\infty)\)
2. \(x^2 - 3x - 4 \le 0 \iff (x + 1)(x - 4) \le 0\)
\(\implies x \in [-1, 4]\)
ប្រសព្វលក្ខខណ្ឌទាំងពីរ និង \(x \ge 0\) ៖
\(x \in [1, 4]\)។
ដូចនេះ សំណុំចម្លើយគឺ \(x \in [1, 4]\)។

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ ៖ \(\dfrac{|x - 2|}{x + 1} \le 1\)
លក្ខខណ្ឌ ៖ \(x + 1 \ne 0 \iff x \ne -1\)។
យើងចែកជាពីរករណី ៖
- ករណីទី ១ ៖ \(x + 1 < 0 \iff x < -1\)
ដោយ \(|x - 2| \ge 0\) និង \(x + 1 < 0\) នោះ \(\dfrac{|x - 2|}{x + 1} \le 0 < 1\) ជានិច្ច។
ដូចនេះ គ្រប់ \(x \in (-\infty, -1)\) សុទ្ធតែជាចម្លើយ។
- ករណីទី ២ ៖ \(x + 1 > 0 \iff x > -1\)
គុណអង្គទាំងពីរនឹង \(x + 1 > 0\) ៖
\(|x - 2| \le x + 1 \iff -(x + 1) \le x - 2 \le x + 1\)
\(\bullet\ -x - 1 \le x - 2 \iff 2x \ge 1 \iff x \ge \dfrac{1}{2}\)
\(\bullet\ x - 2 \le x + 1 \iff -2 \le 1\) (ពិតជានិច្ច)
នាំឱ្យ \(x \ge \dfrac{1}{2}\) (ផ្ទៀងផ្ទាត់ \(x > -1\))។
រួមចម្លើយករណីទាំងពីរ ៖
\(x \in (-\infty, -1) \cup \left[\dfrac{1}{2}, +\infty\right)\)។

\(\iff m \le -2 \) ឬ \( m \ge 2\)។

ឫសភាគយកគឺ \(x = -2, x = 1\) និងឫសភាគបែងគឺ \(x = 3\)។
តារាងសញ្ញា ៖

រូបភាពនេះកំពុងរៀបចំ

តាមតារាងសញ្ញា វិសមីការ \(f(x) \ge 0\) លុះត្រាតែ ៖
\(x \in (-\infty, -2] \cup \{1\} \cup (3, +\infty)\)។
ដូចនេះ សំណុំចម្លើយគឺ \(x \in (-\infty, -2] \cup \{1\} \cup (3, +\infty)\)។

ដោះស្រាយវិសមីការ ៖ \(\sqrt{x + 2} \le x\)។

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ ៖ \(\sqrt{x + 2} \le x\)
រូបមន្ត ៖ \(\sqrt{A} \le B \iff \begin{cases} A \ge 0 \\ B \ge 0 \\ A \le B^2 \end{cases}\)
អនុវត្ត ៖
\(\begin{cases} x + 2 \ge 0 \iff x \ge -2 \\ x \ge 0 \\ x + 2 \le x^2 \iff x^2 - x - 2 \ge 0 \end{cases}\)
ដោះស្រាយ \(x^2 - x - 2 \ge 0\) ៖
\((x - 2)(x + 1) \ge 0 \iff x \le -1 \) ឬ \( x \ge 2\)។
យកប្រសព្វជាមួយលក្ខខណ្ឌ \(x \ge 0\) ៖
\(x \ge 2\)។
ដូចនេះ សំណុំចម្លើយគឺ \(x \in [2, +\infty)\)។

៣៩លំហាត់ទី ៣៩

ដោះស្រាយវិសមីការ ៖ \(\sqrt{2x - 1} > x - 2\)។

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ ៖ \(\sqrt{2x - 1} > x - 2\)
លក្ខខណ្ឌរ៉ាឌីកាល់ ៖ \(2x - 1 \ge 0 \iff x \ge \dfrac{1}{2}\)។
យើងពិនិត្យពីរករណីនៃអង្គខាងស្តាំ ៖
- ករណីទី ១ ៖ \(x - 2 < 0 \iff x < 2\)
ជាមួយ \(x \ge \dfrac{1}{2}\) យើងបាន \(\dfrac{1}{2} \le x < 2\)។
នៅពេលនោះ អង្គខាងឆ្វេង \(\ge 0\) ហើយអង្គខាងស្តាំ \(< 0\) នាំឱ្យវិសមីការផ្ទៀងផ្ទាត់ជានិច្ច ៖
ចម្លើយករណីទី ១ គឺ \(x \in \left[\dfrac{1}{2}, 2\right)\)។
- ករណីទី ២ ៖ \(x - 2 \ge 0 \iff x \ge 2\)
លើកជាការ៉េអង្គទាំងពីរ ៖
\(2x - 1 > (x - 2)^2 \iff 2x - 1 > x^2 - 4x + 4\)
\(\iff x^2 - 6x + 5 < 0 \iff (x - 1)(x - 5) < 0\)
\(\iff 1 < x < 5\)។
ប្រសព្វជាមួយ \(x \ge 2\) នាំឱ្យ \(2 \le x < 5\) ៖
ចម្លើយករណីទី ២ គឺ \(x \in [2, 5)\)។
រួមចម្លើយទាំងពីរករណី ៖
\(x \in \left[\dfrac{1}{2}, 2\right) \cup [2, 5) = \left[\dfrac{1}{2}, 5\right)\)។

៤០លំហាត់ទី ៤០

ដោះស្រាយវិសមីការ ៖ \(\sqrt{x^2 - 3x - 4} \ge x - 1\)។

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ ៖ \(\sqrt{x^2 - 3x - 4} \ge x - 1\)
លក្ខខណ្ឌរ៉ាឌីកាល់ ៖ \(x^2 - 3x - 4 \ge 0 \iff (x + 1)(x - 4) \ge 0\)
\(\iff x \le -1 \) ឬ \( x \ge 4\)។
- ករណីទី ១ ៖ \(x - 1 < 0 \iff x < 1\)
ប្រសព្វជាមួយលក្ខខណ្ឌរ៉ាឌីកាល់ ៖ \(x \le -1\)។
ដោយ \(\sqrt{x^2 - 3x - 4} \ge 0\) ហើយ \(x - 1 < 0\) នោះវិសមីការតែងតែពិត ៖
ដូចនេះ \(x \in (-\infty, -1]\) ជាចម្លើយ។
- ករណីទី ២ ៖ \(x - 1 \ge 0 \iff x \ge 1\)
ប្រសព្វជាមួយលក្ខខណ្ឌរ៉ាឌីកាល់ ៖ \(x \ge 4\)។
លើកជាការ៉េអង្គទាំងពីរ ៖
\(x^2 - 3x - 4 \ge (x - 1)^2 = x^2 - 2x + 1\)
\(\iff -3x - 4 \ge -2x + 1 \iff -x \ge 5 \iff x \le -5\)។
ប្រសព្វរវាង \(x \le -5\) និង \(x \ge 4\) គឺគ្មានតម្លៃ \(x\) ផ្ទៀងផ្ទាត់ (\(\emptyset\))។
ដូចនេះ សំណុំចម្លើយរួមគឺ \(x \in (-\infty, -1]\)។

៤១លំហាត់ទី ៤១

ដោះស្រាយវិសមីការ ៖ \(|2x - 1| + |x + 2| \le 5\)។

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ ៖ \(|2x - 1| + |x + 2| \le 5\)
ឫសនៃកន្សោមក្នុងតម្លៃដាច់ខាត ៖ \(x = \dfrac{1}{2}\) និង \(x = -2\)។
យើងបែងចែកជា ៣ ចន្លោះ ៖
1. ចន្លោះ \(x < -2\) ៖
\(|2x - 1| = -(2x - 1) = -2x + 1\) និង \(|x + 2| = -(x + 2) = -x - 2\)
វិសមីការទៅជា ៖ \((-2x + 1) + (-x - 2) \le 5\)
\(\iff -3x - 1 \le 5 \iff -3x \le 6 \iff x \ge -2\)
គ្មានចម្លើយលើចន្លោះ \(x < -2\) ទេ។
2. ចន្លោះ \(-2 \le x \le \dfrac{1}{2}\) ៖
\(|2x - 1| = 1 - 2x\) និង \(|x + 2| = x + 2\)
វិសមីការទៅជា ៖ \((1 - 2x) + (x + 2) \le 5 \iff -x + 3 \le 5\)
\(\iff -x \le 2 \iff x \ge -2\) (ផ្ទៀងផ្ទាត់គ្រប់តម្លៃក្នុងចន្លោះនេះ)
នាំឱ្យបានចន្លោះចម្លើយ ៖ \(\left[-2, \dfrac{1}{2}\right]\)។
3. ចន្លោះ \(x > \dfrac{1}{2}\) ៖
\(|2x - 1| = 2x - 1\) និង \(|x + 2| = x + 2\)
វិសមីការទៅជា ៖ \((2x - 1) + (x + 2) \le 5 \iff 3x + 1 \le 5\)
\(\iff 3x \le 4 \iff x \le \dfrac{4}{3}\)
ប្រសព្វជាមួយ \(x > \dfrac{1}{2}\) នាំឱ្យបាន \(x \in \left(\dfrac{1}{2}, \dfrac{4}{3}\right]\)។
រួមចម្លើយ ៖ \(x \in \left[-2, \dfrac{1}{2}\right] \cup \left(\dfrac{1}{2}, \dfrac{4}{3}\right] = \left[-2, \dfrac{4}{3}\right]\)។

៤២លំហាត់ទី ៤២

ដោះស្រាយវិសមីការ ៖ \(|x - 1| - |x + 3| > 2\)។

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ ៖ \(|x - 1| - |x + 3| > 2\)
ឫសនៃកន្សោមតម្លៃដាច់ខាត ៖ \(x = 1, x = -3\)។
បែងចែកជា ៣ ចន្លោះ ៖
1. ចន្លោះ \(x < -3\) ៖
\(|x - 1| = 1 - x\) និង \(|x + 3| = -x - 3\)
វិសមីការ ៖ \((1 - x) - (-x - 3) > 2 \iff 1 - x + x + 3 > 2 \iff 4 > 2\) (ពិតជានិច្ច)
ដូចនេះ គ្រប់ \(x \in (-\infty, -3)\) ជាចម្លើយ។
2. ចន្លោះ \(-3 \le x \le 1\) ៖
\(|x - 1| = 1 - x\) និង \(|x + 3| = x + 3\)
វិសមីការ ៖ \((1 - x) - (x + 3) > 2 \iff -2x - 2 > 2\)
\(\iff -2x > 4 \iff x < -2\)
ប្រសព្វជាមួយ \([-3, 1]\) ទទួលបាន \(x \in [-3, -2)\)។
3. ចន្លោះ \(x > 1\) ៖
\(|x - 1| = x - 1\) និង \(|x + 3| = x + 3\)
វិសមីការ ៖ \((x - 1) - (x + 3) > 2 \iff -4 > 2\) (មិនពិត)។
រួមចម្លើយ ៖ \((-\infty, -3) \cup [-3, -2) = (-\infty, -2)\)។

៤៣លំហាត់ទី ៤៣

បង្ហាញថាចំពោះគ្រប់ចំនួនពិតវិជ្ជមាន \(a, b > 0\) យើងតែងមាន \(\dfrac{a+b}{2} \ge \sqrt{ab}\) (វិសមីការ AM-GM)។

មើលដំណោះស្រាយ

បង្ហាញថា \(\dfrac{a+b}{2} \ge \sqrt{ab}\) ចំពោះគ្រប់ \(a, b > 0\) (វិសមីការ AM-GM) ៖
ដោយសារ \(a > 0\) និង \(b > 0\) យើងអាចសរសេរ \(a = (\sqrt{a})^2\) និង \(b = (\sqrt{b})^2\)។
ពិនិត្យកន្សោមការ៉េនៃផលដក ៖
\((\sqrt{a} - \sqrt{b})^2 \ge 0\) (ពិតជានិច្ចចំពោះគ្រប់ចំនួនពិត \(\sqrt{a}, \sqrt{b}\))
\(\iff (\sqrt{a})^2 - 2\sqrt{a}\sqrt{b} + (\sqrt{b})^2 \ge 0\)
\(\iff a - 2\sqrt{ab} + b \ge 0\)
\(\iff a + b \ge 2\sqrt{ab}\)
ចែកអង្គទាំងពីរនឹង \(2\) ៖
\(\dfrac{a + b}{2} \ge \sqrt{ab}\) (ពិត)។
សមភាពកើតមានកាលណា \(\sqrt{a} - \sqrt{b} = 0 \iff a = b\)។

៤៤លំហាត់ទី ៤៤

គេឱ្យ \(a, b, c > 0\)។ បង្ហាញថា \((a + b)(b + c)(c + a) \ge 8abc\)។

មើលដំណោះស្រាយ

គេឱ្យ \(a, b, c > 0\)។ បង្ហាញថា \((a + b)(b + c)(c + a) \ge 8abc\) ៖
អនុវត្តវិសមីការ AM-GM ចំពោះគូនីមួយៗនៃចំនួនវិជ្ជមាន ៖
\(\bullet\ a + b \ge 2\sqrt{ab}\) (សមភាពពេល \(a = b\))
\(\bullet\ b + c \ge 2\sqrt{bc}\) (សមភាពពេល \(b = c\))
\(\bullet\ c + a \ge 2\sqrt{ca}\) (សមភាពពេល \(c = a\))
ដោយសារអង្គទាំងសងខាងនៃវិសមភាពទាំងបីសុទ្ធតែវិជ្ជមាន យើងគុណវិសមភាពទាំងបីបញ្ចូលគ្នា ៖
\((a + b)(b + c)(c + a) \ge (2\sqrt{ab})(2\sqrt{bc})(2\sqrt{ca})\)
\(\iff (a + b)(b + c)(c + a) \ge 8\sqrt{ab \cdot bc \cdot ca}\)
\(\iff (a + b)(b + c)(c + a) \ge 8\sqrt{a^2 b^2 c^2} = 8abc\) (ពិត)។
សមភាពកើតមានកាលណា \(a = b = c\)។

៤៥លំហាត់ទី ៤៥

គេឱ្យ \(x, y > 0\) ដែលផ្ទៀងផ្ទាត់ \(x + y = 1\)។ រកតម្លៃតូចបំផុតនៃកន្សោម \(S = \dfrac{1}{x} + \dfrac{1}{y}\)។

មើលដំណោះស្រាយ

រកតម្លៃតូចបំផុតនៃ \(S = \dfrac{1}{x} + \dfrac{1}{y}\) ដោយ \(x, y > 0\) និង \(x + y = 1\) ៖
តម្រូវភាគបែង ៖ \(S = \dfrac{x + y}{xy} = \dfrac{1}{xy}\) (ព្រោះ \(x + y = 1\))។
តាមវិសមីការ AM-GM សម្រាប់ \(x, y > 0\) ៖
\(\sqrt{xy} \le \dfrac{x + y}{2} = \dfrac{1}{2} \implies xy \le \left(\dfrac{1}{2}\right)^2 = \dfrac{1}{4}\)
ដោយសារ \(xy > 0\) យើងច្រាសវិសមភាព ៖
\(S = \dfrac{1}{xy} \ge \dfrac{1}{\frac{1}{4}} = 4\)។
សមភាពកើតមានកាលណា \(x = y = \dfrac{1}{2}\) (ផ្ទៀងផ្ទាត់ \(x + y = 1\))។
ដូចនេះ តម្លៃតូចបំផុតនៃ \(S\) គឺ \(S_{\min} = 4\) ត្រង់ \(x = y = \dfrac{1}{2}\)។

  • ប្រសិនបើហៅចេញចំ \(120\) នាទី គម្រោងទាំងពីរអស់ប្រាក់ស្មើគ្នា (\(18\$\))។

លំហាត់ PISA - សមត្ថភាពផ្ទុកទម្ងន់សុវត្ថិភាពនៃជណ្តើរយន្ត ៖ ជណ្តើរយន្តដឹកទំនិញមួយមានកម្រិតផ្ទុកទម្ងន់សុវត្ថិភាពអតិបរមា \(800\text{ kg}\)។ បុគ្គលិកម្នាក់មានទម្ងន់ \(75\text{ kg}\) ត្រូវរុញកេសទំនិញដែលមានទម្ងន់ \(35\text{ kg}\) ក្នុងមួយកេស។

  1. សរសេរវិសមីការតំណាងឱ្យទម្ងន់សរុប។

  2. រកចំនួនកេសអតិបរមាដឹកបានក្នុងមួយជើង។

មើលដំណោះស្រាយ

លំហាត់ PISA - សមត្ថភាពផ្ទុកទម្ងន់សុវត្ថិភាពនៃជណ្តើរយន្ត ៖
តាង \(n\) ជាចំនួនកេសទំនិញដែលអាចដឹកបាន (\(n \in \mathbb{N}\))។
ទម្ងន់មនុស្ស ៖ \(75\text{ kg}\)
ទម្ងន់កេសទំនិញ \(n\) កេស ៖ \(35n\text{ kg}\)
ទម្ងន់ផ្ទុកអតិបរមា ៖ \(800\text{ kg}\)
ក.  វិសមីការតំណាងឱ្យទម្ងន់សរុបប្រកបដោយសុវត្ថិភាព ៖
\(75 + 35n \le 800\)
ខ.  រកចំនួនកេសអតិបរមា ៖
\(35n \le 800 - 75 \iff 35n \le 725\)
\(\iff n \le \dfrac{725}{35} = \dfrac{145}{7} \approx 20.71\)
ដោយសារ \(n\) ជាចំនួនគត់វិជ្ជមាន នោះតម្លៃអតិបរមានៃ \(n\) គឺ \(n_{\max} = 20\)។
ដូចនេះ ជណ្តើរយន្តអាចដឹកកេសទំនិញបានច្រើនបំផុត \(20\) កេស ក្នុងមួយជើង។

៤៨លំហាត់ទី ៤៨

លំហាត់ PISA - ការគ្រប់គ្រងប្រាក់ចំណេញសហគ្រាស ៖ អាជីវកម្មមួយចំណាយថ្លៃដើមថេរ \(1800\$\) និងថ្លៃដើមផលិត \(4\$\) ក្នុងមួយឯកតា។ ផលិតផលត្រូវលក់ក្នុងតម្លៃ \(10\$\)។

  1. សរសេរវិសមីការឱ្យបានចំណេញសុទ្ធយ៉ាងតិច \(1200\$\)។

  2. រកចំនួនឯកតាអប្បបរមាដែលត្រូវលក់ក្នុងមួយខែ។

មើលដំណោះស្រាយ

លំហាត់ PISA - ការគ្រប់គ្រងប្រាក់ចំណេញសហគ្រាស ៖
តាង \(x\) ជាចំនួនឯកតាផលិតផលដែលត្រូវផលិត និងលក់ (\(x \in \mathbb{N}\))។
ចំណូលសរុប ៖ \(R(x) = 10x\)
ថ្លៃដើមសរុប ៖ \(C(x) = 1800 + 4x\)
ប្រាក់ចំណេញសុទ្ធ ៖ \(P(x) = R(x) - C(x) = 10x - (1800 + 4x) = 6x - 1800\)
ក.  វិសមីការដើម្បីទទួលបានចំណេញយ៉ាងតិច \(1200\$\) ៖
\(6x - 1800 \ge 1200\)
ខ.  ដោះស្រាយវិសមីការរកចំនួនឯកតាអប្បបរមា ៖
\(6x \ge 1200 + 1800 \iff 6x \ge 3000\)
\(\iff x \ge \dfrac{3000}{6} = 500\) ឯកតា។
ដូចនេះ សហគ្រាសត្រូវផលិត និងលក់ឱ្យបានយ៉ាងតិច \(500\) ឯកតា ក្នុងមួយខែ។

៤៩លំហាត់ទី ៤៩

លំហាត់ PISA - សីតុណ្ហភាពសុវត្ថិភាពក្នុងការរក្សាទុកឱសថ ៖ ឱសថមួយប្រភេទត្រូវរក្សាទុកនៅសីតុណ្ហភាព \(C\) ចន្លោះ \(2^\circ\text{C}\) ដល់ \(8^\circ\text{C}\) (\(2 \le C \le 8\)) ដោយ \(C = \frac{5}{9}(F - 32)\)។

  1. បំប្លែងជាវិសមីការទ្វេនៃអង្សាហ្វារិនហៃ \(F\)។

  2. កំណត់ដែនសីតុណ្ហភាពគិតជា \(F\)។

មើលដំណោះស្រាយ

លំហាត់ PISA - សីតុណ្ហភាពសុវត្ថិភាពក្នុងការរក្សាទុកឱសថ ៖
លក្ខខណ្ឌសីតុណ្ហភាពគិតជាអង្សាសេ ៖ \(2 \le C \le 8\)
ដោយ \(C = \dfrac{5}{9}(F - 32)\)
ក.  បំប្លែងជាវិសមីការទ្វេនៃ \(F\) ៖
\(2 \le \dfrac{5}{9}(F - 32) \le 8\)
ខ.  កំណត់ដែនសីតុណ្ហភាពជាអង្សាហ្វារិនហៃ (\(F\)) ៖
គុណគ្រប់អង្គនឹង \(\dfrac{9}{5} = 1.8\) ៖
\(2 \times \dfrac{9}{5} \le F - 32 \le 8 \times \dfrac{9}{5}\)
\(\iff 3.6 \le F - 32 \le 14.4\)
បូក \(32\) គ្រប់អង្គ ៖
\(3.6 + 32 \le F \le 14.4 + 32 \iff 35.6 \le F \le 46.4\)។
ដូចនេះ ដែនសីតុណ្ហភាពសុវត្ថិភាពគឺពី \(35.6^\circ\text{F}\) ដល់ \(46.4^\circ\text{F}\) (\(F \in [35.6^\circ\text{F}, 46.4^\circ\text{F}]\))។

៥០លំហាត់ទី ៥០

លំហាត់ PISA - ល្បឿនសុវត្ថិភាពលើផ្លូវល្បឿនលឿន ៖ ផ្លាកសញ្ញាកំណត់ល្បឿនអប្បបរមា \(60\text{ km/h}\) និងអតិបរមា \(120\text{ km/h}\)។

  1. សរសេរវិសមីការតំណាងឱ្យល្បឿន \(v\)។

  2. រកចន្លោះរយៈពេលធ្វើដំណើរលើចម្ងាយ \(180\text{ km}\)។

មើលដំណោះស្រាយ

លំហាត់ PISA - ល្បឿនសុវត្ថិភាពលើផ្លូវល្បឿនលឿន ៖
ចម្ងាយផ្លូវ ៖ \(d = 180\text{ km}\)
ក.  វិសមីការតំណាងឱ្យល្បឿនអនុញ្ញាត \(v\) (\(\text{km/h}\)) ៖
\(60 \le v \le 120\)
ខ.  រកចន្លោះរយៈពេលធ្វើដំណើរ \(t\) (ម៉ោង) ៖
រូបមន្ត ៖ \(t = \dfrac{d}{v} = \dfrac{180}{v}\)
ដោយសារ \(60 \le v \le 120\) និង \(v > 0\) យើងច្រាសវិសមភាព ៖
\(\dfrac{180}{120} \le \dfrac{180}{v} \le \dfrac{180}{60}\)
\(\iff 1.5 \le t \le 3\) ម៉ោង។
បំប្លែង \(1.5\) ម៉ោង \( = 1\) ម៉ោង \( 30\) នាទី ។
ដូចនេះ រយៈពេលធ្វើដំណើរប្រកបដោយសុវត្ថិភាព និងស្របច្បាប់ គឺស្ថិតនៅចន្លោះពី \(1\) ម៉ោង \( 30\) នាទី ដល់ \(3\) ម៉ោង ។
