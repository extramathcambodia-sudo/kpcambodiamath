ដៅចំណុចទាំងនេះ រួចភ្ជាប់គេបានក្រាបដូចរូបខាងស្ដាំ ។

ក្រាបនៃអនុគមន៍ខាងលើហៅថា " ប៉ារ៉ាបូល " ។

ចំណុច \(O(0, 0)\) នៃប៉ារ៉ាបូលនេះដែលស្ថិតនៅទាបជាងគេហៅថា " កំពូល " ហើយអ័ក្សអរដោនេជា " អ័ក្សឆ្លុះ " នៃប៉ារ៉ាបូលនេះ ។ ប៉ារ៉ាបូលនេះបែរភាពផតឡើងលើ ។

សិក្សាភាពចុះ និងកើននៃអនុគមន៍ \(y = x^2\) គេបាន កំណើនអថេរ \(\Delta x = x_2 - x_1\) កំណើនអនុគមន៍ \(\Delta f = f(x_2) - f(x_1) = x_2^2 - x_1^2 = (x_2 + x_1)(x_2 - x_1)\) ដូច្នេះ ផលធៀប \(\frac{\Delta f}{\Delta x} = \frac{(x_2 + x_1)(x_2 - x_1)}{x_2 - x_1} = x_2 + x_1\) ។

ចំពោះគ្រប់ \(x_1, x_2\) ដែល \(x_1 < x_2 < 0\) គេបាន \(\frac{\Delta f}{\Delta x} = x_2 + x_1 < 0\) ហើយត្រង់នឹងប៉ារ៉ាបូលចុះ ។ គេថា \(f\) ជាអនុគមន៍ចុះ ចំពោះ \(x < 0\) ។

ចំពោះគ្រប់ \(x_1, x_2\) ដែល \(0 < x_1 < x_2\) គេបាន \(\frac{\Delta f}{\Delta x} = x_2 + x_1 > 0\) ហើយត្រង់នឹងប៉ារ៉ាបូលកើនឡើង ។ គេថា \(f\) ជាអនុគមន៍កើន ចំពោះ \(x > 0\) ។

តាង \(\Delta\) ជាឌីសគ្រីមីណង់នៃសមីការ \(x^2 - 2x + k = 0\) នោះ \(\frac{\Delta}{4} = 1 - k\) ។ ចំពោះ \(\frac{\Delta}{4} = 1 - k > 0\) ឬ \(k < 1\) នោះក្រាបកាត់អ័ក្សអាប់ស៊ីសត្រង់ពីរចំណុចផ្សេងគ្នា ។ ចំពោះ \(\frac{\Delta}{4} = 0\) ឬ \(k = 1\) នោះក្រាបប៉ះជាមួយអ័ក្សអាប់ស៊ីសត្រង់មួយចំណុច ។ ចំពោះ \(\frac{\Delta}{4} < 0\) ឬ \(k > 1\) នោះក្រាបមិនកាត់អ័ក្សអាប់ស៊ីសទេ ។ ដូច្នេះ ចំពោះ \(k < 1\) នោះមានចំណុចប្រសព្វ 2 ។

រូបភាពនេះកំពុងរៀបចំ

ចំពោះ \(k = 1\) នោះមានចំណុចប្រសព្វ \(1\) និងចំពោះ \(k > 1\) នោះគ្មានចំណុចប្រសព្វ ។

ប្រតិបត្តិ

សិក្សាចំនួនចំណុចប្រសព្វរវាងប៉ារ៉ាបូល តាង \(y = x^2 - mx + 4\) និងអ័ក្សអាប់ស៊ីសទៅតាមតម្លៃ \(m\) ។

មើលចម្លើយ


ប៉ារ៉ាបូលកាត់អ័ក្សអាប់ស៊ីសត្រង់ \(2\) ចំណុច កាលណា \(m < -4, 4 < m\)
ប៉ារ៉ាបូលប៉ះអ័ក្សអាប់ស៊ីសពេល \(m = \pm 4\) គ្មានចំណុចប្រសព្វ \(-4 < m < 4\) ។

ការដោះស្រាយវិសមីការដឺក្រេទី 2 តាមក្រាប

ឧទាហរណ៍

ដោះស្រាយវិសមីការដឺក្រេទី 2 ដោយប្រើក្រាបនៃអនុគមន៍ដឺក្រេទី 2 : \(y = ax^2 + bx + c \quad{} (1)\) ។

បើ \(a > 0\) តាងឌីសគ្រីមីណង់ \(\Delta = b^2 - 4ac\) ហើយ \(\alpha\) និង \(\beta\) ជាឫសពិតមិនស្មើគ្នា និង \(\alpha < \beta\) នៃសមីការដឺក្រេទី 2 : \(ax^2 + bx + c = 0 \quad{} (2)\)

រូបភាពនេះកំពុងរៀបចំ

បើ \(\Delta > 0\) ក្រាបតាងអនុគមន៍ដឺក្រេទី 2 គឺរូប \(I\) និង \(II\) ។ សំណុំឫសនៃវិសមីការដឺក្រេទី 2 \(ax^2 + bx + c > 0\) គឺសំណុំនៃតម្លៃ \(x\) ដែល \(y > 0\) នៅលើក្រាបនៃ (1) គឺ \(x < \alpha\), \(x > \beta\) ។ សំណុំឫសនៃវិសមីការដឺក្រេទី 2 \(ax^2 + bx + c < 0\) គឺ \(\alpha < x < \beta\) ។

បើ \(\Delta = 0\) សមីការ (2) មានឫសឌុប \(\alpha\) នោះក្រាប តាង (1) ដូចក្នុងរូប \(III\) ។ សំណុំឫសនៃ \(ax^2 + bx + c > 0\) ជាចំនួនពិតទាំងអស់លើកលែងតែ \(\alpha\) ហើយ \(ax^2 + bx + c < 0\) គ្មានឫសទេ ។

រូបភាពនេះកំពុងរៀបចំ

បើ \(\Delta < 0\) តាមក្រាបក្នុងរូប \(IV\) គេបានសំណុំឫសនៃ \(ax^2 + bx + c > 0\) ជាចំនួនពិតទាំងអស់ ហើយ \(ax^2 + bx + c < 0\) គ្មានឫសទេ ។

មើលដំណោះស្រាយ

កំណត់តម្លៃអតិបរមា និងអប្បបរមាលើដែនកំណត់ដែលបានផ្ដល់៖

  1. \(y = 3x - x^2 = -\left(x - \dfrac{3}{2}\right)^2 + \dfrac{9}{4}\) លើ \([-1, 2]\)៖
    កំពូល \(x = \dfrac{3}{2} = 1.5 \in [-1, 2]\) នាំឱ្យ៖

    \[y_{\max} = \frac{9}{4} = 2.25 \quad{} \left(\text{ត្រង់ } x = \frac{3}{2}\right)\]
    ពិនិត្យតម្លៃនៅចុងកាត់៖
    \[\begin{aligned} x = -1 &\implies y(-1) = 3(-1) - (-1)^2 = -4 \\ x = 2 &\implies y(2) = 3(2) - 2^2 = 2 \end{aligned}\]
    ដូចនេះ \(y_{\min} = -4\) (ត្រង់ \(x = -1\))។

  2. \(y = x^2 + 5x + 4 = \left(x + \dfrac{5}{2}\right)^2 - \dfrac{9}{4}\) លើ \([-3, 0]\)៖
    កំពូល \(x = -2.5 \in [-3, 0]\) នាំឱ្យ៖

    \[y_{\min} = -\frac{9}{4} = -2.25 \quad{} \left(\text{ត្រង់ } x = -\frac{5}{2}\right)\]
    តម្លៃនៅចុងកាត់៖
    \[\begin{aligned} x = -3 &\implies y(-3) = 9 - 15 + 4 = -2 \\ x = 0 &\implies y(0) = 4 \end{aligned}\]
    ដូចនេះ \(y_{\max} = 4\) (ត្រង់ \(x = 0\))។

មើលដំណោះស្រាយ

កំណត់ចំនួនចំណុចប្រសព្វរវាង \(y = x^2 + 2kx + 1\) និង \(y = 2x - 3\) តាម \(k\)៖
សមីការអាប់ស៊ីសប្រសព្វ៖

\[x^2 + 2kx + 1 = 2x - 3 \iff x^2 + 2(k - 1)x + 4 = 0\]
គណនាឌីសគ្រីមីណង់សង្ខេប៖
\[\Delta' = (k - 1)^2 - 4 = k^2 - 2k - 3 = (k - 3)(k + 1)\]

  • បើ \(\Delta' > 0 \iff k \in (-\infty, -1) \cup (3, +\infty)\)៖ មាន ២ ចំណុចប្រសព្វ។

  • បើ \(\Delta' = 0 \iff k = -1\) ឬ \(k = 3\)៖ មាន ១ ចំណុចប្រសព្វ (បន្ទាត់ប៉ះប៉ារ៉ាបូល)។

  • បើ \(\Delta' < 0 \iff k \in (-1, 3)\)៖ គ្មានចំណុចប្រសព្វទេ។

សមីការអាប់ស៊ីសប្រសព្វ៖

\[\begin{aligned} x^2 + 3x - 1 &= 4 - x^2 \\ \iff 2x^2 + 3x - 5 &= 0 \iff (x - 1)(2x + 5) = 0 \\ \implies x_1 &= 1, \quad{} x_2 = -\frac{5}{2} \end{aligned}\]

  • ចំពោះ \(x = 1\) នោះ \(y = 4 - 1^2 = 3 \implies (1, 3)\)

  • ចំពោះ \(x = -\dfrac{5}{2}\) នោះ \(y = 4 - \left(-\dfrac{5}{2}\right)^2 = 4 - \dfrac{25}{4} = -\dfrac{9}{4} \implies \left(-\dfrac{5}{2}, -\dfrac{9}{4}\right)\)

ចំណុចប្រសព្វគឺ \((1, 3)\) និង \(\left(-\dfrac{5}{2}, -\dfrac{9}{4}\right)\)។

១៣លំហាត់ទី ១៣

គេមានអនុគមន៍ \(f\) កំណត់ដោយ \(f(x) = |2x - 1|\) ចំពោះ \(-1 \leq x \leq 3\) ។

  1. សង់ក្រាបតាងអនុគមន៍ \(f\) និងរកសំណុំរូបភាពតាងអនុគមន៍ \(f\) ។

  2. ដោះស្រាយសមីការ \(f(x) \leq 3\) ។

  3. សង់ក្រាបតាងអនុគមន៍ \(y = x + 1\) រួចដោះស្រាយសមីការ \(|2x - 1| = x + 1\) តាមក្រាប ។

មើលដំណោះស្រាយ

\(f(x) = |2x - 1|\) ចំពោះ \(-1 \le x \le 3\)៖
តម្លៃអប្បបរមាកើតមានត្រង់ \(2x - 1 = 0 \iff x = \dfrac{1}{2} \in [-1, 3]\) គឺ \(f\left(\dfrac{1}{2}\right) = 0\)។
តម្លៃនៅចុងកាត់៖

\[\begin{aligned} x = -1 &\implies f(-1) = |-3| = 3 \\ x = 3 &\implies f(3) = |5| = 5 \quad{} (\text{អតិបរមា}) \end{aligned}\]
ដូចនេះ សំណុំរូបភាពគឺ \(R_f = [0, 5]\)។

១៤លំហាត់ទី ១៤

មើលដំណោះស្រាយ

\(f(x) = 2x^2 + 12x - 3\) លើ \(\mathbb{R}\)៖
បំប្លែងជាទម្រង់កាណូនិក៖

\[\begin{aligned} f(x) &= 2(x^2 + 6x) - 3 = 2(x^2 + 6x + 9 - 9) - 3 \\ &= 2(x + 3)^2 - 18 - 3 = 2(x + 3)^2 - 21 \end{aligned}\]

  • កំពូលប៉ារ៉ាបូលគឺ \(V(-3, -21)\)

  • អ័ក្សឆ្លុះគឺបន្ទាត់ \(x = -3\)

  • តម្លៃអប្បបរមាគឺ \(-21\) ត្រង់ \(x = -3\)

គេមានប៉ារ៉ាបូល \((P) : y = ax^2 + bx + c\) កាត់តាមចំណុច \(A(-1, 0)\) , \(B(1, 3)\) និង \(C(3, 4)\) និងបន្ទាត់ \(D : x + 2\) ។

  1. កំណត់ចំនួនពិត \(a, b\) និង \(c\) រួចសង់ក្រាបតាងប៉ារ៉ាបូល ។

  2. ដោះស្រាយវិសមីការ \(-\frac{1}{4}x^2 + \frac{3}{2}x + \frac{7}{4} \leq x + 2\) តាមក្រាហ្វិក ។

មើលដំណោះស្រាយ

\((P) : y = ax^2 + bx + c\) កាត់តាម \(A(-1, 0), B(1, 3), C(3, 4)\)៖

  1. កំណត់តម្លៃ \(a, b, c\)៖
    ជំនួសចំណុចទាំងបីចូល៖

    \[\begin{cases} a - b + c = 0 \quad{} (1) \\ a + b + c = 3 \quad{} (2) \\ 9a + 3b + c = 4 \quad{} (3) \end{cases}\]
    យក \((2) - (1)\)៖ \(2b = 3 \implies b = \dfrac{3}{2}\)។
    ជំនួស \(b = \dfrac{3}{2}\) ចូល \((1)\)៖ \(a + c = \dfrac{3}{2}\)។
    យក \((3) - (2)\)៖ \(8a + 2b = 1 \implies 8a + 3 = 1 \implies 8a = -2 \implies a = -\dfrac{1}{4}\)។
    \(c = \dfrac{3}{2} - \left(-\dfrac{1}{4}\right) = \dfrac{7}{4}\)។
    ដូចនេះ \((P) : y = -\dfrac{1}{4}x^2 + \dfrac{3}{2}x + \dfrac{7}{4}\)។

  2. រកចំណុចប្រសព្វរវាង \((P)\) និង \(D : y = x + 2\)៖

    \[\begin{aligned} -\frac{1}{4}x^2 + \frac{3}{2}x + \frac{7}{4} &= x + 2 \\ \iff -x^2 + 6x + 7 &= 4x + 8 \end{aligned}\]
    \[\iff x^2 - 2x + 1 = 0 \iff (x - 1)^2 = 0 \implies x = 1\]
    ត្រង់ \(x = 1 \implies y = 1 + 2 = 3\)។
    ដូចនេះ បន្ទាត់ \(D\) ប៉ះនឹងប៉ារ៉ាបូល \((P)\) ត្រង់ចំណុច \(B(1, 3)\)។

១៦លំហាត់ទី ១៦

គន្លងបាល់បោះ៖ កីឡាករម្នាក់បោះបាល់បញ្ចូលកន្ត្រក។ កម្ពស់បាល់ \(h\) (គិតជាម៉ែត្រ) ធៀបនឹងដី បន្ទាប់ពីរយៈពេល \(t\) វិនាទី កំណត់ដោយអនុគមន៍ \(h(t) = -5t^2 + 10t + 2\)។

  1. តើបាល់ឡើងដល់កម្ពស់អតិបរមានៅវិនាទីទីប៉ុន្មាន?

  2. តើកម្ពស់អតិបរមានោះស្មើនឹងប៉ុន្មានម៉ែត្រ?

មើលដំណោះស្រាយ

គន្លងបាល់បោះ៖
សមីការកម្ពស់បាល់ជាអនុគមន៍ដឺក្រេទី ២ មានទម្រង់ \(h(t) = -5t^2 + v_0 t + h_0\)។
កំពូលនៃប៉ារ៉ាបូលផ្ដល់កម្ពស់អតិបរមាដែលបាល់អាចឡើងដល់ខ្ពស់បំផុត ត្រង់ខណៈ \(t_v = -\dfrac{v_0}{2a}\)។

១៧លំហាត់ទី ១៧

ប្រាក់ចំណេញនៃរោងចក្រ៖ រោងចក្រផលិតអាវយឺតមួយរកប្រាក់ចំណេញប្រចាំថ្ងៃ \(P\) (គិតជាពាន់រៀល) ជាអនុគមន៍នៃចំនួនអាវយឺត \(x\) ដែលផលិតបាន ដោយសមីការ \(P(x) = -2x^2 + 400x - 5000\)។

  1. តើរោងចក្រត្រូវផលិតអាវយឺតប៉ុន្មានទើបទទួលបានប្រាក់ចំណេញខ្ពស់បំផុត?

  2. តើប្រាក់ចំណេញខ្ពស់បំផុតនោះមានចំនួនប៉ុន្មាន?

មើលដំណោះស្រាយ

ប្រាក់ចំណេញនៃរោងចក្រ៖ \(P(x) = -2x^2 + 40x - 50\) (ពាន់រៀល)៖
ដោយ \(a = -2 < 0\) អនុគមន៍មានតម្លៃអតិបរមាត្រង់កំពូល៖

\[x_v = -\frac{b}{2a} = -\frac{40}{2(-2)} = 10\text{ (រយអាវ)}\]
ប្រាក់ចំណេញអតិបរមាគឺ៖
\[\begin{aligned} P(10) &= -2(10^2) + 40(10) - 50 \\ &= -200 + 400 - 50 = 150\text{ ពាន់រៀល} \end{aligned}\]

ផលបូកការេនៃចំនួនទាំងពីរគឺ៖

\[\begin{aligned} S(x) &= x^2 + (x - 10)^2 \\ &= 2x^2 - 20x + 100 \\ &= 2(x - 5)^2 + 50 \end{aligned}\]
ផលបូកការេតូចបំផុតគឺ \(50\) កើតមានកាលណា \(x = 5\) និងចំនួនទីពីរគឺ \(5 - 10 = -5\)។
ដូចនេះ ចំនួនទាំងពីរគឺ \(5\) និង \(-5\)។

៤៥លំហាត់ទី ៤៥

កសិករម្នាក់មានរបងប្រវែង \(120\text{ m}\) សម្រាប់ព័ទ្ធដីចតុកោណកែងមួយជាប់មាត់ស្ទឹងត្រង់ (មិនចាំបាច់ធ្វើរបងតាមបណ្តោយមាត់ស្ទឹងទេ)។ រកវិមាត្រដីដើម្បីឱ្យផ្ទៃក្រឡាព័ទ្ធបានធំបំផុត រួចគណនាផ្ទៃក្រឡាអតិបរមានោះ។

មើលដំណោះស្រាយ

របងដីចតុកោណកែងជាប់មាត់ស្ទឹង៖
តាង \(x\) ជាទទឹងដី (ជ្រុងកែងនឹងមាត់ស្ទឹងចំនួន ២) និង \(y\) ជាបណ្តោយ (ជ្រុងស្របនឹងមាត់ស្ទឹងចំនួន ១)៖
ប្រវែងរបងសរុបគឺ \(2x + y = 120 \implies y = 120 - 2x\)។
ផ្ទៃក្រឡាដី៖

\[\begin{aligned} S(x) &= x(120 - 2x) = -2x^2 + 120x \\ &= -2(x - 30)^2 + 1800 \end{aligned}\]
ផ្ទៃក្រឡាធំបំផុតគឺ \(1800\text{ m}^2\) កើតមានត្រង់ទទឹង \(x = 30\text{ m}\) និងបណ្តោយ \(y = 120 - 2(30) = 60\text{ m}\)។

៤៦លំហាត់ទី ៤៦

គ្រាប់ផ្លោងមួយត្រូវបានបាញ់ឡើងលើពីកម្ពស់ \(20\text{ m}\) ធៀបនឹងដី ដោយមានកម្ពស់កំណត់ដោយ \(h(t) = -5t^2 + 30t + 20\) (គិតជា \(\text{m}\)) បន្ទាប់ពីរយៈពេល \(t\) វិនាទី។

  1. តើគ្រាប់ផ្លោងឡើងដល់កម្ពស់អតិបរមានៅវិនាទីទីប៉ុន្មាន? រកកម្ពស់អតិបរមានោះ។

  2. តើរយៈពេលប៉ុន្មានវិនាទីទើបគ្រាប់ផ្លោងធ្លាក់មកដល់ដី?

មើលដំណោះស្រាយ

កម្ពស់គ្រាប់ផ្លោង៖ \(h(t) = -5t^2 + 30t + 20\) (\(t \ge 0\))៖

  • កម្ពស់អតិបរមាកើតមានត្រង់កំពូលប៉ារ៉ាបូល៖

    \[t_v = -\frac{b}{2a} = -\frac{30}{2(-5)} = 3\text{ s}\]
    \[\begin{aligned} h_{\max} &= h(3) = -5(3^2) + 30(3) + 20 \\ &= -45 + 90 + 20 = 65\text{ m} \end{aligned}\]

  • គ្រាប់ធ្លាក់ដល់ដីកាលណា \(h(t) = 0\)៖

    \[-5t^2 + 30t + 20 = 0 \iff t^2 - 6t - 4 = 0\]
    \(\Delta' = 9 - (-4) = 13 \implies t = 3 + \sqrt{13} \approx 6.61\text{ s}\) (\(t > 0\))។

៤៧លំហាត់ទី ៤៧

ហាងមួយលក់វត្ថុអនុស្សាវរីយ៍បាន \(80\) គ្រឿងក្នុងមួយថ្ងៃ ក្នុងតម្លៃ \(10\$\) ក្នុងមួយគ្រឿង។ រាល់ពេលដែលដំឡើងថ្លៃ \(1\$\) ការលក់នឹងថយចុះ \(4\) គ្រឿង។

  1. បង្ហាញប្រាក់ចំណូលប្រចាំថ្ងៃ \(R(x)\) ជាអនុគមន៍នៃការដំឡើងថ្លៃ \(x\) ដុល្លារ។

  2. តើត្រូវលក់ក្នុងតម្លៃប៉ុន្មានដើម្បីឱ្យប្រាក់ចំណូលទទួលបានអតិបរមា?

មើលដំណោះស្រាយ

ចំណូលលក់វត្ថុអនុស្សាវរីយ៍៖
តាង \(x\) ជាចំនួនដងនៃការតម្លើងថ្លៃ \(1\$\) (\(x \ge 0\))៖

  • តម្លៃលក់ថ្មី៖ \(P(x) = 10 + x\) ($/គ្រឿង)

  • បរិមាណលក់បាន៖ \(Q(x) = 80 - 4x\) (គ្រឿង)

ចំណូលសរុបប្រចាំថ្ងៃគឺ៖

\[\begin{aligned} R(x) &= (10 + x)(80 - 4x) \\ &= -4x^2 + 40x + 800 \\ &= -4(x^2 - 10x + 25) + 900 \\ &= -4(x - 5)^2 + 900 \end{aligned}\]
ចំណូលអតិបរមាគឺ \(900\$\) កើតមានកាលណា \(x = 5\) នោះតម្លៃលក់ត្រូវកំណត់គឺ \(10 + 5 = 15\$\) ក្នុងមួយគ្រឿង។

៤៨លំហាត់ទី ៤៨

ធ្នូស្ពានមួយមានរាងជាប៉ារ៉ាបូល \(y = -0.05x^2 + 1.2x\) ដែល \(x\) និង \(y\) គិតជាម៉ែត្រ។

  1. គណនាប្រវែងគម្លាតជើងធ្នូស្ពាននៅកម្រិតផ្ទៃទឹក (\(y = 0\))។

  2. គណនាកម្ពស់ខ្ពស់បំផុតនៃធ្នូស្ពានធៀបនឹងផ្ទៃទឹក។

មើលដំណោះស្រាយ

ធ្នូស្ពានរាងប៉ារ៉ាបូល \(y = -0.05x^2 + 1.2x\)៖

  • ប្រវែងចន្លោះស្ពាន (ចម្ងាយរវាងជើងធ្នូទាំងសងខាង \(y = 0\))៖

    \[\begin{aligned} -0.05x^2 + 1.2x &= 0 \\ \iff x(-0.05x + 1.2) &= 0 \\ \implies x = 0 \text{ ឬ } x &= \frac{1.2}{0.05} = 24\text{ m} \end{aligned}\]

  • កម្ពស់ខ្ពស់បំផុតនៃធ្នូស្ពាន (ត្រង់ចំណុចកណ្តាល \(x = 12\text{ m}\))៖

    \[\begin{aligned} y(12) &= -0.05(12^2) + 1.2(12) \\ &= -7.2 + 14.4 = 7.2\text{ m} \end{aligned}\]

៤៩លំហាត់ទី ៤៩

ចានឆ្លុះពន្លឺព្រះអាទិត្យ (STEM/PISA)៖ មុខកាត់នៃចានឆ្លុះប្រមូលកម្ដៅព្រះអាទិត្យមួយមានរាងជាប៉ារ៉ាបូល \(y = \dfrac{1}{16}x^2\) ចំពោះ \(-4 \le x \le 4\) (គិតជាម៉ែត្រ)។

  1. គណនាទទឹងមាត់ចាន និងជម្រៅនៃចានឆ្លុះ។

  2. កំណត់ទីតាំងចំណុចកំណុំ (Focus) ដែលកាំរស្មីព្រះអាទិត្យប្រមូលផ្តុំខ្លាំងបំផុត (\(f = \dfrac{1}{4a}\))។

មើលដំណោះស្រាយ

ចានឆ្លុះពន្លឺព្រះអាទិត្យ (STEM/PISA)៖
មុខកាត់ជាប៉ារ៉ាបូលមានសមីការ \(y = ax^2\) ដែលមានគល់ \(O(0, 0)\) ជាបាតចាន។
បើអង្កត់ផ្ចិតមាត់ចានគឺ \(D\) និងជម្រៅចានគឺ \(H\) នោះចានកាត់តាមចំណុច \(\left(\dfrac{D}{2}, H\right)\) នាំឱ្យ៖

\[H = a\left(\frac{D}{2}\right)^2 = a \cdot \frac{D^2}{4} \implies a = \frac{4H}{D^2}\]
គន្លាតកំណុំ (ទីតាំងទទួលកម្ដៅប្រមូលផ្តុំខ្លាំងបំផុត) គឺ \(f = \dfrac{1}{4a} = \dfrac{D^2}{16H}\)។

៥០លំហាត់ទី ៥០

ការបង្កើនប្រសិទ្ធភាពចំណេញកសិកម្ម (PISA)៖ សហគមន៍កសិកម្មមួយផលិតស្រូវ ដោយមានថ្លៃដើមផលិតសរុប \(C(q) = 2q^2 + 40q + 500\) (គិតជាពាន់រៀល) ចំពោះបរិមាណស្រូវ \(q\) តោន។ តម្លៃលក់គឺ \(120\) ពាន់រៀលក្នុងមួយតោន (\(R(q) = 120q\))។

  1. សរសេរអនុគមន៍ប្រាក់ចំណេញ \(P(q) = R(q) - C(q)\)។

  2. តើត្រូវផលិតស្រូវប៉ុន្មានតោនដើម្បីទទួលបានប្រាក់ចំណេញអតិបរមា? គណនាប្រាក់ចំណេញនោះ។

  3. រកចន្លោះបរិមាណផលិតផលដែលធានាថាមិនខាតបង់ (\(P(q) \ge 0\))។

មើលដំណោះស្រាយ

ការបង្កើនប្រសិទ្ធភាពចំណេញកសិកម្ម (PISA)៖
ថ្លៃដើមផលិត៖ \(C(q) = 2q^2 + 40q + 500\) (ពាន់រៀល)។
ចំណូលពីការលក់ក្នុងតម្លៃ \(120\) ពាន់រៀល/តោន៖ \(R(q) = 120q\)។
ប្រាក់ចំណេញសុទ្ធគឺ \(P(q) = R(q) - C(q)\)៖

\[\begin{aligned} P(q) &= 120q - (2q^2 + 40q + 500) \\ &= -2q^2 + 80q - 500 \\ &= -2(q^2 - 40q + 400) + 800 - 500 \\ &= -2(q - 20)^2 + 300 \end{aligned}\]
ដោយ \(a = -2 < 0\) ប្រាក់ចំណេញអតិបរមាគឺ \(300\) ពាន់រៀល កើតមាននៅពេលសហគមន៍ផលិត និងលក់ស្រូវបានបរិមាណ \(q = 20\) តោន។
