  3. \(D \rightarrow C\) \(\square\)

មើលដំណោះស្រាយ

ពិនិត្យរូបធរណីមាត្រដែលបានឱ្យ ផ្ចិតវិលគឺចំណុច \(O\) ហើយការបំប្លែងវិលប្លែងចំណុច \(I \to N\)៖

មុំវិលកំណត់ដោយ \(\angle(OI, ON)\) ក្នុងទិសដៅច្រាសទ្រនិចនាឡិកា។

តាមលក្ខណៈធរណីមាត្រនៃរូប៖

  • ចំណុច \(D\) ស្ថិតនៅទីតាំងដែលត្រូវបង្វិលជុំវិញ \(O\) ដោយមុំស្មើគ្នានេះ នឹងទៅធ្លាក់ចំចំណុច \(C\) (\(D \to C\))។

  • ចំណុច \(A\) មិនប្លែងទៅ \(B\) ទេ (\(A \to B\) មិនត្រឹមត្រូវ)។

  • \(N \to D\) មិនត្រឹមត្រូវ។

ដូចនេះ ចម្លើយត្រឹមត្រូវគឺ៖

\[\text{\textbf{គ.}~ } D \rightarrow C \quad{} \text{$\text{\rlap{$\checkmark$}}\square$}\]

  1. \(90^\circ\)

  2. \(180^\circ\)

  3. \(270^\circ\)

មើលដំណោះស្រាយ

រូបមន្តនៃការបំប្លែងវិលជុំវិញគល់ \(O(0, 0)\) ដោយមុំវិល \(\theta\) គឺ៖

\[\begin{cases} x' = x\cos\theta - y\sin\theta \\ y' = x\sin\theta + y\cos\theta \end{cases}\]
ចំណុចដើមគឺ \(P(5, 7)\)៖

ក.  មុំវិល \(\theta = 90^\circ\)៖ ដោយ \(\cos 90^\circ = 0\) និង \(\sin 90^\circ = 1\) នាំឱ្យ \((x', y') = (-y, x)\)៖

\[P'(-7, 5)\]
ខ.  មុំវិល \(\theta = 180^\circ\)៖ ដោយ \(\cos 180^\circ = -1\) និង \(\sin 180^\circ = 0\) នាំឱ្យ \((x', y') = (-x, -y)\)៖
\[P'(-5, -7)\]
គ.  មុំវិល \(\theta = 270^\circ\) (ឬ \(-90^\circ\))៖ ដោយ \(\cos 270^\circ = 0\) និង \(\sin 270^\circ = -1\) នាំឱ្យ \((x', y') = (y, -x)\)៖
\[P'(7, -5)\]

៤លំហាត់ទី ៤

រករូបភាពនៃបន្ទាត់ដែលមានសមីការ \(y = x + 2\) តាមការបំប្លែងវិលមុំ \(\alpha = -90^\circ\) ហើយមានផ្ចិតបំប្លែងវិលខាងក្រោម៖

  1. ចំណុច \(O(0, 0)\)

  2. \(P(0, 2)\)

  3. \(Q(-2, 0)\)

មើលដំណោះស្រាយ

បន្ទាត់ដើម \((d): y = x + 2\) មានមេគុណប្រាប់ទិស \(m_1 = 1\)។

ការបំប្លែងវិលដោយមុំ \(\alpha = -90^\circ\) នឹងប្លែងបន្ទាត់ \((d)\) ទៅជាបន្ទាត់កែងនឹងវា គឺមានមេគុណប្រាប់ទិស \(m_2 = -\dfrac{1}{m_1} = -1\)។

ក.  ផ្ចិតវិល \(O(0, 0)\)៖ រូបមន្តវិល \(-90^\circ\) ជុំវិញ \(O\) គឺ \((x', y') = (y, -x) \implies x = -y', y = x'\)។

ជំនួសចូលសមីការដើម៖ \(x' = (-y') + 2 \iff y' = -x' + 2\)។

សមីការរូបភាពគឺ \(y = -x + 2\)។

ខ.  ផ្ចិតវិល \(P(0, 2)\)៖ ដោយសារ \(2 = 0 + 2\) នាំឱ្យចំណុច \(P(0, 2) \in (d)\)។

ចំណុច \(P\) ជាផ្ចិតវិល ដូច្នេះរូបភាពរបស់វាគឺខ្លួនឯង (\(P' \equiv P\))។

បន្ទាត់រូបភាពកាត់តាម \(P(0, 2)\) និងមានមេគុណប្រាប់ទិស \(m = -1\)៖

\[y - 2 = -1(x - 0) \iff y = -x + 2\]
គ.  ផ្ចិតវិល \(Q(-2, 0)\)៖ ដោយសារ \(0 = -2 + 2\) នាំឱ្យចំណុច \(Q(-2, 0) \in (d)\)។

ចំណុច \(Q\) ជាផ្ចិតវិល ដូច្នេះ \(Q' \equiv Q(-2, 0)\)។

បន្ទាត់រូបភាពកាត់តាម \(Q(-2, 0)\) និងមានមេគុណប្រាប់ទិស \(m = -1\)៖

\[y - 0 = -1(x - (-2)) \iff y = -x - 2\]

៨លំហាត់ទី ៨

គេមានត្រីកោណ \(ABC\) មានកំពូល \(A(1, 2)\), \(B(3, 3)\) និង \(C(2, 5)\) ។

មើលដំណោះស្រាយ

ត្រីកោណ \(ABC\) មាន \(A(1, 2), B(3, 3), C(2, 5)\)។

ក.  រកកូអរដោនេនៃកំពូល \(\Delta A'B'C'\) តាម \(R_{(O, -90^\circ)}\)៖ រូបមន្តបំប្លែងវិលដោយមុំ \(-90^\circ\) ជុំវិញ \(O\) គឺ \((x, y) \to (y, -x)\)៖

\[\begin{aligned} A(1, 2) &\to A'(2, -1) \\ B(3, 3) &\to B'(3, -3) \\ C(2, 5) &\to C'(5, -2) \end{aligned}\]
ខ.  គណនាប្រវែងជ្រុងដើម្បីផ្ទៀងផ្ទាត់អ៊ីសូមេទ្រី៖
\[\begin{aligned} AB &= \sqrt{(3 - 1)^2 + (3 - 2)^2} = \sqrt{4 + 1} = \sqrt{5} \\ A'B' &= \sqrt{(3 - 2)^2 + (-3 + 1)^2} = \sqrt{5} \end{aligned}\]
យើងឃើញថា \(A'B' = AB = \sqrt{5}\) (ការបំប្លែងវិលរក្សាប្រវែងជ្រុង)។

  3. សរសេរសមីការបន្ទាត់ \((L')\) កាត់តាមពីរចំណុច \(A'\) និង \(B'\) ។

  4. តើបន្ទាត់ \((L')\) និង \((L)\) មានទំនាក់ទំនងគ្នាយ៉ាងដូចម្ដេច?

មើលដំណោះស្រាយ

បន្ទាត់ \((L): 2x + 3y = 6\)។

ក.  រកកូអរដោនេចំណុចប្រសព្វ \(A\) និង \(B\)៖

  • ប្រសព្វជាមួយ \(Ox\) (\(y = 0\))៖ \(2x = 6 \implies x = 3 \implies A(3, 0)\)

  • ប្រសព្វជាមួយ \(Oy\) (\(x = 0\))៖ \(3y = 6 \implies y = 2 \implies B(0, 2)\)

ខ.  រកកូអរដោនេ \(A'\) និង \(B'\) តាម \(R(O, -90^\circ)\)៖ រូបមន្តគឺ \((x, y) \to (y, -x)\)៖

\[\begin{aligned} A(3, 0) &\to A'(0, -3) \\ B(0, 2) &\to B'(2, 0) \end{aligned}\]
គ.  សរសេរសមីការបន្ទាត់ \((L')\) កាត់តាម \(A'\) និង \(B'\)៖ មេគុណប្រាប់ទិស៖ \(m = \dfrac{0 - (-3)}{2 - 0} = \dfrac{3}{2}\)។

សមីការបន្ទាត់ \((L')\) គឺ៖

\[y = \frac{3}{2}x - 3 \iff 3x - 2y = 6 \quad{} (\text{ឬ } 3x - 2y - 6 = 0)\]
ឃ.  ទំនាក់ទំនងរវាងបន្ទាត់ \((L')\) និង \((L)\)៖ មេគុណប្រាប់ទិសនៃ \((L)\) គឺ \(m_1 = -\dfrac{2}{3}\) និងនៃ \((L')\) គឺ \(m_2 = \dfrac{3}{2}\)។

ផលគុណមេគុណប្រាប់ទិស៖ \(m_1 \times m_2 = \left(-\dfrac{2}{3}\right) \times \left(\dfrac{3}{2}\right) = -1\)។

ដូចនេះ បន្ទាត់ទាំងពីរកាត់កែងគ្នា៖ \((L') \perp (L)\)។

១១លំហាត់ទី ១១

ចំណុច \(M(x, y)\) លើបន្ទាត់ \((L): 3x + y = 1\) ។ តាង \(M'\) ជារូបភាពនៃ \(M\) តាម \(R(O, 90^\circ)\) ។ បីចំណុច \(M, M', O\) បង្កើតបានត្រីកោណកែងត្រង់ \(O\) ។

  1. បង្ហាញថាផ្ទៃក្រឡា \(\triangle OMM'\) គឺ \(A = \frac{1}{2}(10x^2 - 6x + 1)\) ។

  2. រកផ្ទៃក្រឡាអប្បបរមារបស់ត្រីកោណ \(OMM'\) ។

មើលដំណោះស្រាយ

ចំណុច \(M(x, y)\) លើបន្ទាត់ \((L): 3x + y = 1 \implies y = 1 - 3x\)។

រូបភាព \(M'\) តាម \(R(O, 90^\circ)\) គឺ \(M'(-y, x)\)។

ក.  បង្ហាញថាផ្ទៃក្រឡា \(\triangle OMM'\) គឺ \(A = \dfrac{1}{2}(10x^2 - 6x + 1)\)៖ ដោយសារការបំប្លែងវិល \(90^\circ\) ជុំវិញ \(O\) នាំឱ្យ \(OM \perp OM'\) និង \(OM' = OM\)។

ត្រីកោណ \(OMM'\) ជាត្រីកោណកែងសមបាតត្រង់ \(O\)។ ផ្ទៃក្រឡារបស់វាគឺ៖

\[A = \frac{1}{2} OM \times OM' = \frac{1}{2} OM^2 = \frac{1}{2}(x^2 + y^2)\]
ជំនួស \(y = 1 - 3x\) ចូល៖
\[\begin{aligned} A &= \frac{1}{2}\big[x^2 + (1 - 3x)^2\big] \\ &= \frac{1}{2}\big[x^2 + (1 - 6x + 9x^2)\big] \\ &= \frac{1}{2}(10x^2 - 6x + 1) \end{aligned}\]
ខ.  រកផ្ទៃក្រឡាអប្បបរមារបស់ត្រីកោណ \(OMM'\)៖ ត្រីធាដឺក្រេទីពីរ \(f(x) = 10x^2 - 6x + 1\) មាន \(a = 10 > 0\) សម្រេចតម្លៃអប្បបរមាត្រង់៖
\[x = -\frac{b}{2a} = -\frac{-6}{2(10)} = \frac{3}{10} = 0.3\]
តម្លៃអប្បបរមានៃ \(f(x)\) គឺ៖
\[\begin{aligned} f\left(\frac{3}{10}\right) &= 10\left(\frac{9}{100}\right) - 6\left(\frac{3}{10}\right) + 1 \\ &= \frac{9}{10} - \frac{18}{10} + 1 = \frac{1}{10} \end{aligned}\]
ដូចនេះ ផ្ទៃក្រឡាអប្បបរមានៃ \(\triangle OMM'\) គឺ៖
\[A_{\min} = \frac{1}{2} \times \frac{1}{10} = \frac{1}{20} = 0.05 \text{ ឯកតាផ្ទៃ}\]

១២លំហាត់ទី ១២

កង់វិលកម្សាន្ត៖ កង់វិលកម្សាន្តមួយមានកន្ត្រកមួយស្ថិតនៅទីតាំងចំណុច \(A(4, 0)\) ធៀបនឹងផ្ចិតកង់ដែលមានកូអរដោនេ \(O(0, 0)\)។ កង់នេះវិលក្នុងទិសដៅស្របនឹងទ្រនិចនាឡិកា (ទិសដៅអវិជ្ជមាន)។

  1. បន្ទាប់ពីវិលបានមុំ \(-90^\circ\) តើកន្ត្រកនេះនឹងស្ថិតនៅចំណុចណា? តាងដោយ \(A'\)។

  2. ប្រសិនបើកន្ត្រកបន្តវិល \(-180^\circ\) ទៀតពីទីតាំង \(A'\) តើវានឹងទៅដល់ចំណុចណា?

  3. តើចម្ងាយពីផ្ចិត \(O\) ទៅកន្ត្រកប្រែប្រួលដែរឬទេក្នុងពេលកំពុងវិល? ហេតុអ្វី?

មើលដំណោះស្រាយ

កង់វិលកម្សាន្តមានផ្ចិត \(O(0, 0)\) និងកន្ត្រកនៅ \(A(4, 0)\) (កាំ \(R = 4\))។

ក.  ទីតាំង \(A'\) ក្រោយវិលបានមុំ \(-90^\circ\)៖ រូបមន្តវិល \(-90^\circ\) គឺ \((x, y) \to (y, -x)\)៖

\[A(4, 0) \to A'(0, -4)\]
ខ.  ទីតាំងក្រោយវិលបន្ត \(-180^\circ\) ទៀតពី \(A'\)៖ ការវិលបន្ត \(-180^\circ\) ពី \(A'(0, -4)\) មានរូបមន្ត \((x, y) \to (-x, -y)\)៖
\[A'(0, -4) \to A''(0, 4)\]
គ.  ការប្រែប្រួលនៃចម្ងាយពីផ្ចិត \(O\) ទៅកន្ត្រក៖ ចម្ងាយពីផ្ចិត \(O\) ទៅកន្ត្រកមិនប្រែប្រួលទេ (\(OA = OA' = OA'' = 4\)) ពីព្រោះការបំប្លែងវិលរក្សាទុកចម្ងាយពីចំណុចទៅកាន់ផ្ចិតវិល (ចំណុចទាំងអស់ផ្លាស់ទីលើរង្វង់តែមួយដែលមានផ្ចិត \(O\) និងកាំ \(R = 4\))។

១៣លំហាត់ទី ១៣

ប្រព័ន្ធរ៉ាដា៖ អង់តែនរ៉ាដាមួយបាញ់សញ្ញាចាប់បានយន្តហោះមួយគ្រឿងនៅទីតាំង \(P(3, 4)\) ក្នុងតម្រុយកូអរដោនេ (គិតជាគីឡូម៉ែត្រ)។ ដើម្បីតាមដានយន្តហោះមួយទៀត រ៉ាដាត្រូវបង្វិលមុំ \(90^\circ\) ក្នុងទិសដៅច្រាសទ្រនិចនាឡិកា។

  1. តើកូអរដោនេថ្មីនៃទីតាំងដែលរ៉ាដាកំពុងចង្អុលទៅ (តាងដោយ \(P'\)) គឺអ្វី?

  2. គណនាចម្ងាយពីទីតាំងរ៉ាដា \(O(0, 0)\) ទៅយន្តហោះ \(P\) និង \(P'\)។ តើចម្ងាយនេះស្មើគ្នាឬទេ?

មើលដំណោះស្រាយ

ក.  រកកូអរដោនេថ្មី \(P'\)៖ យន្តហោះដើមស្ថិតនៅ \(P(3, 4)\)។ ការបង្វិលរ៉ាដាមុំ \(90^\circ\) ច្រាសទ្រនិចនាឡិកាជុំវិញ \(O(0, 0)\) មានរូបមន្ត \((x, y) \to (-y, x)\)៖

\[P'(-4, 3)\]
ខ.  គណនាចម្ងាយពី \(O\) ទៅ \(P\) និង \(P'\)៖
\[\begin{aligned} OP &= \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5\text{ km} \\ OP' &= \sqrt{(-4)^2 + 3^2} = \sqrt{16 + 9} = \sqrt{25} = 5\text{ km} \end{aligned}\]
ចម្ងាយទាំងពីរនេះស្មើគ្នា (\(OP = OP' = 5\text{ km}\)) ពីព្រោះការបំប្លែងវិលរក្សាចម្ងាយពីចំណុចទៅកាន់ផ្ចិតវិល។

១៤លំហាត់ទី ១៤

គេឱ្យចំណុច \(A(3, 2)\)។ រកកូអរដោនេនៃចំណុច \(A'\) ជាភាពនៃ \(A\) តាមការបំប្លែងវិលជុំវិញគល់ \(O\) ដោយមុំវិល៖

  1. \(\theta = 90^\circ\)

  2. \(\theta = -90^\circ\)

  3. \(\theta = 180^\circ\)

មើលដំណោះស្រាយ

ចំណុច \(A(3, 2)\)។ រូបមន្តវិលជុំវិញគល់ \(O\)៖

ក.  \(\theta = 90^\circ\)៖ \((x', y') = (-y, x) \implies A'(-2, 3)\)
ខ.  \(\theta = -90^\circ\)៖ \((x', y') = (y, -x) \implies A'(2, -3)\)
គ.  \(\theta = 180^\circ\)៖ \((x', y') = (-x, -y) \implies A'(-3, -2)\)

១៥លំហាត់ទី ១៥

គេឱ្យចំណុច \(M(4, -1)\) និងផ្ចិតវិល \(I(1, 2)\)។ រកកូអរដោនេនៃភាព \(M'\) តាមការបំប្លែងវិល \(R_{(I, 90^\circ)}\)។

មើលដំណោះស្រាយ

ចំណុច \(M(4, -1)\) និងផ្ចិតវិល \(I(1, 2)\) មុំ \(\theta = 90^\circ\)។

វ៉ិចទ័រ \(\overrightarrow{IM} = (x_M - x_I, \, y_M - y_I) = (4 - 1, \, -1 - 2) = (3, -3)\)។

រូបភាពនៃវ៉ិចទ័រនេះតាមការវិល \(90^\circ\) គឺ៖

\[\overrightarrow{IM'} = (-y_{\overrightarrow{IM}}, \, x_{\overrightarrow{IM}}) = (-(-3), \, 3) = (3, 3)\]
កូអរដោនេនៃ \(M'\) គឺ៖
\[\begin{cases} x_{M'} = x_I + 3 = 1 + 3 = 4 \\ y_{M'} = y_I + 3 = 2 + 3 = 5 \end{cases} \implies M'(4, 5)\]

១៦លំហាត់ទី ១៦

គេឱ្យបន្ទាត់ \((d): 2x - y + 3 = 0\)។ រកសមីការបន្ទាត់ \((d')\) ជាភាពនៃ \((d)\) តាមការបំប្លែងវិល \(R_{(O, 90^\circ)}\)។

មើលដំណោះស្រាយ

បន្ទាត់ \((d): 2x - y + 3 = 0\)។

ការបំប្លែងវិល \(R_{(O, 90^\circ)}\) មានរូបមន្ត \((x', y') = (-y, x)\)។

ទាញរក \(x\) និង \(y\)៖

\[\begin{cases} x' = -y \implies y = -x' \\ y' = x \implies x = y' \end{cases}\]
ជំនួស \(x\) និង \(y\) ចូលក្នុងសមីការ \((d)\)៖
\[\begin{aligned} 2(y') - (-x') + 3 &= 0 \\ x' + 2y' + 3 &= 0 \end{aligned}\]
ដូចនេះ សមីការបន្ទាត់រូបភាព \((d')\) គឺ \(x + 2y + 3 = 0\)។

១៧លំហាត់ទី ១៧

គេឱ្យរង្វង់ \((C): (x - 2)^2 + (y - 3)^2 = 25\)។ រកសមីការរង្វង់ \((C')\) ជាភាពនៃ \((C)\) តាមការបំប្លែងវិល \(R_{(O, 180^\circ)}\)។

មើលដំណោះស្រាយ

រង្វង់ \((C): (x - 2)^2 + (y - 3)^2 = 25\) មានផ្ចិត \(I(2, 3)\) និងកាំ \(R = 5\)។

តាមការបំប្លែងវិល \(R_{(O, 180^\circ)}\)៖

  • ផ្ចិតថ្មី \(I'\) ជារូបភាពនៃ \(I\) តាមការវិល \(180^\circ\)៖

    \[I'(-2, -3)\]

  • កាំរង្វង់រក្សាតម្លៃដដែល៖ \(R' = R = 5\)

សមីការរង្វង់រូបភាព \((C')\) គឺ៖

\[(x + 2)^2 + (y + 3)^2 = 25\]

១៨លំហាត់ទី ១៨

គេឱ្យត្រីកោណសម័ង្ស \(ABC\) មានផ្ចិត \(O\)។

  1. រករូបភាពនៃត្រីកោណ \(ABC\) តាមការបំប្លែងវិល \(R_{(O, 120^\circ)}\)។

  2. បញ្ជាក់ថាតើត្រីកោណសម័ង្សមានស៊ីមេទ្រីវិលកម្រិតប៉ុន្មាន។

មើលដំណោះស្រាយ

ត្រីកោណសម័ង្ស \(ABC\) មានផ្ចិត \(O\) (ជាទីប្រជុំទម្ងន់ផង ជាផ្ចិតរង្វង់ចារឹកក្រៅផង)។

មុំនៅផ្ចិតស្មើគ្នា៖ \(\widehat{AOB} = \widehat{BOC} = \widehat{COA} = \dfrac{360^\circ}{3} = 120^\circ\)។

ក.  រូបភាពនៃ \(\triangle ABC\) តាម \(R_{(O, 120^\circ)}\)៖ ការវិល \(120^\circ\) ជុំវិញ \(O\) តាមទិសវិជ្ជមានប្លែងកំពូលនីមួយៗទៅកំពូលបន្ទាប់៖

\[A \to B, \quad{} B \to C, \quad{} C \to A\]
រូបភាពនៃត្រីកោណ \(ABC\) គឺត្រីកោណ \(BCA\) ដែលត្រួតស៊ីគ្នាទាំងស្រុងលើ \(\triangle ABC\) ដើម។

ខ.  កម្រិតស៊ីមេទ្រីវិល៖ ត្រីកោណសម័ង្សមានស៊ីមេទ្រីវិល កម្រិត ៣ (Order 3) ត្រូវគ្នានឹងមុំវិល \(120^\circ, 240^\circ\) និង \(360^\circ\) (ឬ \(0^\circ\))។

គេឱ្យចំណុច \(A(2, 0)\)។ រកកូអរដោនេនៃ \(A'\) ជាភាពនៃ \(A\) តាមការបំប្លែងវិល \(R_{(O, 60^\circ)}\)។

មើលដំណោះស្រាយ

ចំណុច \(A(2, 0)\)។ តាមរូបមន្តការបំប្លែងវិល \(R_{(O, 60^\circ)}\)៖

\[\begin{cases} x' = x\cos 60^\circ - y\sin 60^\circ \\ y' = x\sin 60^\circ + y\cos 60^\circ \end{cases}\]
ជំនួស \(x = 2, y = 0\) និង \(\cos 60^\circ = \dfrac{1}{2}, \sin 60^\circ = \dfrac{\sqrt{3}}{2}\)៖
\[\begin{aligned} x' &= 2\left(\frac{1}{2}\right) - 0 = 1 \\ y' &= 2\left(\frac{\sqrt{3}}{2}\right) + 0 = \sqrt{3} \end{aligned}\]
ដូចនេះ កូអរដោនេនៃចំណុចរូបភាពគឺ \(A'(1, \sqrt{3})\)។

២០លំហាត់ទី ២០

បង្ហាញថាក្នុងការបំប្លែងវិល \(R_{(I, \theta)}\) ផ្ចិតវិល \(I\) ជាចំណុចមិនប្រែប្រួលតែមួយគត់ (បើ \(\theta \ne 2k\pi\))។

មើលដំណោះស្រាយ

តាង \(R_{(I, \theta)}\) ជាការបំប្លែងវិលផ្ចិត \(I\) មុំ \(\theta \ne 2k\pi\) (\(k \in \mathbb{Z}\))។

ចំណុច \(M\) គឺជាចំណុចមិនប្រែប្រួល លុះត្រាតែ \(R_{(I, \theta)}(M) = M\)។

តាមនិយមន័យនៃការបំប្លែងវិល៖

  1. ចំពោះចំណុច \(I\)៖ \(R_{(I, \theta)}(I) = I\) ជានិច្ច ហេតុនេះ \(I\) ជាចំណុចមិនប្រែប្រួល។

  2. ចំពោះចំណុច \(M \ne I\)៖ គេមាន \(IM' = IM\) និងមុំតម្រង់ទិស \((\overrightarrow{IM}, \overrightarrow{IM'}) = \theta\)។ ដើម្បីឱ្យ \(M' \equiv M\) លុះត្រាតែមុំ \((\overrightarrow{IM}, \overrightarrow{IM}) = 0 \equiv \theta \pmod{2\pi}\) ដែលផ្ទុយពីសម្មតិកម្ម \(\theta \ne 2k\pi\)។

ដូចនេះ គ្មានចំណុច \(M \ne I\) ណាអាចមិនប្រែប្រួលបានឡើយ។

សរុបមក ផ្ចិតវិល \(I\) គឺជាចំណុចមិនប្រែប្រួលតែមួយគត់នៃការបំប្លែងវិល។

  1. រកភាព \(A'\) និង \(B'\) តាមការបំប្លែងវិល \(R_{(O, 90^\circ)}\)។

  2. គណនាប្រវែង \(AB\) និង \(A'B'\) រួចផ្ទៀងផ្ទាត់ថាការបំប្លែងវិលរក្សាប្រវែងអង្កត់។

មើលដំណោះស្រាយ

ចំណុច \(A(1, 1)\) និង \(B(3, 4)\)។

ក.  រកភាព \(A'\) និង \(B'\) តាម \(R_{(O, 90^\circ)}\)៖ រូបមន្ត \((x, y) \to (-y, x)\)៖

\[A'(-1, 1) \quad{} \text{និង} \quad{} B'(-4, 3)\]
ខ.  គណនាប្រវែង \(AB\) និង \(A'B'\)៖
\[\begin{aligned} AB &= \sqrt{(3 - 1)^2 + (4 - 1)^2} = \sqrt{4 + 9} = \sqrt{13} \\ A'B' &= \sqrt{(-4 + 1)^2 + (3 - 1)^2} = \sqrt{9 + 4} = \sqrt{13} \end{aligned}\]
យើងឃើញថា \(A'B' = AB = \sqrt{13}\) ឯកតា។ នេះបញ្ជាក់ថាការបំប្លែងវិលរក្សាទុកប្រវែងអង្កត់ (Isometry)។

២២លំហាត់ទី ២២

គេឱ្យការបំប្លែងវិលពីរមានផ្ចិតរួម \(O\) គឺ \(R_1 = R_{(O, 30^\circ)}\) និង \(R_2 = R_{(O, 45^\circ)}\)។

  1. កំណត់ការបំប្លែងបណ្តាក់ \(R_2 \circ R_1\)។

  2. រករូបភាពនៃចំណុច \(P(4, 0)\) តាមការបំប្លែងបណ្តាក់នោះ។

មើលដំណោះស្រាយ

ការបំប្លែងវិលពីរមានផ្ចិតរួម \(O\) គឺ \(R_1 = R_{(O, 30^\circ)}\) និង \(R_2 = R_{(O, 45^\circ)}\)។

ក.  កំណត់ការបំប្លែងបណ្តាក់ \(R_2 \circ R_1\)៖ ផលបណ្តាក់នៃការបំប្លែងវិលពីរដែលមានផ្ចិតរួម គឺជាការបំប្លែងវិលមួយដែលមានផ្ចិតរួមដដែល និងមានមុំវិលស្មើផលបូកនៃមុំវិលទាំងពីរ៖

\[R_2 \circ R_1 = R_{(O, \, 30^\circ + 45^\circ)} = R_{(O, 75^\circ)}\]
ខ.  រករូបភាពនៃចំណុច \(P(4, 0)\) តាម \(R_{(O, 75^\circ)}\)៖ រូបមន្តបំប្លែងវិល៖
\[\begin{aligned} x' &= 4\cos 75^\circ - 0\sin 75^\circ = 4\cos 75^\circ \\ y' &= 4\sin 75^\circ + 0\cos 75^\circ = 4\sin 75^\circ \end{aligned}\]
ដោយ \(\cos 75^\circ = \cos(45^\circ + 30^\circ) = \dfrac{\sqrt{6} - \sqrt{2}}{4}\) និង \(\sin 75^\circ = \dfrac{\sqrt{6} + \sqrt{2}}{4}\)៖
\[\begin{aligned} x' &= 4\left(\frac{\sqrt{6} - \sqrt{2}}{4}\right) = \sqrt{6} - \sqrt{2} \\ y' &= 4\left(\frac{\sqrt{6} + \sqrt{2}}{4}\right) = \sqrt{6} + \sqrt{2} \end{aligned}\]
ដូចនេះ \(P'(\sqrt{6} - \sqrt{2}, \, \sqrt{6} + \sqrt{2})\)។

មើលដំណោះស្រាយ

ក.  បញ្ជាក់ប្រភេទ និងធាតុនៃការបំប្លែង៖ កន្សោមនេះមានទម្រង់ \(\begin{cases} x' = x\cos 90^\circ - y\sin 90^\circ \\ y' = x\sin 90^\circ + y\cos 90^\circ \end{cases}\)។

នេះជា ការបំប្លែងវិល (Rotation) ដែលមាន៖

  • ផ្ចិតវិលគឺគល់ \(O(0, 0)\)

  • មុំវិលគឺ \(\theta = 90^\circ\) (ទិសច្រាសទ្រនិចនាឡិកា)

ជំនួសចូលសមីការ \((D)\)៖

\[\begin{aligned} 3(y') + 4(-x') - 5 &= 0 \\ -4x' + 3y' - 5 &= 0 \iff 4x' - 3y' + 5 = 0 \end{aligned}\]
ដូចនេះ សមីការបន្ទាត់រូបភាព \((D')\) គឺ \(4x - 3y + 5 = 0\)។

មើលដំណោះស្រាយ

ចំណុច \(A(5, 2)\) និង \(B(2, -5)\)។

១. បង្ហាញថា \(B\) ជារូបភាពនៃ \(A\) តាមការបំប្លែងវិលផ្ចិត \(O\)៖ គណនាចម្ងាយពីគល់ \(O(0, 0)\) ទៅចំណុចទាំងពីរ៖

\[\begin{aligned} OA &= \sqrt{5^2 + 2^2} = \sqrt{25 + 4} = \sqrt{29} \\ OB &= \sqrt{2^2 + (-5)^2} = \sqrt{4 + 25} = \sqrt{29} \end{aligned}\]
ដោយសារ \(OA = OB = \sqrt{29}\) នាំឱ្យចំណុច \(B\) ស្ថិតនៅលើរង្វង់តែមួយជាមួយ \(A\) ដែលមានផ្ចិត \(O\)។ ហេតុនេះ \(B\) ពិតជាអាចកើតឡើងពី \(A\) តាមការបំប្លែងវិលជុំវិញ \(O\)។

២. កំណត់មុំវិល \(\theta\)៖ ប្រៀបធៀបកូអរដោនេ \(A(5, 2)\) និង \(B(2, -5)\)៖

\[x_B = 2 = y_A \quad{} \text{និង} \quad{} y_B = -5 = -x_A\]
ទំនាក់ទំនងនេះត្រូវគ្នានឹងកន្សោមបំប្លែងវិល \((x', y') = (y, -x)\) ដែលជាការវិលដោយមុំ \(\theta = -90^\circ\) (ស្របទ្រនិចនាឡិកា) ឬ \(\theta = 270^\circ\) (ច្រាសទ្រនិចនាឡិកា)។

គេឱ្យបន្ទាត់ \((d): x + y - 2 = 0\)។ រកសមីការនៃបន្ទាត់ \((d')\) ជាភាពនៃ \((d)\) តាមការបំប្លែងវិល \(R_{(O, 45^\circ)}\)។

មើលដំណោះស្រាយ

បន្ទាត់ \((d): x + y - 2 = 0\)។

រូបមន្តនៃការបំប្លែងវិល \(R_{(O, 45^\circ)}\) គឺ៖

\[\begin{cases} x' = x\cos 45^\circ - y\sin 45^\circ = \dfrac{\sqrt{2}}{2}(x - y) \\[8pt] y' = x\sin 45^\circ + y\cos 45^\circ = \dfrac{\sqrt{2}}{2}(x + y) \end{cases}\]
យើងសង្កេតឃើញថា \(y' = \dfrac{\sqrt{2}}{2}(x + y) \iff x + y = \sqrt{2}y'\)។

ជំនួស \(x + y = \sqrt{2}y'\) ចូលក្នុងសមីការបន្ទាត់ \((d): x + y - 2 = 0\)៖

\[\sqrt{2}y' - 2 = 0 \iff y' = \frac{2}{\sqrt{2}} = \sqrt{2}\]
ដូចនេះ សមីការបន្ទាត់រូបភាព \((d')\) គឺ \(y = \sqrt{2}\) (បន្ទាត់ដេកស្របនឹង \(Ox\))។

បង្ហាញថា ការបំប្លែងវិលដោយមុំ \(\theta = 180^\circ\) ជុំវិញចំណុច \(I\) គឺដូចគ្នាទៅនឹងការបំប្លែងឆ្លុះកណ្តាលធៀបនឹងចំណុច \(I\) (\(R_{(I, 180^\circ)} \equiv S_I\))។

តាង \(M(x, y)\) ជាចំណុចណាមួយក្នុងប្លង់ និង \(I(a, b)\) ជាចំណុចថេរ។

១. តាមការបំប្លែងវិល \(R_{(I, 180^\circ)}\)៖ រូបភាព \(M'\) ផ្ទៀងផ្ទាត់ \(IM' = IM\) និងមុំតម្រង់ទិស \((\overrightarrow{IM}, \overrightarrow{IM'}) = 180^\circ = \pi\)។

មុំ \(180^\circ\) មានន័យថា វ៉ិចទ័រទាំងពីរមានទិសផ្ទុយគ្នា៖

\[\overrightarrow{IM'} = -\overrightarrow{IM} \iff \overrightarrow{IM} + \overrightarrow{IM'} = \vec{0}\]
សមភាពនេះបញ្ជាក់ថា ចំណុច \(I\) គឺជាចំណុចកណ្តាលនៃអង្កត់ \([MM']\)។

២. តាមនិយមន័យនៃការបំប្លែងឆ្លុះកណ្តាល \(S_I\)៖ រូបភាពនៃ \(M\) តាមការឆ្លុះធៀបនឹងចំណុច \(I\) (\(S_I\)) គឺជាចំណុច \(M'\) ដែលធ្វើឱ្យ \(I\) ជាចំណុចកណ្តាលនៃអង្កត់ \([MM']\)។

ដោយសារនិយមន័យទាំងពីរផ្ដល់លទ្ធផលដូចគ្នាទាំងស្រុងចំពោះគ្រប់ចំណុច \(M\) យើងសន្និដ្ឋានបានថា៖

\[R_{(I, 180^\circ)} \equiv S_I\]

២៩លំហាត់ទី ២៩

គេឱ្យឆកោណទៀងទាត់ \(ABCDEF\) មានផ្ចិត \(O\)។

  1. រករូបភាពនៃកំពូលនីមួយៗតាមការបំប្លែងវិល \(R_{(O, 60^\circ)}\)។

  2. រកមុំវិលវិជ្ជមានតូចបំផុតដែលប្លែងឆកោណនេះឱ្យត្រួតស៊ីគ្នាលើខ្លួនឯង។

មើលដំណោះស្រាយ

ឆកោណទៀងទាត់ \(ABCDEF\) មានផ្ចិត \(O\)។ មុំនៅផ្ចិតស្មើគ្នា៖ \(\dfrac{360^\circ}{6} = 60^\circ\)។

ក.  រករូបភាពនៃកំពូលនីមួយៗតាម \(R_{(O, 60^\circ)}\)៖ ការវិល \(60^\circ\) តាមទិសវិជ្ជមាន (ច្រាសទ្រនិចនាឡិកា) ប្លែងកំពូលនីមួយៗទៅកំពូលជាប់បន្ទាប់៖

\[\begin{aligned} A &\to B, \quad{} B \to C, \quad{} C \to D \\ D &\to E, \quad{} E \to F, \quad{} F \to A \end{aligned}\]
រូបភាពនៃឆកោណគឺ \(BCDEFA\) ដែលត្រួតស៊ីគ្នាលើឆកោណដើម \(ABCDEF\)។

ខ.  មុំវិលវិជ្ជមានតូចបំផុតឱ្យឆកោណត្រួតស៊ីគ្នាលើខ្លួនឯង៖ មុំវិលវិជ្ជមានតូចបំផុតនោះគឺមុំនៅផ្ចិតដែលទ្រជ្រុងមួយ៖

\[\theta_{\min} = \frac{360^\circ}{6} = 60^\circ\]

៣០លំហាត់ទី ៣០

គេឱ្យចំណុច \(A(4, 3)\) និង \(I(1, -1)\)។ រកកូអរដោនេនៃ \(A'\) ជាភាពនៃ \(A\) តាមការបំប្លែងវិល \(R_{(I, 180^\circ)}\)។

មើលដំណោះស្រាយ

ចំណុច \(A(4, 3)\) និងផ្ចិតវិល \(I(1, -1)\) មុំ \(\theta = 180^\circ\)។

ការបំប្លែងវិល \(R_{(I, 180^\circ)}\) ស្មើនឹងការបំប្លែងឆ្លុះកណ្តាលធៀបនឹង \(I\) (\(S_I\)) ដែលនាំឱ្យ \(I\) ជាចំណុចកណ្តាលនៃ \([AA']\)៖

\[\begin{cases} x_{A'} = 2x_I - x_A = 2(1) - 4 = -2 \\[6pt] y_{A'} = 2y_I - y_A = 2(-1) - 3 = -5 \end{cases}\]
ដូចនេះ កូអរដោនេនៃចំណុចរូបភាពគឺ \(A'(-2, -5)\)។

៣១លំហាត់ទី ៣១

គេឱ្យប៉ារ៉ាបូល \((P): y = x^2\)។ រកសមីការនៃខ្សែកោង \((P')\) ជាភាពនៃ \((P)\) តាមការបំប្លែងវិល \(R_{(O, 90^\circ)}\)។

មើលដំណោះស្រាយ

ប៉ារ៉ាបូល \((P): y = x^2\)។

ការបំប្លែងវិល \(R_{(O, 90^\circ)}\) មានរូបមន្ត \((x', y') = (-y, x)\)។

ទាញរក \(x\) និង \(y\) ជាអនុគមន៍នៃ \(x'\) និង \(y'\)៖

\[\begin{cases} x = y' \\ y = -x' \end{cases}\]
ជំនួស \(x\) និង \(y\) ចូលក្នុងសមីការប៉ារ៉ាបូល \((P)\)៖
\[\begin{aligned} -x' &= (y')^2 \\ x' &= -(y')^2 \end{aligned}\]
ដូចនេះ សមីការខ្សែកោងរូបភាព \((P')\) គឺ \(x = -y^2\) (ប៉ារ៉ាបូលបើកទៅឆ្វេង)។

៣២លំហាត់ទី ៣២

បង្ហាញថា ការបំប្លែងវិលជាអ៊ីសូមេទ្រីផ្ទាល់ (Direct Isometry) ដែលរក្សាប្រវែង រង្វាស់មុំ និងទិសដៅតម្រង់ទិសនៃប្លង់។

មើលដំណោះស្រាយ

១. រក្សាប្រវែងអង្កត់ (Isometry)៖ យកចំណុចពីរ \(A, B\) និងរូបភាព \(A', B'\) តាម \(R_{(O, \theta)}\)។

ក្នុងត្រីកោណ \(OAB\) និង \(\triangle OA'B'\) យើងមាន៖

  • \(OA' = OA\) (ការវិលរក្សាចម្ងាយពីផ្ចិត)

  • \(OB' = OB\)

  • \(\widehat{A'OB'} = \widehat{A'OA} + \widehat{AOB} - \widehat{B'OB} = \theta + \widehat{AOB} - \theta = \widehat{AOB}\)

នាំឱ្យ \(\triangle OA'B' \cong \triangle OAB\) (ករណី ជ.ម.ជ) ហេតុនេះ \(A'B' = AB\)។

២. ជាអ៊ីសូមេទ្រីផ្ទាល់ (Direct Isometry)៖ ម៉ាទ្រីសតំណាងនៃការបំប្លែងវិលគឺ \(M = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}\)។

ដេទែរមីណង់នៃម៉ាទ្រីស៖

\[\det(M) = \cos^2\theta + \sin^2\theta = +1 > 0\]
ដោយសារ \(\det(M) = +1\) នាំឱ្យការបំប្លែងវិលរក្សាទិសដៅតម្រង់ទិស (Orientation) នៃប្លង់ ហេតុនេះវាជាអ៊ីសូមេទ្រីផ្ទាល់ (Direct Isometry)។

៣៣លំហាត់ទី ៣៣

គេឱ្យចំណុច \(A(2, 1)\) និង \(B(6, 1)\)។ រកកូអរដោនេនៃចំណុច \(C\) ដើម្បីឱ្យត្រីកោណ \(ABC\) ជាត្រីកោណសម័ង្ស (ប្រើការបំប្លែងវិល \(R_{(A, 60^\circ)}\))។

មើលដំណោះស្រាយ

ចំណុច \(A(2, 1)\) និង \(B(6, 1)\) នាំឱ្យ \(\overrightarrow{AB} = (6 - 2, \, 1 - 1) = (4, 0)\) និង \(AB = 4\)។

ដើម្បីឱ្យ \(\triangle ABC\) ជាត្រីកោណសម័ង្ស ចំណុច \(C\) អាចរកបានតាមការបំប្លែងវិល \(R_{(A, 60^\circ)}(B)\)៖

វ៉ិចទ័រ \(\overrightarrow{AC}\) ទទួលបានពីការបង្វិល \(\overrightarrow{AB}\) ដោយមុំ \(60^\circ\)៖

\[\begin{aligned} x_C - x_A &= 4\cos 60^\circ = 2 \implies x_C = 4 \\ y_C - y_A &= 4\sin 60^\circ = 2\sqrt{3} \implies y_C = 1 + 2\sqrt{3} \end{aligned}\]
ដូចនេះ កូអរដោនេនៃ \(C\) គឺ \(C(4, \, 1 + 2\sqrt{3})\) (ឬ \(C'(4, \, 1 - 2\sqrt{3})\) តាមការវិល \(-60^\circ\))។

មើលដំណោះស្រាយ

រង្វង់ \((C): x^2 + y^2 - 4x = 0\)។

សរសេរជាទម្រង់ស្ដង់ដា៖

\[(x - 2)^2 + y^2 = 4\]
នាំឱ្យរង្វង់ \((C)\) មានផ្ចិត \(I(2, 0)\) និងកាំ \(R = \sqrt{4} = 2\)។

តាមការបំប្លែងវិល \(R_{(O, 90^\circ)}\)៖

  • ផ្ចិតថ្មី \(I'\) ជារូបភាពនៃ \(I(2, 0)\)៖

    \[I'(0, 2)\]

  • កាំរង្វង់រក្សាដដែល៖ \(R' = R = 2\)

សមីការរង្វង់រូបភាព \((C')\) គឺ៖

\[(x - 0)^2 + (y - 2)^2 = 2^2 \iff x^2 + (y - 2)^2 = 4\]
(ឬពន្លាត៖ \(x^2 + y^2 - 4y = 0\))។

មើលដំណោះស្រាយ

ចំណុច \(A(2, 3)\) និង \(A'(-1, 4)\) ដោយ \(A' = R_{(O, \theta)}(A)\)។

រូបមន្តបំប្លែងវិលផ្ដល់ប្រព័ន្ធសមីការ៖

\[\begin{cases} -1 = 2\cos\theta - 3\sin\theta \quad{} (1) \\ 4 = 2\sin\theta + 3\cos\theta \quad{} (2) \end{cases}\]
គុណសមីការ (1) នឹង \(2\) និងគុណសមីការ (2) នឹង \(3\)៖
\[\begin{aligned} -2 &= 4\cos\theta - 6\sin\theta \\ 12 &= 9\cos\theta + 6\sin\theta \end{aligned}\]
បូកសមីការទាំងពីរចូលគ្នា៖
\[10 = 13\cos\theta \implies \cos\theta = \frac{10}{13}\]
ជំនួស \(\cos\theta = \dfrac{10}{13}\) ចូលសមីការ (2)៖
\[\begin{aligned} 2\sin\theta &= 4 - 3\left(\frac{10}{13}\right) = \frac{22}{13} \\ \implies \sin\theta &= \frac{11}{13} \end{aligned}\]
ដូចនេះ \(\cos\theta = \dfrac{10}{13}\) និង \(\sin\theta = \dfrac{11}{13}\)។

  2. រកកម្ពស់នៃកន្ត្រកធៀបនឹងដីនៅពេលកង់វិលបានមុំ \(120^\circ\)។

មើលដំណោះស្រាយ

កង់វិលកម្សាន្តមានកាំ \(R = 20\text{ m}\) ផ្ចិត \(O(0, 25)\) និងទីតាំងទាបបំផុត \(P_0(0, 5)\)។

ក.  រកកូអរដោនេកន្ត្រកពេលវិលបានមុំ \(90^\circ\) ច្រាសទ្រនិចនាឡិកា៖ វ៉ិចទ័រពីផ្ចិតទៅចំណុចដើមគឺ \(\overrightarrow{OP_0} = (0 - 0, \, 5 - 25) = (0, -20)\)។

បង្វិលវ៉ិចទ័រនេះដោយមុំ \(90^\circ\) ច្រាសទ្រនិចនាឡិកាបាន \((x', y') = (-(-20), 0) = (20, 0)\)។

កូអរដោនេថ្មីនៃកន្ត្រកគឺ៖

\[P_1 = O + (20, 0) = (0 + 20, \, 25 + 0) = (20, 25)\]
ខ.  រកកម្ពស់ធៀបនឹងដីពេលវិលបានមុំ \(120^\circ\)៖ នៅទីតាំងដើម \(P_0\) មុំប៉ូលែធៀបនឹងផ្ចិត \(O\) គឺ \(\alpha_0 = -90^\circ\)។

ក្រោយពេលវិលបានមុំ \(+120^\circ\) មុំថ្មីគឺ \(\alpha = -90^\circ + 120^\circ = 30^\circ\)។

អរដោនេ (កម្ពស់ធៀបនឹងដី) គឺ៖

\[\begin{aligned} y &= y_O + R\sin 30^\circ \\ &= 25 + 20\left(\frac{1}{2}\right) = 35\text{ m} \end{aligned}\]
ដូចនេះ កម្ពស់នៃកន្ត្រកធៀបនឹងដីគឺ \(35\text{ m}\)។

គេឱ្យត្រីកោណ \(ABC\) កែងត្រង់ \(A\) ដែលមាន \(AB = AC\) (កែងសមបាត)។ បង្ហាញថាការបំប្លែងវិល \(R_{(A, 90^\circ)}\) ប្លែងចំណុច \(B\) ទៅជាចំណុច \(C\) (ឬផ្ទុយទៅវិញ)។

មើលដំណោះស្រាយ

ត្រីកោណ \(ABC\) កែងសមបាតត្រង់ \(A\) នាំឱ្យ \(AB = AC\) និង \(\widehat{BAC} = 90^\circ\)។

ពិនិត្យការបំប្លែងវិល \(R_{(A, 90^\circ)}\) ដែលមានផ្ចិត \(A\) និងមុំ \(90^\circ\)៖

  1. ផ្ចិត \(A\) ជាចំណុចមិនប្រែប្រួល៖ \(R_{(A, 90^\circ)}(A) = A\)។

  2. ចម្ងាយពីផ្ចិតទៅ \(B\) គឺ \(AB\)។ ដោយសារ \(AB = AC\) នាំឱ្យរូបភាពត្រូវមានចម្ងាយ \(AC\) ពី \(A\)។

  3. មុំរវាងកន្លះបន្ទាត់ \([AB)\) និង \([AC)\) គឺ \(\widehat{BAC} = 90^\circ\) តាមទិសវិជ្ជមាន (ឬអវិជ្ជមានអាស្រ័យតាមការរៀបកំពូល)។

ហេតុនេះ ការបង្វិលកាំរស្មី \([AB)\) ដោយមុំ \(90^\circ\) ជុំវិញ \(A\) នឹងធ្វើឱ្យវាត្រួតស៊ីគ្នាលើកាំរស្មី \([AC)\) ហើយដោយ \(AB = AC\) នាំឱ្យ៖

\[R_{(A, 90^\circ)}(B) = C\]
(ឬបើតម្រង់ទិសផ្ទុយគឺ \(R_{(A, -90^\circ)}(B) = C\))។

៣៨លំហាត់ទី ៣៨

គេឱ្យបន្ទាត់ពីរ \((d_1): x - 2y + 1 = 0\) និង \((d_2): 2x + y - 4 = 0\)។ បង្ហាញថា \((d_2)\) ជារូបភាពនៃ \((d_1)\) តាមការបំប្លែងវិលជុំវិញចំណុចប្រសព្វនៃបន្ទាត់ទាំងពីរដោយមុំ \(90^\circ\)។

មើលដំណោះស្រាយ

បន្ទាត់ \((d_1): x - 2y + 1 = 0\) មានវ៉ិចទ័រណរម៉ាល់ \(\vec{n}_1 = (1, -2)\)។

បន្ទាត់ \((d_2): 2x + y - 4 = 0\) មានវ៉ិចទ័រណរម៉ាល់ \(\vec{n}_2 = (2, 1)\)។

គណនាផលគុណស្កាលែនៃវ៉ិចទ័រណរម៉ាល់ទាំងពីរ៖

\[\vec{n}_1 \cdot \vec{n}_2 = 1(2) + (-2)(1) = 2 - 2 = 0\]
ដោយសារ \(\vec{n}_1 \cdot \vec{n}_2 = 0 \implies \vec{n}_1 \perp \vec{n}_2\) នាំឱ្យបន្ទាត់ទាំងពីរកាត់កែងគ្នា៖ \((d_1) \perp (d_2)\)។

តាង \(I\) ជាចំណុចប្រសព្វរវាង \((d_1)\) និង \((d_2)\) (\(I \in (d_1)\) និង \(I \in (d_2)\))។

ការបំប្លែងវិលជុំវិញផ្ចិត \(I\) ដោយមុំ \(90^\circ\) នឹងរក្សាទុកចំណុច \(I\) នៅដដែល និងបង្វិលគ្រប់បន្ទាត់កាត់តាម \(I\) ដោយមុំ \(90^\circ\)។

ដោយហេតុថា \((d_2)\) កាត់តាម \(I\) ហើយកែងនឹង \((d_1)\) នោះរូបភាពនៃ \((d_1)\) តាមការបំប្លែងវិល \(R_{(I, 90^\circ)}\) គឺពិតជាបន្ទាត់ \((d_2)\)។

៣៩លំហាត់ទី ៣៩

រកកូអរដោនេនៃផ្ចិតវិល \(I\) បើដឹងថាការបំប្លែងវិល \(R_{(I, 90^\circ)}\) ប្លែងចំណុច \(A(1, 2)\) ទៅជា \(A'(3, 4)\)។

មើលដំណោះស្រាយ

តាងផ្ចិតវិលគឺ \(I(a, b)\)។

រូបមន្តបំប្លែងវិល \(90^\circ\) ជុំវិញ \(I(a, b)\) គឺ៖

\[\begin{cases} x' - a = -(y - b) \\ y' - b = x - a \end{cases}\]
ជំនួសកូអរដោនេ \(A(1, 2)\) និង \(A'(3, 4)\) ចូល៖
\[\begin{cases} 3 - a = -(2 - b) \iff a + b = 5 \quad{} (1) \\ 4 - b = 1 - a \iff a - b = -3 \quad{} (2) \end{cases}\]
បូកសមីការ (1) និង (2)៖
\[2a = 2 \implies a = 1\]
ជំនួស \(a = 1\) ចូល (1)៖ \(1 + b = 5 \implies b = 4\)។

ដូចនេះ កូអរដោនេនៃផ្ចិតវិលគឺ \(I(1, 4)\)។

៤០លំហាត់ទី ៤០

គេឱ្យចំណុច \(A(3, 0)\) និង \(B(0, 3)\)។ រកចំណុច \(C\) ដើម្បីឱ្យ \(\triangle ABC\) ក្លាយជាត្រីកោណសម័ង្ស។

មើលដំណោះស្រាយ

ចំណុច \(A(3, 0)\) និង \(B(0, 3)\) នាំឱ្យ \(\overrightarrow{AB} = (-3, 3)\) និង \(AB = \sqrt{(-3)^2 + 3^2} = 3\sqrt{2}\)។

ដើម្បីឱ្យ \(\triangle ABC\) ជាត្រីកោណសម័ង្ស ចំណុច \(C\) អាចរកបានតាមការបំប្លែងវិល \(R_{(A, 60^\circ)}\)៖

\[\begin{aligned} x_C - 3 &= -3\left(\frac{1}{2}\right) - 3\left(\frac{\sqrt{3}}{2}\right) = \frac{-3 - 3\sqrt{3}}{2} \\ x_C &= 3 + \frac{-3 - 3\sqrt{3}}{2} = \frac{3 - 3\sqrt{3}}{2} \\[6pt] y_C &= -3\left(\frac{\sqrt{3}}{2}\right) + 3\left(\frac{1}{2}\right) = \frac{3 - 3\sqrt{3}}{2} \end{aligned}\]
ដូចនេះ ចំណុច \(C\) គឺ \(C\left(\frac{3 - 3\sqrt{3}}{2}, \, \frac{3 - 3\sqrt{3}}{2}\right)\)
(ឬចំណុចស៊ីមេទ្រីតាមការវិល \(-60^\circ\) គឺ \(C'\left(\frac{3 + 3\sqrt{3}}{2}, \, \frac{3 + 3\sqrt{3}}{2}\right)\))។

៤១លំហាត់ទី ៤១

បង្ហាញថា ផលបណ្តាក់នៃការបំប្លែងវិលពីរដែលមានផ្ចិតខុសគ្នា \(R_{(A, \alpha)}\) និង \(R_{(B, -\alpha)}\) គឺជាការបំប្លែងកិលមួយ។

មើលដំណោះស្រាយ

តាង \(f = R_{(B, -\alpha)} \circ R_{(A, \alpha)}\) ជាផលបណ្តាក់នៃការបំប្លែងវិលទាំងពីរ។

  1. ការបំប្លែងវិលទាំងពីរ \(R_{(A, \alpha)}\) និង \(R_{(B, -\alpha)}\) សុទ្ធតែជាអ៊ីសូមេទ្រីផ្ទាល់ (Direct Isometries)។

  2. ផលបណ្តាក់នៃអ៊ីសូមេទ្រីផ្ទាល់ពីរ គឺជាអ៊ីសូមេទ្រីផ្ទាល់មួយ (Direct Isometry)។

  3. មុំវិលសរុបនៃផលបណ្តាក់គឺស្មើផលបូកនៃមុំវិលទាំងពីរ៖

    \[\theta_{\text{សរុប}} = \alpha + (-\alpha) = 0\]

ក្នុងប្លង់ អ៊ីសូមេទ្រីផ្ទាល់ដែលមានមុំវិលស្មើ \(0\) គឺជាការបំប្លែងកិល (Translation) ឬជាការបំប្លែងឯកត្តកម្ម (ករណី \(A \equiv B\))។

ដោយសារ \(A \ne B\) ផលបណ្តាក់នេះមិនមែនជាការបំប្លែងឯកត្តកម្មទេ ដូច្នេះវាគឺជា ការបំប្លែងកិល ពិតប្រាកដ។

៤២លំហាត់ទី ៤២

(PISA - ទ្រនិចនាឡិកា) នាឡិកាជញ្ជាំងមួយមានទ្រនិចខ្លី (ទ្រនិចម៉ោង) ប្រវែង \(6\text{ cm}\) និងទ្រនិចវែង (ទ្រនិចនាទី) ប្រវែង \(10\text{ cm}\)។ ផ្ចិតនាឡិកាស្ថិតនៅគល់ \(O(0, 0)\)។

  1. នៅម៉ោង \(12: 00\) ត្រង់ ទ្រនិចទាំងពីរសុទ្ធតែចង្អុលទៅទិសខាងលើ (អ័ក្ស \(+Oy\))។ រកកូអរដោនេនៃចុងទ្រនិចទាំងពីរ។

  2. នៅម៉ោង \(3: 00\) រកកូអរដោនេនៃចុងទ្រនិចម៉ោង តាមរយៈការបំប្លែងវិល។

  3. គណនាមុំវិលនៃទ្រនិចនាទីក្នុងរយៈពេល \(20\) នាទី។

មើលដំណោះស្រាយ

ក.  កូអរដោនេចុងទ្រនិចនៅម៉ោង \(12: 00\)៖ ទ្រនិចទាំងពីរកំពុងចង្អុលចំទិសឈរឡើងលើតាមអ័ក្ស \(+Oy\)៖

  • ទ្រនិចម៉ោង (ប្រវែង \(6\text{ cm}\))៖ \(H(0, 6)\)

  • ទ្រនិចនាទី (ប្រវែង \(10\text{ cm}\))៖ \(M(0, 10)\)

ខ.  កូអរដោនេចុងទ្រនិចម៉ោងនៅម៉ោង \(3: 00\)៖ ពីម៉ោង \(12\) ដល់ម៉ោង \(3\) ទ្រនិចម៉ោងវិលបានមុំ \(90^\circ\) តាមទិសទ្រនិចនាឡិកា (មុំវិល \(\theta = -90^\circ\))៖

\[H(0, 6) \xrightarrow{R_{(O, -90^\circ)}} H'(6, 0)\]
គ.  មុំវិលនៃទ្រនិចនាទីក្នុងរយៈពេល ២០ នាទី៖ ទ្រនិចនាទីវិលមួយជុំ (\(360^\circ\)) ក្នុងរយៈពេល \(60\) នាទី។ ក្នុងរយៈពេល \(20\) នាទី មុំវិលគឺ៖
\[\theta = \frac{20}{60} \times 360^\circ = 120^\circ\]
តាមទិសដៅទ្រនិចនាឡិកា (ទិសអវិជ្ជមាន) មុំវិលគឺ \(-120^\circ\)។

៤៣លំហាត់ទី ៤៣

គេឱ្យចំណុច \(M(r\cos\alpha, r\sin\alpha)\) ក្នុងកូអរដោនេប៉ូលែ។ បង្ហាញថារូបភាពនៃ \(M\) តាម \(R_{(O, \theta)}\) គឺ \(M'(r\cos(\alpha+\theta), r\sin(\alpha+\theta))\)។

មើលដំណោះស្រាយ

ចំណុច \(M\) មានកូអរដោនេប៉ូលែ \(x = r\cos\alpha\) និង \(y = r\sin\alpha\)។

តាមរូបមន្តបំប្លែងវិល \(R_{(O, \theta)}\) កូអរដោនេនៃ \(M'(x', y')\) គឺ៖

\[\begin{aligned} x' &= x\cos\theta - y\sin\theta \\ &= (r\cos\alpha)\cos\theta - (r\sin\alpha)\sin\theta \\ &= r(\cos\alpha\cos\theta - \sin\alpha\sin\theta) \end{aligned}\]
តាមរូបមន្តត្រីកោណមាត្រ \(\cos(\alpha + \theta) = \cos\alpha\cos\theta - \sin\alpha\sin\theta\) នាំឱ្យ៖
\[x' = r\cos(\alpha + \theta)\]
ដូចគ្នាដែរ ចំពោះ \(y'\)៖
\[\begin{aligned} y' &= x\sin\theta + y\cos\theta \\ &= (r\cos\alpha)\sin\theta + (r\sin\alpha)\cos\theta \\ &= r(\sin\theta\cos\alpha + \cos\theta\sin\alpha) \\ &= r\sin(\alpha + \theta) \end{aligned}\]
ដូចនេះ \(M'(r\cos(\alpha + \theta), \, r\sin(\alpha + \theta))\) ត្រូវបានបង្ហាញត្រឹមត្រូវ។

៤៤លំហាត់ទី ៤៤

គេឱ្យត្រីកោណ \(ABC\)។ នៅលើជ្រុង \([AB]\) និង \([AC]\) ខាងក្រៅត្រីកោណ គេសង់ការ៉េ \(ABDE\) និង \(ACFG\)។ បង្ហាញថា \(CD = BF\) និង \(CD \perp BF\) ដោយប្រើការបំប្លែងវិល \(R_{(A, 90^\circ)}\)។

មើលដំណោះស្រាយ

ពិនិត្យការបំប្លែងវិល \(R_{(A, 90^\circ)}\) ដែលមានផ្ចិត \(A\) និងមុំ \(90^\circ\) តាមទិសវិជ្ជមាន៖

  • ដោយសារ \(ABDE\) ជាការ៉េ នាំឱ្យ \(AB = AD\) និង \(\widehat{BAD} = 90^\circ\) ហេតុនេះ \(R_{(A, 90^\circ)}(B) = D\)។

  • ដោយសារ \(ACFG\) ជាការ៉េ នាំឱ្យ \(AF = AC\) និង \(\widehat{FAC} = 90^\circ\) ហេតុនេះ \(R_{(A, 90^\circ)}(F) = C\) (ឬតាមទិសវិលត្រូវគ្នា)។

ការបំប្លែងវិល \(R_{(A, 90^\circ)}\) ប្លែងអង្កត់ \([BF]\) ទៅជាអង្កត់ \([DC]\)។

ដោយសារការបំប្លែងវិលរក្សាប្រវែងអង្កត់ និងបង្វិលបន្ទាត់ដោយមុំ \(90^\circ\) យើងទាញបានភ្លាមៗថា៖

\[CD = BF \quad{} \text{និង} \quad{} CD \perp BF\]

៤៥លំហាត់ទី ៤៥

គេឱ្យបន្ទាត់ \((d): y = \sqrt{3}x + 2\)។ រកសមីការនៃបន្ទាត់ \((d')\) ជាភាពនៃ \((d)\) តាមការបំប្លែងវិល \(R_{(O, 60^\circ)}\)។

មើលដំណោះស្រាយ

បន្ទាត់ \((d): y = \sqrt{3}x + 2\)។

មេគុណប្រាប់ទិស \(m = \sqrt{3} \implies \tan\alpha = \sqrt{3} \implies \alpha = 60^\circ\)។

ប្រសព្វជាមួយអ័ក្ស \(Oy\) គឺចំណុច \(A(0, 2)\)។

  • ក្រោយពេលវិល \(60^\circ\) ច្រាសទ្រនិចនាឡិកា មុំទិសថ្មីគឺ \(\alpha' = 60^\circ + 60^\circ = 120^\circ\)។

    មេគុណប្រាប់ទិសនៃ \((d')\) គឺ \(m' = \tan 120^\circ = -\sqrt{3}\)។

  • រូបភាពនៃចំណុច \(A(0, 2)\) តាម \(R_{(O, 60^\circ)}\)៖

    \[\begin{cases} x' = -2\sin 60^\circ = -\sqrt{3} \\ y' = 2\cos 60^\circ = 1 \end{cases} \implies A'(-\sqrt{3}, 1)\]

សមីការបន្ទាត់ \((d')\) កាត់តាម \(A'(-\sqrt{3}, 1)\) មានមេគុណប្រាប់ទិស \(m' = -\sqrt{3}\)៖

\[\begin{aligned} y - 1 &= -\sqrt{3}(x - (-\sqrt{3})) \\ y - 1 &= -\sqrt{3}(x + \sqrt{3}) = -\sqrt{3}x - 3 \\ \sqrt{3}x + y + 2 &= 0 \end{aligned}\]
ដូចនេះ សមីការបន្ទាត់រូបភាពគឺ \(\sqrt{3}x + y + 2 = 0\)។

៤៦លំហាត់ទី ៤៦

រកកូអរដោនេនៃចំណុច \(P'\) ជាភាពនៃ \(P(-2, 3)\) តាមការបំប្លែងវិល \(R_{(I, -90^\circ)}\) ដោយផ្ចិត \(I(1, 1)\)។

មើលដំណោះស្រាយ

ចំណុច \(P(-2, 3)\) ផ្ចិតវិល \(I(1, 1)\) មុំវិល \(\theta = -90^\circ\)។

រូបមន្តបំប្លែងវិលដោយមុំ \(-90^\circ\) ជុំវិញ \(I(a, b)\) គឺ៖

\[\begin{cases} x' - a = y - b \\ y' - b = -(x - a) \end{cases}\]
ជំនួស \(a = 1, b = 1\) និង \(x = -2, y = 3\)៖
\[\begin{aligned} x' - 1 &= 3 - 1 = 2 \implies x' = 3 \\ y' - 1 &= -(-2 - 1) = -(-3) = 3 \implies y' = 4 \end{aligned}\]
ដូចនេះ កូអរដោនេនៃចំណុចរូបភាពគឺ \(P'(3, 4)\)។

៤៧លំហាត់ទី ៤៧

គេឱ្យផ្កាយប្រាំបែកទៀងទាត់មួយមានផ្ចិត \(O\)។ រកមុំវិលវិជ្ជមានតូចបំផុតដែលប្លែងផ្កាយនេះឱ្យត្រួតស៊ីគ្នាលើខ្លួនឯង។

មើលដំណោះស្រាយ

ផ្កាយប្រាំបែកទៀងទាត់មួយមានកំពូលទាំង ៥ ចែករង្វង់ជុំវិញផ្ចិត \(O\) ជា ៥ ធ្នូស្មើៗគ្នា។

មុំនៅផ្ចិតរវាងកំពូលជាប់គ្នាពីរគឺ៖

\[\theta = \frac{360^\circ}{5} = 72^\circ\]
ការបំប្លែងវិលជុំវិញផ្ចិត \(O\) ដោយមុំ \(72^\circ\) នឹងប្លែងកំពូលនីមួយៗឱ្យទៅធ្លាក់ចំកំពូលបន្ទាប់ ហេតុនេះរូបផ្កាយទាំងមូលនឹងត្រួតស៊ីគ្នាលើខ្លួនឯងដដែល។

ដូចនេះ មុំវិលវិជ្ជមានតូចបំផុតគឺ \(\theta = 72^\circ\)។

៤៨លំហាត់ទី ៤៨

(PISA - រ៉ាដាស្កេន (Radar Scanner)) អង់តែនរ៉ាដាត្រួតពិនិត្យដែនអាកាសមួយវិលជុំវិញផ្ចិត \(O\) ដោយល្បឿនថេរ \(6\) ជុំ/នាទី ។

  1. គណនាល្បឿនមុំនៃការវិល (គិតជា ដឺក្រេ/វិនាទី)។

  2. បើរ៉ាដាចាប់បានសញ្ញាយន្តហោះមួយនៅទីតាំង \((30, 40)\text{ km}\) នៅខណៈ \(t = 0\) ហើយយន្តហោះហោះហើរតាមគន្លងរង្វង់ជុំវិញ \(O\) ដោយល្បឿនមុំស្មើនឹងរ៉ាដា តើទីតាំងយន្តហោះនៅឯណាពេល \(t = 2.5\) វិនាទី ?

មើលដំណោះស្រាយ

ក.  គណនាល្បឿនមុំនៃការវិល៖ រ៉ាដាវិលបាន \(6\) ជុំ/នាទី ។ មួយជុំស្មើនឹង \(360^\circ\)៖

\[\omega = \frac{6 \times 360^\circ}{60\text{ s}} = \frac{2160^\circ}{60\text{ s}} = 36^\circ/\text{s}\]
ខ.  រកទីតាំងយន្តហោះនៅខណៈ \(t = 2.5\) វិនាទី ៖ ក្នុងរយៈពេល \(t = 2.5\text{ s}\) មុំវិលសរុបគឺ៖
\[\theta = \omega \times t = 36^\circ \times 2.5 = 90^\circ\]
ទីតាំងដើមគឺ \(P(30, 40)\text{ km}\)។ ការវិលជុំវិញគល់ \(O(0, 0)\) ដោយមុំ \(90^\circ\) មានរូបមន្ត \((x', y') = (-y, x)\)៖
\[P'(-40, 30)\text{ km}\]
ដូចនេះ ទីតាំងយន្តហោះនៅខណៈ \(t = 2.5\text{ s}\) គឺ \((-40, 30)\text{ km}\)។

៤៩លំហាត់ទី ៤៩

គេឱ្យចំណុច \(A(1, 0), B(0, 1), C(-1, 0), D(0, -1)\)។ បង្ហាញថា \(ABCD\) ជាការ៉េដោយប្រើការបំប្លែងវិល \(R_{(O, 90^\circ)}\)។

មើលដំណោះស្រាយ

ចំណុច \(A(1, 0), B(0, 1), C(-1, 0), D(0, -1)\)។

អនុវត្តការបំប្លែងវិល \(R_{(O, 90^\circ)}\) ដែលមានរូបមន្ត \((x, y) \to (-y, x)\)៖

\[\begin{aligned} A(1, 0) &\to (-0, 1) = (0, 1) = B \\ B(0, 1) &\to (-1, 0) = C \\ C(-1, 0) &\to (0, -1) = D \\ D(0, -1) &\to (-(-1), 0) = (1, 0) = A \end{aligned}\]
ការបំប្លែងវិល \(R_{(O, 90^\circ)}\) ប្លែងកំពូល \(A \to B \to C \to D \to A\) និងប្លែងជ្រុង \([AB] \to [BC] \to [CD] \to [DA] \to [AB]\)។

ដោយសារការបំប្លែងវិលជាអ៊ីសូមេទ្រី វារក្សាប្រវែងជ្រុង (\(AB = BC = CD = DA\)) និងបង្វិលជ្រុងជាប់គ្នាដោយមុំ \(90^\circ\) (\(\widehat{ABC} = \widehat{BCD} = \widehat{CDA} = \widehat{DAB} = 90^\circ\))។

ដូចនេះ ចតុកោណ \(ABCD\) គឺជាការ៉េពិតប្រាកដ។

៥០លំហាត់ទី ៥០

(PISA - ថាមពលកង្ហារខ្យល់ Wind Turbine) កង្ហារខ្យល់មួយមានស្លាប ៣ ស្មើៗគ្នា ប្រវែងស្លាបនីមួយៗគឺ \(40\text{ m}\) ភ្ជាប់គ្នាត្រង់ផ្ចិត \(O(0, 50)\) (គិតជាម៉ែត្រ)។ ស្លាបទីមួយចង្អុលចំទិសឈរត្រង់ឡើងលើនៅខណៈដើម។

  1. រកកូអរដោនេនៃចុងស្លាបទាំងបីនៅខណៈដើម។

  2. រកកូអរដោនេនៃចុងស្លាបទីមួយក្រោយពេលកង្ហារវិលបានមុំ \(45^\circ\) តាមទិសទ្រនិចនាឡិកា។

មើលដំណោះស្រាយ

ក.  រកកូអរដោនេនៃចុងស្លាបទាំងបីនៅខណៈដើម៖ ផ្ចិតកង្ហារស្ថិតនៅ \(O(0, 50)\) និងប្រវែងស្លាប \(R = 40\text{ m}\)។

ស្លាបទាំង ៣ បង្កើតមុំ \(120^\circ\) នឹងគ្នា៖

  • ស្លាបទី ១ (ចង្អុលឡើងលើ \(\alpha_1 = 90^\circ\))៖

    \[A_1(0, \, 50 + 40) = A_1(0, 90)\]

  • ស្លាបទី ២ (មុំ \(\alpha_2 = 90^\circ + 120^\circ = 210^\circ\))៖

    \[\begin{cases} x_2 = 40\left(-\dfrac{\sqrt{3}}{2}\right) = -20\sqrt{3} \\[6pt] y_2 = 50 + 40\left(-\dfrac{1}{2}\right) = 30 \end{cases}\]
    \(\implies A_2(-20\sqrt{3}, 30)\)

  • ស្លាបទី ៣ (មុំ \(\alpha_3 = 210^\circ + 120^\circ = 330^\circ\))៖

    \[\begin{cases} x_3 = 40\left(\dfrac{\sqrt{3}}{2}\right) = 20\sqrt{3} \\[6pt] y_3 = 50 + 40\left(-\dfrac{1}{2}\right) = 30 \end{cases}\]
    \(\implies A_3(20\sqrt{3}, 30)\)

ខ.  កូអរដោនេចុងស្លាបទី ១ ក្រោយវិលបាន \(45^\circ\) តាមទ្រនិចនាឡិកា៖ មុំថ្មីធៀបនឹងផ្ចិត \(O\) គឺ \(\alpha' = 90^\circ - 45^\circ = 45^\circ\)៖

\[\begin{cases} x' = 40\left(\dfrac{\sqrt{2}}{2}\right) = 20\sqrt{2} \approx 28.28\text{ m} \\[6pt] y' = 50 + 20\sqrt{2} \approx 78.28\text{ m} \end{cases}\]
ដូចនេះ កូអរដោនេចុងស្លាបទី ១ គឺ \((20\sqrt{2}, \, 50 + 20\sqrt{2})\)។
