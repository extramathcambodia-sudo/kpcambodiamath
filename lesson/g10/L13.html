\[\begin{cases} 2x + y \le 6 \\ x + 2y \le 6 \\ x \ge 0, \quad{} y \ge 0 \end{cases}\]

មើលដំណោះស្រាយ

រកកូអរដោនេកំពូលនៃតំបន់ចម្លើយ ៖
\(\begin{cases} 2x + y \le 6 \quad{} (1) \\ x + 2y \le 6 \quad{} (2) \\ x \ge 0, \quad{} y \ge 0 \end{cases}\)
- គល់កូអរដោនេ ៖ \(O(0, 0)\)
- ប្រសព្វលើ \(Ox\) ៖ \(A(3, 0)\) (ពី \(2x + y = 6\))
- ប្រសព្វលើ \(Oy\) ៖ \(C(0, 3)\) (ពី \(x + 2y = 6\))
- ប្រសព្វរវាង \((1)\) និង \((2)\) ៖
បូក \((1)\) និង \((2)\) ៖ \(3x + 3y = 12 \iff x + y = 4 \iff x = 4 - y\)
ជំនួសចូល \((1)\) ៖ \(2(4 - y) + y = 6 \iff 8 - y = 6 \iff y = 2\)
ទាញបាន \(x = 4 - 2 = 2 \implies B(2, 2)\)។
ដូចនេះ កំពូលទាំង ៤ គឺ \(O(0, 0), A(3, 0), B(2, 2), C(0, 3)\)។

\[\begin{cases} x + y \le 5 \\ 2x + y \le 8 \\ x \ge 0, \quad{} y \ge 0 \end{cases}\]

មើលដំណោះស្រាយ

រកកូអរដោនេកំពូលទាំងអស់នៃប្រព័ន្ធ ៖
\(\begin{cases} x + y \le 5 \\ 2x + y \le 8 \\ x \ge 0, \quad{} y \ge 0 \end{cases}\)
- គល់កូអរដោនេ ៖ \(O(0, 0)\)
- លើ \(Ox\) ៖ យកតម្លៃតូចជាង \(x = \min(5, 4) = 4 \implies A(4, 0)\)
- លើ \(Oy\) ៖ យកតម្លៃតូចជាង \(y = \min(5, 8) = 5 \implies C(0, 5)\)
- ប្រសព្វរវាងបន្ទាត់ទាំងពីរ ៖
\((2x + y) - (x + y) = 8 - 5 \iff x = 3\)
\(y = 5 - 3 = 2 \implies B(3, 2)\)។

មើលដំណោះស្រាយ

លំហាត់ PISA - ការបែងចែកផ្ទៃដីដាំដុះដំណាំកសិកម្ម ៖
តាង \(x\) ជាផ្ទៃដីដាំស្រូវ (ហិកតា) និង \(y\) ជាផ្ទៃដីដាំពោត (ហិកតា) ៖
\(\begin{cases} x + y \le 10 \quad{} (\text{ផ្ទៃដីសរុប}) \\ 3x + 2y \le 24 \quad{} (\text{ធនធានទឹក}) \\ x \ge 0, \quad{} y \ge 0 \end{cases}\)
អនុគមន៍ប្រាក់ចំណេញ ៖ \(P(x, y) = 500x + 400y\) ($)
កំពូលនៃតំបន់ ៖
ប្រសព្វ \(x + y = 10\) និង \(3x + 2y = 24 \implies x = 4, y = 6\)
កំពូលទាំងអស់ ៖ \((0, 0), (8, 0), (4, 6), (0, 10)\)
- \(P(0, 0) = 0\$\)
- \(P(8, 0) = 500(8) = 4000\$\)
- \(P(4, 6) = 500(4) + 400(6) = 2000 + 2400 = 4400\$\)
- \(P(0, 10) = 400(10) = 4000\$\)
ដូចនេះ កសិករគួរដាំ ស្រូវ \(4\) ហិកតា និង ពោត \(6\) ហិកតា ដើម្បីទទួលបានចំណេញអតិបរមា \(4400\$\)។

មើលដំណោះស្រាយ

លំហាត់ PISA - ការកាត់បន្ថយថ្លៃដើមរបបអាហាររូបត្ថម្ភ ៖
តាង \(x, y\) ជាចំនួនកញ្ចប់អាហារ I និង II (\(x \ge 0, y \ge 0\)) ៖
\(\begin{cases} 2x + 4y \ge 16 \iff x + 2y \ge 8 \\ 4x + 2y \ge 24 \iff 2x + y \ge 12 \end{cases}\)
អនុគមន៍ចំណាយ ៖ \(C(x, y) = 3x + 2y\) ($)
ប្រសព្វបន្ទាត់ ៖ \(x = \dfrac{16}{3} \approx 5.33, \quad{} y = \dfrac{4}{3} \approx 1.33\)
- ត្រង់ \((0, 12) \implies C = 24\$\)
- ត្រង់ \(\left(\dfrac{16}{3}, \dfrac{4}{3}\right) \implies C = 3\left(\dfrac{16}{3}\right) + 2\left(\dfrac{4}{3}\right) = \dfrac{56}{3} \approx 18.67\$\)
- ត្រង់ \((8, 0) \implies C = 24\$\)
បើគិតជាចំនួនកញ្ចប់គត់ដែលនៅជិតបំផុត ៖ ចំណុច \((5, 2)\) ផ្ទៀងផ្ទាត់លក្ខខណ្ឌ (\(5+4=9 \ge 8\) និង \(10+2=12 \ge 12\)) មានចំណាយ \(C = 3(5) + 2(2) = 19\$\)។
ដូចនេះ ចំណាយទាបបំផុតគឺប្រមាណ \(18.67\$\) (ទ្រឹស្តី) ឬ \(19\$\) (ទិញជាក់ស្តែង ៥ កញ្ចប់ I និង ២ កញ្ចប់ II)។

លំហាត់ PISA ៖ ការផ្ទុកទំនិញតាមកប៉ាល់ដឹកជញ្ជូន ៖

- ប្រសព្វលើ \(Oy\) ៖ \(2y \le 18 \implies (0, 9)\)
- ប្រសព្វរវាងបន្ទាត់ទាំងពីរ ៖

\(x = 18 - 2(4) = 10 \implies (10, 4)\)។
