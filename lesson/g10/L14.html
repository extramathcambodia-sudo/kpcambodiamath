ប្រវត្តិនៃផលធៀបត្រីកោណមាត្រ និងតារាវិទូ Hipparchus

ហ៊ីប៉ាឃើស (Hipparchus) (ប្រមាណ ១៩០-១២០ មុនគ.ស) គឺជាតារាវិទូ និងគណិតវិទូក្រិកបុរាណ ដែលត្រូវបានគេទទួលស្គាល់ថាជាបិតានៃត្រីកោណមាត្រ។ គាត់បានបង្កើតតារាងត្រីកោណមាត្រដំបូងគេបង្អស់ ដើម្បីជួយក្នុងការគណនាចលនារបស់ព្រះអាទិត្យ និងព្រះច័ន្ទ។ នៅក្នុងប្រវត្តិសាស្ត្រខ្មែរ បុព្វបុរសខ្មែរនាសម័យអង្គរក៏បានប្រើប្រាស់ចំណេះដឹងធរណីមាត្រ និងរង្វាស់ជ្រុងមុំដើម្បីតម្រង់ទិសប្រាសាទអង្គរវត្តឱ្យស្របនឹងទិសថ្ងៃរះចំកំពូលកណ្ដាលនៅថ្ងៃសមរាត្រី (Equinox) យ៉ាងអស្ចារ្យ។

តង់សង់

ឧទាហរណ៍

គេដាក់ជើងឧបករណ៍នៅត្រង់ចំណុច \(O\) ឱ្យឈរតែកែងនឹងផ្ទៃដីមានចម្ងាយ \(OD\) ពីដងទង់ជាតិ ។

រូបភាពនេះកំពុងរៀបចំ

គេដាក់ភ្នែកតាមបំពង់រ៉ាប់ទ័រតម្រង់ត្រង់ឱ្យឃើញចុង \(B\) នៃដងទង់ជាតិ ។ ខ្សែទម្ងន់ដែលធ្លាក់ត្រង់ចុះមកដីជួបនឹងអ័ក្សរង្វាស់នៃរ៉ាប់ទ័រ កំណត់បានមុំស្មើនឹងមុំ \(BAC\) ។ កម្ពស់ដងទង់ជាតិ \(DB = DC + CB\) ដែល \(DC = OA\) ជាកម្ពស់ជើងឧបករណ៍ ។ ឧបមាថា \(\angle BAC = 25^\circ\) ចម្ងាយ \(OD = 10\text{ m}\) និង \(OA = 2\text{ m}\) ។

គេសង់ត្រីកោណ \(A'B'C'\) ត្រង់ \(C'\) ដោយយក \(A'C' = 5\text{ cm}\), \(\angle B'A'C' = 25^\circ\) រួចយកបន្ទាត់ក្រិតវាស់រកប្រវែងជ្រុង \(B'C'\) ។

រូបភាពនេះកំពុងរៀបចំ

\(ABC\) ជាត្រីកោណកែងកំណត់ពីសេណារីយោខាងលើ គេឃើញថាត្រីកោណ \(ABC\) និង \(A'B'C'\) ជាត្រីកោណដូចគ្នាតាមករណីទី \(1\) ។ តាមផលធៀបចំណុចយើងទាញបាន \(\frac{BC}{AC} = \frac{B'C'}{A'C'}\) ឬ \(BC = AC \times \frac{B'C'}{A'C'}\)

  • គេសង្កេតឃើញថា ផលធៀប \(\frac{BC}{AC}\) ត្រូវកំណត់បានដោយគ្រាន់តែស្គាល់ចំណុច \(A\) និងរង្វាស់មុំ \(A\) ។

  • ផលធៀប \(\frac{BC}{AC}\) រវាងរង្វាស់ជ្រុងឈមនឹងរង្វាស់ជ្រុងជាប់នៃមុំ \(A\) ហៅថាតង់សង់នៃមុំ \(A\) ។ គេកំណត់សរសេរ \(\tan A\) ។

  • គេកំណត់សរសេររង្វាស់មុំត្រង់កំពូលត្រីកោណដោយឈ្មោះកំពូលត្រីកោណនោះ ។

និយមន័យ

ក្នុងត្រីកោណកែងមួយ បើ \(A\) ជារង្វាស់មុំស្រួចមួយ នោះតង់សង់នៃមុំ \(A\) គឺជាផលធៀបរង្វាស់ជ្រុងឈមមុំ \(A\) និងរង្វាស់ជ្រុងជាប់មុំ \(A\)

\[\tan A = \frac{BC}{AC} = \frac{a}{b} \text{ ឬ } a = b \cdot \tan A \text{~។}\]

ឧទាហរណ៍

\(ABC\) ជាត្រីកោណកែងត្រង់ \(C\) ។ បើស្គាល់ \(\tan A = 0.75\) និង \(AC = 5\text{ cm}\) ចូរគណនាផលធៀប \(\frac{BC}{AB}\) និង \(\frac{AC}{AB}\) ។

ដំណោះស្រាយ


តាមរូបមន្តតង់សង់ គេបាន \(\tan A = \frac{BC}{AC}\) ឬ \(BC = AC \cdot \tan A\)

\[BC = 5 \times 0.75 = 3.75 \text{~។}\]
តាមទ្រឹស្ដីបទពីតាក័រ គេបាន
\[AB^2 = AC^2 + BC^2 \text{ ឬ}\]
\[AB = \sqrt{AC^2 + BC^2} = \sqrt{5^2 + (3.75)^2} = 6.25\]
\[\frac{BC}{AB} = \frac{3.75}{6.25} = 0.6 \text{ និង } \frac{AC}{AB} = \frac{5}{6.25} = 0.8 \text{~។}\]

តម្លៃផលធៀបត្រីកោណមាត្រនៃមុំពិសេស

ត្រីកោណសម័ង្ស

គេប្រើលក្ខណៈត្រីកោណសម័ង្ស \(ABC\) ដែលជ្រុងមានរង្វាស់ \(a\) ដើម្បីគណនាផលធៀបត្រីកោណមាត្រនៃមុំ \(30^\circ\) និងមុំ \(60^\circ\) ។

គេគូសកម្ពស់ \(AH\) គេបាន \(ABH\) ជាត្រីកោណកែងត្រង់ \(H\) ដែលមានមុំ \(B = 60^\circ\) និង \(\angle BAH = 30^\circ\) ។ គេមាន \(AB = BC = AC\), \(BH = HC = \frac{BC}{2} = \frac{a}{2}\)

រូបភាពនេះកំពុងរៀបចំ

តាមទ្រឹស្ដីបទពីតាក័រ គេបាន

\[AH^2 = AB^2 - BH^2 = a^2 - \left(\frac{a}{2}\right)^2 = \frac{3a^2}{4} \text{ នោះ } AH = \frac{a\sqrt{3}}{2} \text{~។}\]

តាមនិយមន័យផលធៀបត្រីកោណមាត្រ គេបាន

\[\tan 60^\circ = \frac{AH}{BH} = \frac{\frac{a\sqrt{3}}{2}}{\frac{a}{2}} = \sqrt{3} \; , \; \sin 60^\circ = \frac{AH}{AB} = \frac{\frac{a\sqrt{3}}{2}}{a} = \frac{\sqrt{3}}{2}\]
\[\cos 60^\circ = \frac{BH}{AB} = \frac{\frac{a}{2}}{a} = \frac{1}{2} \; , \; \tan 30^\circ = \frac{BH}{AH} = \frac{\frac{a}{2}}{\frac{a\sqrt{3}}{2}} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}\]
\[\sin 30^\circ = \frac{BH}{AB} = \frac{\frac{a}{2}}{a} = \frac{1}{2} \; , \; \cos 30^\circ = \frac{AH}{AB} = \frac{\frac{a\sqrt{3}}{2}}{a} = \frac{\sqrt{3}}{2} \text{~។}\]

ត្រីកោណកែងសមបាត

គេប្រើលក្ខណៈត្រីកោណកែងសមបាត ដើម្បីគណនាផលធៀបត្រីកោណមាត្រនៃមុំ \(45^\circ\) ។ គេមាន \(BC = AC = a\), \(\angle A = \angle B = 45^\circ\) (ដូចរូប)

រូបភាពនេះកំពុងរៀបចំ

តាមទ្រឹស្ដីបទពីតាក័រ

\[AB^2 = BC^2 + AC^2 = a^2 + a^2 = 2a^2 \text{ នាំឱ្យ } AB = a\sqrt{2} \text{~។}\]

តាមនិយមន័យផលធៀបត្រីកោណមាត្រ

\[\tan 45^\circ = \frac{BC}{AC} = 1\]
\[\sin 45^\circ = \frac{BC}{AB} = \frac{a}{a\sqrt{2}} = \frac{\sqrt{2}}{2}\]
\[\cos 45^\circ = \frac{AC}{AB} = \frac{a}{a\sqrt{2}} = \frac{\sqrt{2}}{2}\]

តាមការកំណត់តម្លៃផលធៀបត្រីកោណមាត្រនេះ គេអាចបង្កើតបានតារាងតម្លៃផលធៀបត្រីកោណមាត្រនៃមុំពី \(0^\circ\) ទៅ \(90^\circ\) (តារាងត្រីកោណមាត្រ) ។

ទំនាក់ទំនងរវាងផលធៀបត្រីកោណមាត្រ

ទំនាក់ទំនងរវាងតង់សង់ ស៊ីនុស និងកូស៊ីនុស

\(ABC\) ជាត្រីកោណកែងត្រង់ \(C\) គេបាន \(\tan A = \frac{a}{b} \; , \; \sin A = \frac{a}{c} \; , \; \cos A = \frac{b}{c}\) ដោយ \(a = c \cdot \sin A\), \(b = c \cdot \cos A\) នោះ \(\tan A = \frac{c \cdot \sin A}{c \cdot \cos A}\) ដូច្នេះ \(\tan A = \frac{\sin A}{\cos A}\) ។

រូបភាពនេះកំពុងរៀបចំ

ទំនាក់ទំនងរវាងស៊ីនុស និងកូស៊ីនុស

តាមទ្រឹស្ដីបទពីតាក័រ \(BC^2 + AC^2 = AB^2\) ឬ \((c \cdot \sin A)^2 + (c \cdot \cos A)^2 = c^2\) \(c^2 [ (\sin A)^2 + (\cos A)^2 ] = c^2\) ឬ \((\sin A)^2 + (\cos A)^2 = 1\) ។

គេអាចសរសេរ \((\sin A)^2 = \sin^2 A\) និង \((\cos A)^2 = \cos^2 A\)។

ដូច្នេះ គេបានទំនាក់ទំនងសំខាន់ក្នុងផលធៀបត្រីកោណមាត្រ ៖

\[\boxed{\sin^2 A + \cos^2 A = 1}\]

បើគេចែកអង្គទាំងពីរនៃ \(\sin^2 A + \cos^2 A = 1\) នឹង \(\cos^2 A \neq 0\) នោះ គេបាន

\[\frac{\sin^2 A + \cos^2 A}{\cos^2 A} = \frac{1}{\cos^2 A} \text{ ដូច្នេះ } \boxed{1 + \tan^2 A = \frac{1}{\cos^2 A}} \text{~។}\]

ផលធៀបត្រីកោណមាត្រនៃមុំបំពេញ

បើមុំ \(A\) និង \(B\) មានផលបូកស្មើ \(90^\circ\) នោះគេថាមុំ \(A\) និង \(B\) ជាមុំបំពេញគ្នា ។ បើ \(ABC\) ជាត្រីកោណកែងត្រង់ \(C\) នោះ \(A + B = 90^\circ\) ។

រូបភាពនេះកំពុងរៀបចំ

តាមផលធៀបត្រីកោណមាត្រ គេបាន

\[\sin A = \frac{a}{c} \; , \; \cos A = \frac{b}{c} \; , \; \sin B = \frac{b}{c} \; , \; \cos B = \frac{a}{c}\]

ដោយ \(\angle B = 90^\circ - \angle A\) នោះ \(\sin(90^\circ - A) = \cos A\) ឬ \(\cos(90^\circ - A) = \sin A\)

\[\tan(90^\circ - A) = \frac{\cos A}{\sin A} = \frac{1}{\tan A} \text{~។}\]

ដោយមុំ \(A\) និង \((90^\circ - A)\) ជាមុំបំពេញគ្នានោះ៖

  • ស៊ីនុសនៃមុំមួយស្មើនឹងកូស៊ីនុសនៃមុំមួយទៀត

  • តង់សង់នៃមុំមួយស្មើនឹងចម្រាសតង់សង់នៃមុំមួយទៀត ។

ជាទូទៅ

\[\begin{aligned} \sin(90^\circ - A) & = \cos A \\ \cos(90^\circ - A) & = \sin A \\ \tan(90^\circ - A) & = \frac{1}{\tan A} \end{aligned}\]

៦លំហាត់គំរូ ៦

\[\tan A = \frac{\sin A}{\cos A} = \frac{\frac{4}{7}}{\frac{\sqrt{33}}{7}} = \frac{4}{\sqrt{33}} = \frac{4\sqrt{33}}{3}\]

៧លំហាត់គំរូ ៧

ដំណោះស្រាយ


\(\sin^2 \alpha = 1 - \cos^2 \alpha = 1 - \left(\frac{3}{5}\right)^2 = \frac{16}{25}\)

ដោយ \(\sin \alpha > 0\) នោះ \(\sin \alpha = \frac{4}{5}\) និង \(\tan \alpha = \frac{\sin \alpha}{\cos \alpha} = \frac{4}{3}\)

៨លំហាត់គំរូ ៨

ដំណោះស្រាយ


គេមាន \(\tan \alpha = \frac{\sin \alpha}{\cos \alpha} = 2\) នាំឱ្យ \(\sin \alpha = 2 \cos \alpha\)

\[\frac{2 \sin \alpha + \cos \alpha}{\cos \alpha - 3 \sin \alpha} = \frac{2 \cdot 2 \cos \alpha + \cos \alpha}{\cos \alpha - 6 \cos \alpha} = \frac{5 \cos \alpha}{-5 \cos \alpha} = -1 \text{ ឬម្យ៉ាងទៀត}\]

ដូច្នេះ \(\frac{2 \sin \alpha + \cos \alpha}{\cos \alpha - 3 \sin \alpha} = -1\) ។

មើលដំណោះស្រាយ

ស្រាយបំភ្លឺសមភាព៖

\[\frac{3 - 6\cos^2\alpha}{\sin\alpha - \cos\alpha} = 3(\sin\alpha + \cos\alpha)\]
ដំណោះស្រាយ៖
ពិនិត្យអង្គខាងឆ្វេង៖
\[\text{LHS} = \frac{3(1 - 2\cos^2\alpha)}{\sin\alpha - \cos\alpha}\]
ដោយប្រើរូបមន្តគ្រឹះ \(1 = \sin^2\alpha + \cos^2\alpha\) យើងបាន៖
\[\begin{aligned} 1 - 2\cos^2\alpha &= (\sin^2\alpha + \cos^2\alpha) - 2\cos^2\alpha \\ &= \sin^2\alpha - \cos^2\alpha \\ &= (\sin\alpha - \cos\alpha)(\sin\alpha + \cos\alpha) \end{aligned}\]
ជំនួសចូលអង្គខាងឆ្វេង៖
\[\begin{aligned} \text{LHS} &= \frac{3(\sin\alpha - \cos\alpha)(\sin\alpha + \cos\alpha)}{\sin\alpha - \cos\alpha} \\ &= 3(\sin\alpha + \cos\alpha) = \text{RHS} \end{aligned}\]
សមភាពត្រូវបានស្រាយបំភ្លឺយ៉ាងពិតប្រាកដ។

  2. \(\tan 45^\circ + \tan 30^\circ \tan 60^\circ\)

  3. \(\frac{\sin 65^\circ}{\cos 25^\circ}\)

  4. \(\tan 75^\circ \tan 15^\circ\) ។

មើលដំណោះស្រាយ

គណនាតម្លៃនៃកន្សោមនីមួយៗ៖

  1. \(\dfrac{\sin 45^\circ}{\cos 30^\circ + \sin 60^\circ}\)៖

    \[= \frac{\frac{\sqrt{2}}{2}}{\frac{\sqrt{3}}{2} + \frac{\sqrt{3}}{2}} = \frac{\frac{\sqrt{2}}{2}}{\sqrt{3}} = \frac{\sqrt{2}}{2\sqrt{3}} = \frac{\sqrt{6}}{6}\]

  2. \(\tan 45^\circ + \tan 30^\circ \tan 60^\circ\)៖

    \[= 1 + \left(\frac{\sqrt{3}}{3}\right)(\sqrt{3}) = 1 + 1 = 2\]

  3. \(\dfrac{\sin 65^\circ}{\cos 25^\circ}\)៖
    ដោយ \(65^\circ + 25^\circ = 90^\circ\) ជាមុំបំពេញគ្នា នោះ \(\sin 65^\circ = \cos 25^\circ\)៖

    \[\frac{\sin 65^\circ}{\cos 25^\circ} = \frac{\cos 25^\circ}{\cos 25^\circ} = 1\]

  4. \(\tan 75^\circ \tan 15^\circ\)៖
    ដោយ \(75^\circ + 15^\circ = 90^\circ\) នោះ \(\tan 75^\circ = \cot 15^\circ = \dfrac{1}{\tan 15^\circ}\)៖

    \[\tan 75^\circ \tan 15^\circ = \frac{1}{\tan 15^\circ} \cdot \tan 15^\circ = 1\]

មើលដំណោះស្រាយ

សម្រួលកន្សោម \(B = \cos(180^\circ - \alpha) - \sin(180^\circ - \alpha) + \cos(90^\circ - \alpha)\)៖
តាមរូបមន្តមុំបន្ថែម និងមុំបំពេញ៖

\[\begin{aligned} \cos(180^\circ - \alpha) &= -\cos\alpha \\ \sin(180^\circ - \alpha) &= \sin\alpha \\ \cos(90^\circ - \alpha) &= \sin\alpha \end{aligned}\]
ជំនួសចូលកន្សោម \(B\)៖
\[\begin{aligned} B &= (-\cos\alpha) - (\sin\alpha) + (\sin\alpha) \\ &= -\cos\alpha \end{aligned}\]

១០លំហាត់ទី ១០

រកតម្លៃ \(\cos \alpha\) ឬ \(\sin \alpha\) ឬ \(\tan \alpha\) ដោយស្គាល់៖

  1. \(\sin \alpha = \frac{\sqrt{3}}{2}\) និង \(0^\circ \leq \alpha \leq 180^\circ\)

  2. \(\cos \alpha = -\frac{4}{5}\) និង \(90^\circ \leq \alpha \leq 180^\circ\)

  3. \(\tan \alpha = 2\) និង \(0^\circ \leq \alpha \leq 90^\circ\)

  4. \(\tan \alpha = -\frac{1}{2}\) និង \(90^\circ \leq \alpha \leq 180^\circ\) ។

មើលដំណោះស្រាយ

រកតម្លៃផលធៀបត្រីកោណមាត្រ៖

  1. \(\sin\alpha = \dfrac{\sqrt{3}}{2}\) និង \(0^\circ \le \alpha \le 180^\circ\)៖
    \(\cos^2\alpha = 1 - \sin^2\alpha = 1 - \frac{3}{4} = \frac{1}{4} \implies \cos\alpha = \pm\frac{1}{2}\)

    • បើ \(\alpha = 60^\circ\) (មុំស្រួច)៖ \(\cos\alpha = \frac{1}{2}, \ \tan\alpha = \sqrt{3}\)

    • បើ \(\alpha = 120^\circ\) (មុំទាល)៖ \(\cos\alpha = -\frac{1}{2}, \ \tan\alpha = -\sqrt{3}\)

  2. \(\cos\alpha = -\dfrac{4}{5}\) និង \(90^\circ \le \alpha \le 180^\circ\) (កាដ្រង់ទី ២)៖
    ក្នុងកាដ្រង់ទី ២ ស៊ីនុសវិជ្ជមាន៖

    \[\sin\alpha = \sqrt{1 - \cos^2\alpha} = \sqrt{1 - \frac{16}{25}} = \frac{3}{5}\]
    \[\tan\alpha = \frac{\sin\alpha}{\cos\alpha} = \frac{3/5}{-4/5} = -\frac{3}{4}\]

  3. \(\tan\alpha = 2\) និង \(0^\circ \le \alpha \le 90^\circ\) (កាដ្រង់ទី ១)៖
    \(1 + \tan^2\alpha = \dfrac{1}{\cos^2\alpha} \implies \cos^2\alpha = \dfrac{1}{1 + 4} = \dfrac{1}{5} \implies \cos\alpha = \dfrac{\sqrt{5}}{5}\)

    \[\sin\alpha = \tan\alpha \cdot \cos\alpha = 2 \cdot \frac{\sqrt{5}}{5} = \frac{2\sqrt{5}}{5}\]

  4. \(\tan\alpha = -\dfrac{1}{2}\) និង \(90^\circ \le \alpha \le 180^\circ\) (កាដ្រង់ទី ២)៖
    ក្នុងកាដ្រង់ទី ២ កូស៊ីនុសអវិជ្ជមាន៖

    \[\begin{aligned} \cos\alpha &= -\frac{1}{\sqrt{1 + \tan^2\alpha}} = -\frac{1}{\sqrt{1 + 1/4}} \\ &= -\frac{2}{\sqrt{5}} = -\frac{2\sqrt{5}}{5} \\ \sin\alpha &= \left(-\frac{1}{2}\right)\left(-\frac{2\sqrt{5}}{5}\right) = \frac{\sqrt{5}}{5} \end{aligned}\]

  1. តាង \(h\) ជាកម្ពស់សរុបនៃអគារ និង \(h_1\) ជាកម្ពស់ពីកម្រិតភ្នែកសុភាទៅកំពូលអគារ នោះ \(h_1 = h - 1.6\)។
    ក្នុងត្រីកោណកែងដែលបង្កើតឡើងដោយភ្នែក កំពូល និងកម្រិតផ្ដេក៖

    \[\tan 56^\circ = \frac{h - 1.6}{30}\]

  2. គណនាកម្ពស់អគារ៖

    \[\begin{aligned} h - 1.6 &= 30 \tan 56^\circ \approx 44.48\text{ m} \\ \implies h &= 44.48 + 1.6 \approx 46.1\text{ m} \end{aligned}\]
    ដូចនេះ កម្ពស់អគារគឺប្រហែល \(46.1\text{ m}\)។

១២លំហាត់ទី ១២

ការដើរតាមជំរាល៖ ផ្លូវមួយដើរឡើងភ្នំមានមុំជំរាល \(12^\circ\) ធៀបនឹងផ្ទៃដីផ្ដេក។ សិស្សម្នាក់ដើរតាមផ្លូវនោះបាន \(200\text{ m}\) ។

  1. តើសិស្សនោះបានឡើងខ្ពស់ប៉ុន្មាន? (គណនាដោយប្រើ \(\sin 12^\circ \approx 0.2079\))

  2. តើចម្ងាយផ្ដេកដែលសិស្សដើរបានគឺប៉ុន្មាន? (គណនាដោយប្រើ \(\cos 12^\circ \approx 0.9781\))

មើលដំណោះស្រាយ

ការដើរតាមជំរាល៖ មុំជំរាល \(\alpha = 12^\circ\), ចម្ងាយដើរតាមផ្លូវ \(s = 200\text{ m}\) (អ៊ីប៉ូតេនុស)៖

  1. កម្ពស់ដែលសិស្សឡើងបាន (ជ្រុងឈម)៖

    \[h = s \cdot \sin 12^\circ \approx 200 \times 0.2079 = 41.58\text{ m}\]

  2. ចម្ងាយផ្ដេកដែលដើរបាន (ជ្រុងជាប់)៖

    \[d = s \cdot \cos 12^\circ \approx 200 \times 0.9781 = 195.62\text{ m}\]

១៣លំហាត់ទី ១៣

ក្នុងត្រីកោណកែងមួយមានជ្រុងកែងប្រវែង \(6\text{ cm}\) និង \(8\text{ cm}\) ។ គណនាផលធៀបត្រីកោណមាត្រ \(\sin, \cos, \tan\) នៃមុំស្រួចទាំងពីរនៃត្រីកោណនោះ។

មើលដំណោះស្រាយ

ក្នុងត្រីកោណកែងមានជ្រុងកែង \(a = 6\text{ cm}\) និង \(b = 8\text{ cm}\)៖
តាមទ្រឹស្ដីបទពីតាករ អ៊ីប៉ូតេនុសគឺ៖

\[c = \sqrt{a^2 + b^2} = \sqrt{6^2 + 8^2} = \sqrt{36 + 64} = 10\text{ cm}\]

  • ចំពោះមុំស្រួច \(A\) ឈមនឹងជ្រុង \(6\text{ cm}\)៖
    \(\sin A = \frac{6}{10} = \frac{3}{5}\), \(\cos A = \frac{8}{10} = \frac{4}{5}\), \(\tan A = \frac{6}{8} = \frac{3}{4}\)

  • ចំពោះមុំស្រួច \(B\) ឈមនឹងជ្រុង \(8\text{ cm}\)៖
    \(\sin B = \frac{8}{10} = \frac{4}{5}\), \(\cos B = \frac{6}{10} = \frac{3}{5}\), \(\tan B = \frac{8}{6} = \frac{4}{3}\)

មើលដំណោះស្រាយ

\[\begin{aligned} \cos\theta &= \sqrt{1 - \sin^2\theta} = \sqrt{1 - (5/13)^2} \\ &= \sqrt{1 - 25/169} = \sqrt{144/169} = \frac{12}{13} \end{aligned}\]
គណនា \(\tan\theta\)៖
\[\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{5/13}{12/13} = \frac{5}{12}\]

ដោយ \(\theta\) ជាមុំស្រួច នាំឱ្យ \(\cos\theta = \sqrt{\dfrac{64}{289}} = \dfrac{8}{17}\)។
គណនា \(\sin\theta\)៖
\[\sin\theta = \tan\theta \cdot \cos\theta = \frac{15}{8} \cdot \frac{8}{17} = \frac{15}{17}\]

មើលដំណោះស្រាយ

មើលដំណោះស្រាយ

មើលដំណោះស្រាយ

២២លំហាត់ទី ២២

ស្រាយបំភ្លឺសមភាពត្រីកោណមាត្រ \(\tan^2\alpha - \sin^2\alpha = \tan^2\alpha \cdot \sin^2\alpha\)។

មើលដំណោះស្រាយ

ស្រាយបំភ្លឺសមភាពត្រីកោណមាត្រ៖

\[\tan^2\alpha - \sin^2\alpha = \tan^2\alpha \cdot \sin^2\alpha\]
ដំណោះស្រាយ៖
បំប្លែងអង្គខាងឆ្វេង៖
\[\begin{aligned} \text{LHS} &= \tan^2\alpha - \sin^2\alpha = \frac{\sin^2\alpha}{\cos^2\alpha} - \sin^2\alpha \\ &= \sin^2\alpha \left( \frac{1}{\cos^2\alpha} - 1 \right) \\ &= \sin^2\alpha \left( \frac{1 - \cos^2\alpha}{\cos^2\alpha} \right) \\ &= \sin^2\alpha \cdot \frac{\sin^2\alpha}{\cos^2\alpha} \\ &= \sin^2\alpha \cdot \tan^2\alpha = \text{RHS} \end{aligned}\]
សមភាពត្រូវបានស្រាយបំភ្លឺ។

២៣លំហាត់ទី ២៣

ស្រាយបំភ្លឺសមភាព \(\dfrac{1}{1 + \sin\alpha} + \dfrac{1}{1 - \sin\alpha} = \dfrac{2}{\cos^2\alpha}\) (ចំពោះ \(\cos\alpha \neq 0\))។

មើលដំណោះស្រាយ

ស្រាយបំភ្លឺសមភាព៖

\[\frac{1}{1 + \sin\alpha} + \frac{1}{1 - \sin\alpha} = \frac{2}{\cos^2\alpha}\]
ដំណោះស្រាយ៖
តម្រូវភាគបែងរួមនៃអង្គខាងឆ្វេង៖
\[\begin{aligned} \text{LHS} &= \frac{(1 - \sin\alpha) + (1 + \sin\alpha)}{(1 + \sin\alpha)(1 - \sin\alpha)} \\ &= \frac{2}{1 - \sin^2\alpha} \end{aligned}\]
ដោយ \(1 - \sin^2\alpha = \cos^2\alpha\) នោះ៖
\[\text{LHS} = \frac{2}{\cos^2\alpha} = \text{RHS}\]
សមភាពត្រូវបានស្រាយបំភ្លឺ។

២៤លំហាត់ទី ២៤

ស្រាយបំភ្លឺសមភាព \((\sin\alpha + \cos\alpha)^2 + (\sin\alpha - \cos\alpha)^2 = 2\)។

មើលដំណោះស្រាយ

ស្រាយបំភ្លឺសមភាព៖

\[(\sin\alpha + \cos\alpha)^2 + (\sin\alpha - \cos\alpha)^2 = 2\]
ដំណោះស្រាយ៖
ពន្លាតកន្សោមទាំងពីរតាមរូបមន្តស្វ័យគុណទ្វេធា៖
\[\begin{aligned} \text{LHS} &= (\sin^2\alpha + 2\sin\alpha\cos\alpha + \cos^2\alpha) \\ &\quad{} + (\sin^2\alpha - 2\sin\alpha\cos\alpha + \cos^2\alpha) \\ &= 2\sin^2\alpha + 2\cos^2\alpha \\ &= 2(\sin^2\alpha + \cos^2\alpha) = 2(1) = 2 = \text{RHS} \end{aligned}\]
សមភាពត្រូវបានស្រាយបំភ្លឺ។

២៥លំហាត់ទី ២៥

ស្រាយបំភ្លឺសមភាព \(\dfrac{\cos\alpha}{1 - \sin\alpha} = \dfrac{1 + \sin\alpha}{\cos\alpha}\) (ចំពោះ \(\cos\alpha \neq 0, \sin\alpha \neq 1\))។

មើលដំណោះស្រាយ

ស្រាយបំភ្លឺសមភាព៖

\[\frac{\cos\alpha}{1 - \sin\alpha} = \frac{1 + \sin\alpha}{\cos\alpha}\]
ដំណោះស្រាយ៖
គុណភាគយកនិងភាគបែងនៃអង្គខាងឆ្វេងនឹង \((1 + \sin\alpha)\)៖
\[\begin{aligned} \text{LHS} &= \frac{\cos\alpha(1 + \sin\alpha)}{(1 - \sin\alpha)(1 + \sin\alpha)} \\ &= \frac{\cos\alpha(1 + \sin\alpha)}{1 - \sin^2\alpha} \\ &= \frac{\cos\alpha(1 + \sin\alpha)}{\cos^2\alpha} \\ &= \frac{1 + \sin\alpha}{\cos\alpha} = \text{RHS} \end{aligned}\]
សមភាពត្រូវបានស្រាយបំភ្លឺ។

មើលដំណោះស្រាយ

\[\begin{aligned} \text{LHS} &= (\sin^2\alpha)^2 - (\cos^2\alpha)^2 \\ &= (\sin^2\alpha - \cos^2\alpha)(\sin^2\alpha + \cos^2\alpha) \end{aligned}\]

\[\frac{\tan\alpha + \tan\beta}{\cot\alpha + \cot\beta} = \tan\alpha \tan\beta\]
ដំណោះស្រាយ៖
បំប្លែងកូតង់សង់ជាតង់សង់៖ \(\cot\alpha = \dfrac{1}{\tan\alpha}, \ \cot\beta = \dfrac{1}{\tan\beta}\)។
ភាគបែងនៃអង្គខាងឆ្វេងក្លាយជា៖
\[\cot\alpha + \cot\beta = \frac{1}{\tan\alpha} + \frac{1}{\tan\beta} = \frac{\tan\beta + \tan\alpha}{\tan\alpha \tan\beta}\]
ជំនួសចូលអង្គខាងឆ្វេង៖
\[\begin{aligned} \text{LHS} &= \frac{\tan\alpha + \tan\beta}{\dfrac{\tan\alpha + \tan\beta}{\tan\alpha \tan\beta}} \\ &= (\tan\alpha + \tan\beta) \cdot \frac{\tan\alpha \tan\beta}{\tan\alpha + \tan\beta} \\ &= \tan\alpha \tan\beta = \text{RHS} \end{aligned}\]
សមភាពត្រូវបានស្រាយបំភ្លឺ។

២៨លំហាត់ទី ២៨

គេឱ្យ \(\sin\alpha + \cos\alpha = \dfrac{7}{5}\) ។ គណនាតម្លៃនៃផលគុណ \(P = \sin\alpha \cos\alpha\)។

មើលដំណោះស្រាយ

គេឱ្យ \(\sin\alpha + \cos\alpha = \dfrac{7}{5}\)។ គណនាតម្លៃនៃផលគុណ \(P = \sin\alpha \cos\alpha\)៖
លើកអង្គទាំងពីរនៃសមភាពជាការេ៖

\[\begin{aligned} (\sin\alpha + \cos\alpha)^2 &= \left(\frac{7}{5}\right)^2 \\ \sin^2\alpha + 2\sin\alpha\cos\alpha + \cos^2\alpha &= \frac{49}{25} \\ (\sin^2\alpha + \cos^2\alpha) + 2P &= \frac{49}{25} \\ 1 + 2P &= \frac{49}{25} \\ 2P &= \frac{49}{25} - 1 = \frac{24}{25} \\ \implies P &= \frac{12}{25} \end{aligned}\]
ដូចនេះ \(P = \sin\alpha\cos\alpha = \dfrac{12}{25}\)។

២៩លំហាត់ទី ២៩

គេឱ្យ \(\sin\alpha - \cos\alpha = \dfrac{1}{3}\) ។ គណនាតម្លៃនៃ \(Q = \sin^4\alpha + \cos^4\alpha\)។

មើលដំណោះស្រាយ

គេឱ្យ \(\sin\alpha - \cos\alpha = \dfrac{1}{3}\)។ គណនាតម្លៃនៃ \(Q = \sin^4\alpha + \cos^4\alpha\)៖
លើកជាការេដើម្បីរកផលគុណ \(\sin\alpha\cos\alpha\)៖

\[\begin{aligned} (\sin\alpha - \cos\alpha)^2 &= \left(\frac{1}{3}\right)^2 \\ 1 - 2\sin\alpha\cos\alpha &= \frac{1}{9} \\ 2\sin\alpha\cos\alpha &= 1 - \frac{1}{9} = \frac{8}{9} \\ \implies \sin\alpha\cos\alpha &= \frac{4}{9} \end{aligned}\]
គណនា \(Q\)៖
\[\begin{aligned} Q &= (\sin^2\alpha + \cos^2\alpha)^2 - 2\sin^2\alpha\cos^2\alpha \\ &= 1^2 - 2(\sin\alpha\cos\alpha)^2 = 1 - 2\left(\frac{4}{9}\right)^2 \\ &= 1 - \frac{32}{81} = \frac{49}{81} \end{aligned}\]
ដូចនេះ \(Q = \dfrac{49}{81}\)។

៣០លំហាត់ទី ៣០

គេឱ្យ \(\tan\alpha = 3\) ។ គណនាតម្លៃនៃកន្សោម \(E = \dfrac{2\sin\alpha + 3\cos\alpha}{4\sin\alpha - 5\cos\alpha}\)។

មើលដំណោះស្រាយ

គេឱ្យ \(\tan\alpha = 3\)។ គណនា \(E = \dfrac{2\sin\alpha + 3\cos\alpha}{4\sin\alpha - 5\cos\alpha}\)៖
ដោយចែកភាគយកនិងភាគបែងនឹង \(\cos\alpha \neq 0\) យើងបាន៖

\[E = \frac{2\dfrac{\sin\alpha}{\cos\alpha} + 3}{4\dfrac{\sin\alpha}{\cos\alpha} - 5} = \frac{2\tan\alpha + 3}{4\tan\alpha - 5}\]
ជំនួស \(\tan\alpha = 3\) ចូល៖
\[E = \frac{2(3) + 3}{4(3) - 5} = \frac{6 + 3}{12 - 5} = \frac{9}{7}\]
ដូចនេះ \(E = \dfrac{9}{7}\)។

៣១លំហាត់ទី ៣១

គេឱ្យ \(\tan\alpha = 2\) ។ គណនាតម្លៃនៃកន្សោម \(F = \dfrac{\sin^2\alpha - 2\sin\alpha\cos\alpha + 3\cos^2\alpha}{2\sin^2\alpha + \cos^2\alpha}\)។

មើលដំណោះស្រាយ

គេឱ្យ \(\tan\alpha = 2\)។ គណនា៖

\[F = \frac{\sin^2\alpha - 2\sin\alpha\cos\alpha + 3\cos^2\alpha}{2\sin^2\alpha + \cos^2\alpha}\]
ចែកភាគយកនិងភាគបែងនឹង \(\cos^2\alpha \neq 0\) យើងបាន៖
\[F = \frac{\tan^2\alpha - 2\tan\alpha + 3}{2\tan^2\alpha + 1}\]
ជំនួស \(\tan\alpha = 2\) ចូល៖
\[F = \frac{2^2 - 2(2) + 3}{2(2^2) + 1} = \frac{4 - 4 + 3}{8 + 1} = \frac{3}{9} = \frac{1}{3}\]
ដូចនេះ \(F = \dfrac{1}{3}\)។

៣២លំហាត់ទី ៣២

គណនាតម្លៃពិតប្រាកដនៃផលធៀបត្រីកោណមាត្រនៃមុំពិសេសខាងក្រោម៖

  1. \(\sin 120^\circ, \cos 120^\circ, \tan 120^\circ\)

  2. \(\sin 135^\circ, \cos 135^\circ, \tan 135^\circ\)

  3. \(\sin 150^\circ, \cos 150^\circ, \tan 150^\circ\)។

មើលដំណោះស្រាយ

គណនាតម្លៃពិតប្រាកដនៃផលធៀបត្រីកោណមាត្រនៃមុំពិសេស៖

  1. មុំ \(120^\circ = 180^\circ - 60^\circ\)៖

    \[\begin{aligned} \sin 120^\circ &= \sin 60^\circ = \frac{\sqrt{3}}{2} \\ \cos 120^\circ &= -\cos 60^\circ = -\frac{1}{2} \\ \tan 120^\circ &= -\tan 60^\circ = -\sqrt{3} \end{aligned}\]

  2. មុំ \(135^\circ = 180^\circ - 45^\circ\)៖

    \[\begin{aligned} \sin 135^\circ &= \sin 45^\circ = \frac{\sqrt{2}}{2} \\ \cos 135^\circ &= -\cos 45^\circ = -\frac{\sqrt{2}}{2} \\ \tan 135^\circ &= -\tan 45^\circ = -1 \end{aligned}\]

  3. មុំ \(150^\circ = 180^\circ - 30^\circ\)៖

    \[\begin{aligned} \sin 150^\circ &= \sin 30^\circ = \frac{1}{2} \\ \cos 150^\circ &= -\cos 30^\circ = -\frac{\sqrt{3}}{2} \\ \tan 150^\circ &= -\tan 30^\circ = -\frac{\sqrt{3}}{3} \end{aligned}\]

៣៣លំហាត់ទី ៣៣

គណនាតម្លៃនៃកន្សោម \(M = 2\sin 30^\circ + 4\cos 60^\circ - \sqrt{3}\tan 60^\circ + \sin 90^\circ\)។

មើលដំណោះស្រាយ

គណនាតម្លៃកន្សោម \(M = 2\sin 30^\circ + 4\cos 60^\circ - \sqrt{3}\tan 60^\circ + \sin 90^\circ\)៖
ជំនួសតម្លៃមុំពិសេស៖ \(\sin 30^\circ = \dfrac{1}{2}, \ \cos 60^\circ = \dfrac{1}{2}, \ \tan 60^\circ = \sqrt{3}, \ \sin 90^\circ = 1\)។

\[\begin{aligned} M &= 2\left(\frac{1}{2}\right) + 4\left(\frac{1}{2}\right) - \sqrt{3}(\sqrt{3}) + 1 \\ &= 1 + 2 - 3 + 1 = 1 \end{aligned}\]
ដូចនេះ \(M = 1\)។

៣៤លំហាត់ទី ៣៤

គណនាតម្លៃនៃកន្សោម \(N = \sin^2 30^\circ + \cos^2 45^\circ + \tan^2 60^\circ - \cos^2 90^\circ\)។

មើលដំណោះស្រាយ

គណនាតម្លៃកន្សោម \(N = \sin^2 30^\circ + \cos^2 45^\circ + \tan^2 60^\circ - \cos^2 90^\circ\)៖
ជំនួសតម្លៃមុំពិសេស៖ \(\sin 30^\circ = \dfrac{1}{2}, \ \cos 45^\circ = \dfrac{\sqrt{2}}{2}, \ \tan 60^\circ = \sqrt{3}, \ \cos 90^\circ = 0\)។

\[\begin{aligned} N &= \left(\frac{1}{2}\right)^2 + \left(\frac{\sqrt{2}}{2}\right)^2 + (\sqrt{3})^2 - 0^2 \\ &= \frac{1}{4} + \frac{2}{4} + 3 - 0 = \frac{3}{4} + 3 = \frac{15}{4} \end{aligned}\]
ដូចនេះ \(N = \dfrac{15}{4}\)។

៣៥លំហាត់ទី ៣៥

គណនាតម្លៃនៃកន្សោម \(P = \dfrac{\sin 150^\circ + \cos 120^\circ}{\tan 135^\circ + \sin 90^\circ + 1}\)។

មើលដំណោះស្រាយ

គណនាតម្លៃកន្សោម \(P = \dfrac{\sin 150^\circ + \cos 120^\circ}{\tan 135^\circ + \sin 90^\circ + 1}\)៖
គណនាភាគយក៖

\[\sin 150^\circ + \cos 120^\circ = \frac{1}{2} + \left(-\frac{1}{2}\right) = 0\]
គណនាភាគបែង៖
\[\tan 135^\circ + \sin 90^\circ + 1 = -1 + 1 + 1 = 1 \neq 0\]
នាំឱ្យ៖
\[P = \frac{0}{1} = 0\]

៣៦លំហាត់ទី ៣៦

គណនាតម្លៃផលបូក \(S = \cos 0^\circ + \cos 20^\circ + \cos 40^\circ + \dots + \cos 160^\circ + \cos 180^\circ\)។

មើលដំណោះស្រាយ

គណនាតម្លៃផលបូក \(S = \cos 0^\circ + \cos 20^\circ + \cos 40^\circ + \dots + \cos 160^\circ + \cos 180^\circ\)៖
ដោយប្រើរូបមន្តមុំបន្ថែម \(\cos(180^\circ - x) = -\cos x\) យើងបាន \(\cos x + \cos(180^\circ - x) = 0\)។
ផ្គុំតួជាគូៗ៖

\[\begin{aligned} S &= (\cos 0^\circ + \cos 180^\circ) + (\cos 20^\circ + \cos 160^\circ) \\ &\quad{} + (\cos 40^\circ + \cos 140^\circ) + (\cos 60^\circ + \cos 120^\circ) \\ &\quad{} + (\cos 80^\circ + \cos 100^\circ) + \cos 90^\circ \\ &= 0 + 0 + 0 + 0 + 0 + 0 = 0 \end{aligned}\]
ដូចនេះ \(S = 0\)។

  1. \(\sin\alpha = \dfrac{1}{2}\)

  2. \(\cos\alpha = -\dfrac{\sqrt{3}}{2}\)

  3. \(\tan\alpha = -1\)

  4. \(2\sin\alpha - \sqrt{3} = 0\)។

មើលដំណោះស្រាយ

កំណត់តម្លៃនៃមុំ \(\alpha\) ដែល \(0^\circ \le \alpha \le 180^\circ\)៖

  1. \(\sin\alpha = \dfrac{1}{2} \implies \alpha = 30^\circ\) ឬ \(\alpha = 180^\circ - 30^\circ = 150^\circ\)

  2. \(\cos\alpha = -\dfrac{\sqrt{2}}{2} \implies \alpha = 180^\circ - 45^\circ = 135^\circ\)

  3. \(\tan\alpha = -1 \implies \alpha = 180^\circ - 45^\circ = 135^\circ\)

  4. \(\sin\alpha = 0 \implies \alpha = 0^\circ\) ឬ \(\alpha = 180^\circ\)

៣៨លំហាត់ទី ៣៨

ដោះស្រាយសមីការត្រីកោណមាត្រខាងក្រោមចំពោះ \(0^\circ \le \alpha \le 180^\circ\)៖

  1. \(2\cos^2\alpha - 3\cos\alpha + 1 = 0\)

  2. \(2\sin^2\alpha - \sin\alpha - 1 = 0\)។

មើលដំណោះស្រាយ

ដោះស្រាយសមីការត្រីកោណមាត្រចំពោះ \(0^\circ \le \alpha \le 180^\circ\)៖

  1. \(2\sin\alpha - 1 = 0 \implies \sin\alpha = \dfrac{1}{2}\)៖
    ដូចនេះ \(\alpha = 30^\circ\) ឬ \(\alpha = 150^\circ\)។

  2. \(2\cos\alpha + \sqrt{3} = 0 \implies \cos\alpha = -\dfrac{\sqrt{3}}{2}\)៖
    ដូចនេះ \(\alpha = 180^\circ - 30^\circ = 150^\circ\)។

  3. \(\sqrt{3}\tan\alpha + 1 = 0 \implies \tan\alpha = -\dfrac{1}{\sqrt{3}}\)៖
    ដូចនេះ \(\alpha = 180^\circ - 30^\circ = 150^\circ\)។

  4. \(4\cos^2\alpha - 1 = 0 \implies \cos^2\alpha = \dfrac{1}{4} \implies \cos\alpha = \pm\dfrac{1}{2}\)៖

    • បើ \(\cos\alpha = \frac{1}{2} \implies \alpha = 60^\circ\)

    • បើ \(\cos\alpha = -\frac{1}{2} \implies \alpha = 120^\circ\)

    ដូចនេះ \(\alpha \in \{60^\circ, 120^\circ\}\)។

  1. \(\sin 115^\circ\)

  2. \(\cos 140^\circ\)

  3. \(\tan 98^\circ\)

  4. \(\cos 75^\circ \cdot \sin 130^\circ\)។

មើលដំណោះស្រាយ

កំណត់សញ្ញានៃកន្សោមនីមួយៗ៖

  1. \(\sin 115^\circ \cdot \cos 115^\circ\)៖
    ដោយ \(90^\circ < 115^\circ < 180^\circ\) នោះ \(\sin 115^\circ > 0\) និង \(\cos 115^\circ < 0\)។
    ដូច្នេះ ផលគុណមានតម្លៃ អវិជ្ជមាន (\(< 0\))។

  2. \(\cos 140^\circ \cdot \tan 140^\circ\)៖
    ដោយ \(\cos 140^\circ < 0\) និង \(\tan 140^\circ < 0\) នោះផលគុណមានតម្លៃ វិជ្ជមាន (\(> 0\))។
    (ឬដោយ \(\cos 140^\circ \cdot \tan 140^\circ = \sin 140^\circ > 0\))។

  3. \(\sin 90^\circ - \cos 90^\circ = 1 - 0 = 1 > 0\) ៖ មានតម្លៃ វិជ្ជមាន។

  4. \(\cos 120^\circ + \sin 30^\circ = -\dfrac{1}{2} + \dfrac{1}{2} = 0\) ៖ មានតម្លៃ សូន្យ។

៤០លំហាត់ទី ៤០

ក្នុងត្រីកោណកែង \(ABC\) កែងត្រង់ \(A\) មានមុំ \(B = 30^\circ\) និងអ៊ីប៉ូតេនុស \(BC = 12\text{ cm}\) ។ គណនាប្រវែងជ្រុង \(AB, AC\) និងកម្ពស់ \(AH\) គូសចេញពីកំពូល \(A\)។

មើលដំណោះស្រាយ

ក្នុងត្រីកោណកែង \(ABC\) កែងត្រង់ \(A\) មាន \(\angle B = 30^\circ\) និងអ៊ីប៉ូតេនុស \(BC = 12\text{ cm}\)៖
មុំស្រួចមួយទៀតគឺ៖

\[\angle C = 90^\circ - 30^\circ = 60^\circ\]
ប្រវែងជ្រុងឈម \(AC\) គឺ៖
\[AC = BC \cdot \sin 30^\circ = 12 \cdot \frac{1}{2} = 6\text{ cm}\]
ប្រវែងជ្រុងជាប់ \(AB\) គឺ៖
\[AB = BC \cdot \cos 30^\circ = 12 \cdot \frac{\sqrt{3}}{2} = 6\sqrt{3} \approx 10.39\text{ cm}\]

៤១លំហាត់ទី ៤១

ត្រីកោណសមបាត \(ABC\) មាន \(AB = AC = 10\text{ cm}\) និងបាត \(BC = 12\text{ cm}\) ។ គណនាផលធៀបត្រីកោណមាត្រនៃមុំបាត និងផ្ទៃក្រឡានៃត្រីកោណនោះ។

មើលដំណោះស្រាយ

ត្រីកោណសមបាត \(ABC\) មាន \(AB = AC = 10\text{ cm}\) និងបាត \(BC = 12\text{ cm}\)៖
គូសកម្ពស់ \(AH \perp BC\) (\(H \in BC\))។ ដោយ \(\triangle ABC\) សមបាត នោះ \(H\) ជាចំណុចកណ្ដាលនៃ \(BC\) នាំឱ្យ \(BH = HC = \dfrac{12}{2} = 6\text{ cm}\)។
ក្នុងត្រីកោណកែង \(ABH\) កែងត្រង់ \(H\)៖

\[AH = \sqrt{AB^2 - BH^2} = \sqrt{10^2 - 6^2} = \sqrt{64} = 8\text{ cm}\]

  • ផលធៀបត្រីកោណមាត្រនៃមុំបាត \(B\)៖

    \[\begin{aligned} \sin B &= \frac{AH}{AB} = \frac{8}{10} = \frac{4}{5} = 0.8 \\ \cos B &= \frac{BH}{AB} = \frac{6}{10} = \frac{3}{5} = 0.6 \\ \tan B &= \frac{AH}{BH} = \frac{8}{6} = \frac{4}{3} \end{aligned}\]

  • ផ្ទៃក្រឡាត្រីកោណ \(ABC\)៖

    \[S = \frac{1}{2} \cdot BC \cdot AH = \frac{1}{2} \times 12 \times 8 = 48\text{ cm}^2\]

ចតុកោណស្មើ \(ABCD\) មានជ្រុង \(a = 8\text{ cm}\) និង \(\angle A = 60^\circ\)៖
អង្កត់ទ្រូងកាត់គ្នាត្រង់ចំណុចកណ្ដាល \(O\) និងកែងគ្នា។
\(\triangle ABD\) សមបាតមាន \(AB = AD\) និង \(\angle A = 60^\circ\) នាំឱ្យ \(\triangle ABD\) ជាត្រីកោណសម័ង្ស \(\implies BD = 8\text{ cm}\)។
ក្នុងត្រីកោណកែង \(OAB\) កែងត្រង់ \(O\) មាន \(\angle OAB = \dfrac{60^\circ}{2} = 30^\circ\)៖

\[OA = AB \cdot \cos 30^\circ = 8 \cdot \frac{\sqrt{3}}{2} = 4\sqrt{3}\text{ cm}\]
នាំឱ្យអង្កត់ទ្រូង \(AC = 2OA = 8\sqrt{3}\text{ cm} \approx 13.86\text{ cm}\)។
ផ្ទៃក្រឡាចតុកោណស្មើ៖
\[\begin{aligned} S &= \frac{1}{2} \cdot AC \cdot BD = \frac{1}{2} (8\sqrt{3})(8) \\ &= 32\sqrt{3} \approx 55.43\text{ cm}^2 \end{aligned}\]

៤៣លំហាត់ទី ៤៣

ជណ្ដើរមួយមានប្រវែង \(6\text{ m}\) ត្រូវបានដាក់ផ្អែកនឹងជញ្ជាំងអគារមួយ ដោយបាតជណ្ដើរបង្កើតបានមុំ \(65^\circ\) ជាមួយនឹងផ្ទៃដីរាបស្មើ។

  1. តើចុងលើនៃជណ្ដើរនោះឡើងដល់កម្ពស់ប៉ុន្មានម៉ែត្រលើជញ្ជាំង?

  2. តើជើងជណ្ដើរនៅឆ្ងាយពីជញ្ជាំងអគារប្រវែងប៉ុន្មានម៉ែត្រ?

មើលដំណោះស្រាយ

ជណ្ដើរផ្អែកនឹងជញ្ជាំង៖ ប្រវែងជណ្ដើរ \(L = 6\text{ m}\) (អ៊ីប៉ូតេនុស), មុំបាត \(\theta = 65^\circ\)៖

  1. កម្ពស់ចុងលើជណ្ដើរលើជញ្ជាំង (ជ្រុងឈម)៖

    \[h = L \cdot \sin 65^\circ \approx 6 \times 0.9063 \approx 5.44\text{ m}\]

  2. ចម្ងាយពីជើងជណ្ដើរទៅជញ្ជាំង (ជ្រុងជាប់)៖

    \[d = L \cdot \cos 65^\circ \approx 6 \times 0.4226 \approx 2.54\text{ m}\]

៤៤លំហាត់ទី ៤៤

បង្គោលអង់តែនទូរគមនាគមន៍មួយបញ្ឈរត្រង់លើដីរាបស្មើ បង្កើតបានស្រមោលប្រវែង \(42\text{ m}\) នៅពេលដែលព្រះអាទិត្យមានមុំផ្គុំ \(38^\circ\) ធៀបនឹងដីរាបស្មើ។ គណនាកម្ពស់នៃបង្គោលអង់តែននោះ។

មើលដំណោះស្រាយ

បង្គោលអង់តែន៖ ស្រមោល \(d = 42\text{ m}\), មុំផ្គុំនៃព្រះអាទិត្យ \(\alpha = 38^\circ\)៖
កម្ពស់បង្គោលអង់តែន \(h\) ផ្ទៀងផ្ទាត់៖

\[\tan 38^\circ = \frac{h}{d} \implies h = d \cdot \tan 38^\circ\]
ជំនួសតម្លៃ \(\tan 38^\circ \approx 0.7813\)៖
\[h \approx 42 \times 0.7813 = 32.81\text{ m}\]
ដូចនេះ បង្គោលអង់តែនមានកម្ពស់ប្រហែល \(32.81\text{ m}\)។

៤៥លំហាត់ទី ៤៥

ពីកំពូលច្រាំងចោទមួយដែលមានកម្ពស់ \(80\text{ m}\) ពីផ្ទៃទឹកសមុទ្រ អ្នកសង្កេតការណ៍ម្នាក់បានមើលឃើញទូកមួយនៅសមុទ្រក្រោមមុំស្រុត \(24^\circ\)។ តើទូកនោះស្ថិតនៅចម្ងាយប៉ុន្មានម៉ែត្រពីជើងច្រាំងចោទ?

មើលដំណោះស្រាយ

ចម្ងាយពីច្រាំងចោទទៅទូក៖ កម្ពស់ច្រាំង \(H = 80\text{ m}\), មុំស្រុត \(\alpha = 24^\circ\)៖
មុំស្រុតស្មើនឹងមុំងើបពីទូកទៅកំពូលច្រាំង (មុំឆ្លាស់ក្នុង)៖

\[\tan 24^\circ = \frac{H}{d} \implies d = \frac{H}{\tan 24^\circ}\]
ជំនួសតម្លៃ \(\tan 24^\circ \approx 0.4452\)៖
\[d \approx \frac{80}{0.4452} \approx 179.69\text{ m}\]
ដូចនេះ ទូកស្ថិតនៅចម្ងាយប្រហែល \(179.69\text{ m}\) (ឬ \(179.7\text{ m}\)) ពីជើងច្រាំងចោទ។

៤៦លំហាត់ទី ៤៦

ពីលើកំពូលបង្គោលភ្លើងហ្វារមួយដែលមានកម្ពស់ \(50\text{ m}\) គេសង្កេតឃើញកប៉ាល់ពីរនៅលើខ្សែបន្ទាត់តែមួយជាមួយជើងបង្គោលភ្លើង ដោយមានមុំស្រុតរៀងគ្នា \(30^\circ\) និង \(45^\circ\)។ គណនាចម្ងាយរវាងកប៉ាល់ទាំងពីរនោះ។

មើលដំណោះស្រាយ

ចម្ងាយរវាងកប៉ាល់ទាំងពីរ៖ កំពូលបង្គោលភ្លើងកម្ពស់ \(H = 50\text{ m}\), មុំស្រុតទៅកប៉ាល់ទាំងពីរគឺ \(30^\circ\) និង \(45^\circ\)៖

  • ចម្ងាយពីជើងបង្គោលភ្លើងទៅកប៉ាល់ជិត៖

    \[d_1 = \frac{50}{\tan 45^\circ} = \frac{50}{1} = 50\text{ m}\]

  • ចម្ងាយពីជើងបង្គោលភ្លើងទៅកប៉ាល់ឆ្ងាយ៖

    \[d_2 = \frac{50}{\tan 30^\circ} = \frac{50}{1/\sqrt{3}} = 50\sqrt{3} \approx 86.60\text{ m}\]

  • ចម្ងាយរវាងកប៉ាល់ទាំងពីរ (នៅលើខ្សែបន្ទាត់តែមួយទិសដៅតែមួយ)៖

    \[\begin{aligned} \Delta d &= d_2 - d_1 = 50\sqrt{3} - 50 \\ &= 50(\sqrt{3} - 1) \approx 36.60\text{ m} \end{aligned}\]

(ចំណាំ៖ ប្រសិនបើកប៉ាល់ទាំងពីរស្ថិតនៅសងខាងជើងបង្គោលភ្លើង ចម្ងាយរវាងពួកវាគឺ \(d_1 + d_2 = 50 + 50\sqrt{3} \approx 136.60\text{ m}\))។

៤៧លំហាត់ទី ៤៧

ក្មេងប្រុសម្នាក់បង្ហោះខ្លែងមួយដោយខ្សែខ្លែងតឹងត្រង់ប្រវែង \(85\text{ m}\) និងបង្កើតបានមុំងើប \(52^\circ\) ធៀបនឹងដីរាបស្មើ។ ប្រសិនបើដៃកាន់ខ្សែខ្លែងរបស់ក្មេងនោះមានកម្ពស់ \(1.2\text{ m}\) ពីផ្ទៃដី ចូរគណនាកម្ពស់នៃខ្លែងធៀបនឹងដី។

មើលដំណោះស្រាយ

កម្ពស់ខ្លែង៖ ខ្សែខ្លែង \(L = 85\text{ m}\), មុំងើប \(\alpha = 52^\circ\), កម្ពស់ដៃ \(h_0 = 1.2\text{ m}\)៖
កម្ពស់ខ្លែងធៀបនឹងកម្រិតដៃកាន់ខ្សែគឺ៖

\[h_1 = L \cdot \sin 52^\circ \approx 85 \times 0.7880 = 66.98\text{ m}\]
កម្ពស់សរុបនៃខ្លែងធៀបនឹងផ្ទៃដីគឺ៖
\[H = h_1 + h_0 = 66.98 + 1.2 = 68.18\text{ m}\]
ដូចនេះ ខ្លែងហោះនៅកម្ពស់ប្រហែល \(68.18\text{ m}\) ពីដី។

៤៨លំហាត់ទី ៤៨

ដើមឈើមួយដើមត្រូវបានខ្យល់បោកបក់បាក់ត្រង់កណ្ដាល ដោយចុងឈើធ្លាក់មកប៉ះផ្ទៃដីបង្កើតបានមុំ \(30^\circ\) និងមានចម្ងាយ \(9\text{ m}\) ពីគល់ឈើ។ គណនាកម្ពស់ដើមឈើកាលពីមិនទាន់បាក់។

មើលដំណោះស្រាយ

កម្ពស់ដើមឈើកាលមិនទាន់បាក់៖ ចុងឈើប៉ះដីមុំ \(30^\circ\) និងមានចម្ងាយ \(9\text{ m}\) ពីគល់ឈើ៖

  • កម្ពស់គល់ឈើដែលនៅសល់ (ជ្រុងឈម)៖

    \[y = 9 \cdot \tan 30^\circ = 9 \cdot \frac{\sqrt{3}}{3} = 3\sqrt{3}\text{ m} \approx 5.20\text{ m}\]

  • ប្រវែងកំណាត់ដើមឈើដែលបាក់ធ្លាក់ (អ៊ីប៉ូតេនុស)៖

    \[z = \frac{9}{\cos 30^\circ} = \frac{9}{\sqrt{3}/2} = \frac{18}{\sqrt{3}} = 6\sqrt{3}\text{ m} \approx 10.39\text{ m}\]

  • កម្ពស់ដើមឈើដើមទាំងមូល៖

    \[H = y + z = 3\sqrt{3} + 6\sqrt{3} = 9\sqrt{3}\text{ m} \approx 15.59\text{ m}\]

៤៩លំហាត់ទី ៤៩

ការរចនាផ្លូវជម្រាលសម្រាប់ជនមានពិការភាព (PISA)៖ បទដ្ឋានសំណង់តម្រូវឱ្យផ្លូវជម្រាលសម្រាប់រទេះរុញជនមានពិការភាពមានមុំជម្រាលមិនលើសពី \(4.76^\circ\) (\(\tan 4.76^\circ \approx \dfrac{1}{12}\))។

  1. ប្រសិនបើតម្រូវឱ្យផ្លូវជម្រាលនេះឡើងដល់កម្ពស់ \(1.5\text{ m}\) តើប្រវែងដីផ្ដេកអប្បបរមាត្រូវមានប៉ុន្មានម៉ែត្រ?

  2. គណនាប្រវែងផ្ទៃផ្លូវជម្រាលពិតប្រាកដ។

មើលដំណោះស្រាយ

ការរចនាផ្លូវជម្រាលសម្រាប់ជនមានពិការភាព (PISA)៖
បទដ្ឋានសំណង់កំណត់ \(\tan 4.76^\circ \approx \dfrac{1}{12}\), កម្ពស់ត្រូវឡើង \(h = 1.5\text{ m}\)៖

  1. ប្រវែងដីផ្ដេកអប្បបរមា \(x\)៖

    \[\begin{aligned} \tan 4.76^\circ &= \frac{h}{x} \implies x = \frac{h}{\tan 4.76^\circ} \\ &= \frac{1.5}{1/12} = 1.5 \times 12 = 18\text{ m} \end{aligned}\]

  2. ប្រវែងផ្ទៃផ្លូវជម្រាលពិតប្រាកដ \(L\)៖
    តាមទ្រឹស្ដីបទពីតាករ៖

    \[\begin{aligned} L &= \sqrt{x^2 + h^2} = \sqrt{18^2 + 1.5^2} \\ &= \sqrt{324 + 2.25} = \sqrt{326.25} \approx 18.06\text{ m} \end{aligned}\]
    (ឬតាមផលធៀប \(L = \dfrac{h}{\sin 4.76^\circ} \approx \dfrac{1.5}{0.0829} \approx 18.08\text{ m}\))។

៥០លំហាត់ទី ៥០

ការវាស់កម្ពស់ប្រាសាទបុរាណ (STEM/PISA)៖ វិស្វករម្នាក់ចង់វាស់កម្ពស់កំពូលកណ្ដាលនៃប្រាសាទមួយដោយប្រើឧបករណ៍វាស់មុំ (Theodolite) កម្ពស់ \(1.5\text{ m}\) ពីដី។ នៅចំណុច \(A\) គេវាស់មុំងើបទៅកំពូលប្រាសាទឃើញ \(32^\circ\)។ បន្ទាប់មក គេដើរសំដៅទៅជិតប្រាសាទបានចម្ងាយ \(35\text{ m}\) ដល់ចំណុច \(B\) រួចវាស់មុំងើបម្ដងទៀតឃើញ \(48^\circ\)។

  1. ចូរសរសេរប្រព័ន្ធសមីការត្រីកោណមាត្រដែលភ្ជាប់កម្ពស់ \(h\) និងចម្ងាយ \(x\)។

  2. គណនាកម្ពស់សរុបនៃប្រាសាទនោះធៀបនឹងផ្ទៃដី។

មើលដំណោះស្រាយ

ការវាស់កម្ពស់ប្រាសាទបុរាណ (STEM/PISA)៖
ឧបករណ៍វាស់កម្ពស់ \(h_0 = 1.5\text{ m}\)។ នៅ \(A\) មុំងើប \(32^\circ\), នៅ \(B\) មុំងើប \(48^\circ\), ចម្ងាយ \(AB = 35\text{ m}\)។

  1. តាង \(h\) ជាកម្ពស់ពីកម្រិតឧបករណ៍វាស់ទៅកំពូលប្រាសាទ និង \(x\) ជាចម្ងាយផ្ដេកពីចំណុច \(B\) ទៅប្រាសាទ៖

    • ពីចំណុច \(B\)៖ \(\tan 48^\circ = \dfrac{h}{x} \implies h = x\tan 48^\circ\)

    • ពីចំណុច \(A\)៖ \(\tan 32^\circ = \dfrac{h}{x + 35} \implies h = (x + 35)\tan 32^\circ\)

    ប្រព័ន្ធសមីការត្រីកោណមាត្រគឺ៖

    \[\begin{cases} h = x\tan 48^\circ \\ h = (x + 35)\tan 32^\circ \end{cases}\]

  2. គណនាកម្ពស់សរុបនៃប្រាសាទ៖
    ផ្ទឹមសមីការទាំងពីរ៖

    \[\begin{aligned} x\tan 48^\circ &= (x + 35)\tan 32^\circ \\ x(\tan 48^\circ - \tan 32^\circ) &= 35\tan 32^\circ \\ x &= \frac{35\tan 32^\circ}{\tan 48^\circ - \tan 32^\circ} \end{aligned}\]
    ជំនួសតម្លៃ \(\tan 48^\circ \approx 1.1106\) និង \(\tan 32^\circ \approx 0.6249\)៖
    \[x = \frac{35 \times 0.6249}{1.1106 - 0.6249} = \frac{21.8715}{0.4857} \approx 45.03\text{ m}\]
    កម្ពស់ \(h\) គឺ៖
    \[h = 45.03 \times 1.1106 \approx 50.01\text{ m}\]
    កម្ពស់សរុបនៃប្រាសាទធៀបនឹងផ្ទៃដីគឺ៖
    \[H = h + h_0 = 50.01 + 1.5 = 51.51\text{ m} \approx 51.5\text{ m}\]
