ប្រព័ន្ធកូអរដោនេដែលយើងប្រើប្រាស់សព្វថ្ងៃ ត្រូវបានបង្កើតឡើងដោយគណិតវិទូជនជាតិបារាំង រ៉ឺនេ ដេកាត (René Descartes) នៅក្នុងសតវត្សទី១៧។ លោកបានភ្ជាប់ធរណីមាត្រទៅនឹងពីជគណិត ដែលអនុញ្ញាតឱ្យយើងដោះស្រាយបញ្ហាធរណីមាត្រដោយប្រើប្រាស់សមីការ។ ប្រព័ន្ធនេះត្រូវបានគេហៅថា "ប្រព័ន្ធកូអរដោនេដេកាត" ដើម្បីជាការផ្តល់កិត្តិយសដល់លោក។

នៅក្នុងអារ្យធម៌អង្គរ បុព្វបុរសខ្មែរបានប្រើប្រាស់ប្រព័ន្ធក្រឡាចត្រង្គ និងអ័ក្សស៊ីមេទ្រីដ៏ល្អឥតខ្ចោះក្នុងការរៀបចំប្លង់មេនៃទីក្រុងអង្គរធំ និងប្រាសាទអង្គរវត្ត ដោយកំណត់ចំណុចស្នូល និងប្រព័ន្ធកូអរដោនេផ្ដេក-បញ្ឈរយ៉ាងច្បាស់លាស់។

ឧទាហរណ៍

ជួរគ្រូមួយតាងដោយបន្ទាត់ចំនួនពិតដែលមានគល់តម្រុយ \(O\) ។

រូបភាពនេះកំពុងរៀបចំ

សុខឈរនៅត្រង់ចំណុច \(A(-3)\) ហើយចំណានឈរនៅត្រង់ចំណុច \(B(5)\) នៃជួរ \(L\) ។ តើសុខឈរនៅចម្ងាយប៉ុន្មានឯកតាពីចំណានចម្ងាយ? ចម្ងាយពី \(A\) ទៅគល់តម្រុយ \(O\) មាន \(3\) ឯកតា ហើយចម្ងាយពី \(O\) ទៅ \(B\) មាន \(5\) ឯកតា ។
គេអាចបកស្រាយតាមកូអរដោនេនៃចំណុចទាំងពីរ \(AB = |5 - (-3)| = |8| = 8\) ។
ដូច្នេះ សុខឈរនៅចម្ងាយ \(8\) ឯកតាពីចំណានចម្ងាយ ។

ជាទូទៅ

ចំណុចចែកខាងក្នុង

ឧទាហរណ៍

គេឱ្យចំណុច \(A(1) \, , \quad{} B(11)\) និង \(P(4)\) នៃបន្ទាត់ចំនួនពិតមួយដែលមានគល់ \(O\) ។ គណនាផលធៀប \(AP : PB\) ។

\(AP = |4 - 1| = 3 \, , \quad{} PB = |11 - 4| = 7\) នោះ \(AP : PB = 3 : 7\) ហើយ \(P\) ជាចំណុចនៃអង្កត់ \(AB\) ។ គេថាចំណុច \(P\) ចែកអង្កត់ \(AB\) ខាងក្នុងតាមផលធៀប \(3 : 7\) ។

ជាទូទៅ

គេឱ្យចំណុច \(P\) នៅលើអង្កត់ \(AB\) ។ បើចំណុច \(P\) ផ្ទៀងផ្ទាត់លក្ខខណ្ឌ \(AP : PB = m : n\) ឬ \(\left(\frac{AP}{PB} = \frac{m}{n}\right)\) ចំពោះ \(m > 0\) និង \(n > 0\) នោះគេថាចំណុច \(P\) ចែកអង្កត់ \(AB\) ខាងក្នុងតាមផលធៀប \(m : n\) ។

\(AP = p + 6 \, , \quad{} PB = 5 - p\) ដោយចំណុច \(P\) ចែកអង្កត់ \(AB\) ខាងក្នុងផលធៀប \(9 : 2\) គេបាន \(AP : PB = (p + 6) : (5 - p) = 9 : 2\) នោះ \(p = 3\) ។

គេឱ្យចំណុចពីរ \(A(a)\) និង \(B(b)\) ។ បង្ហាញថា កូអរដោនេ \(x\) នៃចំណុច \(P\) ចែកអង្កត់ \(AB\) ខាងក្នុងតាមផលធៀប \(m : n\) ដែល

    \[x = \frac{mb + na}{m + n}\]
     ។

    គេបាន \(b < x < a\) ព្រោះ \(P\) នៅចន្លោះ \(B\) និង \(A\)
    \(BP = x - b \, , \quad{} PA = a - x\)

    រូបភាពនេះកំពុងរៀបចំ

ជាទូទៅ

គេឱ្យចំណុច \(Q\) នៅលើបន្លាយ \(AB\) ។ បើចំណុច \(Q\) ផ្ទៀងផ្ទាត់លក្ខខណ្ឌ \(AQ : QB = m : n\) ឬ \(\left(\frac{AQ}{QB} = \frac{m}{n}\right)\) ចំពោះគ្រប់ \(m > 0\) និង \(n > 0\) ហើយ \(m \neq n\) នោះគេថាចំណុច \(Q\) ចែកអង្កត់ \(AB\) ខាងក្រៅតាមផលធៀប \(m : n\) ។
បើ \(m < n\) នោះ \(Q\) ស្ថិតនៅខាងឆ្វេង \(A\) និង បើ \(m > n\) នោះ \(Q\) ស្ថិតនៅខាងស្តាំ \(B\) ។

រូបភាពនេះកំពុងរៀបចំ

ចម្ងាយរវាងពីរចំណុចក្នុងប្លង់កូអរដោនេ

គេអាចប្រើទ្រឹស្តីពីតាក័រ ដើម្បីរកចម្ងាយរវាងពីរចំណុច \(A(x_1, y_1)\) និង \(B(x_2, y_2)\) ។ គូសបន្ទាត់អង្កត់ \(AB\) បិទស្របទៅនឹងអ័ក្សកូអរដោនេ ។
គេអាចបង្កើតត្រីកោណកែង \(ABC\) ដោយ \(C\) ជាចំណុចប្រសព្វរវាងបន្ទាត់ដេកគូសចេញពី \(A\) និងបន្ទាត់ឈរគូសចេញពី \(B\) នោះគេបាន \(AC = |x_2 - x_1| \, , \quad{} BC = |y_2 - y_1|\) ។

រូបភាពនេះកំពុងរៀបចំ

តាមទ្រឹស្តីបទពីតាក័រ

\[AB^2 = AC^2 + BC^2 \Rightarrow AB = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\]
 ។

រូបមន្ត

ចម្ងាយរវាងពីរចំណុច \(A(x_1, y_1)\) និង \(B(x_2, y_2)\) គឺ

\[AB = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\]

\[OP = \sqrt{x^2 + y^2}\]
 ។

ដោយកូអរដោនេនៃចំណុច \(A', B'\) និង \(P'\) គឺ \(x_a \, , \quad{} x_b\) និង \(x\) រៀងគ្នា នោះរូបមន្តចំណុចចែកខាងក្នុងនៅលើបន្ទាត់ចំនួនពិតគឺ

ដោយចំណុច \(Q'\) ជាចំណុចចែកអង្កត់ខាងក្រៅ \(A', B'\) និង \(Q'\) គឺ \(x_a \, , \quad{} x_b\) និង \(x\) រៀងគ្នា នោះរូបមន្តចំណុចចែកក្រៅនៅលើបន្ទាត់ចំនួនពិត គឺ \(x = \frac{mx_b - nx_a}{m - n}\) ។
សម្រាយដូចគ្នាដែរ ដោយគូសបន្ទាត់កែងទៅនឹងអ័ក្សអរដោនេ គេបាន \(y = \frac{my_b - ny_a}{m - n}\) ។ ដូច្នេះ កូអរដោនេនៃចំណុច \(Q\left(\frac{mx_b - nx_a}{m - n}, \frac{my_b - ny_a}{m - n}\right)\) ។

ជាទូទៅ

ចំណុចពីរ \(A(x_a, y_a)\) និង \(B(x_b, y_b)\) ក្នុងតម្រុយកូអរដោនេ ។ បើចំណុច \(Q(x, y)\) ចែកអង្កត់ \(AB\) ខាងក្រៅតាមផលធៀប \(m : n\) នោះ \(Q\left(\frac{mx_b - nx_a}{m - n}, \frac{my_b - ny_a}{m - n}\right)\) ។

៦លំហាត់គំរូ ៦

ដំណោះស្រាយ

ប្រតិបត្តិ

\(P\left(-7, \frac{13}{2}\right)\) ។

លំហាត់អនុវត្តន៍

១លំហាត់ទី ១

គេឱ្យចំណុច \(A(-4)\), \(B(2)\), \(C(6)\) និង \(D(-1)\) លើបន្ទាត់ចំនួន។ គណនាចម្ងាយ \(AB\), \(BC\), \(CD\) និង \(AD\)។

មើលដំណោះស្រាយ

គណនាចម្ងាយរវាងចំណុចលើបន្ទាត់ចំនួន ៖
រូបមន្តចម្ងាយរវាងចំណុច \(X(x_1)\) និង \(Y(x_2)\) គឺ \(XY = |x_2 - x_1|\)។
គេមាន \(A(-4)\), \(B(2)\), \(C(6)\) និង \(D(-1)\) ៖

  • \(AB = |x_B - x_A| = |2 - (-4)| = |2 + 4| = 6\)

  • \(BC = |x_C - x_B| = |6 - 2| = |4| = 4\)

  • \(CD = |x_D - x_C| = |-1 - 6| = |-7| = 7\)

  • \(AD = |x_D - x_A| = |-1 - (-4)| = |-1 + 4| = 3\)

ដូចនេះ \(AB = 6\), \(BC = 4\), \(CD = 7\) និង \(AD = 3\)។

២លំហាត់ទី ២

លើបន្ទាត់ចំនួន គេឱ្យចំណុច \(A(-3)\) និង \(B(7)\)។ រកកូអរដោនេនៃចំណុចកណ្តាល \(M\) នៃអង្កត់ \(AB\)។

មើលដំណោះស្រាយ

រកកូអរដោនេចំណុចកណ្តាល \(M\) នៃអង្កត់ \(AB\) លើបន្ទាត់ចំនួន ៖
រូបមន្ត ៖ \(x_M = \dfrac{x_A + x_B}{2}\)
គេមាន \(A(-3)\) និង \(B(7)\) ៖
\(x_M = \dfrac{-3 + 7}{2} = \dfrac{4}{2} = 2\)
ដូចនេះ ចំណុចកណ្តាលគឺ \(M(2)\)។

៣លំហាត់ទី ៣

គេឱ្យពីរចំណុច \(A(-2)\) និង \(B(8)\) លើបន្ទាត់ចំនួន។ រកកូអរដោនេនៃចំណុច \(P\) ដែលចែកអង្កត់ \(AB\) ខាងក្នុងតាមផលធៀប \(\dfrac{AP}{PB} = \dfrac{2}{3}\)។

មើលដំណោះស្រាយ

រកចំណុច \(P\) ចែកអង្កត់ \(AB\) ខាងក្នុងតាមផលធៀប \(\dfrac{AP}{PB} = \dfrac{2}{3}\) ៖
រូបមន្តចែកខាងក្នុងតាមផលធៀប \(m:n\) ៖
\(x_P = \dfrac{m x_B + n x_A}{m + n}\)
ដោយ \(m = 2, n = 3, x_A = -2, x_B = 8\) ៖
\(x_P = \dfrac{2(8) + 3(-2)}{2 + 3} = \dfrac{16 - 6}{5} = \dfrac{10}{5} = 2\)
ដូចនេះ ចំណុចចែកគឺ \(P(2)\)។

៤លំហាត់ទី ៤

គេឱ្យចំណុច \(E(1)\) និង \(F(9)\) លើបន្ទាត់ចំនួន។ រកកូអរដោនេនៃចំណុច \(Q\) ដែលចែកអង្កត់ \(EF\) ខាងក្រៅតាមផលធៀប \(\dfrac{QE}{QF} = 3\)។

មើលដំណោះស្រាយ

រកចំណុច \(Q\) ចែកអង្កត់ \(EF\) ខាងក្រៅតាមផលធៀប \(\dfrac{QE}{QF} = 3\) ៖
រូបមន្តចែកខាងក្រៅតាមផលធៀប \(k = 3\) ៖
\(x_Q = \dfrac{k x_F - x_E}{k - 1}\)
ដោយ \(x_E = 1, x_F = 9, k = 3\) ៖
\(x_Q = \dfrac{3(9) - 1}{3 - 1} = \dfrac{27 - 1}{2} = \dfrac{26}{2} = 13\)
ដូចនេះ ចំណុចចែកខាងក្រៅគឺ \(Q(13)\)។

៦លំហាត់ទី ៦

គណនាចម្ងាយរវាងពីរចំណុច \(A\) និង \(B\) ៖

  1. \(A(1, 2)\) និង \(B(4, 6)\)

  2. \(A(-2, 3)\) និង \(B(3, -9)\)

  3. \(A(0, -4)\) និង \(B(6, 4)\)

  4. \(A(-3, -2)\) និង \(B(5, 4)\)

មើលដំណោះស្រាយ

គណនាចម្ងាយរវាងពីរចំណុច \(A(x_A, y_A)\) និង \(B(x_B, y_B)\) ៖
រូបមន្ត ៖ \(AB = \sqrt{(x_B - x_A)^2 + (y_B - y_A)^2}\)
ក.  \(A(1, 2)\) និង \(B(4, 6)\) ៖
\(AB = \sqrt{(4 - 1)^2 + (6 - 2)^2} = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5\)។
ខ.  \(A(-2, 3)\) និង \(B(3, -9)\) ៖
\(AB = \sqrt{(3 - (-2))^2 + (-9 - 3)^2} = \sqrt{5^2 + (-12)^2} = \sqrt{25 + 144} = \sqrt{169} = 13\)។
គ.  \(A(0, -4)\) និង \(B(6, 4)\) ៖
\(AB = \sqrt{(6 - 0)^2 + (4 - (-4))^2} = \sqrt{6^2 + 8^2} = \sqrt{36 + 64} = \sqrt{100} = 10\)។
ឃ.  \(A(-3, -2)\) និង \(B(5, 4)\) ៖
\(AB = \sqrt{(5 - (-3))^2 + (4 - (-2))^2} = \sqrt{8^2 + 6^2} = \sqrt{64 + 36} = \sqrt{100} = 10\)។

៨លំហាត់ទី ៨

រកចំណុច \(M\) លើអ័ក្សអាប់ស៊ីស (\(Ox\)) ដែលនៅស្មើចម្ងាយពីចំណុច \(A(2, -1)\) និង \(B(4, 3)\)។

មើលដំណោះស្រាយ

រកចំណុច \(M\) លើអ័ក្ស \(Ox\) ដែលស្មើចម្ងាយពី \(A(2, -1)\) និង \(B(4, 3)\) ៖
ដោយ \(M \in Ox\) នាំឱ្យ \(M\) មានកូអរដោនេ \(M(x, 0)\)។
លក្ខខណ្ឌស្មើចម្ងាយ ៖ \(MA = MB \iff MA^2 = MB^2\)
\((x - 2)^2 + (0 - (-1))^2 = (x - 4)^2 + (0 - 3)^2\)
\(\iff x^2 - 4x + 4 + 1 = x^2 - 8x + 16 + 9\)
\(\iff x^2 - 4x + 5 = x^2 - 8x + 25\)
\(\iff -4x + 8x = 25 - 5 \iff 4x = 20 \iff x = 5\)
ដូចនេះ ចំណុចដែលត្រូវរកគឺ \(M(5, 0)\)។

៩លំហាត់ទី ៩

មើលដំណោះស្រាយ

រកចំណុច \(N\) លើអ័ក្ស \(Oy\) ដែលស្មើចម្ងាយពី \(P(-3, 2)\) និង \(Q(5, -4)\) ៖
ដោយ \(N \in Oy\) នាំឱ្យ \(N\) មានកូអរដោនេ \(N(0, y)\)។
លក្ខខណ្ឌ ៖ \(NP^2 = NQ^2\)
\((0 - (-3))^2 + (y - 2)^2 = (0 - 5)^2 + (y - (-4))^2\)
\(\iff 9 + y^2 - 4y + 4 = 25 + y^2 + 8y + 16\)
\(\iff y^2 - 4y + 13 = y^2 + 8y + 41\)
\(\iff -4y - 8y = 41 - 13 \iff -12y = 28 \iff y = -\dfrac{28}{12} = -\dfrac{7}{3}\)
ដូចនេះ ចំណុចដែលត្រូវរកគឺ \(N\left(0, -\dfrac{7}{3}\right)\)។

១០លំហាត់ទី ១០

រកចំណុច \(P(x, y)\) ដែលនៅស្មើចម្ងាយពីចំណុចទាំងបី \(A(1, 7)\), \(B(8, 6)\) និង \(C(7, -1)\) (ផ្ចិតរង្វង់ចារឹកក្រៅត្រីកោណ)។

មើលដំណោះស្រាយ

រកចំណុច \(P(x, y)\) ដែលនៅស្មើចម្ងាយពី \(A(1, 7)\), \(B(8, 6)\) និង \(C(7, -1)\) ៖
លក្ខខណ្ឌ ៖ \(PA^2 = PB^2 = PC^2\)
\(\bullet\ PA^2 = (x - 1)^2 + (y - 7)^2 = x^2 + y^2 - 2x - 14y + 50\)
\(\bullet\ PB^2 = (x - 8)^2 + (y - 6)^2 = x^2 + y^2 - 16x - 12y + 100\)
\(\bullet\ PC^2 = (x - 7)^2 + (y + 1)^2 = x^2 + y^2 - 14x + 2y + 50\)
ពី \(PA^2 = PB^2\) ៖
\(-2x - 14y + 50 = -16x - 12y + 100\)
\(\iff 14x - 2y = 50 \iff 7x - y = 25 \quad{} (1)\)
ពី \(PA^2 = PC^2\) ៖
\(-2x - 14y + 50 = -14x + 2y + 50\)
\(\iff 12x - 16y = 0 \iff 3x - 4y = 0 \iff y = \dfrac{3}{4}x \quad{} (2)\)
ជំនួស \((2)\) ចូល \((1)\) ៖
\(7x - \dfrac{3}{4}x = 25 \iff \dfrac{25}{4}x = 25 \iff x = 4\)
ទាញបាន \(y = \dfrac{3}{4}(4) = 3\)។
ដូចនេះ ចំណុចនោះគឺ \(P(4, 3)\) (ជាផ្ចិតរង្វង់ចារឹកក្រៅ \(\triangle ABC\))។

\(x_M = \dfrac{-4 + 2}{2} = -1, \quad{} y_M = \dfrac{-6 + 2}{2} = -2 \implies M(-1, -2)\)។
ឃ.  \(A(0, 7)\) និង \(B(-6, 1)\) ៖
\(x_M = \dfrac{0 + (-6)}{2} = -3, \quad{} y_M = \dfrac{7 + 1}{2} = 4 \implies M(-3, 4)\)។

១២លំហាត់ទី ១២

គេឱ្យចំណុចកណ្តាល \(M(3, -2)\) នៃអង្កត់ \(AB\) និងចុងម្ខាង \(A(1, 4)\)។ រកកូអរដោនេនៃចុង \(B\)។

មើលដំណោះស្រាយ

រកកូអរដោនេចុង \(B(x_B, y_B)\) ដោយស្គាល់ \(M(3, -2)\) និង \(A(1, 4)\) ៖
តាមរូបមន្តចំណុចកណ្តាល ៖
\(x_M = \dfrac{x_A + x_B}{2} \iff 3 = \dfrac{1 + x_B}{2} \iff 1 + x_B = 6 \iff x_B = 5\)
\(y_M = \dfrac{y_A + y_B}{2} \iff -2 = \dfrac{4 + y_B}{2} \iff 4 + y_B = -4 \iff y_B = -8\)
ដូចនេះ ចុង \(B\) មានកូអរដោនេគឺ \(B(5, -8)\)។

១៣លំហាត់ទី ១៣

រកកូអរដោនេនៃចំណុច \(P\) ដែលចែកអង្កត់ \(AB\) ខាងក្នុងតាមផលធៀប \(2:1\) ដោយដឹងថា \(A(1, 2)\) និង \(B(7, 8)\)។

មើលដំណោះស្រាយ

រកចំណុច \(P\) ចែកអង្កត់ \(AB\) ខាងក្នុងតាមផលធៀប \(m:n = 2:1\) ៖
រូបមន្ត ៖ \(x_P = \dfrac{m x_B + n x_A}{m + n}, \quad{} y_P = \dfrac{m y_B + n y_A}{m + n}\)
ដោយ \(A(1, 2)\) និង \(B(7, 8)\) ៖
\(x_P = \dfrac{2(7) + 1(1)}{2 + 1} = \dfrac{14 + 1}{3} = \dfrac{15}{3} = 5\)
\(y_P = \dfrac{2(8) + 1(2)}{2 + 1} = \dfrac{16 + 2}{3} = \dfrac{18}{3} = 6\)
ដូចនេះ \(P(5, 6)\)។

១៤លំហាត់ទី ១៤

រកកូអរដោនេនៃចំណុច \(Q\) ដែលចែកអង្កត់ \(AB\) ខាងក្នុងតាមផលធៀប \(1:3\) ដោយដឹងថា \(A(-4, 2)\) និង \(B(4, 10)\)។

មើលដំណោះស្រាយ

រកចំណុច \(Q\) ចែកអង្កត់ \(AB\) ខាងក្នុងតាមផលធៀប \(m:n = 1:3\) ៖
ដោយ \(A(-4, 2)\) និង \(B(4, 10)\) ៖
\(x_Q = \dfrac{1(4) + 3(-4)}{1 + 3} = \dfrac{4 - 12}{4} = \dfrac{-8}{4} = -2\)
\(y_Q = \dfrac{1(10) + 3(2)}{1 + 3} = \dfrac{10 + 6}{4} = \dfrac{16}{4} = 4\)
ដូចនេះ \(Q(-2, 4)\)។

១៥លំហាត់ទី ១៥

រកកូអរដោនេនៃចំណុច \(R\) ដែលចែកអង្កត់ \(AB\) ខាងក្រៅតាមផលធៀប \(3:1\) ដោយដឹងថា \(A(2, 1)\) និង \(B(4, 3)\)។

មើលដំណោះស្រាយ

រកចំណុច \(R\) ចែកអង្កត់ \(AB\) ខាងក្រៅតាមផលធៀប \(k = 3:1 = 3\) ៖
រូបមន្ត ៖ \(x_R = \dfrac{k x_B - x_A}{k - 1}, \quad{} y_R = \dfrac{k y_B - y_A}{k - 1}\)
ដោយ \(A(2, 1)\) និង \(B(4, 3)\) ៖
\(x_R = \dfrac{3(4) - 2}{3 - 1} = \dfrac{12 - 2}{2} = \dfrac{10}{2} = 5\)
\(y_R = \dfrac{3(3) - 1}{3 - 1} = \dfrac{9 - 1}{2} = \dfrac{8}{2} = 4\)
ដូចនេះ \(R(5, 4)\)។

១៦លំហាត់ទី ១៦

រកកូអរដោនេនៃចំណុចបែងចែកជាបីស្មើគ្នា (Trisection points) នៃអង្កត់ \(AB\) ដែល \(A(-3, 6)\) និង \(B(6, -3)\)។

មើលដំណោះស្រាយ

រកចំណុចបែងចែកជាបីស្មើគ្នា (Trisection points) នៃ \(AB\) ៖
គេមាន \(A(-3, 6)\) និង \(B(6, -3)\)។
- ចំណុច \(P_1\) ចែក \(AB\) តាមផលធៀប \(1:2\) ៖
\(x_1 = \dfrac{1(6) + 2(-3)}{1 + 2} = \dfrac{6 - 6}{3} = 0\)
\(y_1 = \dfrac{1(-3) + 2(6)}{1 + 2} = \dfrac{-3 + 12}{3} = \dfrac{9}{3} = 3 \implies P_1(0, 3)\)
- ចំណុច \(P_2\) ចែក \(AB\) តាមផលធៀប \(2:1\) ៖
\(x_2 = \dfrac{2(6) + 1(-3)}{2 + 1} = \dfrac{12 - 3}{3} = \dfrac{9}{3} = 3\)
\(y_2 = \dfrac{2(-3) + 1(6)}{2 + 1} = \dfrac{-6 + 6}{3} = 0 \implies P_2(3, 0)\)
ដូចនេះ ចំណុចបែងចែកទាំងពីរគឺ \((0, 3)\) និង \((3, 0)\)។

១៧លំហាត់ទី ១៧

គេឱ្យចំណុច \(A(1, 1)\), \(B(5, 3)\), \(C(7, 7)\) និង \(D(3, 5)\)។

  1. គណនាកូអរដោនេចំណុចកណ្តាលនៃអង្កត់ទ្រូង \(AC\) និង \(BD\)។

  2. ទាញបញ្ជាក់ថា \(ABCD\) ជាប្រលេឡូក្រាម។

មើលដំណោះស្រាយ

គេឱ្យចំណុច \(A(1, 1)\), \(B(5, 3)\), \(C(7, 7)\) និង \(D(3, 5)\) ៖
ក.  គណនាកូអរដោនេចំណុចកណ្តាលនៃអង្កត់ទ្រូង \(AC\) និង \(BD\) ៖
- ចំណុចកណ្តាល \(M_{AC}\) នៃ \(AC\) ៖
\(x = \dfrac{1 + 7}{2} = 4, \quad{} y = \dfrac{1 + 7}{2} = 4 \implies M_{AC}(4, 4)\)
- ចំណុចកណ្តាល \(M_{BD}\) នៃ \(BD\) ៖
\(x = \dfrac{5 + 3}{2} = 4, \quad{} y = \dfrac{3 + 5}{2} = 4 \implies M_{BD}(4, 4)\)
ខ.  បញ្ជាក់ថា \(ABCD\) ជាប្រលេឡូក្រាម ៖
ដោយសារអង្កត់ទ្រូងទាំងពីរ \(AC\) និង \(BD\) មានចំណុចកណ្តាលរួមគ្នាគឺ \((4, 4)\) (ប្រសព្វគ្នានៅត្រង់ចំណុចកណ្តាលរៀងៗខ្លួន) តាមលក្ខណៈធរណីមាត្រ ចតុកោណ \(ABCD\) គឺជាប្រលេឡូក្រាម។

១៨លំហាត់ទី ១៨

គេឱ្យកំពូលបីនៃប្រលេឡូក្រាម \(ABCD\) គឺ \(A(1, 2)\), \(B(4, 5)\) និង \(C(6, 3)\)។ រកកូអរដោនេនៃកំពូលទីបួន \(D\)។

មើលដំណោះស្រាយ

រកកំពូលទីបួន \(D(x_D, y_D)\) នៃប្រលេឡូក្រាម \(ABCD\) ៖
គេឱ្យ \(A(1, 2)\), \(B(4, 5)\) និង \(C(6, 3)\)។
ក្នុងប្រលេឡូក្រាម អង្កត់ទ្រូង \(AC\) និង \(BD\) មានចំណុចកណ្តាលរួម ៖
\(x_A + x_C = x_B + x_D \implies x_D = x_A + x_C - x_B = 1 + 6 - 4 = 3\)
\(y_A + y_C = y_B + y_D \implies y_D = y_A + y_C - y_B = 2 + 3 - 5 = 0\)
ដូចនេះ កំពូលទីបួនគឺ \(D(3, 0)\)។

១៩លំហាត់ទី ១៩

គេឱ្យចំណុច \(A(2, 4)\), \(B(-1, 1)\) និង \(C(5, 1)\)។

  1. គណនាប្រវែងជ្រុង \(AB\), \(BC\) និង \(AC\)។

  2. បង្ហាញថា \(\triangle ABC\) ជាត្រីកោណកែងត្រង់ \(A\)។

មើលដំណោះស្រាយ

គេឱ្យចំណុច \(A(2, 4)\), \(B(-1, 1)\) និង \(C(5, 1)\) ៖
ក.  គណនាប្រវែងជ្រុងទាំងបី ៖
\(AB = \sqrt{(-1 - 2)^2 + (1 - 4)^2} = \sqrt{(-3)^2 + (-3)^2} = \sqrt{18} = 3\sqrt{2}\)
\(AC = \sqrt{(5 - 2)^2 + (1 - 4)^2} = \sqrt{3^2 + (-3)^2} = \sqrt{18} = 3\sqrt{2}\)
\(BC = \sqrt{(5 - (-1))^2 + (1 - 1)^2} = \sqrt{6^2 + 0} = 6\)
ខ.  បង្ហាញថា \(\triangle ABC\) ជាត្រីកោណកែងត្រង់ \(A\) ៖
ពិនិត្យផលបូកការ៉េនៃជ្រុង ៖
\(AB^2 + AC^2 = (3\sqrt{2})^2 + (3\sqrt{2})^2 = 18 + 18 = 36\)
\(BC^2 = 6^2 = 36\)
ដោយ \(AB^2 + AC^2 = BC^2\) តាមច្រាសទ្រឹស្តីបទពីតាករ \(\triangle ABC\) គឺជាត្រីកោណកែងត្រង់ \(A\) (លើសពីនេះជាត្រីកោណកែងសមបាតព្រោះ \(AB = AC = 3\sqrt{2}\))។

២០លំហាត់ទី ២០

បង្ហាញថាចំណុច \(A(1, 3)\), \(B(4, 7)\) និង \(C(8, 4)\) ជាកំពូលនៃត្រីកោណកែងសមបាត។

មើលដំណោះស្រាយ

បង្ហាញថា \(A(1, 3)\), \(B(4, 7)\) និង \(C(8, 4)\) ជាកំពូលនៃត្រីកោណកែងសមបាត ៖
គណនាការ៉េនៃប្រវែងជ្រុងទាំងបី ៖
\(AB^2 = (4 - 1)^2 + (7 - 3)^2 = 3^2 + 4^2 = 9 + 16 = 25\)
\(BC^2 = (8 - 4)^2 + (4 - 7)^2 = 4^2 + (-3)^2 = 16 + 9 = 25\)
\(AC^2 = (8 - 1)^2 + (4 - 3)^2 = 7^2 + 1^2 = 49 + 1 = 50\)
សង្កេតឃើញថា ៖

  1. \(AB^2 = BC^2 = 25 \implies AB = BC = 5\) (ត្រីកោណសមបាតកំពូល \(B\))

  2. \(AB^2 + BC^2 = 25 + 25 = 50 = AC^2\) (ត្រីកោណកែងត្រង់ \(B\) តាមច្រាសពីតាករ)

ដូចនេះ \(\triangle ABC\) ជាត្រីកោណកែងសមបាតត្រង់កំពូល \(B\)។

២១លំហាត់ទី ២១

រកកូអរដោនេទីប្រជុំទម្ងន់ \(G\) នៃត្រីកោណ \(ABC\) ៖

  1. \(A(1, 4), B(3, -2), C(5, 7)\)

  2. \(A(-2, 3), B(4, 1), C(1, -7)\)

  3. \(A(0, 0), B(6, 0), C(0, 9)\)

  4. \(A(-3, -1), B(2, 4), C(4, -6)\)

មើលដំណោះស្រាយ

រកកូអរដោនេទីប្រជុំទម្ងន់ \(G\) នៃត្រីកោណ \(ABC\) ៖
រូបមន្ត ៖ \(x_G = \dfrac{x_A + x_B + x_C}{3}, \quad{} y_G = \dfrac{y_A + y_B + y_C}{3}\)
ក.  \(A(1, 4), B(3, -2), C(5, 7)\) ៖
\(x_G = \dfrac{1 + 3 + 5}{3} = \dfrac{9}{3} = 3, \quad{} y_G = \dfrac{4 - 2 + 7}{3} = \dfrac{9}{3} = 3 \implies G(3, 3)\)។
ខ.  \(A(-2, 3), B(4, 1), C(1, -7)\) ៖
\(x_G = \dfrac{-2 + 4 + 1}{3} = 1, \quad{} y_G = \dfrac{3 + 1 - 7}{3} = -1 \implies G(1, -1)\)។
គ.  \(A(0, 0), B(6, 0), C(0, 9)\) ៖
\(x_G = \dfrac{0 + 6 + 0}{3} = 2, \quad{} y_G = \dfrac{0 + 0 + 9}{3} = 3 \implies G(2, 3)\)។
ឃ.  \(A(-3, -1), B(2, 4), C(4, -6)\) ៖
\(x_G = \dfrac{-3 + 2 + 4}{3} = 1, \quad{} y_G = \dfrac{-1 + 4 - 6}{3} = -1 \implies G(1, -1)\)។

២២លំហាត់ទី ២២

ត្រីកោណ \(ABC\) មានទីប្រជុំទម្ងន់ \(G(2, 3)\) និងកំពូលពីរគឺ \(A(1, 2)\) និង \(B(3, 5)\)។ រកកូអរដោនេនៃកំពូលទីបី \(C\)។

មើលដំណោះស្រាយ

រកកូអរដោនេកំពូលទីបី \(C(x_C, y_C)\) នៃត្រីកោណ \(ABC\) ៖
គេឱ្យ \(G(2, 3)\), \(A(1, 2)\) និង \(B(3, 5)\) ៖
\(x_G = \dfrac{x_A + x_B + x_C}{3} \iff 2 = \dfrac{1 + 3 + x_C}{3} \iff 4 + x_C = 6 \iff x_C = 2\)
\(y_G = \dfrac{y_A + y_B + y_C}{3} \iff 3 = \dfrac{2 + 5 + y_C}{3} \iff 7 + y_C = 9 \iff y_C = 2\)

២៣លំហាត់ទី ២៣

ក្នុងត្រីកោណ \(ABC\) ដែលមានកំពូល \(A(0, 6)\), \(B(-4, 0)\) និង \(C(2, 0)\) គណនាប្រវែងមេដ្យាន \(AM\) គូសចេញពីកំពូល \(A\)។

មើលដំណោះស្រាយ

គណនាប្រវែងមេដ្យាន \(AM\) ចេញពីកំពូល \(A(0, 6)\) នៃ \(\triangle ABC\) ៖
គេមាន \(B(-4, 0)\) និង \(C(2, 0)\)។
ចំណុចកណ្តាល \(M\) នៃជ្រុង \(BC\) ៖

ប្រវែងមេដ្យាន \(AM\) ៖

២៤លំហាត់ទី ២៤

បង្ហាញថាចំណុចទាំងបី \(A(1, 2)\), \(B(3, 5)\) និង \(C(7, 11)\) រត់ត្រង់ជួរគ្នា (Collinear)។

មើលដំណោះស្រាយ

បង្ហាញថា \(A(1, 2)\), \(B(3, 5)\) និង \(C(7, 11)\) រត់ត្រង់ជួរគ្នា (Collinear) ៖
វិធីទី ១ (ពិនិត្យមេគុណប្រាប់ទិស) ៖
- មេគុណប្រាប់ទិសនៃបន្ទាត់ \(AB\) ៖
\(m_{AB} = \dfrac{y_B - y_A}{x_B - x_A} = \dfrac{5 - 2}{3 - 1} = \dfrac{3}{2}\)
- មេគុណប្រាប់ទិសនៃបន្ទាត់ \(BC\) ៖
\(m_{BC} = \dfrac{y_C - y_B}{x_C - x_B} = \dfrac{11 - 5}{7 - 3} = \dfrac{6}{4} = \dfrac{3}{2}\)
ដោយសារ \(m_{AB} = m_{BC}\) និងមានចំណុច \(B\) រួម នោះចំណុចទាំងបី \(A, B, C\) ស្ថិតនៅលើបន្ទាត់តែមួយ (រត់ត្រង់ជួរគ្នា)។

២៥លំហាត់ទី ២៥

កំណត់តម្លៃ \(k\) ដើម្បីឱ្យចំណុច \(A(2, 3)\), \(B(4, k)\) និង \(C(6, 9)\) រត់ត្រង់ជួរគ្នា។

មើលដំណោះស្រាយ

កំណត់តម្លៃ \(k\) ដើម្បីឱ្យ \(A(2, 3)\), \(B(4, k)\) និង \(C(6, 9)\) រត់ត្រង់ជួរគ្នា ៖
ចំណុចទាំងបីរត់ត្រង់ជួរគ្នាលុះត្រាតែ \(m_{AB} = m_{AC}\) ៖
\(m_{AB} = \dfrac{k - 3}{4 - 2} = \dfrac{k - 3}{2}\)
\(m_{AC} = \dfrac{9 - 3}{6 - 2} = \dfrac{6}{4} = \dfrac{3}{2}\)
សមមូលនឹង ៖ \(\dfrac{k - 3}{2} = \dfrac{3}{2} \iff k - 3 = 3 \iff k = 6\)។
ដូចនេះ តម្លៃដែលត្រូវរកគឺ \(k = 6\)។

២៦លំហាត់ទី ២៦

គណនាផ្ទៃក្រឡានៃត្រីកោណ \(ABC\) ដោយប្រើរូបមន្តកូអរដោនេ ៖

  1. \(A(1, 2), B(4, 6), C(3, 8)\)

  2. \(A(-2, 1), B(3, 4), C(1, -3)\)

  3. \(A(0, 0), B(5, 2), C(2, 6)\)

  4. \(A(3, 1), B(-1, 3), C(2, -4)\)

មើលដំណោះស្រាយ

គណនាផ្ទៃក្រឡានៃត្រីកោណ \(ABC\) តាមរូបមន្តកូអរដោនេ ៖
\(S = \dfrac{1}{2} |x_A(y_B - y_C) + x_B(y_C - y_A) + x_C(y_A - y_B)|\)
ក.  \(A(1, 2), B(4, 6), C(3, 8)\) ៖
\(S = \dfrac{1}{2} |1(6 - 8) + 4(8 - 2) + 3(2 - 6)| = \dfrac{1}{2} |-2 + 24 - 12| = \dfrac{1}{2} |10| = 5\) ឯកតាផ្ទៃ។
ខ.  \(A(-2, 1), B(3, 4), C(1, -3)\) ៖
\(S = \dfrac{1}{2} |-2(4 - (-3)) + 3(-3 - 1) + 1(1 - 4)|\)
\(= \dfrac{1}{2} |-14 - 12 - 3| = \dfrac{1}{2} |-29| = \dfrac{29}{2} = 14.5\) ឯកតាផ្ទៃ។
គ.  \(A(0, 0), B(5, 2), C(2, 6)\) ៖
\(S = \dfrac{1}{2} |x_B y_C - x_C y_B| = \dfrac{1}{2} |5(6) - 2(2)| = \dfrac{1}{2} |30 - 4| = \dfrac{26}{2} = 13\) ឯកតាផ្ទៃ។
ឃ.  \(A(3, 1), B(-1, 3), C(2, -4)\) ៖
\(S = \dfrac{1}{2} |3(3 - (-4)) + (-1)(-4 - 1) + 2(1 - 3)|\)
\(= \dfrac{1}{2} |21 + 5 - 4| = \dfrac{1}{2} |22| = 11\) ឯកតាផ្ទៃ។

២៧លំហាត់ទី ២៧

គណនាផ្ទៃក្រឡានៃចតុកោណ \(ABCD\) ដែលមានកំពូល \(A(1, 1)\), \(B(4, 2)\), \(C(5, 6)\) និង \(D(2, 5)\)។

មើលដំណោះស្រាយ

គណនាផ្ទៃក្រឡាចតុកោណ \(ABCD\) តាមក្បួនចងខ្សែស្បែកជើង ៖
កំពូល \(A(1, 1), B(4, 2), C(5, 6), D(2, 5)\) ៖
ផលបូកអង្កត់ទ្រូងចុះ ៖
\(\Sigma_{\downarrow} = 1(2) + 4(6) + 5(5) + 2(1) = 2 + 24 + 25 + 2 = 53\)
ផលបូកអង្កត់ទ្រូងឡើង ៖
\(\Sigma_{\uparrow} = 1(4) + 2(5) + 6(2) + 5(1) = 4 + 10 + 12 + 5 = 31\)
ផ្ទៃក្រឡា ៖
\(S = \dfrac{1}{2} |\Sigma_{\downarrow} - \Sigma_{\uparrow}| = \dfrac{1}{2} |53 - 31| = \dfrac{1}{2}(22) = 11\) ឯកតាផ្ទៃ។

២៨លំហាត់ទី ២៨

រកកូអរដោនេផ្ចិតរង្វង់ចារឹកក្រៅត្រីកោណកែង \(A(0, 0)\), \(B(6, 0)\) និង \(C(0, 8)\)។

មើលដំណោះស្រាយ

រកកូអរដោនេផ្ចិតរង្វង់ចារឹកក្រៅត្រីកោណកែង \(A(0, 0)\), \(B(6, 0)\) និង \(C(0, 8)\) ៖
ត្រីកោណនេះកែងត្រង់ \(A(0, 0)\) ព្រោះជ្រុង \(AB\) ស្ថិតលើអ័ក្ស \(Ox\) និងជ្រុង \(AC\) ស្ថិតលើអ័ក្ស \(Oy\)។
ក្នុងត្រីកោណកែង ផ្ចិតរង្វង់ចារឹកក្រៅ \(I\) គឺជាចំណុចកណ្តាលនៃអ៊ីប៉ូតេនុស \(BC\) ៖
\(x_I = \dfrac{x_B + x_C}{2} = \dfrac{6 + 0}{2} = 3\)
\(y_I = \dfrac{y_B + y_C}{2} = \dfrac{0 + 8}{2} = 4\)
ដូចនេះ ផ្ចិតរង្វង់ចារឹកក្រៅគឺ \(I(3, 4)\) (មានកាំ \(R = \dfrac{BC}{2} = \dfrac{\sqrt{6^2 + 8^2}}{2} = 5\))។

២៩លំហាត់ទី ២៩

រកកូអរដោនេអរតូសង់ \(H\) (ប្រសព្វកម្ពស់) នៃត្រីកោណ \(A(0, 0)\), \(B(4, 0)\) និង \(C(0, 5)\)។

មើលដំណោះស្រាយ

រកអរតូសង់ \(H\) (ប្រសព្វកម្ពស់) នៃ \(\triangle ABC\) ដែល \(A(0, 0)\), \(B(4, 0)\), \(C(0, 5)\) ៖
ជ្រុង \(AB\) ស្ថិតលើអ័ក្ស \(Ox\) ហើយជ្រុង \(AC\) ស្ថិតលើអ័ក្ស \(Oy\) នាំឱ្យ \(AB \perp AC\) (ត្រីកោណកែងត្រង់កំពូល \(A\))។
ក្នុងត្រីកោណកែង កម្ពស់គូសចេញពី \(B\) គឺជ្រុង \(BA\) ហើយកម្ពស់គូសចេញពី \(C\) គឺជ្រុង \(CA\)។ កម្ពស់ទាំងពីរនេះប្រសព្វគ្នាត្រង់កំពូលមុំកែង \(A\) តែម្តង។
ដូចនេះ អរតូសង់គឺ \(H \equiv A(0, 0)\)។

៣០លំហាត់ទី ៣០

រកសមីការសំណុំចំណុច \(M(x, y)\) ដែលនៅស្មើចម្ងាយពី \(A(1, 2)\) និង \(B(3, 4)\) (មេដ្យាទ័រនៃ \(AB\))។

មើលដំណោះស្រាយ

រកសមីការសំណុំចំណុច \(M(x, y)\) ដែលនៅស្មើចម្ងាយពី \(A(1, 2)\) និង \(B(3, 4)\) ៖
លក្ខខណ្ឌ ៖ \(MA^2 = MB^2\)
\((x - 1)^2 + (y - 2)^2 = (x - 3)^2 + (y - 4)^2\)
\(\iff x^2 - 2x + 1 + y^2 - 4y + 4 = x^2 - 6x + 9 + y^2 - 8y + 16\)
\(\iff -2x - 4y + 5 = -6x - 8y + 25\)
\(\iff 4x + 4y = 20 \iff x + y - 5 = 0\)។
ដូចនេះ សមីការមេដ្យាទ័រនៃ \(AB\) គឺ \(x + y - 5 = 0\) (ឬ \(y = -x + 5\))។

៣១លំហាត់ទី ៣១

រកសំណុំចំណុច \(M(x, y)\) ដែលផ្ទៀងផ្ទាត់ \(MA^2 + MB^2 = 20\) ដោយដឹងថា \(A(-1, 0)\) និង \(B(1, 0)\)។

មើលដំណោះស្រាយ

រកសំណុំចំណុច \(M(x, y)\) ដែលផ្ទៀងផ្ទាត់ \(MA^2 + MB^2 = 20\) ៖
គេមាន \(A(-1, 0)\) និង \(B(1, 0)\) ៖
\(MA^2 = (x + 1)^2 + y^2 = x^2 + 2x + 1 + y^2\)
\(MB^2 = (x - 1)^2 + y^2 = x^2 - 2x + 1 + y^2\)
បូកបញ្ចូលគ្នា ៖
\(MA^2 + MB^2 = 2x^2 + 2y^2 + 2 = 20\)
\(\iff 2(x^2 + y^2) = 18 \iff x^2 + y^2 = 9\)។
ដូចនេះ សំណុំចំណុច \(M\) គឺជារង្វង់ដែលមានផ្ចិតនៅគល់កូអរដោនេ \(O(0, 0)\) និងកាំ \(R = 3\)។

៣២លំហាត់ទី ៣២

រកសំណុំចំណុច \(M(x, y)\) ដែលផ្ទៀងផ្ទាត់ \(\dfrac{MA}{MB} = 2\) ដោយដឹងថា \(A(-2, 0)\) និង \(B(1, 0)\) (រង្វង់អាប៉ូឡូនីញ៉ុស)។

មើលដំណោះស្រាយ

រកសំណុំចំណុច \(M(x, y)\) ដែលផ្ទៀងផ្ទាត់ \(\dfrac{MA}{MB} = 2\) ៖
គេមាន \(A(-2, 0)\) និង \(B(1, 0)\) ៖
\(\dfrac{MA}{MB} = 2 \iff MA = 2MB \iff MA^2 = 4MB^2\)
\((x + 2)^2 + y^2 = 4[(x - 1)^2 + y^2]\)
\(\iff x^2 + 4x + 4 + y^2 = 4(x^2 - 2x + 1 + y^2)\)
\(\iff x^2 + 4x + 4 + y^2 = 4x^2 - 8x + 4 + 4y^2\)
\(\iff 3x^2 + 3y^2 - 12x = 0\)
ចែកនឹង \(3\) ៖
\(x^2 - 4x + y^2 = 0 \iff (x - 2)^2 + y^2 = 4\)។
ដូចនេះ សំណុំចំណុច \(M\) គឺជារង្វង់អាប៉ូឡូនីញ៉ុស ដែលមានផ្ចិត \(I(2, 0)\) និងកាំ \(R = 2\)។

៣៣លំហាត់ទី ៣៣

រកកូអរដោនេនៃចំណុចឆ្លុះនៃ \(A(3, 4)\) ធៀបនឹង ៖

  1. អ័ក្សអាប់ស៊ីស (\(Ox\))

  2. អ័ក្សអរដោនេ (\(Oy\))

  3. គល់កូអរដោនេ \(O(0, 0)\)

  4. បន្ទាត់ពុះមុំទីមួយ \(y = x\)

មើលដំណោះស្រាយ

រកកូអរដោនេចំណុចឆ្លុះនៃ \(A(3, 4)\) ៖
ក.  ធៀបនឹងអ័ក្ស \(Ox\) ៖ រក្សា \(x\) ដូរសញ្ញា \(y\)
\(\implies A_1(3, -4)\)
ខ.  ធៀបនឹងអ័ក្ស \(Oy\) ៖ ដូរសញ្ញា \(x\) រក្សា \(y\)
\(\implies A_2(-3, 4)\)
គ.  ធៀបនឹងគល់កូអរដោនេ \(O(0, 0)\) ៖ ដូរសញ្ញាទាំងពីរ
\(\implies A_3(-3, -4)\)
ឃ.  ធៀបនឹងបន្ទាត់ \(y = x\) ៖ ត្រឡប់កូអរដោនេ \((x, y) \to (y, x)\)
\(\implies A_4(4, 3)\)

៣៤លំហាត់ទី ៣៤

រកកូអរដោនេនៃចំណុចឆ្លុះនៃ \(P(2, 5)\) ធៀបនឹងចំណុច \(I(1, 2)\)។

មើលដំណោះស្រាយ

រកចំណុចឆ្លុះ \(P'(x', y')\) នៃ \(P(2, 5)\) ធៀបនឹងចំណុច \(I(1, 2)\) ៖
\(I\) គឺជាចំណុចកណ្តាលនៃអង្កត់ \(PP'\) ៖
\(x_I = \dfrac{x_P + x'}{2} \iff x' = 2x_I - x_P = 2(1) - 2 = 0\)
\(y_I = \dfrac{y_P + y'}{2} \iff y' = 2y_I - y_P = 2(2) - 5 = -1\)
ដូចនេះ ចំណុចឆ្លុះគឺ \(P'(0, -1)\)។

៣៥លំហាត់ទី ៣៥

ពិនិត្យថាតើចំណុច \(A(3, 0)\), \(B(6, 4)\) និង \(C(-1, 3)\) បង្កើតបានជាត្រីកោណប្រភេទអ្វី។

មើលដំណោះស្រាយ

ពិនិត្យប្រភេទត្រីកោណ \(ABC\) ដែល \(A(3, 0)\), \(B(6, 4)\), \(C(-1, 3)\) ៖
គណនាការ៉េនៃប្រវែងជ្រុងទាំងបី ៖
\(AB^2 = (6 - 3)^2 + (4 - 0)^2 = 3^2 + 4^2 = 9 + 16 = 25\)
\(AC^2 = (-1 - 3)^2 + (3 - 0)^2 = (-4)^2 + 3^2 = 16 + 9 = 25\)
\(BC^2 = (-1 - 6)^2 + (3 - 4)^2 = (-7)^2 + (-1)^2 = 49 + 1 = 50\)
យើងឃើញថា ៖

  1. \(AB^2 = AC^2 = 25 \implies AB = AC = 5\) (ត្រីកោណសមបាតត្រង់ \(A\))

  2. \(AB^2 + AC^2 = 25 + 25 = 50 = BC^2\) (ត្រីកោណកែងត្រង់ \(A\))

ដូចនេះ \(\triangle ABC\) គឺជា ត្រីកោណកែងសមបាតត្រង់កំពូល \(A\)។

៣៦លំហាត់ទី ៣៦

គណនាបរិមាត្រនៃត្រីកោណ \(ABC\) ដែល \(A(1, 1)\), \(B(4, 5)\) និង \(C(1, 5)\)។

មើលដំណោះស្រាយ

គណនាបរិមាត្រនៃត្រីកោណ \(ABC\) ដែល \(A(1, 1)\), \(B(4, 5)\), \(C(1, 5)\) ៖
គណនាប្រវែងជ្រុងនីមួយៗ ៖
\(AB = \sqrt{(4 - 1)^2 + (5 - 1)^2} = \sqrt{3^2 + 4^2} = 5\)
\(BC = \sqrt{(1 - 4)^2 + (5 - 5)^2} = \sqrt{(-3)^2 + 0} = 3\)
\(AC = \sqrt{(1 - 1)^2 + (5 - 1)^2} = \sqrt{0 + 4^2} = 4\)
បរិមាត្រត្រីកោណ ៖
\(P = AB + BC + AC = 5 + 3 + 4 = 12\) ឯកតាប្រវែង។

៣៧លំហាត់ទី ៣៧

គណនាកាំរង្វង់ចារឹកក្រៅត្រីកោណកែង \(A(0, 0)\), \(B(8, 0)\) និង \(C(0, 6)\)។

មើលដំណោះស្រាយ

គណនាកាំរង្វង់ចារឹកក្រៅត្រីកោណកែង \(A(0, 0)\), \(B(8, 0)\) និង \(C(0, 6)\) ៖
ត្រីកោណកែងត្រង់កំពូល \(A(0, 0)\) ព្រោះ \(AB\) នៅលើ \(Ox\) និង \(AC\) នៅលើ \(Oy\)។
ប្រវែងអ៊ីប៉ូតេនុស \(BC\) ៖
\(BC = \sqrt{(8 - 0)^2 + (0 - 6)^2} = \sqrt{64 + 36} = \sqrt{100} = 10\)
ក្នុងត្រីកោណកែង កាំរង្វង់ចារឹកក្រៅស្មើនឹងពាក់កណ្តាលអ៊ីប៉ូតេនុស ៖
\(R = \dfrac{BC}{2} = \dfrac{10}{2} = 5\) ឯកតាប្រវែង។

៣៨លំហាត់ទី ៣៨

គេឱ្យចំណុច \(A(2, -3)\) និង \(B(-4, 5)\)។ រកចំណុចប្រសព្វនៃអង្កត់ \(AB\) ជាមួយអ័ក្ស \(Ox\) និងអ័ក្ស \(Oy\)។

មើលដំណោះស្រាយ

រកចំណុចប្រសព្វនៃអង្កត់ \(AB\) ជាមួយអ័ក្ស \(Ox\) និង \(Oy\) ៖
គេមាន \(A(2, -3)\) និង \(B(-4, 5)\)។
សមីការបន្ទាត់ \(AB\) ៖
មេគុណប្រាប់ទិស ៖ \(m = \dfrac{5 - (-3)}{-4 - 2} = \dfrac{8}{-6} = -\dfrac{4}{3}\)
សមីការ ៖ \(y - (-3) = -\dfrac{4}{3}(x - 2) \iff y = -\dfrac{4}{3}x - \dfrac{1}{3}\)
- ប្រសព្វជាមួយអ័ក្ស \(Ox\) (\(y = 0\)) ៖
\(0 = -\dfrac{4}{3}x - \dfrac{1}{3} \iff 4x = -1 \iff x = -\dfrac{1}{4}\)
ចំណុចប្រសព្វគឺ \(I_x\left(-\dfrac{1}{4}, 0\right)\) (ស្ថិតនៅលើអង្កត់ \(AB\) ព្រោះ \(-\dfrac{1}{4} \in [-4, 2]\))។
- ប្រសព្វជាមួយអ័ក្ស \(Oy\) (\(x = 0\)) ៖
\(y = -\dfrac{1}{3} \implies I_y\left(0, -\dfrac{1}{3}\right)\) (ស្ថិតនៅលើអង្កត់ \(AB\) ព្រោះ \(-\dfrac{1}{3} \in [-3, 5]\))។

៣៩លំហាត់ទី ៣៩

រកកូអរដោនេនៃកំពូលទាំងបីនៃត្រីកោណ \(ABC\) ដោយដឹងថាចំណុចកណ្តាលនៃជ្រុងទាំងបីគឺ \(M(1, 2)\), \(N(3, 4)\) និង \(P(2, 6)\)។

មើលដំណោះស្រាយ

រកកំពូលនៃ \(\triangle ABC\) ដោយស្គាល់ចំណុចកណ្តាល \(M(1, 2), N(3, 4), P(2, 6)\) ៖
តាង \(M\) ជាចំណុចកណ្តាល \(AB\), \(N\) ជាចំណុចកណ្តាល \(BC\), \(P\) ជាចំណុចកណ្តាល \(AC\) ៖
\(\begin{cases} x_A + x_B = 2(1) = 2 \\ x_B + x_C = 2(3) = 6 \\ x_A + x_C = 2(2) = 4 \end{cases} \implies 2(x_A + x_B + x_C) = 12 \iff x_A + x_B + x_C = 6\)
- \(x_A = 6 - (x_B + x_C) = 6 - 6 = 0\)
- \(x_B = 6 - (x_A + x_C) = 6 - 4 = 2\)
- \(x_C = 6 - (x_A + x_B) = 6 - 2 = 4\)
ចំពោះអរដោនេ ៖
\(\begin{cases} y_A + y_B = 2(2) = 4 \\ y_B + y_C = 2(4) = 8 \\ y_A + y_C = 2(6) = 12 \end{cases} \implies 2(y_A + y_B + y_C) = 24 \iff y_A + y_B + y_C = 12\)
- \(y_A = 12 - 8 = 4\)
- \(y_B = 12 - 12 = 0\)
- \(y_C = 12 - 4 = 8\)
ដូចនេះ កំពូលទាំងបីគឺ \(A(0, 4)\), \(B(2, 0)\) និង \(C(4, 8)\)។

៤០លំហាត់ទី ៤០

បង្ហាញថាអង្កត់ទ្រូងទាំងពីរនៃចតុកោណកែង \(A(0, 0)\), \(B(a, 0)\), \(C(a, b)\) និង \(D(0, b)\) មានប្រវែងស្មើគ្នា។

មើលដំណោះស្រាយ

បង្ហាញថាអង្កត់ទ្រូងទាំងពីរនៃចតុកោណកែងស្មើគ្នា ៖
ចតុកោណកែងមានកំពូល \(A(0, 0)\), \(B(a, 0)\), \(C(a, b)\) និង \(D(0, b)\)។
គណនាប្រវែងអង្កត់ទ្រូងទាំងពីរ ៖
\(AC = \sqrt{(a - 0)^2 + (b - 0)^2} = \sqrt{a^2 + b^2}\)
\(BD = \sqrt{(0 - a)^2 + (b - 0)^2} = \sqrt{(-a)^2 + b^2} = \sqrt{a^2 + b^2}\)
ដោយ \(AC = BD = \sqrt{a^2 + b^2}\) នាំឱ្យអង្កត់ទ្រូងទាំងពីរមានប្រវែងស្មើគ្នាជានិច្ច។

៤១លំហាត់ទី ៤១

បង្ហាញតាមវិធីវិភាគកូអរដោនេថា ចំណុចកណ្តាលនៃអ៊ីប៉ូតេនុសក្នុងត្រីកោណកែងនៅស្មើចម្ងាយពីកំពូលទាំងបី។

មើលដំណោះស្រាយ

បង្ហាញថាចំណុចកណ្តាលនៃអ៊ីប៉ូតេនុសក្នុងត្រីកោណកែងនៅស្មើចម្ងាយពីកំពូលទាំងបី ៖
ជ្រើសរើសតម្រុយអរតូណរម៉េដែលមានគល់ \(O(0, 0)\) ត្រង់មុំកែង។
កំពូលទាំងបីគឺ \(O(0, 0)\), \(A(2a, 0)\) លើ \(Ox\) និង \(B(0, 2b)\) លើ \(Oy\)។
អ៊ីប៉ូតេនុសគឺ \(AB\) ដែលមានចំណុចកណ្តាល ៖
\(M\left(\dfrac{2a + 0}{2}, \dfrac{0 + 2b}{2}\right) = M(a, b)\)
គណនាចម្ងាយពី \(M\) ទៅកំពូលទាំងបី ៖
\(MO = \sqrt{(a - 0)^2 + (b - 0)^2} = \sqrt{a^2 + b^2}\)
\(MA = \sqrt{(a - 2a)^2 + (b - 0)^2} = \sqrt{(-a)^2 + b^2} = \sqrt{a^2 + b^2}\)
\(MB = \sqrt{(a - 0)^2 + (b - 2b)^2} = \sqrt{a^2 + (-b)^2} = \sqrt{a^2 + b^2}\)
ដូចនេះ \(MO = MA = MB = \sqrt{a^2 + b^2}\) ពិតប្រាកដមែន។

៤២លំហាត់ទី ៤២

បង្ហាញថាអង្កត់តភ្ជាប់ចំណុចកណ្តាលនៃជ្រុងពីរនៃត្រីកោណស្របនឹងជ្រុងទីបី និងមានប្រវែងស្មើពាក់កណ្តាលជ្រុងទីបីនោះ។

មើលដំណោះស្រាយ

បង្ហាញលក្ខណៈនៃអង្កត់មធ្យមនៃត្រីកោណ ៖
តាងកំពូលនៃត្រីកោណជា \(A(x_1, y_1)\), \(B(x_2, y_2)\) និង \(C(x_3, y_3)\)។
តាង \(M\) ជាចំណុចកណ្តាលនៃ \(AB\) និង \(N\) ជាចំណុចកណ្តាលនៃ \(AC\) ៖
\(M\left(\dfrac{x_1 + x_2}{2}, \dfrac{y_1 + y_2}{2}\right), \quad{} N\left(\dfrac{x_1 + x_3}{2}, \dfrac{y_1 + y_3}{2}\right)\)
វ៉ិចទ័រ \(\vec{MN}\) និង \(\vec{BC}\) ៖
\(\vec{MN} = \left(\dfrac{x_1 + x_3}{2} - \dfrac{x_1 + x_2}{2}, \dfrac{y_1 + y_3}{2} - \dfrac{y_1 + y_2}{2}\right) = \left(\dfrac{x_3 - x_2}{2}, \dfrac{y_3 - y_2}{2}\right)\)
\(\vec{BC} = (x_3 - x_2, y_3 - y_2)\)
នាំឱ្យ \(\vec{MN} = \dfrac{1}{2}\vec{BC}\)។
ទំនាក់ទំនងវ៉ិចទ័រនេះបង្ហាញថា ៖

  1. បន្ទាត់ \(MN\) ស្របនឹងបន្ទាត់ \(BC\) (\(MN \parallel BC\))

  2. ប្រវែង \(MN = \dfrac{1}{2}BC\)។

៤៣លំហាត់ទី ៤៣

បង្ហាញថាចតុកោណដែលកើតឡើងពីការភ្ជាប់ចំណុចកណ្តាលនៃជ្រុងទាំងបួននៃចតុកោណមួយ តែងតែជាប្រលេឡូក្រាមជានិច្ច (ទ្រឹស្តីបទវ៉ារីញ៉ុង Varignon’s Theorem)។

មើលដំណោះស្រាយ

បង្ហាញទ្រឹស្តីបទវ៉ារីញ៉ុង (Varignon’s Theorem) ៖
ពិនិត្យចតុកោណទូទៅ \(ABCD\) ដែលមាន \(P, Q, R, S\) ជាចំណុចកណ្តាលនៃជ្រុង \(AB, BC, CD, DA\) រៀងគ្នា។
គូសអង្កត់ទ្រូង \(AC\) ៖
- ក្នុង \(\triangle ABC\) ចំណុច \(P, Q\) ជាចំណុចកណ្តាលនៃ \(AB, BC\) នាំឱ្យ \(PQ\) ជាអង្កត់មធ្យម ៖
\(\vec{PQ} = \dfrac{1}{2}\vec{AC}\)
- ក្នុង \(\triangle ADC\) ចំណុច \(S, R\) ជាចំណុចកណ្តាលនៃ \(DA, CD\) នាំឱ្យ \(SR\) ជាអង្កត់មធ្យម ៖
\(\vec{SR} = \dfrac{1}{2}\vec{AC}\)
ទាញបាន \(\vec{PQ} = \vec{SR}\) នាំឱ្យជ្រុងឈម \(PQ\) និង \(SR\) ស្របគ្នា និងមានប្រវែងស្មើគ្នា។
ដូចនេះ ចតុកោណ \(PQRS\) គឺជាប្រលេឡូក្រាមជានិច្ច។

៤៤លំហាត់ទី ៤៤

បង្ហាញទ្រឹស្តីបទអាប៉ូឡូនីញ៉ុស ៖ ក្នុងត្រីកោណ \(ABC\) បើ \(M\) ជាចំណុចកណ្តាលនៃ \(BC\) នោះ \(AB^2 + AC^2 = 2AM^2 + \dfrac{BC^2}{2}\)។

មើលដំណោះស្រាយ

បង្ហាញទ្រឹស្តីបទអាប៉ូឡូនីញ៉ុស ៖ \(AB^2 + AC^2 = 2AM^2 + \dfrac{BC^2}{2}\)
ជ្រើសរើសតម្រុយអរតូណរម៉េដែលមានគល់ \(O(0, 0) \equiv M\) (ចំណុចកណ្តាលនៃ \(BC\)) ហើយអ័ក្ស \(Ox\) ស្របតាមបន្ទាត់ \(BC\)។
តាងកូអរដោនេ ៖
\(B(-c, 0)\) និង \(C(c, 0)\) នាំឱ្យ \(BC = 2c \implies BC^2 = 4c^2\)
តាង \(A(x, y)\) ជាកំពូលទីបី ៖
- \(AM^2 = x^2 + y^2\)
- \(AB^2 = (x + c)^2 + y^2 = x^2 + 2cx + c^2 + y^2\)
- \(AC^2 = (x - c)^2 + y^2 = x^2 - 2cx + c^2 + y^2\)
បូកអង្គនិងអង្គ ៖
\(AB^2 + AC^2 = (x^2 + 2cx + c^2 + y^2) + (x^2 - 2cx + c^2 + y^2)\)
\(= 2(x^2 + y^2) + 2c^2\)
ដោយ \(x^2 + y^2 = AM^2\) និង \(2c^2 = \dfrac{4c^2}{2} = \dfrac{BC^2}{2}\) ៖
\(AB^2 + AC^2 = 2AM^2 + \dfrac{BC^2}{2}\) (ពិតប្រាកដមែន)។

៤៥លំហាត់ទី ៤៥

រកផ្ទៃក្រឡានៃពហុកោណដែលមានកំពូល \(A(1, 2)\), \(B(3, 1)\), \(C(5, 4)\), \(D(4, 7)\) និង \(E(2, 6)\) (ក្បួនចងខ្សែស្បែកជើង Shoelace Formula)។

មើលដំណោះស្រាយ

រកផ្ទៃក្រឡាពហុកោណ \(ABCDE\) តាមក្បួនចងខ្សែស្បែកជើង (Shoelace Formula) ៖
កំពូលរៀបតាមលំដាប់ ៖ \(A(1, 2) \to B(3, 1) \to C(5, 4) \to D(4, 7) \to E(2, 6) \to A(1, 2)\)
ផលបូកអង្កត់ទ្រូងចុះ ៖
\(\Sigma_{\downarrow} = 1(1) + 3(4) + 5(7) + 4(6) + 2(2) = 1 + 12 + 35 + 24 + 4 = 76\)
ផលបូកអង្កត់ទ្រូងឡើង ៖
\(\Sigma_{\uparrow} = 2(3) + 1(5) + 4(4) + 7(2) + 6(1) = 6 + 5 + 16 + 14 + 6 = 47\)
ផ្ទៃក្រឡា ៖
\(S = \dfrac{1}{2} |\Sigma_{\downarrow} - \Sigma_{\uparrow}| = \dfrac{1}{2} |76 - 47| = \dfrac{29}{2} = 14.5\) ឯកតាផ្ទៃ។

លំហាត់ PISA - ប្រព័ន្ធកំណត់ទីតាំងសកល (GPS) ៖ អ្នកឡើងភ្នំម្នាក់ទទួលសញ្ញាពីស្ថានីយ A\((0, 0)\text{ km}\) និង B\((6, 0)\text{ km}\)។ បើនៅចម្ងាយ \(5\text{ km}\) ពី A និង \(5\text{ km}\) ពី B រកទីតាំងអ្នកឡើងភ្នំ (\(y > 0\)) រួចគណនាចម្ងាយកាត់ទៅកាន់ទីតាំងសង្គ្រោះ \(C(3, 8)\text{ km}\)។

មើលដំណោះស្រាយ

លំហាត់ PISA - ប្រព័ន្ធកំណត់ទីតាំងសកល (GPS) ៖
តាងទីតាំងអ្នកឡើងភ្នំជា \(H(x, y)\) ដោយ \(y > 0\)។
ស្ថានីយ \(A(0, 0)\) និង \(B(6, 0)\) គិតជា \(\text{km}\)។
ចម្ងាយ \(HA = 5\text{ km} \implies x^2 + y^2 = 25 \quad{} (1)\)
ចម្ងាយ \(HB = 5\text{ km} \implies (x - 6)^2 + y^2 = 25 \quad{} (2)\)
ដក \((2)\) ចេញពី \((1)\) ៖
\(x^2 - (x - 6)^2 = 0 \iff 12x - 36 = 0 \iff x = 3\)
ជំនួស \(x = 3\) ចូល \((1)\) ៖
\(3^2 + y^2 = 25 \iff y^2 = 16 \implies y = 4\) (ព្រោះ \(y > 0\))
ដូចនេះ ទីតាំងអ្នកឡើងភ្នំគឺ \(H(3, 4)\text{ km}\)។
គណនាចម្ងាយកាត់ទៅទីតាំងសង្គ្រោះ \(C(3, 8)\text{ km}\) ៖
\(HC = \sqrt{(3 - 3)^2 + (8 - 4)^2} = \sqrt{0 + 4^2} = 4\text{ km}\)។

៤៧លំហាត់ទី ៤៧

លំហាត់ PISA - ប្លង់បណ្តាញផ្លូវក្រុងភ្នំពេញ ៖ មន្ទីរពេទ្យស្ថិតនៅ \(H(2, 3)\) និងសាលារៀននៅ \(S(8, 11)\) (គិតជា \(\text{km}\))។ គណនាចម្ងាយផ្លូវកាត់ត្រង់ (ចម្ងាយអឺគ្លីដ) \(HS\) និងគណនាប្រវែងផ្លូវកែងតាមអ័ក្ស (ចម្ងាយ Manhattan)។

មើលដំណោះស្រាយ

លំហាត់ PISA - ប្លង់បណ្តាញផ្លូវក្រុងភ្នំពេញ ៖
មន្ទីរពេទ្យ \(H(2, 3)\) និងសាលារៀន \(S(8, 11)\) គិតជា \(\text{km}\) ៖
- ចម្ងាយផ្លូវកាត់ត្រង់ (ចម្ងាយអឺគ្លីដ) ៖
\(d_E = \sqrt{(8 - 2)^2 + (11 - 3)^2} = \sqrt{6^2 + 8^2} = \sqrt{36 + 64} = \sqrt{100} = 10\text{ km}\)។
- ប្រវែងផ្លូវកែងតាមបណ្តាញក្រឡាអ័ក្ស (ចម្ងាយ Manhattan) ៖
\(d_M = |x_S - x_H| + |y_S - y_H| = |8 - 2| + |11 - 3| = 6 + 8 = 14\text{ km}\)។

៤៨លំហាត់ទី ៤៨

លំហាត់ PISA - គន្លងហោះហើរដ្រូនកសិកម្ម ៖ ដ្រូនហោះពី \(O(0, 0)\text{ m}\) ទៅ \(A(300, 400)\text{ m}\) រួចបន្តទៅ \(B(700, 700)\text{ m}\)។ គណនាប្រវែងជើងហោះហើរ \(OA\), \(AB\) និងចម្ងាយផ្លូវកាត់ពី \(B\) មកស្ថានីយ \(O\) វិញ។

មើលដំណោះស្រាយ

លំហាត់ PISA - គន្លងហោះហើរដ្រូនកសិកម្ម ៖
\(O(0, 0)\text{ m} \to A(300, 400)\text{ m} \to B(700, 700)\text{ m}\) ៖
- ជើងហោះហើរទី ១ (\(OA\)) ៖
\(OA = \sqrt{300^2 + 400^2} = \sqrt{90000 + 160000} = \sqrt{250000} = 500\text{ m}\)។
- ជើងហោះហើរទី ២ (\(AB\)) ៖
\(AB = \sqrt{(700 - 300)^2 + (700 - 400)^2} = \sqrt{400^2 + 300^2} = 500\text{ m}\)។
- ចម្ងាយផ្លូវកាត់ត្រង់ត្រឡប់ពី \(B\) មកស្ថានីយ \(O\) វិញ ៖
\(BO = \sqrt{700^2 + 700^2} = 700\sqrt{2} \approx 989.95\text{ m}\)។

៤៩លំហាត់ទី ៤៩

លំហាត់ PISA - តំបន់គ្របដណ្តប់នៃអង់តែនទូរស័ព្ទ ៖ អង់តែន 4G នៅចំណុច \(T(2, 3)\) មានកាំគ្របដណ្តប់ \(R = 5\text{ km}\)។ ពិនិត្យថាតើចំណុច \(A(5, 7)\) និង \(B(6, 6)\) ចាប់សញ្ញាបានដែរឬទេ?

មើលដំណោះស្រាយ

លំហាត់ PISA - តំបន់គ្របដណ្តប់នៃអង់តែនទូរស័ព្ទ ៖
អង់តែននៅ \(T(2, 3)\) មានកាំគ្របដណ្តប់ \(R = 5\text{ km}\)។
ចំណុចមួយចាប់សញ្ញាបានកាលណា \(d \le R = 5\text{ km}\) ៖
- ចំពោះចំណុច \(A(5, 7)\) ៖
\(TA = \sqrt{(5 - 2)^2 + (7 - 3)^2} = \sqrt{3^2 + 4^2} = \sqrt{25} = 5\text{ km}\)
ដោយ \(TA = 5 \le 5\) នាំឱ្យទីតាំង \(A\) ស្ថិតនៅលើបន្ទាត់ព្រំដែនគ្របដណ្តប់ ពោលគឺ ចាប់សញ្ញាបាន។
- ចំពោះចំណុច \(B(6, 6)\) ៖
\(TB = \sqrt{(6 - 2)^2 + (6 - 3)^2} = \sqrt{4^2 + 3^2} = \sqrt{16 + 9} = \sqrt{25} = 5\text{ km}\)
ដោយ \(TB = 5 \le 5\) នាំឱ្យទីតាំង \(B\) ស្ថិតនៅលើព្រំដែនគ្របដណ្តប់ ពោលគឺ ចាប់សញ្ញាបាន ដូចគ្នា។

៥០លំហាត់ទី ៥០

លំហាត់ PISA - ការតម្រង់ទិសនាវាចរណ៍កំពង់ផែ ៖ ភ្លើងហ្វារពីរនៅ \(L_1(0, 0)\) និង \(L_2(10, 0)\) ម៉ាយល៍។ កប៉ាល់រក្សាចម្ងាយស្មើគ្នាពីភ្លើងហ្វារទាំងពីរ។ រកសមីការនៃគន្លងធ្វើដំណើររបស់កប៉ាល់ និងបើ \(y = 12\) ម៉ាយល៍ គណនាចម្ងាយពីកប៉ាល់ទៅភ្លើងហ្វារនីមួយៗ។

មើលដំណោះស្រាយ

លំហាត់ PISA - ការតម្រង់ទិសនាវាចរណ៍កំពង់ផែ ៖
ភ្លើងហ្វារ \(L_1(0, 0)\) និង \(L_2(10, 0)\) គិតជាម៉ាយល៍។
កប៉ាល់ \(S(x, y)\) រក្សាចម្ងាយស្មើគ្នាពីភ្លើងហ្វារទាំងពីរ (\(SL_1 = SL_2 \iff SL_1^2 = SL_2^2\)) ៖
\((x - 0)^2 + (y - 0)^2 = (x - 10)^2 + (y - 0)^2\)
\(\iff x^2 = x^2 - 20x + 100 \iff 20x = 100 \iff x = 5\)
ដូចនេះ សមីការគន្លងធ្វើដំណើររបស់កប៉ាល់គឺបន្ទាត់ឈរ \(x = 5\) (ជាមេដ្យាទ័រនៃ \(L_1 L_2\))។
នៅពេល \(y = 12\) ម៉ាយល៍ ទីតាំងកប៉ាល់គឺ \(S(5, 12)\) ៖
ចម្ងាយពីកប៉ាល់ទៅភ្លើងហ្វារនីមួយៗគឺ ៖
\(d = SL_1 = \sqrt{5^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169} = 13\) ម៉ាយល៍។
