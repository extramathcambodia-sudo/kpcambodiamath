មេរៀនទាំងអស់
ប្រវត្តិនៃរង្វង់ និងការស្រាវជ្រាវរបស់ Apollonius

រង្វង់ (Circle) គឺជារាងធរណីមាត្រដ៏ល្អឥតខ្ចោះបំផុតក្នុងធម្មជាតិ និងវិទ្យាសាស្ត្រ ៖

  • លោក Apollonius of Perga (២៦២-១៩០ មុន គ.ស.) ៖ គណិតវិទូក្រិកបុរាណដែលទទួលបានរហស្សនាមថា «មហាធរណីមាត្រវិទូ» (The Great Geometer)។ គាត់បានសិក្សាយ៉ាងស៊ីជម្រៅអំពីលក្ខណៈនៃបន្ទាត់ប៉ះរង្វង់ និងបានចោទជាបញ្ហាប្រវត្តិសាស្ត្រ «បញ្ហារបស់ Apollonius» ៖ សង់រង្វង់ដែលប៉ះនឹងរង្វង់បីផ្សេងទៀត។

  • លោក Archimedes (២៨៧-២១២ មុន គ.ស.) ៖ បានប្រើប្រាស់ពហុកោណចារឹកក្នុង និងចារឹកក្រៅរង្វង់ដើម្បីគណនាតម្លៃ \(\pi\) ដោយភាពសុក្រឹតអស្ចារ្យ ៖ \(3\frac{10}{71} < \pi < 3\frac{1}{7}\)។

  • ការអនុវត្តក្នុងវិស្វកម្មគ្រឿងយន្ត ៖ គោលការណ៍នៃបន្ទាត់ប៉ះរួមរវាងរង្វង់ពីរ គឺជាមូលដ្ឋានគ្រឹះក្នុងការរចនាប្រព័ន្ធខ្សែពានយន្តការ (Belt Drives) និងប្រព័ន្ធធ្មេញប្រអប់លេខ (Gears) ក្នុងម៉ាស៊ីនឧស្សាហកម្ម។

លក្ខណៈនៃអង្កត់ធ្នូ និងផ្ចិតរង្វង់

បន្ទាត់កែងពីផ្ចិតទៅកាន់អង្កត់ធ្នូ

ក្នុងរង្វង់មួយ ៖

  1. បន្ទាត់គូសចេញពីផ្ចិតហើយកែងនឹងអង្កត់ធ្នូ តែងតែកាត់តាមចំណុចកណ្តាលនៃអង្កត់ធ្នូនោះ (\(OM \perp AB \implies AM = MB\))។

  2. មេដ្យាទ័រនៃអង្កត់ធ្នូណាមួយ តែងតែកាត់តាមផ្ចិតនៃរង្វង់។

  3. អង្កត់ធ្នូពីរមានប្រវែងស្មើគ្នា លុះត្រាតែវាមានចម្ងាយស្មើគ្នាពីផ្ចិត (\(AB = CD \iff d(O, AB) = d(O, CD)\))។

ឧទាហរណ៍

រង្វង់ផ្ចិត \(O\) មានកាំ \(R = 5\,\text{cm}\)។ អង្កត់ធ្នូ \(AB = 8\,\text{cm}\)។ គណនាចម្ងាយពីផ្ចិត \(O\) ទៅកាន់អង្កត់ធ្នូ \(AB\)។

ដំណោះស្រាយ

តាង \(H\) ជាចំណុចកណ្តាលនៃ \(AB\) នាំឱ្យ \(OH \perp AB\) និង \(AH = \dfrac{8}{2} = 4\,\text{cm}\)។ ក្នុងត្រីកោណកែង \(OHA\) តាមទ្រឹស្តីបទពីតាគ័រ ៖

\[OH = \sqrt{OA^2 - AH^2} = \sqrt{5^2 - 4^2} = \sqrt{25 - 16} = \sqrt{9} = 3\,\text{cm}\]

ប្រតិបត្តិ

រង្វង់ផ្ចិត \(O\) កាំ \(R = 10\,\text{cm}\)។ អង្កត់ធ្នូមួយនៅចម្ងាយ \(6\,\text{cm}\) ពីផ្ចិត។ គណនាប្រវែងអង្កត់ធ្នូនោះ។

បន្ទាត់ប៉ះនឹងរង្វង់ (Tangents to a Circle)

លក្ខណៈនៃបន្ទាត់ប៉ះ

  1. បន្ទាត់ប៉ះរង្វង់ត្រង់ចំណុច \(A\) តែងតែកែងនឹងកាំ \(OA\) ត្រង់ចំណុចប៉ះ ៖ \(d \perp OA\)។

  2. ពីចំណុច \(P\) នៅក្រៅរង្វង់ គេអាចគូសបន្ទាត់ប៉ះបានពីរ \(PA\) និង \(PB\) ទៅកាន់រង្វង់ ដែលផ្ទៀងផ្ទាត់ ៖

    \[PA = PB\]
    ហើយបន្ទាត់ \(PO\) ជាកន្លះបន្ទាត់ពុះមុំ \(\angle APB\) និង \(\angle AOB\) ព្រមទាំងជាមេដ្យាទ័រនៃអង្កត់ \([AB]\)។

ឧទាហរណ៍

ពីចំណុច \(P\) នៅចម្ងាយ \(13\,\text{cm}\) ពីផ្ចិតនៃរង្វង់កាំ \(5\,\text{cm}\) គេគូសបន្ទាត់ប៉ះ \(PA\)។ គណនាប្រវែង \(PA\)។

ដំណោះស្រាយ

ដោយ \(OA \perp PA\) នោះ \(\Delta OAP\) ជាត្រីកោណកែងត្រង់ \(A\)។

\[PA = \sqrt{OP^2 - OA^2} = \sqrt{13^2 - 5^2} = \sqrt{169 - 25} = \sqrt{144} = 12\,\text{cm}\]

ប្រតិបត្តិ

ពីចំណុច \(P\) ក្រៅរង្វង់ គូសបន្ទាត់ប៉ះពីរ \(PA\) និង \(PB\)។ បើមុំរវាងបន្ទាត់ប៉ះទាំងពីរស្មើ \(60^\circ\) និងកាំ \(R = 6\,\text{cm}\) ចូរគណនាប្រវែង \(OP\)។

ទីតាំងធៀបនៃរង្វង់ពីរ និងបន្ទាត់ប៉ះរួម

ទីតាំងធៀបនៃរង្វង់ពីរ \((O, R)\) និង \((O', r)\) (\(R \ge r\), \(d = OO'\))

  • នៅក្រៅគ្នា ៖ \(d > R + r\) (មានបន្ទាត់ប៉ះរួម ៤)

  • ប៉ះក្រៅ ៖ \(d = R + r\) (មានបន្ទាត់ប៉ះរួម ៣)

  • កាត់គ្នា ៖ \(R - r < d < R + r\) (មានបន្ទាត់ប៉ះរួម ២)

  • ប៉ះក្នុង ៖ \(d = R - r\) (មានបន្ទាត់ប៉ះរួម ១)

  • នៅខាងក្នុងគ្នា ៖ \(d < R - r\) (គ្មានបន្ទាត់ប៉ះរួម)

លំហាត់អនុវត្តន៍

១លំហាត់ទី ១

គេមានរង្វង់ផ្ចិត \(O\) និងអង្កត់ធ្នូ \(AB = 10\,\text{cm}\)។ បើ \(OC \perp AB\) គណនាប្រវែង \(AC\)។

មើលដំណោះស្រាយ

គណនាប្រវែង \(AC\) ៖ ដោយ \(OC \perp AB\) ត្រង់ \(C\) នាំឱ្យ \(C\) ជាចំណុចកណ្តាលនៃ \(AB\)។ ដូចនេះ \(AC = \frac{AB}{2} = \frac{10}{2} = 5\,\text{cm}\)។

២លំហាត់ទី ២

គេមានរង្វង់ផ្ចិត \(O\) និងអង្កត់ធ្នូ \(AB\) ដែលមាន \(C\) ជាចំណុចកណ្តាល។ បើ \(AC = 6\,\text{cm}\) គណនា \(AB\)។

មើលដំណោះស្រាយ

គណនាប្រវែង \(AB\) ៖ តាមរូប \(C\) ជាចំណុចកណ្តាល និង \(AC = 6\,\text{cm}\) នាំឱ្យ \(AB = 2 \times AC = 12\,\text{cm}\)។

៣លំហាត់ទី ៣

ក្នុងរង្វង់ផ្ចិត \(O\) គេមាន \(\angle OXY = 30^\circ, \angle XOY = 60^\circ\) និងអង្កត់ផ្ចិត \(XZ = 32\,\text{cm}\)។ រករង្វាស់ \(XY\)។

មើលដំណោះស្រាយ

គណនារង្វាស់ \(XY\) ៖ ក្នុង \(\Delta OXY\) មាន \(\angle OXY = 30^\circ, \angle XOY = 60^\circ \implies \angle OYX = 90^\circ\) (ត្រីកោណកែងត្រង់ \(Y\))។ ដោយ \(XZ = 32\,\text{cm}\) ជាអង្កត់ផ្ចិត នាំឱ្យកាំ \(OX = 16\,\text{cm}\)។ ក្នុងត្រីកោណកែង \(OYX\) ជ្រុង \(XY = OX \cos 30^\circ = 16 \times \frac{\sqrt{3}}{2} = 8\sqrt{3}\,\text{cm}\)។

៤លំហាត់ទី ៤

គេមាន \(AB = 25\,\text{cm}\) ជាអង្កត់ផ្ចិត និងចំណុច \(C\) លើរង្វង់។ បើ \(BC = 15\,\text{cm}\) គណនាប្រវែង \(AC\)។

មើលដំណោះស្រាយ

គណនាប្រវែង \(AC\) និង \(BC\) ៖ \(AB = 25\,\text{cm}\) ជាអង្កត់ផ្ចិត នាំឱ្យ \(\angle ACB = 90^\circ\) (មុំចារឹកក្នុងកន្លះរង្វង់)។ តាមសមាមាត្រត្រីកោណមាត្រ ឬពីតាគ័រ ៖ បើ \(BC = 15\,\text{cm}\) នោះ \(AC = \sqrt{25^2 - 15^2} = 20\,\text{cm}\)។

៥លំហាត់ទី ៥

រង្វង់ផ្ចិត \(O\) មានកាំ \(5\,\text{cm}\) និងអង្កត់ធ្នូប្រវែង \(8\,\text{cm}\)។ គណនាចម្ងាយពីផ្ចិតទៅអង្កត់ធ្នូ។

មើលដំណោះស្រាយ

គណនាចម្ងាយពីផ្ចិតរង្វង់ទៅអង្កត់ធ្នូ ៖ កាំ \(R = 5\,\text{cm}\), អង្កត់ធ្នូ \(AB = 8\,\text{cm} \implies AH = 4\,\text{cm}\)។ ចម្ងាយ \(d = OH = \sqrt{R^2 - AH^2} = \sqrt{5^2 - 4^2} = \sqrt{25 - 16} = 3\,\text{cm}\)។

៦លំហាត់ទី ៦

រង្វង់ផ្ចិត \(O\) មានកាំ \(10\,\text{cm}\)។ អង្កត់ធ្នូមួយនៅចម្ងាយ \(6\,\text{cm}\) ពីផ្ចិត។ គណនាប្រវែងអង្កត់ធ្នូនោះ។

មើលដំណោះស្រាយ

គណនាប្រវែងអង្កត់ធ្នូ ៖ កាំ \(R = 10\,\text{cm}\), ចម្ងាយ \(d = 6\,\text{cm}\) ៖ កន្លះអង្កត់ធ្នូ ៖ \(AH = \sqrt{10^2 - 6^2} = 8\,\text{cm}\) នាំឱ្យ \(AB = 2 \times 8 = 16\,\text{cm}\)។

៧លំហាត់ទី ៧

អង្កត់ធ្នូមួយមានប្រវែង \(24\,\text{cm}\) និងនៅចម្ងាយ \(5\,\text{cm}\) ពីផ្ចិត។ គណនាកាំនៃរង្វង់នោះ។

មើលដំណោះស្រាយ

គណនាកាំរង្វង់ ៖ អង្កត់ធ្នូ \(AB = 24\,\text{cm}\) (\(AH = 12\)), ចម្ងាយ \(d = 5\,\text{cm}\) ៖ \(R = \sqrt{12^2 + 5^2} = \sqrt{144 + 25} = 13\,\text{cm}\)។

៨លំហាត់ទី ៨

បង្ហាញថាអង្កត់ធ្នូពីរដែលមានចម្ងាយស្មើគ្នាពីផ្ចិត ត្រូវតែមានប្រវែងស្មើគ្នា។

មើលដំណោះស្រាយ

បង្ហាញអង្កត់ធ្នូពីរប៉ុនគ្នា ៖ ចម្ងាយពីផ្ចិតទៅ \(AB\) និង \(CD\) គឺ \(d_1 = d_2 = 4\,\text{cm}\) នាំឱ្យ \(AB = CD = 2\sqrt{R^2 - 16}\)។

៩លំហាត់ទី ៩

ពីចំណុច \(P\) នៅចម្ងាយ \(13\,\text{cm}\) ពីផ្ចិតនៃរង្វង់កាំ \(5\,\text{cm}\) គេគូសបន្ទាត់ប៉ះ \(PT\)។ គណនាប្រវែង \(PT\)។

មើលដំណោះស្រាយ

ប្រវែងបន្ទាត់ប៉ះពីចំណុចក្រៅ ៖ \(OP = 13\,\text{cm}, R = 5\,\text{cm}\) ៖ បន្ទាត់ប៉ះកែងនឹងកាំ នាំឱ្យ \(PT = \sqrt{OP^2 - R^2} = \sqrt{169 - 25} = 12\,\text{cm}\)។

១០លំហាត់ទី ១០

បន្ទាត់ប៉ះ \(PT = 8\,\text{cm}\) គូសទៅរង្វង់កាំ \(R = 6\,\text{cm}\)។ គណនាចម្ងាយ \(OP\)។

មើលដំណោះស្រាយ

ចម្ងាយពីចំណុចទៅផ្ចិត ៖ \(PT = 8\,\text{cm}, R = 6\,\text{cm}\) ៖ \(OP = \sqrt{8^2 + 6^2} = 10\,\text{cm}\)។

១១លំហាត់ទី ១១

ចម្ងាយពី \(P\) ទៅផ្ចិតគឺ \(25\,\text{cm}\) និងបន្ទាត់ប៉ះ \(PT = 24\,\text{cm}\)។ គណនាកាំ \(R\)។

មើលដំណោះស្រាយ

កាំរង្វង់ពីបន្ទាត់ប៉ះ ៖ \(OP = 25\,\text{cm}, PT = 24\,\text{cm}\) ៖ \(R = \sqrt{25^2 - 24^2} = \sqrt{49} = 7\,\text{cm}\)។

១២លំហាត់ទី ១២

ពីចំណុច \(P\) គូសបន្ទាត់ប៉ះពីរ \(PA\) និង \(PB\) ទៅរង្វង់ផ្ចិត \(O\)។ បើ \(\angle AOB = 130^\circ\) រកមុំ \(\angle APB\)។

មើលដំណោះស្រាយ

មុំរវាងបន្ទាត់ប៉ះទាំងពីរ ៖ មុំផ្ចិត \(\angle AOB = 130^\circ\) នាំឱ្យ \(\angle APB = 180^\circ - 130^\circ = 50^\circ\)។

១៣លំហាត់ទី ១៣

ពីចំណុច \(P\) គូសបន្ទាត់ប៉ះពីរទៅរង្វង់។ បើមុំរវាងបន្ទាត់ប៉ះទាំងពីរគឺ \(70^\circ\) រកមុំផ្ចិត \(\angle AOB\)។

មើលដំណោះស្រាយ

មុំផ្ចិតបង្កើតដោយចំណុចប៉ះ ៖ \(\angle APB = 70^\circ \implies \angle AOB = 180^\circ - 70^\circ = 110^\circ\)។

១៤លំហាត់ទី ១៤

រង្វង់ពីរមានកាំ \(9\,\text{cm}\) និង \(4\,\text{cm}\) ចម្ងាយផ្ចិត \(13\,\text{cm}\)។ គណនាប្រវែងបន្ទាត់ប៉ះរួមក្រៅ។

មើលដំណោះស្រាយ

បន្ទាត់ប៉ះរួមក្រៅ ៖ \(R = 9\,\text{cm}, r = 4\,\text{cm}, d = 13\,\text{cm}\) ៖ \(L = \sqrt{d^2 - (R - r)^2} = \sqrt{13^2 - 5^2} = 12\,\text{cm}\)។

១៥លំហាត់ទី ១៥

រង្វង់ពីរមានកាំ \(5\,\text{cm}\) និង \(3\,\text{cm}\) ចម្ងាយផ្ចិត \(10\,\text{cm}\)។ គណនាប្រវែងបន្ទាត់ប៉ះរួមក្នុង។

មើលដំណោះស្រាយ

បន្ទាត់ប៉ះរួមក្នុង ៖ \(R = 5\,\text{cm}, r = 3\,\text{cm}, d = 10\,\text{cm}\) ៖ \(L' = \sqrt{d^2 - (R + r)^2} = \sqrt{10^2 - 8^2} = 6\,\text{cm}\)។

១៦លំហាត់ទី ១៦

ចតុកោណ \(ABCD\) ចារឹកក្រៅរង្វង់មាន \(AB = 6, BC = 7, CD = 9\)។ គណនាប្រវែងជ្រុង \(AD\)។

មើលដំណោះស្រាយ

ចតុកោណចារឹកក្រៅរង្វង់ ៖ \(AB + CD = BC + AD \implies 6 + 9 = 7 + AD \implies AD = 8\,\text{cm}\)។

១៧លំហាត់ទី ១៧

ចតុកោណមួយចារឹកក្រៅរង្វង់មានផលបូកជ្រុងឈមមួយគូស្មើ \(24\,\text{cm}\)។ គណនាបរិមាត្រចតុកោណនោះ។

មើលដំណោះស្រាយ

បរិមាត្រចតុកោណចារឹកក្រៅរង្វង់ ៖ \(P = 2(AB + CD) = 2(10 + 14) = 48\,\text{cm}\)។

១៨លំហាត់ទី ១៨

គណនាកាំនៃរង្វង់ចារឹកក្នុងត្រីកោណកែងដែលមានជ្រុង \(9\,\text{cm}, 12\,\text{cm}, 15\,\text{cm}\)។

មើលដំណោះស្រាយ

កាំរង្វង់ចារឹកក្នុងត្រីកោណកែង ៖ \(a = 9, b = 12 \implies c = 15\) \(r = \frac{a + b - c}{2} = \frac{9 + 12 - 15}{2} = 3\,\text{cm}\)។

១៩លំហាត់ទី ១៩

រង្វង់មួយមានកាំ \(10\,\text{cm}\)។ គណនាចម្ងាយរវាងអង្កត់ធ្នូស្របគ្នាពីរប្រវែង \(12\,\text{cm}\) និង \(16\,\text{cm}\) (សងខាងផ្ចិត និងម្ខាងផ្ចិត)។

មើលដំណោះស្រាយ

ចម្ងាយរវាងអង្កត់ធ្នូស្របគ្នា ៖ \(R = 10\,\text{cm}\), អង្កត់ធ្នូ \(12\,\text{cm}\) (\(d_1 = 8\)) និង \(16\,\text{cm}\) (\(d_2 = 6\)) ៖

  • សងខាងផ្ចិត ៖ \(d = 8 + 6 = 14\,\text{cm}\)

  • ម្ខាងផ្ចិត ៖ \(d = 8 - 6 = 2\,\text{cm}\)

២០លំហាត់ទី ២០

អង្កត់ធ្នូពីរ \(AB\) និង \(CD\) កាត់គ្នាត្រង់ \(P\) ក្នុងរង្វង់។ បើ \(PA = 4, PB = 6, PC = 3\) រក \(PD\)។

មើលដំណោះស្រាយ

ទ្រឹស្តីបទអង្កត់ធ្នូកាត់គ្នា ៖ \(PA \times PB = PC \times PD \implies 4 \times 6 = 3 \times PD \implies PD = 8\,\text{cm}\)។

២១លំហាត់ទី ២១

បន្ទាត់កាត់ពីរ \(PAB\) និង \(PCD\) គូសចេញពី \(P\) ក្រៅរង្វង់។ បើ \(PA = 3, PB = 8, PC = 4\) រក \(PD\)។

មើលដំណោះស្រាយ

ទ្រឹស្តីបទបន្ទាត់កាត់ពីរ ៖ \(PA \times PB = PC \times PD \implies 3 \times 8 = 4 \times PD \implies PD = 6\,\text{cm}\)។

២២លំហាត់ទី ២២

ពី \(P\) ក្រៅរង្វង់ គូសបន្ទាត់ប៉ះ \(PT\) និងបន្ទាត់កាត់ \(PAB\)។ បើ \(PA = 4, PB = 9\) គណនា \(PT\)។

មើលដំណោះស្រាយ

ទ្រឹស្តីបទបន្ទាត់ប៉ះ និងបន្ទាត់កាត់ ៖ \(PT^2 = PA \times PB \implies PT^2 = 4 \times 9 = 36 \implies PT = 6\,\text{cm}\)។

២៣លំហាត់ទី ២៣

បើ \(PT = 8\,\text{cm}\) និង \(PA = 4\,\text{cm}\) រកប្រវែងអង្កត់ធ្នូ \(AB\)។

មើលដំណោះស្រាយ

រកប្រវែងបន្ទាត់កាត់ ៖ \(PT = 8\,\text{cm}, PA = 4\,\text{cm} \implies 64 = 4 \times PB \implies PB = 16\,\text{cm}\) \(AB = PB - PA = 16 - 4 = 12\,\text{cm}\)។

២៤លំហាត់ទី ២៤

បង្ហាញថា \(OP\) ជាមេដ្យាទ័រនៃអង្កត់ភ្ជាប់ចំណុចប៉ះទាំងពីរ \([AB]\)។

មើលដំណោះស្រាយ

ត្រីកោណកែងបង្កើតដោយបន្ទាត់ប៉ះ ៖ \(PA = PB\) និង \(OA = OB = R\) នាំឱ្យ \(OP\) ជាមេដ្យាទ័រនៃ \([AB]\)។ \(AB = \frac{2 \times PA \times R}{OP}\)។

២៥លំហាត់ទី ២៥

គណនាប្រវែងខ្សែពួរដែលរុំព័ទ្ធស៊ីឡាំងពីរស្មើគ្នាកាំ \(R\) ប៉ះក្រៅគ្នា។

មើលដំណោះស្រាយ

គណនាប្រវែងខ្សែពួររុំស៊ីឡាំងពីរ ៖ ប្រវែងស្មើផលបូកបន្ទាត់ប៉ះរួម និងធ្នូនៃរង្វង់ទាំងពីរ។

២៦លំហាត់ទី ២៦

បង្ហាញថាបើអង្កត់ធ្នូពីរកាត់កែងគ្នាត្រង់ \(P\) នោះ \(PA^2 + PB^2 + PC^2 + PD^2 = 4R^2\)។

មើលដំណោះស្រាយ

អង្កត់ធ្នូកាត់កែងគ្នា ៖ បើអង្កត់ធ្នូពីរកាត់កែងគ្នាត្រង់ \(P\) នោះ \(PA^2 + PB^2 + PC^2 + PD^2 = 4R^2\)។

២៧លំហាត់ទី ២៧

បង្ហាញថាបន្ទាត់មួយកែងនឹងកាំត្រង់ចំណុចលើរង្វង់ គឺជាបន្ទាត់ប៉ះនឹងរង្វង់។

មើលដំណោះស្រាយ

បង្ហាញបន្ទាត់ប៉ះ ៖ \(\Delta OAT\) មាន \(OA = 5, AT = 12, OT = 13\)។ ដោយ \(5^2 + 12^2 = 13^2\) នោះ \(\angle OAT = 90^\circ\) នាំឱ្យ \(AT\) ជាបន្ទាត់ប៉ះ។

២៨លំហាត់ទី ២៨

រកកាំរង្វង់ចារឹកក្នុងចតុកោណស្មើដែលមានអង្កត់ទ្រូង \(12\,\text{cm}\) និង \(16\,\text{cm}\)។

មើលដំណោះស្រាយ

រង្វង់ចារឹកក្នុងចតុកោណស្មើ ៖ អង្កត់ទ្រូង \(12\) និង \(16\) (\(a = 10\)) ៖ ផ្ទៃក្រឡា \(S = \frac{1}{2}(12)(16) = 96 = p \times r = 20 \times r \implies r = 4.8\,\text{cm}\)។

២៩លំហាត់ទី ២៩

រង្វង់ពីរប៉ះក្រៅគ្នាមានកាំ \(7\,\text{cm}\) និង \(3\,\text{cm}\)។ គណនាចម្ងាយរវាងផ្ចិតទាំងពីរ។

មើលដំណោះស្រាយ

ចម្ងាយរវាងផ្ចិតរង្វង់ពីរប៉ះក្រៅ ៖ \(R = 7\,\text{cm}, r = 3\,\text{cm} \implies OO' = R + r = 10\,\text{cm}\)។

៣០លំហាត់ទី ៣០

រង្វង់ពីរប៉ះក្នុងគ្នាមានកាំ \(8\,\text{cm}\) និង \(3\,\text{cm}\)។ គណនាចម្ងាយរវាងផ្ចិតទាំងពីរ។

មើលដំណោះស្រាយ

ចម្ងាយរវាងផ្ចិតរង្វង់ពីរប៉ះក្នុង ៖ \(R = 8\,\text{cm}, r = 3\,\text{cm} \implies OO' = R - r = 5\,\text{cm}\)។

៣១លំហាត់ទី ៣១

រង្វង់រួមផ្ចិតពីរមានកាំ \(10\,\text{cm}\) និង \(6\,\text{cm}\)។ គណនាប្រវែងអង្កត់ធ្នូរង្វង់ធំដែលប៉ះរង្វង់តូច។

មើលដំណោះស្រាយ

អង្កត់ធ្នូនៃរង្វង់ធំប៉ះរង្វង់តូច ៖ រង្វង់រួមផ្ចិតកាំ \(R = 10, r = 6\) ៖ ប្រវែងអង្កត់ធ្នូ ៖ \(2\sqrt{R^2 - r^2} = 2\sqrt{100 - 36} = 16\,\text{cm}\)។

៣២លំហាត់ទី ៣២

គណនាផ្ទៃក្រឡាចិញ្ចៀនរង្វង់ក្នុងលំហាត់ ៣១។

មើលដំណោះស្រាយ

ផ្ទៃក្រឡាចិញ្ចៀនរង្វង់ (Annulus) ៖ \(S = \pi (R^2 - r^2) = \pi (8^2) = 64\pi\,\text{cm}^2\) (ស្មើផ្ទៃរង្វង់ដែលមានអង្កត់ផ្ចិតជាអង្កត់ធ្នូប៉ះ)។

៣៣លំហាត់ទី ៣៣

រង្វង់ពីរស្មើគ្នាកាំ \(5\,\text{cm}\) មានចម្ងាយផ្ចិត \(12\,\text{cm}\)។ គណនាប្រវែងបន្ទាត់ប៉ះរួមក្រៅ។

មើលដំណោះស្រាយ

បន្ទាត់ប៉ះរួមរង្វង់ស្មើគ្នា ៖ រង្វង់ពីរមានកាំ \(R = 5\) ចម្ងាយ \(d = 12\) ៖ បន្ទាត់ប៉ះរួមក្រៅ \(L = d = 12\,\text{cm}\)។

៣៤លំហាត់ទី ៣៤

ពីលំហាត់ ៣៣ គណនាប្រវែងបន្ទាត់ប៉ះរួមក្នុង។

មើលដំណោះស្រាយ

បន្ទាត់ប៉ះរួមក្នុងរង្វង់ស្មើគ្នា ៖ \(L' = \sqrt{d^2 - (2R)^2} = \sqrt{144 - 100} = \sqrt{44} = 2\sqrt{11}\,\text{cm}\)។

៣៥លំហាត់ទី ៣៥

គណនាផ្ទៃក្រឡាត្រីកោណ \(PAB\) ដែលបង្កើតដោយបន្ទាត់ប៉ះពីរពី \(P\) ទៅរង្វង់។

មើលដំណោះស្រាយ

គណនាផ្ទៃត្រីកោណ \(PAB\) បង្កើតដោយបន្ទាត់ប៉ះ ៖ \(PA = 12, R = 5 \implies OP = 13\) \(S_{PAB} = \frac{PA^3 \times R}{OP^2} = \frac{1728 \times 5}{169} \approx 51.12\,\text{cm}^2\)។

៣៦លំហាត់ទី ៣៦

គណនាកាំរង្វង់ចារឹកក្នុងត្រីកោណសម័ង្សដែលមានជ្រុងប្រវែង \(12\,\text{cm}\)។

មើលដំណោះស្រាយ

កាំរង្វង់ចារឹកក្នុងត្រីកោណសម័ង្ស ៖ \(a = 12\,\text{cm} \implies r = \frac{a\sqrt{3}}{6} = 2\sqrt{3}\,\text{cm}\)។

៣៧លំហាត់ទី ៣៧

គណនាកាំរង្វង់ចារឹកក្រៅត្រីកោណសម័ង្សដែលមានជ្រុងប្រវែង \(12\,\text{cm}\)។

មើលដំណោះស្រាយ

កាំរង្វង់ចារឹកក្រៅត្រីកោណសម័ង្ស ៖ \(a = 12\,\text{cm} \implies R = \frac{a\sqrt{3}}{3} = 4\sqrt{3}\,\text{cm}\)។

៣៨លំហាត់ទី ៣៨

បង្ហាញថាអង្កត់ធ្នូដែលត្រូវនឹងមុំផ្ចិត \(60^\circ\) មានប្រវែងស្មើនឹងកាំរង្វង់ \(R\)។

មើលដំណោះស្រាយ

អង្កត់ធ្នូ និងមុំផ្ចិត \(60^\circ\) ៖ \(\Delta OAB\) សមបាតមានមុំ \(60^\circ\) នាំឱ្យជាត្រីកោណសម័ង្ស \(\implies AB = R\)។

៣៩លំហាត់ទី ៣៩

បង្ហាញថាអង្កត់ធ្នូដែលត្រូវនឹងមុំផ្ចិត \(90^\circ\) មានប្រវែង \(R\sqrt{2}\)។

មើលដំណោះស្រាយ

អង្កត់ធ្នូ និងមុំផ្ចិត \(90^\circ\) ៖ \(\Delta OAB\) កែងសមបាត \(\implies AB = R\sqrt{2}\)។

៤០លំហាត់ទី ៤០

បង្ហាញថាអង្កត់ធ្នូដែលត្រូវនឹងមុំផ្ចិត \(120^\circ\) មានប្រវែង \(R\sqrt{3}\)។

មើលដំណោះស្រាយ

អង្កត់ធ្នូ និងមុំផ្ចិត \(120^\circ\) ៖ \(AB = 2R \sin 60^\circ = R\sqrt{3}\)។

៤១លំហាត់ទី ៤១

រកចម្ងាយខ្លីបំផុតពីចំណុច \(P\) នៅចម្ងាយ \(15\,\text{cm}\) ពីផ្ចិតរង្វង់កាំ \(6\,\text{cm}\) ទៅកាន់រង្វង់។

មើលដំណោះស្រាយ

ចម្ងាយអប្បបរមាពីចំណុចក្រៅទៅរង្វង់ ៖ \(OP = 15, R = 6 \implies d_{\min} = 15 - 6 = 9\,\text{cm}\)។

៤២លំហាត់ទី ៤២

រកចម្ងាយវែងបំផុតពីចំណុច \(P\) ក្នុងលំហាត់ ៤១ ទៅកាន់រង្វង់។

មើលដំណោះស្រាយ

ចម្ងាយអតិបរមាពីចំណុចក្រៅទៅរង្វង់ ៖ \(d_{\max} = OP + R = 15 + 6 = 21\,\text{cm}\)។

៤៣លំហាត់ទី ៤៣

ចំណុច \(M\) នៅក្នុងរង្វង់កាំ \(9\,\text{cm}\) នៅចម្ងាយ \(4\,\text{cm}\) ពីផ្ចិត។ រកចម្ងាយខ្លីបំផុត និងវែងបំផុតពី \(M\) ទៅរង្វង់។

មើលដំណោះស្រាយ

ចំណុចក្នុងរង្វង់ ៖ \(OP = 4, R = 9 \implies\) ចម្ងាយខ្លីបំផុតទៅរង្វង់គឺ \(9 - 4 = 5\), វែងបំផុតគឺ \(9 + 4 = 13\)។

៤៤លំហាត់ទី ៤៤

បង្ហាញថាអង្កត់ធ្នូខ្លីបំផុតដែលកាត់តាមចំណុច \(M\) ក្នុងរង្វង់ គឺជាអង្កត់ធ្នូដែលកែងនឹង \(OM\)។

មើលដំណោះស្រាយ

អង្កត់ធ្នូខ្លីបំផុតកាត់តាមចំណុច \(M\) ក្នុងរង្វង់ ៖ គឺអង្កត់ធ្នូដែលកែងនឹង \(OM\)។ ប្រវែងគឺ \(2\sqrt{R^2 - OM^2}\)។

៤៥លំហាត់ទី ៤៥

បង្ហាញថាអង្កត់ធ្នូវែងបំផុតដែលកាត់តាមចំណុច \(M\) ក្នុងរង្វង់ គឺជាអង្កត់ផ្ចិត។

មើលដំណោះស្រាយ

អង្កត់ធ្នូវែងបំផុតកាត់តាមចំណុច \(M\) ក្នុងរង្វង់ ៖ គឺអង្កត់ផ្ចិតដែលកាត់តាម \(M\) ប្រវែង \(2R\)។

៤៦លំហាត់ទី ៤៦

បង្ហាញថាក្នុងចតុកោណព្នាយសមបាតចារឹកក្រៅរង្វង់ ជ្រុងទ្រេតស្មើនឹងកន្លះផលបូកបាតទាំងពីរ។

មើលដំណោះស្រាយ

ចតុកោណព្នាយសមបាតចារឹកក្រៅរង្វង់ ៖ \(a + b = 2c\) នាំឱ្យជ្រុងទ្រេតស្មើកន្លះផលបូកបាត។

៤៧លំហាត់ទី ៤៧

ពន្យល់ពីវិធីសង់រង្វង់មួយឱ្យកាត់តាមបីចំណុចមិនរត់ត្រង់ជួរគ្នា។

មើលដំណោះស្រាយ

លក្ខខណ្ឌបន្ទាត់ប៉ះរង្វង់កាត់តាម ៣ ចំណុច ៖ ផ្ចិតជាប្រសព្វនៃមេដ្យាទ័រទាំងពីរ។

៤៨លំហាត់ទី ៤៨

ពន្យល់ពីគោលការណ៍នៃកម្លាំងអំណាចនៃចំណុចធៀបនឹងរង្វង់ (Power of a Point)។

មើលដំណោះស្រាយ

កម្លាំងអំណាចនៃចំណុចធៀបនឹងរង្វង់ (Power of a Point) ៖ \(\mathcal{P}(P) = OP^2 - R^2 = PA \times PB\)។

៤៩លំហាត់ទី ៤៩

ពន្យល់ពីអ័ក្សរ៉ាឌីកាល់ (Radical Axis) នៃរង្វង់ពីរ។

មើលដំណោះស្រាយ

អ័ក្សរ៉ាឌីកាល់នៃរង្វង់ពីរ (Radical Axis) ៖ ជាសំណុំចំណុចដែលមានកម្លាំងអំណាចស្មើគ្នាចំពោះរង្វង់ទាំងពីរ (បន្ទាត់កែងនឹង \(OO'\))។

៥០លំហាត់ទី ៥០

សរសេរការពិពណ៌នាអំពីបញ្ហារបស់ Apollonius និងសារៈសំខាន់របស់វាក្នុងប្រវត្តិសាស្ត្រគណិតវិទ្យា។

មើលដំណោះស្រាយ

ចំណោទ Apollonius ស្តីពីរង្វង់ ៖ ការសង់រង្វង់ប៉ះនឹងវត្ថុធរណីមាត្រ ៣ (ចំណុច បន្ទាត់ ឬរង្វង់) ដែលជាបញ្ហាប្រវត្តិសាស្ត្រដ៏ល្បីល្បាញ។

សំណួរពហុជ្រើសរើស

ជ្រើសរើសចម្លើយត្រឹមត្រូវតែមួយ រួចចុច «ពិនិត្យ»។ ចម្លើយរបស់អ្នកត្រូវបានរក្សាទុកក្នុងកុំព្យូទ័រនេះ។
