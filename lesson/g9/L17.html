ប្រវត្តិពហុកោណ និង Carl Friedrich Gauss ពាក្យ ពហុកោណ (Polygon) មានប្រភពមកពីភាសាក្រិកបុរាណ polus (ច្រើន) និង gonia (មុំ ឬជង្គង់)។ ការសិក្សាអំពីពហុកោណបានចាប់ផ្ដើមតាំងពីសម័យបាប៊ីឡូន និងក្រិកបុរាណ ជាពិសេសនៅក្នុងគម្ពីរ Elements របស់ Euclid។

នៅឆ្នាំ ១៧៩៦ គណិតវិទូអាល្លឺម៉ង់ដ៏ឆ្នើម Carl Friedrich Gauss (1777–1855) ក្នុងវ័យទើបតែ ១៩ ឆ្នាំ បានធ្វើឱ្យពិភពគណិតវិទ្យាភ្ញាក់ផ្អើលយ៉ាងខ្លាំង ដោយគាត់បានរកឃើញវិធីសង់ ពហុកោណនិយ័ត ១៧ ជ្រុង (Heptadecagon) ដោយប្រើប្រាស់តែបន្ទាត់គ្មានលេខ និងដែកឈានប៉ុណ្ណោះ។ នេះជាការបោះជំហានទៅមុខជាលើកដំបូងក្នុងធរណីមាត្រសង់រូបបន្ទាប់ពីស្ងប់ស្ងាត់អស់រយៈពេលជាង ២០០០ ឆ្នាំតាំងពីសម័យក្រិកបុរាណមក។ Gauss មានមោទនភាពចំពោះរបកគំហើញនេះរហូតដល់ស្នើសុំឱ្យគេឆ្លាក់រូបពហុកោណ ១៧ ជ្រុងនៅលើផ្នូររបស់លោកទៀតផង។

ពហុកោណ

ពហុកោណ ជាផ្នែកមួយនៃប្លង់ខណ្ឌដោយខ្សែកាច់បិទជិត។

  • ពហុកោណប៉ោង ៖ ជាពហុកោណដែលគ្រប់អង្កត់តភ្ជាប់ពីរបំណុចណាក៏ដោយនៅក្នុងពហុកោណ សុទ្ធតែស្ថិតនៅក្នុងផ្ទៃពហុកោណទាំងស្រុង។

  • ពហុកោណផត ៖ ជាពហុកោណដែលមានអង្កត់តភ្ជាប់យ៉ាងហោចពីរបំណុចធ្លាក់ចេញមកក្រៅផ្ទៃពហុកោណ។

អង្កត់ទ្រូងនៃពហុកោណ

ចំពោះពហុកោណប៉ោងមួយដែលមាន \(n\) ជ្រុង (\(n \ge 3\)) ៖

  1. ចំនួនអង្កត់ទ្រូងដែលគូសចេញពីកំពូលមួយគឺ \(d = n - 3\)។

  2. ចំនួនអង្កត់ទ្រូងសរុបនៃពហុកោណគឺ ៖

    \[D = \frac{n(n-3)}{2}\]

ឧទាហរណ៍

ចូរគណនាចំនួនអង្កត់ទ្រូងសរុបនៃឆកោណ (\(n=6\)) និងអដ្ឋកោណ (\(n=8\))។

ដំណោះស្រាយ

  • ចំពោះឆកោណ (\(n=6\)) ៖ \(D = \dfrac{6(6-3)}{2} = \dfrac{6 \times 3}{2} = 9\) អង្កត់ទ្រូង។

  • ចំពោះអដ្ឋកោណ (\(n=8\)) ៖ \(D = \dfrac{8(8-3)}{2} = \dfrac{8 \times 5}{2} = 20\) អង្កត់ទ្រូង។

គណនាចំនួនអង្កត់ទ្រូងនៃពហុកោណដែលមាន \(12\) ជ្រុង និងរកចំនួនជ្រុងនៃពហុកោណដែលមាន \(35\) អង្កត់ទ្រូង។

ផលបូកមុំក្នុងនៃពហុកោណ

ផលបូករង្វាស់មុំក្នុងនៃពហុកោណប៉ោងមួយដែលមាន \(n\) ជ្រុង (\(n \ge 3\)) កំណត់ដោយរូបមន្ត ៖

\[S = (n - 2) \times 180^\circ\]

ឧទាហរណ៍

គណនាផលបូករង្វាស់មុំក្នុងនៃបញ្ចកោណ (\(n=5\)) និងទសកោណ (\(n=10\))។

ដំណោះស្រាយ

  • ចំពោះបញ្ចកោណ (\(n=5\)) ៖ \(S = (5-2) \times 180^\circ = 3 \times 180^\circ = 540^\circ\)។

  • ចំពោះទសកោណ (\(n=10\)) ៖ \(S = (10-2) \times 180^\circ = 8 \times 180^\circ = 1440^\circ\)។

ប្រតិបត្តិ

ផលបូករង្វាស់មុំក្នុងនៃពហុកោណមួយស្មើនឹង \(2160^\circ\)។ តើពហុកោណនោះមានជ្រុងប៉ុន្មាន?

ផលបូករង្វាស់មុំក្រៅនៃពហុកោណ

ផលបូកមុំក្រៅ

ផលបូករង្វាស់មុំក្រៅនៃពហុកោណប៉ោងណាក៏ដោយ (យកមួយនៅកំពូលនីមួយៗ) តែងតែមានរង្វាស់ស្មើនឹង \(360^\circ\) ជានិច្ច ៖

\[S_{\text{ext}} = 360^\circ\]

ឧទាហរណ៍

ក្នុងចតុកោណមួយ មុំក្រៅបីមានរង្វាស់ \(80^\circ, 110^\circ, 70^\circ\)។ រករង្វាស់មុំក្រៅទីបួន។

ដំណោះស្រាយ

  • តាង \(x\) ជាមុំក្រៅទីបួន ៖

    \[80^\circ + 110^\circ + 70^\circ + x = 360^\circ \implies 260^\circ + x = 360^\circ \implies x = 100^\circ\]

ប្រតិបត្តិ

ក្នុងបញ្ចកោណមួយ មុំក្រៅទាំងប្រាំសមាមាត្រនឹង \(1, 2, 3, 4, 5\)។ គណនារង្វាស់មុំក្រៅនីមួយៗ។

ពហុកោណនិយ័ត

ពហុកោណនិយ័ត ជាពហុកោណដែលមានជ្រុងទាំងអស់ប៉ុនគ្នា និងមុំក្នុងទាំងអស់ប៉ុនគ្នា។

មុំនៃពហុកោណនិយ័ត

ចំពោះពហុកោណនិយ័តដែលមាន \(n\) ជ្រុង ៖

  1. រង្វាស់មុំក្នុងនីមួយៗគឺ ៖

    \[\alpha = \frac{(n-2) \times 180^\circ}{n}\]

  2. រង្វាស់មុំក្រៅនីមួយៗគឺ ៖

    \[\beta = \frac{360^\circ}{n}\]

  3. ទំនាក់ទំនងរវាងមុំក្នុង និងមុំក្រៅ ៖

    \[\alpha + \beta = 180^\circ\]

ឧទាហរណ៍

គណនារង្វាស់មុំក្នុង និងមុំក្រៅនៃឆកោណនិយ័ត (\(n=6\))។

ដំណោះស្រាយ

  • មុំក្រៅ ៖ \(\beta = \dfrac{360^\circ}{6} = 60^\circ\)

  • មុំក្នុង ៖ \(\alpha = 180^\circ - 60^\circ = 120^\circ\)

ប្រតិបត្តិ

ពហុកោណនិយ័តមួយមានមុំក្នុងស្មើនឹង \(150^\circ\)។ រកចំនួនជ្រុងនៃពហុកោណនោះ។

១លំហាត់ទី ១

គណនាផលបូករង្វាស់មុំក្នុងនៃពហុកោណដែលមាន ៖ \(n = 5, n = 7, n = 10, n = 12\)។

មើលដំណោះស្រាយ

គណនាផលបូករង្វាស់មុំក្នុង \(S = (n-2) \times 180^\circ\) ៖

  • \(n = 5\) ៖ \(S = (5-2) \times 180^\circ = 3 \times 180^\circ = 540^\circ\)

  • \(n = 7\) ៖ \(S = (7-2) \times 180^\circ = 5 \times 180^\circ = 900^\circ\)

  • \(n = 10\) ៖ \(S = (10-2) \times 180^\circ = 8 \times 180^\circ = 1440^\circ\)

  • \(n = 12\) ៖ \(S = (12-2) \times 180^\circ = 10 \times 180^\circ = 1800^\circ\)

២លំហាត់ទី ២

រកចំនួនជ្រុង \(n\) នៃពហុកោណបើផលបូកមុំក្នុងស្មើ ៖ ក) \(1260^\circ\), ខ) \(1800^\circ\), គ) \(2340^\circ\), ឃ) \(3240^\circ\)។

មើលដំណោះស្រាយ

រកចំនួនជ្រុង \(n\) តាមរូបមន្ត \(n = \dfrac{S}{180^\circ} + 2\) ៖

  • ក) \(S = 1260^\circ \implies n = \dfrac{1260}{180} + 2 = 7 + 2 = 9\) ជ្រុង

  • ខ) \(S = 1800^\circ \implies n = \dfrac{1800}{180} + 2 = 10 + 2 = 12\) ជ្រុង

  • គ) \(S = 2340^\circ \implies n = \dfrac{2340}{180} + 2 = 13 + 2 = 15\) ជ្រុង

  • ឃ) \(S = 3240^\circ \implies n = \dfrac{3240}{180} + 2 = 18 + 2 = 20\) ជ្រុង

៣លំហាត់ទី ៣

គណនាចំនួនអង្កត់ទ្រូងដែលគូសចេញពីកំពូលមួយ និងចំនួនអង្កត់ទ្រូងសរុបនៃពហុកោណដែលមាន ៖ ក) \(8\) ជ្រុង, ខ) \(11\) ជ្រុង, គ) \(15\) ជ្រុង, ឃ) \(20\) ជ្រុង។

មើលដំណោះស្រាយ

ចំនួនអង្កត់ទ្រូងពីកំពូលមួយគឺ \(d = n - 3\) និងសរុបគឺ \(D = \dfrac{n(n-3)}{2}\) ៖

  • ក) \(n = 8\) ៖ \(d = 8-3 = 5\), \(D = \dfrac{8 \times 5}{2} = 20\)

  • ខ) \(n = 11\) ៖ \(d = 11-3 = 8\), \(D = \dfrac{11 \times 8}{2} = 44\)

  • គ) \(n = 15\) ៖ \(d = 15-3 = 12\), \(D = \dfrac{15 \times 12}{2} = 90\)

  • ឃ) \(n = 20\) ៖ \(d = 20-3 = 17\), \(D = \dfrac{20 \times 17}{2} = 170\)

៤លំហាត់ទី ៤

ពហុកោណមួយមានចំនួនអង្កត់ទ្រូងសរុប \(54\)។ រកចំនួនជ្រុង និងផលបូកមុំក្នុងនៃពហុកោណនោះ។

គេមាន \(D = \dfrac{n(n-3)}{2} = 54 \implies n(n-3) = 108\)។ ដោយ \(108 = 12 \times 9\) គេបាន \(n = 12\) ជ្រុង។ ផលបូកមុំក្នុងគឺ ៖

\[S = (12-2) \times 180^\circ = 10 \times 180^\circ = 1800^\circ\]

៥លំហាត់ទី ៥

តើមានពហុកោណណាដែលមានផលបូកមុំក្នុងស្មើនឹង \(2500^\circ\) ដែរឬទេ? ពន្យល់។

មើលដំណោះស្រាយ

ផលបូកមុំក្នុងត្រូវតែចែកដាច់នឹង \(180^\circ\) ៖

\[\dfrac{2500}{180} = 13.888\dots \notin \mathbb{N}\]
ដូចនេះ គ្មានពហុកោណណាដែលមានផលបូកមុំក្នុងស្មើនឹង \(2500^\circ\) ឡើយ។

៦លំហាត់ទី ៦

ក្នុងចតុកោណមួយមានមុំបីរៀងគ្នាគឺ \(75^\circ, 105^\circ, 110^\circ\)។ គណនារង្វាស់មុំទីបួន។

មើលដំណោះស្រាយ

ផលបូកមុំក្នុងនៃចតុកោណគឺ \(360^\circ\)។ តាង \(x\) ជាមុំទីបួន ៖

\[75^\circ + 105^\circ + 110^\circ + x = 360^\circ\]
\[290^\circ + x = 360^\circ \implies x = 360^\circ - 290^\circ = 70^\circ\]
ដូចនេះ មុំទីបួនគឺ \(70^\circ\)។

៧លំហាត់ទី ៧

ក្នុងបញ្ចកោណមួយ មុំទាំងប្រាំសមាមាត្រនឹង \(2, 3, 4, 5, 6\)។ គណនារង្វាស់មុំនីមួយៗនៃបញ្ចកោណ។

មើលដំណោះស្រាយ

ផលបូកមុំក្នុងនៃបញ្ចកោណគឺ \(540^\circ\)។ ផលបូកភាគសមាមាត្រ ៖ \(2 + 3 + 4 + 5 + 6 = 20\) ភាគ។ តម្លៃមួយភាគ ៖ \(\dfrac{540^\circ}{20} = 27^\circ\)។ រង្វាស់មុំទាំងប្រាំគឺ ៖

\[\begin{aligned} \angle 1 &= 2 \times 27^\circ = 54^\circ \\ \angle 2 &= 3 \times 27^\circ = 81^\circ \\ \angle 3 &= 4 \times 27^\circ = 108^\circ \\ \angle 4 &= 5 \times 27^\circ = 135^\circ \\ \angle 5 &= 6 \times 27^\circ = 162^\circ \end{aligned}\]

៨លំហាត់ទី ៨

រកតម្លៃ \(x\) ក្នុងឆកោណដែលមានរង្វាស់មុំក្នុងគឺ \(x, x+10^\circ, x+20^\circ, x+30^\circ, x+40^\circ, x+50^\circ\)។

មើលដំណោះស្រាយ

ផលបូកមុំក្នុងនៃឆកោណគឺ \((6-2) \times 180^\circ = 720^\circ\)។

\[\begin{aligned} x + (x+10^\circ) &+ (x+20^\circ) + (x+30^\circ) \\ &+ (x+40^\circ) + (x+50^\circ) = 720^\circ \\ 6x + 150^\circ &= 720^\circ \implies 6x = 570^\circ \implies x = 95^\circ \end{aligned}\]
ដូចនេះ តម្លៃ \(x = 95^\circ\)។

៩លំហាត់ទី ៩

គណនារង្វាស់មុំក្រៅនីមួយៗ និងមុំក្នុងនីមួយៗនៃពហុកោណនិយ័តខាងក្រោម ៖ ក) បញ្ចកោណនិយ័ត, ខ) ឆកោណនិយ័ត, គ) អដ្ឋកោណនិយ័ត, ឃ) ទសកោណនិយ័ត។

មើលដំណោះស្រាយ

រូបមន្តមុំក្រៅ \(\beta = \dfrac{360^\circ}{n}\) និងមុំក្នុង \(\alpha = 180^\circ - \beta\) ៖

  • ក) បញ្ចកោណ (\(n=5\)) ៖ \(\beta = \dfrac{360^\circ}{5} = 72^\circ\), \(\alpha = 180^\circ - 72^\circ = 108^\circ\)

  • ខ) ឆកោណ (\(n=6\)) ៖ \(\beta = \dfrac{360^\circ}{6} = 60^\circ\), \(\alpha = 180^\circ - 60^\circ = 120^\circ\)

  • គ) អដ្ឋកោណ (\(n=8\)) ៖ \(\beta = \dfrac{360^\circ}{8} = 45^\circ\), \(\alpha = 180^\circ - 45^\circ = 135^\circ\)

  • ឃ) ទសកោណ (\(n=10\)) ៖ \(\beta = \dfrac{360^\circ}{10} = 36^\circ\), \(\alpha = 180^\circ - 36^\circ = 144^\circ\)

១០លំហាត់ទី ១០

រកចំនួនជ្រុងនៃពហុកោណនិយ័តបើស្គាល់មុំក្នុងមួយស្មើ ៖ ក) \(140^\circ\), ខ) \(150^\circ\), គ) \(156^\circ\), ឃ) \(162^\circ\)។

មើលដំណោះស្រាយ

មុំក្រៅ \(\beta = 180^\circ - \alpha\) និងចំនួនជ្រុង \(n = \dfrac{360^\circ}{\beta}\) ៖

  • ក) \(\alpha = 140^\circ \implies \beta = 40^\circ \implies n = \dfrac{360^\circ}{40^\circ} = 9\) ជ្រុង

  • ខ) \(\alpha = 150^\circ \implies \beta = 30^\circ \implies n = \dfrac{360^\circ}{30^\circ} = 12\) ជ្រុង

  • គ) \(\alpha = 156^\circ \implies \beta = 24^\circ \implies n = \dfrac{360^\circ}{24^\circ} = 15\) ជ្រុង

  • ឃ) \(\alpha = 162^\circ \implies \beta = 18^\circ \implies n = \dfrac{360^\circ}{18^\circ} = 20\) ជ្រុង

១១លំហាត់ទី ១១

រកចំនួនជ្រុងនៃពហុកោណនិយ័តបើស្គាល់មុំក្រៅមួយស្មើ ៖ ក) \(45^\circ\), ខ) \(30^\circ\), គ) \(24^\circ\), ឃ) \(15^\circ\)។

មើលដំណោះស្រាយ

ចំនួនជ្រុង \(n = \dfrac{360^\circ}{\beta}\) ៖

  • ក) \(\beta = 45^\circ \implies n = \dfrac{360^\circ}{45^\circ} = 8\) ជ្រុង (អដ្ឋកោណ)

  • ខ) \(\beta = 30^\circ \implies n = \dfrac{360^\circ}{30^\circ} = 12\) ជ្រុង (ទ្វាទសកោណ)

  • គ) \(\beta = 24^\circ \implies n = \dfrac{360^\circ}{24^\circ} = 15\) ជ្រុង

  • ឃ) \(\beta = 15^\circ \implies n = \dfrac{360^\circ}{15^\circ} = 24\) ជ្រុង

១២លំហាត់ទី ១២

ផលបូកមុំក្នុង និងមុំក្រៅទាំងអស់នៃពហុកោណមួយស្មើនឹង \(1440^\circ\)។ រកចំនួនជ្រុងនៃពហុកោណនោះ។

មើលដំណោះស្រាយ

ផលបូកមុំក្នុង \(S_{\text{int}} = (n-2) \times 180^\circ\) និងផលបូកមុំក្រៅ \(S_{\text{ext}} = 360^\circ\)។

\[S_{\text{int}} + S_{\text{ext}} = (n-2) \times 180^\circ + 360^\circ = 1440^\circ\]
\[(n-2) \times 180^\circ = 1080^\circ \implies n-2 = 6 \implies n = 8\]
ដូចនេះ ពហុកោណនោះមាន \(8\) ជ្រុង (អដ្ឋកោណ)។

១៣លំហាត់ទី ១៣

ពហុកោណមួយមានផលបូកមុំក្នុងស្មើនឹង \(3\) ដងនៃផលបូកមុំក្រៅ។ រកចំនួនជ្រុងនៃពហុកោណនេះ។

មើលដំណោះស្រាយ

គេមាន \(S_{\text{int}} = 3 \times S_{\text{ext}}\) ៖

\[(n-2) \times 180^\circ = 3 \times 360^\circ = 1080^\circ\]
\[n - 2 = \dfrac{1080^\circ}{180^\circ} = 6 \implies n = 8\]
ដូចនេះ ពហុកោណនោះមាន \(8\) ជ្រុង។

១៤លំហាត់ទី ១៤

មុំក្នុងមួយនៃពហុកោណនិយ័តធំជាងមុំក្រៅរបស់វា \(100^\circ\)។ រកចំនួនជ្រុងនៃពហុកោណនិយ័តនោះ។

មើលដំណោះស្រាយ

គេមាន \(\alpha - \beta = 100^\circ\) និង \(\alpha + \beta = 180^\circ\)។ បូកសមីការទាំងពីរ ៖ \(2\alpha = 280^\circ \implies \alpha = 140^\circ\)។ មុំក្រៅ ៖ \(\beta = 180^\circ - 140^\circ = 40^\circ\)។ ចំនួនជ្រុង ៖

\[n = \dfrac{360^\circ}{40^\circ} = 9 \text{ ជ្រុង}\]

១៥លំហាត់ទី ១៥

ផលធៀបរវាងមុំក្នុង និងមុំក្រៅនៃពហុកោណនិយ័តមួយគឺ \(7:2\)។ រកចំនួនជ្រុងនៃពហុកោណនោះ។

មើលដំណោះស្រាយ

ផលធៀប \(\dfrac{\alpha}{\beta} = \dfrac{7}{2}\) និង \(\alpha + \beta = 180^\circ\)។ ផលបូកភាគ ៖ \(7 + 2 = 9\) ភាគ។ \(\beta = \dfrac{2}{9} \times 180^\circ = 40^\circ\)។ ចំនួនជ្រុង ៖

\[n = \dfrac{360^\circ}{40^\circ} = 9 \text{ ជ្រុង}\]

១៦លំហាត់ទី ១៦

គណនារង្វាស់មុំក្នុងមួយនៃពហុកោណនិយ័តដែលមាន \(16\) ជ្រុង។

មើលដំណោះស្រាយ

ចំពោះពហុកោណនិយ័ត \(16\) ជ្រុង (\(n=16\)) ៖

\[\begin{aligned} \alpha &= \dfrac{(16-2) \times 180^\circ}{16} = \dfrac{14 \times 180^\circ}{16} \\ &= \dfrac{2520^\circ}{16} = 157.5^\circ = 157^\circ 30' \end{aligned}\]

១៧លំហាត់ទី ១៧

បង្ហាញថាផលបូករង្វាស់មុំក្រៅនៃពហុកោណប៉ោងណាក៏ដោយ តែងតែស្មើ \(360^\circ\)។

មើលដំណោះស្រាយ

នៅគ្រប់កំពូលនីមួយៗ មុំក្នុង និងមុំក្រៅជាប់គ្នាមានផលបូក \(180^\circ\)។ ផលបូកមុំក្នុង និងមុំក្រៅទាំងអស់គឺ \(n \times 180^\circ\)។ ផលបូកមុំក្នុងតែឯងគឺ \((n-2) \times 180^\circ\)។ ផលបូកមុំក្រៅគឺ ៖

\[S_{\text{ext}} = n \times 180^\circ - (n-2) \times 180^\circ = 2 \times 180^\circ = 360^\circ\]
ដូចនេះ ផលបូកមុំក្រៅតែងតែស្មើ \(360^\circ\) ជានិច្ច។

១៨លំហាត់ទី ១៨

រកចំនួនជ្រុងនៃពហុកោណមួយដែលមានចំនួនអង្កត់ទ្រូងស្មើនឹងពីរដងនៃចំនួនជ្រុង។

មើលដំណោះស្រាយ

គេឱ្យ \(D = 2n\) ៖

\[\dfrac{n(n-3)}{2} = 2n \implies n-3 = 4 \implies n = 7\]
ដូចនេះ ពហុកោណនោះមាន \(7\) ជ្រុង (សប្តកោណ)។

១៩លំហាត់ទី ១៩

រកចំនួនជ្រុងនៃពហុកោណមួយដែលមានចំនួនអង្កត់ទ្រូងស្មើនឹងចំនួនជ្រុង។

មើលដំណោះស្រាយ

គេឱ្យ \(D = n\) ៖

\[\dfrac{n(n-3)}{2} = n \implies n-3 = 2 \implies n = 5\]
ដូចនេះ ពហុកោណនោះមាន \(5\) ជ្រុង (បញ្ចកោណ)។

២០លំហាត់ទី ២០

បង្ហាញថារូបមន្តចំនួនអង្កត់ទ្រូងនៃពហុកោណ \(n\) ជ្រុងគឺ \(D = \frac{n(n-3)}{2}\)។

មើលដំណោះស្រាយ

ពីកំពូលមួយ គេអាចគូសអង្កត់ទ្រូងទៅកាន់កំពូលផ្សេងទៀតលើកលែងតែកំពូលខ្លួនឯង និងកំពូលជាប់សងខាង (\(3\) កំពូល) គឺបាន \((n-3)\) អង្កត់ទ្រូង។ ដោយពហុកោណមាន \(n\) កំពូល ចំនួនអង្កត់ទ្រូងសរុបគឺ \(n(n-3)\)។ ប៉ុន្តែអង្កត់ទ្រូងនីមួយៗត្រូវបានរាប់ពីរដង (ពីចុងសងខាង) ដូច្នេះចំនួនអង្កត់ទ្រូងពិតប្រាកដគឺ ៖

\[D = \dfrac{n(n-3)}{2}\]

២១លំហាត់ទី ២១

ក្នុងឆកោណនិយ័ត \(ABCDEF\) មានអង្កត់ផ្ចិតកាត់តាមផ្ចិត \(O\)។ បង្ហាញថាត្រីកោណទាំងប្រាំមួយដែលបង្កើតដោយផ្ចិត \(O\) និងជ្រុងទាំង ៦ ជាត្រីកោណសម័ង្ស។

មើលដំណោះស្រាយ

ក្នុងឆកោណនិយ័ត \(ABCDEF\) មុំផ្ចិតនីមួយៗស្មើ \(\dfrac{360^\circ}{6} = 60^\circ\)។ ត្រីកោណ \(OAB\) មាន \(OA = OB = R\) នាំឱ្យជាត្រីកោណសមបាតដែលមានមុំកំពូល \(60^\circ\)។ ដូច្នេះមុំបាតស្មើ \(\dfrac{180^\circ - 60^\circ}{2} = 60^\circ\)។ នាំឱ្យត្រីកោណទាំងប្រាំមួយសុទ្ធតែជាត្រីកោណសម័ង្ស។

២២លំហាត់ទី ២២

មើលដំណោះស្រាយ

ឆកោណនិយ័តជ្រុង \(a = 6\,\text{cm}\) ផ្សំឡើងពីត្រីកោណសម័ង្សចំនួន \(6\) ដែលមានជ្រុង \(a\) ៖

\[\begin{aligned} S &= 6 \times \left(\dfrac{\sqrt{3}}{4} a^2\right) = \dfrac{3\sqrt{3}}{2} \times 6^2 \\ &= \dfrac{3\sqrt{3}}{2} \times 36 = 54\sqrt{3}\,\text{cm}^2 \approx 93.53\,\text{cm}^2 \end{aligned}\]

២៣លំហាត់ទី ២៣

គណនាផ្ទៃក្រឡានៃអដ្ឋកោណនិយ័តដែលមានជ្រុង \(a\)។

មើលដំណោះស្រាយ

អដ្ឋកោណនិយ័តជ្រុង \(a\) អាចគណនាផ្ទៃក្រឡាតាមរូបមន្ត ៖

\[S = 2(1 + \sqrt{2})a^2\]
រូបមន្តនេះបានមកពីការកាត់ជ្រុងទាំង ៤ នៃការេធំដែលមានជ្រុង \(a(1+\sqrt{2})\)។

២៤លំហាត់ទី ២៤

ចូរពន្យល់មូលហេតុដែលការេ ត្រីកោណសម័ង្ស និងឆកោណនិយ័តអាចយកមកក្រាលកម្រាលប្លង់ (Tessellation) ជិតល្អដោយគ្មានចន្លោះ។

មើលដំណោះស្រាយ

ដើម្បីក្រាលប្លង់ជិតល្អដោយគ្មានចន្លោះ (Tessellation) មុំក្នុងនៃពហុកោណនិយ័តត្រូវតែជាតួចែកនៃ \(360^\circ\) ៖

  • ត្រីកោណសម័ង្ស ៖ \(60^\circ \implies \dfrac{360^\circ}{60^\circ} = 6\) (៦ ត្រីកោណជួបគ្នា)

  • ការេ ៖ \(90^\circ \implies \dfrac{360^\circ}{90^\circ} = 4\) (៤ ការេជួបគ្នា)

  • ឆកោណនិយ័ត ៖ \(120^\circ \implies \dfrac{360^\circ}{120^\circ} = 3\) (៣ ឆកោណជួបគ្នា)

២៥លំហាត់ទី ២៥

បង្ហាញថាបញ្ចកោណនិយ័តមិនអាចយកមកក្រាលកម្រាលប្លង់ទោលដោយគ្មានចន្លោះបានទេ។

មើលដំណោះស្រាយ

បញ្ចកោណនិយ័តមានមុំក្នុង \(\alpha = 108^\circ\)។ ផលធៀប ៖ \(\dfrac{360^\circ}{108^\circ} = 3.333\dots \notin \mathbb{N}\)។ ដូច្នេះ មុំនៃបញ្ចកោណនិយ័តមិនអាចផ្គុំគ្នាជុំវិញចំណុចមួយឱ្យបាន \(360^\circ\) ឡើយ នាំឱ្យមិនអាចក្រាលប្លង់ទោលបានទេ។

២៦លំហាត់ទី ២៦

មុំក្នុងមួយនៃពហុកោណនិយ័ត \(A\) ស្មើនឹង \(\frac{4}{3}\) នៃមុំក្នុងមួយនៃពហុកោណនិយ័ត \(B\)។ បើពហុកោណ \(B\) ជាឆកោណនិយ័ត រកចំនួនជ្រុងនៃពហុកោណ \(A\)។

មើលដំណោះស្រាយ

ពហុកោណ \(B\) ជាឆកោណនិយ័ត នាំឱ្យ \(\alpha_B = 120^\circ\)។ មុំក្នុងនៃពហុកោណ \(A\) គឺ ៖

\[\alpha_A = \dfrac{4}{3} \times 120^\circ = 160^\circ\]
មុំក្រៅនៃពហុកោណ \(A\) គឺ \(\beta_A = 180^\circ - 160^\circ = 20^\circ\)។ ចំនួនជ្រុងនៃពហុកោណ \(A\) គឺ ៖
\[n_A = \dfrac{360^\circ}{20^\circ} = 18 \text{ ជ្រុង}\]

២៧លំហាត់ទី ២៧

ពហុកោណមួយមានមុំកែង \(3\) ហើយមុំផ្សេងទៀតមានរង្វាស់ \(150^\circ\) ដូចៗគ្នា។ រកចំនួនជ្រុងនៃពហុកោណនោះ។

មើលដំណោះស្រាយ

ពហុកោណមាន \(n\) ជ្រុង មានមុំកែង \(3\) (\(3 \times 90^\circ = 270^\circ\)) និងមុំ \((n-3)\) ទៀតស្មើ \(150^\circ\) ៖

\[(n-2) \times 180^\circ = 270^\circ + (n-3) \times 150^\circ\]
\[180n - 360 = 270 + 150n - 450\]
\[30n = 180 \implies n = 6\]
ដូចនេះ ពហុកោណនោះមាន \(6\) ជ្រុង។

២៨លំហាត់ទី ២៨

មុំក្នុងនៃពហុកោណប៉ោងមួយបង្កើតបានជាស្វ៊ីតនព្វន្ត ដែលមុំតូចបំផុតគឺ \(120^\circ\) និងផលសងរួមគឺ \(5^\circ\)។ រកចំនួនជ្រុងនៃពហុកោណ។

មើលដំណោះស្រាយ

ផលបូកមុំក្នុងនៃពហុកោណ \(n\) ជ្រុងគឺ \(S_n = \dfrac{n}{2}[2a + (n-1)d] = (n-2) \times 180^\circ\)។

\[\begin{aligned} &\dfrac{n}{2}[2(120) + (n-1)5] = 180(n-2) \\ &n[240 + 5n - 5] = 360(n-2) \\ &5n^2 + 235n = 360n - 720 \\ &5n^2 - 125n + 720 = 0 \implies n^2 - 25n + 144 = 0 \end{aligned}\]
\((n - 9)(n - 16) = 0 \implies n = 9\) ឬ \(n = 16\)។ បើ \(n = 16\) មុំធំបំផុតគឺ \(120^\circ + 15 \times 5^\circ = 195^\circ > 180^\circ\) (មិនមែនពហុកោណប៉ោង)។ ដូច្នេះ យក \(n = 9\) ជ្រុង។

២៩លំហាត់ទី ២៩

រកចំនួនកំពូលនៃពហុកោណមួយបើដឹងថាចំនួនអង្កត់ទ្រូងច្រើនជាងចំនួនជ្រុងចំនួន \(42\)។

មើលដំណោះស្រាយ

គេឱ្យ \(D - n = 42\) ៖

\[\dfrac{n(n-3)}{2} - n = 42 \implies \dfrac{n^2 - 5n}{2} = 42\]
\[n^2 - 5n - 84 = 0 \implies (n-12)(n+7) = 0\]
ដោយ \(n > 0\) គេបាន \(n = 12\) កំពូល។

៣០លំហាត់ទី ៣០

ក្នុងបញ្ចកោណនិយ័ត \(ABCDE\) អង្កត់ទ្រូង \(AC\) និង \(BD\) កាត់គ្នាត្រង់ \(P\)។ គណនារង្វាស់មុំ \(\angle APB\)។

មើលដំណោះស្រាយ

ក្នុងបញ្ចកោណនិយ័ត \(ABCDE\) មុំក្នុងគឺ \(108^\circ\)។ \(\Delta ABC\) សមបាតត្រង់ \(B\) មាន \(\angle B = 108^\circ \implies \angle BAC = \angle BCA = \dfrac{180^\circ - 108^\circ}{2} = 36^\circ\)។ ស្រដៀងគ្នា \(\Delta BCD\) សមបាតត្រង់ \(C \implies \angle CBD = \angle CDB = 36^\circ\)។ ក្នុង \(\Delta PBC\) ៖

\[\angle BPC = 180^\circ - (36^\circ + 36^\circ) = 108^\circ\]
មុំជាប់គ្នាបន្ថែម \(\angle APB = 180^\circ - 108^\circ = 72^\circ\)។

៣១លំហាត់ទី ៣១

បង្ហាញថាក្នុងបញ្ចកោណនិយ័ត អង្កត់ទ្រូងទាំងប្រាំមានប្រវែងស្មើគ្នាទាំងអស់។

មើលដំណោះស្រាយ

ក្នុងបញ្ចកោណនិយ័ត ត្រីកោណដែលបង្កើតដោយជ្រុងពីរជាប់គ្នានិងអង្កត់ទ្រូងមួយ ដូចជា \(\Delta ABC, \Delta BCD, \dots\) សុទ្ធតែប៉ុនគ្នា (តាមករណី ជ.ម.ជ ព្រោះជ្រុងស្មើគ្នា និងមុំ \(108^\circ\) ដូចគ្នា)។ ដូច្នេះ អង្កត់ទ្រូងដែលជាជ្រុងទីបីនៃត្រីកោណទាំងនោះមានប្រវែងស្មើគ្នាទាំងអស់ ៖

\[AC = BD = CE = DA = EB\]

៣២លំហាត់ទី ៣២

គេភ្ជាប់កំពូលឆ្លាស់គ្នានៃឆកោណនិយ័ត \(ABCDEF\) (គឺ \(A, C, E\))។ បង្ហាញថា \(\Delta ACE\) ជាត្រីកោណសម័ង្ស។

មើលដំណោះស្រាយ

ក្នុងឆកោណនិយ័ត \(ABCDEF\) ជ្រុងទាំងអស់ស្មើគ្នា និងមុំក្នុងទាំងអស់ស្មើ \(120^\circ\)។ ត្រីកោណ \(ABC, CDE, EFA\) ប៉ុនគ្នាតាមករណី ជ.ម.ជ ៖ \(AB=BC=CD=DE=EF=FA\) និង \(\angle B = \angle D = \angle F = 120^\circ\)។ នាំឱ្យជ្រុងទីបី \(AC = CE = EA\)។ ដូចនេះ \(\Delta ACE\) មានជ្រុងទាំងបីស្មើគ្នា គឺជាត្រីកោណសម័ង្ស។

៣៣លំហាត់ទី ៣៣

ពីលំហាត់ ៣២ គណនាផលធៀបផ្ទៃក្រឡារវាង \(\Delta ACE\) និងឆកោណនិយ័ត \(ABCDEF\)។

មើលដំណោះស្រាយ

តាងជ្រុងឆកោណគឺ \(a\)។ ផ្ទៃក្រឡាឆកោណគឺ \(S_6 = \dfrac{3\sqrt{3}}{2} a^2\)។ ប្រវែង \(AC = 2a \sin 60^\circ = a\sqrt{3}\)។ ផ្ទៃក្រឡាត្រីកោណសម័ង្ស \(\Delta ACE\) ជ្រុង \(a\sqrt{3}\) គឺ ៖

\[S_{\Delta} = \dfrac{\sqrt{3}}{4}(a\sqrt{3})^2 = \dfrac{3\sqrt{3}}{4} a^2\]
ផលធៀបផ្ទៃក្រឡាគឺ ៖
\[\dfrac{S_{\Delta}}{S_6} = \dfrac{\frac{3\sqrt{3}}{4} a^2}{\frac{3\sqrt{3}}{2} a^2} = \dfrac{1}{2}\]

៣៤លំហាត់ទី ៣៤

ដោយជ្រុងនីមួយៗនៃឆកោណនិយ័តជាជ្រុងនៃការេដែលគូសនៅខាងក្រៅឆកោណ។ គេភ្ជាប់កំពូលការេជាប់គ្នា។ បង្ហាញថារូបដែលកើតឡើងជាពហុកោណនិយ័ត \(12\) ជ្រុង (Dodecagon)។

មើលដំណោះស្រាយ

នៅកំពូលនីមួយៗនៃឆកោណ មានមុំក្នុង \(120^\circ\) និងមុំការេពីរ \(90^\circ \times 2 = 180^\circ\)។ មុំដែលនៅសល់ជុំវិញកំពូលគឺ \(360^\circ - (120^\circ + 180^\circ) = 60^\circ\)។ ត្រីកោណដែលភ្ជាប់កំពូលការេជាប់គ្នាជាត្រីកោណសមបាតមានជ្រុងស្មើជ្រុងការេ និងមុំកំពូល \(60^\circ\) នាំឱ្យជាត្រីកោណសម័ង្ស។ ដូច្នេះជ្រុងថ្មីទាំងអស់ស្មើនឹងជ្រុងការេ និងមុំក្នុងនៃពហុកោណថ្មីស្មើ \(90^\circ + 60^\circ = 150^\circ\)។ ដោយមុំក្នុង \(150^\circ\) នោះចំនួនជ្រុងគឺ \(n = \dfrac{360^\circ}{180^\circ - 150^\circ} = 12\) ជ្រុងនិយ័ត។

៣៥លំហាត់ទី ៣៥

មុំក្រៅនៃអដ្ឋកោណនិយ័តមួយតិចជាងមុំក្រៅមួយនៃពហុកោណនិយ័តមួយចំនួន \(27^\circ\)។ គណនាចំនួនជ្រុង \(n\) នៃពហុកោណនោះ។

មើលដំណោះស្រាយ

មុំក្រៅនៃអដ្ឋកោណនិយ័តគឺ \(\beta_8 = \dfrac{360^\circ}{8} = 45^\circ\)។ មុំក្រៅនៃពហុកោណ \(n\) ជ្រុងគឺ \(\beta_n\) ដោយ \(\beta_8 = \beta_n - 27^\circ\) ៖

\[\beta_n = 45^\circ + 27^\circ = 72^\circ\]
ចំនួនជ្រុង \(n\) គឺ ៖
\[n = \dfrac{360^\circ}{72^\circ} = 5 \text{ ជ្រុង (បញ្ចកោណនិយ័ត)}\]

៣៦លំហាត់ទី ៣៦

មុំក្រៅនៃពហុកោណនិយ័តមួយច្រើនជាងមុំក្រៅនៃឆកោណនិយ័តចំនួន \(30^\circ\)។ គណនាចំនួនជ្រុងនៃពហុកោណនោះ។

មើលដំណោះស្រាយ

មុំក្រៅនៃឆកោណនិយ័តគឺ \(\beta_6 = \dfrac{360^\circ}{6} = 60^\circ\)។ មុំក្រៅនៃពហុកោណ \(n\) ជ្រុងគឺ \(\beta_n = 60^\circ + 30^\circ = 90^\circ\)។ ចំនួនជ្រុងគឺ ៖

\[n = \dfrac{360^\circ}{90^\circ} = 4 \text{ ជ្រុង (ការេ)}\]

៣៧លំហាត់ទី ៣៧

គណនាផលបូករង្វាស់មុំកំពូលទាំងប្រាំនៃផ្កាយប្រាំ (\(5\)-pointed star)។

មើលដំណោះស្រាយ

ផ្កាយប្រាំ (\(5\)-pointed star) បង្កើតដោយការបន្តជ្រុងនៃបញ្ចកោណនិយ័ត។ នៅកំពូលនីមួយៗ មុំកំពូលស្មើនឹង \(180^\circ - 2 \times 72^\circ = 36^\circ\)។ ផលបូករង្វាស់មុំកំពូលទាំងប្រាំគឺ ៖

\[S = 5 \times 36^\circ = 180^\circ\]

៣៨លំហាត់ទី ៣៨

គណនាផលបូករង្វាស់មុំកំពូលទាំង \(n\) នៃផ្កាយ \(n\) កំពូល។

មើលដំណោះស្រាយ

ចំពោះផ្កាយ \(n\) កំពូលធម្មតា ផលបូកមុំកំពូលទាំង \(n\) គឺ ៖

\[S = (n - 4) \times 180^\circ\]
ចំពោះ \(n = 5\) ៖ \(S = (5-4) \times 180^\circ = 180^\circ\)។ ចំពោះ \(n = 6\) (Star of David) ផលបូកគឺ \(2 \times 180^\circ = 360^\circ\)។

៣៩លំហាត់ទី ៣៩

ក្នុងអដ្ឋកោណនិយ័ត \(ABCDEFGH\) គណនារង្វាស់មុំ \(\angle ABC, \angle ABD, \angle ABE\)។

មើលដំណោះស្រាយ

ក្នុងអដ្ឋកោណនិយ័ត \(ABCDEFGH\) ចារឹកក្នុងរង្វង់ ៖

  • \(\angle ABC = \dfrac{(8-2) \times 180^\circ}{8} = 135^\circ\)

  • \(\Delta ABC\) សមបាត \(\implies \angle BAC = \angle BCA = \dfrac{180^\circ - 135^\circ}{2} = 22.5^\circ\)

  • \(\angle ABD = 135^\circ - 2 \times 22.5^\circ = 90^\circ\) (ឬតាមមុំចារឹកក្នុងកាត់ធ្នូ \(4\) ចំណែក)

  • \(\angle ABE = 135^\circ - 22.5^\circ = 112.5^\circ\)

៤០លំហាត់ទី ៤០

គណនាកាំរង្វង់ចារឹកក្រៅ \(R\) និងកាំរង្វង់ចារឹកក្នុង \(r\) នៃឆកោណនិយ័តដែលមានជ្រុង \(a\)។

មើលដំណោះស្រាយ

ក្នុងឆកោណនិយ័តជ្រុង \(a\) ៖

  • កាំរង្វង់ចារឹកក្រៅស្មើនឹងប្រវែងជ្រុង ៖ \(R = a\)

  • កាំរង្វង់ចារឹកក្នុងស្មើនឹងកម្ពស់ត្រីកោណសម័ង្ស ៖ \(r = \dfrac{a\sqrt{3}}{2}\)

៤១លំហាត់ទី ៤១

រកចំនួនជ្រុងនៃពហុកោណនិយ័តពីរ ដែលផលធៀបរវាងចំនួនជ្រុងគឺ \(1:2\) និងផលធៀបរវាងមុំក្នុងគឺ \(3:4\)។

មើលដំណោះស្រាយ

តាងចំនួនជ្រុងគឺ \(n\) និង \(2n\)។ ផលធៀបមុំក្នុង ៖

\[\dfrac{\frac{(n-2)180}{n}}{\frac{(2n-2)180}{2n}} = \dfrac{2(n-2)}{2n-2} = \dfrac{n-2}{n-1} = \dfrac{3}{4}\]
\[4(n-2) = 3(n-1) \implies 4n - 8 = 3n - 3 \implies n = 5\]
ដូចនេះ ពហុកោណទាំងពីរមានចំនួនជ្រុងគឺ \(5\) ជ្រុង និង \(10\) ជ្រុង។

៤២លំហាត់ទី ៤២

រកចំនួនជ្រុងនៃពហុកោណនិយ័តពីរ ដែលផលធៀបរវាងចំនួនជ្រុងគឺ \(2:3\) និងផលធៀបរវាងមុំក្រៅគឺ \(3:2\)។

មើលដំណោះស្រាយ

តាងចំនួនជ្រុងគឺ \(2k\) និង \(3k\)។ មុំក្រៅគឺ \(\beta_1 = \dfrac{360^\circ}{2k}\) និង \(\beta_2 = \dfrac{360^\circ}{3k}\)។ ផលធៀបមុំក្រៅ ៖ \(\dfrac{\beta_1}{\beta_2} = \dfrac{3k}{2k} = \dfrac{3}{2}\) ផ្ទៀងផ្ទាត់ជានិច្ចចំពោះគ្រប់ \(k\)។ ដោយជាពហុកោណសាមញ្ញ និងសមាមាត្រជ្រុង \(2:3\) ករណីតូចបំផុតគឺ \(n_1 = 4\) និង \(n_2 = 6\) (ការេ និងឆកោណ)។

៤៣លំហាត់ទី ៤៣

គេកាត់ជ្រុងទាំងបួននៃការេដែលមានជ្រុង \(a\) ដោយត្រីកោណកែងសមបាតបួនដើម្បីបានអដ្ឋកោណនិយ័ត។ គណនាប្រវែងជ្រុងនៃអដ្ឋកោណនិយ័តនោះ។

មើលដំណោះស្រាយ

តាងការេធំមានជ្រុង \(x\)។ កាត់ត្រីកោណកែងសមបាតជ្រុង \(y\) ចេញពីជ្រុងទាំង ៤។ ជ្រុងអដ្ឋកោណគឺ \(a = y\sqrt{2} = x - 2y\)។ \(y = \dfrac{a}{\sqrt{2}} = \dfrac{a\sqrt{2}}{2}\)។ ប្រវែងជ្រុងការេគឺ \(x = a + 2y = a + a\sqrt{2} = a(1+\sqrt{2})\)។ ច្រាសមកវិញ បើការេដើមមានជ្រុង \(L\) នោះ \(a = \dfrac{L}{1+\sqrt{2}} = L(\sqrt{2}-1)\)។

៤៤លំហាត់ទី ៤៤

ពហុកោណប៉ោងមួយមាន \(n\) ជ្រុង។ បើគេបង្កើនចំនួនជ្រុងឡើង \(2\) នោះផលបូកមុំក្នុងកើនឡើងប៉ុន្មានដឺក្រេ?

មើលដំណោះស្រាយ

ផលបូកមុំក្នុងដើម ៖ \(S_n = (n-2) \times 180^\circ\)។ ផលបូកមុំក្នុងថ្មី ៖ \(S_{n+2} = (n+2-2) \times 180^\circ = n \times 180^\circ\)។ កំណើនផលបូកមុំក្នុងគឺ ៖

\[\Delta S = S_{n+2} - S_n = 2 \times 180^\circ = 360^\circ\]

៤៥លំហាត់ទី ៤៥

ពហុកោណប៉ោងមួយមាន \(n\) ជ្រុង។ បើគេបង្កើនចំនួនជ្រុងឡើង \(1\) នោះចំនួនអង្កត់ទ្រូងកើនឡើងប៉ុន្មាន?

មើលដំណោះស្រាយ

ចំនួនអង្កត់ទ្រូងដើម ៖ \(D_n = \dfrac{n(n-3)}{2}\)។ ចំនួនអង្កត់ទ្រូងថ្មី ៖ \(D_{n+1} = \dfrac{(n+1)(n-2)}{2}\)។ កំណើនចំនួនអង្កត់ទ្រូងគឺ ៖

\[\Delta D = \dfrac{n^2 - n - 2 - (n^2 - 3n)}{2} = \dfrac{2n - 2}{2} = n - 1\]
ដូចនេះ ចំនួនអង្កត់ទ្រូងកើនឡើង \((n-1)\)។

៤៦លំហាត់ទី ៤៦

បង្ហាញថាគ្មានពហុកោណប៉ោងណាដែលអាចមានមុំស្រួចច្រើនជាង \(3\) បានឡើយ។

មើលដំណោះស្រាយ

បើពហុកោណមានមុំស្រួចមួយ នោះមុំក្រៅជាប់គ្នានឹងជាមុំទាល (\(> 90^\circ\))។ បើពហុកោណមានមុំស្រួច \(4\) ឬច្រើនជាង នោះវានឹងមានមុំក្រៅទាលចំនួន \(4\) ឬច្រើនជាង។ ផលបូកមុំក្រៅទាំង \(4\) នោះគឺ \(> 4 \times 90^\circ = 360^\circ\) ដែលផ្ទុយពីទ្រឹស្តីបទផលបូកមុំក្រៅស្មើ \(360^\circ\)។ ដូចនេះ ពហុកោណប៉ោងមិនអាចមានមុំស្រួចលើសពី \(3\) ឡើយ។

៤៧លំហាត់ទី ៤៧

បង្ហាញថាផលបូករង្វាស់មុំក្នុងនៃពហុកោណមួយស្មើនឹងផលបូកមុំក្នុងនៃត្រីកោណ \((n-2)\) ដែលបំបែកចេញពីកំពូលមួយ។

មើលដំណោះស្រាយ

ជ្រើសរើសកំពូលមួយនៃពហុកោណ \(n\) ជ្រុង។ គូសអង្កត់ទ្រូងទាំងអស់ចេញពីកំពូលនោះបាន \((n-3)\) អង្កត់ទ្រូង។ អង្កត់ទ្រូងទាំងនោះចែកពហុកោណជា \((n-2)\) ត្រីកោណដែលមិនត្រួតស៊ីគ្នា។ ផលបូកមុំក្នុងនៃត្រីកោណនីមួយៗគឺ \(180^\circ\)។ ដូច្នេះ ផលបូកមុំក្នុងនៃពហុកោណស្មើនឹងផលបូកមុំក្នុងនៃត្រីកោណទាំង \((n-2)\) គឺ \((n-2) \times 180^\circ\)។

៤៨លំហាត់ទី ៤៨

គណនាបរិមាត្រ និងផ្ទៃក្រឡានៃពហុកោណនិយ័ត \(n\) ជ្រុងចារឹកក្នុងរង្វង់កាំ \(R\)។

មើលដំណោះស្រាយ

ពហុកោណនិយ័ត \(n\) ជ្រុងចារឹកក្នុងរង្វង់កាំ \(R\) ៖ មុំផ្ចិត \(\theta = \dfrac{360^\circ}{n}\)។ ជ្រុងនីមួយៗ \(a = 2R \sin\left(\dfrac{180^\circ}{n}\right)\)។ បរិមាត្រ ៖ \(P = n a = 2nR \sin\left(\dfrac{180^\circ}{n}\right)\)។ ផ្ទៃក្រឡា ៖ \(S = \dfrac{1}{2} n R^2 \sin\left(\dfrac{360^\circ}{n}\right)\)។

៤៩លំហាត់ទី ៤៩

សរសេររៀបរាប់អំពីរបកគំហើញរបស់ Gauss លើការសង់ពហុកោណនិយ័ត \(17\) ជ្រុងដោយបន្ទាត់ និងដែកឈាន។

មើលដំណោះស្រាយ

នៅឆ្នាំ ១៧៩៦ ក្នុងវ័យ ១៩ ឆ្នាំ Carl Friedrich Gauss បានស្រាយបញ្ជាក់ថា ពហុកោណនិយ័ត \(17\) ជ្រុងអាចសង់បានដោយប្រើតែបន្ទាត់ត្រង់ និងដែកឈាន (Compass and Straightedge)។ គាត់បានរកឃើញទ្រឹស្តីបទ Gauss-Wantzel ថាពហុកោណនិយ័ត \(n\) ជ្រុងអាចសង់បាន លុះត្រាតែ \(n\) ជាផលគុណនៃស្វ័យគុណនៃ ២ និងចំនួនបឋម Fermat ផ្សេងៗគ្នា (\(F_k = 2^{2^k} + 1\))។ របកគំហើញនេះបានដោះស្រាយប្រស្នាធរណីមាត្រក្រិកបុរាណដែលមានអាយុកាលជាង ២០០០ ឆ្នាំ។

៥០លំហាត់ទី ៥០

សង្ខេបលក្ខណៈទូទៅនៃពហុកោណនិយ័ត និងទំនាក់ទំនងរវាងមុំក្នុង មុំក្រៅ និងចំនួនអង្កត់ទ្រូង។

មើលដំណោះស្រាយ

សង្ខេបលក្ខណៈគ្រឹះនៃពហុកោណនិយ័ត \(n\) ជ្រុង ៖

  1. ចំនួនអង្កត់ទ្រូង ៖ \(D = \dfrac{n(n-3)}{2}\)

  2. ផលបូកមុំក្នុង ៖ \(S_{\text{int}} = (n-2) \times 180^\circ\)

  3. មុំក្នុងនីមួយៗ ៖ \(\alpha = \dfrac{(n-2) \times 180^\circ}{n}\)

  4. ផលបូកមុំក្រៅ ៖ \(S_{\text{ext}} = 360^\circ\)

  5. មុំក្រៅនីមួយៗ ៖ \(\beta = \dfrac{360^\circ}{n}\)

  6. ទំនាក់ទំនងមុំ ៖ \(\alpha + \beta = 180^\circ\)

សំណួរពហុជ្រើសរើស

ជ្រើសរើសចម្លើយត្រឹមត្រូវតែមួយ រួចចុច «ពិនិត្យ»។ ចម្លើយរបស់អ្នកត្រូវបានរក្សាទុកក្នុងកុំព្យូទ័រនេះ។
