  • វិធាន Al-Jabr (សតវត្សទី ៩) ៖ លោក Al-Khwarizmi បានបង្កើតវិធាន Al-Jabr (ការប្តូរតួអវិជ្ជមានទៅអង្គម្ខាងទៀតដោយប្តូរសញ្ញា) និង Al-Muqabala (ការលុបតួដូចគ្នាចេញពីអង្គទាំងពីរ) ដែលជាគ្រឹះពីជគណិតរហូតដល់សព្វថ្ងៃ។

សមីការដឺក្រេទី១ មានមួយអញ្ញាត

សមីការដឺក្រេទី១ មានមួយអញ្ញាត គឺជាសមីការដែលអាចសរសេរជាទម្រង់ទូទៅ ៖

\[ax + b = 0 \quad{} (a \ne 0)\]
ដែល \(x\) ជាអញ្ញាត (អថេរ) ហើយ \(a, b\) ជាចំនួនពិតដែលបានស្គាល់ (\(a\) ជាមេគុណនៃ \(x\) និង \(b\) ជាតួថេរ)។

ដំណោះស្រាយសមីការ \(ax + b = 0\)

  • បើ \(a \ne 0\) ៖ សមីការមានឫសតែមួយគត់គឺ \(x = -\dfrac{b}{a}\)។

  • បើ \(a = 0\) និង \(b \ne 0\) ៖ សមីការទៅជា \(0x = -b\) គ្មានឫស (សំណុំចម្លើយ \(S = \emptyset\))។

  • បើ \(a = 0\) និង \(b = 0\) ៖ សមីការទៅជា \(0x = 0\) ផ្ទៀងផ្ទាត់ចំពោះគ្រប់ចំនួនពិត \(x\) (មានឫសរាប់មិនអស់ \(S = \mathbb{R}\))។

ដោះស្រាយសមីការខាងក្រោម ៖

  1. \(5x - 7 = 2x + 8\)

  2. \(3(2x - 1) - 2(x - 4) = 17\)

ដំណោះស្រាយ

  • \(5x - 7 = 2x + 8 \iff 5x - 2x = 8 + 7 \iff 3x = 15 \iff x = \dfrac{15}{3} = 5\)

  • ដូចនេះ សមីការមានឫស \(x = 5\)។

  • \(3(2x - 1) - 2(x - 4) = 17 \iff 6x - 3 - 2x + 8 = 17\)

  • \(\iff 4x + 5 = 17 \iff 4x = 17 - 5 \iff 4x = 12 \iff x = 3\)

  • ដូចនេះ សមីការមានឫស \(x = 3\)។

ដើម្បីដោះស្រាយសមីការដែលមានភាគបែងជាលេខ គេត្រូវ ៖

  1. រកភាគបែងរួមតូចបំផុត (LCM) នៃភាគបែងទាំងអស់។

  3. ពន្លាតវង់ក្រចក និងលើកតួមានអញ្ញាតទៅអង្គម្ខាង តួថេរទៅអង្គម្ខាងទៀត រួចទាញរកតម្លៃ \(x\)។

ដោះស្រាយសមីការ ៖ \(\dfrac{2x - 1}{3} - \dfrac{x - 2}{4} = \dfrac{x + 5}{6}\)

ដំណោះស្រាយ

  • ភាគបែងរួមតូចបំផុតនៃ \(3, 4, 6\) គឺ \(\text{LCM}(3, 4, 6) = 12\)។

  • គុណអង្គទាំងពីរនៃសមីការនឹង \(12\) ៖

    \[12\left(\frac{2x - 1}{3}\right) - 12\left(\frac{x - 2}{4}\right) = 12\left(\frac{x + 5}{6}\right)\]
    \[4(2x - 1) - 3(x - 2) = 2(x + 5)\]

  • ពន្លាតវង់ក្រចក និងដោះស្រាយ ៖

    \[8x - 4 - 3x + 6 = 2x + 10 \iff 5x + 2 = 2x + 10\]
    \[\iff 5x - 2x = 10 - 2 \iff 3x = 8 \iff x = \frac{8}{3}\]

  • ដូចនេះ សមីការមានឫស \(x = \dfrac{8}{3}\)។

ផលគុណនៃពីរកត្តាស្មើសូន្យ លុះត្រាតែកត្តាណាមួយស្មើសូន្យ ៖

\[A \times B = 0 \iff A = 0 \quad{} \text{ឬ} \quad{} B = 0\]

ឧទាហរណ៍

ដោះស្រាយសមីការផលគុណកត្តាខាងក្រោម ៖

  1. \((2x - 5)(3x + 6) = 0\)

  2. \((x - 3)(2x + 1) + (x - 3)(x + 4) = 0\)

ដំណោះស្រាយ

  • \((2x - 5)(3x + 6) = 0 \iff 2x - 5 = 0 \quad{} \) ឬ \( \quad{} 3x + 6 = 0\)

    • \(2x - 5 = 0 \iff 2x = 5 \iff x = \dfrac{5}{2}\)

    • \(3x + 6 = 0 \iff 3x = -6 \iff x = -2\)

  • ដូចនេះ សមីការមានឫសពីរគឺ \(x = \dfrac{5}{2}\) និង \(x = -2\)។

  • ដាក់ជាផលគុណកត្តាដោយទាញកត្តារួម \((x - 3)\) ៖

    \[(x - 3)[(2x + 1) + (x + 4)] = 0 \iff (x - 3)(3x + 5) = 0\]
    \[\iff x - 3 = 0 \quad{} \text{ឬ} \quad{} 3x + 5 = 0 \iff x = 3 \quad{} \text{ឬ} \quad{} x = -\frac{5}{3}\]

  • ដូចនេះ សមីការមានឫសពីរគឺ \(x = 3\) និង \(x = -\dfrac{5}{3}\)។

  2. \((2x - 1)(x + 2) - (2x - 1)(3x - 5) = 0\)

ដើម្បីដោះស្រាយចំណោទដោយប្រើសមីការ គេត្រូវអនុវត្តតាម ៥ ជំហាន ៖

  2. បកប្រែប្រធានជាកន្សោមពីជគណិត ៖ សរសេរបរិមាណដទៃទៀតជាអនុគមន៍នៃ \(x\)។

  3. បង្កើតសមីការ ៖ ផ្អែកលើទំនាក់ទំនងដែលប្រធានបានកំណត់។

  4. ដោះស្រាយសមីការ ៖ រកតម្លៃ \(x\)។

  5. ផ្ទៀងផ្ទាត់ និងឆ្លើយ ៖ ពិនិត្យថាតើតម្លៃ \(x\) ស្របតាមលក្ខខណ្ឌជាក់ស្ដែង រួចសរសេរចម្លើយ។

ចតុកោណកែងមួយមានបរិមាត្រ \(48\,\text{cm}\)។ ប្រវែងបណ្តោយវែងជាងទទឹង \(4\,\text{cm}\)។ គណនាទទឹង បណ្តោយ និងផ្ទៃក្រឡានៃចតុកោណកែងនោះ។

ដំណោះស្រាយ

  • ជំហានទី ១ (ជ្រើសរើសអញ្ញាត) ៖ តាង \(x\) ជាទទឹងនៃចតុកោណកែង (\(x > 0\), គិតជា \(\text{cm}\))។

  • ជំហានទី ២ (បកប្រែកន្សោម) ៖ នោះបណ្តោយគឺ \(x + 4\) (គិតជា \(\text{cm}\))។

  • ជំហានទី ៣ (បង្កើតសមីការ) ៖ រូបមន្តបរិមាត្រគឺ \(P = 2(\) បណ្តោយ \( + \) ទទឹង \()\) ៖

    \[2[(x + 4) + x] = 48\]

  • ជំហានទី ៤ (ដោះស្រាយសមីការ) ៖

    \[2(2x + 4) = 48 \iff 4x + 8 = 48 \iff 4x = 40 \iff x = 10\]

  • ជំហានទី ៥ (ផ្ទៀងផ្ទាត់ និងឆ្លើយ) ៖

    • ទទឹងនៃចតុកោណកែងគឺ \(10\,\text{cm}\)

    • បណ្តោយនៃចតុកោណកែងគឺ \(10 + 4 = 14\,\text{cm}\)

    • ផ្ទៀងផ្ទាត់បរិមាត្រ ៖ \(2(14 + 10) = 48\,\text{cm}\) (ពិត)

    • ផ្ទៃក្រឡាចតុកោណកែង ៖ \(S = 14 \times 10 = 140\,\text{cm}^2\)

សិស្សរៃអង្គាសប្រាក់ ៖ តាង \(n\) ជាចំនួនសិស្ស ៖ \(3n + 4 = 4n - 3 \implies n = 7\) នាក់។ តម្លៃបាល់ \(3(7) + 4 = 25\,\$\)។

កម្មករពីរនាក់ធ្វើការងារមួយជាមួយគ្នាចប់ក្នុងរយៈពេល \(6\) ថ្ងៃ។ បើកម្មករទីមួយធ្វើការតែម្នាក់ឯងត្រូវចំណាយពេល \(10\) ថ្ងៃទើបចប់។ តើកម្មករទីពីរធ្វើការតែម្នាក់ឯងត្រូវចំណាយពេលប៉ុន្មានថ្ងៃ?

មើលដំណោះស្រាយ

កម្មករធ្វើការងារ ៖ \(\frac{1}{10} + \frac{1}{x} = \frac{1}{6} \implies \frac{1}{x} = \frac{1}{6} - \frac{1}{10} = \frac{2}{30} = \frac{1}{15} \implies x = 15\,\) ថ្ងៃ ។

៣៨លំហាត់ទី ៣៨

ទុយោទឹកពីរបង្ហូរទឹកចូលអាងមួយ។ បើបើកទុយោទាំងពីរព្រមគ្នា ទឹកពេញអាងក្នុងរយៈពេល \(4\) ម៉ោង។ បើបើកតែទុយោទីមួយ ទឹកពេញអាងក្នុងរយៈពេល \(6\) ម៉ោង។ តើបើកតែទុយោទីពីរត្រូវចំណាយពេលប៉ុន្មានម៉ោងទើបពេញអាង?

មើលដំណោះស្រាយ

ទុយោទឹក ៖ \(\frac{1}{6} + \frac{1}{y} = \frac{1}{4} \implies \frac{1}{y} = \frac{1}{4} - \frac{1}{6} = \frac{1}{12} \implies y = 12\,\) ម៉ោង ។

៣៩លំហាត់ទី ៣៩

អ្នកជំនួញម្នាក់បានទិញសៀវភៅមួយចំនួនអស់ប្រាក់ \(120\,\$\)។ បើសៀវភៅមួយក្បាលបញ្ចុះតម្លៃ \(1\,\$\) នោះគាត់អាចទិញបានសៀវភៅបន្ថែម \(4\) ក្បាលទៀតលើប្រាក់ដដែល។ រកចំនួនសៀវភៅដែលគាត់បានទិញ។

មើលដំណោះស្រាយ

ទិញសៀវភៅ ៖ \(\frac{120}{x-1} - \frac{120}{x} = 4 \implies \frac{120}{x(x-1)} = 4 \implies x(x-1) = 30 \implies x = 6\) ក្បាល។

៤០លំហាត់ទី ៤០

ពូហេងមានប្រាក់សរុប \(8000\,\$\)។ គាត់បានយកប្រាក់មួយផ្នែកទៅដាក់ធនាគារក្នុងអត្រាការប្រាក់ \(5\%\) និងប្រាក់ដែលនៅសល់ដាក់ក្នុងអត្រាការប្រាក់ \(7\%\) ក្នុងមួយឆ្នាំ។ ក្នុងមួយឆ្នាំគាត់ទទួលបានការប្រាក់សរុប \(460\,\$\)។ រកប្រាក់ដែលគាត់ដាក់ក្នុងអត្រានីមួយៗ។

មើលដំណោះស្រាយ

ការប្រាក់ ៖ \(0.05x + 0.07(8000 - x) = 460 \implies -0.02x + 560 = 460 \implies 0.02x = 100 \implies x = 5000\,\$\) ក្នុងអត្រា \(5\%\) និង \(3000\,\$\) ក្នុងអត្រា \(7\%\)។

៤១លំហាត់ទី ៤១

ដោះស្រាយ និងពិភាក្សាសមីការតាមប៉ារ៉ាម៉ែត្រ \(m\) ៖

\[mx - 4 = 2x + m\]

មើលដំណោះស្រាយ

សមីការប៉ារ៉ាម៉ែត្រ ៖ \((m-2)x = m+4\)

  • បើ \(m \ne 2\) ៖ \(x = \frac{m+4}{m-2}\)

  • បើ \(m = 2\) ៖ \(0x = 6\) (គ្មានឫស)

៤២លំហាត់ទី ៤២

ដោះស្រាយ និងពិភាក្សាសមីការតាមប៉ារ៉ាម៉ែត្រ \(m\) ៖

\[(m^2 - 1)x = m - 1\]

មើលដំណោះស្រាយ

សមីការប៉ារ៉ាម៉ែត្រ ៖ \((m-1)(m+1)x = m-1\)

  • បើ \(m \ne \pm 1\) ៖ \(x = \frac{1}{m+1}\)

  • បើ \(m = 1\) ៖ \(0x = 0\) (ឫសរាប់មិនអស់)

  • បើ \(m = -1\) ៖ \(0x = -2\) (គ្មានឫស)

៤៣លំហាត់ទី ៤៣

ដោះស្រាយសមីការ ៖

\[\frac{x-a}{b+c} + \frac{x-b}{c+a} + \frac{x-c}{a+b} = 3 \quad{} (a+b, b+c, c+a \ne 0)\]

មើលដំណោះស្រាយ

សមីការស៊ីមេទ្រី ៖ ដក \(1\) ពីប្រភាគនីមួយៗ ៖ \(\frac{x-(a+b+c)}{b+c} + \frac{x-(a+b+c)}{c+a} + \frac{x-(a+b+c)}{a+b} = 0\)

\[[x - (a+b+c)] \left( \frac{1}{b+c} + \frac{1}{c+a} + \frac{1}{a+b} \right) = 0\]
\[\implies x = a + b + c\]

៤៤លំហាត់ទី ៤៤

ដោះស្រាយសមីការ ៖

\[\frac{x+1}{99} + \frac{x+2}{98} + \frac{x+3}{97} = \frac{x+4}{96} + \frac{x+5}{95} + \frac{x+6}{94}\]

មើលដំណោះស្រាយ

សមីការបូក \(1\) ៖ បូក \(1\) លើគ្រប់ប្រភាគ ៖ \(\frac{x+100}{99} + \frac{x+100}{98} + \frac{x+100}{97} = \frac{x+100}{96} + \frac{x+100}{95} + \frac{x+100}{94}\) \(\implies (x + 100) \times K = 0 \implies x = -100\)។

៤៥លំហាត់ទី ៤៥

ដោះស្រាយសមីការ ៖

\[(x - 1)^3 + (x - 2)^3 + (x - 3)^3 = 3(x - 1)(x - 2)(x - 3)\]

មើលដំណោះស្រាយ

ផលបូកគូបស្មើ \(3abc\) ៖ \(a^3+b^3+c^3 = 3abc \iff a+b+c = 0\) \((x-1) + (x-2) + (x-3) = 0 \implies 3x - 6 = 0 \implies x = 2\)។

៤៦លំហាត់ទី ៤៦

ដោះស្រាយសមីការ ៖

\[|2x - 3| = 7\]

មើលដំណោះស្រាយ

សមីការតម្លៃដាច់ខាត ៖ \(2x - 3 = 7 \implies 2x = 10 \implies x = 5\) \(2x - 3 = -7 \implies 2x = -4 \implies x = -2\) សំណុំចម្លើយ \(S = \{-2, 5\}\)។

៤៧លំហាត់ទី ៤៧

ដោះស្រាយសមីការ ៖

\[|x - 1| + |x - 4| = 3\]

មើលដំណោះស្រាយ

សមីការ \(|x-1| + |x-4| = 3\) ៖ តាមវិសមភាពត្រីកោណ \(|x-1| + |4-x| \ge |(x-1) + (4-x)| = 3\)។ សមភាពកើតឡើងលុះត្រាតែ \((x-1)(4-x) \ge 0 \iff 1 \le x \le 4\)។

៤៨លំហាត់ទី ៤៨

ដោះស្រាយសមីការ ៖

\[|x + 2| = 2x - 1\]

មើលដំណោះស្រាយ

សមីការ \(|x+2| = 2x-1\) ៖ លក្ខខណ្ឌ \(2x - 1 \ge 0 \iff x \ge 0.5\)។ \(x + 2 = 2x - 1 \implies x = 3\) (យក) \(x + 2 = -(2x - 1) \implies 3x = -1 \implies x = -1/3\) (មិនយក)។ ចម្លើយគឺ \(x = 3\)។

៤៩លំហាត់ទី ៤៩

ដោះស្រាយសមីការ ៖

\[(x^2 - 3x + 1)^2 - 3(x^2 - 3x + 1) + 2 = 0\]

មើលដំណោះស្រាយ

សមីការដឺក្រេទី ៤ ៖ តាង \(t = x^2 - 3x + 1\) ៖ \(t^2 - 3t + 2 = 0 \implies t = 1\) ឬ \(t = 2\)។

  • \(x^2 - 3x + 1 = 1 \implies x(x-3) = 0 \implies x = 0\) ឬ \(x = 3\)

  • \(x^2 - 3x + 1 = 2 \implies x^2 - 3x - 1 = 0 \implies x = \frac{3 \pm \sqrt{13}}{2}\)

៥០លំហាត់ទី ៥០

រកតម្លៃនៃ \(k\) ដើម្បីឱ្យសមីការ \(x^2 - 2(k+1)x + k^2 + 5 = 0\) មានឫសឌុប។ រកឫសឌុបនោះ។

មើលដំណោះស្រាយ

សមីការមានឫសឌុប ៖ \(\Delta' = (k+1)^2 - (k^2+5) = k^2 + 2k + 1 - k^2 - 5 = 2k - 4\) សមីការមានឫសឌុប \(\iff \Delta' = 0 \iff 2k - 4 = 0 \iff k = 2\)។ ឫសឌុបនោះគឺ \(x_0 = -\frac{b'}{a} = k+1 = 2+1 = 3\)។
