មេរៀនទាំងអស់
ប្រវត្តិនៃធរណីមាត្រវិភាគ និងតម្រុយកូអរដោនេ

ធរណីមាត្រវិភាគ (Analytic Geometry) គឺជាស្ពានចម្លងដ៏អស្ចារ្យដែលតភ្ជាប់ពិភពពីជគណិត និងពិភពធរណីមាត្រ ៖

  • លោក René Descartes (១៥៩៦-១៦៥០) ៖ ទស្សនវិទូ និងគណិតវិទូជនជាតិបារាំង បានបោះពុម្ពស្នាដៃអមតៈ La Géométrie ក្នុងឆ្នាំ ១៦៣៧ ដោយណែនាំនូវ «ប្រព័ន្ធកូអរដោនេដេកាត» (Cartesian Coordinate System)។ គំនិតបដិវត្តន៍នេះអនុញ្ញាតឱ្យគេតាងចំណុចធរណីមាត្រដោយគូនៃចំនួន \((x, y)\) និងតាងរាងធរណីមាត្រដោយសមីការពីជគណិត។

  • ការផ្សារភ្ជាប់នឹងទ្រឹស្តីបទពីតាគ័រ ៖ រូបមន្តចម្ងាយរវាងពីរចំណុចក្នុងប្លង់ មិនមែនជាអ្វីក្រៅពីការអនុវត្តផ្ទាល់នៃទ្រឹស្តីបទពីតាគ័រលើត្រីកោណកែងដែលបង្កើតឡើងដោយផលសងអាប់ស៊ីស (\(\Delta x\)) និងផលសងអរដោនេ (\(\Delta y\)) នោះឡើយ។

  • ការអនុវត្តក្នុងប្រព័ន្ធ GPS ទំនើប ៖ បច្ចេកវិទ្យាកំណត់ទីតាំងសកល (GPS) ប្រើប្រាស់រូបមន្តចម្ងាយកូអរដោនេនេះដើម្បីគណនាចម្ងាយពីផ្កាយរណបមកកាន់ទូរសព្ទដៃ ដែលអនុញ្ញាតឱ្យកំណត់ទីតាំងលើផែនដីបានយ៉ាងសុក្រឹត។

ចម្ងាយរវាងពីរចំណុចក្នុងប្លង់កូអរដោនេ

រូបមន្តចម្ងាយរវាងពីរចំណុច

ក្នុងតម្រុយអរតូណរម៉េ \((O, \vec{i}, \vec{j})\) ចម្ងាយរវាងពីរចំណុច \(A(x_1, y_1)\) និង \(B(x_2, y_2)\) កំណត់ដោយ ៖

\[AB = d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\]
ជាពិសេស ចម្ងាយពីគល់តម្រុយ \(O(0, 0)\) ទៅចំណុច \(M(x, y)\) គឺ ៖
\[OM = \sqrt{x^2 + y^2}\]

ឧទាហរណ៍

គណនាចម្ងាយរវាងចំណុច \(A(1, 2)\) និង \(B(4, 6)\)។

ដំណោះស្រាយ

អនុវត្តរូបមន្តចម្ងាយ ៖

\[AB = \sqrt{(4 - 1)^2 + (6 - 2)^2} = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5\]

ប្រតិបត្តិ

គណនាចម្ងាយរវាងពីរចំណុច ៖

  1. \(P(-2, 3)\) និង \(Q(1, -1)\)

  2. \(A(0, 0)\) និង \(B(8, -15)\)

កូអរដោនេចំណុចកណ្តាលនៃអង្កត់

កូអរដោនេចំណុចកណ្តាល

បើ \(M\) ជាចំណុចកណ្តាលនៃអង្កត់ \([AB]\) ដែល \(A(x_1, y_1)\) និង \(B(x_2, y_2)\) នោះកូអរដោនេនៃ \(M\) គឺ ៖

\[M\left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)\]

ឧទាហរណ៍

រកកូអរដោនេចំណុចកណ្តាល \(M\) នៃអង្កត់ \([AB]\) ដែល \(A(-3, 5)\) និង \(B(7, 1)\)។

ដំណោះស្រាយ

\[x_M = \frac{-3 + 7}{2} = \frac{4}{2} = 2 \quad{} ; \quad{} y_M = \frac{5 + 1}{2} = \frac{6}{2} = 3\]
ដូចនេះ ចំណុចកណ្តាលគឺ \(M(2, 3)\)។

ប្រតិបត្តិ

បើ \(M(3, 4)\) ជាចំណុចកណ្តាលនៃ \([AB]\) ដោយដឹងថា \(A(1, 2)\)។ ចូរកំណត់កូអរដោនេនៃចំណុច \(B\)។

អនុវត្តន៍ក្នុងធរណីមាត្រ ៖ ត្រីកោណ និងចតុកោណ

ការបញ្ជាក់ប្រភេទត្រីកោណ និងចតុកោណ

  • ត្រីកោណសមបាត ៖ មានជ្រុងពីរស្មើគ្នា (\(AB = AC\))។

  • ត្រីកោណសម័ង្ស ៖ មានជ្រុងទាំងបីស្មើគ្នា (\(AB = BC = CA\))។

  • ត្រីកោណកែង ៖ ផ្ទៀងផ្ទាត់ទ្រឹស្តីបទបញ្ច្រាសពីតាគ័រ (\(BC^2 = AB^2 + AC^2 \implies \angle A = 90^\circ\))។

  • ប្រលេឡូក្រាម ៖ អង្កត់ទ្រូងទាំងពីរ \([AC]\) និង \([BD]\) កាត់គ្នាត្រង់ចំណុចកណ្តាលរួម។

  • ចតុកោណកែង ៖ ជាប្រលេឡូក្រាមដែលមានអង្កត់ទ្រូងស្មើគ្នា (\(AC = BD\))។

១លំហាត់ទី ១

គណនាចម្ងាយរវាងពីរចំណុច \(A\) និង \(B\) ក្នុងករណីនីមួយៗ ៖

  1. \(A(3, 7)\) និង \(B(8, -5)\)

  2. \(A(-1, -2)\) និង \(B(3, 4)\)

  3. \(A(0, 0)\) និង \(B(8, -15)\)

  4. \(A(-2, 6)\) និង \(B(3, -6)\)

មើលដំណោះស្រាយ

គណនាចម្ងាយ \(AB\) ៖

  • \(A(3, 7), B(8, -5) \implies AB = \sqrt{(8-3)^2 + (-5-7)^2} = \sqrt{25 + 144} = \sqrt{169} = 13\)

  • \(A(-1, -2), B(3, 4) \implies AB = \sqrt{(3+1)^2 + (4+2)^2} = \sqrt{16 + 36} = \sqrt{52} = 2\sqrt{13}\)

  • \(A(0, 0), B(8, -15) \implies AB = \sqrt{8^2 + (-15)^2} = \sqrt{64 + 225} = \sqrt{289} = 17\)

  • \(A(-2, 6), B(3, -6) \implies AB = \sqrt{(3+2)^2 + (-6-6)^2} = \sqrt{25 + 144} = 13\)

២លំហាត់ទី ២

គណនាចម្ងាយរវាងពីរចំណុច \(A\) និង \(B\) ក្នុងករណីនីមួយៗ ៖

  1. \(A(-3, -5)\) និង \(B(-1, -8)\)

  2. \(A(5, 3)\) និង \(B(11, 11)\)

  3. \(A(9, 2)\) និង \(B(6, 8)\)

  4. \(A(5, -3)\) និង \(B(-2, 4)\)

មើលដំណោះស្រាយ

គណនាចម្ងាយ \(AB\) ៖

  • \(A(-3, -5), B(-1, -8) \implies AB = \sqrt{(-1+3)^2 + (-8+5)^2} = \sqrt{4 + 9} = \sqrt{13}\)

  • \(A(5, 3), B(11, 11) \implies AB = \sqrt{(11-5)^2 + (11-3)^2} = \sqrt{36 + 64} = \sqrt{100} = 10\)

  • \(A(9, 2), B(6, 8) \implies AB = \sqrt{(6-9)^2 + (8-2)^2} = \sqrt{9 + 36} = \sqrt{45} = 3\sqrt{5}\)

  • \(A(5, -3), B(-2, 4) \implies AB = \sqrt{(-2-5)^2 + (4+3)^2} = \sqrt{49 + 49} = \sqrt{98} = 7\sqrt{2}\)

៣លំហាត់ទី ៣

គណនាចម្ងាយរវាងពីរចំណុច \(A\) និង \(B\) ក្នុងករណីនីមួយៗ ៖

  1. \(A(2, 5)\) និង \(B(0, 0)\)

  2. \(A(-6, -3)\) និង \(B(2, 1)\)

  3. \(A(8, 7)\) និង \(B(8, -6)\)

  4. \(A(3, 12)\) និង \(B(7, 12)\)

មើលដំណោះស្រាយ

គណនាចម្ងាយ \(AB\) ៖

  • \(A(2, 5), B(0, 0) \implies AB = \sqrt{2^2 + 5^2} = \sqrt{29}\)

  • \(A(-6, -3), B(2, 1) \implies AB = \sqrt{(2+6)^2 + (1+3)^2} = \sqrt{64 + 16} = \sqrt{80} = 4\sqrt{5}\)

  • \(A(8, 7), B(8, -6) \implies AB = \sqrt{(8-8)^2 + (-6-7)^2} = \sqrt{169} = 13\)

  • \(A(3, 12), B(7, 12) \implies AB = \sqrt{(7-3)^2 + (12-12)^2} = \sqrt{16} = 4\)

៤លំហាត់ទី ៤

គណនាចម្ងាយរវាងពីរចំណុច \(A\) និង \(B\) ក្នុងករណីនីមួយៗ ៖

  1. \(A(100, -203)\) និង \(B(97, -200)\)

  2. \(A(-3, 8)\) និង \(B(-4, 7)\)

  3. \(A(2, 5)\) និង \(B(6, 2)\)

មើលដំណោះស្រាយ

គណនាចម្ងាយ \(AB\) ៖

  • \(A(100, -203), B(97, -200) \implies AB = \sqrt{(97-100)^2 + (-200+203)^2} = \sqrt{9 + 9} = 3\sqrt{2}\)

  • \(A(-3, 8), B(-4, 7) \implies AB = \sqrt{(-4+3)^2 + (7-8)^2} = \sqrt{1 + 1} = \sqrt{2}\)

  • \(A(2, 5), B(6, 2) \implies AB = \sqrt{(6-2)^2 + (2-5)^2} = \sqrt{16 + 9} = 5\)

៥លំហាត់ទី ៥

រកកូអរដោនេចំណុចកណ្តាលនៃអង្កត់ \([AB]\) ក្នុងលំហាត់ ១ ខាងលើ។

មើលដំណោះស្រាយ

  • \(A(3, 7), B(8, -5) \implies M\left(\frac{3+8}{2}, \frac{7-5}{2}\right) = M(5.5, 1)\)

  • \(A(-1, -2), B(3, 4) \implies M\left(\frac{-1+3}{2}, \frac{-2+4}{2}\right) = M(1, 1)\)

  • \(A(0, 0), B(8, -15) \implies M(4, -7.5)\)

  • \(A(5, 3), B(11, 11) \implies M(8, 7)\)

រកកូអរដោនេចំណុចកណ្តាលនៃអង្កត់ \([AB]\) ក្នុងលំហាត់ ៣ និង ៤ ខាងលើ។

  • \(A(3, 12), B(7, 12) \implies M(5, 12)\)

  • \(A(2, 5), B(6, 2) \implies M(4, 3.5)\)

បើ \(M(2, 3)\) ជាចំណុចកណ្តាលនៃ \([AB]\) ដោយ \(A(-1, 5)\)។ រកកូអរដោនេ \(B\)។

រកកូអរដោនេចុងម្ខាងទៀត ៖ \(M(2, 3)\) ជាចំណុចកណ្តាលនៃ \([AB]\) ដោយ \(A(-1, 5)\) ៖ \(x_M = \frac{x_A + x_B}{2} \implies 2 = \frac{-1 + x_B}{2} \implies x_B = 5\) \(y_M = \frac{y_A + y_B}{2} \implies 3 = \frac{5 + y_B}{2} \implies y_B = 1\) ដូចនេះ \(B(5, 1)\)។

៨លំហាត់ទី ៨

មើលដំណោះស្រាយ

រកចំណុចឆ្លុះ ៖ ចំណុចឆ្លុះ \(A'\) នៃ \(A(4, -2)\) ធៀបនឹង \(I(1, 3)\) ៖ \(I\) ជាចំណុចកណ្តាលនៃ \([AA']\) នាំឱ្យ ៖ \(x_{A'} = 2(1) - 4 = -2\) និង \(y_{A'} = 2(3) - (-2) = 8\) នាំឱ្យ \(A'(-2, 8)\)។

៩លំហាត់ទី ៩

១០លំហាត់ទី ១០

មើលដំណោះស្រាយ

១៣លំហាត់ទី ១៣

មើលដំណោះស្រាយ

រក \(y\) ដើម្បីឱ្យរត់ត្រង់ជួរ ៖ \(A(2, 1), B(4, 5), C(6, y)\) ៖ មេគុណប្រាប់ទិស \(a_{AB} = \frac{5-1}{4-2} = 2\)។ ដើម្បីឱ្យរត់ត្រង់ជួរ \(a_{BC} = \frac{y-5}{6-4} = 2 \implies y - 5 = 4 \implies y = 9\)។

មើលដំណោះស្រាយ

រកចំណុចលើអ័ក្សអាប់ស៊ីស ៖ \(M(x, 0)\) ស្មើចម្ងាយពី \(A(1, 3)\) និង \(B(5, 1)\) ៖ \(MA^2 = MB^2 \iff (x-1)^2 + 3^2 = (x-5)^2 + 1^2\) \(x^2 - 2x + 1 + 9 = x^2 - 10x + 25 + 1 \implies 8x = 16 \implies x = 2\) ដូចនេះ \(M(2, 0)\)។

មើលដំណោះស្រាយ

រកចំណុចលើអ័ក្សអរដោនេ ៖ \(N(0, y)\) ស្មើចម្ងាយពី \(A(-2, 1)\) និង \(B(4, 3)\) ៖ \(NA^2 = NB^2 \iff 2^2 + (y-1)^2 = (-4)^2 + (y-3)^2\) \(4 + y^2 - 2y + 1 = 16 + y^2 - 6y + 9 \implies 4y = 20 \implies y = 5\) ដូចនេះ \(N(0, 5)\)។

១៦លំហាត់ទី ១៦

គេឱ្យចំណុច \(A(1, 2), B(5, 3), C(7, 6)\)។ រកកូអរដោនេ \(D\) ដើម្បីឱ្យ \(ABCD\) ជាប្រលេឡូក្រាម។

មើលដំណោះស្រាយ

រក \(x\) ដើម្បីឱ្យ \(AB = 10\) ៖ \(A(2, 3), B(x, 9) \implies (x-2)^2 + (9-3)^2 = 100 \implies (x-2)^2 = 64 \implies x - 2 = \pm 8\) នាំឱ្យ \(x = 10\) ឬ \(x = -6\)។

២៩លំហាត់ទី ២៩

រកកូអរដោនេចំណុច \(P\) ដែលចែកអង្កត់ \([AB]\) តាមផលធៀប \(1:2\)។

មើលដំណោះស្រាយ

រកចំណុចចែកអង្កត់តាមផលធៀប ៖ \(P\) ចែក \([AB]\) តាមផលធៀប \(1:2\) ៖ \(x_P = \frac{2x_A + x_B}{3}, y_P = \frac{2y_A + y_B}{3}\)។

៣០លំហាត់ទី ៣០

សរសេររូបមន្ត Shoelace សម្រាប់គណនាផ្ទៃក្រឡាត្រីកោណតាមកូអរដោនេកំពូល។

មើលដំណោះស្រាយ

ផ្ទៃក្រឡាត្រីកោណតាមកូអរដោនេ (Shoelace Formula) ៖ \(S = \frac{1}{2}|x_A(y_B - y_C) + x_B(y_C - y_A) + x_C(y_A - y_B)|\)។

៣១លំហាត់ទី ៣១

គណនាផ្ទៃក្រឡាត្រីកោណដែលមានកំពូល \(A(1, 2), B(4, 6), C(5, 1)\)។

មើលដំណោះស្រាយ

គណនាផ្ទៃក្រឡាត្រីកោណ \(A(1, 2), B(4, 6), C(5, 1)\) ៖ \(S = \frac{1}{2}|1(6-1) + 4(1-2) + 5(2-6)| = \frac{1}{2}|5 - 4 - 20| = \frac{19}{2} = 9.5\) ឯកតាផ្ទៃ។

៣២លំហាត់ទី ៣២

បង្ហាញថាចំណុច \(A(0, 0), B(6, 0), C(4, 3), D(2, 3)\) បង្កើតបានជាចតុកោណព្នាយ។

មើលដំណោះស្រាយ

បង្ហាញចំណុច ៤ បង្កើតបានជាចតុកោណព្នាយ ៖ \(A(0, 0), B(6, 0), C(4, 3), D(2, 3)\) ៖ មេគុណប្រាប់ទិស \(AB\) និង \(CD\) សុទ្ធតែស្មើ \(0\) (ស្របគ្នា) នាំឱ្យ \(ABCD\) ជាចតុកោណព្នាយ។

៣៣លំហាត់ទី ៣៣

បង្ហាញថាចតុកោណព្នាយក្នុងលំហាត់ ៣២ ជាចតុកោណព្នាយសមបាត។

មើលដំណោះស្រាយ

បង្ហាញចតុកោណព្នាយសមបាត ៖ ពីលំហាត់ ៣២ ជ្រុងទ្រេត \(AD = \sqrt{2^2 + 3^2} = \sqrt{13}\) និង \(BC = \sqrt{(-2)^2 + 3^2} = \sqrt{13}\) ស្មើគ្នា នាំឱ្យជាចតុកោណព្នាយសមបាត។

៣៤លំហាត់ទី ៣៤

គណនាប្រវែងអង្កត់ទ្រូងទាំងពីរនៃចតុកោណព្នាយសមបាតខាងលើ។

មើលដំណោះស្រាយ

គណនាប្រវែងអង្កត់ទ្រូងចតុកោណព្នាយសមបាត ៖ \(AC = \sqrt{4^2 + 3^2} = 5\) និង \(BD = \sqrt{(2-6)^2 + 3^2} = 5\) ស្មើគ្នា។

៣៥លំហាត់ទី ៣៥

រកកូអរដោនេផ្ចិតរង្វង់កាត់តាម ៣ ចំណុច \(O(0, 0), A(4, 0), B(0, 4)\)។

មើលដំណោះស្រាយ

រកកូអរដោនេផ្ចិតរង្វង់កាត់តាម ៣ ចំណុច ៖ \(O(0, 0), A(4, 0), B(0, 4)\) ៖ ត្រីកោណកែងត្រង់ \(O\) ផ្ចិតជារង្វង់កណ្តាល \(AB\) គឺ \(I(2, 2)\) កាំ \(R = 2\sqrt{2}\)។

៣៦លំហាត់ទី ៣៦

កំណត់កូអរដោនេចំណុចឆ្លុះនៃ \(P(a, b)\) ធៀបនឹងបន្ទាត់ពុះទី ១ (\(y = x\))។

មើលដំណោះស្រាយ

កូអរដោនេចំណុចស៊ីមេទ្រីធៀបនឹងបន្ទាត់ពុះទី ១ (\(y = x\)) ៖ ចំណុចស៊ីមេទ្រីនៃ \(P(a, b)\) ធៀបនឹង \(y = x\) គឺ \(P'(b, a)\)។

៣៧លំហាត់ទី ៣៧

កំណត់កូអរដោនេចំណុចឆ្លុះនៃ \(P(a, b)\) ធៀបនឹងបន្ទាត់ពុះទី ២ (\(y = -x\))។

មើលដំណោះស្រាយ

កូអរដោនេចំណុចស៊ីមេទ្រីធៀបនឹងបន្ទាត់ពុះទី ២ (\(y = -x\)) ៖ ចំណុចស៊ីមេទ្រីនៃ \(P(a, b)\) ធៀបនឹង \(y = -x\) គឺ \(P'(-b, -a)\)។

៣៨លំហាត់ទី ៣៨

រកតម្លៃ \(k\) ដើម្បីឱ្យចម្ងាយរវាង \(A(1, k)\) និង \(B(3, 5)\) ស្មើនឹង \(\sqrt{20}\)។

មើលដំណោះស្រាយ

រក \(k\) ដើម្បីឱ្យចម្ងាយស្មើ \(\sqrt{20}\) ៖ \(A(1, k), B(3, 5) \implies (3-1)^2 + (5-k)^2 = 20 \implies 4 + (5-k)^2 = 20 \implies (5-k)^2 = 16\) នាំឱ្យ \(5 - k = \pm 4 \implies k = 1\) ឬ \(k = 9\)។

៣៩លំហាត់ទី ៣៩

គណនាប្រវែងកម្ពស់គូសចេញពី \(A\) នៃត្រីកោណសមបាត \(A(0, 4), B(-3, 0), C(3, 0)\)។

មើលដំណោះស្រាយ

ប្រវែងកម្ពស់នៃត្រីកោណសមបាត ៖ \(A(0, 4), B(-3, 0), C(3, 0)\) ៖ បាត \(BC = 6\) ចំណុចកណ្តាល \(O(0, 0)\) នាំឱ្យកម្ពស់ \(h = AO = 4\)។

៤០លំហាត់ទី ៤០

គណនាផ្ទៃក្រឡាត្រីកោណសមបាតក្នុងលំហាត់ ៣៩ ខាងលើ។

មើលដំណោះស្រាយ

ផ្ទៃក្រឡាត្រីកោណសមបាត ៖ \(S = \frac{1}{2} \times BC \times h = \frac{1}{2} \times 6 \times 4 = 12\) ឯកតាផ្ទៃ។

៤១លំហាត់ទី ៤១

រកកូអរដោនេចំណុចត្រីភាគទាំងពីរនៃអង្កត់ \([AB]\) ដែល \(A(1, 1), B(7, 4)\)។

មើលដំណោះស្រាយ

រកចំណុចត្រីភាគនៃអង្កត់ ៖ ចំណុច \(P\) និង \(Q\) ដែលចែក \([AB]\) ជា ៣ ស្មើគ្នា ៖ \(P = \left(\frac{2x_A+x_B}{3}, \frac{2y_A+y_B}{3}\right)\) និង \(Q = \left(\frac{x_A+2x_B}{3}, \frac{y_A+2y_B}{3}\right)\)។

៤២លំហាត់ទី ៤២

បង្ហាញវិសមភាពត្រីកោណ \(AB + BC \ge AC\) ក្នុងប្លង់កូអរដោនេ។

មើលដំណោះស្រាយ

វិសមភាពត្រីកោណក្នុងប្លង់កូអរដោនេ ៖ ចំពោះ ៣ ចំណុច \(A, B, C\) ណាក៏ដោយ ៖ \(AB + BC \ge AC\)។ សមភាពកើតឡើងលុះត្រាតែ \(B\) ស្ថិតនៅលើអង្កត់ \([AC]\)។

៤៣លំហាត់ទី ៤៣

រកចំណុច \(M\) លើអ័ក្ស \(x'x\) ដើម្បីឱ្យ \(MA + MB\) មានតម្លៃតូចបំផុត (ចំណោទឆ្លុះពន្លឺ)។

មើលដំណោះស្រាយ

គណនាចម្ងាយអប្បបរមា (Fermat point / Reflection) ៖ រក \(M \in x'x\) ដើម្បីឱ្យ \(MA + MB\) តូចបំផុតដោយ \(A, B\) នៅខាងលើអ័ក្ស ៖ យក \(A'\) ឆ្លុះនៃ \(A\) ធៀបនឹង \(x'x\) រួចភ្ជាប់ \(A'B\) កាត់ \(x'x\) ត្រង់ \(M\)។

៤៤លំហាត់ទី ៤៤

បង្ហាញទ្រឹស្តីបទប្រលេឡូក្រាម ៖ \(2(AB^2 + BC^2) = AC^2 + BD^2\) តាមវិធីកូអរដោនេ។

មើលដំណោះស្រាយ

ទំនាក់ទំនងស្តីពីអង្កត់ទ្រូងប្រលេឡូក្រាម (Parallelogram Law) ៖ \(2(AB^2 + BC^2) = AC^2 + BD^2\) ៖ បង្ហាញដោយជំនួសកូអរដោនេ \(A(0, 0), B(a, 0), C(a+b, c), D(b, c)\)។

៤៥លំហាត់ទី ៤៥

បង្ហាញទ្រឹស្តីបទមេដ្យានរបស់ Apollonius តាមវិធីកូអរដោនេ។

មើលដំណោះស្រាយ

ទ្រឹស្តីបទមេដ្យានរបស់ Apollonius ៖ ក្នុងត្រីកោណ \(ABC\) ដែល \(M\) ជាចំណុចកណ្តាល \(BC\) ៖ \(AB^2 + AC^2 = 2AM^2 + 2BM^2\)។

៤៦លំហាត់ទី ៤៦

ពន្យល់ពីវិធីរកផ្ចិតរង្វង់កាត់តាម ៣ ចំណុចមិនរត់ត្រង់ជួរគ្នា។

មើលដំណោះស្រាយ

ផ្ចិត និងកាំនៃរង្វង់ឆ្លងកាត់ចំណុច ៣ ៖ ដោះស្រាយប្រព័ន្ធចម្ងាយស្មើគ្នា \(IA^2 = IB^2 = IC^2\) ដើម្បីទាញរកកូអរដោនេផ្ចិត \(I(x, y)\)។

៤៧លំហាត់ទី ៤៧

ពន្យល់ពីទីតាំងអរតូសង់ \(H\) នៃត្រីកោណកែងក្នុងប្លង់កូអរដោនេ។

មើលដំណោះស្រាយ

អរតូសង់ (Orthocenter) នៃត្រីកោណ ៖ ប្រសព្វនៃកម្ពស់ទាំងបី ៖ ចំពោះត្រីកោណកែង អរតូសង់ជាកំពូលមុំកែង។

៤៨លំហាត់ទី ៤៨

ពន្យល់ពីបន្ទាត់ Euler ដែលកាត់តាម \(H, G, O\) នៃត្រីកោណមួយ។

មើលដំណោះស្រាយ

បន្ទាត់ Euler នៃត្រីកោណ ៖ បង្ហាញថា អរតូសង់ \(H\), ទីប្រជុំទម្ងន់ \(G\), និងផ្ចិតរង្វង់ចារឹកក្រៅ \(O\) រត់ត្រង់ជួរគ្នាដោយ \(\vec{HG} = 2\vec{GO}\)។

៤៩លំហាត់ទី ៤៩

គណនាផ្ទៃក្រឡាពហុកោណប៉ោង ៥ ជ្រុងតាមកូអរដោនេកំពូល។

មើលដំណោះស្រាយ

គណនាផ្ទៃក្រឡាពហុកោណប៉ោង ៖ ប្រើរូបមន្ត Shoelace សម្រាប់ពហុកោណ \(n\) ជ្រុង។

៥០លំហាត់ទី ៥០

ពន្យល់ពីរបៀបដែលប្រព័ន្ធ GPS ប្រើប្រាស់រូបមន្តចម្ងាយកូអរដោនេក្នុងការកំណត់ទីតាំង (Trilateration)។

មើលដំណោះស្រាយ

ការអនុវត្តកូអរដោនេក្នុងការរុករក GPS ៖ ចម្ងាយរវាងស្ថានីយពីរ និងទីតាំងឧបករណ៍ត្រូវបានគណនាតាមរូបមន្តត្រីកោណមាត្រកូអរដោនេ (Trilateration) ផ្អែកលើរូបមន្តចម្ងាយពីរចំណុច។
