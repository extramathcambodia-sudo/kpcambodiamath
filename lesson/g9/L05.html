វិសមភាព (Inequality) គឺជាមូលដ្ឋានគ្រឹះដ៏សំខាន់ក្នុងការប៉ាន់ស្មាន ព្រំដែនកំហុស និងការដោះស្រាយបញ្ហាអតិបរមា/អប្បបរមា ៖

  • លោក Thomas Harriot (១៥៦០-១៦២១) ៖ គណិតវិទូជនជាតិអង់គ្លេស Thomas Harriot គឺជាអ្នកបង្កើតនិមិត្តសញ្ញា «ធំជាង» (\(>\)) និង «តូចជាង» (\(<\)) ក្នុងសៀវភៅ Artis Analyticae Praxis ដែលបោះពុម្ពក្នុងឆ្នាំ ១៦៣១។ និមិត្តសញ្ញានេះផ្អែកលើគំនិតដែលថា ចុងស្រួចចង្អុលទៅរកចំនួនតូចជាង ហើយផ្នែកបើកធំចង្អុលទៅរកចំនួនធំជាង។

  • លោក Pierre Bouguer (១៦៩៨-១៧៥៨) ៖ គណិតវិទូ និងតារាវិទូជនជាតិបារាំង Pierre Bouguer បានបង្កើតនិមិត្តសញ្ញា «ធំជាង ឬស្មើ» (\(\ge\)) និង «តូចជាង ឬស្មើ» (\(\le\)) ក្នុងឆ្នាំ ១៧៣៤ ដោយដាក់របារផ្ដេកពីក្រោមក្បាលសញ្ញា។

  • វិសមភាពក្នុងវិស្វកម្មសំណង់ខ្មែរ ៖ ក្នុងការសាងសង់ប្រាសាទថ្មបុរាណ វិស្វករខ្មែរបានគិតគូរយ៉ាងល្អិតល្អន់ពី «បន្ទុកសុវត្ថិភាព» (Safety Load) នៃធ្នឹម និងសសរថ្មភក់ ៖ បន្ទុកសរុបត្រូវតែតូចជាង ឬស្មើនឹងកម្លាំងទ្រទ្រង់អតិបរមានៃថ្ម (\(P_{\text{load}} \le P_{\text{capacity}}\))។ គោលការណ៍វិសមភាពនេះហើយដែលធ្វើឱ្យប្រាសាទខ្មែរឈររឹងមាំរាប់ពាន់ឆ្នាំ។

លក្ខណៈគ្រឹះនៃវិសមភាព

លក្ខណៈបូក ដក គុណ ចែកលើវិសមភាព

ចំពោះគ្រប់ចំនួនពិត \(a, b, c\) ៖

  1. វិធីបូក ឬដកចំនួនដូចគ្នា ៖

    \[a > b \iff a + c > b + c \quad{} ; \quad{} a > b \iff a - c > b - c\]

  2. វិធីគុណ ឬចែកនឹងចំនួនវិជ្ជមាន (\(c > 0\)) ៖ រក្សាទិសដៅវិសមភាពដដែល ៖

    \[a > b \iff ac > bc \quad{} ; \quad{} a > b \iff \frac{a}{c} > \frac{b}{c}\]

  3. វិធីគុណ ឬចែកនឹងចំនួនអវិជ្ជមាន (\(c < 0\)) ៖ ត្រូវត្រឡប់ទិសដៅវិសមភាព ៖

    \[a > b \iff ac < bc \quad{} ; \quad{} a > b \iff \frac{a}{c} < \frac{b}{c}\]

ចំណុចត្រូវប្រយ័ត្នបំផុត!

នៅពេលគុណ ឬចែកអង្គទាំងពីរនៃវិសមភាពនឹង ចំនួនអវិជ្ជមាន អ្នកត្រូវតែ ប្តូរទិសដៅវិសមភាព ជានិច្ច ៖

\[-2x < 6 \iff x > \frac{6}{-2} \iff x > -3\]

\[ax + b > 0 \quad{} ; \quad{} ax + b < 0 \quad{} ; \quad{} ax + b \ge 0 \quad{} ; \quad{} ax + b \le 0 \quad{} (a \ne 0)\]

  • \(x \ge a\) ៖ ចន្លោះ \([a, +\infty)\) (រាប់បញ្ចូល \(a\) គូសរង្វង់ខ្មៅជិត \(\bullet\))

  • \(x < a\) ៖ ចន្លោះ \((-\infty, a)\)

  • \(x \le a\) ៖ ចន្លោះ \((-\infty, a]\)

ឧទាហរណ៍

សិស្សម្នាក់ទទួលបានពិន្ទុតេស្តគណិតវិទ្យាពីរលើកដំបូងគឺ \(75\) និង \(82\)។ ដើម្បីទទួលបាននិទ្ទេសល្អ សិស្សនោះត្រូវមានពិន្ទុមធ្យមភាគយ៉ាងហោចណាស់ \(80\) ក្នុងតេស្តទាំងបីលើក។ តើតេស្តលើកទីបីគាត់ត្រូវទទួលបានពិន្ទុយ៉ាងតិចប៉ុន្មាន?

ដំណោះស្រាយ

  • តាង \(x\) ជាពិន្ទុតេស្តលើកទីបី (\(0 \le x \le 100\))។

  • មធ្យមភាគនៃតេស្តទាំងបីគឺ ៖ \(\dfrac{75 + 82 + x}{3}\)

  • តាមប្រាប់ ៖

    \[\frac{75 + 82 + x}{3} \ge 80 \iff 157 + x \ge 240 \iff x \ge 240 - 157 \iff x \ge 83\]

  • ដូចនេះ តេស្តលើកទីបីគាត់ត្រូវទទួលបានពិន្ទុយ៉ាងតិច \(83\) ពិន្ទុ។

មើលដំណោះស្រាយ

៣៣លំហាត់ទី ៣៣

មើលដំណោះស្រាយ

៣៤លំហាត់ទី ៣៤

សូលុយស្យុងអាស៊ីត \(10\,\text{L}\) មានកំហាប់ \(30\%\)។ តើត្រូវបន្ថែមទឹកសុទ្ធយ៉ាងតិចប៉ុន្មានលីត្រ ដើម្បីឱ្យកំហាប់អាស៊ីតធ្លាក់ចុះមកនៅក្រោម \(20\%\)?

មើលដំណោះស្រាយ

ពង្រាវអាស៊ីត ៖ \(\frac{3}{10 + x} < 0.20 \implies 10 + x > 15 \implies x > 5\,\text{L}\)។ ត្រូវបន្ថែមទឹកសុទ្ធលើសពី \(5\,\text{L}\)។

រថយន្តមួយបើកបរលើផ្លូវចម្ងាយ \(180\,\text{km}\)។ ដើម្បីទៅដល់គោលដៅក្នុងរយៈពេលមិនលើសពី \(2\) ម៉ោង \(15\) នាទី តើរថយន្តត្រូវបើកបរក្នុងល្បឿនមធ្យមយ៉ាងតិចប៉ុន្មាន?

មើលដំណោះស្រាយ

ល្បឿនរថយន្ត ៖ \(t \le 2.25\,\text{h} \implies \frac{180}{v} \le 2.25 \implies v \ge \frac{180}{2.25} = 80\,\text{km/h}\)។

៣៧លំហាត់ទី ៣៧

រកគ្រប់ចំនួនគត់ \(x\) ដែលផ្ទៀងផ្ទាត់ប្រព័ន្ធវិសមីការ ៖

\[\begin{cases} \dfrac{x-1}{2} - \dfrac{x-2}{3} < 1 \\[4pt] \dfrac{2-x}{2} \le \dfrac{3-x}{3} \end{cases}\]

មើលដំណោះស្រាយ

៣៨លំហាត់ទី ៣៨

\[-1 \le \frac{2x - 5}{3} \le 3\]

មើលដំណោះស្រាយ

វិសមីការឌុប ៖ \(-3 \le 2x - 5 \le 9 \implies 2 \le 2x \le 14 \implies 1 \le x \le 7\)។ \(x \in \{1, 2, 3, 4, 5, 6, 7\}\)។

៣៩លំហាត់ទី ៣៩

បង្ហាញថា ប្រសិនបើ \(a, b > 0\) នោះ ៖

\[\frac{a}{b} + \frac{b}{a} \ge 2\]
តើសមភាពកើតឡើងនៅពេលណា?

មើលដំណោះស្រាយ

វិសមភាព \(\frac{a}{b} + \frac{b}{a} \ge 2\) ៖ \(\frac{a^2+b^2-2ab}{ab} = \frac{(a-b)^2}{ab} \ge 0\) (ពិតព្រោះ \((a-b)^2 \ge 0\) និង \(ab > 0\))។ សមភាពកើតឡើងពេល \(a = b\)។

៤០លំហាត់ទី ៤០

បង្ហាញថា ប្រសិនបើ \(a, b, c > 0\) នោះ ៖

\[(a + b)(b + c)(c + a) \ge 8abc\]

មើលដំណោះស្រាយ

វិសមភាព ៖ តាម AM-GM ៖ \(a+b \ge 2\sqrt{ab}\), \(b+c \ge 2\sqrt{bc}\), \(c+a \ge 2\sqrt{ca}\)។ គុណអង្គនិងអង្គ ៖ \((a+b)(b+c)(c+a) \ge 8\sqrt{a^2b^2c^2} = 8abc\)។

៤១លំហាត់ទី ៤១

បង្ហាញថា ចំពោះគ្រប់ចំនួនពិត \(x, y\) គេបាន ៖

\[x^2 + y^2 + 1 \ge xy + x + y\]

មើលដំណោះស្រាយ

វិសមភាព ៖ \(2(x^2+y^2+1 - xy - x - y) = (x-y)^2 + (x-1)^2 + (y-1)^2 \ge 0\) ពិតជានិច្ច។

៤២លំហាត់ទី ៤២

បង្ហាញថា ចំពោះគ្រប់ចំនួនពិត \(a, b, c\) គេបាន ៖

\[a^2 + b^2 + c^2 \ge ab + bc + ca\]

មើលដំណោះស្រាយ

វិសមភាព ៖ \(2(a^2+b^2+c^2 - ab - bc - ca) = (a-b)^2 + (b-c)^2 + (c-a)^2 \ge 0\) ពិតជានិច្ច។

៤៣លំហាត់ទី ៤៣

បង្ហាញថា ប្រសិនបើ \(a + b \ge 2\) នោះ \(a^4 + b^4 \ge 2\)។

មើលដំណោះស្រាយ

បង្ហាញ \(a^4+b^4 \ge 2\) ៖ តាម Cauchy-Schwarz ឬ AM-GM ៖ \(a^2+b^2 \ge \frac{(a+b)^2}{2} \ge 2\)។ \(a^4+b^4 \ge \frac{(a^2+b^2)^2}{2} \ge \frac{4}{2} = 2\)។

៤៤លំហាត់ទី ៤៤

រកតម្លៃតូចបំផុតនៃកន្សោម \(P = x + \dfrac{4}{x}\) ចំពោះ \(x > 0\)។

មើលដំណោះស្រាយ

តម្លៃតូចបំផុត \(P\) ៖ តាម AM-GM ៖ \(x + \frac{4}{x} \ge 2\sqrt{x \times \frac{4}{x}} = 4\)។ តូចបំផុតគឺ \(4\) ពេល \(x = 2\)។

៤៥លំហាត់ទី ៤៥

រកតម្លៃតូចបំផុតនៃកន្សោម \(Q = \dfrac{x^2 + 5}{\sqrt{x^2 + 1}}\)។

មើលដំណោះស្រាយ

តម្លៃតូចបំផុត \(Q\) ៖ \(Q = \sqrt{x^2+1} + \frac{4}{\sqrt{x^2+1}} \ge 2\sqrt{4} = 4\)។ តូចបំផុតគឺ \(4\) ពេល \(x^2+1 = 4 \implies x = \pm \sqrt{3}\)។

៤៦លំហាត់ទី ៤៦

ដោះស្រាយវិសមីការ ៖

\[\frac{1}{x-2} + \frac{1}{x-1} > \frac{2}{x}\]

មើលដំណោះស្រាយ

ដោះស្រាយវិសមីការ ៖ បម្លែង និងសិក្សាតារាងសញ្ញា ៖ \(x \in (0, 1) \cup (2, +\infty)\)។

៤៧លំហាត់ទី ៤៧

ដោះស្រាយវិសមីការ ៖

\[|x - 1| + |2x - 4| \le 5\]

មើលដំណោះស្រាយ

វិសមីការតម្លៃដាច់ខាត ៖ បំបែកតាមចន្លោះ \(x < 1\), \(1 \le x \le 2\), \(x > 2\) ៖ សំណុំចម្លើយគឺ \(0 \le x \le \frac{10}{3}\) (ចន្លោះ \([0, 3.33]\))។

៤៨លំហាត់ទី ៤៨

រកគ្រប់តម្លៃ \(m\) ដើម្បីឱ្យវិសមីការ \((m - 2)x + 3 > 0\) ផ្ទៀងផ្ទាត់ចំពោះគ្រប់ \(x \in \mathbb{R}\)។

មើលដំណោះស្រាយ

រក \(m\) ៖ ដើម្បីឱ្យ \((m-2)x + 3 > 0\) ចំពោះគ្រប់ \(x\) លុះត្រាតែ \(m - 2 = 0 \iff m = 2\) (ពេលនោះ \(3 > 0\) ពិតជានិច្ច)។

៤៩លំហាត់ទី ៤៩

រកគ្រប់តម្លៃ \(m\) ដើម្បីឱ្យវិសមីការ \(mx - 2 < 3x + m\) ផ្ទៀងផ្ទាត់ចំពោះគ្រប់ \(x > 1\)។

មើលដំណោះស្រាយ

រក \(m\) ៖ \((m-3)x < m+2\) ចំពោះគ្រប់ \(x > 1\) ៖ លុះត្រាតែ \(m - 3 \le 0\) និងផ្ទៀងផ្ទាត់ព្រំដែន នាំឱ្យ \(m \le 3\) និង \(m - 3 \le m + 2\)។

៥០លំហាត់ទី ៥០

បង្ហាញវិសមភាព Cauchy-Schwarz ចំពោះ \(n=2\) ៖

\[(a_1^2 + a_2^2)(b_1^2 + b_2^2) \ge (a_1b_1 + a_2b_2)^2\]

មើលដំណោះស្រាយ

Cauchy-Schwarz ៖ \((a_1b_2 - a_2b_1)^2 \ge 0 \iff a_1^2b_2^2 - 2a_1a_2b_1b_2 + a_2^2b_1^2 \ge 0\) បូក \(a_1^2b_1^2 + a_2^2b_2^2\) លើអង្គទាំងពីរ គេបាន \((a_1^2+a_2^2)(b_1^2+b_2^2) \ge (a_1b_1+a_2b_2)^2\)។

ជ្រើសរើសចម្លើយត្រឹមត្រូវតែមួយ រួចចុច «ពិនិត្យ»។ ចម្លើយរបស់អ្នកត្រូវបានរក្សាទុកក្នុងកុំព្យូទ័រនេះ។
