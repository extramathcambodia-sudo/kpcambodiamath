សមាមាត្រ (Proportion) និង ផលធៀប (Ratio) គឺជាឧបករណ៍គណិតវិទ្យាដ៏ចំណាស់បំផុតមួយ ដែលមនុស្សជាតិបានប្រើប្រាស់តាំងពីរាប់ពាន់ឆ្នាំមុនគ្រិស្តសករាជ ៖

  • ទ្រឹស្តីសមាមាត្ររបស់អឺដុកស៊ុស (Eudoxus of Cnidus, ៤០៨-៣៥៥ មុន គ.ស.) ៖ គណិតវិទូក្រិក Eudoxus បានបង្កើតទ្រឹស្តីផលធៀប និងសមាមាត្រដ៏ល្អឥតខ្ចោះ ដែលត្រូវបាន Euclid ចងក្រងទុកក្នុងសៀវភៅទី ៥ នៃ Elements។ ទ្រឹស្តីនេះអាចអនុវត្តបានទាំងលើចំនួនសនិទាន និងចំនួនអសនិទាន ដែលជាមូលដ្ឋានគ្រឹះនៃធរណីមាត្រ និងការវាស់វែង។

  • ប្រភពនៃនិមិត្តសញ្ញាភាគរយ \(\%\) ៖ ពាក្យ «ភាគរយ» មកពីភាសាឡាតាំង "Per Centum" មានន័យថា «ក្នុងចំណោមមួយរយ»។ និមិត្តសញ្ញា \(\%\) បានវិវត្តបន្តិចម្តងៗនៅប្រទេសអ៊ីតាលីក្នុងសតវត្សទី ១៥ ពីពាក្យកាត់ "per 100" ទៅជា "p 100" ហើយក្លាយជាសញ្ញា \(\%\) នៅសតវត្សទី ១៧។

  • ការគណនាការប្រាក់ និងពាណិជ្ជកម្មបុរាណ ៖ នៅបាប៊ីឡូនបុរាណ (ប្រហែល ២០០០ មុន គ.ស.) ផ្ទាំងដីឥដ្ឋគ្លីនិកបានកត់ត្រាការគណនាការប្រាក់សមាសលើប្រាក់កម្ចីស្រូវ និងប្រាក់។ ក្រោយមក គណិតវិទូអារ៉ាប់ Al-Khwarizmi បានសរសេរបញ្ចូលក្បួនសមាមាត្រត្រីគុណ (Rule of Three) ក្នុងសៀវភៅពិជគណិតរបស់លោក។

  • ស្ថាបត្យកម្មប្រាសាទអង្គរវត្ត ៖ ក្នុងការរៀបចំផែនទី និងសំណង់ប្រាសាទអង្គរវត្ត បុព្វបុរសខ្មែរបានប្រើប្រាស់ប្រព័ន្ធមាត្រដ្ឋានសមាមាត្រយ៉ាងតឹងរ៉ឹង ដូចជាផលធៀប \(1 : 2\), \(2 : 3\), \(3 : 4\) និងផលធៀបមាស ដើម្បីកំណត់ទំហំខឿន កម្ពស់កំពូល និងចម្ងាយរវាងគូទឹកនិងកំពែងប្រាសាទ ធ្វើឱ្យសំណង់ទាំងមូលមានតុល្យភាពស្ថាបត្យកម្មដ៏អស្ចារ្យ។

សមាមាត្រ គឺជាសមភាពរវាងពីរផលធៀប ៖

\[\frac{a}{b} = \frac{c}{d} \quad{} \text{ឬ} \quad{} a : b = c : d \quad{} (b \ne 0, d \ne 0)\]

  • \(a\) និង \(d\) ហៅថា តួចុង (Extremes)

  • \(b\) និង \(c\) ហៅថា តួកណ្ដាល (Means)

លក្ខណៈគ្រឹះនៃសមាមាត្រ

ក្នុងគ្រប់សមាមាត្រ ផលគុណតួចុងស្មើនឹងផលគុណតួកណ្ដាល (ផលគុណខ្វែង) ៖

\[\frac{a}{b} = \frac{c}{d} \iff a \times d = b \times c\]
ពីសមាមាត្រនេះ គេអាចទាញបានសមាមាត្រសមមូលដទៃទៀត ៖
\[\frac{a}{c} = \frac{b}{d} \quad{} ; \quad{} \frac{d}{b} = \frac{c}{a} \quad{} ; \quad{} \frac{b}{a} = \frac{d}{c}\]

លក្ខណៈនៃផលធៀបស្មើគ្នា

បើ \(\dfrac{a}{b} = \dfrac{c}{d} = k\) នោះចំពោះគ្រប់ចំនួន \(m, n\) (ដែលភាគបែងមិនសូន្យ) គេបាន ៖

\[\frac{a}{b} = \frac{c}{d} = \frac{a + c}{b + d} = \frac{a - c}{b - d} = \frac{ma + nc}{mb + nd} = k\]

ភាគរយ

ភាគរយ គឺជាផលធៀបដែលមានភាគបែងស្មើ \(100\)។ ភាគរយនៃ \(a\) ធៀបនឹង \(b\) គិតជា ៖

\[P = \frac{a}{b} \times 100\%\]

រូបមន្តភាគរយកំណើន និងតំហយ

បើបរិមាណមួយប្រែប្រួលពីតម្លៃដើម \(V_1\) ទៅតម្លៃថ្មី \(V_2\) ៖

  • បើ \(V_2 > V_1\) (កំណើន) ៖

    \[\text{ភាគរយកំណើន} = \frac{V_2 - V_1}{V_1} \times 100\%\]

  • បើ \(V_2 < V_1\) (តំហយ/បញ្ចុះតម្លៃ) ៖

    \[\text{ភាគរយតំហយ} = \frac{V_1 - V_2}{V_1} \times 100\%\]

  1. គណនាប្រាក់ដែលបានបញ្ចុះ។

  • ប្រាក់ដែលបានបញ្ចុះ ៖ \(25 \times 20\% = 25 \times \dfrac{20}{100} = 5\,\$\)

តាង \(P_0\) ជាប្រាក់ដើម, \(r\) ជាអត្រាការប្រាក់ប្រចាំឆ្នាំ (គិតជាទសភាគ), \(t\) ជារយៈពេលគិតជាឆ្នាំ ៖

  1. ការប្រាក់ទោល (Simple Interest) ៖ ការប្រាក់គិតតែលើប្រាក់ដើមប៉ុណ្ណោះ ៖

    \[I = P_0 \times r \times t \quad{} ; \quad{} \text{ប្រាក់សរុប } A = P_0 + I = P_0(1 + rt)\]

  2. ការប្រាក់សមាស (Compound Interest) ៖ ការប្រាក់នៃឆ្នាំនីមួយៗត្រូវបានបូកបញ្ចូលក្នុងប្រាក់ដើមដើម្បីបង្កើតជាប្រាក់ដើមថ្មីសម្រាប់ឆ្នាំបន្ទាប់ ៖

    \[P_t = P_0(1 + r)^t\]

ឧទាហរណ៍

លោកសុខបានយកប្រាក់ \(2000\,\$\) ទៅផ្ញើធនាគារដោយទទួលបានអត្រាការប្រាក់ទោល \(6\%\) ក្នុងមួយឆ្នាំ។ រកការប្រាក់ និងប្រាក់សរុបដែលគាត់ទទួលបានក្រោយពេលផ្ញើរយៈពេល \(3\) ឆ្នាំ។

ដំណោះស្រាយ

  • ប្រាក់ដើម \(P_0 = 2000\,\$\), អត្រាការប្រាក់ \(r = 6\% = 0.06\), រយៈពេល \(t = 3\) ឆ្នាំ។

  • ការប្រាក់ទោល ៖ \(I = P_0 \times r \times t = 2000 \times 0.06 \times 3 = 360\,\$\)

  • ប្រាក់សរុប ៖ \(A = P_0 + I = 2000 + 360 = 2360\,\$\)

  • ដូចនេះ គាត់ទទួលបានការប្រាក់ \(360\,\$\) និងប្រាក់សរុប \(2360\,\$\)។

ប្រតិបត្តិ

គេយកប្រាក់ \(5000\,\$\) ទៅផ្ញើធនាគារក្នុងអត្រាការប្រាក់ទោល \(5\%\) ក្នុងមួយឆ្នាំ។ រកប្រាក់សរុបដែលទទួលបានក្រោយរយៈពេល \(4\) ឆ្នាំ។

លំហាត់អនុវត្តន៍

១លំហាត់ទី ១

រកតម្លៃនៃ \(x\) ក្នុងសមាមាត្រខាងក្រោម ៖

  1. \(\dfrac{x}{15} = \dfrac{4}{5}\)

  2. \(\dfrac{24}{x} = \dfrac{6}{7}\)

  3. \(\dfrac{x+1}{8} = \dfrac{3}{4}\)

  4. \(\dfrac{5}{x-2} = \dfrac{2}{3}\)

  5. \(\dfrac{2x-1}{3} = \dfrac{x+4}{2}\)

  6. \(\dfrac{3x+2}{5} = \dfrac{2x-1}{3}\)

មើលដំណោះស្រាយ

រកតម្លៃ \(x\) តាមផលគុណខ្វែង ៖

  • a. \(5x = 60 \implies x = 12\)

  • b. \(6x = 168 \implies x = 28\)

  • c. \(4(x+1) = 24 \implies 4x = 20 \implies x = 5\)

  • d. \(2(x-2) = 15 \implies 2x = 19 \implies x = 9.5\)

  • e. \(2(2x-1) = 3(x+4) \implies 4x-2 = 3x+12 \implies x = 14\)

  • f. \(3(3x+2) = 5(2x-1) \implies 9x+6 = 10x-5 \implies x = 11\)

២លំហាត់ទី ២

ចូរប្តូរឯកតារង្វាស់តាមប្រព័ន្ធខ្នាតអន្តរជាតិ (\(1\,\text{in} \approx 2.54\,\text{cm}, 1\,\text{ft} \approx 0.3048\,\text{m}, 1\,\text{mi} \approx 1.609\,\text{km}, 1\,\text{lb} \approx 0.453\,\text{kg}\)) ៖

  1. ប្តូរ \(2.5\,\text{m}\) ទៅជា \(\text{inches}\)

  2. ប្តូរ \(50\,\text{miles}\) ទៅជា \(\text{km}\)

  3. ប្តូរ \(12\,\text{feet}\) ទៅជា \(\text{m}\)

  4. ប្តូរ \(10\,\text{kg}\) ទៅជា \(\text{lb}\)

មើលដំណោះស្រាយ

ប្តូរឯកតារង្វាស់ ៖

  • a. \(2.5\,\text{m} = 250\,\text{cm} \approx \frac{250}{2.54} \approx 98.43\,\text{in}\)

  • b. \(50\,\text{mi} \approx 50 \times 1.609 = 80.45\,\text{km}\)

  • c. \(12\,\text{ft} \approx 12 \times 0.3048 = 3.658\,\text{m}\)

  • d. \(10\,\text{kg} \approx \frac{10}{0.453} \approx 22.08\,\text{lb}\)

៣លំហាត់ទី ៣

អាងទឹកមួយមានចំណុះ \(9000\,\text{L}\)។ បើគេបង្ហូរទឹកចូលក្នុងល្បឿន \(150\,\text{L}\) ក្នុងរយៈពេល \(2\) នាទី តើត្រូវចំណាយពេលប៉ុន្មាននាទីទើបទឹកពេញអាង?

មើលដំណោះស្រាយ

គណនារយៈពេលបញ្ចូលទឹក ៖ ល្បឿនបញ្ចូលទឹកគឺ \(\frac{150\,\text{L}}{2\,\text{mn}} = 75\,\text{L/mn}\)។ រយៈពេលបំពេញទឹកពេញអាង ៖

\[t = \frac{9000}{75} = 120\,\text{នាទី} = 2\,\text{ម៉ោង}\]

៤លំហាត់ទី ៤

រថយន្តមួយធ្វើដំណើរដោយល្បឿនថេរ បើកបរបានចម្ងាយ \(210\,\text{km}\) ក្នុងរយៈពេល \(3\) ម៉ោង។

  1. គណនាចម្ងាយផ្លូវដែលរថយន្តបើកបរបានក្នុងរយៈពេល \(5\) ម៉ោង។

  2. តើរថយន្តត្រូវចំណាយពេលប៉ុន្មានម៉ោង ដើម្បីធ្វើដំណើរបានចម្ងាយ \(490\,\text{km}\)?

មើលដំណោះស្រាយ

ចម្ងាយនិងពេលវេលារថយន្ត ៖ ល្បឿនរថយន្ត \(v = \frac{210}{3} = 70\,\text{km/h}\)។

  • a. ក្នុងរយៈពេល \(5\,\text{h}\) ៖ \(d = 70 \times 5 = 350\,\text{km}\)

  • b. រយៈពេលធ្វើដំណើរ \(490\,\text{km}\) ៖ \(t = \frac{490}{70} = 7\,\) ម៉ោង

៥លំហាត់ទី ៥

កង់ម៉ាស៊ីនមួយវិលបាន \(2400\) ជុំក្នុងរយៈពេល \(8\) វិនាទី។ តើក្នុងរយៈពេល \(1\) នាទី កង់នោះវិលបានប៉ុន្មានជុំ?

មើលដំណោះស្រាយ

គណនាចំនួនជុំនៃកង់ម៉ាស៊ីន ៖ ក្នុងរយៈពេល \(1\,\text{s}\) វិលបាន \(\frac{2400}{8} = 300\,\) ជុំ ។ ក្នុងរយៈពេល \(1\,\text{mn} = 60\,\text{s}\) វិលបាន ៖

\[N = 300 \times 60 = 18\,000\,\text{ជុំ}\]

៦លំហាត់ទី ៦

បើជាងសំណង់ \(6\) នាក់សង់ជញ្ជាំងមួយរួចរាល់ក្នុងរយៈពេល \(12\) ថ្ងៃ។ បើគេបង្កើនជាងដល់ \(9\) នាក់ តើការងារនោះត្រូវចំណាយពេលប៉ុន្មានថ្ងៃទើបរួចរាល់ (សមាមាត្រច្រាស)?

មើលដំណោះស្រាយ

សមាមាត្រច្រាស ៖ កម្លាំងពលកម្ម \(6\) នាក់ធ្វើការ \(12\) ថ្ងៃ \(\implies\) បរិមាណការងារ \(6 \times 12 = 72\) នាក់-ថ្ងៃ។ បើមានជាង \(9\) នាក់ រយៈពេលចំណាយគឺ ៖

\[t = \frac{72}{9} = 8\,\text{ថ្ងៃ}\]

៧លំហាត់ទី ៧

ចែកប្រាក់ចំនួន \(450\,\$\) ទៅឱ្យមនុស្សពីរនាក់តាមផលធៀប \(4 : 5\)។ រកប្រាក់ដែលម្នាក់ៗទទួលបាន។

មើលដំណោះស្រាយ

ចែកប្រាក់តាមផលធៀប \(4 : 5\) ៖ ផលបូកភាគ \(4 + 5 = 9\) ភាគ។ តម្លៃមួយភាគ \(\frac{450}{9} = 50\,\$\)។

  • អ្នកទីមួយ ៖ \(4 \times 50 = 200\,\$\)

  • អ្នកទីពីរ ៖ \(5 \times 50 = 250\,\$\)

៨លំហាត់ទី ៨

ចែកប្រាក់ចំនួន \(1200\,\$\) ទៅឱ្យកូនបីនាក់តាមផលធៀប \(2 : 3 : 5\)។ រកប្រាក់ដែលកូនម្នាក់ៗទទួលបាន។

មើលដំណោះស្រាយ

ចែកប្រាក់តាមផលធៀប \(2 : 3 : 5\) ៖ ផលបូកភាគ \(2 + 3 + 5 = 10\) ភាគ។ តម្លៃមួយភាគ \(\frac{1200}{10} = 120\,\$\)។

  • កូនទីមួយ ៖ \(2 \times 120 = 240\,\$\)

  • កូនទីពីរ ៖ \(3 \times 120 = 360\,\$\)

  • កូនទីបី ៖ \(5 \times 120 = 600\,\$\)

៩លំហាត់ទី ៩

ត្រីកោណមួយមានមុំទាំងបីសមាមាត្រនឹងចំនួន \(2, 3, 4\)។ គណនារង្វាស់មុំនីមួយៗនៃត្រីកោណនោះ។

មើលដំណោះស្រាយ

រង្វាស់មុំត្រីកោណ ៖ ផលបូកមុំក្នុងត្រីកោណគឺ \(180^\circ\)។ ផលបូកភាគ \(2 + 3 + 4 = 9\) ភាគ។ តម្លៃមួយភាគ \(\frac{180^\circ}{9} = 20^\circ\)។

  • មុំទីមួយ ៖ \(2 \times 20^\circ = 40^\circ\)

  • មុំទីពីរ ៖ \(3 \times 20^\circ = 60^\circ\)

  • មុំទីបី ៖ \(4 \times 20^\circ = 80^\circ\)

១០លំហាត់ទី ១០

ចតុកោណកែងមួយមានបរិមាត្រ \(64\,\text{cm}\) ហើយផលធៀបរវាងបណ្ដោយ និងទទឹងគឺ \(5 : 3\)។ គណនាផ្ទៃក្រឡានៃចតុកោណកែងនោះ។

មើលដំណោះស្រាយ

ចតុកោណកែង ៖ កន្លះបរិមាត្រ \(L + W = 32\,\text{cm}\)។ ផលបូកភាគ \(5 + 3 = 8\) ភាគ។ មួយភាគ \(\frac{32}{8} = 4\,\text{cm}\)។

  • បណ្ដោយ \(L = 5 \times 4 = 20\,\text{cm}\)

  • ទទឹង \(W = 3 \times 4 = 12\,\text{cm}\)

  • ផ្ទៃក្រឡា \(S = L \times W = 20 \times 12 = 240\,\text{cm}^2\)

១១លំហាត់ទី ១១

គណនាតម្លៃនៃ \(n\) ក្នុងករណីនីមួយៗខាងក្រោម ៖

  1. \(25\%\) នៃ \(n\) ស្មើនឹង \(60\)

  2. \(n\%\) នៃ \(180\) ស្មើនឹង \(45\)

  3. \(35\%\) នៃ \(240\) ស្មើនឹង \(n\)

  4. \(12.5\%\) នៃ \(n\) ស្មើនឹង \(25\)

មើលដំណោះស្រាយ

គណនាតម្លៃ \(n\) ៖

  • a. \(0.25n = 60 \implies n = 240\)

  • b. \(\frac{n}{100} \times 180 = 45 \implies 1.8n = 45 \implies n = 25\)

  • c. \(n = 0.35 \times 240 = 84\)

  • d. \(0.125n = 25 \implies n = 200\)

១២លំហាត់ទី ១២

តេស្តគណិតវិទ្យាមួយមាន \(40\) សំណួរ។ វិបុលឆ្លើយត្រូវចំនួន \(34\) សំណួរ។ គណនាភាគរយនៃសំណួរដែលវិបុលឆ្លើយត្រូវ និងភាគរយដែលឆ្លើយខុស។

មើលដំណោះស្រាយ

ភាគរយនៃសំណួរ ៖

  • ភាគរយឆ្លើយត្រូវ ៖ \(\frac{34}{40} \times 100\% = 85\%\)

  • ភាគរយឆ្លើយខុស ៖ \(100\% - 85\% = 15\%\)

១៣លំហាត់ទី ១៣

ក្នុងចំណោមសិស្ស \(500\) នាក់នៃសាលារៀនមួយ មានសិស្សស្រី \(260\) នាក់។

  1. រកភាគរយនៃសិស្សស្រីក្នុងសាលា។

  2. រកភាគរយនៃសិស្សប្រុសក្នុងសាលា។

មើលដំណោះស្រាយ

ភាគរយសិស្ស ៖

  • a. សិស្សស្រី ៖ \(\frac{260}{500} \times 100\% = 52\%\)

  • b. សិស្សប្រុស ៖ \(100\% - 52\% = 48\%\)

១៤លំហាត់ទី ១៤

ទឹកអំបិលមួយកែវមានទម្ងន់ \(400\,\text{g}\) ដែលមានផ្ទុកអំបិលសុទ្ធ \(24\,\text{g}\)។ គណនាកំហាប់ភាគរយនៃអំបិលក្នុងទឹកនោះ។

មើលដំណោះស្រាយ

កំហាប់ភាគរយអំបិល ៖

\[C = \frac{24}{400} \times 100\% = 6\%\]

១៥លំហាត់ទី ១៥

លោហៈផ្សំមួយដុំទម្ងន់ \(850\,\text{g}\) មានផ្ទុកទង់ដែង \(68\%\)។ គណនាទម្ងន់ទង់ដែងសុទ្ធដែលមានក្នុងដុំលោហៈនោះ។

មើលដំណោះស្រាយ

ទម្ងន់ទង់ដែងសុទ្ធ ៖

\[m = 850 \times 68\% = 850 \times 0.68 = 578\,\text{g}\]

៣៥លំហាត់ទី ៣៥

លោកវិចិត្រដាក់ប្រាក់ \(3000\,\$\) នៅធនាគារតាមអត្រាការប្រាក់សមាស \(5\%\) ក្នុងមួយឆ្នាំ។ គណនាប្រាក់សរុបដែលគាត់ទទួលបាននៅដំណាច់ឆ្នាំទី ៣ (\(P_3 = P_0(1+r)^3\))។

មើលដំណោះស្រាយ

ការប្រាក់សមាស ៖

\[\begin{aligned} P_3 &= 3000 \times (1 + 0.05)^3 = 3000 \times (1.05)^3 \\ &= 3000 \times 1.157625 = 3472.875\text{ ដុល្លារ} \end{aligned}\]

៣៦លំហាត់ទី ៣៦

ពូហេងបានផ្ញើប្រាក់ \(10\,000\,\$\) នៅធនាគារមួយក្នុងអត្រាការប្រាក់សមាស \(8\%\) ក្នុងមួយឆ្នាំ។

  1. គណនាប្រាក់សរុបនៅដំណាច់ឆ្នាំទី ១ និងឆ្នាំទី ២។

  2. គណនាផលដកនៃការប្រាក់សមាស និងការប្រាក់ទោលក្រោយរយៈពេល \(2\) ឆ្នាំ។

មើលដំណោះស្រាយ

ការប្រាក់សមាសធៀបនឹងការប្រាក់ទោល ៖

  • a. ឆ្នាំទី ១ ៖ \(P_1 = 10\,000(1.08) = 10\,800\,\$\)
    ឆ្នាំទី ២ ៖ \(P_2 = 10\,800(1.08) = 11\,664\,\$\)

  • b. ការប្រាក់សមាស \(2\) ឆ្នាំគឺ \(1664\,\$\)។ ការប្រាក់ទោលគឺ \(10\,000 \times 0.08 \times 2 = 1600\,\$\)។ ផលដកគឺ \(1664 - 1600 = 64\,\$\)។

៣៧លំហាត់ទី ៣៧

យុវជនម្នាក់អាយុ ២០ ឆ្នាំ បានផ្ញើប្រាក់ \(1000\,\$\) នៅធនាគារក្នុងអត្រាការប្រាក់សមាស \(10\%\) ក្នុងមួយឆ្នាំ។ តើគាត់នឹងទទួលបានប្រាក់សរុបប៉ុន្មាននៅពេលគាត់មានអាយុ ២៣ ឆ្នាំ?

មើលដំណោះស្រាយ

ប្រាក់សរុបអាយុ ២៣ ឆ្នាំ (\(3\) ឆ្នាំក្រោយ) ៖

\[P_3 = 1000 \times (1 + 0.10)^3 = 1000 \times 1.331 = 1331\text{ ដុល្លារ}\]

៣៨លំហាត់ទី ៣៨

កសិករម្នាក់ខ្ចីប្រាក់ \(4000\,\$\) ពីគ្រឹះស្ថានមីក្រូហិរញ្ញវត្ថុក្នុងអត្រាការប្រាក់សមាស \(12\%\) ក្នុងមួយឆ្នាំ។ រកចំនួនប្រាក់ដែលត្រូវសងសរុបនៅដំណាច់ឆ្នាំទី ២។

មើលដំណោះស្រាយ

ប្រាក់សងសរុប ៖

\[\begin{aligned} P_2 &= 4000 \times (1 + 0.12)^2 \\ &= 4000 \times 1.2544 = 5017.6\text{ ដុល្លារ} \end{aligned}\]

៣៩លំហាត់ទី ៣៩

តើប្រាក់ដើម \(P_0\) ត្រូវចំណាយពេលប៉ុន្មានឆ្នាំ ដើម្បីកើនឡើងទ្វេដង (\(2P_0\)) តាមអត្រាការប្រាក់ទោល \(10\%\) ក្នុងមួយឆ្នាំ?

មើលដំណោះស្រាយ

ពេលកើនឡើងទ្វេដង (ការប្រាក់ទោល \(10\%\)) ៖ \(I = P_0 \implies P_0 \times 0.10 \times t = P_0 \implies 0.10t = 1 \implies t = 10\,\) ឆ្នាំ ។

៤០លំហាត់ទី ៤០

តើប្រាក់ដើម \(P_0\) ត្រូវចំណាយពេលប៉ុន្មានឆ្នាំ ដើម្បីកើនឡើងទ្វេដងតាមអត្រាការប្រាក់ទោល \(8\%\) ក្នុងមួយឆ្នាំ?

មើលដំណោះស្រាយ

ពេលកើនឡើងទ្វេដង (ការប្រាក់ទោល \(8\%\)) ៖ \(P_0 \times 0.08 \times t = P_0 \implies 0.08t = 1 \implies t = \frac{1}{0.08} = 12.5\,\) ឆ្នាំ (១២ ឆ្នាំ ៦ ខែ)។

៤១លំហាត់ទី ៤១

គេមានសូលុយស្យុងអាស៊ីតពីរកែវ ៖ កែវទីមួយមានកំហាប់ \(20\%\) និងកែវទីពីរមានកំហាប់ \(50\%\)។ តើត្រូវយកសូលុយស្យុងពីកែវនីមួយៗប៉ុន្មានលីត្រ ដើម្បីលាយបញ្ចូលគ្នាឱ្យបានសូលុយស្យុងថ្មីចំណុះ \(60\,\text{L}\) ដែលមានកំហាប់ \(30\%\)?

មើលដំណោះស្រាយ

ល្បាយសូលុយស្យុងអាស៊ីត ៖ តាង \(x\) ជាចំណុះកែវទីមួយ និង \(y = 60 - x\) ជាចំណុះកែវទីពីរ ៖

\[\begin{aligned} 0.20x + 0.50(60 - x) &= 0.30 \times 60 \\ 0.20x + 30 - 0.50x &= 18 \implies -0.30x = -12 \end{aligned}\]
\[x = 40\,\text{L} \quad{} ; \quad{} y = 20\,\text{L}\]

៤២លំហាត់ទី ៤២

ទឹកអំបិល \(300\,\text{g}\) មានកំហាប់អំបិល \(6\%\)។ តើគេត្រូវបន្ថែមទឹកសុទ្ធប៉ុន្មានក្រាមទៀត ដើម្បីឱ្យកំហាប់អំបិលធ្លាក់ចុះមកត្រឹម \(4\%\)?

មើលដំណោះស្រាយ

បន្ថែមទឹកសុទ្ធ ៖ បរិមាណអំបិលថេរ \(300 \times 0.06 = 18\,\text{g}\)។ ទម្ងន់ទឹកអំបិលថ្មី \(M = \frac{18}{0.04} = 450\,\text{g}\)។ ទឹកសុទ្ធត្រូវបន្ថែម \(450 - 300 = 150\,\text{g}\)។

៤៣លំហាត់ទី ៤៣

ទឹកផ្លែឈើ \(500\,\text{mL}\) មានជាតិស្ករ \(12\%\)។ តើគេត្រូវរម្ងួតទឹកឱ្យហួតអស់ប៉ុន្មាន \(\text{mL}\) ទើបកំហាប់ស្ករកើនឡើងដល់ \(15\%\)?

មើលដំណោះស្រាយ

រម្ងួតទឹក ៖ បរិមាណស្ករថេរ \(500 \times 0.12 = 60\,\text{g}\)។ ចំណុះទឹកថ្មី \(V = \frac{60}{0.15} = 400\,\text{mL}\)។ ទឹកត្រូវរម្ងួតឱ្យហួត \(500 - 400 = 100\,\text{mL}\)។

៤៤លំហាត់ទី ៤៤

មនុស្សបីនាក់ \(A, B, C\) ចូលទុនរកស៊ីជាមួយគ្នា ៖ \(A\) ចូលទុន \(3000\,\$\) រយៈពេល \(12\) ខែ, \(B\) ចូលទុន \(4000\,\$\) រយៈពេល \(9\) ខែ និង \(C\) ចូលទុន \(5000\,\$\) រយៈពេល \(6\) ខែ។ នៅដំណាច់ឆ្នាំ ក្រុមហ៊ុនទទួលបានប្រាក់ចំណេញ \(5100\,\$\)។ រកប្រាក់ចំណេញដែលម្នាក់ៗទទួលបានស្របតាមសមាមាត្រនៃទុននិងពេលវេលា។

មើលដំណោះស្រាយ

ចែកប្រាក់ចំណេញតាមទុននិងពេលវេលា ៖

  • \(A\) ៖ \(3000 \times 12 = 36\,000\) ភាគ

  • \(B\) ៖ \(4000 \times 9 = 36\,000\) ភាគ

  • \(C\) ៖ \(5000 \times 6 = 30\,000\) ភាគ

ផលធៀប \(36 : 36 : 30 = 6 : 6 : 5\) (សរុប \(17\) ភាគ)។ មួយភាគ \(\frac{5100}{17} = 300\,\$\)។

  • \(A\) ទទួលបាន ៖ \(6 \times 300 = 1800\,\$\)

  • \(B\) ទទួលបាន ៖ \(6 \times 300 = 1800\,\$\)

  • \(C\) ទទួលបាន ៖ \(5 \times 300 = 1500\,\$\)

៤៥លំហាត់ទី ៤៥

បើ \(x, y, z\) ផ្ទៀងផ្ទាត់សមាមាត្រ \(\dfrac{x}{2} = \dfrac{y}{3} = \dfrac{z}{4}\) និង \(2x^2 + 3y^2 - z^2 = 76\)។ រកតម្លៃនៃ \(x, y, z\)។

មើលដំណោះស្រាយ

រក \(x, y, z\) ៖ តាង \(\frac{x}{2} = \frac{y}{3} = \frac{z}{4} = k \implies x = 2k, y = 3k, z = 4k\)។ ជំនួស ៖ \(2(4k^2) + 3(9k^2) - 16k^2 = 76 \implies 19k^2 = 76 \implies k^2 = 4 \implies k = \pm 2\)។

  • បើ \(k = 2\) ៖ \((x, y, z) = (4, 6, 8)\)

  • បើ \(k = -2\) ៖ \((x, y, z) = (-4, -6, -8)\)

៤៦លំហាត់ទី ៤៦

បង្ហាញថា ប្រសិនបើ \(\dfrac{a}{b} = \dfrac{c}{d}\) នោះគេបាន ៖

\[\frac{a^2 + c^2}{b^2 + d^2} = \frac{ac}{bd}\]

មើលដំណោះស្រាយ

បង្ហាញសមភាព ៖ តាង \(\frac{a}{b} = \frac{c}{d} = k \implies a = bk, c = dk\)។ អង្គខាងឆ្វេង ៖ \(\frac{b^2k^2 + d^2k^2}{b^2 + d^2} = \frac{k^2(b^2 + d^2)}{b^2 + d^2} = k^2\)។ អង្គខាងស្តាំ ៖ \(\frac{ac}{bd} = \frac{(bk)(dk)}{bd} = k^2\)។ អង្គទាំងពីរស្មើគ្នា។

៤៧លំហាត់ទី ៤៧

បង្ហាញថា ប្រសិនបើ \(\dfrac{a}{b} = \dfrac{c}{d}\) នោះគេបាន ៖

\[\frac{a+b}{a-b} = \frac{c+d}{c-d} \quad{} (a \ne b, c \ne d)\]

មើលដំណោះស្រាយ

បង្ហាញសមភាព ៖ តាង \(\frac{a}{b} = \frac{c}{d} = k \implies a = bk, c = dk\)។ \(\frac{a+b}{a-b} = \frac{bk+b}{bk-b} = \frac{k+1}{k-1}\) \(\frac{c+d}{c-d} = \frac{dk+d}{dk-d} = \frac{k+1}{k-1}\)។ ដូចនេះ \(\frac{a+b}{a-b} = \frac{c+d}{c-d}\)។

៤៨លំហាត់ទី ៤៨

កសិករម្នាក់មានចំណីសត្វល្មមសម្រាប់ចិញ្ចឹមគោ \(20\) ក្បាលក្នុងរយៈពេល \(30\) ថ្ងៃ។ ក្រោយចិញ្ចឹមបាន \(10\) ថ្ងៃ គាត់បានទិញគោបន្ថែមចំនួន \(5\) ក្បាលទៀត។ តើចំណីដែលនៅសល់អាចចិញ្ចឹមគោទាំងអស់បានប៉ុន្មានថ្ងៃទៀត?

មើលដំណោះស្រាយ

ចំណីសត្វដែលនៅសល់ ៖ ក្រោយ \(10\) ថ្ងៃ ចំណីដែលនៅសល់ល្មមសម្រាប់គោ \(20\) ក្បាលស៊ីបាន \(20\) ថ្ងៃទៀត (\(20 \times 20 = 400\) គោ-ថ្ងៃ)។ ពេលមានគោ \(25\) ក្បាល ចំនួនថ្ងៃស៊ីបានគឺ ៖

\[t = \frac{400}{25} = 16\,\text{ថ្ងៃ}\]

៤៩លំហាត់ទី ៤៩

ជាងកាត់ដេរ \(5\) នាក់ កាត់អាវបាន \(60\) ក្នុងរយៈពេល \(4\) ថ្ងៃ។ តើជាងកាត់ដេរ \(8\) នាក់ អាចកាត់អាវបានប៉ុន្មានក្នុងរយៈពេល \(6\) ថ្ងៃ (សមាមាត្រចម្រុះ)?

មើលដំណោះស្រាយ

សមាមាត្រចម្រុះ ៖ កម្លាំង \(1\) នាក់ក្នុង \(1\) ថ្ងៃកាត់បាន \(\frac{60}{5 \times 4} = 3\) អាវ។ ជាង \(8\) នាក់ក្នុងរយៈពេល \(6\) ថ្ងៃ កាត់បាន ៖

\[N = 8 \times 6 \times 3 = 144\,\text{អាវ}\]

៥០លំហាត់ទី ៥០

ក្រុមហ៊ុនមួយលក់ដីមួយកន្លែងបានប្រាក់កម្រៃជើងសារ \(3\%\) ដែលស្មើនឹង \(2700\,\$\)។ ក្រោយមក ក្រុមហ៊ុនយកប្រាក់កម្រៃនេះទៅទិញភាគហ៊ុន ហើយទទួលបានចំណេញ \(15\%\) បន្ថែមទៀត។ គណនាតម្លៃលក់នៃដី និងប្រាក់សរុបចុងក្រោយដែលក្រុមហ៊ុនទទួលបាន។

មើលដំណោះស្រាយ

ដីនិងប្រាក់កម្រៃ ៖

  • តម្លៃដី ៖ \(\frac{2700}{0.03} = 90\,000\,\$\)

  • ប្រាក់កម្រៃចំណេញបន្ថែម \(15\%\) ៖ \(2700 \times (1 + 0.15) = 3105\,\$\)
