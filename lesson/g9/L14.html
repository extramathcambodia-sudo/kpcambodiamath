មុំនៃរង្វង់ (Angle Properties in Circles) គឺជាមូលដ្ឋានគ្រឹះដ៏សំខាន់នៃត្រីកោណមាត្រ និងការរុករកផ្កាយលើលម្ហអាកាស ៖

  • លោក Thales of Miletus (៦២៤-៥៤៦ មុន គ.ស.) ៖ គណិតវិទូក្រិកដំបូងគេបង្អស់ បានរកឃើញទ្រឹស្តីបទដ៏ល្បីល្បាញ «ទ្រឹស្តីបទតាលែសលើរង្វង់» ៖ មុំចារឹកក្នុងកន្លះរង្វង់ តែងតែជាមុំកែង (\(90^\circ\))។ រឿងព្រេងដំណាលថា លោកតាលែសសប្បាយចិត្តយ៉ាងខ្លាំងរហូតដល់ថ្វាយគោ ១០០ ក្បាលដល់អាទិទេព!

  • លោក Claudius Ptolemy (១០០-១៧០ គ.ស.) ៖ គណិតវិទូ និងតារាវិទូក្រិក-អេហ្ស៊ីប បានសរសេរសៀវភៅ Almagest ដែលមាន «ទ្រឹស្តីបទតូលេមេ» ដ៏អស្ចារ្យសម្រាប់ចតុកោណចារឹកក្នុងរង្វង់ ៖ ផលគុណអង្កត់ទ្រូងស្មើនឹងផលបូកនៃផលគុណជ្រុងឈម (\(AC \cdot BD = AB \cdot CD + BC \cdot AD\))។

  • ការវាស់មុំលើមេឃ ៖ ជនជាតិបាប៊ីឡូនបុរាណបានបែងចែករង្វង់ជា \(360^\circ\) ព្រោះវាប្រហាក់ប្រហែលនឹងចំនួនថ្ងៃក្នុងមួយឆ្នាំ (\(365\) ថ្ងៃ) ដែលអនុញ្ញាតឱ្យព្រះអាទិត្យធ្វើដំណើរបានប្រមាណ \(1^\circ\) ក្នុងមួយថ្ងៃលើផ្ទៃមេឃ។

មុំផ្ចិត និងមុំចារឹកក្នុងរង្វង់

មុំផ្ចិត និងមុំចារឹកក្នុង

  • មុំផ្ចិត (Central Angle) ៖ ជាមុំដែលមានកំពូលនៅលើផ្ចិតនៃរង្វង់ ហើយជ្រុងទាំងពីរជាកាំនៃរង្វង់។ រង្វាស់មុំផ្ចិតស្មើនឹងរង្វាស់ធ្នូស្កាត់ ៖

    \[\angle AOB = \overset{\frown}{AB}\]

  • មុំចារឹកក្នុង (Inscribed Angle) ៖ ជាមុំដែលមានកំពូលនៅលើរង្វង់ ហើយជ្រុងទាំងពីរជាអង្កត់ធ្នូនៃរង្វង់។ រង្វាស់មុំចារឹកក្នុងស្មើនឹងពាក់កណ្តាលរង្វាស់ធ្នូស្កាត់ ៖

    \[\angle ACB = \frac{1}{2}\overset{\frown}{AB} = \frac{1}{2}\angle AOB\]

រូបភាពនេះកំពុងរៀបចំ

លក្ខណៈសំខាន់ៗនៃមុំចារឹកក្នុង

  1. ស្កាត់ធ្នូតែមួយ ៖ មុំចារឹកក្នុងទាំងឡាយណាដែលស្កាត់ធ្នូតែមួយ (ឬធ្នូប៉ុនគ្នា) មានរង្វាស់ស្មើគ្នា ៖ \(\angle ACB = \angle ADB\)។

  2. ស្កាត់កន្លះរង្វង់ ៖ មុំចារឹកក្នុងដែលស្កាត់កន្លះរង្វង់ ជា មុំកែង (\(90^\circ\)) ៖ \(\angle ACB = 90^\circ\)។

ក្នុងរង្វង់ផ្ចិត \(O\) បើមុំផ្ចិត \(\angle AOB = 80^\circ\) គណនារង្វាស់មុំចារឹកក្នុង \(\angle ACB\) ដែលស្កាត់ធ្នូជាមួយគ្នា។

រូបភាពនេះកំពុងរៀបចំ

តាមទ្រឹស្តីបទមុំចារឹកក្នុង ៖

\[\angle ACB = \frac{1}{2}\angle AOB = \frac{1}{2}(80^\circ) = 40^\circ\]

ប្រតិបត្តិ

អង្កត់ផ្ចិត \(AB\) នៃរង្វង់ផ្ចិត \(O\) និងចំណុច \(C\) លើរង្វង់។ បើ \(\angle CAB = 35^\circ\) គណនាមុំ \(\angle CBA\)។

មុំបង្កើតដោយបន្ទាត់ប៉ះ និងអង្កត់ធ្នូ

មុំប៉ះ-អង្កត់ធ្នូ

មុំដែលបង្កើតឡើងដោយបន្ទាត់ប៉ះ និងអង្កត់ធ្នូគូសចេញពីចំណុចប៉ះ មានរង្វាស់ស្មើនឹងពាក់កណ្តាលនៃរង្វាស់ធ្នូដែលវាស្កាត់ (ស្មើនឹងមុំចារឹកក្នុងដែលស្កាត់ធ្នូនោះ) ៖

\[\angle TAB = \frac{1}{2}\overset{\frown}{AB} = \angle ACB\]

រូបភាពនេះកំពុងរៀបចំ

ឧទាហរណ៍

បន្ទាត់ប៉ះ \(xy\) ប៉ះរង្វង់ត្រង់ \(A\)។ អង្កត់ធ្នូ \(AB\) ខណ្ឌបានធ្នូ \(\overset{\frown}{AB} = 100^\circ\)។ គណនាមុំ \(\angle xAB\)។

ដំណោះស្រាយ

\[\angle xAB = \frac{1}{2}\overset{\frown}{AB} = \frac{1}{2}(100^\circ) = 50^\circ\]

ពីចំណុច \(P\) ក្រៅរង្វង់ គូសបន្ទាត់ប៉ះពីរ \(PA\) និង \(PB\)។ បើ \(\angle APB = 50^\circ\) រករង្វាស់ធ្នូតូច \(\overset{\frown}{AB}\) និងធ្នូធំ \(\overset{\frown}{AB}\)។

ចតុកោណចារឹកក្នុងរង្វង់ (Cyclic Quadrilaterals)

លក្ខណៈចតុកោណចារឹកក្នុងរង្វង់

ចតុកោណមួយអាចចារឹកក្នុងរង្វង់បាន លុះត្រាតែ ៖

  1. ផលបូកនៃរង្វាស់មុំឈមទាំងពីរស្មើនឹង \(180^\circ\) ៖

    \[\angle A + \angle C = 180^\circ \quad{} ; \quad{} \angle B + \angle D = 180^\circ\]

  2. មុំក្រៅត្រង់កំពូលមួយស្មើនឹងមុំក្នុងឈមនឹងវា ៖ \(\angle DCE = \angle A\)។

ក្នុងរង្វង់ផ្ចិត \(O\) បើធ្នូ \(\overset{\frown}{AB} = 70^\circ\) គណនាមុំផ្ចិត \(\angle AOB\) និងមុំចារឹកក្នុង \(\angle ACB\)។

មើលដំណោះស្រាយ

គណនាមុំផ្ចិត និងមុំចារឹកក្នុង ៖

  • បើ \(\overset{\frown}{AB} = 70^\circ \implies \angle AOB = 70^\circ\) (មុំផ្ចិត)

  • មុំចារឹកក្នុងស្កាត់ធ្នូនេះ ៖ \(\angle ACB = \frac{1}{2}\overset{\frown}{AB} = \frac{70^\circ}{2} = 35^\circ\)

២លំហាត់ទី ២

បង្ហាញថាមុំចារឹកក្នុងកន្លះរង្វង់តែងតែជាមុំកែង (\(90^\circ\))។

មើលដំណោះស្រាយ

មុំចារឹកក្នុងស្កាត់កន្លះរង្វង់ ៖ \(AB\) ជាអង្កត់ផ្ចិត នាំឱ្យធ្នូ \(\overset{\frown}{AB} = 180^\circ\)។ ចំពោះគ្រប់ចំណុច \(C\) លើកន្លះរង្វង់ ៖ \(\angle ACB = \frac{180^\circ}{2} = 90^\circ\) (ទ្រឹស្តីបទតាលែសលើរង្វង់)។

៣លំហាត់ទី ៣

បង្ហាញថាមុំចារឹកក្នុងទាំងឡាយណាដែលស្កាត់ធ្នូតែមួយមានរង្វាស់ស្មើគ្នា។

មើលដំណោះស្រាយ

មុំចារឹកក្នុងស្កាត់ធ្នូតែមួយ ៖ ចំណុច \(C, D\) លើរង្វង់ស្កាត់ធ្នូ \(\overset{\frown}{AB}\) តែមួយ នាំឱ្យ \(\angle ACB = \angle ADB = \frac{1}{2}\overset{\frown}{AB}\)។

៤លំហាត់ទី ៤

បន្ទាត់ \(xy\) ប៉ះរង្វង់ត្រង់ \(A\)។ អង្កត់ធ្នូ \(AB\) ខណ្ឌបានធ្នូ \(\overset{\frown}{AB} = 110^\circ\)។ គណនាមុំ \(\angle xAB\)។

មើលដំណោះស្រាយ

មុំបង្កើតដោយបន្ទាត់ប៉ះ និងអង្កត់ធ្នូ ៖ \(xy\) ប៉ះរង្វង់ត្រង់ \(A\) និងអង្កត់ធ្នូ \(AB\)។ បើ \(\overset{\frown}{AB} = 110^\circ\) នោះ \(\angle xAB = \frac{110^\circ}{2} = 55^\circ\)។ មុំចារឹកក្នុងស្កាត់ធ្នូនេះក៏ស្មើ \(55^\circ\) ដែរ។

៥លំហាត់ទី ៥

អង្កត់ធ្នូពីរ \(AB\) និង \(CD\) កាត់គ្នាត្រង់ \(P\) ក្នុងរង្វង់។ បើ \(\overset{\frown}{AC} = 40^\circ\) និង \(\overset{\frown}{BD} = 80^\circ\) រកមុំ \(\angle APC\)។

មើលដំណោះស្រាយ

មុំមានកំពូលក្នុងរង្វង់ ៖ អង្កត់ធ្នូ \(AB\) និង \(CD\) កាត់គ្នាត្រង់ \(P\) ក្នុងរង្វង់ ៖ \(\angle APC = \frac{\overset{\frown}{AC} + \overset{\frown}{BD}}{2} = \frac{40^\circ + 80^\circ}{2} = 60^\circ\)។

៦លំហាត់ទី ៦

ខណ្ឌបន្ទាត់ពីរ \(PAB\) និង \(PCD\) កាត់គ្នាត្រង់ \(P\) ក្រៅរង្វង់។ បើ \(\overset{\frown}{BD} = 100^\circ\) និង \(\overset{\frown}{AC} = 30^\circ\) រកមុំ \(\angle P\)។

មើលដំណោះស្រាយ

មុំមានកំពូលក្រៅរង្វង់ ៖ ខណ្ឌបន្ទាត់ \(PAB\) និង \(PCD\) កាត់គ្នាត្រង់ \(P\) ក្រៅរង្វង់ ៖ \(\angle P = \frac{\overset{\frown}{BD} - \overset{\frown}{AC}}{2} = \frac{100^\circ - 30^\circ}{2} = 35^\circ\)។

៧លំហាត់ទី ៧

ពីចំណុច \(P\) ក្រៅរង្វង់ គូសបន្ទាត់ប៉ះពីរ \(PA\) និង \(PB\)។ បើ \(\angle P = 40^\circ\) គណនាមុំផ្ចិត \(\angle AOB\)។

មើលដំណោះស្រាយ

មុំរវាងបន្ទាត់ប៉ះពីរ ៖ បន្ទាត់ប៉ះ \(PA\) និង \(PB\) មានមុំ \(\angle P = \frac{\text{ធ្នូធំ} - \text{ធ្នូតូច}}{2}\)។ ដោយ ធ្នូធំ \(= 360^\circ - \) ធ្នូតូច នាំឱ្យ \(\angle P = 180^\circ - \) ធ្នូតូច \( = 180^\circ - \angle AOB\)។ បើ \(\angle P = 40^\circ \implies \angle AOB = 140^\circ\)។

៨លំហាត់ទី ៨

ចតុកោណ \(ABCD\) ចារឹកក្នុងរង្វង់មាន \(\angle A = 75^\circ, \angle B = 110^\circ\)។ គណនាមុំ \(\angle C\) និង \(\angle D\)។

មើលដំណោះស្រាយ

ចតុកោណចារឹកក្នុងរង្វង់ ៖ \(ABCD\) ចារឹកក្នុងរង្វង់ ៖ \(\angle A + \angle C = 180^\circ\) និង \(\angle B + \angle D = 180^\circ\)។ បើ \(\angle A = 75^\circ \implies \angle C = 105^\circ\)។ បើ \(\angle B = 110^\circ \implies \angle D = 70^\circ\)។

៩លំហាត់ទី ៩

បង្ហាញថាមុំក្រៅនៃចតុកោណចារឹកក្នុងរង្វង់ស្មើនឹងមុំក្នុងឈមនឹងវា។

មើលដំណោះស្រាយ

មុំក្រៅនៃចតុកោណចារឹកក្នុងរង្វង់ ៖ មុំក្រៅត្រង់កំពូល \(C\) បន្ថែមនឹង \(\angle C\) (\(180^\circ - \angle C\)) នាំឱ្យស្មើនឹង \(\angle A\) (មុំក្នុងឈម)។

១០លំហាត់ទី ១០

ត្រីកោណសម័ង្ស \(ABC\) ចារឹកក្នុងរង្វង់។ គណនារង្វាស់ធ្នូនីមួយៗ និងមុំផ្ចិតនីមួយៗ។

មើលដំណោះស្រាយ

ត្រីកោណសម័ង្សចារឹកក្នុងរង្វង់ ៖ ជ្រុងទាំងបីស្មើគ្នា ចែករង្វង់ជា ៣ ធ្នូប៉ុនគ្នា ៖ \(\overset{\frown}{AB} = \overset{\frown}{BC} = \overset{\frown}{CA} = \frac{360^\circ}{3} = 120^\circ\)។ មុំផ្ចិតនីមួយៗស្មើ \(120^\circ\) ហើយមុំក្នុងត្រីកោណស្មើ \(60^\circ\)។

១១លំហាត់ទី ១១

ការេ \(ABCD\) ចារឹកក្នុងរង្វង់។ គណនារង្វាស់ធ្នូនីមួយៗ និងមុំផ្ចិតដែលស្កាត់ជ្រុងមួយនៃការេ។

មើលដំណោះស្រាយ

ការេចារឹកក្នុងរង្វង់ ៖ ជ្រុងទាំង ៤ ចែករង្វង់ជា ៤ ធ្នូស្មើគ្នា ៖ ធ្នូនីមួយៗស្មើ \(\frac{360^\circ}{4} = 90^\circ\)។ មុំផ្ចិតស្មើ \(90^\circ\) (អង្កត់ទ្រូងកែងគ្នា)។

១២លំហាត់ទី ១២

ឆកោណទៀងទាត់ចារឹកក្នុងរង្វង់។ បង្ហាញថាជ្រុងនៃឆកោណស្មើនឹងកាំរង្វង់ \(R\)។

មើលដំណោះស្រាយ

ឆកោណទៀងទាត់ចារឹកក្នុងរង្វង់ ៖ ធ្នូនីមួយៗស្មើ \(\frac{360^\circ}{6} = 60^\circ\)។ មុំផ្ចិតស្មើ \(60^\circ\) នាំឱ្យត្រីកោណផ្ចិតជាត្រីកោណសម័ង្ស \(\implies a = R\)។

១៣លំហាត់ទី ១៣

អង្កត់ផ្ចិត \(AB\) និងចំណុច \(C\) លើរង្វង់។ បើ \(\angle A = 35^\circ\) គណនាមុំ \(\angle B\) និងរង្វាស់ធ្នូ \(\overset{\frown}{AC}, \overset{\frown}{BC}\)។

មើលដំណោះស្រាយ

ត្រីកោណកែងក្នុងរង្វង់ ៖ \(AB\) ជាអង្កត់ផ្ចិត, \(C\) លើរង្វង់។ បើ \(\angle A = 35^\circ\) នោះ \(\angle B = 90^\circ - 35^\circ = 55^\circ\)។ ធ្នូ \(\overset{\frown}{BC} = 2(35^\circ) = 70^\circ\) និង \(\overset{\frown}{AC} = 2(55^\circ) = 110^\circ\)។

១៤លំហាត់ទី ១៤

ត្រីកោណសមបាត \(ABC\) មានកំពូល \(A = 40^\circ\) ចារឹកក្នុងរង្វង់។ គណនាមុំផ្ចិត \(\angle BOC, \angle AOB, \angle AOC\)។

មើលដំណោះស្រាយ

គណនាមុំ \(\angle BOC\) ៖ \(\Delta ABC\) សមបាតកំពូល \(A\) មាន \(\angle A = 40^\circ\) ចារឹកក្នុងរង្វង់ ៖ \(\angle B = \angle C = 70^\circ\)។ មុំផ្ចិត \(\angle BOC = 2\angle A = 80^\circ\)។ \(\angle AOB = \angle AOC = 2(70^\circ) = 140^\circ\)។

១៥លំហាត់ទី ១៥

អង្កត់ធ្នូ \(AB\) ខណ្ឌរង្វង់ជាធ្នូតូច \(80^\circ\)។ គណនាមុំចារឹកក្នុងដែលស្កាត់ធ្នូតូច និងធ្នូធំ។

មើលដំណោះស្រាយ

មុំចារឹកក្នុងស្កាត់ធ្នូធំ ៖ បើធ្នូតូច \(\overset{\frown}{AB} = 80^\circ\) នោះធ្នូធំស្មើ \(360^\circ - 80^\circ = 280^\circ\)។ មុំចារឹកក្នុងដែលស្កាត់ធ្នូធំស្មើ \(\frac{280^\circ}{2} = 140^\circ\)។ ផលបូកមុំចារឹកក្នុងសងខាងអង្កត់ធ្នូ ៖ \(40^\circ + 140^\circ = 180^\circ\)។

១៦លំហាត់ទី ១៦

បង្ហាញថាកន្លះបន្ទាត់ពុះមុំចារឹកក្នុង \(\angle BAC\) កាត់រង្វង់ត្រង់ចំណុចកណ្តាលនៃធ្នូ \(\overset{\frown}{BC}\)។

មើលដំណោះស្រាយ

បន្ទាត់ពុះមុំចារឹកក្នុង ៖ កន្លះបន្ទាត់ពុះមុំ \(\angle BAC\) កាត់រង្វង់ត្រង់ \(M\) នាំឱ្យ \(\overset{\frown}{BM} = \overset{\frown}{MC}\) (\(M\) ជាចំណុចកណ្តាលនៃធ្នូ \(\overset{\frown}{BC}\))។

១៧លំហាត់ទី ១៧

បង្ហាញថាបើអង្កត់ធ្នូពីរស្របគ្នា \(AB \parallel CD\) នោះធ្នូដែលខណ្ឌចន្លោះមានរង្វាស់ស្មើគ្នា (\(\overset{\frown}{AC} = \overset{\frown}{BD}\))។

មើលដំណោះស្រាយ

អង្កត់ធ្នូស្របគ្នា ៖ បើ \(AB \parallel CD\) នោះធ្នូដែលខណ្ឌចន្លោះស្មើគ្នា ៖ \(\overset{\frown}{AC} = \overset{\frown}{BD}\)។

១៨លំហាត់ទី ១៨

បង្ហាញថាចតុកោណព្នាយចារឹកក្នុងរង្វង់បាន លុះត្រាតែវាជាចតុកោណព្នាយសមបាត។

មើលដំណោះស្រាយ

ចតុកោណព្នាយសមបាតចារឹកក្នុងរង្វង់ ៖ ដោយ \(AB \parallel CD\) នាំឱ្យ \(\overset{\frown}{AD} = \overset{\frown}{BC} \implies AD = BC\)។ ដូចនេះចតុកោណព្នាយចារឹកក្នុងរង្វង់ត្រូវតែជាចតុកោណព្នាយសមបាត។

១៩លំហាត់ទី ១៩

ពីចំណុច \(P\) គូសបន្ទាត់ប៉ះពីរ \(PA\) និង \(PB\) ទៅរង្វង់។ បើ \(\angle APB = 60^\circ\) បង្ហាញថា \(\Delta PAB\) ជាត្រីកោណសម័ង្ស។

មើលដំណោះស្រាយ

បន្ទាត់ប៉ះកាត់គ្នា ៖ \(PA, PB\) ប៉ះរង្វង់ត្រង់ \(A, B\)។ បើ \(\angle APB = 60^\circ\) នោះ \(\Delta PAB\) ជាត្រីកោណសម័ង្ស (\(PA = PB\) និងមានមុំ \(60^\circ\))។ ដូចនេះ \(AB = PA = PB\)។

២០លំហាត់ទី ២០

ក្នុងរង្វង់ផ្ចិត \(O\) បើកាំពីរ \(OA \perp OB\) គណនាប្រវែងអង្កត់ធ្នូ \(AB\) និងមុំចារឹកក្នុងស្កាត់ \(AB\)។

មើលដំណោះស្រាយ

មុំផ្ចិត និងកាំកែងគ្នា ៖ បើ \(OA \perp OB\) នោះ \(\angle AOB = 90^\circ \implies AB = R\sqrt{2}\)។ មុំចារឹកក្នុងស្កាត់ \(AB\) ស្មើ \(45^\circ\) ឬ \(135^\circ\)។

២១លំហាត់ទី ២១

ចតុកោណ \(ABCD\) ចារឹកក្នុងរង្វង់មាន \(\angle A = 3x, \angle C = 2x\)។ គណនាមុំទាំងពីរ។

មើលដំណោះស្រាយ

រកមុំនៃចតុកោណចារឹកក្នុងរង្វង់ ៖ \(\angle A = 3x, \angle C = 2x \implies 3x + 2x = 180^\circ \implies 5x = 180^\circ \implies x = 36^\circ\)។ \(\angle A = 108^\circ, \angle C = 72^\circ\)។

២២លំហាត់ទី ២២

ចតុកោណ \(ABCD\) ចារឹកក្នុងរង្វង់មាន \(\angle B = y + 20^\circ, \angle D = 2y - 50^\circ\)។ គណនា \(y\) និងបញ្ជាក់ប្រភេទចតុកោណ។

មើលដំណោះស្រាយ

រកមុំនៃចតុកោណចារឹកក្នុងរង្វង់ ៖ \(\angle B = y + 20^\circ, \angle D = 2y - 50^\circ \implies 3y - 30^\circ = 180^\circ \implies 3y = 210^\circ \implies y = 70^\circ\)។ \(\angle B = 90^\circ, \angle D = 90^\circ\) (ជាចតុកោណកែង)។

២៣លំហាត់ទី ២៣

រង្វង់ពីរកាត់គ្នាត្រង់ \(A\) និង \(B\)។ បង្ហាញថាអង្កត់ធ្នូរួម \(AB\) កែងនឹងបន្ទាត់តភ្ជាប់ផ្ចិត \(OO'\)។

មើលដំណោះស្រាយ

ចំណុចរួមនៃរង្វង់ពីរ ៖ រង្វង់ពីរកាត់គ្នាត្រង់ \(A\) និង \(B\)។ អង្កត់ធ្នូរួម \(AB\) កែងនឹងបន្ទាត់តភ្ជាប់ផ្ចិត \(OO'\) ត្រង់ចំណុចកណ្តាល។

រូបមន្ត Heron ជាករណីពិសេសនៃ Brahmagupta ៖ កាលណាជ្រុងមួយខិតជិត \(0\) (\(d = 0\)) ចតុកោណក្លាយជាត្រីកោណ ហើយរូបមន្តក្លាយជា \(S = \sqrt{p(p-a)(p-b)(p-c)}\)។

៤៨លំហាត់ទី ៤៨

ពន្យល់ពីលក្ខខណ្ឌចាំបាច់ និងគ្រប់គ្រាន់ដើម្បីឱ្យ ៤ ចំណុចស្ថិតនៅលើរង្វង់តែមួយ (Concyclic Points)។

មើលដំណោះស្រាយ

លក្ខខណ្ឌចំណុច ៤ លើរង្វង់តែមួយ ៖ ផលបូកមុំឈមស្មើ \(180^\circ\) ឬមុំពីរបង្កើតដោយអង្កត់ទ្រូងស្មើគ្នា។

៤៩លំហាត់ទី ៤៩

បង្ហាញពីវិធីសាស្ត្រគូសបន្ទាត់ជំនួយដើម្បីដោះស្រាយលំហាត់មុំរង្វង់។

មើលដំណោះស្រាយ

គន្លឹះដោះស្រាយលំហាត់មុំរង្វង់ ៖ តែងតែភ្ជាប់ចំណុចលើរង្វង់ទៅកាន់ផ្ចិត ឬគូសអង្កត់ផ្ចិតដើម្បីបង្កើតមុំកែង \(90^\circ\)។

៥០លំហាត់ទី ៥០

សរសេរការពិពណ៌នាអំពីការអនុវត្តរង្វាស់មុំរង្វង់ក្នុងការរុករកផ្កាយ និងប្រព័ន្ធនាវាចរណ៍សម័យបុរាណ និងសម័យទំនើប។

មើលដំណោះស្រាយ

ការអនុវត្តតារាសាស្ត្រ និងនាវាចរណ៍ ៖ ការវាស់មុំធ្នូផ្ទៃមេឃ (Arcminutes, Arcseconds) ក្នុងការកំណត់ទីតាំងផ្កាយ និងការធ្វើដំណើរលើផ្ទៃផែនដីរាងស្វ៊ែរ។

សំណួរពហុជ្រើសរើស
