ប្រព័ន្ធប្រឡងគំរូទាញសំណួរពី JSON មាននាឡិកាកំណត់ពេល (Timer) ជ្រើសរើសចម្លើយ ផ្ទៀងផ្ទាត់ និងកែពិន្ទុភ្លាមៗជាមួយអត្រាកំណែ។

💡 របៀបបើក និងណែនាំ AI ឱ្យបន្តបង្កើតប្រព័ន្ធ

  1. របៀបបើកមើលលើកុំព្យូទ័រ៖
    • អាចចុច Double-click លើ File index.html នេះដើម្បីបើកមើលតាម Chrome/Firefox/Safari បានភ្លាមៗ។
    • ឬបើក Terminal ក្នុង Folder នេះ រួចវាយ៖ python3 -m http.server 8000 រួចបើក http://localhost:8000។
  2. របៀបសួរ AI (ChatGPT / Claude / Gemini) ឱ្យបន្ថែមមុខងារ៖

    អ្នកអាចចម្លងកូដក្នុង File គំរូទាំងបីនេះ ផ្ញើទៅកាន់ AI ហើយប្រើ Prompt ដូចខាងក្រោម៖

    "I have a local math exam and lesson system. 
Here is my sample code in exam-demo.html and static/data/sample_bank.json.
Please help me write a Python/Node.js backend or generate 10 new math questions for Grade 8 with step-by-step solutions."
  3. របៀបសួរ AI បង្កើតសំណង់ធរណីមាត្រថ្មី៖ 
    "Here is my geometry construction template in geometry-angle-bisector.html. 
Please help me create a new step-by-step SVG construction for Perpendicular Bisector with ruler and compass steps."
